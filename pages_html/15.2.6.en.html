One-line summary: the 10 batch tools behind the "tools" icon on the toolbar — conversion into the library, batch processing, material mapping and script browsing all start here.

How to open it

  1. Find the tools icon on the top toolbar (tooltip "Quick tools: run the scripts in the quicktools directory");
  2. Click to open the menu;
  3. Click an item to run that tool.

Item-by-item details

The menu has 10 items, one per script file in the quicktools directory (underscores in file names are shown as spaces).

Submenus

This menu has no second level (all 10 items either run directly or open the matching tool window; nothing has ▶).

Where this menu comes from

  • The contents are not hard-coded: every time it opens, the .py files in the quicktools directory are scanned and rebuilt in file-name order.
  • So dropping a script into that directory makes it appear the next time you open the button; when the directory is empty a gray line reads "No quick tools".
  • The menu has a dashed line at the top and can be torn off into a floating window for repeated clicks.

Differences between the plug-in edition and the standalone edition

FormWhere tools run
Maya-embedded editionIn place, in the local Maya Python
Standalone editionTools that need Maya are dispatched to the Maya selected in Maya target; pure file tools (such as Image format conversion tool, Batch mirror copy and the three to-zasset tools) run locally

Beginner pitfalls

  • Clicking does nothing / just a flash: most of these tools open their own window before running; if no window appears, check the Maya Script Editor log (the standalone edition also prints hints such as "no online Maya found").
  • "No online Maya found" in the standalone edition: confirm a Maya with an open bridge port exists and is selected in Maya target, see 8.2.4.
  • Clicking twice: this opens two tool windows / runs the task twice, so avoid repeating operations that write to the library.
  • Assuming these are all the tools: only scripts in the quicktools directory are listed; items such as Format conversion in the asset context menu are a different entry.
