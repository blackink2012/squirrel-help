插件的配置分散在包内预设和用户目录两处，备份就是把这几份 JSON 复制走，迁移就是放回对应位置。

前置条件

先关闭 Maya，或至少关闭设置窗口，避免复制到写了一半的文件。

配置文件清单

文件位置内容
config.json<插件包>/Assets/preset/子库、默认分类、支持格式、扩展名、材质节点类型、导入策略等
context_menu_preset.json同上右键菜单按子库的勾选状态
double_click_preset.json同上双击命令与子选项
export_preset.json同上导出默认格式
pbr_mapping.json同上贴图类型别名与 PBR 映射
app_settings.json~/.squirrel_asset_manager/字号、主题、语言、库列表、隐藏分类、AI 配置与密钥等个人设置

操作步骤

  1. 关闭 Maya。
  2. 复制上表六个文件到备份目录。
  3. 在新机器上按相同相对位置放回：预设文件放入插件包的 Assets/preset/，app_settings.json 放入当前用户的 ~/.squirrel_asset_manager/。
  4. 启动 Maya 与插件，打开设置逐页核对。

结果验证

设置各页显示的值与备份前一致；资产库列表能正常打开。

提示

  • 预设文件位于 EXE 安装目录内；覆盖安装会用新包里的同名预设覆盖它们（你在 Assets/preset/ 里改过的配置会丢），升级前先备份。~/.squirrel_asset_manager/app_settings.json 在安装目录外，覆盖安装不受影响。
  • app_settings.json 里的库路径是绝对路径，换机后可能需要在设置里重新指定。
  • 文件包含 AI API Key 等敏感信息，备份与传输时注意保密。
  • 资产库本体不在这些文件里，备份方法见「备份与恢复」。
