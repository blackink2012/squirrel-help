日常只需要增量同步：只重嵌新增、修改、删除的行；全量重建留给换模型、索引损坏或格式升级。

自动发生的同步

  • 打开或切换资产库时，后台预热当前库的文本索引，搜索不等它。
  • 检索前做一次增量同步；同一状态重复同步不碰模型。
  • 图像索引只在该库比索引新时刷新；首次以图搜图时才冷建。

手动同步

设置 → AI 设置 →「向量索引维护」组里有两个按钮：「更新向量」做增量、「重建全部向量索引」做全量；这一组的说明写着它管的是帮助库、Maya 文档库与当前资产库（文本 / 图像 / 音频 / 视频）的向量索引。

也可以走命令行：

  1. 文本索引（增量）：python tools\asset_index.py --sync。
  2. 文本索引（全量）：python tools\asset_index.py --rebuild。
  3. 图像索引（增量）：python tools\asset_vision_encode.py sync --library "<库根>"。
  4. 图像索引（全量）：在上面命令后加 --rebuild。
  5. 也可以通过命令 index_sync 执行，kind 取 materials、images 或 both，rebuild 只影响图像索引。

结果验证

同步后用 asset_semantic_status 或 python tools\asset_index.py --status 查看条数与更新时间；一致性可用 --verify 检查。

提示与警告

  • 命令 index_sync 的 rebuild 只作用于图像索引；文本要全量重建请用 python tools\asset_index.py --rebuild。
  • 不要用图像同步的 --limit 做抽样，它会把索引裁成前 N 条。
  • 索引目录上有新鲜锁时，搜索会跳过同步，避免卡住；等对方写完再试。
