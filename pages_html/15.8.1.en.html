One-line summary: the thin strip at the very bottom of the window reports counts on the left and which asset is selected on the right.

It spans the right work area (excluding the leftmost navigation column), has a fixed height, cannot be dragged and takes no working space.

What the two text segments are

PositionContentMeaning
LeftMaterials: 84/84The left of the slash is the number of assets visible in the current view, the right is the total number of assets loaded in the library
Left (appended when selecting)`\Selected: 3`How many assets are selected (meaningful when multi-selecting)
RightSelected: CARTOON12The readable name (name field) of the selected asset; with multiple selected it shows the first

"Materials" is historical wording and here simply means "assets"; it has nothing to do with how many material assets the library holds.

When the numbers change

OperationEffect
Switching category / sub-library / favorite setThe visible count changes (the total does not; the total is for the whole library)
Keyword search / tag filter / AI search / search by imageThe visible count changes — this is "how many matched right now"
Multi-select / rubber band / deselect"Selected" appears or disappears
Creating, importing or deleting assets and refreshingThe total changes
While the library is loadingPlaceholder text first; real numbers once loading finishes

The right segment also shows other things temporarily

The right-hand information slot does not only show asset names; many operation results temporarily occupy it (until the next asset selection):

ScenarioWhat the right side may show
An asset is selectedSelected: asset name
AI search / search by imageResult notes such as "AI search 'keyword': found n assets", "Image search: …"
Text search for video / musicNotes such as "Text search for video: matched n animations"
Background rendering / UUID repairProgress such as "Generating n thumbnails with …", "Repairing UUIDs: 3/20"
A layout operation failedHints such as "At least one area must remain"

So changed text on the right is not necessarily an error; just read what it is talking about.

Common questions

SymptomCause
The two numbers differ (such as 12/84)Normal: the left is the visible count in the current category / search and the right is the whole library
The number stays 0The library did not load, or the current category really has no assets
"Selected" never disappearsThe selection is still active; single-click blank space in the asset grid to clear it and it empties
No asset path anywhereThe status bar does not show paths; see them in the asset details window (8.11.1)
