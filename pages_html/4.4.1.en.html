The middle grid is the main work area for assets: single-click to select, double-click to run the preset command, and multi-select to batch operate.

Interface

  • Every card has a square thumbnail, a favorite star at the bottom left and the name at the bottom. The top-left of the thumbnail may show a multi-version badge, a variant V badge, or L when there are several LODs; the top right shows the asset type icon.
  • Assets with a video thumbnail play a preview on the card after the mouse rests on it for a moment.
  • The result count is in the bottom status bar: visible / total plus the number selected; the view-control row no longer shows it.

Selection

  • Single-click: selects only that card, and the properties and preview on the right follow.
  • Ctrl+click: toggles that card and keeps the rest.
  • Shift+click: adds the range from the anchor to that card, which can be stretched repeatedly.
  • Dragging on empty space: marquee select; a plain drag replaces the selection and holding Ctrl/Shift adds to it.
  • Clicking empty space: clears the selection.
  • Ctrl+A selects all; Ctrl+C copies; Ctrl+F scrolls the selected card to the center of the viewport.

Keyboard and double-click

  • Arrow keys move and select, Home/End jump to the first and last card, PageUp/PageDown page; Ctrl+arrow moves only the focus, and Ctrl+Space toggles the focus card's selection.
  • Typing letters or digits jumps by Chinese name or pinyin initial; typing the same letter repeatedly cycles through candidates with that initial.
  • A double-click follows double_click_preset.json: materials import .zmetal, models / scenes / dynamics / node trees import .ma, lights import .zlight, textures create a material, HDR creates an environment light; audio imports to the timeline, images import as a file node, and animation data runs 「导入动画（层级映射）…」 (Import animation (hierarchy mapping)…); unregistered categories import the first available format by default. All of this can be changed per sub-library under Settings → 右键菜单 (Context menu), in the lower half (double-click command).

Verify the result

After selecting a card, the properties and preview panels on the right show the same asset and the selected count in the status bar changes.
