Sorting decides the order of assets and filtering decides which assets appear; the two combine. The asset count is shown in the status bar at the bottom.

Sorting

  1. Click the sort button in the view-control row (its label is the current sort key, 「名称」 (Name) by default).
  2. Choose the sort key in the upper part: 「名称 / 类型 / 分类 / 时间」 (Name / Type / Category / Time) (items are not check-marked; the current one is shown by the button label).
  3. Choose the direction in the lower part: 「升序 / 降序」 (Ascending / Descending); the arrow on the button points in the current direction (accent color).
  4. List view can also sort by clicking the 「名称 / 类型 / 分类」 (Name / Type / Category) header directly (there is no time column in the header), and clicking the same column toggles the direction.

Filtering

  • Keyword search: type a name, tag or ID in the top search box and results filter as you type.
  • AI search: check 「AI 搜索」 (AI search) in the search box, type a sentence and press Enter.
  • Tag filter: click 「编辑标签」 (Edit tags) in the view-control row to open the tag editor and click tag chips to filter (multiple tags form a union: any match counts); the button stays highlighted while a filter is active.
  • Category filter: select a category in the left tree and the grid shows only that category and its sub-categories.
  • Media search: from the search box you can upload an image, video or audio file, take a screenshot or record the screen (audio recording under the 「音乐」 (Music) category), or drag a file into the search box.

Clearing the search box or clicking a selected tag again removes that filter.

Verify the result

  • Changing the sort order reorders the cards immediately, and the header arrows in list view follow.
  • Typing a keyword reduces the count in the status bar, and clearing it restores everything.
  • After checking a tag only assets with that tag remain, and the matching filter term appears in the search box.

Tips

  • If AI search is unavailable it falls back to keyword search automatically and does not affect normal filtering.
  • Sorting and thumbnail size are saved together with the layout.
