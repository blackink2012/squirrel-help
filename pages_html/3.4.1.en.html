Turn an external model into an asset

Import a model file from outside and the plug-in wraps it into a .zasset inside the current category; this is the first step of the whole workflow.

Create an asset from a Maya model

Prerequisites

  • The asset library is initialized and its categories display properly.
  • A specific sub-library and category are selected on the left (while 「全部资产」 (All assets) or favorites is active, the import entry is disabled).
  • Have a model file ready, for example .ma, .mb, .fbx, .obj, .usd, .abc or .glb.

Steps

  1. On the 「分类」 (Categories) tab on the left, choose the 「模型」 (Models) sub-library and then a specific category.
  2. In the view-control row in the middle click 「从外部导入」 (Import from Files) and choose 「从文件导入」 (Import from files).
  3. In the file dialog select one or more model files and confirm.
  4. Each file becomes its own .zasset, named after the file; duplicate names get a non-conflicting name automatically.
  5. The grid refreshes when the import finishes and jumps to the target category showing the new assets.
  6. Check the name, format and size in the properties panel on the right, and add a thumbnail if needed.

Verify the result

  • New cards appear in the target category with the same names as the source files.
  • The properties panel shows the asset type, format and file size.
  • The source files were not moved or deleted; they were copied into the library.

Tips

  • You must select a specific sub-library / category first: while 「全部资产」 (All assets) or favorites is active the 「从外部导入」 (Import from Files) button is disabled (greyed out), and the 「从外部导入」 (Import from Files) submenu of the empty-area context menu shows a grey line: 「当前分类不支持从外部导入」 (this category does not support importing from files).
  • To bring in a .zasset, use 「从外部导入 → 导入 .zasset 资产」 (Import from Files → Import a .zasset asset); do not copy folders by hand.
  • Having no thumbnail right after import is normal: capture one in the preview panel or use 「更新缩略图 → 后台渲染」 (Update thumbnail → Background render) (see 4.1.7).
