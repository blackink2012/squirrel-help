一句话定位：带版本/变体/LOD 的资产，导入时不是「导入资产」，而是「先挑一条再导入」——本页讲这个挑选动作在哪儿做、怎么做。

两种入口，先记结论

场景你该用哪个入口
只想快点把某个变体/版本/LOD 导进场景资产右键 →「导入变体 / 版本」子菜单里直接点那一条（最快）
想先看清楚图、看信息再导双击预览图打开版本浏览器，左栏选条目 → 右栏「导入此版本 / 导入此 LOD / 导入此变体」

入口一：右键子菜单

右键带版本/变体的资产 →「导入…」子菜单，标题会随资产内容变：

子菜单标题出现条件
导入变体资产只有变体（没有多版本）
导入版本 / LOD资产只有版本/LOD（没有变体）
导入变体 / 版本变体和版本都有（或存在旧版版本记录）

子菜单里逐条列出变体/版本：

  • 一条变体有多档 LOD → 会再多一层子菜单（LOD 精度）；
  • 一条变体有多种几何格式 → 再多一层格式子菜单（ma、fbx…；同扩展名多个文件时会带文件名区分）；
  • 鼠标悬停条目会在旁边弹出该条目的缩略图大图。

点最末一级 = 直接导入。

入口二：版本浏览器

在 8.11.2 的版本浏览器里：左栏选中条目 → 右栏按钮导入。按钮文字会变成「导入此版本 / 导入此 LOD / 导入此变体」，与所选条目对应。

源码里还有一个独立的小选择窗

插件源码里保留了一个独立的「导入变体几何体」对话框（旧版选择方式）：列出该资产的版本单选 + 对应的 LOD 精度单选，确定后按选择导入。当前版本没有把它挂到任何菜单上，正常操作路径下点不到它——日常请用上面两个入口。它的结构如下，供对照旧文档/旧截图时辨认：

控件内容
标题导入变体几何体
顶部显示要导入的资产名
版本单选列表，每项 tag - 显示名 (创建日期)，有注释的会另起一行显示注释
LOD 精度单选列表，每项 显示名 (LODx) + 三角面/顶点数 + 可用格式；该版本没有 LOD 时显示「该版本无可用 LOD」
无变体时只显示「该资产不包含变体数据」和「取消」
按钮取消 / 确定

一句话：看到这个窗口说明你用的是旧版入口；当前版本请走右键「导入变体 / 版本」或版本浏览器。

一次完整操作（导入某个变体的 LOD1、ma 格式）

  1. 在资产网格里找到带变体角标的资产。
  2. 右键 → 展开「导入变体 / 版本」子菜单。
  3. 找到目标变体那一行，悬停看一下弹出的缩略图，确认没点错。
  4. 若有 LOD 层，展开并选「LOD1」。
  5. 若有多格式层，选 ma。
  6. 松手后几何导入当前 Maya 场景。
  7. 想核对导进来的版本对不对：看脚本编辑器里的 [VariantImport] 日志，会写清 version/lod/geom。

出问题怎么办

现象原因处理
右键里没有导入变体/版本子菜单该资产没有变体/多版本；或只有一个可用格式因而没显示子菜单直接用普通「导入」；或先创建变体/版本
选完没反应该条目几何文件缺失，或独立运行模式没连上 Maya看脚本编辑器 [VariantImport] 日志；确认 Maya 在线
导入后发现模型不对选错了 LOD 或格式重新导入正确条目，用 Maya 撤销（Ctrl+Z）撤掉上一个
导入动画资产报错动画版本走的是 ATOM 映射导入，不是几何导入用资产右键的动画导入路径，或版本浏览器里对应的导入按钮
