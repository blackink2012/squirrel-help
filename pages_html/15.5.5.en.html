One-line summary: right-clicking a textures asset card in the asset grid opens this menu. A texture asset is a whole PBR set (several resolutions with type suffixes), so the menu offers three routes — create a material, import textures, or assign onto a material — instead of one generic import.

How to open it

  1. Left Category tab → click Textures or any category under it;
  2. In the center asset grid, right-click any texture card.

The textures menu has no generic import or add reference — bringing textures into the library from outside goes through the toolbar's Import from outside → Import textures, see 8.4.2.

Submenu: Create material ▶

The 7 target materials on the sample asset:

Sub-itemDescription
openPBRSurfaceMaya native OpenPBR material (no renderer family tag)
aiStandardSurface (AI)Arnold standard material
VRayMtl (VR)V-Ray general material
rsStandardMaterial (RS)Redshift standard material
RedshiftOpenPBR (RS)Redshift OpenPBR material
standardSurfaceMaya native Standard Surface
lambertMaya native Lambert

Two details:

  • The tag in parentheses is the renderer family (AI / RS / VR); untagged entries are Maya native materials.
  • If the asset holds texture directories for several resolutions, choosing a material type asks for a resolution afterwards (such as 2K / 4K); with a single resolution the material is created directly.

Submenu: Import textures ▶

Sub-item formDescription
A single texture (such as aerial_beach_02_diff_2k.jpg)Imports only that one and creates a file node
Import allImports every texture of the asset (or of that resolution) as one set, sharing a single place2dTexture node

With several resolutions the submenu groups by resolution, and each group ends with an "Import all (this resolution)" item.

Notes specific to this sub-library

  • How the three routes differ: Create material builds a new material and wires the images; Import textures only brings the images in (you wire them); Assign texture to material puts the images onto the material you already selected. Decide first whether you want "build from scratch", "images only" or "add to an existing material".
  • "Assign texture to material" opens no picker: it only looks at the material currently selected in the scene. Clicking it with no material selected reports failure.
  • Import all shares UVs: one PBR set shares a single place2dTexture, so a UV change applies everywhere. That is deliberate; do not split it by hand.
