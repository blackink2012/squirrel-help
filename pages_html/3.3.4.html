排序决定资产顺序，筛选决定显示哪些资产；两者可以叠加。资产数量显示在底部状态栏。

排序

  1. 点视控行的排序按钮（按钮文字是当前排序键，默认「名称」）。
  2. 菜单上段选排序键：名称 / 类型 / 分类 / 时间（菜单项不标勾，当前项看按钮文字）。
  3. 菜单下段选方向：升序 / 降序；按钮上的箭头指向当前方向（强调色）。
  4. 列表视图也可以直接点「名称 / 类型 / 分类」表头排序（时间列不在表头里），同列连续点击切换升降序。

筛选

  • 关键词搜索：在顶部搜索框输入名称、标签或 ID，结果实时过滤。
  • AI 搜索：勾选搜索框里的「AI 搜索」，输入一句自然语言后回车。
  • 标签筛选：点视控行「编辑标签」打开标签编辑器，点标签芯片筛选（多选是并集，任一命中即可）；有筛选时按钮保持高亮。
  • 分类筛选：在左侧分类树选择具体分类，网格只显示该分类及子分类。
  • 媒体搜索：搜索框内可上传图片 / 视频 / 音频、截屏、录屏（「音乐」分类下是录音），也可以把文件拖进搜索框。

清除搜索框内容或再点已选标签即可取消对应筛选。

结果验证

  • 切换排序后，卡片顺序立即变化；列表视图的表头箭头同步。
  • 输入关键词后底部状态栏的数量减少，清空后恢复全部。
  • 勾选标签后只显示带该标签的资产，搜索框里会出现对应的筛选词。

提示

  • AI 搜索不可用时会自动退回关键词搜索，不影响普通筛选。
  • 排序方式与缩略图大小会随布局一起保存。
