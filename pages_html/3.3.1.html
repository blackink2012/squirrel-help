单击负责选中，双击按子库预设执行动作，右键打开完整的资产菜单。

单击

  • 单击卡片：只选中这一张，右侧属性与预览同步更新。
  • 单击空白处：清空选中，右侧面板回到未选择状态。
  • 单击列表视图的行：选中该行资产。

双击

双击执行当前子库的「双击命令」预设，出厂默认如下：

子库双击动作
材质导入 .zmetal，重建着色网络
模型 / 场景 / 动态 / 节点树导入 ma（节点树导入后选中新建节点）
灯光导入 .zlight
贴图创建 PBR 材质（openPBRSurface）
HDR创建穹顶灯（按当前渲染器选模板）
图片创建 file 节点（把图片接成纹理节点）
音频导入 Maya 时间轴（当前帧 = 音频首帧）
动画数据走层级映射与通道选择，把关键帧写到场景层级上
未登记分类导入第一个可用格式

双击行为可在设置 →「右键菜单」页下半部分的「双击命令」里按子库修改。

右键

  1. 右键卡片；若卡片已在多选中，保留整批选中，否则先单选它。
  2. 菜单顶部是该子库的专属项，各子库不一样：
    • 材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态：导入（单格式直接执行，多格式出子菜单）、添加引用、导入几何体等，并各自带应用材质、指定贴图、应用灯光、创建穹顶灯等专属项；
    • 图片：导入为 file 节点、创建 imagePlane、指定到选中材质槽、打开图像；
    • 音频：导入到时间轴、导入到时间编辑器、导入到 Trax 编辑器、导入摄像机序列器；
    • 动画数据：导入动画、导入动画（层级映射）…、导入到选择属性；
    • 节点树：导入 ma、添加引用、预览节点。
  3. 下半部分是公共条目：收藏夹、全选、复制、打开文件夹、移动 / 复制到、编辑、更新缩略图（截取 / 导入 / Maya拍屏 / 渲染图 / 添加 / 截取添加，部分子库还有「后台渲染」）、更新资产、删除、预览节点、AI 分析缩略图、资产详情等。
  4. 在网格空白处右键，菜单同样随分类变化：可创建资产、粘贴、从外部导入等；「全部资产」下「从外部导入」子菜单里是一条灰字「当前分类不支持从外部导入」。

结果验证

  • 双击模型资产后，Maya 视口与大纲视图出现新对象；双击图片资产会在 Hypershade 里多一个 file 节点；双击音频资产会在时间轴出现声音波形。
  • 右键材质资产能看到「导入」与「应用材质」；右键 HDR 能看到「创建穹顶灯」；右键动画数据能看到「导入动画」。

提示

  • 完整右键菜单项按子库不同，可在设置 →「右键菜单」里开关，详见 4.1.4.6。
  • 双击没有反应时，先确认该子库的双击命令不是「无」。
