The export preset file is Assets/preset/export_preset.json; to back it up, move machines or standardize default formats across a team, simply copy this JSON.

Prerequisites

  • The current machine has been configured as described in "Save defaults per sub-library".
  • The plug-in install directory's squirrel_asset_manager/Assets/preset/ is accessible.

Steps

Export the preset file

  1. Locate squirrel_asset_manager/Assets/preset/export_preset.json.
  2. Copy it to a backup directory or a shared location.
  3. Include a date or project name in the file name, for example export_preset_20261019.json.

Import a preset file

  1. Close any open export dialog and Settings window first.
  2. Back up the current machine's export_preset.json.
  3. Overwrite export_preset.json at the same path with the target file.
  4. Reopen Create asset or Settings → 导出默认值 (Export defaults); the new defaults apply immediately.

Verify the result

  • Reopening Settings → 导出默认值 (Export defaults) shows checks matching the replaced file.
  • Opening Create asset in that sub-library preselects the format checkboxes per the new defaults.
  • Opening export_preset.json in a text editor shows the replaced sub-library entries and booleans.

File structure

{
  "_default": { "ma": true, "zmetal": false },
  "materials": { "zmetal": true, "ma": true, "material_only": true },
  "models": { "ma": true, "material_only": false }
}
KeyPurpose
_defaultFallback when a sub-library has no entry of its own
materials / models / lights / textures / scenes / hdr / ani / images / audio / animation / nodetreeDefaults for each built-in sub-library (one-to-one with sub_libraries in config.json, 11 in total)
zmetal / zmetal_merge / mcmMaterial nodes and material mapping
ma / mb / fbx / obj / usdGeometry formats
abc / arnold / vray / redshift / vrmeshCaches and proxies
material_only / collect_associated / texturesMaterials only, collect linked files, package textures
ani_frame_modecurrent / timeline / keyframe
delay_msCapture delay in milliseconds; 2000 means 2 seconds
thumb_sourcescreenshot / playblast / render

Tips and warnings

Tip: the file is read only when the new-asset dialog opens; no Maya restart is needed after replacing it, just reopen the dialog.

Tip: creating assets on the AI side reads export_preset.json as well, so this file is the shared default source for both the UI and the AI.

Warning: on invalid JSON the plug-in logs a load failure and falls back to built-in defaults, which looks like "every format is unchecked". Validate with any JSON checker before replacing.

Current version: the Settings window has no 导入预设 / 导出预设文件 (import preset / export preset file) buttons (verified 2026-11-03); importing and exporting here is done by copying the file, which is the most direct and reliable route.

Do not confuse it with "export material as preset": the plug-in also has an 「导出材质为预设」 (Export material as preset) dialog that exports scene materials into a .zmetal / JSON preset, which is not the same thing as export_preset.json here ("what is checked by default for a new asset"); that dialog is not wired to any menu entry today (see 15.12.3), so there is nothing to look for here.
