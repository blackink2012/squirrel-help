One-line summary: convert a batch of images from one format to another (png / jpg / exr / hdr / tga / tif / bmp / webp), optionally changing resolution.

It only handles "format and size" conversion, does not import into the library and never touches the Maya scene. It is not the same as Format conversion for assets (8.12.4): that one targets assets in the library, while this one targets directories on disk.

A complete flow

  1. Quick tools → Image format conversion tool;
  2. Choose input mode Choose folder and browse to the source directory;
  3. Fill Input format filter with the formats to convert (such as exr); leaving it empty converts all supported formats;
  4. Choose an empty directory as the Output location;
  5. Pick the Target format;
  6. Fill width / height when resizing and tick Keep aspect ratio; otherwise leave both empty;
  7. When the source is layered and you want the structure kept, tick Keep hierarchy;
  8. Click Start conversion and read the log: confirm the "converting N files -> .xxx" count and the "output to" path;
  9. When done it reports "Conversion finished! X succeeded, Y failed", with failure reasons one per line in the log;
  10. Check the files in the output directory (same-named files sit in their subdirectories).

Where the output lands

  • Output files are under the output location, named after the source file with the target extension;
  • With Keep hierarchy ticked the subdirectory structure matches the source;
  • Conversion never opens the folder for you, so check the output directory yourself; every log line states the path it processed.

Risks and how to undo (two traps that really bite)

  • Same-named output is overwritten silently. When the output directory already holds a same-named file (a previous run, for example), this run overwrites it without a word. To keep the old result, use an empty output directory or rename / move the old files first.
  • When a source file name contains characters Windows forbids, the tool renames the source file. The log shows "source file renamed: old -> new". That is its only write to the source directory and it is irreversible (the old path is gone). To avoid touching the sources, copy the source directory and convert the copy.
  • Aborting is safe: Abort stops after the current file finishes, keeps converted files and logs "user aborted the conversion".
  • To undo, delete the converted files in the output directory; apart from that rename case, source files are never modified or deleted.
