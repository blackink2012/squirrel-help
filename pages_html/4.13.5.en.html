The variant management window lists every variant of the asset in one table with thumbnails, face counts and formats, and lets you import, add from files or delete them.

How to open it

Right-click the asset → 「更新资产」 (Update asset) → 「变体管理…」 (Variant management…).

Interface

AreaContents
ListEach variant shows its thumbnail, variant name (id), face count, formats and LOD ×N; Ctrl / Shift multi-selection is supported
「导入选中变体」 (Import selected variants)Imports the selected variants into the current scene one by one (double-clicking a row imports only that one)
「从文件添加…」 (Add from files…)Pick model files from disk, one file = one variant
「删除选中变体」 (Delete selected variants)Deletes the selected variants (with confirmation; the dialog shows the count for a multi-selection)
Footer noteAll variants share the textures and materials in the asset root; the variant directory stores geometry only

Multi-selection

  • With the first row selected, hold Ctrl and click other rows to add or remove single rows; hold Shift and click to take a range.
  • 「导入选中变体」 (Import selected variants) and 「删除选中变体」 (Delete selected variants) act on the current selection; both buttons are disabled when nothing is selected.
  • Double-clicking one row imports only that row, regardless of other selections.

Adding variants from files

  1. Click 「从文件添加…」 (Add from files…) and select one or more model files: *.ma, *.mb, *.fbx, *.obj, *.usd, *.usda, *.usdc, *.glb, *.gltf.
  2. Each file becomes one variant named after the file (without extension); duplicates get _2, _3 appended.
  3. The progress dialog can be cancelled; afterwards it reports successes / failures and the list refreshes.
  • This path only copies geometry and does not generate thumbnails; add images through the thumbnail entries in 「更新变体」 (Update variant).

Deleting variants

  1. Select one or more variants (Ctrl / Shift), then click 「删除选中变体」 (Delete selected variants).
  2. The confirmation says 「只删除这些变体的几何体与缩略图，资产共享的贴图 / 材质不受影响」 (only the geometry and thumbnails of these variants are deleted; the asset's shared textures / materials are unaffected); a multi-selection shows the count, and the actual number deleted is reported afterwards.

Verify the result

  • The list refreshes immediately after adding or deleting, and the library in the main window refreshes too.
  • The matching <id>.<ext>, <id>_lodN.<ext> and <id>.sicon files under variants/ are removed while the asset root's textures and materials stay.
  • The version browser (double-click the preview on the right) also lists variant entries and offers 「导入此变体」 (Import this variant) and 「删除此变体」 (Delete this variant).
