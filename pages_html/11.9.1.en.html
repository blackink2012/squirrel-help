Show in main UI controls whether a sub-library or top-level category appears in the main window sidebar. Everything is shown by default.

What it does

The checkbox sits at the top right of Settings → Sub-libraries and categories. After selecting a sub-library on the left, ticking it means the entry appears in the main window category tree; clearing it hides that entry.

Values and defaults

  • Values: ticked = shown, cleared = hidden.
  • Default: all ticked. The settings file stores hidden entries as a blocklist hidden_top_categories, so top-level categories added to the library later appear automatically.
  • The state is written to ~/.squirrel_asset_manager/app_settings.json, not to config.json.

Scope of effect

  • It only affects sidebar entries in the main window, including the category tree and the collapsed icon strip.
  • All assets is always shown and is not affected; a hidden category can still be browsed and searched through All assets.
  • The category tree of project libraries is not affected.
  • The checkbox is not covered by Unlock all settings; it can be changed even while locked.

Steps

  1. Open Settings → Sub-libraries and categories.
  2. Select the sub-library or top-level category on the left.
  3. Tick or clear Show in main UI.
  4. Click Apply or OK.

Verify the result

Return to the main window: the sidebar should show or hide that entry according to the new setting.

When to change it

When there are many sub-libraries and the sidebar is too long, or when a sub-library is not needed by the current project. Do not use it to "delete" a category; no data on disk is deleted.
