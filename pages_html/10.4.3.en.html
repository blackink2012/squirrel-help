A frame sequence captures a set of viewport images frame by frame (playblast per frame) for watching motion and change; use "viewport screenshot" for a single detailed frame.

Prerequisites

  • Maya is in a GUI session with a usable modelPanel.
  • The frame range and output location are decided.

Steps

  1. Call capture_sequence; frames accepts "1-10", "1,3,5", "1-10:2" or a plain array.
  2. Set the output: image_path may be a placeholder template (such as .../shot_{frame:04d}.png), a prefix or a directory; without it the system temp directory is used.
  3. Set size, camera and display mode: width / height, camera, mode, wireframe, panel.
  4. Set the frame-number padding (4 by default) and the per-call max_frames limit (200 by default).
  5. To also encode a video, pass video and fps and encoding follows immediately.

Verify the result

It returns the list of produced frames and their file paths; the count should match the requested range, and a few frames should look right. Every frame gets a blank check and anomalies are listed in blank_frames.

Tips and warnings

  • At most 200 frames per call, a hard gate that keeps the Maya main thread from being monopolized.
  • There is a cancel checkpoint per frame; cancelling stops immediately and keeps captured frames with status=cancelled and stopped_early=true.
  • Capturing temporarily changes the current frame and restores it afterwards; a large sequence can leave the scene marked as modified, so use cmds.file(modified=False) when that matters.
  • A placeholder such as {frame:04d} is expanded from the format string; a prefix or directory uses padding for zero filling, ready for the encoding command.
