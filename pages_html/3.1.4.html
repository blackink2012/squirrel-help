中间资产区是日常操作的主区域：上方一行视控，下方用图标卡片或列表展示当前分类的资产。

视控行

从左到右依次是：

  • 「从外部导入」下拉菜单：内容随当前分类变化（见下表）；停在「全部资产」、收藏夹或回收站时整颗按钮禁用。
  • 「创建资产」：把 Maya 中选中的物体导出为资产。
  • 「音乐播放」下拉（只在「音乐」分类有音频时出现）：播放 / 暂停、上一首 / 下一首与播放模式。
  • 面包屑：显示当前位置（全部资产 › 子库 › 分类 …），点前面的段可以往回跳。
  • 「编辑标签」：打开标签编辑器，按标签筛选。
  • 「视图」按钮：按钮文字显示当前模式（「图标」或「列表」），点开切换。
  • 「名称」按钮（排序）：按钮文字是当前排序键，点开选排序依据与升 / 降序。
  • 「缩略图:」滑块：调整卡片大小；图标视图下也可 Ctrl + 滚轮 缩放。

资产数量不在这行，而在底部状态栏（材料: 可见数/总数）。

「从外部导入」随当前分类变化

全部资产 / 收藏夹 / 回收站按钮禁用；从网格空白处右键的「从外部导入」子菜单里是一条灰字「当前分类不支持从外部导入」

菜单按顶级子库裁剪：想导入什么，先得在左栏选中具体子库 / 分类，插件才知道往哪落。

卡片与列表

  • 图标视图：每张卡片显示缩略图、易读名和收藏星标；选中时高亮，悬停有描边。
  • 列表视图：列为收藏星标、名称、资产类型、分类、标签，适合快速核对元数据。
  • 单击选中，双击执行当前子库的双击预设，右键打开资产菜单；拖动卡片可拖入 Maya 视口或分类树。
  • 在空白处右键可创建资产、粘贴或导入；在空白处拖动可框选。

结果验证

  • 切换分类后，网格只显示该分类下的资产，底部状态栏的数量同步变化。
  • 切换「视图」后，同一批资产在卡片与表格之间切换，选中状态保留。

提示

  • 双击行为按子库不同：模型 / 场景 / 动态 / 节点树 导入 ma、材质导入 zmetal、贴图创建 PBR 材质、HDR 创建穹顶灯；图片建 file 节点、音频导入时间轴、动画数据走层级映射。可在设置 →「右键菜单」页下半部分的「双击命令」里按子库修改。
  • 资产缩略图缺失时卡片会显示占位图，可在右侧预览区截取，或用「更新缩略图 → 后台渲染」补一张。
