Settings open from the gear button in the plug-in main window toolbar, and changes reach the disk only after clicking 「应用」 (Apply) or 「确定」 (OK).

Prerequisites

  • The plug-in main window is open (either the in-Maya version or the standalone edition).

Steps

  1. Click the gear button on the right of the main window toolbar; its tooltip reads 「设置（AI / 字号 / 语言 / 资产库…）」 (settings: AI / font size / language / asset library…).
  2. Choose a page in the left navigation of the Settings window: General, AI settings, Export defaults, Context menu, Supported formats, Texture suffixes, Sub-libraries and categories, Other configuration, License activation, About. The tabs are stacked vertically on the left (long English labels would not fit across the top).
  3. Change what you need.
  4. Click 「应用」 (Apply) to save without closing, 「确定」 (OK) to save and close, or 「取消」 (Cancel) to close without saving.
  5. At any time click 「设置帮助」 (Settings help) (the orange question mark icon) at the bottom to open the built-in settings help page.
  6. Apart from General, AI settings, License activation and About, the other tabs are read-only by default; to change them check 「解锁全部配置」 (Unlock all configuration) at the bottom and confirm the warning first.

Saving semantics

  • 「应用」 (Apply) collects per tab: General and AI preferences go to ~/.squirrel_asset_manager/app_settings.json; asset library, format and sub-library settings go to Assets/preset/config.json inside the plug-in package; export defaults, context menu, double-click commands and texture aliases each write their own preset file.
  • Some settings apply immediately after applying: color theme, language, default library switch, drag-and-drop toggle, bridge port toggle.
  • Font size and interface scaling rebuild the main window style after applying; the thumbnail output size takes effect from the next generation or capture.
  • The Settings window is a non-modal singleton: clicking the gear while it is open only brings the existing window forward.

Verify the result

  • Close and reopen Settings and the values you changed are still there.
  • The main window's font size, color theme, language or view changes as expected.
  • To confirm writing to disk, check the modification time of app_settings.json listed on the configuration file locations page.

Tips

Tip: 「恢复默认设置」 (Restore default settings) at the bottom only resets some items in the current dialog; see "Restoring defaults".

Tip: to back up, move to another machine or restore factory settings, use save / import / export / restore in Settings → 常规 → 设置预设 (General → Settings preset); see 15.9.2.

Tip: clicking Apply while unlocked opens one more confirmation; choosing No saves nothing.

Tip: installing and mounting inside the 「外部 AI 工具」 (External AI tools) panel writes to the other tool's directory immediately and is unrelated to this window's Cancel.
