Two buttons at the top of the asset area: 「图标」 (Icons) on the left (click to choose icons / list) and 「名称」 (Name) on the right (the label is the current sort key; click to choose the sort type and direction). Both affect display only, never the assets themselves.

View modes

  1. Click the 「图标」 (Icons) button at the top of the asset area (its label follows the current view; in list view it reads 「列表」 (List)).
  2. Choose 「图标」 (Icons) for a grid of thumbnail cards, or 「列表」 (List) for a table with the columns star, name, asset type, category and tags.
  3. Both views share the current filter and selection; the button label and icon change together when switching.

Thumbnail size

  • The 「缩略图:」 (Thumbnail:) slider at the top of the asset area: small cards with many columns on the left, large cards with few columns on the right, roughly 2–16 columns.
  • In icon view, holding Ctrl and scrolling the wheel also zooms: up enlarges, down shrinks.
  • Widening the window adds columns first instead of stretching the cards.

Sorting

Clicking the 「名称」 (Name) button opens the sort menu in two parts:

PartItemsNotes
Sort typeName / Type / Category / TimeSingle choice; items are not check-marked, compare the toolbar button label instead
Separator——
Sort directionAscending / DescendingThe current direction has a blue arrow; picking once applies it
  • Ascending / descending apply to all four sort keys: descending simply reverses the current order (including the name order inside each group);
  • Names sort by Chinese display name and time sorts by file modification time;
  • List view can also sort by clicking the 「名称 / 资产类型 / 分类」 (Name / Asset type / Category) headers, and clicking the same column toggles the direction; the star and tag columns do not participate.

Verify the result

After switching, the cards / table reorder immediately without losing the filter. The view mode and sorting are written into the interface state and restored after a restart.
