On import the extension decides the importer, and that importer turns the file into nodes in the Maya scene.

CategoryExtensionsImport behavior
Geometryma, mb, fbx, obj, usd, usda, usdc, abc, glb, gltf, daeHanded to Maya's file import; abc and usd are first copied into the project cache; ma/mb additionally rewrite texture paths and redirect linked dependencies
Render proxiesass, rs, vrmesh, vrscene, proxyass creates an Arnold StandIn; rs creates a RedshiftProxyMesh; vrmesh creates a V-Ray proxy; vrscene creates a VRayScene; proxy is imported as an ordinary file
VolumesvdbImported as an ordinary file; actual display depends on the renderer plug-in installed
Texturespng, jpg, jpeg, tga, tiff, tif, bmp, psdCreates a file node wired to a place2dTexture, with sRGB set by extension
HDRhdr, exrCreates a file node set to Raw; importing HDR from the library can also go through "create environment light"
MaterialszmetalRebuilds the shading network from the node network; textures are written to disk per the import policy
LightszlightCreates the light for the current renderer; dependencies such as HDR, IES and textures are written per the import policy
Images (loose files)png, jpg, jpeg, tga, tif, bmp, exr and othersNot through the geometry importer: right-click an image asset → 「导入为 file 节点」 (Import as file node) creates file + place2dTexture; 「创建 imagePlane」 (Create imagePlane) makes a viewport reference image; 「指定到选中材质槽」 (Assign to selected material slot) connects it to the color slot of the selected material
Audio (loose files)wav, aiff (mp3 / flac / m4a / ogg / aac are first converted to a WAV copy)Right-click an audio asset → import to timeline / import to Time Editor / import to Trax Editor / import to camera sequencer; Maya only accepts wav and aiff
Animation data.atom (packed inside a .zasset)Right-click → 「导入动画」 (Import animation) (automatic mapping), 「导入动画（层级映射）…」 (Import animation (hierarchy mapping)…) or 「导入到选择属性」 (Import to selected attributes); it only writes keyframes, so the target hierarchy must exist in the scene
Node trees.ma node networks inside a .zassetRight-click → 「导入 ma」 (Import ma); afterwards the newly created nodes are selected from the before/after difference (there may be no visible geometry — look in the Hypershade or Node Editor)
Material mappingmcmImport the material first, then assign it to the selected object by vertex, face or edge topology matching

The first categories above (geometry / materials / lights / textures / HDR) go through the format list of asset context menu → import; the last four (images / audio / animation data / node trees) are loose files or special content, whose entries are the sub-library specific menu items rather than the format list — see 5.1.2 and the "Menu reference" pages 15.5.9 to 15.5.12.

hdr and exr are treated as HDR by the unified import entry and not as ordinary textures; when ordinary texture behavior is needed, use the 「导入贴图」 (Import texture) submenu of a texture asset.

Texture formats never appear in the context menu's import format list; they are handled by the 「导入贴图」 (Import texture) submenu, and sicon and aicon cannot be imported at all.

Available formats are read from formats or exported_formats in meta.json first; when those fields are missing the files inside the .zasset are scanned and inferred. That inference skips ordinary textures under textures/ and keeps only HDRs.
