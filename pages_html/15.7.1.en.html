One-line summary: the Preview area on the right shows the selected asset's thumbnail (possibly several), and double-clicking opens a larger viewer.

It shows a thumbnail, not a live Maya viewport render. To change the image use the context menu (8.7.2) or the four buttons below (8.7.3).

How to open it

  1. Pick any category in the left navigation to enter the asset grid;
  2. Single-click any asset card and the Preview area on the right shows the image immediately;
  3. With no asset selected the preview is a blank canvas with a faint placeholder icon.

If the panel was closed, reopen the Preview area from the Panels menu at the top (see 8.2.5); it can also be dragged, split and torn off (see 3.2.1).

The preview area itself

FeatureDescription
SizeAlways a 1:1 square whose side follows the column width; on a narrow column it shrinks to the available height and never draws outside the area
Empty stateA dark canvas with a translucent placeholder icon in the center
Right-clickRight-clicking the preview image opens the Update thumbnail menu (8.7.2)
Double-clickOpens a larger viewer: an ordinary asset opens the asset details / inspection window (8.11.1); an asset with versions or variants opens the version browser (8.11.2)
Animated imagesWhen the asset carries a GIF / MP4 it plays right in the preview
Video previewPlayblast videos of animation data assets (mp4 in .cache) play in the preview
Recycle binRead-only display; every thumbnail control and context menu is disabled

Thumbnail slots: one asset can hold several images

SlotNaming in a .zasset assetNaming in a plain folder asset
First image (main)thumb.sicon / thumb.aicon / thumb.png / thumb.mp4<asset name>.sicon
Second onward (extra slots)thumb_2.sicon, thumb_3.sicon…<asset name>_2.sicon, <asset name>_3.sicon…
  • The main image is the card cover and cannot be deleted; it can only be overwritten by capture or import;
  • Extra images start from the second and can be deleted;
  • Extra image numbering continues after the highest existing number and never collides.

Switching between several thumbnails

When a selected asset has several images, a counter appears below the preview (such as 2/3) and you can switch three ways:

MethodOperationDescription
Hover arrowsMove the cursor into the preview and ◀ ▶ appear on both sides◀ is gray on the first image and ▶ is gray on the last
WheelScroll the wheel while hovering the previewUp = previous, down = next
Automatic slideshowNo action needed; it advances every 2 seconds by default and loopsHovering pauses it; it does not run while an animation / video plays or when there is only one image

Deleting an extra thumbnail

  1. Switch to the image to delete (the counter must not read 1/n);
  2. Click Delete below the preview;
  3. That image file is removed from the asset directory immediately and the preview falls back to the remaining images.
警告

Deleting an extra thumbnail has no confirmation and does not use the recycle bin; it deletes the image file on disk. Check the counter while switching, and never click delete on the main image (the delete button is gray there).

Previewing audio assets

Music / audio assets gain two things:

  • A large translucent button in the middle of the preview: play / pause (the icon follows the state);
  • A timeline below showing current time / total duration that you can drag to seek.

Common questions

SymptomCause
The preview stays a blank canvasNo asset selected, or the selection is a virtual entry / recycle bin entry
The preview image is small / shrankThe column width or area height is insufficient and the square side was reduced; widen the right column
It does not show the newest captureThe preview reads the thumbnail file and never refreshes live; capture or generate it again
Double-click did not open a viewerIt may be a read-only entry, or the asset has versions / variants and double-click opens the version browser
