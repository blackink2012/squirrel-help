Index status can be checked without any network access: whether it is usable, which model it uses, how many entries it has, where it lives and whether it lags behind the library.

Prerequisites

An asset library is open; to check the documentation index the machine needs the knowledge base or the online fallback enabled.

Steps

  1. Ask the AI assistant for the index status, or call the read-only command asset_semantic_status.
  2. Focus on four groups of fields: available and reason (whether and why), model / dim / count (model and scale), index_dir / library_id (location and owning library) and index_lag (whether it lags).
  3. For finer environment diagnostics run python tools\asset_index.py --status or --doctor; for the image index use python tools\asset_vision_encode.py status --library "<library root>".
  4. For the documentation index use maya_docs(action="status"), where semantic.diagnose lists which link is missing and the matching command.

Verify the result

available=true with index_lag.stale=false means the index is usable and keeps up with the library; reason is empty or only mentions optional features not installed.

Tips and warnings

  • The status query reads local files only and never uses the network; only --doctor probes Ollama and the models.
  • index_lag.stale=true is not fatal, since the next search syncs incrementally; it is common on shared libraries.
  • When the index in that directory belongs to another library it reports an error explicitly; never copy an index directory by hand to "fix" it.
