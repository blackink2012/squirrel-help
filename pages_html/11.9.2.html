子库 ID 是唯一标识，显示名只影响界面文字；两者都在「子库与分类」页右侧编辑。

作用

左侧列表显示为「显示名 (ID)」。ID 同时对应资产库里的子库文件夹名，并被右键菜单、双击预设、导出预设等按子库分段的配置引用；显示名只用于界面展示。

可选值与默认值

  • 内置子库共 11 个，ID 与显示名对应：materials 材质、models 模型、lights 灯光、textures 贴图、scenes 场景、hdr HDR、ani 动态、images 图片、audio 音频、animation 动画数据、nodetree 节点树。
  • 其中 materials、models、lights、textures、scenes、hdr、ani 这 7 个受删除保护；images、audio、animation、nodetree 虽然也是内置 ID，但目前允许删除（风险见「添加与删除子库」）。
  • 自定义子库 ID 形如 custom_1、custom_2，显示名形如「自定义1」。
  • ID 不可与已有子库重复，重复时提示「子库ID「xxx」已存在」。

操作步骤

  1. 打开「设置 → 子库与分类」，选中左侧子库。
  2. 修改「子库ID:」或「显示名:」。
  3. 点「应用」或「确定」。

影响范围

  • 修改显示名是安全的，只改界面文字。
  • 修改 ID 只改配置文件中的键，不会自动重命名磁盘上的子库文件夹；已有资产可能因此找不到对应子库。
  • 核心子库的 ID 被其它预设按段引用，改动后旧配置段可能失效。

结果验证

应用后左侧列表应显示新的「显示名 (ID)」，重开设置仍保持。

何时修改

一般只改显示名。确实要改 ID 时先备份资产库与 config.json，并同步检查右键菜单、双击预设中的同名段。
