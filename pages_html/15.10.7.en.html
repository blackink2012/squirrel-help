One-line summary: the bottom three blocks of the right column: whether animation is included, whether a point cache is stored, and whether render proxies are stored.

Block one: animation export

Three radios that only apply to time-based formats — abc / usd / ass / rs / vrmesh (the gray (abc/usd/ass/rs/vrmesh) note on the right of the block reminds you); they do not change the content of .ma/.mb/.fbx.

ControlTypeRange actually capturedSuggested valueWhat filling it in wrongly does
Current frameRadio (factory default)Only the frame at Maya's current timeStatic assets, or models that just need a poseAn animated asset will not move after export
TimelineRadioThe timeline / playback range (the start and end of playbackOptions)When you want the whole action and the range is already set on the timelineIf the timeline is set to 1–100 but the animation lives at frame 200, only the first part exports
KeyframesRadioThe start and end range of the selected objects' keyframes (falling back to the current frame when there are none)When the action is concentrated in one segment and you want no empty framesWith several objects whose keyframe ranges differ, the overall captured range wins

The export preset of the animation (ani) sub-library defaults to timeline; other categories default to current frame. The preset comes from Assets/preset/export_preset.json, see 4.3.4.1.

Block two: cache formats

ControlTypeEffectSuggested valueWhat filling it in wrongly does
Alembic .abcCheckboxBakes the selected geometry into a point cache that works across software and renderersTick it when delivering effects / simulation resultsLarge files (points stored per frame), and a long range makes them huge; this checkbox is locked in material-type categories

.abc uses the same frame mode as animation export above: timeline = playback range, keyframes = keyframe range, current frame = a single frame.

Block three: proxy formats

ControlTypeEffectSuggested valueWhat filling it in wrongly does
Arnold .assCheckboxStored as an Arnold proxy (loaded as a proxy at render time to lighten the scene)Large scenes rendered with ArnoldWith mtoa missing or not loaded the status shows "not loaded / unavailable"
Redshift .rsCheckboxStored as a Redshift proxyLarge scenes rendered with RedshiftAs above; the Redshift plug-in is required
V-Ray .vrsceneCheckboxStored as a V-Ray scene proxyWhen rendering with V-RayAs above; the V-Ray plug-in is required
V-Ray .vrmeshCheckboxStored as a V-Ray mesh proxyWhen you only need a geometry proxy, not the whole sceneAs above

The status text after a proxy format is plug-in status again: ready / not loaded / unavailable. When it is "unavailable" the checkbox is disabled and cannot enter the export configuration.

Materials and lights lock all proxy formats by default (they have no geometry to proxy). Models / scenes allow them. To change locks: Settings → Export defaults.

A complete example (adding an animated model)

  1. Select the model to export in Maya (including its animation curves).
  2. Open the export dialog and tick Maya ASCII .ma in the right column.
  3. Under animation export pick timeline or keyframes as needed — confirm with the timeline range that the animation really is in that segment.
  4. Tick Alembic .abc if a cache is part of the deliverable.
  5. To make life easier for a rendering colleague, tick one proxy format for the renderer you use (check the status reads "ready" first).
  6. Click Create asset and wait. The package is much larger than a plain model, which is normal.
  7. Verify: Asset details should list ma + abc/ass and so on under included formats, and the animation format row shows the animation formats carried this time.

Troubleshooting

SymptomCauseWhat to do
The exported asset does not moveAnimation export was left on current frameRe-export with timeline or keyframes
The .abc is hugeThe frame range was too long, or per-frame baking is inherently heavyUse keyframes to narrow the range, or accept the size if you really need the whole segment
A proxy format cannot be tickedLocked by the category, or the plug-in is not installedSwitch to the models / scenes category; confirm the renderer plug-in is loaded
Proxy export errors outRenderer version / license issueCheck the Script Editor; export only .ma first to keep the asset usable
