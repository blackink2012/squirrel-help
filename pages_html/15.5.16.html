一句话定位：这五条都会动到资产本身（字段 / 缩略图 / 内容 / 存亡 / 格式），是右键菜单里最需要看清再用的一段。

菜单逐项详解

菜单项作用前提点了之后注意
编辑改资产的中文名、分类、标签、注释无弹「编辑资产」对话框，保存后卡片、标题与属性面板一起更新只改元数据，不动几何 / 贴图
更新缩略图 ▶换掉或新增缩略图「后台渲染」需本机有 mayapy子菜单 7 项，见下节缩略图是资产的展示门面，改之前先备份原图也行——旧图会被覆盖
更新资产 ▶把资产内容换成 / 扩成新的「替换资产」等需要场景里有选中物体子菜单 7 项，见下节每一项都写磁盘，做前确认目标资产对不对
删除 ▶删掉这个资产无子菜单两项：移到回收站 / 彻底删除「彻底删除」不可还原
格式转换把资产里的几何体转成其它格式并追加进资产包本机有 mayapy（无头执行）弹「格式转换」对话框，勾选目标格式后开始原有格式保留；转换在库外临时目录完成并验证后才写回

子菜单：更新缩略图 ▶（7 项）

子项来源结果前提
截取弹出截图覆盖层，框选一张覆盖当前主缩略图有屏幕可截
导入选一个本地图片文件覆盖当前主缩略图有本地图片
Maya拍屏先问帧模式（当前帧 / 时间轴范围），再拍屏出图覆盖主缩略图Maya 已连接、有可拍视口
渲染图先问帧模式，再用当前渲染器出图覆盖主缩略图Maya 已连接、渲染器可用
添加选一个本地图片文件存到新槽位（多缩略图）有本地图片
截取添加弹出截图覆盖层，截一张存到新槽位有屏幕可截
后台渲染起独立 mayapy 进程做无头离屏渲染生成新缩略图本机装了 Maya / mayapy；不碰当前视口与场景

要点：

  • 「截取 / 添加」和「截取添加」的差别是覆盖还是新增：带「添加」二字的进新槽位，不覆盖原来的主缩略图。
  • 「后台渲染」是唯一不依赖当前视口的：它在另一个进程里渲染，所以你可以继续在 Maya 里干活；多选时会批量处理全部选中资产。
  • 拍屏与渲染图会先弹帧模式选择：动画类资产要选「时间轴范围」，静帧选「当前帧」。

子菜单：更新资产 ▶（7 项）

子项作用前提
替换资产用场景里当前选中的东西重新导出并覆盖这个资产的内容场景里选中了物体
追加格式给同一资产再追加一种几何格式（原格式保留）场景里选中了物体
追加为 LOD把当前选择导出成这个资产的一条新 LOD场景里选中了物体
创建新版本把当前选择导出成这个资产的新版本（V1/V2…）场景里选中了物体
添加新变体…把当前选择导出成这个资产的一个变体场景里选中了物体
批量添加变体…（每个选中物体一个）场景里每个选中物体各出一个变体场景里选了多个物体
变体管理…打开变体管理窗口，成批改名 / 删除 / 排序资产已有变体

补充说明：

  • 每一项点下去都会先打开导出配置对话框（预填当前资产），确认格式与选项后才真正写入——不是点一下就覆盖。
  • 资产已经有变体时，这个子菜单里还会多一层「更新变体 ▶」：每个变体下面可以单独更新缩略图、用当前选中「覆盖」、追加 LOD、删除变体。
  • 动画数据子库是精简版：只有替换资产 / 创建新版本 / 添加新变体… / 变体管理…。

怎么反悔

做了怎么回去
替换资产没有撤销按钮；靠「版本」——之前如果建过版本，可以从版本浏览器切回旧版本
追加格式 / 追加为 LOD到版本浏览器 / LOD 管理里删掉刚追加的那一条
创建新版本 / 添加变体在版本浏览器 / 变体管理里删掉新建的那个
更新缩略图重新截一张 / 导一张覆盖即可

子菜单：删除 ▶（2 项）

子项行为能反悔吗
移到回收站资产进回收站，网格里消失能：回「回收站」页签可还原，见 8.8.3
彻底删除直接删文件，不进回收站不能：文件从磁盘消失，无法还原

多选时两项都对全部选中资产生效，删之前一定先看底部状态栏的「已选中 N 个资产」。

格式转换对话框

点「格式转换」后弹出一个小窗口：

区域 / 控件说明
顶部说明显示「将对 N 个资产执行」以及资产名
勾选项Maya ASCII .ma / Maya Binary .mb / FBX .fbx / Wavefront OBJ .obj / USD .usd / Alembic .abc
底部说明转换全部在库外临时目录完成并验证后才写进资产包，原有格式不会被删除
按钮取消 / 开始转换
  • 只能追加格式，做不到「转成别的格式并删掉原来的」；
  • 转换是无头执行，期间别关 Maya（插件版）或别退出程序（独立版）；
  • 多选资产时一次批量转换，结果写回各自的资产包。

这段菜单的风险提示

  • 删除 ▶ 的「彻底删除」是整张菜单里唯一不可逆的操作，它没有回收站兜底。
  • 更新资产会覆盖内容：替换资产是「用当前场景覆盖旧内容」，旧内容只有存在于某个版本里才救得回来。
  • 格式转换只加不减：资产会变大，不会变小。
