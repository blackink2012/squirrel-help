为两种材质节点类型建立逐属性的映射关系，并保存成 .mmap 供材质转换工具使用。

用途

决定「源材质的哪个属性 → 目标材质的哪个属性」，还可指定转换函数与默认值，是材质转换质量的关键配置。

输入与输出

  • 输入：源 / 目标材质节点（从 Maya 当前选择加载），或手动填写节点类型与属性。
  • 输出：.mmap 预设（JSON），默认保存在 Assets/material_mapper_presets/，命名形如 源节点类型_目标节点类型.mmap。
  • 映射表共 5 列：选择、源材质属性、目标属性、转换函数、默认值。

操作步骤

  1. 打开「快捷工具 → 材质节点属性映射工具」。
  2. 在 Maya 中选中源材质节点，点击「源节点」旁的「加载」；再选中目标材质节点，点击目标节点旁的「加载」。
  3. 点击「添加行」，从下拉框选择源属性与目标属性；也可用「属性浏览器」按当前选中对象挑属性。
  4. 按需填写转换函数与默认值；「载入默认值」可读取目标节点当前值批量填入。
  5. 需要自动推断时，选择 AI 服务与模型后点击「AI 智能映射」；也可右键单行做局部推断。
  6. 点击「保存预设」保存为 .mmap；下次用「加载预设」复用。

结果验证

  • 保存后提示「预设已保存到: <路径>」，并可在预设目录看到 .mmap。
  • 关闭窗口会自动保存 _last_preset.mmap，下次打开自动恢复上次配置。
  • 在材质转换工具中加载同一映射文件夹后，表格能看到对应源 / 目标类型与属性数量。

参数与注意事项

  • 转换函数覆盖 RGB 通道拆分、透明度转透射、光泽度转粗糙度、金属度估算、自发光、颜色运算等；函数参数以 JSON 填写（如 {"scalar": 2.0}），切换函数会自动填入默认参数。
  • AI 服务可选 Ollama（本地，无需 API Key）、DeepSeek、通义千问（需 API Key）；本地默认模型为 qwen3-vl:8b，未安装时请在下拉框改选已拉取的模型或执行 ollama pull。
  • 属性下拉为空通常是没有通过「加载」载入节点；可改用属性浏览器逐项添加。
  • AI 返回无效结果时，先确认服务可访问、模型可用；属性过多可分批对选中行执行。
  • 预设目录可用界面上的「打开文件夹」直达；同一条源属性重复会被清空重复项。
