Hand the thumbnails of one or more assets to a vision model; it returns a display name, suggested category, tags and notes, and writes them back into the asset metadata once you confirm.

Prerequisites

  • The assets have usable thumbnails; assets without one are skipped.
  • A model that accepts image input is configured, or a local vision chat model is installed.

Steps

  1. Select the assets to analyze in the asset grid.
  2. Right-click an asset and choose 「AI 分析缩略图」 (AI thumbnail analysis), or pick 「AI 分析缩略图」 (AI thumbnail analysis) with the selected count from the 「AI 工具」 (AI tools) menu.
  3. In the analysis configuration choose the provider, model and output language, and decide whether to 「分析完成后弹出窗口供我审查和编辑」 (open a window for review and editing after analysis) and whether to translate existing tags.
  4. Click 「开始分析」 (Start analysis) and wait for progress.
  5. Check each item in the result window, edit as needed and click 「应用到元数据」 (Apply to metadata).

Verify the result

The result window shows the thumbnail, the original asset name, the top-level category and four checkable results: display name, sub-category, tags and notes. After applying, the names and tags in the asset grid update.

Tips and warnings

  • When the current model cannot see images it says so directly instead of silently returning an empty result.
  • DeepSeek's default model is text-only and needs a vision experimental model; Zhipu needs a vision model; OpenAI's o series does not support images.
  • When a model is unavailable the plug-in tries an available vision model from the list and states the substitution reason in the results.
