Moving a category takes the whole folder, including sub-categories and assets, to a new location; category order follows folder names, and there is no manual ordering entry yet.

Moving a category

  1. Right-click the category to move and choose 「移动到...」 (Move to...).
  2. Choose the destination in the list: 根目录 (root) or a top-level category.
  3. Click 「确定」 (OK).

Result: the folder on disk is moved as a whole, the tree and grid refresh, and sub-categories and assets move with it.

Moving assets

Select one or more asset cards in the grid and drag them onto the target category in the left column (the drop target is the category itself, not 「全部资产」 (All assets)). A multi-selection moves as a batch, and the grid jumps to the target category afterwards.

Sorting

  • The category tree is displayed in folder-name order (the source uses sorted(os.listdir(...))); sibling nodes have no move-up / move-down or drag-to-reorder entry (whether this will be added later is to be confirmed).
  • Sorting in the asset grid is a separate mechanism: see "View modes and sorting".

Tips

  • The 「移动到...」 (Move to...) list only contains the root and top-level categories; a deep sub-category cannot be picked directly.
  • Confirm the target category's type before moving; moving across types can make the context menu mismatch the assets.
