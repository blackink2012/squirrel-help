Licenses come as trial, perpetual, subscription and floating licenses, plus offline licenses issued by the vendor for a specific machine code. A license is normally bound to this machine's code, and activation is either online or offline.

License and versions

LicenseValidityWhich versions it covers
TrialPer the license (the current promotion period is 1 year)Latest version
Subscription (annual)365 days, renewableAlways the latest version while valid
PerpetualNo expiryThe major version current at first activation, plus new versions released in the following 3 years (older major versions also work); for offline-issued licenses the major version at issue time applies
  • The 3 years of free upgrades for a perpetual license start on the first activation date (for vendor-issued offline perpetual licenses, the issue date), and the baseline version is the current major version at activation / issue time (independent of which version is installed on this machine). The license window shows 「版本范围：1.x · 免费升级至 <date>」 (Version range: 1.x · free upgrades until <date>).
  • After the 3 years, moving to a newer major version needs a new purchase; versions you already own keep working and are never disabled.
  • The message 「当前版本超出该授权范围」 (this version is outside the license range) means the installed version is beyond your version range: keep using the older version or buy a new license.
  • The 「购买授权」 (Buy license) button is always visible and enabled only when the product is unlicensed, expired, or within 15 days of expiry; with plenty of license time left it is greyed out with a hover reason.
  • The green Activate button appears both on Settings → License activation and in the License management window. With an empty key and no trial started yet, clicking it issues a per-machine trial license from the server (no sign-in window); with a key it activates online.

Once the trial or license expires, unlicensed features are limited to read-only mode; the current code checks the license at import, export and conversion entry points.

Activation methods

  • Free trial: while unlicensed and no trial started yet, leave the key empty and click the green Activate button; the server issues a per-machine trial license (no sign-in needed) that includes all features.
  • Online activation (code): enter a SQAM-XXXX-XXXX-XXXX-XXXX key in the field under the machine code on Settings → License activation, then click Activate. The license window accepts the same key.
  • Offline activation: expand the collapsed 「离线许可证激活」 (Offline license activation) section in the license window and click 「导入许可证文件…」 (Import license file…) to pick a .lic / .dat / .json file issued by the licensor.
  • From the clipboard: copy the full license text and click Import from clipboard; it activates directly and never shows the license content. You can also drag the license file into the license window.
  • Online-activated licenses: deactivation is limited only by the server's daily cap (max 3 per 24 hours); there is no machine-switch counter.
  • Offline-issued licenses: issued by the vendor for a machine code and cannot be unbound for a machine move. When online they only do read-only registration + heartbeat (no seat, no account binding; the server cannot revoke or delete them). The version range and the 3-year free-upgrade cutoff of a perpetual certificate are fixed at issue time; a heartbeat inside the upgrade window raises max_version automatically (the window still shows 「版本范围 / 免费升级至」).
  • The license is written to %PROGRAMDATA%\SquirrelAssetManager\license.dat first and falls back to %LOCALAPPDATA%\SquirrelAssetManager\license.dat if that fails; the trial record is trial.dat.

Machine code

  • The machine code is derived from hardware signals of this machine.
  • Licenses not bound to a machine are issued only by special arrangement; regular offline-issued and online-activated licenses are bound to the machine code.
  • Where to see it: the read-only 「机器码」 (Machine code) field in the Current license card of Settings → License activation, with 「复制」 (Copy) on the right; it is also shown in the 「授权管理」 (License management) window.

Verify the result

  • The status badge on Settings → License activation shows Licensed or Trial, and the status line updates.
  • The machine code is not -, and copying it yields the complete string.
  • Import and export no longer report an insufficient license.

Notes

  • A machine code is not a license and cannot replace an activation code or license file.
  • Do not publish activation codes or license files; offline licenses are usually bound to this machine's code.
