把一组按通道命名的 PBR 贴图按材质分组，每个材质打包成一个 .zasset，并自动识别通道类型与多精度。

用途

省去手工整理 BaseColor、Normal、Roughness 等贴图的工作，把 Megascans、Zoo Tools 或自建贴图目录直接变成资产。

菜单里显示的是脚本名：快捷工具菜单直接扫描 quicktools/ 下的脚本，条目名 = 文件名去掉 .py 后把下划线换成空格，所以菜单里看到的是 pbr to zasset，不是中文标题。三个转资产工具的对应关系：hdr to zasset = HDR 转资产、model to zasset = 模型转资产、pbr to zasset = PBR 贴图转资产。

输入与输出

  • 输入：包含 PBR 贴图的文件夹；勾选「批量模式」时选择父文件夹，每个子文件夹作为独立资产。
  • 输出：每个材质一个 <材质名>.zasset，默认写到输入文件夹（也可另设「输出位置」）。
  • 资产内部：textures/ 下按通道存放贴图；多精度时按 textures/2k/、textures/4k/ 等分层。meta.json 记录 properties 通道映射，以及可选的 resolutions 与 default_resolution；有缩略图时含 thumb.sicon。

贴图命名规则

工具用「下划线 + 通道别名」识别贴图，别名不区分大小写：

通道可用别名
baseColorbasecolor、base_color、albedo、diffuse、col、color、base、diff
normalnormal、norm、nor、nrm、n、normalmap、nor_dx、nor_gl
roughnessroughness、rough、rgh、roughnessmap、rough_map
metallicmetal、mtl、metalness、metal_map、metallic_map
aoao、ambient、occlusion、ambient_occlusion、ao_map、occ
emissiveemissive、emit、emission、illumination、emissive_map、glow
heightheight、heightmap、height_map、bump、bump_map、disp、displacement、disp_map
  • 别名必须与前面的名称用 _ 分隔，例如 wood_albedo.png；woodcolor.png 不会被识别。
  • 组合贴图 arm / orm 按 R=AO、G=Roughness、B=Metallic 处理。
  • 分辨率标记（_2K_、_4K_、_8K_ 等）会从文件名中剥离，也可用 2k/、4k/ 等子目录表达。
  • 材质名取通道别名之前的名称，例如 brick_2K_Albedo → brick。

操作步骤

  1. 打开「快捷工具 → pbr to zasset」。
  2. 点击「浏览」选择贴图文件夹；批量模式则选父文件夹。
  3. 点击「扫描贴图」，在右侧核对材质数量、通道与精度。
  4. 设置输出位置，按需调整选项。
  5. 点击「转换」。

结果验证

  • 扫描后状态栏显示发现的材质与贴图数量。
  • 转换完成弹出统计；输出目录出现每个材质的 .zasset。
  • 打开资产可见 meta.json 的通道路径与 textures/ 内容；资产库中能显示缩略图。

参数与注意事项

选项默认说明
导出 .zasset 资产文件开关闭时只做扫描 / 预览
批量模式（子文件夹作为独立资产）关适合一个父目录下多个资产文件夹
转换后导入当前分类关转换后把 .zasset 拷到当前资产库分类
打包所有精度开开启时各精度分别进 textures/<精度>/；关闭只打包默认精度
递归扫描子文件夹关贴图在 tex/ 等子目录时开启；可选自动递归或手动指定文件夹名
排除空递归时跳过的文件夹名，逗号分隔，如 Thumbs, previews
  • 扫描不到有效贴图时状态栏会提示未发现 PBR 贴图，先检查命名中的下划线与别名。
  • 缩略图与元数据来源由 Assets/preset/pbr_mapping.json 配置；支持 {materialName} / {folderName} 占位与 JSON/TXT 元数据源。
