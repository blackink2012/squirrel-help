One-line summary: the Favorites tab is a set of favorite sets: collect frequently used assets to browse separately, without changing their categories or copying files.

How to open it

Left navigation → click the Favorites tab. On switching, the plug-in syncs the current library's favorites data and selects the favorite set you used last.

How to put assets in

Three ways with the same effect (all just add a "favorite relation"):

  1. Drag and drop: drag an asset card onto a favorite set in the left column (the row highlights on hover) and release.
  2. Star: click the star on an asset card to add or remove it from the currently selected set.
  3. Context menu: right-click an asset → Add to favorite set, see 8.5.14.

Beginner pitfalls

  • Assets are missing from a favorite set: check the Current library hint — you may have switched to another library (main-library favorites are not visible in the project library).
  • Assuming assets were deleted after emptying a set: they were not. Emptying only clears the favorite relation and the assets remain in their original categories; to really delete assets use right-click Move to recycle bin, see 8.5.16.
  • Assets disappeared after deleting a favorite set: assets are never deleted, only the set. They do not appear in the recycle bin either.
  • The default set cannot be renamed or deleted: by design, it is the fallback set; it can be emptied.
  • Editing assets on the Favorites tab seems to do nothing: on the Favorites tab the star follows the selected set, and edit / move entries still work but mind which library you are in; confirm on the Category tab afterwards.
