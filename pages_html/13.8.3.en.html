A useful report contains the version, reproduction steps, the full error and the relevant logs, ideally with a minimal reproduction asset attached.

Symptoms

  • After reporting, you keep having to add information and the problem stays unlocated.
  • The report only says "does not work" or "it errored", with no version, steps or logs.
  • A screenshot was attached, but without the full error text or a timestamp.

Possible causes

  1. Error text takes priority over screenshots; use screenshots to show the UI state.
  2. Attach only the relevant log snippets and state their paths and timestamps.
  3. You may desensitize assets or scenes, but keep the structure and node types that can trigger the problem.

Verify the result

The maintainer can reproduce the problem from the report alone, or can tell exactly which layer's logs are needed.

If it still fails

  • If unsure what to attach, at least provide the version, reproduction steps, the full error and the --doctor output.
  • For crashes, attach the event log module name and offset and keep the crash dump.
  • Never publish full license files, private keys or credentials containing personal information.
  • Use 6.8.2 "Diagnostic workflow" to locate the failing layer first, then add the matching material.
