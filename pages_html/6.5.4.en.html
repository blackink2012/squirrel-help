An unavailable format is usually not an asset problem: the Maya plug-in that format needs is not loaded or not installed.

Symptoms

  • The geometry or proxy format checkbox is greyed out and the right side says 未加载 (not loaded) or 不可用 (unavailable).
  • The export succeeds but the .zasset has no file for the checked format.
  • Only a geometry format was checked yet it reports that no geometry was produced.

Common causes

CauseHow to tellFix
Plug-in registered but not loadedThe status says 未加载 (not loaded)Load it in Maya's plug-in manager and reopen the dialog
Plug-in not installedThe status says 不可用 (unavailable) and is greyed outInstall the renderer or format plug-in, or use another format
"Export materials only" is checkedIn that mode fbx / obj / usd / abc and proxies are skippedUncheck it and export again
Proxy does not match the rendererFor example Arnold .ass checked without mtoaLoad the matching plug-in or check a proxy the current renderer supports
.ma failed on unknown dataThe log reports a format conversion failureUse .mb; the program falls back to .mb once when it is unchecked

Steps

  1. Read the status text next to the format checkbox to see whether it is "not loaded" or "unavailable".
  2. Open Maya's plug-in manager and load the plug-in for that format:
    • Arnold .ass: mtoa
    • V-Ray .vrscene / .vrmesh: vrayformaya
    • Redshift .rs: redshift4maya
    • FBX .fbx: the FBX plug-in
  3. Close and reopen the export dialog so the status is detected again.
  4. Uncheck 「仅导出材质」 (Export materials only) when geometry is needed; use .zmetal when only materials are needed.
  5. Export again and confirm inside the .zasset that the target format's file now exists.

If it still fails

  • .ma / .mb are built into Maya and need no third-party plug-in; check only .mb first to verify the geometry is writable.
  • Open the Script Editor and search for [Export] to see whether the format was skipped, failed, or never reached the export flow.
  • Whether the format keys for abc, obj and similar match Maya's actual plug-in names is still to be confirmed; when the status looks wrong, check the real plug-in name in the plug-in manager first.
  • After a renderer upgrade or a fresh install, restart Maya before retrying so the plug-in registration is refreshed.
