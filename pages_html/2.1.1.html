安装前先确认 Windows 位数、Maya 版本与权限，能避免大多数「装到一半失败」。

最低要求

项目要求
操作系统Windows 64 位；安装器是 Windows 桌面程序（最低 Windows 版本待确认）
Maya（插件版）Maya 2022–2027
独立版 / EXE内置 Python 3.11.9（amd64）与 PySide6 6.9.2，不需要另装 Python
界面语言安装向导与卸载器支持简体中文 / English，默认跟随系统语言，安装时可切换
权限按当前用户安装，不需要管理员权限
磁盘安装包与运行时占数百 MB；可选 dsh / Node 另占约 300 MB（以实际包为准）
网络基础功能离线可用；在线激活、下载 dsh、云端 AI 需要网络

操作步骤

  1. 双击exe进行安装。如果弹出提醒请点击“更多信息”再点击“仍要运行”。
  2. 确认 Windows 是 64 位；32 位系统不在支持范围内。
  3. 确认磁盘剩余空间足够容纳安装包、运行时与资产库。
  4. 插件版安装前关闭所有正在运行的 Maya。
  5. 如果只用独立版，可不装 Maya；安装器中「Maya 集成」会自动取消勾选。

结果验证

  • 能读出 Maya 版本，且该版本在 2022–2027 范围内。
  • 目标磁盘可写，当前用户对安装目录有写权限。
  • 没有正在运行的 Maya 占用插件目录。

常见失败

  • Maya 版本过旧：没有对应 ABI 的 .pyd，插件无法加载。
  • 32 位系统：内置 Python 与 Qt 均为 64 位，无法运行。
  • 公司策略限制：杀毒软件或应用白名单可能拦截安装包，需要先申请放行。
  • Mac / Linux：当前只提供 Windows 安装包（Setup.exe），macOS / Linux 没有安装包，也不在支持范围内。
