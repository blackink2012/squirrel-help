The script browser's search box splits on spaces and requires every term to match (AND), and supports four prefix filters: tag:, risk:, cat: and unverified.

Purpose

Narrow down quickly when there are many scripts, for example to see one category, one tag or only unverified scripts.

Syntax

FormMeaning
keywordCase-insensitive substring match across the name, file base name, purpose, category, script root name, path, tags and trigger scenario
tag:textureThe tag must equal that value (case-insensitive)
risk:highThe risk level must be exactly high
cat:qaThe category or script root name contains that value
unverifiedShows only scripts without a live-verification record

Examples

  • tag:texture risk:high: scripts tagged texture with risk high.
  • cat:qa unverified: unverified scripts in the qa category.
  • brick: scripts whose name, purpose, tags or path contain brick.

Steps

  1. Open the script browser.
  2. Type one or more terms in the search box, separated by spaces.
  3. Keep appending prefix conditions to narrow the results; clearing the box restores every script in the current category.

Verify the result

  • The list shrinks or grows live as you type.
  • The status bar reports no error; mutually exclusive conditions simply yield an empty list.

Notes

  • Multiple terms are ANDed; OR and negation are not supported.
  • risk: is an exact match, while cat: and tag: match different scopes, since cat: also looks at the script root name.
  • Chinese keywords work directly without quotes.
  • Search only filters the current scan result and never triggers a rescan; press F5 to refresh after files change.
