「从文件导入」 (Import from files) packages each asset file on disk into its own .zasset inside the current category; it never imports directly into the Maya scene.

Prerequisites

  • A specific category is selected on the left. On 「全部资产」 (All assets) or across top-level categories the whole 「从外部导入」 (Import from Files) menu is disabled and shows one grey line: 「当前分类不支持从外部导入」 (this category does not support importing from files); dropping files onto the grid is blocked the same way with 「请先在左侧选中一个分类，再把文件拖进来。」 (select a category on the left first, then drag the files in.).
  • The current category supports 「从文件导入」 (Import from files): materials, models, lights, scenes, dynamics, node trees. The textures and HDR sub-libraries only have 「导入 .zasset 资产」 (Import a .zasset asset) plus their own imports (import texture / import HDR); the images, audio and animation data sub-libraries only have their own loose-file entries.
  • The files to import are readable on disk.

Steps

  1. Click 「从外部导入」 (Import from Files) in the toolbar above the asset area (tooltip 「导入外部资产（支持文件夹或单个文件）」 (import external assets; folders or single files)).
  2. Choose 「从文件导入」 (Import from files).
  3. Select one or more files in the file dialog; the filter covers the configured asset extensions.
  4. On confirm the plug-in creates one independent .zasset per file inside the current category.
  5. When the target category already has a same-named asset, the new name gets _001, _002 suffixes automatically.

Verify the result

  • New assets appear in the grid, matching the number of files chosen.
  • Opening the asset directory shows same-named .zasset folders containing the source files.
  • 「未能导入任何资产」 (no asset could be imported) means not one file succeeded; check that the files are readable.

Tips

  • This only adds to the library and never changes the Maya scene; to put an asset into the scene, right-click 「导入」 (Import) or double-click it afterwards.
  • The asset name comes from the file name without extension and can be changed in the properties panel on the right.
  • The menu is trimmed by the current top-level category: 「从文件导入」 (Import from files) does not appear under the textures, HDR, images, audio or animation data sub-libraries, which is intentional (those sub-libraries only accept their own kind of file); not finding the entry elsewhere is not a broken plug-in.
