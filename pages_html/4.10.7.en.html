The version browser uses three columns to review the versions, variants, thumbnails and properties of one asset family, and to import or delete versions and variants.

Prerequisites

  • The asset has versions (the card shows a multi-version badge or has_versions is true), or it has variants (the variants section of variants.json is not empty).

How to open it

Double-click the asset preview on the right. With versions or variants the version browser opens; with neither, the asset inspector still opens.

Interface

AreaContents
Left column, versions / variantsThe main version, the V1, V2… entries and the variant entries (shown as "variant · name"), all with thumbnails
Middle, previewThe thumbnail of the current entry; for a variant it shows that variant's thumbnail; with several thumbnails use the wheel or the thumbnail strip at the bottom
Right column, informationCategory breadcrumb, version and tag badges, details (size, resolution, renderer…), formats, tags, notes and path
Bottom buttonsFor versions: 「导入此版本」 (Import this version) and 「删除此版本」 (Delete this version); for variants: 「导入此变体」 (Import this variant) and 「删除此变体」 (Delete this variant)

Steps

  1. Click a version or variant in the left column; the preview in the middle and the information on the right follow.
  2. To import, click 「导入此版本」 (Import this version) or 「导入此变体」 (Import this variant), which imports using the first available format of that entry.
  3. To delete a non-main version, click 「删除此版本」 (Delete this version) or 「删除此变体」 (Delete this variant) and confirm.

Verify the result

  • The window title shows the main asset name.
  • The main version entry carries a 「主版本」 (main version) marker and its delete button is disabled.
  • After deleting a version or variant the list refreshes, and the library in the main window refreshes too.

Tips

  • Neither versions nor variants take a grid entry of their own; they are only viewed here or in the context menu.
  • A variant stores geometry only, so deleting a variant (or its thumbnail) never affects the textures and materials shared by the asset.
  • Entries with several thumbnails can be stepped through with the wheel, and the strip highlights the current image.
  • The window can be resized and maximized, and the layout scales with the interface font size.
