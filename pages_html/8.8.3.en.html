The panel shows "skill landing" and "MCP channel" separately: the first teaches the other model how to proceed, the second makes the tools actually callable.

Prerequisites

The plug-in main window is open and the target tool is installed. The skill directory of some tools has not been verified on this machine and is marked "to be verified".

Steps

  1. Open Settings → AI 设置 (AI settings) and click 「外部 AI 工具…」 (External AI tools…) in the 「外部 AI 工具」 (External AI tools) group.
  2. Find the target tool in the list and check the skill root it shows. When auto-detection is wrong click 「选择路径…」 (Choose path…) to set it by hand.
  3. Click 「安装技能」 (Install skills). If that tool already has skills installed, the list of skills to be overwritten is shown first and installation continues only after confirmation.
  4. After installing read the status line and self-check results: they should show the skills in place with a count, and list any problems item by item.
  5. When MCP is needed check the matching 「MCP 通道」 (MCP channel). For tools without a writable configuration click 「复制配置片段」 (Copy the configuration snippet) or 「手工配置说明」 (Manual configuration instructions) and paste it yourself.
  6. When it is no longer needed click 「移除技能」 (Remove skills); removal only deletes the batch recorded in the ledger.

Verify the result

The status shows 「技能已就位（N 个）」 (skills in place, N), MCP shows as attached with the configuration file path, and after the other tool restarts you can see squirrel-* skills and the matching tools.

Tips and warnings

  • Operations in this panel write to disk directly and are not controlled by the Settings dialog's OK / Cancel.
  • Another tool's configuration is backed up before writing; when it cannot be parsed the panel refuses to write.
  • The path of a tool marked "to be verified" may be wrong, so confirm it before installing.
  • Some clients only read their configuration at startup, so restart that tool after changing it.
