The error text itself is the most accurate clue: match the original wording against this page first, then use the Action column to check logs or diagnostic commands.

Chinese UI messages are quoted verbatim in code, because that is exactly what you will see.

Commands and jobs

Error textMeaningAction
未知命令: <id> (unknown command)The command id is not in the registry, or is misspelledCheck the id with squirrel_list_commands / GET /commands
命令未绑定执行器: <id> (no executor bound)The command is registered but the current host does not implement itConfirm whether the host is Maya or Blender; command sets are not interchangeable
实例 <id> 未在 N 秒内回传结果 (no result within N seconds)The synchronous call timed out; the command may still be running on the Maya main threadCheck GET /late_results first; never blindly rerun destructive commands
作业队列已满（排队 n / 上限 32） (queue full)Backpressure: the queue reached its limitCheck /jobs and submit again after running jobs finish
没有这个作业：<job_id> (no such job)The job id does not exist or was evictedRe-confirm with GET /jobs
Result over 262144 bytes returns truncated: trueThe response body was truncatedAdd limit, specify fields, or query in batches
