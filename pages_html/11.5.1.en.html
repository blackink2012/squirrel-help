Material formats preset which material-related options are checked by default when exporting each asset type.

Effect

When a new export dialog or asset creation starts, material formats are pre-checked for the current asset type, reducing repeated setup.

Values and defaults

  • Choose the asset type in the list on the left, shown as a sub-library ID; there are 11 built-in entries: materials, models, lights, textures, scenes, hdr, ani, images, audio, animation, nodetree (custom sub-libraries also appear).
  • The three options and their default asset types:
OptionAsset types where it is checked by default
Material node (.zmetal)materials, lights
Merge materials (.zmetal_merge)materials
Material → model mapping (.mcm)None

Scope

  • It only decides the initial state of checkboxes in the export interface; a single export can still change them.
  • It never changes existing assets, the context menu or quick tools.
  • It is stored under the matching asset type key in Assets/preset/export_preset.json.

When to change it

  • The material library always delivers .zmetal: keep the defaults.
  • Every material node must be its own file without merging: uncheck 「合并材质」 (Merge materials).
  • A mapping file between materials and models is needed: check .mcm.

Tips

Tip: the list on the left holds asset types, not categories; all categories under one type share the same defaults.

Tip: changes are written to the preset file only after clicking 「应用」 (Apply) and apply the next time the export dialog opens.
