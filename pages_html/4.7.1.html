::: note 名字说明这一项在菜单里和对话框标题上都叫「后台渲染」（早期版本叫「生成缩略图」）。它用独立的 mayapy 进程离屏渲染，不占用当前视口，也不修改当前场景，你可以继续在 Maya 里干活。 :::

哪些子库有这一项

子库右键「更新缩略图 ▶」里的「后台渲染」
材质、模型、灯光、贴图、场景、动态、节点树有
HDR、动画数据没有（更新缩略图只有 6 项）
图片、音频连「更新缩略图」整行都没有

找不到这一项先确认两件事：当前子库在不在上表「有」的那一行；设置 → 右键菜单里该子库的「后台渲染」开关有没有被关掉。

两种执行方式

方式入口说明
后台（无头）右键 → 更新缩略图 → 后台渲染起独立 mayapy 进程渲染，适合批量补图、不打断手头工作
本地截取、Maya 拍屏、渲染图、导出时出图在 Maya 进程内完成，要占当前视口，详见后续页面

前置条件

  • 已在网格里选中资产；多选时会批量处理全部选中项（单选=处理右键那一个）。
  • 机器上能找到 mayapy；找不到会直接提示并中止。
  • 材质、贴图、灯光资产自身没有几何，必须在对话框里选一个预设模型当拍摄对象。

操作步骤

  1. 右键资产卡片（或先多选再右键），打开「更新缩略图 → 后台渲染」。
  2. 在「后台渲染」对话框里依次选（各项含义见下表）。
  3. 点「开始生成」。
  4. 出图期间盯着无头作业进度窗口看（见下节），它会实时显示当前处理到哪个资产、进度百分比和刚出好的图。
  5. 全部完成后弹出报告：成功 / 失败数量、失败原因，以及这批用的是哪套渲染器、环境光、质量——材质 / 贴图 / 灯光还会写明用的是哪个预设模型。
  6. 成功项自动写回缩略图，网格卡片与右侧预览立即刷新。

对话框里都有什么

区域 / 控件作用说明
标题与说明「后台渲染」+「无头出图：起独立 mayapy 进程渲染，不占用当前视口、不改当前场景。」—
渲染器选本批用哪个渲染器出图当前机器不可用的渲染器会置灰并显示原因
预设模型给材质 / 贴图 / 灯光这类自身没有几何的资产指定拍摄对象模型、场景自带几何，这一块整块隐藏；清单与「创建资产 → 创建模型」同源
环境光（HDRI）勾选「使用 HDRI 环境光」并选一张，或选「不用 IBL」灯光资产不显示这一块（灯本身就是光源）；说明写明：HDRI 只作环境照明、球形投射、不进背景，出图是透明背景
尺寸256 / 384 / 512 / 768 / 1024 方图默认跟随「设置 → 常规 → 默认缩略图大小」
质量快速 / 标准 / 高映射到当前渲染器自己的采样设置：越高越干净、越慢
恢复默认把渲染器 / 预设模型 / 环境光勾选 / 尺寸 / 质量恢复出厂值只改这一次对话框，点「开始生成」后才写回设置
取消 / 开始生成放弃 / 开始出图—

出图期间：无头作业进度窗口

点「开始生成」后弹出的是一个非模态的进度窗口（不挡你操作），里面有三样东西：

  • 当前状态文字（准备中 / 正在渲染哪个资产 / 当前阶段）；
  • 进度条（按本批的资产数推进）；
  • 最新出好的一张图预览（还没出图时显示「（还没有出图）」）；
  • 「取消」和「关闭」两个按钮：点「取消」会真的停掉这批作业（已出的图保留）。

结果验证

  • 卡片与右侧预览显示新缩略图。
  • 报告列出成功与失败数量，失败项附带原因。
  • 材质、贴图、灯光那类资产，报告会写明使用的预设模型与渲染器 / 环境光 / 质量。

注意

  • 会覆盖原主缩略图：想保留旧主图时，别用「后台渲染」，改用「更新缩略图 → 添加 / 截取添加」把新图写进附加槽位。
  • 改坏了怎么反悔：重新截一张或导一张覆盖回去即可；「后台渲染」只产出缩略图，不动资产的几何 / 材质 / 贴图，所以不会把资产弄坏。
  • 尺寸只影响以后出的图：旧缩略图不会自动重做，需要重新出图才会用新尺寸（详见 4.1.7.6）。
  • 选项会记住：对话框会预选上次用的渲染器、模型、环境光、尺寸与质量，下次直接点开始即可。
提示

「恢复默认」只改这一次对话框里的选项；点「开始生成」后才把这些值写回设置，下次打开才会是新默认。
