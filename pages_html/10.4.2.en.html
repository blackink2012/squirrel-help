Thumbnail framing takes a clean square PNG of the given objects: it frames automatically, turns off camera gates and mask decorations, and restores the whole scene state afterwards.

Prerequisites

  • There is an explicit subject; the command never guesses "the only thing in the scene".
  • To write into an asset, have the asset's material_id ready.

Steps

  1. Select the objects in Maya, or pass objects when calling thumbnail_shot.
  2. Set the edge length: size is the square pixel size, defaulting to the configured thumbnail size (512 by default).
  3. Tune the composition: fill controls how much of the frame the object occupies (0.85 by default) and fit_factor controls how tight viewFit is (1.0 by default).
  4. For wireframe pass wire=true; to pin a camera or panel pass camera / panel.
  5. To write this image straight into an asset pass material_id, which is equivalent to running "update thumbnail" at the same time.

Verify the result

It returns ok with path plus self-check details such as format, stats and warnings; open the PNG and confirm the subject is centered and the image is not flat. When the format is not PNG or the image is flat, status drops to partial; when the target covers not a single pixel it errors and the image cannot be used.

Tips and warnings

  • With no subject it errors immediately; select objects first or pass objects explicitly.
  • The focal length is only replaced with 70mm when the camera still has Maya's default 35mm; focal_length=0 means no intervention.
  • The capture temporarily isolates the target and hides camera gate decorations; afterwards the camera, panel, selection, current frame and isolation state are all restored, so the scene is unchanged.
