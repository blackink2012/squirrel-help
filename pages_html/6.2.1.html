左栏负责「这一次怎么导」：开始按钮、导出模式、截图方式、命名和标签。

控件界面原文说明
开始按钮创建资产读取当前 Maya 选中并开始导出；对话框是非模态的，导出期间仍可操作其他界面
帮助按钮橙色帮助图标打开旧的导出帮助页
导出模式全自动（各物体独立资产，自动截图） / 半自动（各物体独立资产，手动截图） / 单资产（合并为一个资产，手动截图）默认选「单资产」；三种模式的差别见「三种导出模式」
截图延迟截图延迟: + 秒数输入框范围 0–60 秒，默认 2 秒，0 表示不等待；仅「全自动」时显示
命名信息名称（英文，Maya 节点用） / 易读名（中文显示，可空）名称参与 .zasset 文件名；易读名只影响界面显示
缩略图来源截屏工具 / Maya 拍屏 / 渲染图三选一；具体差别见「缩略图来源与截图延迟」
创建模型创建模型 下拉列出插件 Assets/Meshes 下的模型，选择后导入当前场景；悬停条目显示同名 PNG 预览
创建灯光创建灯光 下拉列出插件 Assets/IBL 下的 HDR，选择后按当前渲染器创建穹顶灯；悬停显示同名 PNG 预览
已选标签已选标签显示本次要写入资产的标签，点标签芯片可移除
常用标签常用标签点击标签即加入「已选标签」；下方输入框可输入新标签，回车或点「+ 添加」
信息行目标分类 / 源节点 / 关联物体 / 检测到 N 个材质只读提示，随打开对话框时的分类和选中内容变化

批量模式的命名规则

全自动和半自动下，名称输入框的占位提示是「首个资产手动命名 → 后续自动使用节点名」，易读名提示是「后续资产留空」。名称留空时，每个资产取各自物体或材质节点名；易读名只有首个资产填写的值会生效。

追加格式模式

从「更新资产」选择「追加格式」时，右栏最上方会多出一条黄色提示：所有格式默认不勾选，资产已有的格式在名称后标注「（已存在）」；勾选已有格式会用本次导出结果替换原文件，未勾选的格式保持原样。

当前版本说明

旧帮助把「导出模式、缩略图来源、截图延迟」放在左侧，把「资产名称、中文名称、标签」放在右侧；当前版本左侧是「创建资产 + 导出模式 + 命名信息 + 缩略图来源 + 标签」，右侧是「收集关联文件 + 导出选项 + 各格式分区」。界面文案以当前版本为准。
