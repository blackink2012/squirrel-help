First, a common misunderstanding: the window behind this page is titled Format conversion, and it converts the asset's geometry formats (.ma / .mb / .fbx / .obj / .usd / .abc), not image formats.

Real image format conversion is a different window (the Image format conversion tool in quick tools), see 8.14.4. This page keeps the directory title "image format conversion" but documents the actual window.

One-line summary: take the geometry already inside an asset, convert it to the formats you tick and append them to the package; existing formats are never deleted.

How to open it

  1. Select the assets to convert in the grid (multi-select allowed).
  2. Right-click → Format conversion.
  3. A window opens (titled Format conversion) whose first line reads "will run on N assets: <names…>".

Prerequisite: the asset holds usable geometry files (ma/mb/fbx/abc/usd/obj). Pure material or pure texture assets have no geometry and report "no processable assets" first.

The footer line "all conversion happens in a temporary directory outside the library and is verified before writing into the package; existing formats are not deleted" is key: unticked formats stay as they are, while a ticked same-named format is replaced by this result.

How the conversion runs

  1. Clicking Start conversion opens a progress window (titled Format conversion) showing which asset of how many is running, with a cancel button.
  2. The plug-in starts a separate headless mayapy process: output goes to a temporary directory outside the library → files are verified → written into the .zasset in one go.
  3. After writing it reloads the index and refreshes the grid; the included formats gain what you ticked.
  4. When finished a summary appears: "Format conversion finished. N succeeded, M failed." Failures come with reasons.

A complete example (adding FBX to a model asset)

  1. Select one (or several) model assets.
  2. Right-click → Format conversion.
  3. Tick only FBX .fbx; if the asset already has fbx the small text says "exists" — confirm you want a replacement before ticking.
  4. Click Start conversion.
  5. Wait for the progress window and read the summary.
  6. Verify: right-click the asset → Asset details → fbx should appear under included formats.

Risks and how to undo

OperationRiskUndo
Ticking a format the asset already hasThe old file of that format is replaced by this conversionExport again from the original source; the old format is not kept automatically
Converting many assetsThe headless process runs them one by one and takes a whileThe progress window can be cancelled and finished assets keep their results
Unticked formatsAll other formats are preserved—

Troubleshooting

SymptomCauseWhat to do
"No processable assets"The asset holds no geometry files (pure material / texture)Such assets cannot convert geometry formats; for images use 8.14.4
One item failed in the summaryThe target format failed to export (plug-in not loaded, format not convertible)Expand the error details and load the matching plug-in before retrying
The grid did not change afterwardsThe index has not refreshedRefresh manually or rebuild the index
The conversion takes very longThe headless process is running on a large assetWait, or cancel from the progress window
