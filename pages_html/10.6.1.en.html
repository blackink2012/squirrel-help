mayapy.exe is Maya's Python interpreter; it starts the complete Maya core without an interface, and the plug-in uses it for thumbnails and format conversion, without touching your open Maya or scene.

How it runs

  • The parent process first looks for a mayapy.exe of the same version as the current Maya. When it cannot find one, set SQUIRREL_MAYAPY to <Maya install directory>\bin\mayapy.exe.
  • Every job creates a working directory in the system temp folder, writes job.json and has mayapy run tools/asset_headless_worker.py.
  • The worker never imports the plug-in package, so it can be reproduced with mayapy alone.
  • Jobs produce output outside the library and only write into the asset package after verification.

Steps

  1. Right-click an asset in the library and choose 「更新缩略图」 (Update thumbnail) → 「后台渲染」 (Background render), or choose 「格式转换」 (Format conversion).
  2. 「后台渲染」 (Background render) first shows its options dialog; confirm renderer, model, environment light, size and quality and click 「开始生成」 (Start).
  3. Wait for the progress window to finish; the interface stays usable meanwhile.

Note: the headless render menu item is now called 「后台渲染」 (Background render) (the old "generate thumbnail" wording is gone). It appears only in the context menu of the materials / models / lights / textures / scenes / dynamics / node trees sub-libraries; HDR, images, audio and animation data do not have it.

Verify the result

The job returns ok / failed with per-item results; once thumbnails are written back the card images refresh. Failures carry a reason, such as no geometry, no mayapy or missing render tools.

Tips and warnings

  • mayapy opens a separate empty scene; it cannot read the scene you have open and has no viewport.
  • To read the current scene or grab a viewport, use the interface version or the bridge channel, never mayapy.
  • The working directory is cleaned up only after results are written back; a mid-way failure leaves unadopted temporary output behind, which does not affect the library.
