The default view decides whether the asset browser presents assets as an icon grid or as a list.

Effect

It sets the display mode used when the library opens and when switching categories.

Values and defaults

  • Icon grid (default): thumbnails in a grid, good for finding assets by appearance.
  • List view: rows of asset information, good for checking fields such as name and type.

Scope

  • After clicking 「应用」 (Apply) the main window switches immediately and remembers the choice as the default.
  • It only changes the presentation and never the filtering, sorting or selection logic.
  • Thumbnail size in the grid is controlled by the toolbar's thumbnail slider and is unrelated to this item.
  • It also does not affect the command run when double-clicking an asset.

When to change it

  • Use the icon grid when there are many assets and thumbnails should be browsed quickly.
  • Use list view when checking names, categories or tags one by one.

Tips

Tip: switching the view never rescans the library; the current category and filters stay as they are.

Tip: to change double-click behavior, see "Choosing a command per sub-library".
