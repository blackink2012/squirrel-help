One-line summary: group the PBR textures in a folder (albedo / roughness / normal…) by material and pack each material into one .zasset texture asset.

It follows the same idea as model to asset but recognizes a different thing: texture sets. A material usually has 4–6 textures (basecolor / roughness / normal / metalness…), and this tool gathers them into one asset instead of scattering six.

A complete flow

  1. Quick tools → pbr to zasset;
  2. Choose the parent directory under Texture folder (tick batch mode for batch import);
  3. Choose an empty directory under Output location;
  4. Tick Export .zasset asset file (the step most often missed);
  5. Tick Recursively scan textures in subfolders when textures live in subdirectories, and Pack all resolutions when a material has several resolutions;
  6. Click Scan textures and check the Detected materials list: file counts per material and whether the structure preview makes sense;
  7. If needed use AI directory parsing to fill routing / metadata sources, then Save routes and Save configuration;
  8. Click Convert and wait for the completion message;
  9. Spot-check 1–2 .zasset folders in the output directory: are the textures complete, are the resolution subfolders right;
  10. Once confirmed, copy into the library category and refresh the main window.

Where the output lands

  • One .zasset folder per material under the output location;
  • Inside are the textures (possibly split by resolution), a thumbnail and meta.json;
  • With Import into the current category after conversion ticked another copy goes to the current category and appears after refreshing the main window.

Risks and how to undo

  • A same-named .zasset is replaced entirely (delete the old one, then build the new one): output into an empty directory before a batch conversion.
  • Wrong texture grouping: the most common result is "one material split into two assets" or "two materials merged into one". In batch mode always read the scan list instead of trusting "conversion finished".
  • Without Export .zasset asset file ticked, nothing is produced and it reports no executable operation — not a bug.
  • To undo, delete the newly generated .zasset folders; ones already imported go to the recycle bin from the main window (8.5.16).
