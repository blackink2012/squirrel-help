Common tags are a shortcut tag library maintained per asset type; a tag typed in the properties panel is added automatically and can then be picked with one click in properties, batch tagging and the right-click editor.

What it is

  • Common tags are not a field on an asset but a table of candidate tags stored separately per sub-library.
  • They are stored per sub-library: materials, models, textures, lights, scenes, HDR and dynamics each have their own list; images, audio, animation data and node trees currently have no preset common tags (tags used there are collected automatically as you type).
  • They serve 「+ 添加标签」 (+ Add tag) in the properties panel, the batch tag dialog and the right-click edit dialog.

Automatic collection

  1. Select an asset and enter property editing.
  2. Click 「+ 添加标签」 (+ Add tag), type a tag that is not in the common tag library yet and add it.
  3. The plug-in writes it into the common tags of the current asset type and saves it to the configuration.
  4. The next time you tag an asset of the same type, the tag can be picked directly in the common tags area.

Manual management

  1. Click 「编辑标签」 (Edit tags) in the toolbar to open the tag window for the current asset type.
  2. The top of the window lists every common tag of that type; clicking a chip toggles the filter.
  3. Type a new tag in the box at the bottom and click 「添加」 (Add) to add it to the common tag library.
  4. Right-click a tag chip and choose 「删除」 (Delete) to remove it from the common tag library.

Verify the result

  • Reopening the tag window still lists the newly added tag.
  • The 「+ 添加标签」 (+ Add tag) dialog in the properties panel shows the new tag.
  • After deleting a common tag it no longer appears among the candidates.
注意

Removing a tag from the common tag library does not remove it from assets that already carry it; remove those in the properties panel or with batch tagging.

提示

The batch tag dialog reads the common tags of the current sub-library, so maintaining common tags first makes organizing assets of the same kind much easier.
