「创建新版本」 (Create new version) builds a complete sub-version V{n} inside the main asset and fills it with this export, leaving the main version unchanged.

Prerequisites

  • The main .zasset already exists.
  • Select the modified geometry, material nodes or texture nodes as needed; a new version does not require geometry, exporting only materials also works.
  • To give the version its own materials, be ready to check 材质预设 .zmetal (material preset).

Steps

  1. Select what the new version should export in Maya.
  2. Right-click the main asset card, expand 「更新资产」 (Update asset) and choose 「创建新版本」 (Create new version).
  3. In the export dialog that opens, check this export's content: geometry, 材质预设 .zmetal, 贴图 textures/ and so on.
  4. Click 「创建资产」 (Create asset).
  5. Wait for it to finish; the program runs a separate thumbnail capture for the new version.

Verify the result

  • 「「资产名」已创建新版本 V1」 (asset "…" got new version V1) appears; the number is the highest existing V{n} plus one.
  • Double-clicking the main asset's preview on the right opens the asset versions window, where 「主版本」 (main version) and V1 are listed.
  • Right-click the asset → 「导入变体 / 版本」 (Import variant / version) (or 「导入版本 / LOD」 (Import version / LOD) when there are no variants) → a V1 submenu appears.
  • V1/ has its own meta.json; the main asset's meta.json records it under version_assets and has_versions is true.

Tips and warnings

Tip: a sub-version is a self-contained version asset: creation first copies the main version's content as a skeleton, then replaces it entirely with this export while keeping the sub-version identity fields (is_version, version_of, version_label, version_tag).

Tip: when the V{n} directory already exists the number moves up automatically instead of overwriting the old version.

Warning: a failed sub-version export reports 「子版本导出失败，内容可能不完整」 (sub-version export failed; the content may be incomplete); that directory already exists, so check it and retry or delete it.

Current version: version directories are V1/, V2/ inside the main asset, not the variants/v2/ structure described in older help.
