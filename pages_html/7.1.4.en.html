The material node preview draws the asset's .zmetal or .ma in a node editor so you can confirm that nodes and connections are complete.

Prerequisites

  • The asset is a .zasset folder containing a .zmetal or .ma node file.
  • The plug-in is installed and its window can be opened in Maya.

Steps

  1. In the library right-click the material asset and point at 「预览节点」 (Preview nodes).
  2. The submenu lists the .zmetal and .ma files in the asset root (node.ma as geometry is not listed) plus node files under variants/....
  3. Choose one; the node editor opens and lays the graph out hierarchically.
  4. Pan with the middle mouse button or Ctrl+left drag, zoom with the wheel (10%–1000%); 「层级布局」 (Hierarchical layout) in the toolbar rearranges the graph.
  5. To compare, click 「打开文件」 (Open file) and pick another .ma / .zmetal, or drop a file straight into the window.

Verify the result

Node cards and connection lines appear; the node names shown for a .zmetal match the asset's root_materials and nodes; green lines are single-attribute connections and yellow lines mean several connections between the same pair of nodes.

Tips

  • Viewing the structure read-only in the node editor is safest; saving overwrites the original file, so back up the asset before editing.
  • The current version does not support adding new nodes by hand; to add nodes, create them in Maya first, save as .ma and then open it.
  • If nothing appears after opening, first confirm the file really contains createNode / connectAttr (.ma) or nodes (.zmetal).
