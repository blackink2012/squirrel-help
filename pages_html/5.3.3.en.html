Right-click a material asset and choose .zmetal; the plug-in rebuilds the complete shading network in the scene and writes the textures to disk per the import policy.

Prerequisites

  • A Maya scene is open.
  • The material asset contains node.zmetal; assets exported by the quick tools do not contain node network data.

Steps

  1. Right-click the material asset.
  2. With zmetal as the only format click 「导入 zmetal」 (Import zmetal); with several formats expand 「导入」 (Import) and choose zmetal.
  3. When the asset has textures at several resolutions, choose one in the 「选择贴图精度」 (Choose texture resolution) dialog; 「取消」 (Cancel) abandons the import.
  4. Wait for the node network to be built.

Verify the result

  • A complete material network appears in the Hypershade: shader, shadingGroup, file, place2dTexture and so on.
  • The new material is selected after import; the Script Editor reports 「已创建 N 个节点」 (created N nodes) and 「已选中新建材质」 (new material selected).
  • The file node's fileTextureName points at the disk path for the chosen resolution.

Tips

  • Textures follow the texture import policy in Settings → 常规 (General): copy into the project, read the asset directory directly, or keep the source path.
  • After importing zmetal, if the current renderer differs from the material's original type, the plug-in converts to the current renderer's default material without asking; to choose a target type, use 「转换导入」 (Convert import) in the context menu.
  • When the log says 「不含 .zmetal 文件（不含节点网络数据）」 (no .zmetal file, no node network data), use 「应用材质到选中」 (Apply material to selection) instead, or use the ma/mb material network inside the asset.
