An asset can have several thumbnails: the first is the main image and the rest are extra slots; the preview panel switches between them and deletes extra images.

Slot rules

  • The main image is the first one, named thumb.sicon, thumb.aicon, thumb.png or thumb.mp4.
  • Extra images start from the second, named thumb_2.sicon, thumb_3.sicon and so on.
  • Folder assets that are not .zasset use <asset name>.sicon, <asset name>_2.sicon and so on.
  • The main image cannot be deleted; it can only be replaced by capture or import.

Switching

  1. Select an asset with several thumbnails; the preview panel shows the counter n/n at the bottom.
  2. Click the arrows on either side of the preview, or scroll the wheel while hovering it.
  3. With several images the preview cycles automatically about every 2 seconds; hovering the preview or a playing animation pauses it.
  4. Double-clicking the preview opens the asset inspector window for a larger view.

Deleting an extra image

  1. Switch to the extra image to delete and confirm the counter is not 1/n.
  2. Click 「删除」 (Delete) at the bottom of the preview panel.
  3. The image file is deleted from the asset directory immediately and the preview returns to the remaining images.

Verify the result

  • After deleting, the counter drops by one and the remaining images can still be switched.
  • With only one image left the counter and delete button hide and the arrows disappear.
  • The main image always exists, so the card cover is unaffected.
警告

Deleting an extra thumbnail has no second confirmation and does not go to the recycle bin; confirm that the current counter is not the main image before deleting.

提示

To use another image as the cover, use 「导入」 (Import) on the target image to overwrite the main image instead of deleting the main image.
