Three preset files control the context menu, double-clicking a thumbnail and the default export options for asset creation. All are written by the settings window and sectioned per sub-library (asset_type).

FilePurposeSettings entry
Assets/preset/context_menu_preset.jsonWhich context menu items each sub-library showsSettings → Context menu
Assets/preset/double_click_preset.jsonWhich command runs when a thumbnail is double-clickedSettings → Context menu (the Double-click commands group in the lower half of that page)
Assets/preset/export_preset.jsonDefault export options when creating assetsSettings → Export defaults

Settings has no separate Double-click commands tab; double-click commands live in the lower half of the Context menu page.

Context menu preset

The default section is the fallback used by custom sub-libraries or categories that are not registered; each of the 11 built-in sub-libraries has its own section. Every key is a boolean and defaults to false.

  • Common items are on by default: import, import_geometry, add_reference, favorites, select_all, duplicate, open_folder, move_to, copy_to, edit, create_asset, update_thumbnail, update_asset, delete, preview_node, ai_analysis, generate_thumbnail (background render) and asset_details.
  • Specialized items are off by default and turned on per sub-library: materials enable apply_material, apply_material_params, convert_import; textures enable apply_material, create_material, import_texture, assign_texture; lights enable apply_light, convert_import; HDR enables create_dome_light, assign_texture; models / scenes / animation / node tree enable convert_format.
  • Images / audio / animation data only have the common items (favorite, duplicate, open folder, move to, edit, delete, AI analysis, asset details and so on); audio additionally enables convert_format (convert to a WAV copy) and animation data additionally enables update_thumbnail. Their own import items are not in this preset table; the UI provides them directly per sub-library.
  • The file only lists items that sub-library actually has; items that do not exist are not shown.

Export preset

_default provides the fallback and other keys override it per asset_type. The fields fall into four groups:

  • Format switches: zmetal, zmetal_merge, mcm, mcm_min_count, ma, mb, fbx, obj, usd, abc, arnold, vray, redshift, vrmesh.
  • Content switches: material_only, collect_associated, textures.
  • Animation frame capture: ani_frame_mode takes current / timeline / keyframe.
  • Thumbnail: delay_ms (default 2000) and thumb_source (screenshot / playblast / render).

Current defaults: collecting associated files and textures are both on, thumbnail source is screenshot; the materials sub-library has material_only=true; the animation sub-library has ani_frame_mode=timeline.

All 11 built-in sub-libraries have sections, and the newer ones differ noticeably:

SectionDifference from _default
imagesAll geometry formats off (ma is false too), material_only=true, collect_associated=false, texture packing for images only
audio / animationAll geometry formats off, material_only / collect_associated / textures all false (these two have no geometry or textures to export)
nodetreeEssentially the same as _default (ma on)
aniabc=true, ani_frame_mode=timeline

Tip: After a manual edit, reopen the main window or reload the plug-in; changes made in the settings window are written back to these files immediately.
