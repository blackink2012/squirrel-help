The troubleshooting order is "check state first, then act": a bridge health check confirms Maya is alive, broker endpoints confirm instances and jobs, and index and AI checks confirm the search chain.

Maya bridge

Run from the project root or the plug-in package directory (with the system Python on Windows):

CommandPurpose
python maya_bridge.py --pingActually dispatches one command and returns the Maya version and current scene
python maya_bridge.py --scanScans the per-version ports and the fallback range 7110–7129, listing online instances
python maya_bridge.py --doctorReport only: who is online, who is hung, what should be cleaned, whether render leftovers exist
python maya_bridge.py --doctor --kill-hungCleans only instances that "listen but do not answer"; healthy instances are untouched
python maya_bridge.py --doctor --launchLaunches Maya and waits until it really answers
python maya_bridge.py <task.py> --retry-if-crashedOn disconnect, automatically diagnose, clean, launch and re-dispatch once; for idempotent tasks only

To target a version or port: --maya 2025, --port 7002, or the SQUIRREL_MAYA_PORT environment variable.

Asset index and AI

CommandPurpose
python tools/asset_index.py --statusShow index count, dimensions, model and owning library
python tools/asset_index.py --verifyConsistency self-check: dimensions, row numbers, id mapping
python tools/asset_index.py --doctorEnvironment check: Ollama, models, index and suggested commands
python tools/asset_index.py --query "生锈的金属"Semantic search spot check
python tools/setup_semantic_env.py --allInstall and verify AI dependencies (Ollama, models, index)

The in-plug-in equivalent is Settings → AI settings → AI dependency check, whose report lands in %TEMP%\squirrel_asset_manager\AI依赖检查报告.txt.

Broker HTTP and commands

The broker listens on 127.0.0.1:39001 (TCP) and 39002 (HTTP) by default; the actual ports are in ~/.squirrel_asset_manager/broker_endpoint.json.

Endpoint / commandPurpose
GET /healthBroker mode, in-flight commands, instance and job statistics
GET /instances, GET /commandsInstance list and command list (including params_schema)
GET /jobs, GET /jobs/<job_id>Job list, and a single job's status, result and progress
GET /late_resultsMailbox of late results from timed-out commands
asset_semantic_statusAsset semantic index and model status
squirrel_ai_depsAI dependency check (run status first)
squirrel_maya_bridgeBridge liveness from the broker's point of view (run ping first)

Warning: --kill-hung only cleans instances that "listen but do not answer". Look at the Maya window first to rule out modal dialogs such as crash recovery, unsaved changes or error reports — dismissing a modal can rescue an unsaved scene.
