One-line summary: rename several assets at once — add a prefix, add a suffix, or replace a piece of the name — with a preview before anything changes.

How to open it

  1. Select the assets to rename in the grid (multi-select with Ctrl+click / Shift+click).
  2. A batch bar appears below the grid; click Batch rename.
  3. The window opens with the main button showing progress as "Run rename (processed/total)".

With a single asset selected the batch bar usually does not appear, so use the properties panel or right-click Edit for one name; the screenshot below is a window illustration (1 asset, button reads (0/1)).

Choosing among the three modes

Desired resultModeExample
Give a batch a common prefix (project / type abbreviation)Add prefixchair → SM_chair
Give a batch a common suffix (detail / version)Add suffixchair → chair_low
Replace words from an old naming ruleFind and replaceReplace SM_ with ENV_ in SM_chair, SM_table

A complete example

  1. Multi-select the assets to rename (2 or more).
  2. Batch bar → Batch rename.
  3. Set Rename to display name (name_cn).
  4. Click Add prefix and type SM_.
  5. Check the preview: every row should read old → SM_old, all highlighted.
  6. Look for assets that already carry SM_ (they would become SM_SM_xxx).
  7. Click Run rename (N/N).
  8. When done it reports "Batch rename finished: N succeeded"; the grid refreshes.
  9. Verify by opening the properties panel of a couple of random assets.

Risks and how to undo

OperationRiskUndo
Renaming the display name (name_cn)It only affects the UI; disk is unchangedBatch-change it back (no undo)
Renaming the file name (name)It changes the .zasset directory name on disk and the asset path with it; external scripts or tickets that hard-code the old path breakBatch-change it back; old path references must be fixed by hand
Batch executionMany at once, so a mistake must be fixed one by oneThere is no undo; copy the assets or back up the library first (4.1.12.4)

If you only want the interface to read better, prefer the display name; the file name involves disk paths, so be careful.

Troubleshooting

SymptomCauseWhat to do
Run rename is grayNo name in the preview will change (empty input, or the find text never matched)Check the inputs; find-and-replace is case-sensitive
Assets vanished after renaming the file nameThe index has not caught up with the disk renameRefresh / rebuild the index (4.1.12.2)
Duplicated prefixes in namesThe batch included assets that already had the prefixFix it again with find-and-replace to remove the duplicate
Fewer successes than selectedA few assets failed to rename (file locked / permissions)Check the [BatchRename] log and retry those individually
