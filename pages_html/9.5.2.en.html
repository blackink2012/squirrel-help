Convert materials in Maya in bulk following "source material type → target material type" mappings, with attribute transfer controlled by .mmap mapping files.

Purpose

Replace legacy materials (lambert, phong, blinn and so on) in bulk with the current renderer's materials (aiStandardSurface, redshiftStandardMaterial, VRayMtl and so on); useful when taking over an old scene or unifying material standards.

Input and output

  • Input: materials in the current scene, the material type mapping table and the .mmap files in the mapping folder.
  • Output: newly created target-type materials in the scene, with the originals deleted or kept and reassigned to objects according to the options.
  • Presets: the material type mapping can be saved as an .mlist in Assets/material_mapper_presets/mapping_type_presets/.

Steps

  1. Open 快捷工具 (Quick tools) → 材质转换工具 (Material conversion tool).
  2. In the 「映射文件」 (Mapping files) area at the top click 「浏览...」 (Browse...) and choose the folder containing .mmap files (default Assets/material_mapper_presets).
  3. Fill the source / target material types in the 「材质类型映射配置」 (Material type mapping configuration) table; pick from the dropdowns or type them by hand.
  4. When needed use 「加载源」 (Load source) / 「加载目标」 (Load target) to read types from the current Maya selection, or maintain the table with 「添加行」 (Add row), 「删除选中」 (Remove selected) and 「清空全部」 (Clear all).
  5. Under 「转换选项」 (Conversion options) confirm copying textures, keeping the original material and applying to the selected objects automatically.
  6. Click 「转换选择」 (Convert selection) to process only the selected materials, or 「转换全部」 (Convert all) to process every matching material in the scene.
  7. Read the success / failure summary afterwards; on failures use 「在Maya中选中失败材质」 (Select failed materials in Maya) to locate them.

Verify the result

  • The status bar shows progress and completion information.
  • A dialog afterwards reports the converted material count and attribute copy statistics.
  • With 「自动应用到选择对象」 (Apply to selected objects automatically) checked the objects in the viewport already use the new materials.
  • Failed materials go into 「转换失败材质列表」 (Failed material list) and can be selected in one click to fix one by one.

Options and notes

OptionDefaultNotes
Copy texture connectionsOnCopies the source material's texture connections to the target
Keep the original materialOffWhen on the source material is not deleted, which makes rollback easy
Apply to selected objects automaticallyOnAssigns the new material to the objects using the original
No mapping → default materialOffCreates a basic material of the target type when no mapping exists; when off it counts as a failure
  • Without a direct mapping file it tries an openPBR detour (A → openPBR → B), and the intermediate materials are cleaned up automatically.
  • Save the scene before converting; the target renderer plug-in must be loaded and material type names are case-sensitive.
  • Conversion needs a valid convert license.
  • With 「源」 (Source) left empty and only one row, every material is converted to that target type.
