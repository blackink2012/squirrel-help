注意

About the name. The entry on the left of the search box now covers images, video and audio; "search by image" is the historical name. This page keeps the old title but describes the buttons that actually exist. Whether you upload an image, take a screenshot, record a section of the screen or record system audio, the plug-in finds assets in the current category by visual or acoustic similarity.

Prerequisites

  • An asset library is open and 「AI 搜索」 (AI search) is checked on the right of the search box. When unchecked, the upload / capture buttons on the left of the search box are hidden.
  • The search scope follows the selected sub-library or category; when the current category does not cover that media type, it falls back to the whole library.
  • The first video / audio search loads the embedding model (about 10–20 seconds, then seconds per query).

Buttons on the left of the search box change with the category

Current categoryButtons inside the box
Materials / models / lights / textures / scenes / HDR / node trees / imagesUpload, screenshot, screen recording
Dynamics / animation dataUpload, screenshot, screen recording (find similar animation by picture)
Audio (music)Upload, screenshot, audio recording (records what this computer is playing, not the microphone)

「上传」 (Upload) is not a single button but a small menu: upload image search / upload video search / upload audio search, and the choice decides the retrieval route.

Steps

  1. Upload a file: click the upload icon on the left of the input box → choose 「上传图片搜索 / 上传视频搜索 / 上传音频搜索」 (Upload image search / video search / audio search) → pick a file.
    • Images: png, jpg, jpeg, webp, bmp, tif, tiff
    • Video: mp4, mov, mkv, webm, gif
    • Audio: wav, mp3, aiff, aif, flac, ogg, m4a, aac
  2. Screenshot search: click the 「截屏搜索」 (Screenshot search) icon, drag a region on screen and release to start; hold Ctrl while dragging to lock a square, and press Esc or right-click to cancel.
  3. Screen recording search (dynamics / animation data): after dragging a region a record button appears at its bottom right — click once to start recording, click again to stop, and the search runs automatically. The limit is about 10 seconds, longest edge 960 px, 15 fps; Esc / right-click cancels.
  4. Audio recording search (audio): click 「录制系统声音搜索」 (Record system audio search) to record what this computer is playing; the interface shows 「录音中 N 秒 / 上限 N 秒」 (recording N s / limit N s), and 「停止并搜索」 (Stop and search) starts the search. A recording shorter than 0.5 seconds asks you to record again.
  5. Drag in: drop a local image / video / audio file, web media or a library asset card onto the search box and the matching search is chosen by actual format (an asset card uses its thumbnail; an asset without a thumbnail shows a hint).
  6. Text search for media: in the audio category typing a description such as "find some rain ambience" and pressing Enter runs "text search for music"; in the dynamics / animation data category a picture description runs "text search for video". The placeholder text changes with the category.

Retrieval routes

Query typeRoute
Image① image vector search (pixel similarity, preferred) → ② a vision model turns the image into one Chinese sentence and text semantics run → ③ a vision model extracts keywords and lexical search runs
Videomedia vector search by picture features (frame sampling / fingerprints), hitting animation and dynamics assets with video thumbnails
Audiomedia vector search by sound features, hitting audio assets

States and results

During the search the status bar shows 「AI 正在分析意图…」 (AI is analyzing the intent…) or that the embedding model is loading; afterwards it reports the route actually used, for example:

  • Image search: 图片搜索：图像向量检索命中 N 个资产（xxx ms） / 按关键词「…」找到 N 个资产 / 按「…」识别后找到 N 个资产;
  • Video / audio: 视频搜索：命中 N 个资产（xxx ms） / 音频搜索：命中 N 个资产（xxx ms）;
  • Text search for media: 文字搜音乐：命中 N 个音频（xxx ms） / 文字搜视频：命中 N 个动画（xxx ms）;
  • No results: 媒体搜索：未找到匹配资产 (or 文字搜视频：没有找到匹配的动画);
  • Environment not ready: 媒体搜索暂不可用：原因.

After the results arrive the grid shows only the hits and the query thumbnail / media marker appears inside the search box.

Cancelling

  • Click the query thumbnail / ✕ inside the input box, or press Backspace with the caret at the very front (this removes only the query and keeps the typed text);
  • The status bar reports 「已取消音视频搜索（或以图搜图），恢复当前分类的全部资产」 (audio-video or image search cancelled; restoring all assets of the current category).
提示

Screen recording and audio recording both rely on the bundled ffmpeg to compose the query file; when ffmpeg is missing the plug-in says so explicitly instead of failing silently.
