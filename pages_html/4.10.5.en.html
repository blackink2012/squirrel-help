Check .zmetal when creating a new version and the materials and textures are written into that version directory, becoming materials that belong only to that version.

Prerequisites

  • The materials and textures for the new version are set up in Maya.
  • The 「更新资产 → 创建新版本」 (Update asset → Create new version) flow is about to be used.

Steps

  1. Prepare the materials and textures the new version needs in Maya.
  2. Select the modified model.
  3. Right-click the asset, expand 「更新资产」 (Update asset) and choose 「创建新版本」 (Create new version).
  4. In the export dialog that follows, check .zmetal (and any needed geometry formats).
  5. Click export; the materials and textures are written into that version's V{n}/ directory.

Verify the result

  • node.zmetal appears in the version directory, along with textures/ when there are textures.
  • Entering that version through 「导入变体 / 版本」 (Import variant / version) (or 「导入版本 / LOD」 (Import version / LOD) when there are no variants) shows and imports this material.
  • After importing, the scene uses the new version's materials and textures, while the materials in the main asset root are unchanged.

Tips

  • Without .zmetal checked the version directory has no materials of its own and importing uses the main version's materials.
  • Textures are exported together with the material; no separate texture option is needed.
  • Per-version materials are only produced by 「创建新版本」 (Create new version); a plain LOD append does not change materials.
  • To see exactly which files a version carries, check the path card in the version browser or the asset directory.
