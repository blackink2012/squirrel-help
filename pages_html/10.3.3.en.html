Applying a light writes the parameters of a light asset onto an existing light shape in the scene, mapping them for the current renderer.

Prerequisites

  • A light exists in the scene and its shape is usable.
  • The current renderer is decided; cross-renderer application converts parameters through the mapping.

Steps

  1. Select the light to modify in Maya (either the transform or the shape).
  2. Right-click the light asset in the library and choose 「应用灯光参数到选中灯光」 (Apply light parameters to the selected light).
  3. You can also call apply_light with explicit targets; without them it uses the current selection.
  4. To preview first, pass dry_run=true, which lists the target and source renderers in the return value.

Verify the result

It returns status=ok with the number of applied entries, the source renderer and a shapes list; compare intensity, color, decay and similar parameters in the Attribute Editor.

Tips and warnings

  • Light attributes live on the shape, not the transform; expand the shape when checking by hand.
  • With no light selected the command returns the error 「未选中任何灯光节点」 (no light node selected) instead of guessing a target.
  • When the source asset differs from the current renderer it converts; some parameters may not map one to one, so trust the returned shapes and the interface.
  • With .zlight present it builds a temporary light from that data and converts; without it, it falls back to the asset's .ma / .mb light network as the parameter source.
