With several assets selected, open 「批量标签」 (Batch tags) in the batch operation bar to add or remove tags on all selected assets at once.

Prerequisites

  • At least two assets are selected; the batch operation bar appears only with a multi-selection.
  • The common tag list is most accurate when the selected assets come from the same sub-library.

Adding tags

  1. Select several assets and click 「批量标签」 (Batch tags) in the batch operation bar.
  2. Keep the 「添加标签」 (Add tags) mode.
  3. Type tags in the box, separated by commas, or click common tag chips below to select them.
  4. 「全选」 (Select all) and 「取消全选」 (Deselect all) speed up working with common tags.
  5. Check 「操作预览」 (Operation preview) to confirm how many assets and tags are affected, then click 「应用」 (Apply).

Removing tags

  1. Choose 「删除标签」 (Remove tags) in the batch tag dialog.
  2. The window lists the union of the tags currently on all selected assets.
  3. Click a tag chip and it turns red to mark it for removal; click again to unmark it.
  4. Check the preview and click 「应用」 (Apply).

Verify the result

  • When it finishes, the number of successes is shown, with failures appended to the same message.
  • Asset cards and the properties panel show the updated tags.
  • Filtering by a new tag finds these assets; removed tags no longer match.
注意

When adding, a tag that already exists on an asset is not added twice; removal matching is case-insensitive.

警告

Batch tagging writes straight into every selected asset; check the asset and tag counts in 「操作预览」 (Operation preview) before applying.
