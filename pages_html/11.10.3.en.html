Day-to-day activation happens on Settings → License activation: the activation key field sits directly under the machine code, and clicking the green Activate button verifies it online. If you have not started a trial yet, leave the key empty and click Activate to start the free trial. Offline import, deactivate and restore remain in the License management window.

Prerequisites

  • Open Settings → License activation; that tab is not locked, so it works without unlocking.
  • Online activation requires a configured activation server. Without one, Activate and the activation key field are unavailable.

Steps

Online activation

  1. Open Settings → License activation.
  2. Enter a SQAM-XXXX-XXXX-XXXX-XXXX key in the Activation key field under the machine code and click Activate.
  3. On success the status badge and status line refresh immediately, and the key field is cleared.

Free trial

  1. Before any trial has been started, leave the key empty and click the green Activate button to start the trial (the server issues it per machine; no sign-in needed).
  2. The page's primary button reads License management while unlicensed and opens the license window; the green Activate there also starts the trial with an empty key.
  3. The trial includes all features; once a full license is active, the trial entry is no longer offered so it cannot overwrite a real license.

Offline license

Offline import has two entries: Settings → License activation → License details & advanced, or the License management window. The steps below use the settings page:

  1. Click the License details & advanced title to expand the card.
  2. From a file: click Import license file… and choose a .lic, .dat or .json file; you can also drag the file into the window.
  3. From the clipboard: copy the full license text first, then click Import from clipboard. It reads and activates directly and never shows the license content in the UI.

Offline import only accepts offline licenses issued manually by support (marked with the offline channel). A license file issued by online activation cannot be used for offline activation; to move or reinstall, click Activate on the License activation page.

Deactivate / restore

  • To move to another machine or re-activate, click Deactivate this machine under License details & advanced (or the same button in the License management window) and confirm. After server confirmation the seat is released; it is limited only by the server's daily release cap (3 per 24 hours), with no machine-switch counter.
  • Restore this machine re-enables a license you deactivated earlier while its local copy is still present; the button is greyed out when there is nothing to restore.
  • Offline-issued licenses do not support unbinding to another machine, so the button is disabled. Contact the licensor for a new license when you need to move.

Sync license

Sync license at the top right of the Current license card syncs with the server immediately (no need to wait for the daily heartbeat after a renewal or machine change). It also works for offline licenses: it only performs a read-only registration and heartbeat, and never revokes, deletes or downgrades the local license.

Scope of effect

  • Activation writes to local license storage; it does not modify the asset library or plug-in configuration.
  • Online and offline licensing are separate paths: a file from online activation cannot be used for offline activation (it reports E_LIC_ONLINE_FILE); offline import only accepts offline license files issued manually by support.
  • After deactivating this machine you must activate again to use restricted features.
  • When online activation fails, the error is shown and nothing falls back to offline automatically; import a license file manually.

Verify the result

The badge on License activation becomes Licensed or Trial, and the status line updates; the settings page refreshes after the license window closes.

Tips

  • A failed activation shows [error code] explanation; check the code, the license file and the network as suggested.
  • The license manager window title includes the product name; click Close to return to settings.
  • Dragging a license file into the window works without expanding the card first.
