Maya 插件版把整套界面与功能装在 Maya 进程内，直接读写当前场景，是功能最完整、操作最顺的形态。

运行方式

  • 插件代码装在本机 EXE 安装目录（默认 %LOCALAPPDATA%\SquirrelAM，安装时可改）的 squirrel_asset_manager 文件夹里，一份安装供所有已装 Maya 版本共用。
  • 核心模块按 Python ABI 提供多份 .pyd，Maya 启动时自动加载匹配的那份。
  • 安装器勾选「Maya 集成」后，会往本机检测到（或你在向导里勾选）的各版本 userSetup.py 写入带标记的启动段：导入路径、MCP 启动注册、状态行按钮、桥接端口；工具架按钮只在安装时创建一次。

入口

  • Maya 工具架的「自定义」分类中的「松鼠资产管家」按钮。
  • Maya 状态行右侧的松鼠图标。
  • 脚本编辑器执行 MaterialLibraryWindow.show_window()（没有单独注册 Maya 菜单项）。

优势

  • 直接使用当前场景与视口，拖放、吸附、缩略图截取、材质应用都在同一进程完成。
  • 不需要另装 Python 或 PySide6，使用 Maya 自带的 Qt 绑定。
  • 与 AI 底座、MCP、无头批处理共用同一套命令与数据。

前提与边界

  • 需要 Maya 2022–2027 之一；更早版本（2021 及以前）没有对应的 .pyd，无法使用。
  • 安装或覆盖 .pyd 前建议关闭所有 Maya，避免文件被占用。
  • Maya 不运行时，插件版无法单独使用；此时改用独立版 / EXE 浏览资产。
