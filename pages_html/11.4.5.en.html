Connecting the plug-in's skills and MCP channel to external AI tools such as Claude Code, Codex or Trae requires both skill landing and MCP to be done.

Prerequisites

  • The target AI tool is installed; with a custom directory, its skill root is known.

Steps

  1. Open Settings → AI 设置 (AI settings) → 外部 AI 工具 (External AI tools) and click 「外部 AI 工具…」 (External AI tools…).
  2. Each row in the panel is one tool; read the two statuses first: whether the skills are in place and whether the MCP channel is mounted.
  3. When a tool is unrecognized or installed elsewhere, click 「选择路径…」 (Choose path…) to set the skill directory.
  4. Click 「安装技能」 (Install skills) to copy the squirrel-* skills into the other tool's directory; 「移除技能」 (Remove skills) undoes it.
  5. For tools supporting MCP check 「MCP 通道」 (MCP channel) to write into the other tool's configuration; for unsupported tools or unconfirmed paths click 「复制配置片段」 (Copy the configuration snippet) and paste it by hand.
  6. Click 「重新探测」 (Detect again) to refresh the status; the settings status line shows how many directories are selected and how many MCP clients are mounted.

Verify the result

  • The panel shows 「技能已就位（n 个）」 (skills in place, n) and 「MCP 通道：已挂上」 (MCP channel: mounted).
  • The other tool lists skills such as squirrel-assets and the squirrel_* tools.

Tips

Tip: with skills installed but MCP unmounted, the model knows an asset library exists yet cannot call the tools.

Warning: operations in the panel write into the other tool's directory immediately and are unrelated to the Settings window's Cancel; the original configuration is backed up before writing.

Tip: tools marked "to be verified" have paths not yet verified on this machine, so installing them may not take effect; the dsh desktop app needs a restart to read the new configuration.

Tip: for tools whose MCP format is not covered, use 「手工配置说明」 (Manual configuration instructions) to get the full paths and snippet.
