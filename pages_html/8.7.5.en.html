The status page answers four questions: what the library holds, how large it is, how long since it was rebuilt and whether semantic retrieval works right now; it also says which source to trust for which query.

The image is only a signpost: the status comes from having the assistant run maya_docs(action="status"); the menu has no separate knowledge base status item.

Prerequisites

maya_docs can be called in the AI assistant, or the same command can be run on the command surface.

Steps

  1. Have the assistant run maya_docs(action="status").
  2. Read the entry count and its distribution by type (command / node / api / devguide / doc), each file's size and the alias count.
  3. Read the rebuild time and sources under rebuilt to judge whether the knowledge base is stale.
  4. Read semantic: model, dimensions, count, availability and reason; for an end-to-end check add probe=true, which sends one real embedding request.
  5. To see which plug-ins are installed, run maya_docs(action="plugins"), optionally filtered by plug-in name.

Verify the result

It returns status=ok with entries, by_type, semantic and authority; with probe=true it adds the result of one real embedding call.

Tips and warnings

  • When the local library is missing it clearly states the current mode is online; do not assume local data exists.
  • authority states the authoritative source: live help for command parameters, details for node attributes and retrieval for body text.
  • When the knowledge base is stale or incomplete rebuild it with tools\rebuild_maya_doc_kb.py; avoid heavy Maya work while it builds.
