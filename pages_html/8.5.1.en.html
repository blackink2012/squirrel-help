With 「AI 搜索」 (AI search) checked, typing a Chinese description and pressing Enter makes the plug-in search assets with local vectors first and only ask a large model to parse the intent when needed.

Prerequisites

An asset library is open and a local embedding model plus asset index are available. No cloud key is needed, and large models are not called during queries by default.

Steps

  1. To limit the scope, select a category or sub-library on the left first.
  2. Check 「AI 搜索」 (AI search) in the search bar.
  3. Type a colloquial description such as "old wood weathered by sun and rain" and press Enter.
  4. Wait for results. Local semantic hits are shown directly; only when local search misses and a model is configured does it parse the intent and search by keywords.
  5. Click ✕ on the right of the search box to clear the search and restore the full list of the current category.

Verify the result

The status bar shows 「语义检索 N 条 · 本地嵌入 <model> · <ms> ms」 (semantic: N results · local embedding … · … ms) or the number of assets found with the keywords. The result grid stays isolated and never modifies the assets.

Tips and warnings

  • Freshly imported assets may not be searchable until they are indexed; opening the library or the next search syncs incrementally.
  • With a category selected the search only covers that category and never crosses libraries.
  • When local semantics are unavailable it falls back to the previous keyword and large-model flow without aborting with an error.
