Batch format conversion turns an asset's own geometry into other formats inside mayapy and appends the results to the asset package, keeping the original formats.

Supported formats

ExtensionName
maMaya ASCII
mbMaya Binary
fbxFBX
objWavefront OBJ
usdUSD
abcAlembic

Prerequisites

  • The asset has geometry of its own; assets without geometry, such as materials, textures and lights, are skipped with an explanation.
  • A mayapy of the same version as the current Maya exists locally.

Steps

  1. Select one or more assets and choose 「格式转换」 (Format conversion) from the context menu.
  2. In the dialog check the target formats to write into the package; an existing format is marked 「已存在」 (already present), and checking it replaces that format with this result.
  3. Click 「开始转换」 (Start conversion) and wait for the progress window to finish.

Verify the result

It returns per-item results plus success / failure / skipped counts; the asset directory gains the new format files and the original formats are not deleted. Everything converts in a temporary directory outside the library and is written back only after verification.

Tips and warnings

  • Assets without geometry cannot be converted; that is a design limit, not a failure.
  • Same-named assets can exist in different categories, and the job uses numbering internally so outputs never overwrite each other.
  • Cancelling or failing leaves the library unchanged, at most leaving one unadopted temporary output behind.
