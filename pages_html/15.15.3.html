一、反馈窗口

怎么打开

设置 →「关于」页 →「反馈与建议」组 →「发送反馈」按钮。

每个控件做什么

控件作用怎么填
「类型」下拉功能异常 / 崩溃 / 授权问题 / 建议 / 其他选最接近的，便于对方分流
「标题」输入框（占位「一句话说明问题（最多 120 字节）」）一句话说清问题写"做了什么 + 出了什么"，别只写"坏了"
「详细描述」多行框（占位「复现步骤、现象、期望结果（20–4096 字节）」）正文按"步骤 / 现象 / 期望"三段写，最有用的就是复现步骤
「联系方式（可选）」输入框（占位「邮箱 / QQ / 微信，可选」）对方要回访时用不填也能提交
「提交反馈」按钮提交提交成功后会禁用，防重复提交
「关闭」按钮关窗—
底部消息行三种结果：已提交，编号：xxx / 当前未联网，已保存到本机，联网后会重试 / 提交失败：原因记下编号，后续沟通用

一次完整的反馈流程

  1. 复现问题，把步骤和现象记下来（有截图 / 日志更好）；
  2. 设置 →「关于」页 →「发送反馈」；
  3. 选类型 → 写标题 → 写详细描述；
  4. 想被回访就填联系方式；
  5. 点「提交反馈」；
  6. 看消息行：
    • 提交成功 → 记下编号；
    • 断网 → 内容已存本机，联网后会自动重试（不用一直开着窗口）；
    • 失败 → 按提示的原因处理（比如服务地址不通）。

写一条有用反馈的要点

  • 必写：做了什么操作、看到什么、期望是什么；
  • 能附就附：日志位置见 6.8.1，反馈模板见 6.8.3；
  • 别写敏感信息：描述里不要贴密钥 / 授权码；联系方式可不填。

风险与反悔

  • 反馈会发到服务器，提交成功就没有"撤回"入口 —— 提交前先确认内容（尤其是联系方式）。
  • 断网排队的内容存在本机，下次有网时自动重试；不想发就趁联网前别提交。

二、其它提示弹窗（你还会遇到哪几种）

弹窗什么时候出现怎么应对
信息 / 警告 / 错误提示各种操作的即时反馈（如"Maya 未连接"、失败原因）读文字，按提示处理；错误里带错误码时记下来
确认框（是 / 否）危险操作前（删除、解除授权、批量转换、覆盖安装技能等）先读清楚它问的是什么再点是；点"否"就什么都不做
进度窗批量导出、AI 批量分析、无头作业、dsh 安装等耗时操作多数可取消；取消是"下一个检查点停下"，已完成的会保留
同名冲突窗导入 / 导出遇到同名资产时选项见 8.12.5
授权提示未授权 / 过期时用受限功能会引导打开授权窗口，见 8.15.2
AI 依赖缺失提示语义搜索 / AI 分析缺少依赖时会引导去「设置 → AI 设置 → 安装 AI 依赖」，见 8.9.3
