场景与动态资产走同一条几何导入管线；含动画的格式会带时间范围或帧序列设置进入场景。

前置条件

  • 当前 Maya 场景已保存，避免导入的相机、灯光与原场景混淆。
  • 场景资产包含 ma、mb、fbx、usd、abc 等格式，或 ass、rs 帧序列。

操作步骤

  1. 右键场景或动态资产，点「导入 ma」（只有一种格式时直接执行；有多种格式时才展开「导入 ▶」）。
  2. 选择要导入的格式。多格式资产会逐项列出格式名。
  3. 等待导入完成。
  4. 播放时间轴，检查动画是否随帧更新。

结果验证

  • Outliner 中出现场景中的模型、相机、灯光等节点。
  • 动态资产的时间轴范围内，模型随帧变化。
  • ass、rs 序列资产的代理节点已开启帧扩展（useFrameExtension）；usd 动画按覆盖时间范围导入。
  • 脚本编辑器出现导入成功日志。

相关：另外四类资产不在这条管线里

本页讲的是「场景 / 动态」这类几何资产。图片、音频、动画数据、节点树 是另外四类，入口与结果都不同：

资产右键入口详见
动画数据（ATOM 关键帧）「导入动画 ▶」/「导入动画（层级映射）…」/「导入到选择属性 ▶」8.5.11
节点树（节点网络）「导入 ma」8.5.12
音频（音乐）「导入到时间轴 / 时间编辑器 / Trax 编辑器 / 摄像机序列器」8.5.10
图片「导入为 file 节点 / 创建 imagePlane / 指定到选中材质槽 / 打开图像」8.5.9

其中动画数据与节点树常一起来用：节点树（或模型）提供场景里的层级，再把动画数据的关键帧贴到这些层级上。

提示

  • usd 动画导入使用 importTimeRange=override 与 readAnimData=1，工作范围以资产内记录为准。
  • abc、usd 会先复制到工程缓存再导入，避免引用资产包内的临时路径。
  • 场景资产会合并进当前场景而非新建文件；导入前先保存当前场景。
  • ass、rs 帧序列是否启用帧扩展，取决于资产 meta.json 的 ani 记录。
