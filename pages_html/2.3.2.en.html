There is no multi-step "Next" wizard. The first launch does three things: check the license, create a default asset library, and open the main window.

What happens

  1. License check: if the product is not activated or the license has expired, the 「授权管理」 (License Manager) window appears first and offers one activation attempt.
  2. Read-only fallback: clicking 「关闭」 (Close) in that window still continues; the main window opens in read-only mode and the library can still be browsed.
  3. Default library: when no library is configured, SquirrelLib is created in the user directory and set as the current library.
  4. Main window: shows the category tree on the left, the asset grid in the middle and the properties / preview area on the right; the title contains the version number.

Suggested first settings

  1. Open Settings → License activation and confirm the current state; if you have a key, enter it under the machine code, or click 「授权管理」 (License management) for offline import / deactivation.
  2. Open Settings → General → Asset library management and add an existing library or create a new one.
  3. Adjust interface language, theme and font size as needed.
  4. AI features are not installed automatically at startup; the dsh install prompt appears only when you click 「AI 助手」 (AI assistant).

Verify the result

  • The main window opens normally and is not stuck on a blank page.
  • Settings → License activation shows the state and the machine code.
  • The category tree has at least one library, and all 11 built-in sub-libraries are visible (materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees).

Common failures

  • Only the license window is visible: that is the normal flow; after closing it you can still browse read-only.
  • The main window is blank: the library path is invalid or has no assets; check the path and directory permissions first.
  • It keeps saying not activated: confirm the activation code or license file matches this machine's machine code, see "License troubleshooting".
  • No default library: it is not rebuilt automatically when the settings file is corrupt; restore from .bak or add a library manually.
