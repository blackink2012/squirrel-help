右键材质资产选择 .zmetal，插件会在场景中重建完整着色网络，并把贴图按导入策略落盘。

前置条件

  • Maya 场景已打开。
  • 材质资产包含 node.zmetal；快捷工具导出的资产不含节点网络数据。

操作步骤

  1. 右键材质资产。
  2. 只有 zmetal 一种格式时点「导入 zmetal」；有多种格式时展开「导入」后选择 zmetal。
  3. 资产含多种精度贴图时，在「选择贴图精度」对话框中选精度；点「取消」则放弃导入。
  4. 等待节点网络创建完成。

结果验证

  • Hypershade 中出现完整材质网络：shader、shadingGroup、file、place2dTexture 等。
  • 导入后自动选中新建材质；脚本编辑器输出「已创建 N 个节点」与「已选中新建材质」。
  • file 节点的 fileTextureName 指向本次精度对应的磁盘路径。

提示

  • 贴图按「设置 → 常规」的贴图导入策略处理：拷贝到工程、直接读资产目录或保持源路径。
  • 导入 zmetal 后，若当前渲染器与材质原类型不同，插件会不弹确认直接转换为当前渲染器默认材质；要指定目标类型，请用右键「转换导入」。
  • 日志提示「不含 .zmetal 文件（不含节点网络数据）」时，改用「应用材质到选中」或直接使用资产内的 ma/mb 材质网络。
