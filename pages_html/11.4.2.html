全局大模型是插件里所有需要大模型的功能默认使用的服务商与模型配置。

作用

在一个地方配置服务商、API Key、API 地址与模型名，供 AI 缩略图分析等功能复用。

可选值与默认值

  • 服务商：Ollama（本地，默认）、LM Studio（本地）、DeepSeek、通义千问（阿里云 DashScope）、智谱（BigModel）、Kimi（月之暗面）、OpenAI、Anthropic Claude、自定义（OpenAI 兼容）。
  • API Key：云端服务商必填；Ollama 等本地服务无需填写，输入框会置灰。
  • API 地址：留空时使用该服务商默认地址；自定义服务商需填写兼容端点。
  • 模型：下拉框实时拉取该服务商的模型列表，也可直接输入模型名；默认留空。
  • 思考模式：默认关闭。开启后模型先输出推理过程再回答，只建议复杂推理任务开启。
  • 各服务商的 Key 分别保存，切换服务商不会串用。

用其它厂商 / 自建接口

插件只对接 OpenAI 兼容协议（POST {地址}/chat/completions，模型列表走 GET {地址}/models）。不在下拉列表里的服务商，只要它提供 OpenAI 兼容端点，就选 自定义（OpenAI 兼容），把地址、Key、模型名填进去即可：

服务API 地址填什么
Google Geminihttps://generativelanguage.googleapis.com/v1beta/openai/
Anthropic Claude可直接选下拉里的 Anthropic Claude（地址 https://api.anthropic.com/v1/，官方 OpenAI SDK 兼容层）
OpenRouterhttps://openrouter.ai/api/v1
硅基流动 / 火山方舟 / 月之暗面 / 百川等各自控制台里的「OpenAI 兼容」地址
聚合网关（OneAPI / NewAPI）http://<你的网关>/v1
本地 LM Studio / vLLM / XinferenceLM Studio 可直接选下拉里的 LM Studio（本地）（默认 http://127.0.0.1:1234/v1）；其它本地服务填 http://127.0.0.1:<端口>/v1

注意：

  • 地址末尾不要重复写 /chat/completions，只填到 /v1 这一层；
  • 模型名拿不到列表时可以直接手输；
  • 本地服务若不要 Key，随便填一个占位值即可（自定义服务商的 Key 输入框是启用的）；
  • Azure OpenAI（api-key 认证头 + deployments/<部署名> 路径 + api-version 参数）与 Anthropic / Gemini 原生协议（/v1/messages、generateContent）不走 OpenAI 兼容格式，当前版本不直接支持 —— 优先选厂商提供的兼容端点，或经 OneAPI 之类的网关转成 OpenAI 兼容。

思考模式

默认关闭。思考（推理过程）与正文共用输出 token，打标签 / 分类 / 一句话描述这类任务开了只会更慢，预算不够时正文还会为空 —— 所以能关的一律默认关。

只有需要多步推理的场景（复杂描述、疑难判定）才建议勾选「开启思考模式」。

各服务商的实际效果：

服务商关闭时的做法
OllamaOpenAI 兼容端传 reasoning_effort: none（实测有效）；原生接口传 think: false
DeepSeek / 智谱（一般模型）传 thinking: disabled
智谱 glm-5.2 / glm-5.3始终思考、无法关闭 → 关思考时降到最低档
OpenAI o 系列 / GPT-5无法真正关闭 → 关思考时用 reasoning_effort: low
Kimi / Claude 兼容层 / 自定义 / LM Studio无通用开关，保持服务端默认

提示：开启思考后如果回答为空，通常是 max_tokens 被推理过程用完，与思考开关本身无关。

影响范围

  • AI 缩略图分析等需要大模型的功能默认读取这组配置。
  • AI 搜索只有在搜索配置里勾选「使用全局大模型」时才调用它；否则只做本地向量检索。
  • 语义搜索与以图搜图使用本地 Ollama 嵌入模型，不受这里的对话模型影响。
  • 配置保存在 app_settings.json 的 ai_provider、ai_api_keys、ai_base_url、ai_model。

何时修改

  • 已购买云端模型服务，想获得比本地更快的分析效果。
  • 使用中转或自建 OpenAI 兼容接口，选「自定义（OpenAI 兼容）」并填地址与模型。
  • 只想本地运行：保持 Ollama，先完成「AI 依赖检查与安装」。

提示

提示：云端服务商需要联网，分析用的缩略图与提示词会发送到该服务商；本地 Ollama 不出本机。

提示：API Key 以明文保存在 app_settings.json，注意不要外发该文件。
