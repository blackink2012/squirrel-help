Caches and proxies preset which cache and render-proxy formats are checked by default when exporting each asset type.

Effect

When a new export dialog or asset creation starts, Alembic, Arnold, V-Ray, Redshift and V-Ray proxy formats are pre-checked for the current asset type.

Values and defaults

  • Choose the asset type in the list on the left, shown as a sub-library ID.
  • The five options and their default asset types:
OptionAsset types where it is checked by default
Alembic (.abc)ani
Arnold (.ass)None
V-Ray (.vrscene)None
Redshift (.rs)None
V-Ray proxy (.vrmesh)None

Scope

  • It only decides the initial state of checkboxes in the export interface; a single export can still change them.
  • Proxy formats only make sense when the matching renderer (Arnold / V-Ray / Redshift) is available.
  • It never changes existing assets, the context menu or quick tools.
  • It is stored under the matching asset type key in Assets/preset/export_preset.json.

When to change it

  • Animation or FX assets need caches: keep .abc for ani.
  • Delivery to a render farm needs lightweight proxies: check the proxy formats matching the farm's renderer.
  • Only local Maya use: keep everything unchecked to shrink assets.

Tips

Tip: cache and proxy files are usually large, so confirm free disk space before exporting.

Tip: the list on the left holds asset types, not categories; all categories under one type share the same defaults.
