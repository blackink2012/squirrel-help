一句话定位：在资产网格里右键一张图片资产卡片时，弹出的就是这个菜单。 图片资产是「散文件图片」，进 Maya 有四条不同的路，菜单最上面四项就是这四条路。

怎么打开

  1. 左侧「分类」页签 → 点「图片」或它下面的任一分类；
  2. 中间资产网格里右键任意图片卡片。

菜单从上到下的顺序

段条目
① 子库专属导入为 file 节点、创建 imagePlane、指定到选中材质槽、打开图像
② 收藏与选择添加到收藏夹 ▶、全选、复制、打开文件夹
③ 整理移动到 ▶、复制到 ▶
④ 维护编辑、删除 ▶
⑤ 查看与 AIAI 分析缩略图
⑥ 最后一条资产详情

图片菜单是最短的一张：没有导入 / 添加引用 / 更新缩略图 / 更新资产 / 格式转换 / 预览节点。理由很直接——图片本身没有几何体，也没有缩略图之外的内容要更新。

菜单逐项详解

菜单项作用前提点了之后注意
导入为 file 节点用这张图建一个 file 纹理节点Maya 已连接场景里生成 file 节点（带 place2dTexture），图已指好只建节点，不自动接材质；要接材质用「指定到选中材质槽」
创建 imagePlane把这张图做成当前视图相机的 imagePlane有当前视图相机（模型面板）视图里多一层参考图（imagePlane 节点）做参考图用；不想看了隐藏 / 删除 imagePlane 即可
指定到选中材质槽把这张图接到选中材质的颜色槽场景里选中了材质节点选中材质的颜色属性上多一个 file 节点不建新材质；没选中材质就点会提示失败
打开图像用内置图像浏览器看这张图资产里有图片文件打开图像浏览器窗口；散文件图片会列出同目录的其它图片可切换窗口复用，不会堆出一屏窗口
添加到收藏夹 ▶把资产加入收藏夹资产库已加载子菜单列「默认收藏夹」+ 你自建的收藏夹；点一下加入、再点一下移出多选时对全部选中的资产生效
全选选中网格里当前可见的全部卡片有卡片全部高亮只选当前筛选 / 搜索结果
复制把资产放进剪贴板无内部剪贴板记录资产，同时把图片文件写进系统剪贴板直接在资源管理器里就能粘贴出来
打开文件夹打开资产在磁盘上的位置资产已入库文件管理器定位到该图片所在文件夹只打开，不改内容
移动到 ▶把资产移到别的分类资产库已加载级联选目标分类，资产从当前分类消失见 8.5.15
复制到 ▶把资产复制一份到别的分类资产库已加载目标分类多出同一资产占双份磁盘空间
编辑改中文名、分类、标签、注释无弹「编辑资产」对话框见 8.5.16
删除 ▶删掉这个资产无子菜单：移到回收站 / 彻底删除「彻底删除」不可还原
AI 分析缩略图让 AI 读缩略图给建议AI 依赖已装好打开 AI 分析窗口，确认后写回资产见 8.5.17
资产详情单独看这个资产的详情无打开资产观察窗口与双击右侧预览图同一条链路

四条路怎么选

你的目的点哪一项
要把这张图接到材质上做贴图指定到选中材质槽（已选材质）或创建材质（贴图子库的那套）
只想在场景里有一个图片纹理节点，自己接线导入为 file 节点
要一张能在视口里对位的参考图创建 imagePlane
只是想看图、确认是哪张打开图像

这个子库特有的注意点

  • 图片没有「更新缩略图」：图片的缩略图就是图片本身，换图要重新入库，不是换缩略图。
  • imagePlane 是挂在当前视图相机上的：换相机可能就看不到它了，这是 Maya 的行为，不是插件丢了。
  • 「指定到选中材质槽」只认颜色槽：它不做「按类型智能匹配」（那套是贴图子库的「指定贴图到材质」）。
