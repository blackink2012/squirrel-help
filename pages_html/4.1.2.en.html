A version is one complete iteration of an asset, and a LOD is a geometry detail level inside one version; both hang off the main asset, and the grid usually shows only the main asset.

Versions

  • The main .zasset can hold version directories such as V1 and V2, each self-contained with geometry, materials, textures and thumbnails; the main asset's meta.json registers them under version_assets.
  • Versions preserve revisitable results. In 「更新资产」 (Update asset) you can choose 「创建新版本」 (Create new version).
  • When a card shows a multi-version badge, double-clicking the preview image opens the 「版本浏览器」 (Version browser), where a version can be viewed, imported or deleted.

LODs

  • A LOD is a chain of geometry detail levels inside one version, indexed in lods.json in the version directory; LOD0 always points at the geometry in the version root, and further levels live in lod1, lod2 and so on.
  • LODs switch detail by purpose or distance, for example a high-poly display model and a low-poly proxy for placement.
  • A card showing an L badge means the asset has several LODs; the context menu item 「导入变体 / 版本」 (Import variant / version) (also labelled 「导入版本 / LOD」 (Import version / LOD)) lets you choose the version, level and variant to import.

Variants

  • A variant is one of several geometry forms of the same asset that share one set of textures and materials; the geometry sits flat under variants/ and thumbnails are stored separately.
  • Variants versus versions: a version is a complete self-contained asset with its own materials and textures, while a variant stores only geometry and inherits materials and textures from the asset root.
  • This fits cases such as "one material, many kinds of bricks and screws"; 「更新资产」 (Update asset) offers adding a new variant, batch-adding variants, updating variants and opening variant management.

When to use which

Use versions when something needs repeated edits without losing earlier results; use LODs when one asset must switch between detail levels; use variants when one set of textures needs several shapes. All three can coexist; see "Append a LOD", "Create a new version", "Switch version and LOD" and the "Variants" section.
