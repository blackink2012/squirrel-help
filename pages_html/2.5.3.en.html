Start with the license state and the error code, then work through machine code → network and time → license file → program integrity.

Order of checks

  1. Open Settings → License activation and confirm the status badge and the machine code display properly.
  2. Note the error code shown in the license window (in the form E_LIC_* / E_ACT_*).
  3. Check that the system time is correct and was not set back.
  4. If online activation fails, confirm the network can reach the activation server; otherwise use an offline license.
  5. Check that the license file is complete and belongs to this product and this machine.
  6. If it still fails, consider program file integrity and reinstall if necessary.

If it still does not work

  • Plug-in edition: in the Maya Script Editor, read the output beginning with [Licensing] and report it together with the error code.
  • Standalone edition / EXE: check the logs\ directory in the install directory and the startup output; the exact log file names are to be confirmed.
  • When reporting, include: the error code, the machine code, the product version (window title), the Windows version and the steps you tried.

Notes

  • Do not edit the license file or the machine code by hand; the signature check will fail.
  • Do not set the system clock back; it triggers E_LIC_CLOCK.
  • An offline license must match the target machine code; unbinding an online license is limited only by the server's daily cap (3 per 24 hours), not by a lifetime switch counter.
  • After an administrator deletes / revokes a license, clicking Sync license on the client switches it to read-only immediately: the server returns a signed denial and the client seals the local license after verifying it (this prevents an old license from coming back after a machine move).
  • Offline-issued licenses cannot be unbound by yourself; contact the licensor to reissue when moving machines.
