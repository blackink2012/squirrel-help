When this machine has no local knowledge base, or local retrieval finds nothing, the plug-in falls back to Autodesk's official help; that guarantees "you can look it up", but only page bodies, no command parameter tables.

Why it exists

Autodesk documentation may not be redistributed with the plug-in, so a local knowledge base can only be built on each machine. Users without one still need a way out, and the online fallback is that way.

How it works

The official help site exposes no public server-side search API, so the plug-in uses two stable public data sets instead: the site-wide table of contents and individual pages. Retrieval scores the table of contents by title and path, then fetches the matching page on demand and converts it to text.

Result fields match the local library, and source is written as online:<product>/<version>/<language> so it is obvious the data is not local.

Cache and network

  • The table of contents is cached for 7 days and pages for 30 days under ~\.squirrel_asset_manager\help_cache.
  • A single request times out after 30 seconds with up to 3 retries; offline, a cached answer is still returned and marked as cached.
  • It queries Maya's official help by default; developer help is English only.

The switch

Off by default: once enabled, query keywords are sent to Autodesk (an overseas server), so you must turn it on yourself and agree separately.

  • UI switch: Settings → AI → 本地文档没有时，在线查询 Maya 官方帮助 (query the official Maya help online when local docs are missing). The first check opens a separate consent dialog; unchecking it at any time turns it off without a restart.
  • Environment variables (they take precedence): MAYA_KB_ONLINE=1 (true / yes / on) forces it on; MAYA_KB_ONLINE=0 (false / off / no) forces it off. An explicitly set environment variable is never overridden by the UI switch.

With it off and no local library, the only answer is a missing-data notice.

Limits

Online results have no flag tables; use the live local help for command parameters. For stable offline lookups, build a knowledge base on this machine.
