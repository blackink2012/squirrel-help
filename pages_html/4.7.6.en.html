「默认缩略图大小」 (Default thumbnail size) is the long-edge pixel size shared by generated and captured thumbnails; the factory value is 512.

Where to set it

  1. Open Settings → 常规 (General).
  2. Find 「默认缩略图大小」 (Default thumbnail size) in the 「缩略图」 (Thumbnails) group.
  3. Pick one of 256, 384, 512, 768 or 1024.
  4. Save the settings. The new value applies to thumbnails generated or captured afterwards.

Where it applies

ScenarioHow the size is used
Background renderAs the output edge length; also changeable in the background render dialog
Maya playblast, renderEdge length of the output image
Quick capture from the preview panelThe screenshot is scaled proportionally by its long edge to this value
Full screenshot toolAs the initial width and height, adjustable temporarily in the toolbar
HDR / model / PBR to assetUsed when quick tools produce thumbnails
Export assetUsed when the export flow produces thumbnails

Verify the result

  • Generated thumbnails are output at the chosen edge length; captured ones scale proportionally by the long edge, so the short edge follows the picture ratio and may not be square.
  • A larger preview looks sharper, and the file size grows accordingly.
  • Old thumbnails are not redone automatically; only regenerating or recapturing uses the new size.
注意

Changing the size in the background render dialog also writes it back to Settings → 常规 → 默认缩略图大小 (General → Default thumbnail size); both entries share one value.

提示

This size is the size of the thumbnail file itself, not how large cards appear in the grid; adjust card size with the toolbar slider.
