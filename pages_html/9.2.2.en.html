Group the model files in a folder by asset and package each one into a .zasset; files with the same name but different formats merge into one asset.

Purpose

Turn .ma, .mb, .fbx, .obj, USD, Alembic and similar models, together with their textures and proxy caches, into uniform assets that are easy to add to the library and import later.

The menu shows the script name: the quick tools menu scans the scripts in quicktools/ directly, and an entry name is the file name without .py with underscores replaced by spaces, so the menu shows model to zasset rather than a Chinese title. The three conversion tools map as follows: hdr to zasset = HDR to asset, model to zasset = model to asset, pbr to zasset = PBR texture to asset.

Supported formats

.ma, .mb, .usd, .usda, .usdc, .abc, .fbx, .obj, .ass.

Default priority: ma > mb > usd > usda > usdc > abc > fbx > obj > ass. The asset name comes from the file name without extension, and source file names are left untouched.

Input and output

  • Input: a model folder. Files with the same name in several formats count as one asset, with all formats packaged into the same .zasset.
  • Output: one <asset name>.zasset per asset. When 「输出位置」 (Output location) is empty the current library category directory is preferred, and a directory picker appears if it cannot be resolved.
  • Inside the asset: the model files, meta.json, an optional thumb.sicon, and sub-directories such as textures/ and ass/; texture references are written into texture_map.

Steps

  1. Open 快捷工具 (Quick tools) → model to zasset.
  2. Click 「浏览...」 (Browse...) and choose the 「模型文件夹」 (Model folder).
  3. Set 「目标格式」 (Target formats) as needed (comma separated; empty packages every format found).
  4. Adjust the conversion options and click 「扫描模型」 (Scan models) to check asset counts and formats.
  5. Set the output location (may be empty) and click 「转换」 (Convert).

Verify the result

  • After scanning, the right side shows 「发现 N 个模型资产」 (found N model assets) with each asset's formats and size.
  • When conversion finishes the status bar shows 「转换完成！成功: x, 失败: y」 (conversion finished! succeeded: x, failed: y).
  • Inside the .zasset you can see the model files, meta.json and, when a thumbnail exists, thumb.sicon.

Options and notes

OptionDefaultNotes
Include sub-foldersOnPackages the contents of ass/, textures/, sourceimages/ and similar
Search sub-folders recursivelyOffScans deeper directories for model files
Include dependencies (textures, materials and so on)OnParses texture references from .ma and collects same-named .mtl / .mcm / .zmetal
Use existing metadata and thumbnailsOnReads thumbnail paths and JSON/TXT metadata sources from the configuration
Import into the current category after conversionOffCopies the asset into the current library category afterwards
  • Configuration comes from Assets/preset/model_mapping.json, with expression overrides in Assets/preset/model_expression.json; file routing, metadata sources and thumbnail search paths are editable in the interface.
  • Metadata field mapping follows the configuration: none keeps the value, split_comma splits on commas into an array and first_line takes the first line; a wrong handler means no metadata is read.
