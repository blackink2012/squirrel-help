Any area can be switched to another panel: navigation, assets, properties, preview, AI assistant, AI search preview or script browser.

Steps

  1. Click the function button on the right of the target area's header to open the three-column horizontal menu.
  2. Click the type you want under 「面板类型」 (Panel type) in the left column; the current type is marked with a blue highlight frame (there is no check mark).
  3. The area switches immediately; the previous panel's content goes to a backup area and is not deleted.
  4. For more areas, split an area in its menu first and then choose a type for the new area.

The seven panel types

TypePurpose
NavigationThe Categories / Projects / Favorites tabs
AssetsThe view-control row and the asset grid / list
PropertiesMetadata of the current asset
PreviewThumbnail viewing and thumbnail operations
AI assistantToggle for the dsh chat surface
AI search previewChat-style natural-language search
Script browserBrowse, search and run scripts

Multiple instances

The same type can appear in several areas at once: each area holds an independent instance and they do not take over from each other. Two 「资产」 (Assets) areas, for example, can sit on two different categories.

Verify the result

  • After switching, the area content changes and the header title and icon follow.
  • Switching back to the previous type keeps that panel's state (for example, navigation still on the original category).

Tips

  • Panel type names are written into the layout configuration, so the layout is saved automatically after switching.
  • If a panel is missing, use 「面板与布局 → 新建面板」 (Panels and layout → New panel) to open a new floating panel of that type.
  • AI search preview and script browser can also be opened as separate windows from the menu, and both can exist at the same time.
