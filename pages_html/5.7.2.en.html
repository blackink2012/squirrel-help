Black textures or missing proxies and caches usually mean the path the import policy points at no longer exists, or the asset package never collected its dependencies.

Symptoms

  • The material exists but the file node's texture path does not, so the viewport shows black or the default color.
  • Proxy nodes for abc, vdb, ass and vrmesh report a missing file.
  • Missing entries appear in the File Path Editor.
  • The log reports texture copy or dependency redirection failures.

Common causes

CauseTypical situation
The texture policy is 「源文件目录」 (source file directory) and the source files were moved or deletedAfter moving machines or reorganizing a disk
The texture or dependency policy is 「当前资产目录」 (current asset directory) and the .zasset was movedThe library was moved by hand
Linked files were not collected on export, so deps/ is emptyOnly geometry was exported
texture_map in meta.json does not match the actual file namesAn older asset, or files edited by hand
Caches were not copied into the project directoryFormats such as abc, vrmesh and vrscene referencing temporary paths
An image asset's file was moved out of its category directoryLibrary folders were reorganized by hand while the file node still points at the old path
The audio codec is not accepted by Maya, or WAV conversion failedA damaged source file, or an mp3 / flac transcode failure

Steps

  1. Use the File Path Editor to confirm the missing files' old and new paths.
  2. Open Settings → 常规 (General), change the texture and dependency policy to 「拷贝到项目」 (copy into the project) and import again.
  3. Check whether .zasset/deps/ contains the matching caches, proxies and references; when empty, export again with linked-file collection checked.
  4. Re-import the asset and confirm the file and proxy nodes point at the new paths.

Verify the result

  • The File Path Editor no longer lists missing entries.
  • Textures display correctly in the viewport and proxy nodes load their models.
  • The Script Editor no longer reports copy or path redirection failures.

If it still fails

  • Point the texture directly at a file inside the asset package to confirm the file itself is readable.
  • Use 「应用材质到选中」 (Apply material to selection) to rebuild the material network and rule out stale paths from an old material.
  • When an image's file node lost its path, re-import that image into the library, or point fileTextureName back at the image file in the category directory; when audio to WAV fails, convert the source to a standard wav first and then add it to the library.
