Scene and dynamics assets use the same geometry import pipeline; formats that contain animation come in with a time range or frame sequence setting.

Prerequisites

  • The current Maya scene is saved, so imported cameras and lights do not get confused with the existing scene.
  • The scene asset contains ma, mb, fbx, usd, abc or similar, or an ass / rs frame sequence.

Steps

  1. Right-click the scene or dynamics asset and click 「导入 ma」 (Import ma) (it runs directly with a single format; with several formats expand 「导入 ▶」 (Import ▶)).
  2. Choose the format to import; multi-format assets list each format name.
  3. Wait for the import to finish.
  4. Play the timeline and check that the animation updates with the frames.

Verify the result

  • Nodes for the scene's models, cameras and lights appear in the Outliner.
  • Within the dynamics asset's time range the model changes with the frames.
  • Proxy nodes of ass / rs sequence assets have frame extension enabled (useFrameExtension); USD animation is imported over the overridden time range.
  • The Script Editor shows the import success log.

Related: four other asset types are not on this pipeline

Animation data and node trees are often used together: the node tree (or a model) provides the hierarchy in the scene, and then the animation data's keyframes are applied to that hierarchy.

Tips

  • USD animation import uses importTimeRange=override and readAnimData=1, and the working range follows what the asset records.
  • abc and usd are first copied into the project cache and then imported, avoiding temporary paths inside the asset package.
  • A scene asset is merged into the current scene rather than opened as a new file; save the current scene before importing.
  • Whether an ass / rs frame sequence enables frame extension depends on the ani record in the asset's meta.json.
