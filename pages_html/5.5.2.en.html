.mcm records the original model's vertex, face and edge counts plus the material assignments; on import those 3D signatures decide which material goes to the selected objects.

Prerequisites

  • One or more meshes to receive the material are selected in Maya.
  • The asset contains .mcm; having .zmetal as well is recommended, otherwise it falls back to the material network in .ma/.mb.
  • The imported model's topology matches the export: no triangulation, point merging or added / removed faces.

Steps

  1. Select the target model in the scene.
  2. Right-click the mcm asset, expand 「导入」 (Import) and choose mcm.
  3. The plug-in imports the material network first: .zmetal gives the node network, and with only .ma/.mb the materials are extracted from it while the imported geometry is deleted.
  4. The plug-in counts the selected object's vertices, faces and edges and compares them item by item with match_info in the .mcm.
  5. Objects that match receive the material; when the .mcm records per-face assignments they are applied per face as well.

Verify the result

  • The selected object shows the connected material in its Hypershade material attributes.
  • The Script Editor reports [MCMImport] MCM 匹配: N/M.
  • With per-face materials different faces of the model show different materials.

Tips

  • With nothing selected it reports 「请先选择要赋予材质的物体」 (select the objects to receive the material first); when none of the selected objects is a mesh it reports 「选中物体均无 mesh 数据」 (the selected objects contain no mesh data).
  • Objects that fail to match log 「选择物中无匹配 …，跳过」 (no match among the selected objects for …, skipping) and never receive the wrong material.
  • Topology must match exactly; a model whose vertices, edges or faces changed after export cannot match.
  • When mcm is missing from the context menu's import list, the asset's meta.json has no such entry under formats; scanning files never infers mcm.
