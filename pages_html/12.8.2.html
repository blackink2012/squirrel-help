错误原文就是最准的线索：先按原文对照本页，再按「处理」一列查日志或诊断命令。

命令与作业

错误原文含义处理
未知命令: <id>命令 id 不在注册表里，或拼写错误用 squirrel_list_commands / GET /commands 核对 id
命令未绑定执行器: <id>命令已登记但当前宿主没有实现确认宿主是 Maya 还是 Blender，命令集合不通用
实例 <id> 未在 N 秒内回传结果同步调用超时；命令可能仍在 Maya 主线程执行先查 GET /late_results，不要盲目重跑破坏性命令
作业队列已满（排队 n / 上限 32）背压，排队数已达上限先查 /jobs，等运行中的作业结束再提交
没有这个作业：<job_id>作业 id 不存在或已过期淘汰用 GET /jobs 重新确认
结果超过 262144 字节，返回 truncated: true返回体被截断加 limit、指定字段或分批查询

连接与安装

错误原文含义处理
连接 Maya commandPort 失败 (127.0.0.1:7001)：[WinError 10061]目标端口没有 Maya 在应答运行 python maya_bridge.py --scan / --doctor；确认端口与版本
当前运行在 Maya 内部，无需经 socket 连接自身在 Maya 里调用了桥接客户端直接 import maya.cmds，不要在 Maya 内连自己的 commandPort
底座进程未能在 Ns 内就绪broker 启动失败看 dsh_home/broker_daemon.log，再查端口占用
找不到底座脚本插件安装不完整重新安装或检查 ai_broker_daemon.py 是否存在
实例 <id> 没有命令 <cmd>把 Maya 命令发给了 Blender 实例，或实例在跑旧代码用 /instances 确认宿主与实例，重启插件刷新清单
该 request_id 当前不在飞取消请求找不到对应命令，可能已结束查作业或命令结果，不要重复取消

资产与配置

错误原文含义处理
有 N 个资产建在了盘上但没能注册进库索引导入结束但索引没写入重扫库；这类资产暂时搜不到，也无法用 undo_last 撤回
加载设置失败app_settings.json 损坏插件会生成 .bak 并回退默认值，修复后再改设置
命令内部报错（详见 result）命令返回了内层 status="error"展开 result.error 看原始原因

提示：完整路径与日志对照见「日志位置」；需要一次跑完体检时用「诊断命令」。
