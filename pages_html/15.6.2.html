一句话定位：在属性区的任意字段上按右键，会弹出「复制 / 复制 ID / 编辑」菜单；点「编辑」才进入可改状态。

先纠正一个常见误会：现在双击字段不会进入编辑（旧版本会，容易在只想看一眼时误改，已经取消）。双击只有一种用法 —— 双击某个标签胶囊，直接进入标签编辑。字段本身的编辑入口是右键，或标题栏的铅笔按钮（见 8.6.3）。

怎么打开

  1. 在资产网格里选中一个资产；
  2. 把鼠标放到右侧属性区的任意一行上（字段名、字段值、甚至空白处都行）；
  3. 按鼠标右键，弹出菜单。

回收站条目也能弹这个菜单，但「编辑」是灰的（只读）。

菜单逐项详解

菜单项作用前提点了之后注意
复制把该字段的文字放进剪贴板字段有文字已选中的部分文字被复制；没选中则整段值被复制只读字段（资产名 / 分类 / 格式 / 大小 / 分辨率 / 音频 / 创建时间）也走这个菜单，所以复制一定在这里
复制 ID复制资产的唯一 ID（meta 里的 id）该资产有 ID剪贴板里是一串 IDID 不在属性区显示，按 ID 搜索 / 对外沟通只能从这里拿
编辑进入编辑态，并定位到这一行对应的字段不是回收站只读条目属性区切换成编辑卡片，光标落在对应输入框里在只读字段上点「编辑」只会进入编辑态，不会定位到那一行（那行本来就不能改）

菜单里各项会自动置灰：字段没文字时「复制」灰；资产没 ID 时「复制 ID」灰；只读条目「编辑」灰。

点「编辑」之后：编辑态里能改什么

编辑态字段控件能改吗说明
名称单行输入框能就是卡片上显示的名字（易读名）
材质类型单行输入框能对应显示态的「节点类型」，纯文本
资产类型下拉框不能（灰）由资产所在子库决定
分类下拉框不能（灰）换分类用右键「移动到」
软件单行输入框能记录信息
渲染器单行输入框能记录信息
色彩空间可输入的下拉框能预设：sRGB / Raw / ACEScg / Linear sRGB / Utility - Raw / Output - sRGB，也可以直接打字
标签标签胶囊 +「+ 添加标签」能点「+ 添加标签」弹窗：输入新标签回车加入、点常用标签快速加入、点胶囊上的 ✖ 移除（见 4.1.6.1）
注释多行输入框能输入框有最大高度，写长注释时内部滚动

编辑态里还有两条约定：

  • 滚轮停在「资产类型 / 分类 / 色彩空间」三个下拉框上不会改值（防误改）；
  • 编辑时点一下资产卡片区（中间网格），会自动应用本次修改并退出编辑态。

保存与取消

操作结果反悔可能
标题栏 ✓（保存）把改动写回资产元数据并刷新面板与卡片保存后没有撤销栈，Ctrl+Z 撤不回；只能再编辑改回原值
标题栏 ×（取消）丢弃本次全部改动，恢复进入编辑前的快照完全还原，可以放心点
点卡片区（自动应用）等同「保存」同第一行
警告

属性编辑改的是资产元数据（.zasset 里的 meta），删掉 / 覆盖资产才会丢；但保存之后插件没有提供「撤销这次属性修改」，改错了只能手动改回去。一次要改多个字段时，先想好再点保存。

一次典型操作：给资产补注释和标签

  1. 选中资产 → 右键「注释」那一行 →「编辑」；
  2. 在注释框里输入说明；点「+ 添加标签」，输入或用常用标签快速加入；
  3. 确认无误点标题栏 ✓（或点一下资产卡片区）；
  4. 面板回到显示态，注释与标签立刻可见；状态栏右侧显示的还是这个资产的名称。
