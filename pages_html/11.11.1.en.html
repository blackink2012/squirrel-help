Plug-in configuration lives in two places: presets inside the package and the user directory. Backing up means copying these JSON files; migrating means putting them back in the right place.

Prerequisites

Close Maya first, or at least close the settings window, so you do not copy a half-written file.

Configuration files

FileLocationContent
config.json<plugin package>/Assets/preset/Sub-libraries, default categories, supported formats, extensions, material node types, import strategy and more
context_menu_preset.jsonSameChecked state of the context menu per sub-library
double_click_preset.jsonSameDouble-click commands and sub-options
export_preset.jsonSameDefault export format
pbr_mapping.jsonSameTexture type aliases and PBR mapping
app_settings.json~/.squirrel_asset_manager/Personal settings: font size, theme, language, library list, hidden categories, AI configuration and keys

Steps

  1. Close Maya.
  2. Copy the six files above into a backup folder.
  3. On the new machine, put them back at the same relative locations: preset files into the plug-in package's Assets/preset/, and app_settings.json into the current user's ~/.squirrel_asset_manager/.
  4. Start Maya and the plug-in, then check each settings page.

Verify the result

Each settings page shows the same values as before the backup, and the asset library list opens normally.

Tips

  • Preset files live inside the EXE installation directory, and an overwrite install replaces them with the presets from the new package (your edits under Assets/preset/ are lost), so back them up before upgrading. ~/.squirrel_asset_manager/app_settings.json is outside the install directory and is not affected by an overwrite install.
  • Library paths in app_settings.json are absolute; after moving to another machine you may need to reselect them in settings.
  • These files contain sensitive data such as AI API keys, so keep backups and transfers private.
  • The asset library itself is not in these files; see Backup and restore for how to back it up.
