Block titles follow the category: materials shows "Material formats", lights shows "Light formats", and models / scenes / node tree show "Node formats". Light assets do not show the material mapping (.mcm) row beyond "material only".

Three rules to remember first

  1. No usable format ticked = hollow asset. Near the end of the export the plug-in checks whether any file was produced for the expected formats and aborts with an error; but if you untick every format it still produces a shell with only meta and a thumbnail, so tick at least one.
  2. A grayed format is not broken, it is unsupported by the current category. Hovering says "this format does not apply to the current category and is locked (adjust in Settings → Export defaults)". Locking rules: materials / lights lock geometry and proxy formats (they have no geometry anyway), while textures / HDR / images / audio / animation data lock nearly everything.
  3. The small text after a format is plug-in status: "Ready" = can export; "Not loaded" = installed but not loaded, which may auto-load during export or may fail; "Unavailable" = plug-in missing, and the checkbox turns gray. The status text is not a format description.

How to read the plug-in status after a format

StatusMeaningWhat happens
Ready (green)The plug-in that format needs is loaded, or it is built into Maya (.ma/.mb)Exports normally
Not loaded (yellow)The plug-in is installed but not loaded (such as fbxmaya, mtoa, vrayformaya)Most cases auto-load during export; if it still fails, check the Script Editor
Unavailable (red)The matching plug-in is not installedThe checkbox is disabled and never enters the export configuration

The notice in append-format mode

When you come in through Update asset → Append format, a yellow notice appears at the top of the right column: "Append format: no format is ticked by default; tick the formats to write this time; ticking an existing format (marked 'exists') replaces it with this export, while unticked formats stay as they are." In this mode all formats start unticked, unlike a normal create asset (which follows the export preset).
