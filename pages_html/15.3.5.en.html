One-line summary: the Project tab manages the asset library that belongs only to the current Maya project — it lives in the project's SquirrelLib folder, so switching projects switches libraries.

How to open it

Left navigation → click the Project tab. The plug-in tries to load the project library automatically; when the project has none yet it shows "Project library not created".

Where the project library lives

  • Path = the workspace root of the current Maya project + SquirrelLib.
  • In Maya you can query the project directory with cmds.workspace(q=True, rootDirectory=True).
  • The standalone edition (with no Maya running) reads its own current working directory — so the project library location there may differ from inside Maya; trust the path shown in the status hint.

When to use the Project tab

ScenarioWhich tab
A set of assets reused across projectsThe Category tab (main asset library)
Assets for this project only, packaged / delivered with itThe Project tab (project library)
Picking frequently used assets out separatelyThe Favorites tab, see 8.3.6

The difference between the main library and the project library, and how favorites relate to them, is covered in 4.1.1.3.

Beginner pitfalls

  • Switching here only shows "Project library not created": that is the normal state (a new project has none by default); click Create.
  • Assets imported on the Project tab cannot be found on the Category tab: they are not lost, they are in the project library; switch back to the Project tab to see them.
  • Assets deleted on the Project tab are missing from the main recycle bin: the two recycle bins are separate; look in the one at the bottom left of the Project tab.
  • The project library is "empty" after switching projects: the project library follows the project directory, so switching projects switches libraries rather than losing data.
