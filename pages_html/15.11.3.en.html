One-line summary: all variants of one asset in a single table, where you can import them one by one, bulk-add from disk, or delete them.

How to open it

  1. Find an asset that has variants in the grid (its card carries a variant badge); this only works for .zasset assets.
  2. Right-click → Update asset ▶ → Variant management….
  3. The Variant management window opens with "Asset: <asset name>" on the line below the title.

Creating variants is not done here: use right-click Update asset → Add as new variant / Batch add variants (see 8.11.4).

A complete example

Bulk-add variants from files

  1. Right-click the asset → Update asset ▶ → Variant management….
  2. Click Add from files… and multi-select model files in the chooser (its title reads "one file = one variant").
  3. After confirming, a Add variants from files progress bar runs, importing one by one with unique variant ids.
  4. When done it reports "Added N variants from files, M failed."
  5. The list refreshes; after closing the window the variant badge count in the grid follows.

Import / delete

  1. Select a row (or Ctrl/Shift multi-select).
  2. Click Import selected variant → the variant geometry enters the current scene; animation-type assets go through animation mapping import rather than geometry import.
  3. Or click Delete selected variants → the confirmation states "only that variant's geometry directory is deleted; the asset's shared textures and materials are unaffected" → confirm.
  4. The list refreshes and the grid follows.

Risks and how to undo

OperationRiskUndo
Delete variantsThat variant's geometry and thumbnail are deleted; shared textures and materials are unaffectedNo undo. To recover, add it again with Add as new variant or Add from files
Add from filesOne file per variant; duplicate names get a new id and never overwrite an existing variantDelete the row you added by mistake
Import variantNo namespace merge with existing scene objects, so names may clashThis is a scene operation; clean up with Maya's Ctrl+Z / undo

Troubleshooting

SymptomCauseWhat to do
No Variant management… in the context menuThe asset is not a .zasset, or Update asset is switched off in the current category's context menuConfirm the asset type; check Settings → Context menu
The list is emptyThe asset has no variants yetUse right-click Add as new variant… to export from the current selection
Nothing appears in the scene after importThe variant geometry file is missing, or the variant is animation dataCheck the Script Editor ([VariantImport] prefix); animated variants go through animation import
Add from files failsThe format is not in the allowed list, or a file is corruptUse ma/mb/fbx/obj/usd/glb/gltf and confirm the file opens in Maya first
