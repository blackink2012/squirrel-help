一句话定位：工具栏中间那个胶囊形输入框就是搜索栏 —— 打字是关键词搜索，配合左侧的上传 / 截屏 / 录屏按钮就是「拿图、拿视频、拿声音去找相似资产」。

怎么打开

不需要打开，它一直在工具栏中间。用法是：

  1. 点进输入框直接打字，按回车搜索；
  2. 或者点输入框左侧内嵌的图标按钮（上传 ▾ / 截屏 / 录屏）走媒体搜索；
  3. 「AI 搜索」勾选框在输入框右侧，默认已勾选。

逐项详解

控件作用前提点了之后注意
搜索输入框按名称 / 标签 / ID 搜索；勾了 AI 搜索就按自然语言理解无回车后网格只留下匹配的资产框里有内容时右侧会出现 ✕，点它取消搜索
上传搜索（▾）选本地图片 / 视频 / 音频，按该格式找相似资产已勾选「AI 搜索」弹出格式子菜单（见下）；选完再弹文件选择框按钮会根据你选的文件类型自动走对应搜索（图 / 视频 / 声音）
截屏搜索框选屏幕画面，按图找相似资产已勾选「AI 搜索」进入框选状态，框完自动开始相似搜索适合找「和这个参考图很像」的材质 / 贴图
录屏搜索框选画面并录制，按画面找相似动画已勾选「AI 搜索」；当前不在「音乐」分类进入录屏框选，录完自动搜索只在画面类分类出现
录音搜索录制当前电脑正在播放的声音，按声音找相似音频已勾选「AI 搜索」；当前在「音乐」分类开始录音，再点一次（或到上限）停止并搜索录的是系统声音，不是麦克风；麦克风只有被系统播放出来才会录进去
「AI 搜索」勾选框切换普通关键词搜索 / AI 语义搜索无立即改变输入框的占位提示，并显示 / 收起左侧的媒体搜索按钮默认开启；你的选择会被记住，下次打开还是上次的状态
清空 ✕取消这次搜索，恢复当前分类的全部资产框里有文字、或正在做媒体搜索网格恢复完整列表媒体搜索（图搜图 / 录音 / 录屏）不会往框里写关键词，所以 ✕ 的语义是「取消这次媒体搜索」
查询缩略图显示当前用来搜索的图片 / 媒体正在做媒体搜索点缩略图即取消这次搜索来自拖入的图片 / 资产卡片时同样会出现

输入框里的提示文案会变

占位提示不是固定的，它反映「现在按回车会发生什么」：

当前状态提示大意
勾选 AI 搜索（默认）用一句话描述要找的资产，按回车 AI 搜索
取消 AI 搜索搜索名称、标签、ID...
在「音乐」分类用一句话描述要找的声音 / 音乐
在「动画数据」分类用一句话描述要找的动画（画面 / 内容）
已经出过媒体搜索结果显示为「搜索结果隔离显示，点 ✕ 取消」的提示

还能直接把文件拖进来

把图片 / 视频 / 音频文件直接拖到搜索框上，会按文件的实际格式自动选择图搜图 / 视频搜索 / 音频搜索，不需要先点按钮。也可以把资产卡片拖进搜索框，用这张卡片作为「相似参考」。

小白易错点

  • 输入框左边没有图标按钮：说明「AI 搜索」没勾选。媒体搜索依赖 AI 能力，勾上就会出现。
  • 按图搜不到东西：先确认 AI 依赖已安装（设置 → AI 页有「AI 依赖检查」与「一键安装」，见 8.9.3）；依赖缺了会直接提示。
  • 搜完看不到别的资产了：搜索结果会隔离显示（只留匹配项），这是有意的。点输入框右侧 ✕ 或在清空筛选后即可恢复，详见 4.1.5.5。
  • 搜索框被压缩得只剩几个字：窗口太窄或多选资产后批量操作栏占位；把窗口拉宽即可，搜索栏会优先恢复。
