One-line summary: the category tree is the asset library's "file manager" — nodes come in several types, and clicking one only filters the central assets without changing them.

How to open it

Left navigation → Category tab → the tree in the body. It is always shown and needs no opening; when the library dropdown changes libraries, the tree switches to that library's categories.

The (N) after a node name is the number of assets it contains; no number means zero. Icon colors differ per sub-library so materials (pink), models (blue) and the rest are recognizable at a glance.

What single-click, double-click and the arrow do

ActionEffect
Single-click the node nameSelects and filters: the grid shows only assets in that node and all its sub-categories
Single-click the arrow in front of a nodeOnly expands / collapses that level without changing the current filter
Double-click the node name (when it has children)Expands / collapses that level (the special case is All assets: it expands or collapses every sub-library)
Ctrl + clickAdds / removes categories; the grid shows the union of several categories
Shift + clickSelects a contiguous range of categories
Double-click All assetsExpands / collapses all sub-libraries together and also switches to the All assets view

Rules to keep in mind

  • Clicking a category never changes assets: a category is only a filter view and an asset's home is decided by its folder. To move an asset between categories use Move to, see 8.5.15.
  • Multi-select shows a union: with Materials + Models selected the grid shows both; to return to one category, single-click a node normally.
  • The Scripts node cannot be multi-selected with asset categories: it is an entry for a whole different view (it switches the main area away), so Ctrl-clicking it keeps only itself.
  • Some sub-libraries are missing: the top-level category may be hidden in settings, see 4.1.2.4.

Beginner pitfalls

  • The asset count did not change after clicking a category: that category may have no assets of its own and the count shows those in sub-categories; try another node.
  • Double-click did not expand but changed the filter: the double-click window is fairly wide (about 800 ms), so two slow clicks count as two single clicks; the arrow in front is the safest.
  • The tree is blank / only shows "All assets": the library is still loading or its path is invalid; check that the dropdown points at a valid library, see 8.3.2.
