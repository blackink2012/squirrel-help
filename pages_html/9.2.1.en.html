Package .hdr / .exr environment textures into .zasset files one per file, optionally generating tone-mapped thumbnails as well.

Purpose

Turn scattered environment textures into assets the library can recognize and preview, either one file at a time or a whole folder.

The menu shows the script name: the quick tools menu scans the scripts in quicktools/ directly, and an entry name is the file name without .py with underscores replaced by spaces, so the menu shows hdr to zasset rather than a Chinese title. The three conversion tools map as follows: hdr to zasset = HDR to asset, model to zasset = model to asset, pbr to zasset = PBR texture to asset.

Input and output

  • Input: one or more .hdr / .exr files, or a folder (recursive, filterable by format).
  • Output: one <file name>.zasset per source file, written to 「输出位置」 (Output location); in folder mode with 「保持层级结构」 (Keep hierarchy) checked it follows the source directory structure.
  • Inside the asset: meta.json and textures/<original file name>, plus thumb.sicon when a thumbnail is generated. meta.json records asset_type: hdr, node_type: environmentMap, the resolution and tags (hdr, environment, the extension).

Steps

  1. Open 快捷工具 (Quick tools) → hdr to zasset.
  2. Choose 「选择文件」 (Choose files) or 「选择文件夹」 (Choose folder) and click 「浏览...」 (Browse...) to set the input.
  3. In folder mode click 「扫描HDR文件」 (Scan HDR files); with 「递归扫描子文件夹」 (Scan sub-folders recursively) checked it searches recursively.
  4. Set 「输出位置」 (Output location); empty means the directory of the input files.
  5. Adjust the options under 「转换选项」 (Conversion options) as needed.
  6. Click 「转换」 (Convert) and wait for the progress to finish.

Verify the result

  • The status bar shows 「完成: x 成功, y 失败」 (finished: x succeeded, y failed) and a 「转换完成」 (conversion finished) dialog appears.
  • The matching .zasset files appear in the output directory.
  • After refreshing the library the assets show thumbnails and resolution information.

Options and notes

OptionDefaultNotes
Generate thumbnail previewOnGenerates a tone-mapped PNG thumbnail from the HDR/EXR
Prefer an existing thumbnailOnSearches for a same-named PNG/JPG next to the source file, with the search formats png, jpg by default
Scan sub-folders recursivelyOnFolder mode only; when off only the current directory is scanned
Keep hierarchyOnFolder mode only; when off all assets go into one directory
Import into the current category after conversionOffCopies the .zasset into the current library category afterwards (without the directory structure)
Format filterEmptyEmpty converts .hdr and .exr; may be set to hdr or exr
  • Thumbnails need cv2 / numpy and Pillow, and imageio improves EXR compatibility; when dependencies are missing it asks whether to skip thumbnails and keep converting.
  • The thumbnail edge length follows 「默认缩略图大小」 (Default thumbnail size) in settings (512 by default) and only shrinks, never enlarges.
  • Conversion needs a valid convert license.
  • Older help recorded that Chinese file names could break conversion and recommended letters, digits and underscores (whether this still applies is to be confirmed).
