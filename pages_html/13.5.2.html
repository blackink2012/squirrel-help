资产库索引与 Maya 文档索引是两套独立数据，缺哪套就补哪套；换了嵌入模型则必须重建。

症状

  • 提示「还没有资产库语义索引」或「没有 kb/semantic/meta.json」。
  • 索引目录存在，但缺少 vectors.i8、scales.f32 或 meta.json。
  • 状态提示索引模型与期望模型不一致，或「索引目录属于另一个资产库」。
  • 换模型后搜索突然退回词法，或结果明显变差。

可能原因

原因判断方法处理
资产库索引从未建立库根下没有 .squirrel_ai_index\<official / ollama>首次同步或重建
索引文件不完整缺 vectors.i8 或 scales.f32重建索引
换模型/改文本模板/改主键方案/换后端meta.json 记录与当前代码或当前后端不一致全量重建
索引目录指向了别的库提示索引属于另一个资产库清掉覆盖目录或重建接管
Ollama 没有该模型ollama list 中没有对应名称拉取模型后再重建
Maya 文档索引缺失kb/semantic/<official / ollama> 下没有 meta.json重建文档索引
索引放在网络盘同一后端多机同时写同一目录改为每台机器本地目录（不同后端已分家）

解决步骤

  1. 执行 asset_semantic_status，记录 dir、model、count、reason 与 index_dir。
  2. 资产库索引缺失时，执行 python tools/asset_index.py --rebuild；只是想追平新增资产时用 --sync。
  3. Maya 文档索引缺失时，执行 python tools/build_semantic_index.py --model embeddinggemma-2:740m。
  4. 模型没有拉取时，先执行 ollama pull embeddinggemma-2:740m，再重建。
  5. 设置过索引根目录时，确认该目录在本机磁盘；每个库会在根下自动使用自己的子目录。
  6. 提示索引属于另一个库时，清掉索引目录覆盖设置后重建，或确认原库索引不再使用后让它接管。

结果验证

asset_semantic_status 显示索引条数大于 0，model 与索引记录一致，搜索不再提示索引缺失。

仍不行怎么办

  • 确认 meta.json 里的模型名与实际拉取的模型完全一致，包括 tag。
  • 删除索引目录前先备份；重建失败时保留 meta.json 与报错信息。
  • 文档索引可用 maya_docs(action="status", probe=true) 或 tools/setup_semantic_env.py --all 验证。
  • 按 4.5.6.5「重建与模型选择」确认换模型后的正确流程。
