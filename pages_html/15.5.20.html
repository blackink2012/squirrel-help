一句话定位：鼠标指着一张资产卡片按一下空格，会围绕鼠标弹出十字标记菜单——上和下、左和右各是一类「导入」命令，朝方向拖一下就执行。 它和右键菜单用的是同一套命令，只是把最常用的那段单独抽出来做成快速环。

怎么打开

  1. 鼠标移到资产区里某一张卡片上（不必先选中它）；
  2. 按一下空格（不要按 Ctrl / Shift）。

细节：

  • 如果那张卡当时没被选中，插件会先把它选中——与右键同一规矩（菜单作用的资产必须先在选中里）。
  • 只在图标视图里有效；列表视图里没有这个环。
  • 资产里一条导入类命令都没有时，什么都不会弹。

看这张图要注意：标记菜单是悬停才展开的——静态截图只能展开一个方向。图里展开的是「上 = 导入」， 另外三个方向（左 引用 / 右 应用 / 下 转换）在鼠标移过去时才展开，所以图上只看到端点标记。 材质资产实际四个方向都有内容：上=导入、左=添加引用、右=为当前选择指定材质 + 应用材质参数、下=转换导入。

四个方向是什么

方向归类典型内容
上导入导入 / 导入 ▶ / 导入贴图 ▶ / 导入到时间轴 等
左引用添加引用 / 添加引用 ▶
右应用为当前选择指定材质 / 应用材质参数 / 创建材质 / 指定贴图 / 应用灯光参数
下转换转换导入 ▶（材质、灯光）

没有对应命令的方向就空着（一颗药丸都不画），这是照 Maya 标记菜单的语义来的。

药丸怎么读

长相含义
一颗药丸（一行字）一条具体命令，拖上去松手就执行
同一方向上下堆叠的多颗该方向有多条命令（例如贴图的右边有三颗）
药丸后面带 ▸它有子项：悬停 / 拖到它上面，一级会消失、只留这一颗 + 子项列表
子菜单只有一条子项直接降级成药丸本身，少一层点击
子项很多子菜单单列显示，超过可视行数用滚轮翻页

子项列表里每一行都是一条可执行命令（例如「转换导入 ▶」下的 18 种材质类型）。

怎么用

操作结果
按住空格弹出 → 朝方向拖 → 松开空格执行高亮的那一条（最顺手的用法）
弹出后用鼠标点药丸 / 点子项同样执行
方向键选方向，Enter 进子项 / 执行全键盘操作
二级里 ↑↓（或 Tab）走动、← 退回一级、Enter 执行子菜单内的键盘操作
Esc取消
高亮在中心 / 没拖到任何药丸就松手取消，什么都不执行

底部提示行会写「松开空格 / Enter 执行 · Esc 取消」，记不住时看它。

各子库的四个方向（典型形态）

子库上（导入）左（引用）右（应用）下（转换）
材质导入 ▶（zmetal / ma）添加引用为当前选择指定材质、应用材质参数转换导入 ▶（18 种）
模型导入 ma添加引用——
灯光导入 ▶（zlight / ma）添加引用应用灯光参数到选中灯光转换导入 ▶（4 种）
贴图导入贴图 ▶（每张 + 导入全部）—为当前选择指定材质、创建材质 ▶、指定贴图到材质—

HDR导入 hdr—创建环境光 ▶、指定贴图—
动态导入 ▶（ma / abc）添加引用 ▶（ma / abc）——

这张表是典型形态：实际药丸的数量与名称取决于资产里到底有几种格式（例如建模资产只有 ma 时，「导入」就是一颗而不是带子项的那颗）。

它和右键菜单的关系

项右键菜单空格标记菜单
命令来源同一套构建代码同一套构建代码（只取「导入段」）
包含范围全部条目（含收藏、编辑、删除、详情）只有导入 / 引用 / 应用 / 转换
多选语义对全部选中资产生效一致（同一批命令，语义不变）
适合场景一次性的管理操作一边摆资产一边快速导入，手不离鼠标

注意点

  • Ctrl+Space 是另一件事：它是「切换当前焦点那张卡片的选中」，不会弹标记菜单。
  • Shift+Space 不响应：只有不带修饰键的空格才会弹环。
  • 标记菜单不提供「删除 / 编辑」：那些操作请走右键菜单。
  • 子项要看清楚再松手：拖到带 ▸ 的药丸上会立刻展开子项，松手执行的是子项里当前高亮的那一行。
