The script browser uses "categories on the left, script list on the right", with a search box at the top that filters live.

Purpose

It gathers scripts scattered across the script asset library, project folders and personal folders in one place, so you can double-click to run them instead of remembering paths or pasting into the Script Editor.

Interface

  • Left column: script asset categories plus 「全部」 (All), 「★ 收藏」 (Favorites), 「🕘 最近运行」 (Recently run) and 「未登记」 (Unregistered); extra script roots are grouped by their first-level sub-directories. Empty categories are shown too.
  • Right column: the script list showing the Chinese name, risk level and whether it has been verified live; hovering shows its purpose and trigger scenario.
  • Top: the search box, 「▶ 运行」 (Run), 「添加目录」 (Add directory) and 「刷新」 (Refresh).
  • Bottom: a status bar with success / failure and the elapsed time.

Steps

  1. Open 快捷工具 (Quick tools) → 脚本浏览器 (Script browser).
  2. Choose a category on the left; on first use click 「添加目录」 (Add directory) or drop a folder into the window to add an extra script root.
  3. Type a keyword in the search box and the list filters as you type.
  4. Select a script to read its list information; double-click, press Enter or click 「▶ 运行」 (Run) to execute it.

Verify the result

  • The number of list entries changes with the category and search terms.
  • After running, the status bar shows 「已运行 <name>（用时 x.xxs）」 (ran <name>, x.xx s) or 「运行失败」 (run failed).
  • The script's print output and tracebacks appear in the Maya Script Editor history.

Notes

  • The scan covers script_assets/ and extra script roots; files starting with . or _ are not listed.
  • F5 refreshes, Ctrl+F focuses the search and Ctrl+C copies the selected script path.
  • The script browser has no separate output panel; all output goes to the Script Editor.
  • The search and filter syntax is described in 9.6.4.
