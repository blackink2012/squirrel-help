一句话定位：「分类」页签最上面那个下拉框，用来在多个主资产库之间切换 —— 换库就是换一整套分类树与资产。

怎么打开

  1. 左侧导航 → 点「分类」页签；
  2. 点页签顶部那个下拉框（显示「库名 — 库路径」）；
  3. 在展开的列表里点另一个库。

菜单逐项详解

菜单项数量 = 你在设置里配置了几个资产库（示例环境是 2 个）。每一行的格式固定为「库名 — 库的完整路径」。

菜单项 / 行作用前提点了之后注意
当前库（下拉框上显示的那个）表示你正在看的库库已加载—（点它等于不切换）认不出当前是哪个库时，看下拉框文字里的路径
另一个库（每一行一个）把主资产库切到这一行该路径真实存在重新加载库：分类树重扫、资产网格切到新库的「全部资产」、状态栏数字更新切换只影响主资产库，不影响「项目」页签的项目库与收藏夹；切换后当前选中分类会复位

子菜单

这个下拉没有二级子菜单：列表里的每一行就是一个库，点它即切换，不会再展开一层。

增删资产库不在这里

这个下拉只负责切换，不提供「添加 / 创建 / 移除 / 设为默认」。这些操作在设置窗口 →「常规」页的「资产库管理」里：

你想做去哪
添加一个已存在的库设置 → 常规 → 资产库管理 →「添加资产库」，见 8.9.2
新建一个空库设置 → 常规 → 资产库管理 →「创建资产库」
移除列表里的库设置 → 常规 → 资产库管理 →「删除选中」
设为启动默认库设置 → 常规 → 资产库管理 →「设为默认」

小白易错点

  • 切了库，资产全变了 / 分类也不一样：正常。每个库有自己的分类树与资产，这是「换库」不是「换分类」。想找回原来的库，在下拉里切回去即可。
  • 下拉里没有我要的库：它还没被登记到设置里，去设置 → 常规 →「添加资产库」。
  • 点另一个库没反应，只弹出一条警告：那个库的路径已经不存在（盘符变了、文件夹被移走 / 改名）。先把文件夹恢复，或到设置里移除这个失效条目。
  • 以为切库会删东西：切换只是「换一个库来显示」，不移动、不删除任何资产。
