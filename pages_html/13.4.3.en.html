The plug-in routes files to different importers by extension; when an extension is not in the supported set it is treated as an unknown format and fails immediately.

Symptoms

  • Right-click import does nothing, or the log reports an unknown format.
  • A file type is missing from the file chooser, or cannot be imported after selection.
  • Image format conversion reports an unsupported target format.
  • A format checkbox in the export dialog is grayed out, or shows unavailable next to it.

Possible causes

CauseHow to tellAction
The extension is not in the supported setexplain_format returns importer=unknownConvert to a supported format, or import as an external file
Upper case or multiple suffixesThe file suffix is not a single dotted extensionRename to a standard extension and retry
A Maya-side plug-in is missingThe import plug-in that format depends on is not loadedLoad the plug-in in the plug-in manager
An internal format treated as an external file.zmetal and .zlight are not ordinary external filesImport from the asset library, or use the matching conversion tool
The external-file import set is narrowerThe extension is missing from the importable_external groupCollect it into the library first, or convert the format
The export format plug-in is unavailableThe format checkbox is grayed outSee 4.3.5.4 "Format unavailable"

Steps

  1. Run list_supported_formats and confirm which group the extension belongs to: geometry, proxy, volume, texture, HDR, zmetal or zlight.
  2. For a single file, run explain_format with the extension and confirm the returned importer is not unknown.
  3. Geometry supports ma, mb, fbx, obj, abc, usd, usda, usdc, glb, gltf, dae; proxies support ass, rs, proxy, vrmesh, vrscene; volumes support vdb.
  4. Textures support png, jpg, jpeg, exr, hdr, tga, tiff, tif, bmp, psd.
  5. To collect an external file into the library, first confirm the importable_external group of list_supported_formats contains that extension; if not, convert it first.
  6. For formats that depend on a Maya plug-in, load that plug-in in the plug-in manager and retry the import or export.

Verify the result

explain_format returns a definite importer type (such as geometry, texture, hdri) and the file imports or converts normally.

If it still fails

  • Record the file extension, source software and full error to confirm the file itself is not corrupt.
  • Save the file as a standard format in the target software first, then import it to verify.
  • For export-side problems, check the plug-in and format presets per 4.3.5.4 "Format unavailable".
  • When reporting, include the returns of list_supported_formats and explain_format so it is clear whether the manifest is missing an entry or a plug-in failed to load.
