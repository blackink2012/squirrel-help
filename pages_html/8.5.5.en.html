Ordinary search does substring matching on names, tags and categories; AI search encodes your words into vectors and compares them, which catches synonyms but depends on indexes and needs more preparation.

Comparison

DimensionOrdinary searchAI semantic searchAI search preview panel
InputKeywordsOne natural-language sentenceNatural language, images, multi-turn chat
MatchingSubstring on name / tags / notesVector similarity fused with lexical resultsLocal vectors first, a large model when needed
DependenciesNoneEmbedding model and asset indexSame, plus optional large and vision models
SpeedFastestFirst search syncs, then usually tens of millisecondsOne extra chat round compared with the main search
When unavailableAlways worksFalls back to keyword searchFalls back to keywords or reports no results

Shared limits

  • Both only search the active library and never cross libraries; with a category selected they search only that category.
  • Assets may be missing while the index lags, and the next search syncs incrementally.
  • Results are shown isolated and never change asset data; clearing restores the original list.

Choosing

Use ordinary search when you know the name or tag; use AI search when you only remember the look, need a material description or want to speak colloquially; use the preview panel when you want to chat while looking, add reference images or build a wishlist.
