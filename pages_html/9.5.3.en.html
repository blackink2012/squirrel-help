Build an attribute-by-attribute mapping between two material node types and save it as an .mmap for the material conversion tool.

Purpose

It decides "which source material attribute goes to which target attribute" and can add transform functions and default values; it is the key configuration behind material conversion quality.

Input and output

  • Input: source / target material nodes (loaded from the current Maya selection), or node types and attributes typed by hand.
  • Output: .mmap presets (JSON) saved in Assets/material_mapper_presets/ by default, named source node type_target node type.mmap.
  • The mapping table has five columns: select, source material attribute, target attribute, transform function, default value.

Steps

  1. Open 快捷工具 (Quick tools) → 材质节点属性映射工具 (Material node attribute mapping tool).
  2. Select the source material node in Maya and click 「加载」 (Load) next to the source node; then select the target material node and click 「加载」 (Load) next to it.
  3. Click 「添加行」 (Add row) and pick the source and target attributes from the dropdowns; 「属性浏览器」 (Attribute browser) also lets you pick attributes from the current selection.
  4. Fill the transform function and default value as needed; 「载入默认值」 (Load defaults) reads the target node's current values into the whole column.
  5. For automatic inference choose the AI service and model and click 「AI 智能映射」 (AI smart mapping); right-clicking a single row also infers locally.
  6. Click 「保存预设」 (Save preset) to save the .mmap; reload it later with 「加载预设」 (Load preset).

Verify the result

  • Saving reports 「预设已保存到: <path>」 (preset saved to: <path>) and the .mmap appears in the preset directory.
  • Closing the window saves _last_preset.mmap automatically and restores the previous configuration next time.
  • After loading the same mapping folder in the material conversion tool the table shows the source / target types and attribute counts.

Options and notes

  • Transform functions cover RGB channel splitting, transparency to transmission, glossiness to roughness, metalness estimation, emission, color math and more; function arguments are JSON (such as {"scalar": 2.0}) and switching a function fills in default arguments automatically.
  • AI services include Ollama (local, no API key), DeepSeek and Qwen (API key required); the local default model is qwen3-vl:8b, so when it is missing pick a pulled model in the dropdown or run ollama pull.
  • An empty attribute dropdown usually means no node was loaded; use the attribute browser to add attributes one by one instead.
  • When AI returns nothing useful, first confirm the service is reachable and the model available; with many attributes run it in batches on selected rows.
  • The preset directory opens directly with 「打开文件夹」 (Open folder); a duplicate source attribute is cleared automatically.
