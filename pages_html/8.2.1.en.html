One check inspects Ollama, the embedding model, the documentation and asset-library indexes, image retrieval, the vision model, dsh and cloud keys, and produces a report you can follow directly.

Prerequisites

The plug-in main window is open; to check the indexes and the current library, open the target asset library first.

Steps

  1. Open Settings → AI 设置 (AI settings).
  2. In the top 「AI 功能与依赖」 (AI features and dependencies) group click 「AI 依赖检查」 (AI dependency check).
  3. Wait for the background check. The report is written to disk and opened in Notepad automatically, and the status line also gives a summary.
  4. Work through the report in order: first the items marked unavailable, then the optional ones not installed; every item states the current state, what is missing, which feature it affects and how to fix it.

Verify the result

Notepad opens %TEMP%\squirrel_asset_manager\AI依赖检查报告.txt, listing each item as available, optional and not installed, or unavailable; the entries should agree with the hints on the settings page.

Tips

  • The check connects to Ollama once and asks about each model's capabilities, which takes a few seconds on a slow machine.
  • To inspect local files quickly without contacting services, run the read-only command ai_deps_status(probe=false).
  • The report only diagnoses and never installs; use 「一键安装」 (One-click install) to fill gaps (next page).
