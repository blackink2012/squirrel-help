A viewport screenshot grabs one PNG frame of the current viewport with Maya's playblast and returns the file path within seconds; it is good for checking shape, proportions and seams.

Prerequisites

  • Maya is in a GUI session; mayapy or -batch has no viewport and cannot capture.
  • The target panel is open and the viewport has refreshed.

Steps

  1. Call capture_viewport; without image_path the output goes to the system temp directory.
  2. Set the size with width / height, 1280×720 by default.
  3. Choose the viewpoint by passing a camera name to camera or a modelPanel name to panel; otherwise the current camera and first panel are used.
  4. Choose the display mode: mode is shaded (default), textured or wireframe; add wireframe=true to overlay wireframe on shaded.
  5. Choose the frame: frame defaults to the current frame.

Verify the result

The return value contains image_path; open the PNG and confirm the image is neither a flat color nor empty. When the image is suspiciously small or looks flat, the reply carries a warning.

Tips and warnings

  • Before capturing it runs dgdirty and forces a refresh; otherwise a newly created or rebuilt scene easily captures an empty image.
  • Camera, display mode, wireframe and current frame are all restored afterwards, so your viewport is never left in a temporary state.
  • A playblast is a single blocking call: you can cancel before it starts, but not once it runs; a large scene can take from a dozen seconds to several minutes, so prefer an async job.
  • panel and camera must refer to the same viewport; playblast captures the active panel by default, so a mismatched camera captures something else.
