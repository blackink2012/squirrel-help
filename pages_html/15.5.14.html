一句话定位：这四条 11 个子库都有，位置固定在「子库专属段」下面。 它们只动「选择」和「收藏」这类轻量状态，不碰资产内容。

菜单逐项详解

菜单项作用前提点了之后注意
添加到收藏夹 ▶把资产加进某个收藏夹资产库已加载子菜单列出所有收藏夹（含「默认收藏夹」和自建的）；点一下加入，再点一下移出已在该夹 → 实心金星；不在 → 描边灰星
全选一次选中网格里当前可见的全部卡片资产区里有卡片所有卡片高亮，属性面板显示最后一张只选筛选 / 搜索后的结果，不是整库
复制把资产放进剪贴板无内部剪贴板记住该资产；同时把资产文件夹路径写进系统剪贴板这不是「复制一份到当前分类」，真正落地要再「粘贴」
打开文件夹打开资产在磁盘上的位置资产是 .zasset 目录，或已入库的散文件系统文件管理器定位到该资产文件夹只打开，不改内容

子菜单：添加到收藏夹 ▶

子项说明
默认收藏夹内置的那个收藏夹，永远存在
得到的（自建收藏夹）你自己新建的收藏夹，按名字排在这里；新建几个就多几项
收藏夹为空时只剩「默认收藏夹」一项

两个细节：

  • 状态会显示出来：已经收藏过的夹是实心金星，没收藏的是描边灰星——不用点开确认。
  • 多选时对全部选中资产生效：多选之后点某个收藏夹，选中的资产会一起加入 / 一起移出。

「全选」到底选了哪些

  • 选了当前视图里看得到的卡片：筛选了标签、搜索了关键词、按分类过滤之后，「全选」只在结果集里选。
  • 「全部资产」页签下全选 = 整个库的可见资产（数量可能很大，随后做批量操作要留意）。
  • 全选之后可以接着右键做批量操作，见 8.5.21。

「复制」复制的到底是什么

层面内容
插件内部剪贴板资产的 ID 与资产包路径
系统剪贴板资产文件夹（.zasset 目录）的路径

所以：

  • 在资产区空白处右键 →「粘贴」，会把剪贴板里的资产复制一份到当前分类（见 8.5.19）；
  • 在 Windows 资源管理器里粘贴，会把资产文件夹整个拷出去（可用于备份或发给同事）。

内部版本 / 变体这些虚拟条目不会被复制——它们不是独立资产。

「打开文件夹」打开的是哪

  • .zasset 资产：打开资产包目录本身（里面有 meta、几何、贴图、缩略图）。
  • 散文件资产（图片 / 音频）：打开文件所在的文件夹。

进去以后别随手改名或删文件：库里的索引指向这些路径，删了资产就损坏了。要腾空间用「删除 → 移到回收站」。

注意点

  • 收藏不等于复制：收藏只是在收藏夹里挂个引用，资产还在原分类里。
  • 全选后误操作影响是批量的：批量删除、批量移动前，先看底部状态栏的「已选中 N 个资产」对不对。
  • 复制不会改名：粘到同一分类会走同名冲突处理（询问 / 自动改名），见 8.12.5。
