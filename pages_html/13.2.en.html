For licensing problems, first check the status and machine code on Settings → License activation, then handle it as not activated, expired, or integrity check failure.

Symptoms

  • The plug-in opens and browses, but import, export, conversion and similar operations are refused.
  • The status shows Not activated (read-only), Trial ended or Subscription expired.
  • Online activation keeps failing, or the old license stops working after switching machines.
  • The log contains E_LIC_INTEGRITY, E_LIC_MISSING or sq_license 不可用，进入只读模式 (license unavailable, entering read-only mode).

Possible causes

CauseHow to tellAction
Not activated yetLicense activation shows Not activatedEnter a key under the machine code, or open the license manager and import a license
Trial expiredStatus shows the trial has ended with 0 days leftPurchase or import a full license
Subscription expiredStatus shows grace period or expiredRenew, then activate again
Machine change or hardware changeThe machine code and the license binding disagreeFirst run Deactivate this machine on the old machine (limited by the server's daily cap, max 3 per 24 hours), then activate on the new machine; offline-issued licenses cannot be unbound yourself, contact the licensor to reissue
Online activation cannot reach the networkThe dialog reports server unreachable, timeout or DNS failureCheck network, proxy and firewall, or use an offline license
Installation package was modifiedIntegrity check failure is reportedReinstall the complete package; never delete or edit integrity.json or the _vendor directory
Licensing module missingThe log says sq_license is unavailableConfirm the package is complete; without it the program can only run read-only

Steps

  1. Open Settings → License activation and note the current status and machine code.
  2. If not activated or the trial expired, enter the key under the machine code and click Activate; alternatively open License management to activate online.
  3. If online activation is unavailable, use Import license file…, or copy the full license text and click Import from clipboard.
  4. When switching machines, copy the machine code on the new machine and activate; if the old machine still holds the license, deactivate it first as the vendor requires.
  5. On an integrity check failure, reinstall the complete package to restore deleted or modified files.
  6. After a successful activation, restart the plug-in window so the feature gates re-read the status.

Verify the result

The status badge on License activation shows Licensed or Trial, and the previously refused import, export or conversion operations now run.

If it still fails

  • Record the status text, error code and machine code and pass them to the plug-in distributor.
  • When online activation fails, try an offline license first to rule out network and proxy factors.
  • If the log shows E_LIC_MISSING, the licensing module did not load; treat it as an installation problem.
  • Never publish full license files, private keys or credentials containing personal information.
