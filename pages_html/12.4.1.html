Assets/preset/config.json 是插件的共享结构配置，决定子库、默认分类、格式识别、标签与配色；改动会影响所有使用这份插件目录的机器。

位置与写入

文件位于 <插件包>/Assets/preset/config.json，当前结构版本为 "1.0"。设置窗口的「常规」（资产库管理分组）、「支持格式」「贴图后缀」「子库与分类」页会把结果写回这里。个人偏好（字号、主题、库路径、AI 密钥）不在这里，而在 ~/.squirrel_asset_manager/app_settings.json。

主要字段

字段当前内容影响
sub_libraries11 个内置子库：materials / models / lights / textures / scenes / hdr / ani / images / audio / animation / nodetree（显示名：材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态 / 图片 / 音频 / 动画数据 / 节点树）左侧导航、资产归类与命令的子库参数
default_sub_categories每个子库的默认「自定义」分类（11 个子库各一组）新建库或分类缺失时的兜底分类
asset_file_extensions39 个扩展名：.zasset、几何、图像、音频（wav/mp3/aiff/aif/flac/ogg/m4a/aac）、动画数据（.atom）、.mcm 等哪些文件会被识别为资产
geometry_extensions15 个几何与代理扩展名几何体导入/导出与格式路由
image_extensions10 个图像扩展名贴图与预览可处理的图像格式
texture_suffixes49 个贴图后缀，如 _basecolor、_normalPBR 贴图类型识别
material_node_types12 种材质节点，如 openPBRSurface、VRayMtl材质识别与转换
common_tags按子库分组的常用标签（目前为 7 个早期子库各一组）编辑与批量打标签时的建议
node_type_colors / category_colors节点与分类颜色主界面配色
material_switch_delay_ms1000预留的材质切换延迟；当前代码未见引用
thumbnail_placeholder_enabledtrue预留的占位图开关；当前代码未见引用
name_conflict_policy对象：{"remember_choice": true, "mode": "auto_rename", "manual_name": ""}同名冲突时的策略（prompt / auto_rename / manual），以及是否记住上次选择
texture_import_policyasset_directory贴图导入到资产目录、源目录或工程目录
dependency_import_policyasset_directory关联文件同上
material_presets7 条材质预设，每条形如 {"name": "openPBRSurface", "node_type": "openPBRSurface"}创建材质时的节点类型选项

编辑注意

  • 手工编辑必须保持合法 JSON；改前先备份，改后重新打开主窗口或重载插件。
  • 新增子库不只是加一行：还要建立对应资产目录，并在设置窗口里同步分类。
  • 未知键会被忽略，不会报错；拼错的键同样静默失效。

警告：这里是共享配置，不是个人设置。多机共用一份插件目录时，改动会同时影响其他使用者。
