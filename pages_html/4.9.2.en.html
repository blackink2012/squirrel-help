A collection is a top-level container in the favorites panel; the default collection always exists, and other collections can be created, renamed, emptied and deleted.

Creating a collection

  1. Click + on the right of the 「收藏夹」 (Favorites) title (tooltip 「新建收藏夹」 (New collection)), or right-click empty space in the list and choose 「新建收藏夹」 (New collection).
  2. Type a name and confirm; the new entry appears in the list and is selected.

Renaming

  1. Right-click a non-default collection and choose 「重命名」 (Rename).
  2. Type the new name and confirm.

Emptying a collection

  1. Right-click the collection and choose 「清空收藏夹」 (Empty collection).
  2. Confirm in the 「确认清空」 (Confirm empty) dialog. Emptying removes only the favorite membership; the assets themselves are not deleted.

Deleting a collection

  1. Right-click a non-default collection and choose 「删除收藏夹」 (Delete collection).
  2. Confirm in the 「确认删除」 (Confirm delete) dialog. Only the container is deleted and the assets are unaffected; if the active collection was deleted the interface falls back to the default collection.

Verify the result

  • The names and counts in the favorites list update immediately.
  • The collections entry in favorites.json in the library root grows, changes or shrinks accordingly.
  • The changes are still there after reopening the plug-in.

Tips

警告

The default collection offers no rename or delete entry; deleting a collection never deletes assets, but it does lose that collection's favorite memberships.

  • A new collection's internal ID looks like fav_xxxxxxxx, and its display name can be changed at any time.
  • On the command side use collection_manage: op=list/create/rename/delete/clear, with dry_run for previewing.
  • Collections are stored per library, so after switching libraries you see that library's own collections.
