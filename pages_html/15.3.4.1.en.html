One-line summary: right-clicking the top "All assets" row (or blank space in the tree) opens a menu with a single item — Add top-level category — which creates a new major category under the library root.

How to open it

  1. Left navigation → Category tab;
  2. Right-click the All assets node at the top of the tree;
  3. Or right-click blank space in the tree (both locations open the same menu).

This menu has exactly 1 item: Add top-level category.

Item-by-item details

Menu itemEffectPrerequisiteWhat happens on clickNotes
Add top-level categoryCreates a top-level category under the asset library root (in effect a new custom major category)The current library is loaded; you are on the Category or Project tabOpens the "Add category" dialog with folder name + readable name + type; on confirm a top-level node appears at the root and is selectedThe folder name must not duplicate an existing category or a built-in sub-library (such as materials), otherwise the dialog reports "Cannot create a category named …" and refuses; a new top-level category comes with a Custom sub-category for assets that belong to no specific category

How to fill the dialog

FieldWhat to enterNotes
Folder nameThe folder name on disk and the internal category id; English letters / digits are recommendedRequired; must not conflict with an existing category chain; it becomes the folder name and cannot be changed afterwards (the field is read-only in the later Edit dialog)
Readable nameThe Chinese name shown in the treeMay be left empty, in which case the folder name is shown
TypeWhich asset type this top-level category behaves as (materials / models / lights / textures / scenes / HDR / animation…)This matters: it decides which context menu assets under this category get and which import modes they support; a wrong choice makes the Import / Create options behave unexpectedly

Submenus

This menu has no second level (one item measured, nothing with ▶). Add top-level category opens a dialog directly rather than another menu.

Risks and how to undo

  • Creating a category touches no existing asset; it only adds an empty folder level.
  • Created it wrongly: right-click that top-level category → Delete category (it goes to the recycle bin and can be restored), see 8.3.4.3.
  • A wrong folder name cannot be renamed here (it is read-only in the edit dialog), so you must delete and recreate — name carefully the first time.

Beginner pitfalls

  • Expecting to import / create assets by right-clicking All assets: you cannot. It is only the library-root entry and its menu only creates top-level categories; importing assets is in 8.4.2.
  • Right-clicking a sub-library root shows only 6 items with no "Add top-level category": menus differ per node. On a sub-library root the item is called Add sub-category, see 8.3.4.2.
  • No idea where the assets went after creating: a new top-level category automatically contains a Custom sub-category, which is where created / imported assets land by default.
  • Chose "materials" as the type and now want models: right-click the node → Edit and switch the type (this only changes the category's type tag and does not convert existing assets).
