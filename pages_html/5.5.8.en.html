「创建环境光」 (Create environment light) builds a dome light from a built-in .ma template and sets the HDR asset as its environment texture.

Prerequisites

  • The HDR asset has .hdr or .exr files under textures/.
  • The matching renderer's .ma template exists under the plug-in's Assets/HDR_ligt/.

Steps

  1. Right-click the HDR asset and expand 「创建环境光」 (Create environment light).
  2. Choose a template; template names correspond to dome lights of different renderers.
  3. The plug-in imports the template .ma and looks for the texture attribute among the nodes it just created.
  4. It prepares the HDR path per the texture import policy and writes it into the file node or the light's texture attribute.
  5. Generic node names are normalized and the selection is cleared at the end.

Verify the result

  • A dome light appears in the Outliner with the renderer's standard name (such as aiSkyDomeLight1).
  • The light's environment texture points at the HDR file, with the Raw color space on the file node.
  • The environment light works in a render preview.

Tips

  • 「创建环境光」 (Create environment light) never modifies existing lights; to swap the HDR of an existing dome light use 「指定贴图」 (Assign texture).
  • The template list comes from Assets/HDR_ligt/; when that directory is empty there is nothing to choose.
  • Dragging an HDR into the viewport silently picks a template from the current renderer or the double-click preset, matching the double-click behavior.
  • Where the HDR is stored is decided by the texture import policy in Settings → 常规 (General).
