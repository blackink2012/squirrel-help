One-line summary: the "app store" for every reusable script in the plug-in — search it, read the description and double-click to run; favorite the good ones and turn them into shelf buttons.

It does not write scripts; it is a "browser and launcher for the script library". It holds scripts shipped with the plug-in and lets you add scripts from directories of your own.

A complete usage flow

  1. Quick tools → Script browser;
  2. Type a keyword in the search box (such as "thumbnail"), or click a category in the left tree;
  3. Hover a script to read its description and risk marker;
  4. Double-click to run it (or select it and click ▶ Run);
  5. The result appears in Maya's Script Editor, and any scene effect happens immediately in the current scene;
  6. Right-click a useful script → ★ Favorite; for repeated use choose Generate run command (for shelf)… to make a shelf button.

Where the output lands

  • Script output goes to the Maya Script Editor (History / Output);
  • Scene changes land directly in the current scene (whether they can be undone depends on the script, see the risk marker);
  • Favorites, recent runs and extra script roots are stored locally and survive restarting;
  • Generate run command produces a command string to paste onto the shelf.

Risks and how to undo

  • Read the risk marker first: list entries show [readonly] / [low] / [high] and similar levels, and the tooltip explains how to undo.
  • Scripts with risk=high ask for a second confirmation before running, with a "do not remind me this time" checkbox — better to leave it unticked and keep the reminder.
  • Running a script may change the scene: save the scene first (Ctrl+S). Read-only scripts change nothing.
  • Deleting a script / deleting a category (with contents) really deletes files from disk and cannot be undone. Confirm it is not your only copy.
  • Move to _internal only relocates the file (it no longer appears as a tool); the file remains.
  • To undo: a deleted script can only come back from a backup or version control; a wrong scene change is undone with Maya's undo or by not saving and reopening.
