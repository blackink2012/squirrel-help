一句话定位：这里管左栏有哪些子库、它们叫什么、每个子库默认带哪些分类。

这一页默认是锁住的，必须先勾「解锁全部配置」并确认警告才能改；只有右上角的「显示在主 UI」例外，随时可点（见 8.9.1）。

怎么打开

设置窗口 → 勾「解锁全部配置」→ 页签「子库与分类」。

控件详解

常见操作

把某个子库从左栏隐藏

  1. 左侧选中该子库；
  2. 取消勾选「显示在主 UI」；
  3. 点「应用 / 确定」→ 左栏不再显示它（「全部资产」里仍能看到这类资产）。

想恢复：重新勾上即可。节点树默认是隐藏的，需要时才勾。

从库的实际目录同步分类

  1. 先在主界面选中并加载好资产库；
  2. 回到设置 → 本页 → 点「读取当前分类文件夹」；
  3. 确认提示（会覆盖设置里的默认分类列表，不动磁盘）；
  4. 左侧列表与各子库的分类列表按库里的实际结构刷新。

加一个自定义子库

  1. 在左侧列表里右键 →「添加子库」；
  2. 出现 custom_1 一类的条目，改显示名、按需填默认分类；
  3. 保存后左栏会出现这个子库（前提是「显示在主 UI」勾着）。

删除自定义子库：在左侧右键它 →「删除子库」→ 确认；11 个内置默认子库（材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态 / 图片 / 音频 / 动画数据 / 节点树）不允许删，只能在「显示在主 UI」里取消勾选隐藏。

容易踩的点

现象说明
改了显示名，左栏没马上变保存后需要左栏重建；切换一次分类或重开插件即可看到
改子库 ID 后，某些分类配置对不上了改 ID 等于换配置键，属于高级操作；改前备份 config.json，并先在副本库试
点了「读取当前分类文件夹」分类少了一半它按磁盘实际目录来；空目录 / 没建文件夹的分类不会出现
「显示在主 UI」勾不动这个复选框不参与锁定；如果连它也灰，说明窗口状态异常，重开设置窗口
项目库的分类也被改了这个页面改的是设置里的默认分类列表，不直接改任何库；已经存在的库目录不受影响

反悔

情况怎么反悔
还没保存点「取消」
已保存、想回到之前「恢复默认设置」不会重置这一页（见 8.9.1）；用备份的 config.json 覆盖回去最稳
只想恢复左栏可见性重新勾选「显示在主 UI」，不需要动别的
警告

这一页里「读取当前分类文件夹」和「改子库 ID」都是会重写配置的动作。前者只影响配置，后者可能让已有配置匹配不上；不确定时先备份 <插件目录>\Assets\preset\config.json。
