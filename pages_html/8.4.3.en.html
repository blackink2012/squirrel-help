After selecting several assets, AI analyzes their thumbnails one by one and collects every result in an editable batch window that is applied at once after confirmation.

Prerequisites

Several assets are selected, they all have thumbnails and a vision model is available.

Steps

  1. Multi-select assets in the asset grid.
  2. Open the 「AI 工具」 (AI tools) menu and click 「AI 分析缩略图 (N 个选中资产)」 (AI thumbnail analysis, N selected assets).
  3. Choose the model and language in the configuration window, decide whether to review the results and click 「开始分析」 (Start analysis).
  4. The progress window shows each asset in turn and can be cancelled at any time; assets without a thumbnail or whose analysis failed are skipped.
  5. When it finishes the 「批量 AI 分析结果 — N 个资产」 (Batch AI analysis results — N assets) window opens: edit the name, category, tags and notes on the left and preview the thumbnail on the right; use 「全选 / 取消全选」 (Select all / Deselect all) to control what is applied.
  6. Decide whether to check 「移动到分析出的分类」 (move to the suggested category) and click 「应用选中的资产 (N 个)」 (Apply selected assets, N).

Verify the result

After applying, names, tags and categories in the grid update and the state and count match the items checked in the window. With review turned off the results are applied directly without a window.

Tips and warnings

  • A batch category move really changes where the assets live, so confirm the category names before applying.
  • Assets whose analysis failed get no fields written and can be retried individually.
  • With large counts, work in batches so each result can be checked in the window.
