最后一步是把库里的资产放进 Maya：双击按预设导入，或右键选择具体格式与导入方式。

操作步骤

  1. 在资产库中找到刚整理好的资产并选中。
  2. 双击卡片，按该子库的双击预设执行；模型默认导入 ma，材质默认导入 zmetal。
  3. 需要指定格式或导入方式时，右键卡片，在菜单顶部选择「导入」及具体格式；有多个格式时可从子菜单挑选。
  4. 材质类资产若已有选中物体，右键选「应用材质」，会把材质网络应用到选中物体。
  5. 导入完成后在 Maya 视口与大纲视图确认新对象；需要调整位置时直接在 Maya 中变换。

结果验证

  • 大纲视图出现新的根节点，视口能看到导入的模型或材质效果。
  • 材质资产导入后，Hypershade 中出现完整着色网络。
  • 双击或右键导入后，脚本编辑器有对应导入日志。
  • 资产导入失败时，脚本编辑器会给出错误信息，可据此检查格式与依赖。

提示

  • 模型、动态、场景拖入视口时会吸附到光标下的表面，比双击更适合摆放（见 3.3.5）。
  • 图片 / 音频 / 动画数据 / 节点树 的双击行为与几何资产不同：图片建 file 节点、音频进时间轴、动画数据走层级映射、节点树导入 ma，详见 3.3.1。
  • .zmetal 记录完整材质网络，即使原 Maya 文件不在也能重建。
  • 贴图丢失或材质不匹配时，先检查资产是否完整，再参考导入问题章节。
