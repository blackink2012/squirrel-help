Quick tools write no central log file: results stay in each tool window, and progress output plus errors go to the Maya Script Editor history.

Where to look

ToolWhere products and results appear
HDR / model / PBR texture to asset.zasset in the configured output directory; a result tree, status bar and completion dialog in the window
Image format conversion toolConverted images in the output directory; the conversion log, progress bar and completion dialog in the window
Batch mirror copyFiles copied with the same structure in the target folder; operation log, progress bar and a completion summary
Batch process Maya filesThe .ma / .mb files themselves (when saving is checked); an execution log area and a closing summary
Material import/export tool.zmetal / .ma / .mcm / .ameta and so on in the export directory; progress details printed to the Script Editor
Material conversion toolNew materials in the current scene; status bar, completion summary and a failed-material list
Material attribute mapping tool.mmap files in Assets/material_mapper_presets; a save prompt and Script Editor logs
Script browserSuccess / failure and elapsed time in the status bar; the script's print, traceback and RESULT in the Script Editor

Verify the result

  1. After a conversion tool finishes, open the configured output directory and confirm the new .zasset or target-format files.
  2. Open a .zasset and you should see meta.json, the source files (for example under textures/) and an optional thumb.sicon.
  3. Refresh or rescan the asset library and confirm the new assets are listed.
  4. Search the Maya Script Editor for the tool prefix (such as [HDR Tool], [材质导出] or [QuickTool]) to read progress output.

Notes

  • A single failed file usually does not abort the batch; trust the success / failure counts and the failure list.
  • The script browser has no separate output panel: script output and tracebacks only appear in the Script Editor history, and failures open a copyable error dialog.
  • The batch Maya file tool can 「保存日志」 (Save log) as .txt or 「复制日志」 (Copy log) to the clipboard.
  • Each tool writes logs only into its own log area in the window (the Script Editor gets output as well); there are no extra log files on disk.
