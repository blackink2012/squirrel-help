Creating a dome light builds the matching dome light node for the current renderer and connects the HDR texture to it as environment lighting.

Prerequisites

  • Maya is online and the current renderer is decided.
  • When using presets, the matching .ma preset exists under the plug-in's Assets/HDR_ligt.

Steps

  1. Right-click the HDR asset in the library and expand the 「创建环境光」 (Create environment light) submenu.
  2. The submenu lists the presets under Assets/HDR_ligt; running inside Maya imports that preset and replaces the HDR path, while the standalone edition builds the light from a built-in template through the command channel and connects the chosen HDR.
  3. You can also call create_dome_light; pass hdr_path for the texture, or leave it empty for the built-in default IBL.
  4. After the light exists, to swap the HDR or connect another HDR to an existing dome light use the HDR branch of "assign texture".

Verify the result

It returns status=ok with node; the Outliner shows the renderer's dome light node (Arnold aiSkyDomeLight, Redshift RedshiftDomeLight, V-Ray VRayLightDomeShape) and the light's texture path points at the chosen HDR.

Tips and warnings

  • The dome light node type varies by renderer, so after switching renderers re-check the light's attributes and texture wiring.
  • When the current renderer has no usable template the command returns 「创建失败（渲染器不支持或 Maya 未就绪）」 (creation failed; renderer unsupported or Maya not ready).
  • Light attributes normally live on the shape; expand it in the Attribute Editor when checking.
  • Without hdr_path the built-in default IBL is used; to change the texture afterwards use the HDR branch of "assign texture".
