The sub-library list supports right-click Add sub-library and Delete sub-library. The 11 built-in default sub-libraries cannot be deleted; you can only hide them by clearing Show in main UI. Only sub-libraries you created yourself can be deleted.

Prerequisites

  • Settings → Sub-libraries and categories is open and Unlock all settings is ticked.

Steps

Add a sub-library

  1. Right-click an empty area of the left sub-library list and choose Add sub-library.
  2. A new sub-library is generated automatically: ID custom_N (N is the first unused value starting from 1) and display name CustomN.
  3. Adjust the display name, ID and default categories as needed.
  4. Click Apply or OK.

Delete a sub-library

  1. Right-click the sub-library to delete and choose Delete sub-library (this item does not exist in the context menu of built-in sub-libraries).
  2. Confirm in the dialog "Delete sub-library 'name'?".
  3. Deletion is written to config.json immediately and also removes that sub-library's default category configuration.

Scope of effect

  • None of the 11 built-in sub-libraries materials, models, lights, textures, scenes, hdr, ani, images, audio, animation, nodetree can be deleted. Trying reports "Built-in default sub-libraries (materials, models, lights, textures, scenes, HDR, animation, images, audio, animation data, node tree) cannot be deleted; hide them with Show in main UI".
  • To keep a built-in sub-library out of the sidebar, clear Show in main UI. Assets and disk folders stay.
  • Deleting only changes configuration; it does not delete folders or assets on disk.
  • If the default category folders of a built-in sub-library are removed by hand outside the system, reloading, switching or refreshing the library rebuilds the folders, metadata and the default custom sub-category.
  • A newly added custom sub-library does not get folders in an existing library right away. If you need the folder structure, fill in the default categories first, then reload or switch the library once.

Verify the result

The entry appears in or disappears from the left list, and the state persists after reopening settings.

Tips

  • Before deleting, make sure no assets under that sub-library still rely on its configuration.
  • Custom sub-libraries can only use the generic context-menu items and the Import / Do nothing double-click commands.
  • To give a custom sub-library the same folder layout as the others, set its default categories first, then reload or switch the library once; folders are created from the default categories.
