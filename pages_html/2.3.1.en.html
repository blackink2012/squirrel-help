The plug-in edition opens from the Custom category of the Maya shelf or from the status-line icon; the standalone edition opens from the Start menu, the desktop shortcut or the main program.

Maya plug-in edition

  1. Open Maya and wait until startup finishes.
  2. Switch the shelf to the 「自定义（Custom）」 (Custom) tab and click the 「松鼠资产管家」 (Squirrel Asset Manager) button.
  3. Or click the squirrel icon on the right side of the Maya status line.
  4. You can also run this in the Script Editor:
from squirrel_asset_manager.ui.main_window import MaterialLibraryWindow
MaterialLibraryWindow.show_window()

The plug-in does not register a separate Maya menu item; the shelf, the status line and the script are the complete set of entry points. Calling it again in the same Maya session brings the existing window forward instead of opening a second one.

Standalone edition / EXE

  • Start menu: Squirrel Asset Manager.
  • Desktop shortcut: Squirrel Asset Manager.
  • Run SquirrelAssetManager.exe in the install directory directly.
  • From source: double-click 启动独立预览.bat (Start standalone preview), or run python squirrel_asset_manager\standalone_preview.py.

Verify the result

  • The main window appears and its title contains the current version number.
  • The category tree on the left and the asset grid are visible.
  • In the standalone edition the toolbar shows the Maya selection dropdown and the connection state.

Common failures

  • No button on the shelf: the button is created only at install time and is not rebuilt at startup after manual deletion; run the installer again to recreate it. It can also be missed when Maya was running but the shelf was not ready during installation — reinstall once more.
  • Status-line icon missing: PySide / shiboken failed to import; check the Maya Script Editor output.
  • Script says the module cannot be found: the install directory is not on sys.path; run the installer again and check the matching Maya version to repair the integration.
  • Double-clicking the standalone edition does nothing: check whether antivirus software blocked it, and whether runtime\python\python.exe is intact.
