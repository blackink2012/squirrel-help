Installs the AI dependencies in a fixed sequence, skipping whatever already exists; after a failure, clicking again only fills in the failed or missing parts.

Prerequisites

Network access; enough free disk space (about 1.3 GB for the embedding model and 5.6 GB for the vision model); installing Ollama may need system permissions.

Steps

  1. Open Settings → AI 设置 (AI settings) → AI 功能与依赖 (AI features and dependencies) and click 「一键安装 AI 功能与依赖」 (One-click install of AI features and dependencies).
  2. In the confirmation dialog check the steps and sizes. When AI asset analysis is needed, check 「同时安装图像检索」 (Also install image retrieval) and confirm the vision model name.
  3. Start it. The progress window shows the current step, live logs and a cancel button; Maya stays usable during the install.
  4. Afterwards read the success or failure list. On failure click the same button again, which only fills the failed or missing steps; check 「强制重装」 (Force reinstall) to reinstall over existing parts.

The install order is: Ollama → start the service → embedding model → documentation vector index → asset library semantic index → (optional) image sidecar → vision chat model.

Verify the result

After installing, run 「AI 依赖检查」 (AI dependency check) again and the related items should show as available; you can also try a natural-language Chinese semantic search or an AI thumbnail analysis.

Tips and warnings

  • After cancelling, the parts already installed are kept and only the missing ones are installed next time.
  • The full log is %TEMP%\squirrel_asset_manager\ai_install.log.
  • This step does not install dsh; use the one-click install offered by 「AI 助手」 (AI assistant) for the assistant runtime.
