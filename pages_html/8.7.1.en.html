The Maya documentation knowledge base has no separate window; its entry is the maya_docs tool in the AI assistant or maya_doc_search on the command surface. First find the name with a sentence, then read the details by name.

The image is only a signpost: there is no separate documentation window and no documentation entry in the menu — click AI 助手 (AI assistant) first and ask it for commands, nodes or the API in the conversation. Results are returned in the chat, not in this menu.

Prerequisites

A local knowledge base exists or the online fallback is available; semantic retrieval also needs Ollama and the documentation index, while lexical retrieval does not.

Steps

  1. Ask directly in the AI assistant, for example "how do I use polyReduce" or "how do I put objects along a curve".
  2. The assistant calls maya_docs(action="search", query="...", mode="auto"). You can limit type to command, node, api, devguide or doc, with limit up to 20.
  3. Read the name, type, plug-in, description and match field in the results and pick the exact name.
  4. Use the name for details: commands go through maya_docs(action="help") for live local parameters, nodes and the API through maya_docs(action="show").

Verify the result

It returns status=ok with a count and a result list; match says whether the hit came from lexical, semantic or both. When a result's source starts with online:, the online fallback was used.

Tips and warnings

  • Command parameters should follow the live local help; the knowledge base is only a snapshot.
  • mode="keyword" is fastest and fully offline; colloquial questions should use the default auto.
  • Commands from installed plug-ins are usually absent from the offline library, so check the plug-in list first and then use live help.
