One-line summary: Create asset exports what is currently selected in Maya into a new asset in the library, so it needs a specific category and something in Maya worth exporting.

How to use it

  1. Select a specific category in the left category tree (materials / models / lights / textures / scenes / animation / node tree and so on);
  2. Select the objects to export in the Maya viewport (the dialog opens without a selection, but export then has nothing to take);
  3. Click Create asset on the asset area toolbar;
  4. Confirm the configuration in the "Create asset" dialog and run the export.

What this button does

ItemDescription
EffectOpens the "Create asset / export" dialog and exports from the current Maya scene into the current category
Source of contentThe objects selected in the current Maya scene (in the standalone edition, the selection of the Maya chosen as Maya target)
Prerequisites① A specific category is selected (not All assets, not a favorite set, not the recycle bin); ② the category is not Images or Audio; ③ Maya is connected (always true in-edition; the standalone edition must pick a Maya target); ④ the scene holds exportable data
What happens on clickOpens a non-modal creation dialog (fill it in while watching the scene); on confirm the export starts and a new card appears in the grid
NotesIt writes to the library (new folder + metadata + thumbnail); same-name cases follow the name conflict setting: prompt / auto rename / manual overwrite, see 8.12.5

How it varies per category

Current categoryButton behavior
Materials / models / lights / textures / scenes / animation / node treeShows Create asset normally
Animation dataThe text becomes Export animation and exports the selected hierarchy frame by frame as an animation asset (.zasset), with matching hints
Images / audioThe button is hidden (those assets are files themselves, so "create from scene" does not apply)
All assetsThe button is gray (no target category, so nowhere to save)
Recycle binThe button is gray

Submenus

This button has no dropdown (no ▾); clicking opens the dialog directly. Details of every tab / field in the dialog are in 8.10.1 ~ 8.10.8.

Risks and how to undo

  • Create vs overwrite: the default is "create a new asset"; only when you choose an update / replace mode in the dialog does it overwrite an existing asset — read the confirmation before overwriting.
  • An interrupted export can leave a half-finished asset (hollow shell / missing textures): confirm in the library that the card has a thumbnail and can be imported, and delete and re-export if not, see 4.3.5.1.
  • Undo: delete a new asset with right-click Move to recycle bin (restorable); overwrite operations rely on the backup / version mechanism offered in the dialog, see 8.5.16.

Beginner pitfalls

  • The button is unclickable: check whether you are on All assets or in the recycle bin, and whether the category is Images / Audio (where the button is hidden).
  • The exported asset is empty: nothing was selected in Maya before exporting, or the selection holds nothing exportable (an empty group, for example). Select in the viewport first.
  • The standalone edition reports that it cannot connect to Maya: first choose an online Maya in Maya target, see 8.2.4.
  • The export does nothing / spins forever: large assets or thumbnail rendering are slow; watch the dialog and status bar and do not click repeatedly (it exports again).
