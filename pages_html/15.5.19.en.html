One-line summary: where you right-click decides which menu opens — on a card it is the asset menu, on blank space with no card it is this short "area menu", and right-clicking a row in list view equals right-clicking a card.

Three locations, three menus

Where you right-clickWhat opensDetails
On an asset card (icon view)The full asset menu8.5.2~8.5.12
Blank space in the asset area (icon view)The area menu (create asset / paste / select all; under All assets only these three, which is what the screenshot shows)This page
On a row in list viewExactly the same full menu as right-clicking a cardSecond half of this page

Blank space in list view has no menu — the list is rows and blank space belongs to no location, so right-click does nothing.

Two rules:

  • Locked under All assets: Create asset is gray and Import from outside disappears entirely, because the plug-in cannot tell which category you want.
  • Custom top-level categories get everything: a category you created has an unknown type, so all four packing routes are listed — better too many than missing.

Right-click in list view

BehaviorSame as icon view
Menu opened on a rowIdentical (same construction code, trimmed by sub-library the same way)
Right-click after selecting several rowsSame: applies to all selected rows plus the one you right-clicked
Right-click on blank spaceIcon view has the area menu; list view does not

So "list view has fewer features" is usually an illusion — the items are identical and only blank-space behavior differs.

Notes

  • What counts as blank space: if the cursor is over a card it is not blank and the asset menu opens. To get the area menu, right-click a gap between cards.
  • Paste targets the current category: click into the target category before pasting; if you paste into the wrong one, move it with Move to.
  • Create asset is unavailable under All assets: click into a specific category first.
