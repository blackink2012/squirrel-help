One-line summary: the AI entry behind the "brain" icon on the toolbar — analyze thumbnails, chat-search assets, turn the AI assistant on or off, and stop the AI broker all live here.

How to open it

  1. Find the brain icon on the top toolbar (tooltip "AI tools: analyze assets / AI search preview / AI assistant");
  2. Click to open the menu, then click an item.

Item-by-item details

The menu has 5 items (including one gray placeholder); when the AI chat panel is already open an extra Recall AI panel item appears in the middle (making 6).

The menu has a dashed line at the top and can be torn off into a floating window for repeated clicks.

Submenus

This menu has no second level (nothing has ▶; every item either opens a window or runs directly).

About "Initializing..."

When the interface has just opened and the asset grid is not ready, the whole menu shows only a gray "Initializing..." line and nothing can be clicked. Wait for the main interface to finish loading and click again; no restart is needed.

Beginner pitfalls

  • "AI thumbnail analysis" does nothing: read the menu text — if it says "(right-click asset → AI analysis)" nothing is selected, so select one or more assets in the grid first.
  • All AI features are unclickable / dependencies are reported missing: the local AI dependencies are not installed; go to Settings → AI and run AI dependency check and one-click install, see 8.9.3.
  • The AI assistant will not open: the first use requires installing dsh, and the plug-in shows an install guide, see 8.13.6.
  • Mistaking "Stop AI broker service" for closing the menu: it really stops the service, cutting off running AI analyses / searches; the next AI feature starts it again automatically.
