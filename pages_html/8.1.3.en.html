By default assets and thumbnails never leave this machine. Requests only leave it when a cloud model is enabled, when the Maya online help fallback is used, or when dsh connects to a cloud model.

Data that stays local

  • Indexes: the text semantic index defaults to <asset library>\.squirrel_ai_index\<official|ollama>\ (split by backend), the image index to img\ and the media index to media\ in the same directory; with ai_asset_index_dir set they live under that root in sub-directories split by "library + backend".
  • Image sidecar: <plug-in directory>\.venvs\asset-vision and its cache.
  • Run records: <plug-in directory>\dsh_home\ (dsh sessions, install logs, reuse records); AI dependency reports and install logs are in %TEMP%\squirrel_asset_manager\.
  • Online help cache: ~\.squirrel_asset_manager\help_cache (directory tree for 7 days, pages for 30 days).

Data that leaves this machine

  • With a cloud model selected, prompts and the thumbnails being analyzed are sent to that provider.
  • When the local knowledge base is missing or has no hit, the "online fallback" sends the query to help.autodesk.com and only reads public help pages.
  • Which model dsh uses is decided by dsh's own settings, and it may connect to the cloud.

Credentials

API keys are stored in the plug-in settings file ~\.squirrel_asset_manager\app_settings.json, which is not an encrypted vault, so protect it like any configuration file. AI search keys and global model keys are stored separately.

Recommendations

On confidential projects turn off cloud models and keep only local Ollama; to work fully offline set MAYA_KB_ONLINE=0 before starting to disable the online help fallback.
