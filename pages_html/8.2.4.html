安装失败通常是网络、权限或 Node 版本问题；先读报告与日志，再按失败的那一步单独补，不要整轮重装。

症状与处理

Ollama 没装上：确认 ollama 命令存在，或从 ollama.com 手动安装后重跑一键安装。Windows 上自动安装依赖 winget，被策略拦截时会失败。

服务没启动：确认 11434 端口未被占用，手动运行 ollama serve，再访问 http://127.0.0.1:11434/api/tags。若系统或环境变量设了代理（HTTP_PROXY / HTTPS_PROXY）且没把 127.0.0.1 放进 NO_PROXY，本地回环请求也会被代理拦掉。

模型拉取中断：直接重跑一键安装，已完成的步骤会跳过。网络慢时先换镜像或稍后再试。

图像 sidecar 装了一半：venv 在但缺 numpy / Pillow 时会被判为未装完。重跑安装，或执行 python tools\asset_vision_env.py --install --self-check。

索引构建失败：多数是 Ollama 没起或模型没拉。先体检，再确认库路径存在；命令行可用 python tools\asset_index.py --status 与 --doctor 查看原因。

dsh 安装失败：先关闭已打开的 AI 面板，再重试，避免文件被占用；Node 必须是 ^22.19 || >=24。

看日志

  • AI 依赖安装：%TEMP%\squirrel_asset_manager\ai_install.log
  • dsh 安装：<插件目录>\dsh_home\dsh_install.log
  • dsh 启动：<插件目录>\dsh_home\squirrel_web_<实例>.log

仍不行

把报告、日志末尾 40 行与系统版本一起反馈；不要手工删除半个 venv 或索引目录，重跑安装即可覆盖修好。
