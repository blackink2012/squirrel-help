The search box at the top of the Help Center supports both keyword and semantic retrieval and can find pages, commands and sections.

Steps

  1. Type a keyword in the search box at the top of the help page, for example "import model", "font size" or "crash".
  2. Results first show local lexical matches, then are replaced by fused "semantic + lexical" results when the service is available.
  3. Each result shows the title, a type badge (page / concept / reference / command / section), its path and a hit snippet.
  4. Use ↑ / ↓ to move, Enter to open and Esc to close the results.
  5. Command results jump to the command reference and highlight the matching row; section results open the section overview.

Result states

  • A label at the top states the current mode: 「语义 + 词法」 (semantic + lexical), 「词法检索」 (lexical) or 「词法检索 · 语义暂不可用」 (lexical · semantic unavailable).
  • With no hits it says 「没有找到匹配的帮助页，试试更短的关键词」 (no matching help page; try a shorter keyword).
  • If the search index has not been generated it asks you to run the build command in the project root (release builds normally ship the index).

Verify the result

  • Typing "import model" returns pages such as importing geometry and importing from files.
  • Typing "text too small" finds the pages about font size.
  • Pressing Esc closes the results without navigating away.

Tips

  • Semantic retrieval depends on the local embedding model; when unavailable it falls back to lexical retrieval and search still works.
  • The shorter the keyword and the closer it is to UI wording, the more reliable the hit.
