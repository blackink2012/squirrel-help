One-line summary: the plug-in's built-in purchase page — plans, prices, benefits and the payment QR code all come from the server; scan and pay on your phone and the activation code is filled in automatically, then click Activate.

How to open it

EntryCondition
Settings → License activation page → Buy licenseAlways visible; clickable when unlicensed, expired, or within 15 days of expiry; greyed out with a hover reason otherwise
Account window → Purchase / renewVisible after signing in; same condition

With plenty of license time left the button is gray and hovering explains why — this reduces invalid orders and is not a fault.

Window structure

AreaContent
Title / subtitleThe sales page title and description delivered by the server
Notice barServer-configured announcements (campaigns, invoice notes); hidden when none
Content card areaSales cards: plans and prices, benefit descriptions, link cards; content and layout are decided by the server; cards with an amount and working payment have Buy now
QR areaThe "scan to pay" card that appears after clicking Buy now, see the next section
Activation code areaThe Activation code input (placeholder SQAM-XXXX-XXXX-XXXX-XXXX) plus Paste and Activate
BottomRefresh on the left, Close on the right, and a status line at the very bottom

How QR payment works

  1. Click Buy now on a card with an amount;
  2. The server creates an order and a scan to pay card is inserted at the top of the window: the payment QR code plus payment notes (including a payment reference code when one exists);
  3. Scan the code on your phone and pay;
  4. The client polls the order in the background (up to about 10 minutes); on success it:
    • fills the activation code into the input below;
    • sets the status line to "activation code received, click Activate to finish.";
  5. Click Activate and the license takes effect with the status line "licensed, you can close this window.".

The QR image comes from the server; when it fails to load the card reads "payment code failed to load", so click Refresh at the bottom.

Entering or pasting a code manually

If you did not scan, or support sent you an activation code directly:

  1. Put the code in the Activation code input (or click Paste to take it from the clipboard);
  2. Click Activate.

With an empty input, activating reports "enter or wait for an activation code first."

Risks and how to undo

  • The purchase window never changes the license itself: only clicking Activate (or activating in the license window) takes effect;
  • Orders and QR codes come from the server; closing the window does not cancel an existing order, but unpaid orders expire on their own;
  • Paid but the window is closed: reopen the purchase window and activate with the received code in the Activation code area;
  • Clicking Buy now repeatedly creates new orders; the last QR code is the valid one.
