Give the plug-in a reference image and it first uses image vectors to find visually similar assets; only when image retrieval is unavailable does it fall back to "image to description" or "vision keywords".

Prerequisites

  • Image search from the main interface: an asset library is open.
  • Pixel-level retrieval needs the image sidecar and the image index; without them a vision model or tag fallback is still possible.
  • A dropped asset must have a usable thumbnail.

Steps

  1. In the search bar click the upload button (tooltip 「上传文件搜索」 (Upload a file to search)) and pick one of 「上传图片搜索」 / 「上传视频搜索」 / 「上传音频搜索」 (upload image / video / audio search), or click screenshot search and marquee a screen region.
  2. You can also drag a local image, video or audio file onto the search bar (the placeholder changes accordingly: images, audio and video each have their own hint).
  3. To find music by "the sound that is playing", switch to the music (audio) category and use record system audio search: it records what this computer is playing, not the microphone.
  4. To find assets from an animation picture, click screen-recording search and record a marquee region.
  5. Wait for retrieval. The internal order is: image vectors → turn the query image into one Chinese description and use text vectors → vision-model keywords and lexical search.
  6. Results appear isolated in the asset grid; click ✕ on the right of the search box to cancel the isolation and restore all assets of the current category.
  7. In 「AI 搜索预览资产」 (AI search preview) you can also add several reference images at once and send them together with text.

Verify the result

The status bar reports the path actually used: image-vector hits show the count and duration, the description route shows the recognized description, and the keyword route shows the keywords. When all three fail it reports no matching assets.

Tips and warnings

  • Building the image index the first time, or a cold start of the sidecar, is noticeably slower; afterwards it is incremental with a resident process.
  • The image index syncs incrementally on thumbnail changes; never use a sync command with --limit as sampling, because it trims index entries.
  • Chinese text-to-image search is not the image index's strength, so prefer a reference image for finding pictures.
