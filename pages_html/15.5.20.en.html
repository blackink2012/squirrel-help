One-line summary: with the cursor over an asset card, pressing Space opens a cross-shaped marking menu around the cursor — up and down, left and right each hold one family of import commands, and dragging toward a direction runs it. It uses the same commands as the context menu but extracts the most common block into a quick ring.

How to open it

  1. Move the cursor onto a card in the asset area (it need not be selected first);
  2. Press Space once (without Ctrl / Shift).

Details:

  • If that card was not selected, the plug-in selects it first — the same rule as right-click (the menu's target asset must be in the selection).
  • It works in icon view only; list view has no ring.
  • When the asset has no import-type commands at all, nothing opens.

How to read the image: a marking menu expands on hover, so a static screenshot can only expand one direction. The image expands "up = import", while the other three (left reference / right apply / down convert) only expand when the cursor moves there, which is why only the end markers show. A materials asset really has all four: up = import, left = add reference, right = assign material to selection + apply material parameters, down = convert import.

What the four directions are

DirectionFamilyTypical content
UpImportImport / Import ▶ / Import textures ▶ / Import to timeline and so on
LeftReferenceAdd reference / Add reference ▶
RightApplyAssign material to selection / apply material parameters / create material / assign texture / apply light parameters
DownConvertConvert import ▶ (materials, lights)

A direction with no matching command stays empty (not even a pill is drawn), following Maya marking menu semantics.

How to read the pills

AppearanceMeaning
One pill (a single line of text)A specific command; drag onto it and release to run
Several stacked pills in one directionThat direction holds several commands (textures, for example, have three to the right)
A pill with ▸ after itIt has sub-items: hovering or dragging onto it removes the first level and leaves this pill plus its sub-item list
A submenu with a single sub-itemIt degrades into the pill itself, saving one click
Many sub-itemsThe submenu lists them separately and the wheel pages when they exceed the visible rows

Every row in a sub-item list is an executable command (for example the 18 material types under Convert import ▶).

How to use it

ActionResult
Hold Space to open → drag toward a direction → release SpaceRuns the highlighted item (the smoothest usage)
Click a pill or a sub-item after openingRuns it too
Arrow keys to pick a direction, Enter to enter sub-items / runFull keyboard operation
In the second level, ↑↓ (or Tab) to move, ← to return, Enter to runKeyboard inside the submenu
EscCancel
Highlight rests in the center / release without reaching a pillCancels and runs nothing

The bottom hint reads "Release Space / Enter to run · Esc to cancel"; read it when you forget.

Notes

  • Ctrl+Space is something else: it toggles the selection of the focused card and does not open the marking menu.
  • Shift+Space does not respond: only plain Space opens the ring.
  • The marking menu offers no delete / edit: use the context menu for those.
  • Read the sub-items before releasing: dragging onto a pill with ▸ expands its sub-items immediately, and releasing runs the currently highlighted row in the sub-items.
