一句话定位：把"松鼠资产管家"的能力（技能说明 + MCP 工具入口）接到 Claude Code、Codex、Trae 这类外部 AI 工具里，让它们也知道你有资产库和 Maya。

要让外部工具真正能干活，需要两半，缺一半就是"模型知道有这回事，但调不动"：

  1. 技能落位：把我们的技能说明拷进对方的技能目录；
  2. MCP 通道：把本插件的 MCP 入口写进对方的配置文件 —— 技能里提到的那些 squirrel_* 工具才会真的存在。

所以窗口里每一家工具都把这两半的状态分开显示。

怎么打开

设置 → AI 设置 → 「外部 AI 工具…」按钮。

注意：这个窗口里的操作当场就落盘（拷技能 / 写对方配置），和设置窗口的「确定 / 取消」不是一套语义 —— 点了取消不会回滚已经做过的安装。

界面结构

顶部

控件作用
标题「把松鼠的能力接给外部 AI 工具」窗口定位
两段说明文字解释上面说的"两半"
⚠ / ✓ 开头的一行内置对话面（DSH）自己的技能状态；显示"技能未就位"时，启动一次 AI 助手就会自动落位，不用在这里管

每家工具一张卡（这是窗口主体）

工具列表包括：跨工具共用技能目录、DeepSeek Harness（桌面版）、Claude Code、Codex CLI、Cursor、豆包（Doubao）、Gemini CLI、QoderWork（国际版 / 国内版）、Trae（国际版 / 国内版）、Windsurf、WorkBuddy、自定义 / 其它工具…

每张卡里的控件都一样：

控件作用取值建议
工具名这一行接的是谁—
状态徽章技能状态：技能已就位（N 个）/ 技能部分就位 / 未落位 / 未安装 / 需要先选择目录 / 待实测先看徽章，再决定要不要装
技能目录路径技能会装到这个目录一般不改；路径不对就点「选择路径…」
「待实测」标签 + 提示这条路径没有官方文档或本机实测依据，装上不一定生效看到它就自己确认路径后再装
「选择路径…」手工指定该工具的技能目录（会记进设置）工具装在非默认位置时用
「安装技能」把技能拷进该目录；目录不存在会自动创建会弹确认，列出要写哪些、会不会覆盖
「移除技能」只删我们落的那些（带 squirrel- 前缀），同目录别人的技能不动不想接了就用它撤
「MCP 通道」勾选框勾 = 把本插件的 MCP 入口写进这个工具的配置；写入前会自动备份原配置想让对方真的能调工具，必须勾
「复制配置片段」复制一段手工配置文本，粘到没收录格式的工具（比如 Trae / 豆包）自己的配置里对方不支持自动写、或写不进去时用
卡底状态行技能目录是否存在 / MCP 是否挂上 / 配置文件路径 / 会不会新建它告诉你现在真实状态，不用猜

底部的三个按钮

控件作用
「重新探测」重新扫一遍各家工具装没装、技能在不在、MCP 挂没挂
「手工配置说明」复制完整的手工说明（解释器 / 入口脚本 / 各家路径 / 片段），适合自己动手改配置的人
「关闭」关窗（已做的安装不会回滚）

一次完整的接入流程（以 Claude Code 为例）

  1. 设置 → AI 设置 → 「外部 AI 工具…」；
  2. 先点底部「重新探测」，确认 Claude Code 那张卡是"未安装 / 未找到"还是已找到；
  3. 看技能目录路径是否正确；不对就点「选择路径…」挑到它的技能目录；
  4. 点「安装技能」→ 确认弹窗里看清"会覆盖哪些、新写哪些"→ 继续；
  5. 勾上「MCP 通道」→ 它会写入对方配置（原配置自动备份，状态行会显示已挂上 + 配置文件路径）；
  6. 点「关闭」；
  7. 去外部工具里新开一个会话，问它"这个项目里能用什么工具"，确认它读到了技能 / 工具。

做完能看见什么

  • 卡片的徽章从「技能未落位」变成「技能已就位（N 个）」；
  • MCP 那一行变成「已挂上（配置文件在下方路径）」；
  • 对方工具的配置目录里多出我们的技能目录 / 配置项。

风险与反悔

  • 「安装技能」是覆盖式的：同名目录会先删后拷。如果你在那边手动改过我们的技能内容，那些改动会丢（确认弹窗会明确列出"会覆盖 N 个"）。
  • 会写对方的配置文件（勾 MCP 时）。写之前自动备份原配置，状态行会提示备份路径；想撤可以再点「移除技能」+ 在对方配置里删掉对应条目，或用备份还原。
  • 「移除技能」只删带 squirrel- 前缀的目录，不会动同目录下别人的技能。
  • 「待实测」的几家（Cursor / Gemini CLI / Windsurf / Trae 国际版等）装上不一定生效，装之前请自己确认那个目录真的是它的技能目录。
