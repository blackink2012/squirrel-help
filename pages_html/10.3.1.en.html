There are two commands for applying materials: apply_material only creates the material network, while apply_material_to_selection builds it and assigns it straight to the current selection.

Prerequisites

  • Maya is online and the target objects exist in the scene.
  • The asset is a material asset; a texture asset without .zmetal falls back to "create a new material from the textures".

Steps

  1. Select one or more objects in Maya.
  2. Right-click the material asset in the library and choose 「为当前选择指定材质」 (Assign material to the current selection). The standalone edition dispatches this step to Maya through the command channel.
  3. The AI assistant can also call apply_material_to_selection with the asset's zasset_path.
  4. To only create the material without assigning it, call apply_material and take the material name from the returned nodes.

Verify the result

It returns status=ok with material and objects counts; the new material appears in the Maya Hypershade and the selected objects' shading network points at it.

Tips and warnings

  • Using apply_material alone looks like "nothing happened" because it only creates and never assigns; use the composite command to put a material on the selection.
  • With nothing selected the command reports an error instead of guessing a target.
  • Cross-renderer materials are converted for the current renderer; check the conversion result and attribute mapping in the returned nodes.
  • To only overwrite an existing material's parameters with the asset's values without rebuilding the network, use apply_material_params.
