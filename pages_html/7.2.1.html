.mmap 是「源材质类型 → 目标材质类型」的属性对照表，转换时逐行把源属性写到目标属性。

前置条件

  • 已安装插件，能访问插件目录下的 Assets/material_mapper_presets（灯光为 Assets/light_mapper_presets）；工具底部会直接显示当前使用的「预设路径」，以那行为准。
  • 知道源、目标材质或灯光的节点类型名（区分大小写）。

操作步骤

  1. 打开映射目录，找到形如 lambert_aiStandardSurface.mmap 的文件；文件名就是 源类型_目标类型。
  2. 打开文件，核对顶层 source_type、target_type 与 mappings；mappings 每行包含 source_attribute、target_attribute、transform、default_value，需要参数时还有 parameters。
  3. 把整个映射文件夹加载到材质转换工具：点「加载预设」（或「打开文件夹」先确认目录），工具会扫描其中所有 .mmap。
  4. 在映射表里核对行数与映射内容（材质属性 / 目标属性 / 转换函数 / 参数 / 默认值）。

结果验证

转换工具状态栏显示已加载的映射文件数量；预览表里能看到源属性、目标属性、转换函数与默认值；转换时脚本编辑器不再提示缺少映射。

提示

  • 查找顺序：根目录 A_B.mmap → B/ 子目录 → 任意一级子目录；灯光映射与材质映射物理隔离，不能混放。
  • source_attribute 留空表示只写 default_value；源属性不存在时也会退回默认值。
  • transform 填转换函数名（如 transparency_to_transmission），需要时用 parameters 传 JSON 参数。
  • .mmap 只描述属性规则，不等于「类型映射配置预设」.mlist；后者只记录哪些类型转哪些类型。
