同一个资产有多种格式时，插件用「双击预设」决定默认导入哪一个，右键菜单则允许临时指定格式。

默认格式的判定

双击导入与拖入视口共用同一处判据：

  1. 读取 Assets/preset/double_click_preset.json 中该子库的条目，未登记时取 default 段。
  2. 只有该子库的双击命令是 import 时，条目里的 option 才被当作导入格式；贴图双击是「创建材质」、HDR 是「创建环境光」，它们的 option 不参与导入格式判定。
  3. 该格式在资产可用格式里就用它；否则（包括 option 为空）退回第一个可用格式。

双击预设可在「设置 → 右键菜单」页下半部分的「双击命令」里按子库修改。

手动指定格式

  • 只有一种可用格式时，右键菜单直接显示「导入 <格式>」。
  • 有多种格式时，右键菜单显示「导入」子菜单，逐项列出格式。
  • 版本资产在「导入版本 / LOD」里先选版本与 LOD，再按需选格式。
  • 贴图、灯光、HDR 走各自的专用菜单（导入贴图、创建环境光、指定贴图等）。
  • 图片、音频、动画数据、节点树 也有各自的专属入口（见下节），它们不在「导入」格式列表里。

四类资产的专属导入入口

这四类资产不是几何 / 材质，导入入口在右键菜单最上面几项，不在格式列表里：

子库右键资产后的专属入口结果详见
图片导入为 file 节点 / 创建 imagePlane / 指定到选中材质槽 / 打开图像file 纹理节点、视图参考图、材质颜色槽上的贴图，或只看图8.5.9
音频导入到时间轴 / 导入到时间编辑器 / 导入到 Trax 编辑器 / 导入摄像机序列器；另可「转换为 WAV」声音挂到时间轴 sound 节点、Time Editor 音频片段、Trax 声音轨或序列器 shot 上8.5.10
动画数据导入动画 ▶ / 导入动画（层级映射）… / 导入到选择属性 ▶把 ATOM 关键帧写到场景里已有的层级 / 属性上8.5.11
节点树导入 ma / 添加引用 / 预览节点节点网络进场景（导入后选中新建节点），或只读预览连接关系8.5.12

几点前提：

  • 这四类都要先在左栏选中具体分类；「全部资产」、收藏夹、回收站下「从外部导入」按钮是禁用的（灰掉），空白处右键的「从外部导入」子菜单里会显示灰字「当前分类不支持从外部导入」。
  • 「指定到选中材质槽」要求场景里已选中材质节点（只认颜色槽）；没选中会提示失败。
  • 动画数据只写关键帧，不会新建骨架 / 物体 —— 场景里没有对应层级时，用「导入动画（层级映射）…」手动指定。
  • 节点树导入后视图里可能看不到东西是正常的：它只有节点网络，去 Hypershade 或节点编辑器看，导入后已自动选中新建节点。

可用格式从哪来

可用格式来自 .zasset 的 meta.json；字段缺失时扫描包内文件推断。普通贴图与 sicon、aicon 不会进入导入格式列表，HDR 除外。
