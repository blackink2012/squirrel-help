这里只列主窗口与资产网格中最常用的按键；完整表见 5.6。

窗口与布局

按键动作
Ctrl + Space最大化 / 还原光标下的区域
Ctrl + F把当前选中的卡片滚到视口中央

资产网格（图标视图）

按键动作
方向键前后 / 上下移动焦点并选中
Shift + 方向键从锚点扩展选中范围
Ctrl + 方向键只移动焦点，不改变选中
Home / End第一张 / 最后一张
PageUp / PageDown翻一屏
Ctrl + A全选
Ctrl + C复制选中资产
空格围绕鼠标弹出导入 / 引用 / 应用 / 转换十字菜单
直接敲字母或数字按名称首字母跳转
Backspace退掉一个已敲的跳转字母
Ctrl + 滚轮缩放卡片

鼠标

操作动作
Ctrl + 单击切换单项选中
Shift + 单击连续范围加选
空白拖动框选
双击卡片执行该子库的双击预设
右键卡片打开资产菜单
Ctrl + 指向音频卡片自动播放试听

搜索与媒体检索

操作动作
搜索框内回车执行关键词 / AI 搜索（看「AI 搜索」是否勾选）
点搜索框右侧 ✕取消当前搜索 / 标签筛选 / 图片或音视频检索，恢复当前分类全部资产
点搜索框里的查询缩略图 / 媒体标记取消这次媒体搜索

结果验证

  • 按 Ctrl + Space，光标所在区域最大化；再按一次还原。
  • 点进网格后按方向键，焦点框移动；Ctrl + A 后批量操作栏出现。

提示

  • 当前代码中注册为应用级快捷键的只有 Ctrl + Space；其余是资产网格内的按键处理。
  • 输入框获得焦点时，方向键归输入框；先点一下网格再使用键盘导航。
