Quick tools have three run paths: the toolbar menu, the AI command quicktool_run, and the script browser or Script Editor; all three run the same script in quicktools/.

Prerequisites

  • Tools that read or write the Maya scene must run inside Maya; the standalone edition dispatches them to an online Maya automatically.
  • 图像格式转换工具.py and 批量镜像复制.py are pure file tools and can run locally.

Path 1: the UI menu

  1. Click 「快捷工具」 (Quick tools) in the main window toolbar.
  2. Choose a tool entry and follow the page instructions once its window opens.

Path 2: the command channel

  1. Call quicktool_run; without name it only returns the script list (including entry points and whether a first-class command already covers it).
  2. Pass name (with or without .py) to run it, and optionally params as arguments.
  3. Add dry_run=true first to see which script and entry would be called without running it.
  4. name only accepts a bare file name inside quicktools/; path separators and .. are rejected.

When a dedicated command exists, prefer it: hdr_to_zasset, model_to_zasset, pbr_to_zasset, convert_image_format, mirror_copy, convert_material, convert_import, material_conversion_info.

Path 3: script browser / Script Editor

  • The script browser scans script_assets/ and extra script roots by default; adding the quicktools/ directory as an extra script root lets you run them there (a general capability, not specially registered for quick tools).
  • You can also run a .py directly in the Maya Script Editor, which is equivalent to running it as __main__.

Entry resolution order

The menu and the command channel behave the same: main() → run() → run once as __main__ when the source contains if __name__ == "__main__". When only main / run exists the module body is not executed again, so top-level side effects never run twice.

Verify the result

  • Menu path: the tool window appears.
  • Command path: it returns status: ok, entry and opened: true; for GUI tools this only means the window opened, not that the work finished.
  • Script browser: the status bar shows success / failure and the elapsed time.

Notes

  • The menu calls main() / run() without arguments; scripts that need arguments must go through the command channel or "run with parameters".
  • After the command channel returns, a GUI tool is still waiting for user interaction; do not treat that as a finished task.
