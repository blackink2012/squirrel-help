The AI chat surface setting decides whether the dsh chat panel docks inside Maya or opens in the system browser when 「AI 助手」 (AI assistant) is clicked.

Effect

It chooses how the dsh front end is hosted.

Values and default

  • The checkbox 「在 Maya 内嵌 AI 对话面（取消则用系统浏览器打开）」 (embed the AI chat surface in Maya; uncheck to open it in the system browser) is checked by default.
  • Checked: dsh docks into Maya as a panel on the right.
  • Unchecked: the system default browser opens it and the plug-in creates no panel.

dsh release track (stable / early access)

The same group has a 「版本轨」 (Release track) dropdown that decides which dsh the next one-click install fetches:

  • Stable track (default): installs the pinned version verified with the plug-in, so problems find a backstop; recommended.
  • Early access track: clicking 「一键安装」 (One-click install) queries the latest version on npm and installs that exact version, pinned;

it never auto-upgrades afterwards. That version is unverified, and individual tool behavior may differ.

An early-access install first lands in a staging directory and replaces the current one only after verification, so a failure never damages the installed stable version. Switching the dropdown itself never changes an already installed dsh; installing the new version still needs another one-click install. If the early-access version misbehaves, switch the track back to 「稳定轨」 (Stable track) and click one-click install again to recover.

Scope

  • Both modes start the same dsh front end with identical sessions, skills and tool calls.
  • The embedded panel takes space on the right of the Maya main window; the browser mode suits a second screen.
  • The panel or tab title automatically carries the current scene name so it is easy to tell apart from your own dsh.
  • Changes apply the next time 「AI 助手」 (AI assistant) is clicked; no restart is needed.

When to change it

  • To chat while watching the viewport: keep it embedded.
  • Two-screen work, or when the panel should not compress the Maya layout: uncheck and use the browser.

Verify the result

  • Click AI 工具 (AI tools) → AI 助手 (AI assistant) in the main window and the chat surface appears in the chosen mode.

Tips

Tip: this only decides where the chat surface opens and never installs dsh; when it is missing follow "Install guide when dsh is missing".

Tip: the Settings window is the only place to switch this; the 「AI 工具」 (AI tools) menu does not offer it.
