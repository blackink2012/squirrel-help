「应用材质参数」 (Apply material parameters) only writes the asset's attribute values into the selected material nodes in the scene; it never creates or replaces a material.

Prerequisites

  • One or more material nodes (shaders) are selected in Maya.
  • The material asset contains .zmetal; otherwise it falls back to the material network in .ma/.mb.

Steps

  1. Select the target material node in the Hypershade or the viewport.
  2. Right-click the material asset and choose 「应用材质参数」 (Apply material parameters).
  3. The plug-in writes depending on the case:
    • Same type as the source material: the serialized attributes are copied directly.
    • Different type: values are mapped through the .mmap files in Assets/material_mapper_presets/ before writing.
  4. Afterwards the modified material nodes are selected.

Verify the result

  • The target material's attribute values are updated.
  • Textures and upstream nodes are reconnected per the mapping.
  • The Script Editor reports 「已应用材质参数到 N 个材质」 (applied material parameters to N materials).

Tips

  • With no material node selected it reports 「请先在场景中选中要应用参数的材质节点」 (select the material nodes to receive parameters first).
  • When the asset holds no material data it reports 「该资产不含材质数据（.zmetal）」 (this asset contains no material data (.zmetal)).
  • With no usable mapping path it reports 「未应用任何参数（目标材质类型缺少对应的映射文件）」 (nothing applied; the target material type has no mapping file).
  • This keeps the target material's node type and name and only changes attributes and connections.
