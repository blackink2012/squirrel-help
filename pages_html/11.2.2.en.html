Interface scaling decides how much everything is enlarged on top of the base font size; the anchor only decides which DPI basis the Automatic step uses.

Effect

It uniformly enlarges the plug-in interface's text, icons and spacing to fit different resolutions and system scaling.

Values and defaults

  • Interface scaling: Automatic (default), 100%, 125%, 150%, 175%, 200%.
  • Scaling anchor: Follow system scaling (default) or follow pixel density. The anchor only works in the Automatic step and is greyed out for manual steps.
  • Automatic rules: when the system scaling is already reflected in Qt's device pixel ratio (above 1.05) no extra enlargement happens; otherwise Follow system scaling uses logical DPI ÷ 96 and Follow pixel density uses physical DPI ÷ 96, clamped to 1.0–2.0.

Scope

  • Effective font size = base font size × scale factor; icons, dialogs and toolbars follow.
  • When the scaling step changes the main window resizes by the old and new ratios so content is not squeezed out.
  • Only the plug-in interface is affected, never Maya's own interface or viewport display.
  • It applies after 「应用」 (Apply) or 「确定」 (OK); no restart is needed.

When to change it

  • On a high-DPI screen where the interface is too small: try Automatic first, then a fixed step if that is still not right.
  • To match system scaling like Photoshop or a browser: choose Follow system scaling as the anchor.
  • A high-DPI screen with 100% system scaling that should feel larger: choose Follow pixel density as the anchor.
  • With a manual step the anchor plays no part in the calculation.

Tips

Tip: font size and scaling multiply, so the 「有效字号」 (effective font size) next to the slider is the clearest guide.

Tip: with scaling too high a window can exceed the screen; lower the base font size before picking a step.
