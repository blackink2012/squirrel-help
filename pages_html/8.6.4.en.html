Day to day only incremental syncing is needed: only added, changed and deleted rows are re-embedded. A full rebuild is reserved for a model change, a damaged index or a format upgrade.

Syncs that happen automatically

  • Opening or switching an asset library warms up its text index in the background, and search never waits for it.
  • A search performs one incremental sync first; repeated syncing of the same state never touches the model.
  • The image index refreshes only when the library is newer than the index; it is created cold on the first search by image.

Manual syncing

Settings → AI 设置 (AI settings) → 向量索引维护 (Vector index maintenance) has two buttons: 「更新向量」 (Update vectors) for incremental and 「重建全部向量索引」 (Rebuild all vector indexes) for full rebuilds; the group's description states that it covers the help library, the Maya documentation library and the current asset library's text / image / audio / video vector indexes.

The command line works too:

  1. Text index (incremental): python tools\asset_index.py --sync.
  2. Text index (full): python tools\asset_index.py --rebuild.
  3. Image index (incremental): python tools\asset_vision_encode.py sync --library "<library root>".
  4. Image index (full): add --rebuild to the command above.
  5. The index_sync command also works, with kind set to materials, images or both; rebuild only affects the image index.

Verify the result

After syncing, check the entry count and update time with asset_semantic_status or python tools\asset_index.py --status; --verify checks consistency.

Tips and warnings

  • The rebuild flag of index_sync only applies to the image index; to rebuild text fully use python tools\asset_index.py --rebuild.
  • Never use --limit on the image sync as sampling, because it trims the index to the first N entries.
  • With a fresh lock on the index directory, search skips syncing to avoid blocking; retry once the other side finishes.
