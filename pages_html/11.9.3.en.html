Default categories are the sub-category folders created automatically when a sub-library is initialized, written as id name.

What it does

It is the multi-line text box in the middle right of Settings → Sub-libraries and categories. Each line is one category: the first part is the folder name (id), the second part is the display name, separated by a space, for example AAAcustom 自定义.

Values and defaults

The factory value lives in default_sub_categories in config.json:

  • Materials, models, lights, scenes, HDR, animation, images, audio, animation data, node tree: AAAcustom 自定义
  • Textures: AAAcustom 自定义贴图

Scope of effect

  • It is used to create folders only on first run, or when the sub-library root has no sub-category folder at all.
  • Existing category folders are neither deleted nor recreated.
  • Each sub-library root also gets AAAcustom (custom) added automatically, so there is always a category that can hold assets.

Steps

  1. Open Settings → Sub-libraries and categories and select a sub-library.
  2. Edit the lines under Default category list (one per line, format: id name).
  3. Click Apply or OK.

Verify the result

Open a new library that has not been initialized yet: the category folders listed here should appear under the sub-library with the matching display names.

When to change it

When you are preparing to create several new libraries from the same configuration and want each of them to start with fixed categories. For libraries that already exist, add and remove categories through category management instead of editing this list.

Tips

The id becomes a folder name on disk, so avoid special characters. Changing an id does not rename an existing folder.
