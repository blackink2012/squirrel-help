One-line summary: when the interface is dragged into a mess, panels are closed, or you want another properties / preview panel, come here — it is both the layout's main entry and its fallback.

How to open it

  1. Find the grid-like icon on the top toolbar (tooltip "Panels and layout"), left of the dropdown arrow;
  2. Click to open the menu (no prior selection needed; it works on any tab).

Item-by-item details

The menu has 11 items in total (including New panel and its 8 sub-items).

Menu itemEffectPrerequisiteWhat happens on clickNotes
New panel ▶Create another panel of a given typeNoneExpands 8 sub-items (next section); after choosing a type it opens as a floating windowSeveral panels of the same type can be open at once; to dock a floating window back, drag it onto the main interface
Reset layoutRestores the default layoutNoneExisting areas are cleared and rebuilt by default into the three columns "navigation / assets / properties and preview"Cannot be undone; your custom splits, ratios and floating positions are lost; asset library data is unaffected
Unlock layout (reads "Unlock layout" when checked, otherwise "Lock layout")Locking forbids dragging / splitting / closing areasNoneThe checked state toggles immediately; the menu rebuilds its text and icon from the current state each time it opensChecked = locked; areas still work while locked, only layout changes are blocked; Reset layout still works while locked

Submenu: New panel ▶

The submenu has 8 items: the first 7 are panel types and the last is an empty area.

Sub-itemDescription
NavigationCreates a left navigation panel (Category / Project / Favorites tabs plus the category tree)
AssetsCreates a center asset grid
PropertiesCreates a properties panel (fields / tags / notes)
PreviewCreates a preview panel (thumbnail and action buttons)
AI assistantCreates an AI assistant area (opens / closes the dsh chat panel)
AI search preview assetsCreates an "AI search preview assets" panel (chat-style natural language search)
Script browserCreates a script browser panel (browse / run script assets)
New areaCreates an empty area whose panel type you pick later from the area header menu

Submenu items always open as a torn-off floating window and do not dock to the main interface; to dock one back, drag it onto the edge of the main interface (this uses Qt's own docking mechanism).

Beginner pitfalls

  • A panel was closed / the properties panel is missing: no need to reopen the plug-in. New panel → Properties restores one immediately; if the whole layout is a mess, use Reset layout.
  • Regretted clicking "Reset layout": there is no undo. The reset rebuilds areas, so previous ratios, splits and torn-off windows are gone — you must arrange them again. Layout saving and restoring are covered in 3.2.5.
  • Areas will not drag or split: the layout is probably locked; check whether the menu item reads "Unlock layout" (= currently locked) and click it, see 3.2.4.
  • Thinking "Unlock layout" means "click to lock": it is the opposite. The menu text says what will happen when you click it: "Unlock layout" means it is locked right now.
