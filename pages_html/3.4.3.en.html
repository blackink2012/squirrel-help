The last step is putting a library asset into Maya: double-click to import with the preset, or right-click to choose a specific format and import method.

Steps

  1. Find the asset you just organized in the library and select it.
  2. Double-click the card to run that sub-library's double-click preset; models import ma by default and materials import zmetal.
  3. To pick a format or import method, right-click the card and choose 「导入」 (Import) plus a specific format at the top of the menu; when several formats exist, pick one from the submenu.
  4. For material assets with an object selected, right-click and choose 「应用材质」 (Apply material) to apply the material network to the selected object.
  5. After importing, confirm the new object in the Maya viewport and Outliner; transform it directly in Maya when it needs to be moved.

Verify the result

  • A new root node appears in the Outliner and the imported model or material is visible in the viewport.
  • After importing a material asset, the complete shading network appears in the Hypershade.
  • After a double-click or context-menu import, the Script Editor shows the matching import log.
  • If an import fails, the Script Editor reports the error, which helps you check the format and dependencies.

Tips

  • Models, dynamics and scenes snap to the surface under the cursor when dragged into the viewport, which is better for placement than a double-click (see 3.3.5).
  • Images, audio, animation data and node trees behave differently from geometry assets on double-click: images create a file node, audio goes to the timeline, animation data uses hierarchy mapping and node trees import ma; see 3.3.1.
  • .zmetal records the complete material network, so it can be rebuilt even when the original Maya file is gone.
  • If textures are missing or materials do not match, first check that the asset is complete, then see the import troubleshooting chapter.
