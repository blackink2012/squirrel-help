A sub-library without its own double-click configuration does not break: it follows the default section of double_click_preset.json.

Effect

Double-click presets are stored per sub-library. Lookup order: the sub-library's own section, then default, and when default is missing too it counts as 「无操作」 (None).

Values and defaults

  • The factory default section is {"cmd": "import", "option": ""}, that is "import with an automatic format".
  • Unregistered custom sub-libraries, and custom top-level categories without a type field, all use this section.
  • Sub-libraries that are explicitly registered (even when the choice is 「无操作」 (None)) follow their own configuration and never fall back.

Scope

  • A custom sub-library imports on double-click by default instead of doing nothing.
  • With option empty the import format is the asset's first available format; when the asset has no importable format that double-click does nothing.
  • When the saved command is not in the sub-library's available list (for example leftover configuration after a rename), the interface falls back to 「无操作」 (None).

When to change it

To give a custom sub-library a specific double-click action, select it in Settings and configure it directly; the result is written into its own section and overrides default.

Verify the result

Create a new custom sub-library and apply settings; double-clicking an asset inside should run "import". If nothing happens, first check whether that sub-library was explicitly set to 「无操作」 (None).

Tips

default is a fallback, not a place to configure one specific sub-library; to change specific behavior, select that sub-library on the left and edit it there.
