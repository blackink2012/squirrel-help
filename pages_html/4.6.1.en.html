Edit an asset's display name, tags and notes in the properties panel on the right; these fields decide whether keyword and semantic search can find the asset.

Prerequisites

  • An asset is selected in the grid.
  • The fields to change are visible in the properties panel; an empty note shows a hint that it can be edited from the context menu.

Steps

  1. Select the asset; the properties panel on the right shows name, type, category, format, tags and notes.
  2. Enter edit mode: click the edit button in the title row of the properties panel, or right-click a property value or empty space and choose 「编辑」 (Edit).
  3. Change 「名称」 (Name). This is the display name (name_cn), not the .zasset folder name.
  4. Change tags: click 「+ 添加标签」 (+ Add tag), type a new tag in the dialog or click a common tag to add it; click ✖ on a tag to remove it.
  5. Change notes: write the description in the 「注释」 (Notes) box.
  6. Click save (✓) to apply or cancel (✕) to discard; clicking outside the panel while editing also applies the changes.

Verify the result

  • The grid card title updates to the new display name immediately.
  • The properties panel shows the new tags and notes.
  • Searching by the new name or tag finds the asset.
提示

Tag chips in display mode can be clicked to filter directly, and Ctrl selects several; no edit mode needed.

警告

Do not rename .zasset folders in Explorer. When the file name must change, use 「批量重命名」 (Batch rename) and choose 「文件名」 (File name) as the target.
