When an asset has several formats, the double-click preset decides which one imports by default, while the context menu lets you pick a format for one occasion.

How the default format is decided

Double-click import and drag-into-viewport share one rule:

  1. Read that sub-library's entry in Assets/preset/double_click_preset.json, falling back to the default section when it is not registered.
  2. Only when that sub-library's double-click command is import is the entry's option treated as an import format; textures double-click to "create material" and HDR to "create environment light", so their option never decides an import format.
  3. If that format is among the asset's available formats it is used; otherwise (including an empty option) it falls back to the first available format.

The double-click presets can be changed per sub-library in Settings → 右键菜单 (Context menu) → 双击命令 (Double-click command).

Choosing a format manually

  • With only one available format the context menu shows 「导入 <format>」 (Import <format>) directly.
  • With several formats the context menu shows an 「导入」 (Import) submenu listing each format.
  • Versioned assets go through 「导入版本 / LOD」 (Import version / LOD), choosing the version and LOD first and the format afterwards.
  • Textures, lights and HDR use their own menus (import texture, create environment light, assign texture and so on).
  • Images, audio, animation data and node trees also have their own entries (see the next section) and are not in the import format list.

The four asset types with dedicated import entries

These four are not geometry or materials, and their entries are the top items of the context menu, not the format list:

A few preconditions:

  • All four require a specific category selected in the left column; under 「全部资产」 (All assets), favorites or the recycle bin the 「从外部导入」 (Import from Files) button is disabled (greyed out), and the empty-space context menu shows a grey line: 「当前分类不支持从外部导入」 (this category does not support importing from files).
  • 「指定到选中材质槽」 (Assign to selected material slot) needs a material node selected in the scene (only the color slot is recognized); without a selection it reports a failure.
  • Animation data only writes keyframes and never creates skeletons or objects — when the scene lacks the matching hierarchy, use 「导入动画（层级映射）…」 (Import animation (hierarchy mapping)…) to point at it manually.
  • Seeing nothing in the viewport after importing a node tree is normal: it contains only a node network, so look in the Hypershade or Node Editor; the newly created nodes are already selected.

Where available formats come from

Available formats come from the .zasset's meta.json; when the fields are missing the files inside the package are scanned. Ordinary textures, sicon and aicon never enter the import format list, with HDR as the exception.
