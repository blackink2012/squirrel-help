插件版从 Maya 工具架「自定义」分类或状态行图标打开；独立版从开始菜单、桌面快捷方式或主程序打开。

Maya 插件版

  1. 打开 Maya，等待启动完成。
  2. 在工具架顶部切到「自定义（Custom）」分类，点击「松鼠资产管家」按钮。
  3. 或点击 Maya 状态行右侧的松鼠图标。
  4. 也可以在脚本编辑器执行：
from squirrel_asset_manager.ui.main_window import MaterialLibraryWindow
MaterialLibraryWindow.show_window()

插件没有单独注册 Maya 菜单项；工具架、状态行和脚本就是全部入口。同一个 Maya 里重复调用只会召回已有窗口，不会开第二个。

独立版 / EXE

  • 开始菜单：Squirrel Asset Manager。
  • 桌面快捷方式：Squirrel Asset Manager。
  • 直接运行安装目录下的 SquirrelAssetManager.exe。
  • 源码运行：双击 启动独立预览.bat，或执行 python squirrel_asset_manager\standalone_preview.py。

结果验证

  • 主窗口出现，标题包含当前版本号。
  • 左侧分类树与资产网格可见。
  • 独立版工具栏能看到 Maya 选择下拉与连接状态。

常见失败

  • 工具架没有按钮：按钮只在安装时创建一次，手动删除后不会在启动时自动补建；重新运行安装器即可再创建。安装时 Maya 正在运行但工具架尚未就绪也可能没建上，同样重装一次即可。
  • 状态行图标缺失：PySide / shiboken 导入失败；查看 Maya 脚本编辑器的输出。
  • 脚本执行报找不到模块：安装目录未加入 sys.path；重新运行安装器并勾选对应 Maya 版本以修复集成。
  • 独立版双击没反应：检查是否被杀毒软件拦截，或 runtime\python\python.exe 是否完整。
