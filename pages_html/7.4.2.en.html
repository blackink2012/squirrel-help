The light category is the lights sub-library of the asset library, holding .zlight or .ma/.mb light assets; the context menu can import them, apply parameters or convert on import.

Prerequisites

  • The current Maya has the target renderer plug-in loaded (Arnold / V-Ray / Redshift or native Maya).
  • The light asset is already in the light category.

Steps

  1. In the library go to the light category on the left.
  2. Right-click the light asset, choose 「导入」 (Import) and then a format such as .zlight or .ma.
  3. Import first builds each light for its own source renderer; when that differs from the current renderer a 「灯光与渲染器不匹配」 (light and renderer do not match) prompt asks whether to convert.
  4. To land directly on a specific type, right-click 「转换导入」 (Convert import) and choose the target light node type in the submenu.
  5. To reuse an asset's parameters on an existing light, use 「应用灯光参数到选中灯光」 (Apply light parameters to the selected light).

Verify the result

After import the light appears in the Outliner and is selected, its node type matches the current renderer or the chosen target type, and the light's illumination is visible in the render viewport.

Tips

  • Double-clicking a .zlight converts directly to the current renderer without asking; right-click 「导入」 (Import) builds first and asks afterwards.
  • The automatic conversion prompt only covers Arnold, V-Ray and Redshift.
  • Arnold has no native spot or distant light, so photometric / dome lights are used as approximations; native Maya has no dome light and uses a directional light instead.
