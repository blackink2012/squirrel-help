There is no built-in one-click rollback, so keep the old installer and reinstall manually; back up the asset library and settings before rolling back.

Rolling back the standalone edition / EXE

  1. Uninstall the current version first (user data is not deleted, see "Uninstall and leftover cleanup").
  2. Run the old installer and reinstall the same components.
  3. Restart Maya (if the Maya integration is installed), then start the standalone edition and confirm the version.

Overwriting the new version with the old installer also works, but files removed by the new version may remain; when diagnosing problems, prefer "uninstall first, then install the old version".

Checks before rolling back

  • The Maya versions supported by the old release match your current Maya.
  • The asset library and settings are backed up, and the license file or activation code is available.

Verify the result

  • The version number is back at the target version.
  • The library still loads and favorites and tags are intact.
  • The Maya entry points and the license state are normal.

Common failures

  • The old version cannot read the new library layout: the library format may have been upgraded; back up before rolling back (compatibility range to be confirmed).
  • Version mismatch: the old package does not include your Maya version, so the plug-in cannot load.
  • The license does not cover the old version: a license may be limited to a version range; reactivate or contact the licensor.
  • The runtime directory is deleted: do not delete the whole directory when replacing folders by hand; move the runtime directory out first.
