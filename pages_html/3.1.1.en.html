The main window is a dockable three-column layout: top toolbar, left navigation, the asset area in the middle, properties and preview on the right, and the status bar at the bottom.

Areas and responsibilities

PositionAreaResponsibility
TopTop toolbarSearch, refresh, AI tools, quick tools, panels and layout, settings, help
LeftNavigationThe three tabs 「分类 / 项目 / 收藏」 (Categories / Projects / Favorites) and the category tree
MiddleAssetsView-control row plus the asset card grid or list
Right, topPropertiesMetadata of the current asset: name, category, tags, notes
Right, middlePreviewViewing and switching thumbnails, and thumbnail operations
Right, bottomAI assistantOpen or close the dsh chat surface
BottomStatus barAsset count, current selection, search and background task progress

In the default layout the two left columns take a narrow strip and the width goes to the asset area in the middle; the right side stacks properties, preview and AI assistant vertically.

Recognizing the areas

  1. Every area has a header: the panel name on the left and function buttons (dropdown menus) on the right.
  2. The header of the asset area also holds the 「从外部导入 / 创建资产 / 面包屑 / 编辑标签 / 视图 / 排序 / 缩略图大小」 (Import from Files / Create asset / Breadcrumb / Edit tags / View / Sort / Thumbnail size) row.
  3. Drag the gap between areas to change width and height; drag an area header to dock or float it.

Verify the result

  • Selecting an asset card updates both 「属性」 (Properties) and 「预览」 (Preview) on the right.
  • Clicking the collapse button on the left of the toolbar folds the left column into a narrow icon strip; click again to expand it.

Tips

  • Areas can be split, closed and torn off; if the layout gets messy, restore it with 「面板与布局 → 重置布局」 (Panels and layout → Reset layout) in the toolbar.
  • The layout and window size are saved automatically and come back the same next time (see 3.2.5).
