「恢复默认设置」把设置窗口里的大部分可编辑项退回出厂值，但不会立即写盘，也不会删除资产库文件。

前置条件

  • 已打开「设置」窗口，并确认没有尚未保存、需要保留的改动。

操作步骤

  1. 点击窗口左下角的「恢复默认设置」。
  2. 在确认框「确定要恢复所有设置到默认值吗？（config.json 将被重置）」中点「是」。
  3. 检查被重置的项；需要保留的重新设置。
  4. 点「应用」或「确定」写入磁盘。

会被重置的项

项目恢复为
字体大小13
界面缩放自动
缩放锚跟随系统缩放
默认视图图标网格
同名冲突处理自动重命名
贴图后缀重新读取 pbr_mapping.json
其它配置出厂几何体 / 图像扩展名与材质节点类型列表
导出默认值重新读取 export_preset.json
右键菜单重新读取 context_menu_preset.json

不会被重置的项

  • 资产库列表、默认库与库路径。
  • 贴图导入策略、依赖文件导入策略。
  • 支持格式列表 asset_file_extensions。
  • 全局大模型、API Key、AI 对话面、外部连接、外部 AI 工具。
  • 界面语言、外观主题、拖放吸附、缩略图输出尺寸。
  • 授权状态。

想要「恢复出厂」：用「还原预设」

上面这个按钮只重置一部分控件、点了「应用 / 确定」才落盘。如果想把整套界面偏好一次恢复成刚装好时的样子，用：

设置 → 常规 → 设置预设 → 还原预设

项目行为
范围app_settings.json 里的全部界面偏好：字号、缩放、语言、配色、默认视图、缩略图尺寸、AI 模型配置、各类开关等
何时生效确认后立即写盘并生效；执行完设置窗口会自动关闭
保留API Key、资产库列表 / 默认库、授权状态
不重置Assets\preset\*.json（导出默认值 / 右键菜单 / 双击命令 / 贴图后缀 / 子库与分类）——这些要单独到对应页签恢复
预设文件本机 settings_preset.json 不会被删除，之后仍可用「导入预设」恢复
警告

导入预设和还原预设都会直接改写磁盘设置并关闭设置窗口。这是为了防止窗口里残留的旧控件值在你点「确定」时把结果盖回去——重新打开设置即可看到新值。

结果验证

  • 点「应用」后重新打开设置，上表中的值均为出厂值。
  • 资产库仍在原处，主窗口能正常浏览。
  • 用「还原预设」后，语言 / 配色 / 字号立即变化；语言等少数项需重启插件才完全生效。

提示

警告：确认框写着「config.json 将被重置」，实际只会把当前对话框收集到的项写回，不会把 export_preset.json 等预设文件改写出厂值。

提示：需要连 Assets\preset\*.json 一起回到干净状态时，先备份再删除配置文件的对应项，参见「重置」；界面偏好本身用「还原预设」即可。
