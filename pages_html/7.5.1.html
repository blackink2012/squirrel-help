图像格式转换工具用 OpenCV 读写，支持浮点 HDR/EXR 与常用 8 位格式互转，浮点转 8 位时会自动做色调映射。

支持的格式

格式扩展名数据模式说明
Radiance HDR.hdr浮点高动态范围环境图
OpenEXR.exr浮点工业级高动态范围图
PNG.png8 位无损，支持透明通道
JPEG.jpg、.jpeg8 位有损压缩，体积小
TIFF.tif、.tiff浮点或 8 位支持多种压缩
BMP.bmp8 位无压缩位图
WebP.webp8 位高压缩率
TGA.tga8 位游戏常用

输出选项

输出格式可用选项
JPEG品质 1–100，默认 95
PNG压缩级别 0–9，默认 5
TIFF压缩方式 NONE / LZW / DEFLATE，默认 LZW
EXR压缩方式，默认 ZIP
HDR / 其他无额外选项

使用与验证

  1. 在工具里选择文件或文件夹，设置输出格式与选项。
  2. 点「开始转换」，日志显示每个文件的处理结果。
  3. 转换完成后到输出目录确认文件存在、扩展名正确、能被 Maya 的 file 节点读取。

提示

  • 依赖 opencv-python 与 numpy；imageio 不是必需，但能改善 EXR 兼容性。
  • TIFF 可以保留浮点数据，也可以输出 8 位；选了 TIFF 后按用途决定压缩方式即可。
  • 从 HDR/EXR 转 PNG/JPEG 时按 Reinhard 压缩并做 2.2 gamma，只适合预览或缩略图。
  • 需要保留完整动态范围时，输出仍选 .exr 或 .hdr。
