One-line summary: right-clicking an audio asset card in the asset grid opens this menu. Music has four "places to go", and the top four rows are those targets; the fifth row converts the audio to WAV ahead of time.

How to open it

  1. Left Category tab → click Audio or any category under it;
  2. In the center asset grid, right-click any audio card.

The audio menu has no import, add reference, update thumbnail, update asset, format conversion or preview node — audio only enters Maya through the four routes above; there is no "import geometry" for it.

Where the four import targets put the music

Sub-itemWhere the music ends upTypical use

Notes specific to this sub-library

  • Maya only accepts wav / aiff: for mp3, flac, m4a and the like, clicking any import item first converts a WAV copy locally and then imports it — so Convert to WAV is optional, it only does that step early (imports are faster afterwards).
  • "Convert to WAV" adds no card: the WAV copy lives in the category cache, so the grid still shows one card. Do not expect to find it in the library.
  • First-frame alignment uses the current frame: import to timeline / time editor / sequencer all mean "current frame = audio first frame", so set the timeline before clicking.
  • No update thumbnail / update asset: audio is a single file, so replacing the music means re-importing.
