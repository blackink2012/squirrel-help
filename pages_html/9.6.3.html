脚本支持直接运行、带参数运行、作为模块导入，以及加载到 Maya 脚本编辑器。

用途

同一份脚本按不同目的使用：验证效果直接运行，需要传值时带参数运行，要在编辑器里继续修改则加载过去。

运行

  1. 选中脚本，双击、按 Enter 或点「▶ 运行」。
  2. 登记为 high 风险的脚本会先弹出确认框，默认按钮为「否」；可勾选本次会话不再提醒。
  3. Python 脚本先做语法编译检查，语法错误不会执行；MEL 通过 mel.eval 执行。
  4. 需要参数时右键选择「带参数运行…」，填写 JSON 对象，会作为 PARAMS 预置给脚本（仅 Python）。
  5. 脚本可把结果放入 RESULT，窗口会在脚本编辑器中打印其摘要。

导入与加载

  • 「导入（加载为模块）」只支持 Python：把脚本所在目录加入 sys.path，以文件主名注册进 sys.modules，并列出可用名称。MEL 不是模块，会被拒绝。
  • 「加载到脚本编辑器」按扩展名写入 Python 或 MEL 页签；目标页签已有内容时不会直接覆盖，会先询问。
  • 「生成执行命令（放工具架）…」可生成 Python / MEL 工具架按钮命令。

结果验证

  • 状态栏显示「已运行 <名称>（用时 x.xxs）」；失败时弹出可复制的报错框。
  • 脚本的 print 与 traceback 出现在 Maya 脚本编辑器历史。
  • 导入后可在脚本编辑器用 import <模块名> 使用；加载后编辑器页签出现脚本源码。

注意事项

  • 带参数运行不适用于 MEL；MEL 没有 PARAMS / RESULT 约定，关键结果请 print。
  • 独立运行版会把脚本投送到在线 Maya 执行；Maya 离线时返回「投送 Maya 失败」。
  • 高风险脚本的免提醒只在本次会话内有效。
