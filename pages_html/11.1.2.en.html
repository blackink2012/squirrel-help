「恢复默认设置」 (Restore default settings) puts most editable items in the Settings window back to factory values, but it writes nothing immediately and never deletes library files.

Prerequisites

  • The Settings window is open and no unsaved change needs keeping.

Steps

  1. Click 「恢复默认设置」 (Restore default settings) at the bottom left of the window.
  2. Click 「是」 (Yes) in the confirmation 「确定要恢复所有设置到默认值吗？（config.json 将被重置）」 (restore all settings to defaults? config.json will be reset).
  3. Check the reset items and re-apply whatever must be kept.
  4. Click 「应用」 (Apply) or 「确定」 (OK) to write to disk.

Items that are not reset

  • The library list, default library and library paths.
  • Texture import policy and dependency file import policy.
  • The supported format list asset_file_extensions.
  • The global model, API keys, AI chat surface, external connection and external AI tools.
  • Interface language, appearance theme, drag-and-drop snapping and thumbnail output size.
  • License state.

Want a "factory reset"? Use "restore preset"

The button above only resets some controls and writes nothing until you apply. To restore the whole set of interface preferences to a freshly installed state, use:

Settings → 常规 (General) → 设置预设 (Settings preset) → 还原预设 (Restore preset)

ItemBehavior
ScopeEvery interface preference in app_settings.json: font size, scaling, language, theme, default view, thumbnail size, AI model configuration, all toggles
When it takes effectWrites to disk and applies immediately after confirmation; the Settings window closes itself afterwards
KeptAPI keys, the library list / default library, license state
Not resetAssets\preset\*.json (export defaults / context menu / double-click commands / texture suffixes / sub-libraries and categories) — restore those on their own tabs
Preset fileThe local settings_preset.json is not deleted and can still be restored later with 「导入预设」 (Import preset)
警告

Importing or restoring a preset rewrites settings on disk directly and closes the Settings window. That prevents stale control values from overwriting the result when you click OK — reopen Settings to see the new values.

Verify the result

  • After clicking Apply and reopening Settings, the values in the table above are factory values.
  • The asset library is still in place and the main window browses normally.
  • After 「还原预设」 (Restore preset) the language, theme and font size change immediately; a few items such as the language need a plug-in restart to apply fully.

Tips

Warning: the confirmation says config.json will be reset, but in practice only the items collected by the current dialog are written back; preset files such as export_preset.json are not rewritten with factory values.

Tip: to also bring Assets\preset\*.json back to a clean state, back them up first and then delete the matching keys, as described in "Reset"; for interface preferences themselves 「还原预设」 (Restore preset) is enough.
