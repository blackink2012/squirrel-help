Name clashes happen at two levels: a duplicate asset name gets a number appended when added to the library, and a duplicate node name is renamed by Maya when entering the scene.

Symptoms

  • After importing an asset, name_001 appears in the grid.
  • Imported nodes in the scene carry a numeric suffix and differ from the asset's original name.
  • MCM matching or material assignment cannot find the target by name.

Causes and rules

SituationRule
Adding from files, textures, HDR or a .zassetWhen the target category already has a same-named asset, the new name gets _001, _002
Importing into the sceneBy default into an isolated namespace named after the asset (_1/_2 on clashes); this can be turned off in Settings → 常规 → 导入命名空间 (General → Import namespace), after which everything goes into the root namespace : and Maya renames duplicate nodes
Adding a referenceThe namespace uses the asset name, appending _1, _2 when it already exists
MCM name mappingWhen Maya appends a numeric suffix to a scene material, matching falls back to the name with the trailing number removed
Importing audio to the timelineA same-named sound node would be replaced, so the plug-in first gives the new sound a unique name
Importing imagesImporting the same image several times creates several file nodes, with Maya numbering the node names
Importing animation dataWritten by node name / hierarchy mapping; when names do not match nothing is written (see 5.7.1)

Steps

  1. Check the final asset name in the grid and rename it in the properties panel if needed.
  2. When the scene needs fixed names, create an isolated namespace with a Reference first and then work inside it.
  3. When a name gets an automatic suffix, check whether a same-named node or material already exists and was not cleaned up.
  4. When MCM matching fails, check the selected object's topology instead of relying on names.

Verify the result

  • The new asset name matches expectations and nothing in the grid is overwritten or lost.
  • Node names in the Outliner carry the expected namespace or number.
  • Material assignments correspond to the selected objects.

Tips

  • The plug-in never overwrites an existing asset or an existing scene node.
  • When unique names are required, clean up same-named nodes in Maya first or isolate them with a Reference.
