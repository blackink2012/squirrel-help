Window and layout

KeyAction
Ctrl + SpaceMaximize / restore the area under the cursor

Asset grid (icon view)

KeyAction
Arrow keysMove the focus back / forward / up / down and select
Shift + arrowExtend the selection from the anchor
Ctrl + arrowMove the focus only, without changing the selection

PageUp / PageDownMove one screen
Ctrl + ASelect all
Ctrl + CCopy the selected assets
SpaceOpen a cross menu at the mouse for import / reference / apply / convert
Type a letter or digitJump by the first letter of the name
BackspaceRemove one typed jump letter

Mouse

ActionEffect

Search and media search

ActionEffect
Enter in the search boxRun keyword / AI search (depending on the 「AI 搜索」 (AI search) checkbox)
Click ✕ on the right of the search boxCancel the current search / tag filter / image or audio-video search and restore all assets of the current category
Click the query thumbnail / media marker in the search boxCancel this media search

Verify the result

  • Pressing Ctrl + Space maximizes the area under the cursor; pressing it again restores it.
  • After clicking into the grid, pressing an arrow key moves the focus frame; Ctrl + A shows the batch operation bar.

Tips

  • Only Ctrl + Space is registered as an application-level shortcut in the current code; the rest are key handlers inside the asset grid.
  • While an input field has focus the arrow keys belong to that field; click the grid once before using keyboard navigation.
