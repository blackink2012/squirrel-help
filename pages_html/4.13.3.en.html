Select several objects and export them at once, one variant per selected root object. This suits assets such as "one texture set, dozens of screw or brick types".

Prerequisites

  • The Maya plug-in edition, with several objects selected in the viewport.
  • Marquee selecting collapses parent and child objects of the same level to the topmost root, and one root object counts as one variant.
  • The asset is a .zasset.

Steps

  1. Select the objects to export in the viewport.
  2. Right-click the target asset → 「更新资产」 (Update asset) → 「批量添加变体…（每个选中物体一个）」 (Batch add variants…, one per selected object).
  3. Choose a geometry format (at least one) and the thumbnail source in the export configuration, then confirm.
  4. Watch the progress dialog (cancellable): each row shows the current variant name, and with a playblast / render source the text notes that an image is being produced.

Naming rules

  • The variant name is the node's short name (namespace and hierarchy prefixes removed).
  • Duplicate names get a number appended automatically: name, name_2, name_3…

  • When the batch finishes your previous selection set is restored, so nothing on screen is lost.
  • If you cancel midway, finished variants are kept and unprocessed ones are skipped.

Verify the result

  • The closing message reads 「批量添加变体完成：成功 N 个，失败 M 个」 (batch add variants finished: N succeeded, M failed).
  • variants/ gains N <variant name>.<ext> files, plus matching .sicon files when images were produced automatically.
  • All new variant entries appear under 「导入变体 / 版本」 (Import variant / version) in the context menu.
