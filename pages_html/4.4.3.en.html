The 「属性」 (Properties) panel on the right shows the editable metadata of the current asset and lets you change fields such as the name, tags and notes directly.

Fields

FieldDescriptionEditable
NameThe asset's readable Chinese nameYes
Material type (node type)For example standardSurface, VRayMtlYes
Asset typeThe sub-library it belongs to (materials / models / textures and so on)No
CategoryThe category the asset is inNo
FormatFormat chips of the files inside the assetNo
SizeDisk space used by the assetNo
ResolutionResolution of textures and similar assetsNo
Software / renderer / color spaceMetadata recorded at export timeYes
Creation timeExport timeNo
TagsFree-form tag chips, addable and removableYes
NotesMulti-line descriptionYes

Actions

  • Click 「编辑」 (Edit) in the title row to start editing; click 「保存」 (Save) to apply or 「取消」 (Cancel) to revert.
  • While editing, clicking an asset card saves and applies the changes immediately.
  • Right-click an editable field for 「复制 / 复制 ID / 编辑」 (Copy / Copy ID / Edit); 「复制 ID」 (Copy ID) copies the asset ID from meta.json.
  • Double-click a tag chip or click 「+ 添加标签」 (+ Add tag) to open the tag dialog, where you can type a new tag or pick a common one.

Tips

  • Category and asset type are read-only in edit mode; to change the category use 「移动到」 (Move to) in the context menu.
