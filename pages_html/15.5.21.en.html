One-line summary: selecting two or more assets makes a batch bar "grow" at the right of the top toolbar, turning the most common batch actions into a row of buttons so you no longer right-click one by one.

When it appears

SituationBar
Two or more assets selected (rubber band / Ctrl+click / Shift+click, or right-click Select all)Appears
Only one asset selected, or nothing selectedHidden
After clicking Clear selectionCollapses automatically

It appears inside the top toolbar, to the right of the search box, scales in height with the font size in settings, and never squeezes out other toolbar buttons.

The bar holds six controls

ControlEffectWhat happens on clickNotes
N assets selectedA count hint only (not a button)—This is where you verify "how many did I really select"
Batch renameRenames assets in bulkOpens the batch rename window (8.12.1), renames one by one on confirm and reports "N succeeded"The naming rule is set in the window; check the preview before confirming
Batch tagsAdds / removes / overwrites tags in bulkOpens the batch tag window (8.12.2) with Add / Remove / Overwrite; writes back on confirmOverwrite clears existing tags, so choose carefully
Batch moveMoves this batch into another categoryOpens a "Choose target category" list (only categories of the current sub-library), then moves one by one and refreshesFor cross-sub-library moves use right-click Move to ▶
Batch copyCopies this batch into another categorySame as above; copies one by one after choosing the targetDoubles disk usage
Batch deleteDeletes this batchOpens a confirmation (listing the first 20 names and the total); moves to the recycle bin on confirmRestorable: recover it in the recycle bin, see 8.8.3
Clear selectionEmpties the current selectionAll cards unhighlight and the bar collapsesDoes not affect asset content

Layout: a blue count label on the left, a row of buttons in the middle (delete uses the red danger style), and the low-key Clear selection at the far right.

How it differs from right-clicking a multi-selection (important)

ActionBatch barContext menu (after multi-select)
Rename / change tags✓ has dedicated windows✗ use Edit one by one, or just use the bar
Target range for move / copyOnly the current sub-library's categoriesFull cascade of all 11 sub-libraries, cross-sub-library allowed
Delete✓ one batch delete (to the recycle bin)✓ Delete ▶ offers move to recycle bin or delete permanently
Delete permanently✗ no such entry✓ right-click Delete ▶ delete permanently

Conclusion: to shuffle things inside one sub-library the bar is handier; to move across sub-libraries or delete permanently use the context menu.

A typical usage

  1. Rubber-band select a dozen materials in the Materials category;
  2. The bar at the top right reads "12 assets selected";
  3. Click Batch tags and add an old-library migration tag;
  4. Click Batch move, choose the target category in the list and confirm;
  5. The bar collapses as the selection empties, the tree refreshes, and the assets are in the new category.

Notes and risks

  • Check the count first: before batch deleting or moving, look at the bar's "N assets selected" and the status bar to confirm nothing extra is selected.
  • Batch delete is not "delete permanently": it goes through the recycle bin and can be restored; to erase them for good use right-click Delete ▶ Delete permanently, which is irreversible.
  • Batch rename / tags write back to asset metadata: to undo, change the names / tags back (the dialogs have no bulk revert).
  • With a selection spanning categories, batch move uses the first asset's sub-library: when the selection mixes sub-libraries, the target list follows the first asset's sub-library, so use the context menu for cross-sub-library moves.
