One-line summary: the configuration window that exports scene materials into "preset files" (titled Export material as preset) for reuse on later imports.

Note on the current entry: this window's interface and logic still exist (clicking Start export really exports), but the asset context menu does not register an item for it, so it cannot be reached through normal operation. This page therefore documents from the source what the window holds and what each control does; to save presets as files today, use "Which route to take now" below.

Which route to take now

What you wantHow the current version does it
Have Create asset tick certain formats by defaultChange the export defaults: Settings → Export defaults (8.9.4), stored in export_preset.json (4.3.4.2)
Export scene materials into reusable files elsewhereUse the quick tool Material import/export (8.14.7), which writes JSON / .ma / .zmetal
Export a .zmetal inside a zassetUse Create asset with Material preset .zmetal ticked (8.10.6)

Risks and how to undo

OperationRiskUndo
Start exportSame-named files in the target directory are overwrittenConfirm the directory first; back up important files
Export allTemporary scene materials also become presetsUse export selection with only the materials you want
ScreenshotOnly grabs an image and writes nothing to the sceneNothing to undo
