One-line summary: let AI look at an asset thumbnail and suggest a name, category, tags and notes; you tick what you accept and write it into the asset metadata.

It is "describe what you see": the input is the thumbnail and the output is four metadata suggestions. That is why assets without a thumbnail cannot be analyzed (they are skipped with a message). AI only suggests; nothing is written until you tick fields and click Apply to metadata — that review step is your chance to fix mistakes.

A complete flow

  1. Select one or more assets in the grid (multi-select goes through the AI tools menu);
  2. (Multi-select) choose provider / model / output language in AI analysis configuration, keep "show a window for review and editing when done" ticked and click Start analysis;
  3. Wait for the progress bar (one asset goes straight to the results window);
  4. Review each suggestion: untick the name if it is wrong, untick the category if it is wrong, edit tags before ticking;
  5. Decide whether to tick "move into the analyzed category" if the asset should really change category;
  6. Click Apply to metadata;
  7. Check in the grid that name / tags / notes updated (moved assets appear under the new category).

What you see afterwards

  • The asset's name, category, tags and notes update per the fields you ticked.
  • Assets with "move into the analyzed category" ticked move into the matching category directory and are visible there after a refresh.
  • With several selected it applies asset by asset; the batch interface is in 8.13.4.

Risks and how to undo

  • Applying is overwrite-style: a ticked field is replaced entirely by the AI suggestion, and merging does not happen here. There is no one-click undo for a mistake — change the fields back (with a multi-selection, try a single asset first).
  • "Move into the analyzed category" moves asset files, the only operation here that changes disk location. If it moves wrongly, right-click the asset → Move to and move it back (see 8.5.15).
  • To take no risk at all, keep the review window and apply only the low-risk tags + notes fields first.
