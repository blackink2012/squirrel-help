色彩空间决定贴图数值是否被转成线性：颜色类贴图用 sRGB，法线、粗糙度、金属度等数据贴图用 Raw。

贴图类型与色彩空间

贴图类型色彩空间
baseColor / albedo / diffuse / colorsRGB
emissive / subsurface 颜色sRGB
normalRaw
roughness / metallic / ao / arm / ormRaw
height / opacity / clearcoat / specular / anisotropy / iorRaw

插件在按 PBR 贴图创建材质时，会从 Assets/preset/pbr_mapping.json 读取这些规则并自动设置 file 节点的 colorSpace。

操作步骤

  1. 用贴图资产或 PBR 贴图流程创建材质，工具按规则为每个 file 节点设置色彩空间。
  2. 在属性编辑器中选中 file 节点，核对 colorSpace 是否与上表一致。
  3. 连接 HDR 到穹顶灯时不要手动改成 sRGB；插件连接时会按 Raw 处理，导入连接时还会开启 ignoreColorSpaceFileRules。
  4. 导入资产后若发现贴图偏色，先检查 file.colorSpace，再检查是否被 Maya 的文件规则重新推导。

结果验证

颜色贴图显示为 sRGB，法线与数据贴图为 Raw；法线贴图不再发灰或偏色，粗糙度数值与源文件一致，HDR 环境亮度正常。

提示

  • 导入 .zmetal / .ma 时，插件会在改贴图路径前后保护原有 colorSpace，避免被 png/jpg 的默认规则覆盖。
  • 图像格式转换工具只转换像素与位深，不写入色彩空间元数据；HDR/EXR 转 8 位还会做色调映射。
  • 颜色贴图设成 Raw 会偏暗、过饱和；数据贴图设成 sRGB 会让法线和粗糙度失真。
