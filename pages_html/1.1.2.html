只要你的 Maya 资产需要反复查找、反复使用或多人共享，松鼠资产管家就能派上用场。

场景一：个人材质与模型库

把常用金属、布料、木材材质，以及角色、道具、家具模型收进自己的库。按子库和分类浏览，看缩略图选资产，双击或右键导入当前场景。

场景二：外部素材批量入库

把下载或制作的 PBR 贴图套件、HDR/EXR、模型文件夹批量转成 .zasset。快捷工具会按命名规则识别贴图类型、生成缩略图，省去逐个建资产的重复劳动。

场景三：跨项目复用

用「项目库」把某个项目的资产单独组织起来，项目结束后整体归档；常用资产放进收藏夹，避免每次重新翻目录。

场景四：版本与 LOD 管理

同一个资产需要多版迭代或多精度时，用版本与 LOD 保留历史版本、代理文件和不同精度，不必在硬盘上复制多份并手工命名。

场景五：跨渲染器材质转换

Arnold、V-Ray、Redshift 与 Maya 原生材质之间需要转换时，用材质映射与转换功能减少手工连节点；复杂网络仍建议转换后检查。

场景六：缩略图、AI 分类与搜索

给资产补缩略图，用 AI 分析建议分类、标签与中文名，再用关键词、标签、自然语言或图片搜索快速定位。

场景七：独立浏览与远程驱动

不想打开 Maya 时，用独立版 / EXE 浏览和搜索资产；Maya 已运行时，独立版还能通过 commandPort 把导入、导出、缩略图等操作投给 Maya。

场景八：图片、音乐与动画数据入库与声音检索

除了几何与材质，散落的参考图、背景音乐、音效、动画数据（.atom）也能收进库里：图片可以导入为 file 节点 / imagePlane、音频可以导入到时间轴 / 时间编辑器 / Trax 编辑器、动画数据可以导入动画并按层级映射到选择属性。想找「听起来像那段的音乐」时，在音乐分类下用录制系统声音搜索；想找「画面像这个的视频」时，用录屏搜索框一段画面。
