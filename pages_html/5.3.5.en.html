Right-click a light asset and choose zlight; the plug-in creates light nodes for the current renderer and copies dependencies such as HDR, IES and textures.

Prerequisites

  • A Maya scene is open and the current renderer is decided.
  • The light asset contains node.zlight.

Steps

  1. Right-click the light asset.
  2. With zlight as the only format click 「导入 zlight」 (Import zlight); with several formats expand 「导入」 (Import) and choose zlight.
  3. When the light inside belongs to another renderer, confirm the conversion as prompted; a whole batch asks only once.
  4. Wait for the light creation and dependency copying to finish.

Verify the result

  • A new light transform and shape appear in the Outliner and the new light is selected after import.
  • The light type matches the current renderer; color, intensity, exposure, color temperature and so on have been written.
  • The Script Editor reports 「已创建 N 个灯光」 (created N lights) and dependencies are written per the import policy.

Tips

  • Cross-renderer conversion only supports Arnold, V-Ray and Redshift; native Maya lights are not converted.
  • zlight converts directly into the current renderer's matching light by default; the standalone edition first creates it for the source renderer and then asks whether to convert.
  • When importing formats such as ma/mb that contain lights of another renderer, the whole batch asks once whether to convert.
  • Lights without a mapping path stay as they are, with only the log 「无 … 映射路径，保留原灯光」 (no mapping path for …, keeping the original light).
  • To apply only the parameters onto an existing light in the scene, use 「应用灯光参数到选中灯光」 (Apply light parameters to the selected light).
