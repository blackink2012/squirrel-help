Semantic search and search by image rely on a local index maintained per asset library; confirm that the AI dependencies and the index are usable before troubleshooting search results.

Search-related settings

SettingWhereDefaultEffect
AI searchCheckbox on the right of the search boxOnWhen off, typing filters by plain keywords and the image-search buttons are hidden; the choice is remembered
ai_search_use_globalModel configuration in the AI search dialogOffWhen on, AI search may use the global model from Settings → AI (AI) for intent analysis
ai_asset_semanticConfiguration keyOnMaster switch for asset-library semantic retrieval; off is the same as having no semantic capability
ai_asset_semantic_syncConfiguration keyOnIncrementally syncs the index automatically during search
ai_asset_index_dirConfiguration keyEmptyEmpty means the index lives in the library's .squirrel_ai_index; a local directory makes each library use its own sub-directory
注意

The three ai_asset_* keys are configuration-file entries and are not visible controls in the Settings window today; use "AI features and dependencies" below to install and check the matching dependencies.

Inspecting and repairing the index

  1. Open Settings → AI → AI 功能与依赖 (AI features and dependencies).
  2. Click 「AI 依赖检查」 (AI dependency check) to generate a report covering the asset-library index and the image index; it opens in Notepad.
  3. When dependencies are missing click 「一键安装 AI 功能与依赖」 (One-click install of AI features and dependencies) and follow the steps to add Ollama, the embedding models, the index and the optional sidecar.
  4. The command asset_semantic_status also shows the index entry count, dimensions, model, index directory, last sync and the reason it is unavailable.
  5. When the index lags or is missing, sync it with index_sync: kind=materials runs the incremental text index, kind=images runs the image index (which can be rebuilt fully) and both does both.

How it runs

  • The index is kept per library, and switching libraries warms up that library's index in the background; while warming up, search uses lexical results first and switches to semantic results when ready.
  • Search performs lazy syncing and does not rescan the same library repeatedly within a short time; when no index exists, search degrades to lexical search.

Verify the result

  • asset_semantic_status reports the index as usable with the right entry count and model.
  • During semantic search the status bar shows 「本地嵌入」 (local embedding) and a duration in milliseconds, meaning the local index was used.
  • When the image index is usable, search by image reports 「图像向量检索命中」 (image vector hits).
提示

The index is derived data and can safely be rebuilt; when several people share an asset library, point the index root at a local directory on each machine so the indexes do not overwrite each other. Changes to the index directory take effect after reopening the plug-in window.
