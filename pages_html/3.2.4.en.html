Locking the layout prevents accidental drags: once locked, areas cannot be dragged around or pulled out into floating windows, while split and close remain available in the menu.

Locking

  1. Click 「面板与布局」 (Panels and layout) in the toolbar.
  2. Check 「锁定布局」 (Lock layout) at the bottom of the menu.
  3. The next time the menu opens the item reads 「解锁布局」 (Unlock layout), meaning the layout is locked.

Unlocking

  1. Click 「面板与布局」 (Panels and layout).
  2. Click 「解锁布局」 (Unlock layout); areas can be dragged and pulled out again.

Behavior while locked

ActionWhile locked
Drag an area header to move itNot available
Drag an area out into a floating windowNot available
Area menu 「撕下」 (Tear off)Still available
Split, merge or close an areaStill available
Drag the gap between areas to resizeNot available

A floating area is not affected by the lock: it can still be moved and docked back into the main window.

Verify the result

  • While locked, holding an area header and dragging no longer changes the layout.
  • After unlocking, the same drag works again.
  • The lock state is saved, and the next start is still locked.

Tips

  • Locking only constrains mouse dragging; it does not prevent layout changes through menus.
  • If the layout is so messed up it cannot be restored, use 「重置布局」 (Reset layout) to return to the default layout (see 3.2.5).
