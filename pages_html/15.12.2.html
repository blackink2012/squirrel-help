一句话定位：一次给多个资产加标签，或者把某个标签从一批资产上一起摘掉。

怎么打开

  1. 在资产网格里多选资产（2 个以上）。
  2. 网格下方「批量操作栏」→「批量标签」。
  3. 弹出窗口，标题「批量标签管理 (N 个资产)」。

单资产改标签用属性面板，不需要这个窗口。

控件逐项

控件类型作用建议取值填错会怎样
添加标签单选（默认）给选中资产追加标签统一打分类标签时用已有同名标签的资产不会重复加
删除标签单选从选中资产上移除标签清理错误/过期标签删掉的标签无法自动恢复，只能再加回来
手动输入标签单行输入输入新标签，多个用英文逗号分隔短词，别带空格用中文逗号或空格分隔会被当成一个长标签
常用标签（点击选中/取消）标签芯片区当前分类的常用标签，点一下选中（高亮）再点取消优先点常用标签没有常用标签时显示「（该分类暂无常用标签）」
全选 / 取消全选次按钮一次勾上/取消全部常用标签常用标签很多时省事全选后要点「应用」才生效
操作预览只读文字告诉你「将影响 N 个资产：追加 X 个标签 / 删除 X 个标签」执行前看一眼数量数量为 0 时按钮逻辑上没意义，别硬点
取消次按钮关窗，不改——
应用主按钮执行标签增减确认预览后点立即写库，无撤销

删除模式下还会多出：

控件说明
提示「点击标签切换红色待删（执行生效）」说明红色=待删
该批资产现有的标签芯片点一下变成红色（待删），再点取消；没有可删标签时显示「（资产暂无可删除的标签）」

两种模式的区别

对比项添加标签删除标签
能选什么标签常用标签 + 手动输入（可以是不存在的标签）只能是这批资产现有的标签
高亮含义选中=待添加红色=待删除
结果每个选中资产都补上这些标签每个选中资产都去掉这些标签

一次完整操作

给一批资产加标签

  1. 多选资产 → 批量操作栏 →「批量标签」。
  2. 保持「添加标签」。
  3. 在「常用标签」里点中要加的几个（高亮），或手动输入 工业,金属（英文逗号）。
  4. 看预览：「将影响 N 个资产：追加 X 个标签」。
  5. 点「应用」，完成后提示「批量标签操作完成：成功 N 个」。

把某个标签从一批资产上摘掉

  1. 多选资产 →「批量标签」→ 切到「删除标签」。
  2. 在现有标签芯片里点要删的那个（变红=待删）。
  3. 预览应显示「将影响 N 个资产：删除 X 个标签（红色标记）」。
  4. 点「应用」。

风险与反悔

操作风险反悔
批量加标签加错标签会污染搜索/筛选（标签会参与检索）选中同一批资产，用「删除标签」把错的摘掉
批量删标签一删就是一批，且没有撤销只能凭记忆/常用标签重新加回；删前先确认预览里的数量
中文逗号分隔会被当成一个标签名的一部分删掉重加时注意用英文逗号

标签会影响搜索与筛选结果（见 4.1.5.2），批量操作前建议先小批量试一次。

出问题怎么办

现象原因处理
「常用标签」是空的该分类没配常用标签先到设置/分类里维护常用标签（4.1.6.2），或直接手动输入
加了标签但筛选不到索引/标签缓存未刷新刷新网格；必要时重建索引
删除模式里没有要删的标签这批资产本来就没标签正常现象，提示「资产暂无可删除的标签」
应用后成功数少于选中数个别资产写失败看脚本编辑器 [BatchTag] 日志，单独重试
