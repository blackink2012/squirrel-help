One-line summary: the left column decides how this export runs — which button starts it, how many assets come out, what they are called and which tags they carry.

Structure of the area

From top to bottom the left column has 6 blocks: the create asset button row → export mode → naming → thumbnail source → selected tags → common tags. The details of thumbnail source are in 8.10.4 and are not repeated here.

Naming rules in batch modes

  • In fully automatic / semi-automatic the Name placeholder becomes "name the first asset manually → later assets use their node names" and the Readable name placeholder becomes "empty for later assets".
  • In other words Name only applies to the first asset, and later assets use their own Maya node names; Readable name likewise only affects the first asset.
  • To name every asset precisely, avoid batch modes and export one at a time with Single asset.

The append-format mode

Choosing Append format from Update asset adds a notice at the top of the right column: no format is ticked by default; existing formats are marked "(exists)", where ticking means the export replaces that format file and leaving it unticked keeps it. Mode, naming and tags on the left are filled in as usual.
