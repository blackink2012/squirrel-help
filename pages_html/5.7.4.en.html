A material mismatch means the imported material belongs to another renderer, or the cross-renderer conversion has no usable mapping path, so the material does not take part in the current render.

Symptoms

  • The material node type in the Hypershade does not match the current renderer.
  • The material renders black, loses highlights, or only a default material shows.
  • The log says 「无 … 映射路径，保留原材质」 (no mapping path for …, keeping the original material).
  • The 「转换导入」 (Convert import) submenu is missing the target type.

Common causes

CauseNotes
The asset material belongs to another rendererFor example an Arnold asset imported into a V-Ray scene
The current renderer is not supportedAutomatic conversion only supports Arnold, V-Ray and Redshift
A .mmap mapping file is missingThe target type has no direct or intermediate path
The target renderer plug-in is not installedThe target material node cannot be created
Native Maya materialsNot converted automatically, kept as their original type

Steps

  1. Check the actual material node type in the Hypershade.
  2. Confirm that defaultRenderGlobals.currentRenderer matches the target renderer.
  3. Right-click the material asset and use 「转换导入」 (Convert import) to choose a target type; a type missing from the submenu has no mapping path.
  4. To sync attributes only between materials of the same type, use 「应用材质参数」 (Apply material parameters) instead of a full conversion.
  5. If the target plug-in is not installed, install and load the renderer plug-in and then convert.

Verify the result

  • The material node type matches the current renderer.
  • Renders are no longer black and textures and highlights look right.
  • The log no longer says 「无 … 映射路径」 (no mapping path).

If it still fails

  • Use 「应用材质到选中」 (Apply material to selection) to rebuild the material network and rule out leftovers from the old material.
  • Use MCM to reassign materials by topology and rule out material name mapping issues.
  • Note the source and target types and report the missing mapping path.
