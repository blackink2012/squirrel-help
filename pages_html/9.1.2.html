快捷工具有三条运行路径：工具栏菜单、AI 命令 quicktool_run、以及脚本浏览器或脚本编辑器；三者最终都执行同一份 quicktools/ 脚本。

前置条件

  • 需要读写 Maya 场景的工具必须在 Maya 内运行；独立运行版会自动把它们投送到在线 Maya。
  • 图像格式转换工具.py 与 批量镜像复制.py 是纯文件工具，可在本地执行。

方式一：界面菜单

  1. 点击主窗口工具栏的「快捷工具」。
  2. 选择工具条目，窗口打开后按页面说明操作。

方式二：命令通道

  1. 调用 quicktool_run；不传 name 时只返回脚本清单（含入口与是否已被一等公民命令覆盖）。
  2. 传入 name（可带或不带 .py）执行；可同时传 params 作为参数。
  3. 先加 dry_run=true 可只看将要调用的脚本与入口，不实际执行。
  4. name 只接受 quicktools/ 下的纯文件名，路径分隔符与 .. 会被拒绝。

已有专门命令时优先用后者：hdr_to_zasset、model_to_zasset、pbr_to_zasset、convert_image_format、mirror_copy、convert_material、convert_import、material_conversion_info。

方式三：脚本浏览器 / 脚本编辑器

  • 脚本浏览器默认扫描 script_assets/ 与额外脚本根；可把 quicktools/ 目录添加为额外脚本根后运行（通用能力，未针对快捷工具做专门登记）。
  • 也可以在 Maya 脚本编辑器中直接执行某个 .py，效果等同 __main__ 方式。

入口解析顺序

菜单与命令通道一致：main() → run() → 源码含 if __name__ == "__main__" 时以 __main__ 身份执行一次。只找到 main / run 时不会再执行模块体，避免顶层副作用跑两遍。

结果验证

  • 菜单方式：工具窗口出现。
  • 命令方式：返回 status: ok、entry 与 opened: true；GUI 工具只代表窗口已打开，不代表操作完成。
  • 脚本浏览器：状态栏显示成功 / 失败与用时。

注意事项

  • 菜单调用 main() / run() 时不传参数；需要参数的脚本请走命令通道或「带参数运行」。
  • 命令通道返回后 GUI 工具仍在等待用户操作，不要据此判断任务已完成。
