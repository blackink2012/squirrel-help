Export and import material networks from one window, in either the "full radar" or the "MA+JSON" flavor.

Purpose

Export the material networks of a scene together with textures and metadata, then restore them in another scene or on another machine and reassign them to models.

The two flavors

TabExport productsBest for
Full radar.zmetal (material network JSON), optionally .ameta metadata, .mcm object mapping and textures/Keeping the complete material network parameters, imported straight in this tool
MA+JSON.ma (material network) + .mcm (object mapping JSON), optionally .ameta and textures/When a Maya MA file is wanted, for manual review or further processing

Input and output

  • Export input: the selected models or materials in Maya, or 「导出所有」 (Export all).
  • Export output: the chosen 「工作目录」 (Working directory); when unset it prefers the current scene's directory and asks for one when the scene is unsaved. With 「创建文件夹」 (Create folders) checked each material gets its own folder.
  • Import input: for the radar flavor a .zmetal / .json; for MA+JSON a .mcm (JSON) named like the material, from which the tool finds the matching .ma; 「从文件夹导入...」 (Import from folder...) collects recursively.
  • Import output: material nodes in the current scene, assigned to the matching models according to the options.

Steps

  1. Open 快捷工具 (Quick tools) → 材质导入导出工具(材质管理) (Material import/export tool).
  2. On the full radar or MA+JSON tab set 「工作目录」 (Working directory) and 「文件名」 (File name) (when empty the selected object name, then the scene name, then MaterialData is used).
  3. Under 「导出 - 选项」 (Export options) choose export selected or export all, and check separate material files, export object mapping, export metadata, create folders and package textures as needed.
  4. Expand 「导出 - 元数据设置」 (Export metadata settings) to fill in the color space (auto-detected by default, falling back to ACEScg), category, tags and Chinese name.
  5. Click 「执行导出」 (Run export).
  6. To import, pick a file or 「从文件夹导入...」 (Import from folder...), set the import mode and options and click 「执行导入」 (Run import).

Verify the result

  • The working directory gains .zmetal or .ma / .mcm files, plus .ameta when metadata is checked and textures/ when packaging textures is checked.
  • After importing the materials appear in Maya, and with 「自动指定物体」 (Auto-assign objects) checked the models already carry them.
  • Progress details are printed in the Maya Script Editor (such as 「[材质导出] 成功」 ([material export] succeeded) and 「导入完成」 (import finished)).

Options and notes

  • Import options include 「自动指定物体」 (Auto-assign objects) (on by default), 「模糊匹配」 (Fuzzy matching) and 「拷贝纹理」 (Copy textures) (on by default); the basic settings accept a namespace, material prefix / suffix and model path prefix / suffix replacement.
  • The MA+JSON tab reminds you to make sure the scene already contains the models to assign to; prepare the target models before importing.
  • Save the scene before exporting or importing; export-selected depends on the current selection and does nothing when it is empty.
  • This tool produces material network files rather than .zasset assets; to add them to the library use the asset import flow.
