「仅导出材质」 (Export materials only) packages only material nodes and textures, skipping model meshes, caches and proxies; it is checked by default when creating an asset in the materials sub-library.

Prerequisites

  • Material nodes are selected in Maya, or objects that already carry materials.
  • At least 材质预设 .zmetal (material preset) or 材质映射 .mcm (material mapping) is checked so the material is stored with the asset.
  • Keep 贴图 textures/ (textures) when textures are needed.

Steps

  1. Check 「仅导出材质（跳过几何体/代理）」 (export materials only, skipping geometry / proxies) in the right column's 「导出选项」 (Export options). It is already checked by default for the materials sub-library.
  2. Check 材质预设 .zmetal (material preset) under material formats; also check .mcm when materials should be assigned by model matching.
  3. Keep 贴图 textures/ (textures) when textures are needed.
  4. For a snapshot of the material nodes you can additionally check Maya ASCII .ma or Maya Binary .mb; those formats still export in this mode but contain only material nodes, no mesh.
  5. Choose the thumbnail source and click 「创建资产」 (Create asset).

Verify the result

  • The .zasset contains node.zmetal (and/or node.mcm) and textures/, and no node.fbx, node.obj, node.usd, .abc or proxy files.
  • Importing the asset rebuilds the material network; a .mcm asset can assign materials by topology matching when a target model is selected.
  • If no material node was resolved this time, no material file is produced and the asset keeps only meta.json and a thumbnail.

Tips and warnings

Tip: this mode does not isolate objects automatically, so the screenshot overlay captures whatever the viewport currently shows; to give a material a preview, place a carrier with 创建模型 (Create model) first.

Tip: ma / mb are not part of the "skipped geometry": they still write files in materials-only mode, but the file contains material nodes instead of a mesh.

Warning: when entering from Update asset with materials-only checked, if no material node can be resolved from the selection the program stops before exporting and says so; creating a new asset has no such precheck, so confirm yourself that material nodes or material-carrying objects are selected.
