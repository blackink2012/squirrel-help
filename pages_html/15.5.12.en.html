One-line summary: right-clicking a node tree asset card in the asset grid opens this menu. A node tree asset stores a node network (its connections) with no geometry and no textures, so the menu looks like the models one but what gets selected after import differs.

How to open it

  1. Left Category tab → click Node tree or any category under it;
  2. In the center asset grid, right-click any node tree card.

How it differs from the models menu

Import✓ (selects the newly created nodes afterwards)✓ (selects the new content / materials afterwards)

Other common itemsSameSame

The menu structure is the same; the difference is what gets selected in the scene after import: a node tree selects the new nodes (the node difference before and after), so you can go straight to Hypershade and wire them.

Notes specific to this sub-library

  • It has no geometry: after import you may see nothing new in the viewport, because what came in is a node network — look in Hypershade or the node editor.
  • "Preview node" and "Import ma" are different: the first only opens a read-only window showing connections; the second really builds the nodes in the scene.
  • The thumbnail shows the node network: so images produced by Update thumbnail → Background render are node-graph views too; do not expect a model render.
