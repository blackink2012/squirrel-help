「AI 搜索预览资产」 (AI search preview) is a chat-style search window: you state a need, it returns keywords and result cards, and you can keep refining or add assets to the wishlist.

Prerequisites

An asset library is open; for search by image an image index or a usable vision model is also needed.

Steps

  1. Open AI 工具 (AI tools) → AI 搜索预览资产 (AI search preview).
  2. Describe the need in the bottom input box, or click 「添加图片」 (Add image) to add a reference image, or 「截图搜索」 (Screenshot search) to marquee a screen region.
  3. Click 「发送」 (Send). The window first shows 「AI 正在分析意图…」 (AI is analyzing the intent…) and then returns keyword bubbles and result cards.
  4. Keywords can be edited or deleted, and changes re-run the search; you can also type the next refinement.
  5. Right-clicking a result card offers import into Maya, locate in the library, find similar, send to AI analysis or view details; cards can be dragged straight into the viewport.
  6. To handle them later, right-click a card to add it to the wishlist on the right.

Verify the result

The result bubble shows the number found and "sorted by relevance", card thumbnails load, and the wishlist count grows.

Tips and warnings

  • 「使用全局大模型」 (Use the global model) at the top is unchecked by default, so only local vector retrieval runs; once checked, intent analysis uses the global model from Settings → AI 设置 (AI settings).
  • The settings at the top right are AI search's own model configuration, stored separately from AI analysis.
  • With no results, check the index status first instead of rewording repeatedly.
