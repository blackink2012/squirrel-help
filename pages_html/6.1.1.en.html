The export mode answers one question only: do the objects selected at once merge into one asset or does each object become its own asset, and does the program capture the thumbnail automatically or do you capture it by hand.

Mode comparison

UI optionResultThumbnailBest for
Single asset (merge into one asset, manual capture)All selected objects merge into one .zassetManual marquee each timeA combined model, a whole material set
Full-auto (each object a separate asset, automatic capture)One .zasset per objectFrame the first one manually and reuse that region automaticallyBatch organizing similar models
Semi-auto (each object a separate asset, manual capture)One .zasset per objectManual marquee every timeEvery asset needs its own framing

Single asset

Every selected DAG object is written into the same asset; the material comes from the first material node that can be resolved. This mode does not hide or isolate unselected objects automatically, so isolate the view yourself when needed (viewport isolate display, shortcut Shift+I) and restore it after capturing.

Full-auto

Each DAG object is exported separately. The program isolates the current target automatically; you position the framing and marquee the capture region for the first asset, and later assets reuse the same framing and region with the target moved to the center of the image — it never auto-frames or changes the camera distance. 「截图延迟」 (Capture delay) in the left column appears only in full-auto mode and waits for the viewport to refresh before capturing.

Semi-auto

Each object is exported separately, but every export opens the screenshot overlay so you can re-frame and capture manually. The program also isolates the current target automatically and never auto-frames.

Notes on the current version

Older help called the button 「导出资产」 (Export asset); in the current version the toolbar and dialog button are 「创建资产」 (Create asset). Older help also put naming and tags in the right column; the current left column holds "create asset + export mode + naming information + thumbnail source + tags", and the right column holds "collect linked files + per-format sections". The current interface is authoritative.

In single-asset mode, if only material nodes are selected, only the first material node is written as the material source. To give every material its own asset, use full-auto or semi-auto.
