右键材质或贴图资产选择「为当前选择指定材质」，插件会创建材质网络并赋给当前选中的物体。

前置条件

  • 已在 Maya 中选中一个或多个物体。
  • 材质资产含 .zmetal，或含带材质网络的 .ma/.mb；贴图资产需带 properties 记录。

操作步骤

  1. 在场景中选中目标物体。
  2. 右键材质或贴图资产，选择「为当前选择指定材质」。
  3. 插件按资产内容选择路径：
    • 有 .zmetal：重建节点网络，取根材质赋给选中物体。
    • 无 .zmetal 但有 .ma/.mb：导入材质网络后赋给选中物体。
    • 只有贴图：创建 openPBRSurface 并连接贴图后赋值。
  4. 等待赋值完成。

结果验证

  • 选中物体的 shadingGroup 指向新材质。
  • Hypershade 中出现对应材质节点。
  • 脚本编辑器输出「赋予材质 … → N 个物体」。

提示

  • 没有选中物体时只创建材质、不赋值，日志为「材质已创建（无选中物体，未赋予）」。
  • 同一资产含多个根材质时只取第一个可用根材质赋给整批选中物体；需要面级分配请用 MCM。
  • 贴图资产缺少 properties 时无法判断通道对应关系，赋值会终止。
