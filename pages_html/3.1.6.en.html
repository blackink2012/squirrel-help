All three are optional panels: the AI assistant handles conversation, AI search finds assets from natural language, and the script browser browses and runs scripts.

AI assistant

The AI assistant sits at the bottom of the default right-hand layout with a single toggle button. Clicking it opens the dsh web chat surface embedded in Maya; clicking again closes the panel and ends the dsh process. The button label changes to 「正在启动 AI 助手…」 (Starting the AI assistant…) or 「关闭 AI 助手」 (Close the AI assistant) depending on the state.

AI search preview

Open it from AI 工具 (AI tools) → AI 搜索预览资产 (AI search preview) in the toolbar. It is a chat-style search window: describe the asset you want in one sentence, the AI extracts keywords and matches names, tags and notes, and the results can be imported directly or located in the library.

Script browser

Run 「脚本浏览器」 (Script browser) from the 「快捷工具」 (Quick tools) menu to open a separate window; you can also assign 「脚本浏览器」 (Script browser) as the panel type of an area and use it inside the main window. It browses, searches, runs and imports scripts.

Switching and coexistence

  • Click the function button in an area header and choose 「AI 助手 / AI 搜索预览资产 / 脚本浏览器」 (AI assistant / AI search preview / Script browser) from the panel type list.
  • The same panel type can appear in several areas at once, each behaving independently.

Verify the result

  • After clicking the AI assistant button the label changes and the dsh chat surface appears or closes.
  • Typing a description in the AI search window and pressing Enter returns matching assets.

Tips

  • AI features depend on the local dsh, Ollama and the index; when unavailable the interface shows a hint and normal search and asset browsing keep working.
  • Before first use, run the AI dependency check (see 4.5.2).
