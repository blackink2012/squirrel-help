「AI 助手」 (AI assistant) is not a separate model: it docks the chat surface of the locally installed dsh (DeepSeek Harness) into Maya and lets it drive the asset library and scene through the plug-in's command surface.

What it is

  • dsh is both a chat front end and a runtime; releases no longer bundle it, and the plug-in uses the copy installed on your machine (verified version 0.2.2-rc.3).
  • The panel opens dsh's web client; inside Maya it docks to the right by default with a tab such as dsh — <scene name>, so it is easy to tell apart from a dsh you opened in a browser yourself.
  • When embedding is unavailable (for example a missing WebView component) it falls back to the system browser, and no functionality is lost.

How it connects to the plug-in

Before opening the panel the plug-in starts the local backend (broker) and registers the current Maya as an instance. The squirrel_* tools inside dsh find that instance through the broker and act on this Maya process only by default.

In addition, the bundled skill set lands in <dshHome>/skills and user-level instructions in <dshHome>/AGENTS.md, so the assistant knows to consult the help first and touch the scene afterwards.

State

The toggle recognizes exactly three states: off, starting and on. "On" means the panel is visible, the dsh service started by this process still runs, or the front end recorded in the reuse log is still alive.

Notes

The AI assistant, 「AI 搜索预览资产」 (AI search preview) and 「AI 分析缩略图」 (AI thumbnail analysis) are three independent paths: the first is a chat surface, the other two are asset retrieval and metadata suggestions, and each can be used alone.
