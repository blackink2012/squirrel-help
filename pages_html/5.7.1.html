导入失败先看脚本编辑器日志，再按「格式是否存在、授权是否有效、文件是否能读」逐项排查。

症状

  • 右键点「导入」后场景没有新增节点。
  • 日志出现「导入失败」「未知格式」「提取失败」「不含 .zmetal/.zlight/.mcm」。
  • 导入过程中弹出授权提示。
  • 「从外部导入」按钮是灰的（停在「全部资产」/ 收藏夹 / 回收站，没有目标分类）。
  • 图片 / 音频拖到视口没反应；节点树导入后场景里看不到东西；动画数据导入后模型没动。

常见原因与处理

日志或现象原因处理
[ImportExecutor] 未知格式资产内没有该格式文件，或格式名不在路由表右键菜单换一个格式；确认 .zasset 内确有对应扩展名文件
[FileImporter] 提取失败资产包内文件缺失或无法解出重新从源文件导出入库，或从备份重新导入资产
[ImportExecutor] .zasset 不含 .zmetal 文件资产由快捷工具导出，没有节点网络改用「应用材质到选中」或资产内的 ma/mb 材质
[Licensing] 功能 'import' 被拒绝授权到期或无效，导入被门控完成激活或续期后重试
fbx 无反应fbxmaya 插件未加载在 Maya 插件管理器中加载后重试
代理或体积格式没有显示对应渲染器插件未安装安装 Arnold、V-Ray 或 Redshift 后重试
「从外部导入」按钮灰掉 / 菜单里只有「当前分类不支持从外部导入」停在「全部资产」、收藏夹或回收站，没有明确目标分类先在左栏选中具体子库与分类再导入
图片 / 音频拖进视口没反应这两类是散文件，不走几何拖放管线用右键菜单：图片 →「导入为 file 节点」/「创建 imagePlane」；音频 →「导入到时间轴」等（见 8.5.9、8.5.10）
动画数据导入后动画没变场景里没有与资产对应的层级，自动映射对不上用「导入动画（层级映射）…」手动指定节点，或先选中目标层级再用「导入到选择属性」
节点树导入后场景里「看不到」节点树只有节点网络、没有几何体，这不是失败去 Hypershade / 节点编辑器看；导入后已自动选中新建节点
「指定到选中材质槽」提示失败场景里没有选中材质节点，或选中的不是材质先在 Hypershade / 视口里选中材质节点再点，或改用「导入为 file 节点」自己接线

结果验证

  • 换格式后日志出现「导入成功」，Outliner 出现新节点。
  • 授权恢复后同一操作不再弹拒绝提示。

仍不行怎么办

  1. 确认 .zasset 目录里确实有对应格式文件，且文件大小不为 0。
  2. 图片 / 音频先确认资产文件本身存在（散文件就在分类目录里），再看右键菜单用的是不是对应导入项。
  3. 换一种格式导入，判断是单个文件问题还是整条导入链路问题。
  4. 复制完整日志与资产名反馈；日志里的 traceback 能定位到具体导入器。
