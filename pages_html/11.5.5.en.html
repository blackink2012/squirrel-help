Export materials only presets, per asset type, whether geometry and proxies are skipped so only materials are packaged.

Effect

When a new export dialog or asset creation starts, 「仅导出材质（跳过几何体/代理）」 (export materials only, skipping geometry / proxies) is pre-checked.

Values and defaults

  • The checkbox 「仅导出材质（跳过几何体/代理）」 (export materials only, skipping geometry / proxies), mapped to material_only.
  • Default: checked for materials; unchecked for models, lights, textures, scenes, hdr and ani.

Scope

  • When checked, the geometry and proxy export stages are skipped and only material nodes are exported.
  • .ma / .mb can still write material nodes in this mode without exporting the associated DAG objects.
  • The animation frame mode uses the current frame and the thumbnail captures the current viewport.
  • It never changes existing assets; it is stored under the matching asset type key in Assets/preset/export_preset.json.

When to change it

  • Material library assets only need materials and textures: keep the materials default checked.
  • Model, scene or animation assets need full geometry: confirm the matching type is unchecked.
  • Only delivering materials for one occasion: check it in that export dialog rather than changing the default.

Tips

Warning: with 「仅导出材质」 (Export materials only) checked and no material nodes selected, an empty shell asset is exported; confirm that materials or material-carrying objects are selected first.

Tip: whether textures are packaged in this mode is still decided by 「收集关联文件」 (Collect linked files).
