导出预设文件就是 Assets/preset/export_preset.json，备份、换机或团队统一默认格式时直接复制这个 JSON 即可。

前置条件

  • 已按「按子库保存默认值」配置好当前机器。
  • 能访问插件安装目录下的 squirrel_asset_manager/Assets/preset/。

操作步骤

导出预设文件

  1. 找到 squirrel_asset_manager/Assets/preset/export_preset.json。
  2. 把它复制到备份目录或共享位置。
  3. 建议在文件名里带上日期或项目名，例如 export_preset_20261019.json。

导入预设文件

  1. 先关闭正在打开的导出对话框和设置窗口。
  2. 备份本机当前的 export_preset.json。
  3. 用目标文件覆盖同路径的 export_preset.json。
  4. 重新打开「创建资产」或「设置 → 导出默认值」，新默认值立即生效。

结果验证

  • 重新打开「设置 → 导出默认值」，各子库的勾选与替换后的文件一致。
  • 在对应子库打开「创建资产」，格式复选框按新默认值勾选。
  • 用文本编辑器打开 export_preset.json，能看到替换后的子库条目和布尔值。

文件结构

{
  "_default": { "ma": true, "zmetal": false },
  "materials": { "zmetal": true, "ma": true, "material_only": true },
  "models": { "ma": true, "material_only": false }
}
键作用
_default子库没有单独条目时的兜底
materials / models / lights / textures / scenes / hdr / ani / images / audio / animation / nodetree各内置子库的默认值（与 config.json 的 sub_libraries 一一对应，共 11 个）
zmetal / zmetal_merge / mcm材质节点与材质映射
ma / mb / fbx / obj / usd几何体格式
abc / arnold / vray / redshift / vrmesh缓存与代理
material_only / collect_associated / textures仅材质、收集关联、打包贴图
ani_frame_modecurrent / timeline / keyframe
delay_ms截图延迟，毫秒；2000 即 2 秒
thumb_sourcescreenshot / playblast / render

提示与警告

提示：新建资产对话框打开时才读取该文件；替换后不需要重启 Maya，重开对话框即可。

提示：AI 侧的新建资产同样读取 export_preset.json，所以这份文件也是 UI 与 AI 的共同默认值来源。

警告：JSON 格式错误时插件会打印加载失败并退回内置默认值，表现为“所有格式都没勾”。替换前先用任意 JSON 校验工具检查。

当前版本：设置窗口没有「导入预设 / 导出预设文件」按钮（2026-11-03 核实），本页的导入导出通过文件复制完成，这样最直接也最稳。

别和「导出材质为预设」混淆：插件里另有一个「导出材质为预设」对话框，作用是把场景里的材质导出成 .zmetal / JSON 预设文件，和本页的 export_preset.json（「新建资产默认勾什么」）不是一件事；而且该对话框当前没有挂到任何菜单入口（详见 8.12.3），所以在本页场景里不用找它。
