An empty shell asset is a .zasset containing only meta.json and a thumbnail, with no geometry, material or textures.

Symptoms

  • The asset appears in the grid, but opening its folder shows only meta.json and thumb.sicon, with no node.*, node.zmetal or textures/.
  • Or the export fails outright: 几何体一个文件都没导出（...） (not a single geometry file was exported).
  • formats in meta.json only lists sicon / aicon.

Common causes

CauseHow to tellFix
No content source checkedformats only has sicon / aicon and there is no textures/ or deps/Check at least one format, or keep 贴图 textures/ (textures)
"Export materials only" checked without material nodesNo node.zmetal / node.mcmSelect material nodes or objects carrying materials; uncheck it when materials-only is not needed
Geometry format checked but the selection has no meshThe log says 「找不到可导出对象」 (no exportable object found)Select models with a shape in the viewport, not empty groups or pure transforms
Format plug-in unavailableThe format's status shows 不可用 (unavailable) and the checkbox is greyed outInstall or load the plug-in, or use .ma / .mb
.ma export failednotes contains ma: 导出失败Check .mb and re-export; without .mb checked the program falls back to .mb automatically, and if that also fails see the next section

Steps

  1. Open .zasset/meta.json and check whether formats contains the expected formats.
  2. Back in Maya, confirm the selected objects really are nodes with a mesh or a material.
  3. In the export dialog check at least one content format and confirm the format status reads 已就绪 (ready).
  4. For material assets prefer 材质预设 .zmetal + 贴图 textures/; for model assets check at least Maya ASCII .ma or Maya Binary .mb.
  5. Export again. If geometry formats were checked but not one file was produced, the export stops instead of overwriting an existing asset with empty content.

If it still fails

  • Open the Maya Script Editor and search for [Export], [Export::zmetal] and [Perf] to see which format failed.
  • Try a fresh scene containing only the target object, ruling out unknown nodes or data breaking format conversion.
  • Export with only .mb checked first to confirm the geometry itself is writable, then add the other formats back one by one.
  • Whether specific format keys differ from Maya's actual plug-in names is still to be confirmed (for example abc and obj).
