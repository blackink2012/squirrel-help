One-line summary: right-clicking a lights asset card in the asset grid opens this menu. Like materials, lights have two entries: one changes lights already in the scene (apply parameters), and one imports with conversion.

How to open it

  1. Left Category tab → click Lights or any category under it;
  2. In the center asset grid, right-click any light card.

Submenu: Convert import ▶

The lights version of convert import uses its own mapping set (light_mapper_presets) and does not affect the materials one. The sample asset shows 4 items:

Sub-itemDescription
aiAreaLight (AI · restore in place)The target type equals the asset's own type, meaning no conversion, an exact rebuild as-is (the first item is always the source type)
RedshiftPhysicalLight (RS)Converts to the Redshift physical light
VRayLightRectShape (VR)Converts to the V-Ray rectangular light
areaLightConverts to the Maya native area light

How to read it: the first item marked "restore in place" means "just build it in my original type"; the rest with (RS) / (VR) are lights from other renderer families. The target list is generated dynamically from "source type → available targets", so another source light changes both the count and the contents.

Notes specific to this sub-library

  • "Apply light parameters" and "Import" are different things: the first assumes the light already exists in the scene (you selected it) and only pushes intensity / color / decay and similar; the second creates the light.
  • Lights offer no "Format conversion": lights are not geometry, so do not look for it here.
  • You may still be asked about conversion after import: even without Convert import, importing a zlight asks once when the current renderer differs — this is "build first, then ask", and answering No keeps the original type.
