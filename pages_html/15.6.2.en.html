One-line summary: right-clicking any field in the properties area opens a menu with copy / copy ID / edit, and only Edit enters an editable state.

First, a common misunderstanding: double-clicking a field no longer enters edit mode (older versions did, which caused accidental edits when you only wanted to look). Double-click has exactly one use — double-clicking a tag chip enters tag editing. The edit entry for fields is right-click, or the pencil button in the title bar (see 8.6.3).

How to open it

  1. Select an asset in the asset grid;
  2. Hover any row in the properties area (the field name, the value, even blank space);
  3. Right-click to open the menu.

Recycle bin entries open this menu too, but Edit is gray (read-only).

The items gray out automatically: no text means Copy is gray; no id means Copy ID is gray; a read-only entry means Edit is gray.

Two more conventions in edit mode:

  • The wheel hovering over the asset type / category / color space dropdowns does not change their values (to prevent accidents);
  • Clicking the asset card area (the center grid) while editing applies the current changes and leaves edit mode.

警告

Property editing changes asset metadata (the meta inside .zasset), which is lost only if the asset is deleted or overwritten; but after saving the plug-in offers no "undo this property change", so a mistake must be fixed by hand. When changing several fields at once, think it through before saving.

A typical operation: add notes and tags to an asset

  1. Select the asset → right-click the Notes row → Edit;
  2. Type the explanation in the notes box; click + Add tag and type a tag or add a common one quickly;
  3. When everything looks right click ✓ in the title bar (or click the asset card area);
  4. The panel returns to display mode with the notes and tags immediately visible; the status bar still shows this asset's name.
