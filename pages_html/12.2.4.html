提交后立刻返回 job_id，用 GET /jobs/<job_id> 查询。状态机为 queued → running → done / error / timeout / cancelled / interrupted。默认 4 个执行线程、排队上限 32、单条默认超时 60 秒；终态作业保留 1 小时、最多 200 条。排队满时返回 QUEUE_FULL，应先查 /jobs 再提交。

进度

支持进度的命令会收到可调用的 progress(percent, message, **extra)。percent 夹到 0–100，message 截到 200 字符，extra 只保留最多 8 个标量字段。进度帧最快 0.4 秒一帧，但完成时的最后一帧一定送达；progress_age_secs 表示这份进度有多旧。

取消

当前 7 条命令声明 cancel_supported=true。取消是协作式的：

阶段效果
queued真取消，命令从未派发给宿主
running 且命令查了检查点在下一个检查点停下，作业记 cancelled 并带回部分结果
running 但没查检查点停不下来，照常跑完并标 cancel_ignored

自己写的长循环应调用 cancelled() 或 cancel.raise_if_cancelled()。

警告：同步超时不等于失败。命令可能仍在 Maya 主线程执行，结果会进入迟到结果邮箱（GET /late_results）；先查邮箱，再决定是否重跑。作业历史保存在 <dsh_home>/ai_jobs.jsonl，底座重启后遗留作业标为 interrupted，不会自动重放。
