所有命令都按同一套结构调用与返回：调用方给 command_id、params 与 dry_run，底座回 status、result、error。

请求参数

字段必填说明
command_id是命令 id，以命令参考和清单里的 params_schema 为准
params否命令参数对象，键名必须来自该命令的 params_schema
dry_run否只预演、不改状态；默认 false
instance_id视入口目标实例；在 Maya 内打开的对话可省略
session_id否审计归属，写进 audit.jsonl
request_id否进度与取消的对号；异步作业由底座预先生成
allow_cross_instance否默认只操作当前绑定的实例

执行器统一签名是 executor(dry_run=False, **params)。只有声明了 progress_supported / cancel_supported 的命令才会被注入 progress / cancel 两个对象；未声明的命令收到它们会直接 TypeError。

命令返回

命令内部统一返回字典，status 取 ok、preview 或 error。preview 是 dry_run 的预览，不是失败；其余字段由各命令定义，例如 changes、moved、created_ids、warning、missing。

外层信封由 /execute 或 squirrel_execute_command 统一包装：

{"status": "ok", "result": {"status": "ok"}, "error": null}

命令内层的 status="error" 会被提升为外层错误，因此只有外层 ok 才代表真正成功。单次响应上限为 262144 字节；超限时返回 truncated: true、original_bytes 与 content_prefix，此时应改用更精确的查询（加 limit、指定字段或分批）。

提示：参数名不要猜。同名字段在不同命令里可能含义不同，以清单中的 params_schema 为唯一依据。
