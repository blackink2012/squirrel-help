An asset library is "the folder is the data", so copying the whole library directory is the most complete backup; deletions performed by the plug-in also leave a temporary backup for emergencies.

Backing up the whole library

  1. Stop writing: stop import / export jobs and preferably close the plug-in window or quit Maya.
  2. Copy the whole library root, including library.json, favorites.json, every sub-library and any custom top-level categories.
  3. Put the copy on another disk or a backup location.

Restoring the whole library

  1. Close the plug-in and put the backup directory back in the target location.
  2. Open Settings → 常规 (General) → 资产库管理 (Asset library management) → 添加资产库 (Add asset library) and register the restored directory.
  3. Go back to the 「分类」 (Categories) page and choose that library in the dropdown.
  4. Run the library health check to confirm the asset count and the load-failure list.

Single assets and recovering a mistaken delete

  • Back up a single asset with the export_assets command (with material_ids and target_dir), which copies the asset as a .zasset; never rename or move a single .zasset inside the library by hand.
  • Assets deleted through commands are backed up beforehand to squirrel_ai_undo under the system temp directory and can be rolled back with undo_last.
  • version_manage op=remove_version backs up the deleted version to squirrel_ai_undo and returns the backup path; copy it back into the main asset root to restore it.

Verify the result

  • After restoring, the asset count matches the backup and collection names and counts are correct.
  • The library health check shows load_failure_count at 0 and duplicate UUIDs as false.
  • Missing thumbnails can simply be regenerated; the assets themselves are unaffected.

Tips

  • The directory index cache and the semantic index are derived data and need no backup; after restoring they rebuild automatically or manually as described in 4.12.2.
  • The library list, default library and wishlist live in user settings ~/.squirrel_asset_manager/app_settings.json and must be backed up separately when moving machines.
  • When several people share a library, avoid concurrent writes; the plug-in's lock only works within a single process.
