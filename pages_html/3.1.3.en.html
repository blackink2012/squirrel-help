The left navigation organizes assets with three tabs: the category library for long-term accumulation, the project library for the current project, and favorites as a cross-category shortlist.

The three tabs

TabContentsBest for
CategoriesLibrary dropdown plus category treeLong-term organization by the 11 built-in sub-libraries: materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees; a 「脚本」 (Scripts) entry sits at the end of the tree
ProjectsCreate / refresh buttons plus the project category treeAssets that belong only to the current project, independent of the category library
FavoritesFavorites panel and collectionsGathering frequently used assets in one place without changing their category

The library dropdown at the top of the Categories tab switches between several asset libraries; the category tree supports several levels and offers new, edit, move and delete in the context menu. A 「回收站 N」 (Recycle bin N) entry button sits at the bottom left of the category tree (not a tree node); click it to switch the middle area to the recycle bin view.

Beyond the 11 built-in sub-libraries you can create your own top-level categories under the library root. 「脚本」 (Scripts) at the end of the tree is a virtual node (clicking it switches the main area to the script browser), not a category on disk, so it has no "add sub-category / edit / delete" context items.

How to use it

  1. Pick a sub-library and a category on the Categories tab; the asset area shows only the assets of that category and its sub-categories.
  2. Drag an asset card onto a target category in the tree to move the asset; a multi-selection can be dragged as one batch.
  3. When the left column is collapsed it becomes a narrow icon strip, and top-level categories can still be switched from that strip.

Verify the result

  • Clicking different categories changes the contents of the asset grid in the middle.
  • After dragging a card to another category the grid jumps to that category and the card appears in it.

Tips

  • The category library and the project library are fully independent and cannot be dragged between directly; to migrate, export the .zasset and import it again.
  • Top-level categories set to "do not show in the main UI" do not appear in the tree; adjust them in Settings → 子库与分类 (Sub-libraries and categories).
