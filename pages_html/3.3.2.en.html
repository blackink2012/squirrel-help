Multi-selection follows Windows Explorer habits: Ctrl-click toggles a single item, Shift-click selects a range, and dragging on empty space draws a marquee.

Mouse multi-selection

ActionResult
Ctrl + clickToggles this card, keeping the other selected cards
Shift + clickAdds the range from the anchor to this card; the anchor stays put
Ctrl + Shift + clickSame as above, adding the range to the existing selection
Drag on empty spaceMarquee select; no modifier = replace the selection, Ctrl / Shift = add
Click empty spaceNo modifier = clear; Ctrl / Shift = keep the existing selection

The anchor is the card where the last plain or Ctrl click landed; repeated Shift clicks stretch the same range instead of measuring from scratch.

Keyboard multi-selection

  1. Click into the asset grid to give it keyboard focus.
  2. Arrow keys move the focus and the selection; Shift + arrow extends the range; Ctrl + arrow moves only the focus without changing the selection.
  3. Ctrl + A selects all; Ctrl + F scrolls the current selection to the center of the viewport.

Verify the result

  • After multi-selecting, the batch operation bar appears in the toolbar and the status bar shows how many are selected.
  • Dragging on empty space shows a marquee rectangle and the cards inside highlight live.
  • Ctrl-clicking a selected card deselects it without clearing the rest.

Tips

  • List view also supports ExtendedSelection, with the same Ctrl / Shift semantics as icon view.
  • With several cards selected, dragging any one of them drags the whole batch into Maya (see 3.3.5).
