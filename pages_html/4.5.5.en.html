A search only replaces what the grid currently shows; it never moves or modifies assets, and clearing it returns to the complete list of the current category.

What isolation means

  • Keyword search, AI semantic search and search by image all replace the grid with their result set.
  • The existing selection is cleared, and the properties and preview panels on the right clear with it.
  • Asset files, categories, tags and favorites never change because of a search.

How to clear

Search typeWhere to clearResult
Keyword searchClick the built-in ✕ in the search box, or delete the inputRestores all assets of the current category
AI semantic searchDelete the input or click ✕Restores the current category list immediately
Search by imageClick the query thumbnail, click ✕, or press Backspace with the caret at the frontRestores the current category list; Backspace removes only the query image and keeps the text

Steps

  1. Confirm the grid is in a search state: there is text or a query image in the search box, or the status bar shows a hit count.
  2. Click the ✕ on the right of the search box.
  3. Watch the grid return to all assets of the current category and the status bar show the new visible count.
  4. To remove only the query image and keep the keyword, put the caret at the very front of the search box and press Backspace.

Verify the result

  • The grid shows all assets of the current category again.
  • The search box is empty, the query image is gone and the built-in ✕ is hidden.
  • The status bar reports 「已取消以图搜图，恢复当前分类的全部资产」 (image search cancelled; restoring all assets of the current category) or the restored asset count.
注意

Switching category, switching tag filters or reloading data also ends image-search isolation automatically; no extra ✕ click is needed.

警告

Search results are only what is currently displayed. Before batch moving or batch deleting, clear the search and confirm which assets are actually selected.
