材质网络结构是 zmetal 对 Maya 着色网络的完整描述：哪些节点、每个属性是什么值、谁连到谁。

顶层由两部分组成

{
  "root_materials": ["Gold_ai"],
  "nodes": {
    "Gold_ai": {
      "node_type": "aiStandardSurface",
      "attrs": {
        "base": {"type": "value", "value": 1.0},
        "baseColor": {
          "type": "connection",
          "source_node": "file1",
          "source_attr": "outColor"
        }
      },
      "displacement_node": "displacementShader1"
    }
  }
}

root_materials 是导入后要建成的材质节点名；nodes 是节点表，键为节点名。

单个节点里有什么

  • node_type：Maya 节点类型，如 aiStandardSurface、file、place2dTexture。
  • attrs：属性表。普通值写成 {"type": "value", "value": ...}；连接写成 {"type": "connection", "source_node": ..., "source_attr": ...}，上游节点会被递归写进 nodes。
  • displacement_node：材质关联的置换节点，导入时由插件创建着色引擎并链接，而不是直接序列化 SE。

为什么这样设计

  • 导入不依赖原始 .ma，只要节点类型在当前 Maya 中存在，就能按属性值重建。
  • 贴图不内嵌，统一收集到 textures/，fileTextureName 改写为相对路径，资产可整体移动。
  • 数组元素属性（如 ramp 的 colorEntryList[i].color）会单独补采，避免导入后回默认值。
  • 场景全局节点（time1、defaultColorMgtGlobals 等）不写入，避免导入时重建出重复全局节点。

注意

连接属性的静态值只作参考，导入以连接为准；同名属性不代表语义相同，跨渲染器时仍需要 .mmap 明确对应关系。

导入时所有节点按 nodes 里的键名重建，随后按 root_materials 确定要赋给物体的材质。节点重名时 Maya 会自动加编号，插件通过旧名到新名的映射继续重连，所以资产里的原始节点名不需要与场景中完全一致。
