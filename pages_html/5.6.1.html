把资产卡片拖出插件窗口、在 Maya 视口中松手，插件按资产类型自动完成导入。

前置条件

  • Maya 场景已打开。
  • 光标从资产卡片拖出插件窗口，落到 Maya 视口内。

操作步骤

  1. 按住资产卡片拖动。
  2. 拖出插件窗口，移动到视口中需要的位置。
  3. 松手。
  4. 等待插件完成导入。

各类资产的行为

资产类型拖入后的行为
模型、动态、场景按默认格式导入；吸附开关打开时落到光标下的表面
灯光按默认格式导入；吸附开关打开时朝命中面法线打光
材质、贴图有选中物体则赋给选中，无选中则只创建并选中新材质
HDR按当前渲染器或双击预设选择模板，直接创建穹顶灯
节点树导入 ma；导入后自动选中新建节点（场景里可能看不到几何，属正常）
动画数据弹「动画起始位置」选择后，把关键帧按层级映射导入；场景里要先有对应层级
图片、音频拖入视口不会导入：它们是散文件，不属于几何拖放管线。图片请用右键「导入为 file 节点 / 创建 imagePlane」，音频请用右键「导入到时间轴 / 时间编辑器 / Trax 编辑器 / 摄像机序列器」

结果验证

  • 场景中出现对应资产，或材质被赋给选中物体（图片 / 音频不走这条路径，见上表）。
  • 脚本编辑器出现 [DragDrop] 日志。
  • 多选拖入且整批都是可吸附资产时，资产并排摆在落点附近。

提示

  • 拖放不弹格式选择框，格式与双击导入同一判据。
  • 图片 / 音频拖到视口松手不会发生导入（它们没有几何/音频导入目标），别以为「拖丢了」——用右键菜单；节点树与动画数据可以拖入，但它们导入的结果不在视口里（节点网络 / 关键帧）。
  • 混选且摆放规则不同（例如模型加灯光）时不走吸附，改为逐个导入。
  • 拖拽缩略图跟随光标；可吸附资产还会显示落点预览。
