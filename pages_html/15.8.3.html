一句话定位：删除资产 / 分类 / 版本时先放进回收站，还能还原；只有「彻底删除」才真的从磁盘删掉。

先记住这个区别

操作文件在哪能还原吗占磁盘吗
移到回收站（资产右键「删除 → 移到回收站」）还在库里，挪进回收站文件夹能还原占（回收站上限 100 GB，满了要手动删旧条目）
彻底删除（资产右键「删除 → 彻底删除」）直接从磁盘删掉，不进回收站不能不再占

删除分类、删除版本也都会先进回收站；回收站里每条记录都标着它是「资产 / 分类 / 版本」。

怎么打开回收站

  1. 看左侧导航的分类树，最下面有独立的「回收站」入口，后面跟着条目数；
  2. 点它，中间内容区就切到回收站页；
  3. 想回到资产，点任意分类即可（回收站入口的高亮会熄灭）。

分类库和项目库各有自己的回收站入口，条目数分别统计各自的库。

回收站页面

元素说明
视图卡片 / 列表两种，跟资产网格用同一套切换；回收站卡片是暗红描边，和正常资产卡片一眼能分开
排序 / 缩略图大小直接用顶部工具栏那三个控件（视图 / 排序 / 缩略图滑块），回收站没有自己单独的一排按钮
条目内容缩略图 + 名称 + 副标题（类型 · 大小 · 删除时间）；文件已丢失的条目会提示「文件已丢失（仍可移除记录）」
结果文字顶部显示「N 项 · 已用 / 上限 100 GB」，并提示「右键条目：还原 / 彻底删除」；用到 90% 会追加「接近上限，建议清理」，写满后删除资产会被拒绝并提示先清理
右侧面板选中条目时，属性与预览只读展示（缩略图、删除时间写在注释里），缩略图按钮全部停用

回收站不会自动清理，也没有「一键清空」：里面的条目只能由你在右键菜单里逐条「彻底删除」。

右键菜单逐项详解

菜单项作用点在哪才有点了之后注意
还原把这条记录恢复到原来的分类 / 位置条目上记录从回收站消失，资产回到原分类并刷新列表能还原就说明文件还在；还原失败会弹提示
彻底删除从磁盘删掉这条记录条目上弹「彻底删除后不可恢复，确定？」→ 确认后文件被真删不可恢复，没有二次回收站
打开回收站文件夹在资源管理器里打开回收站目录条目上 / 空白处打开库里的回收站文件夹，可手动查看文件手动动文件要小心，插件不会同步你的手动改动

在空白处右键只会出现「打开回收站文件夹」一项。

一次典型操作：删错了要还原

  1. 点左侧「回收站」入口，切到回收站页；
  2. 找到那条记录（可按类型 / 名称排序，卡片上有缩略图好认）；
  3. 右键 →「还原」；
  4. 列表刷新，条目消失；回到它原来的分类就能看到这个资产。

一次典型操作：回收站满了怎么腾空间

  1. 确认回收站里没有还要的东西（彻底删除后就找不回了）；
  2. 在要清掉的条目上右键 →「彻底删除」（可以多选后一次操作）；
  3. 弹确认框，点「是」；
  4. 顶部「已用」变小，磁盘空间释放。
警告

「彻底删除」不可撤销、不进回收站、没有备份（文件已丢失的条目也一样）。操作前确认一遍；库里有重要资产时，先做一份库备份（见 4.1.12.4）。

常见疑问

现象原因
删除后资产没进回收站用的是「彻底删除」；或删除的是内部版本 / 变体这类不进回收站的条目
还原失败目标分类已经不存在、或文件已被手动移动 / 删除
回收站条目显示文件已丢失回收站记录还在，但对应文件被外部删掉了；可以彻底删除清掉这条记录
回收站里有东西但磁盘没变小只有「彻底删除」才释放空间；「移到回收站」只是挪了位置
删除时提示「回收站已满」回收站上限 100 GB 且不会自动清理；先在回收站里右键把旧条目「彻底删除」，再重新删除资产
