When an existing variant needs a new shape or another detail level, do it in 「更新变体」 (Update variant) instead of deleting and recreating it; the shared textures and materials never change.

Entry point

Right-click the asset → 「更新资产」 (Update asset) → 「更新变体 ▶」 (Update variant ▶) → choose a variant. The submenu contains:

Menu itemEffect
Capture / import / Maya playblast / render / add / capture and addRedo that variant's thumbnail only, with the same entries as 「更新缩略图」 (Update thumbnail)
「覆盖（用当前选中）」 (Overwrite from current selection)Overwrite the variant with the geometry currently selected in the viewport
「追加 LOD…」 (Append LOD…)Add a detail level to that variant
「删除变体」 (Delete variant)Delete the variant (see "Variant management and deletion")

Overwriting a variant

  1. Select the new geometry in the viewport (marquee selecting collapses to root objects).
  2. Right-click the asset → 「更新资产」 (Update asset) → 「更新变体 ▶」 (Update variant ▶) → target variant → 「覆盖（用当前选中）」 (Overwrite from current selection).
  3. Confirm the prompt to finish overwriting.
  • Only the geometry of variants/<id>.<ext> is replaced; textures and materials are untouched.
  • After overwriting, regenerate the image in 「更新变体」 (Update variant) so the thumbnail matches the geometry.

Appending a LOD

  1. Select the low- or high-poly object to use for that level.
  2. 「更新变体 ▶」 (Update variant ▶) → target variant → 「追加 LOD…」 (Append LOD…) and enter a level number from 1 to 9.
  3. The file is written as variants/<id>_lodN.<ext> and registered in that variant's lods in variants.json.
  • LOD0 is the variant's own geometry (variants/<id>.<ext>) and needs no extra append.
  • Afterwards 「导入变体 / 版本」 (Import variant / version) shows one more level menu for that variant (its own geometry plus LOD1, LOD2…).

Verify the result

  • Overwrite: the Script Editor reports 「变体「…」已用当前选中覆盖」 (variant "…" overwritten from the current selection), and reimporting the variant in the scene gives the new shape.
  • Append LOD: it reports 「变体「…」已追加 LODn」 (variant "…" got LODn appended) and variants/ gains <id>_lodN.<ext>.
注意

Variants do not offer the background (headless) render entry: that path renders a whole asset package, and a variant has no package of its own.
