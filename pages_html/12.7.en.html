This page standardizes the terms that recur throughout the help center; whenever another page uses them, the meaning here applies.

TermMeaning
AssetA single importable, searchable unit that exists as a .zasset folder
Sub-libraryA first-level directory under the asset library, split by type; 11 are built in: Materials, Models, Lights, Textures, Scenes, HDR, Animation, Images, Audio, Animation data, Node tree
CategoryA tree node inside a sub-library, nestable to several levels; it has a folder name and a readable name
Top-level categoryA first-level node of the category tree, which can be shown or hidden in the sidebar
TagA free keyword that spans categories, used for filtering and search
Main asset library (category library)The fixed library organized by categories, corresponding to Category library in the sidebar
Project libraryA library organized per project, switched by tab and independent of the main library
Favorites / wishlistFavorites is a cross-category set of frequently used assets; the wishlist is the cross-session queue of favorited assets from AI search
VersionOne iteration of the same asset (such as v1 → v2), fully self-contained (geometry, material, textures, thumbnail), and each version has its own LOD chain
LODA detail level within one version (lod0 high, lod1 medium, lod2 low)
VariantSeveral geometry forms under one asset that share a single set of textures and materials; only geometry is stored, while materials and textures are inherited from the asset root
.zassetThe unified asset folder format; ZIP packages are no longer used
.zmetalSerialized file of material node attributes
.mcmFile describing which material maps to which object
.sicon / .aiconStatic PNG thumbnail / animated GIF thumbnail
ThumbnailThe asset card image, which can come from a screenshot, playblast, render, imported image, or multiple slots
Proxy fileSubstitute geometry as a low-poly model or cache, such as .ass, .vrmesh, .rs, .abc
Associated fileExternal files an asset depends on, such as textures, caches and references
PBR mappingRules that map texture file names to channels such as baseColor, normal and roughness
Material mapping (.mmap)Entry-by-entry mapping and conversion rules from source material attributes to target material attributes
Semantic indexEncodes assets or help text as vectors to support colloquial Chinese search; falls back to lexical search when missing
BrokerThe separate process that routes commands and hosts jobs; Maya, MCP and dsh all connect to it
InstanceA registered host process, shaped like maya-2026-12345
Command surfaceAll callable commands the plug-in registers, plus their parameter schemas
dry_runAn execution mode that previews without changing state and returns status="preview"
JobThe record of a long-running async command, with a job_id and its own state machine
Cooperative cancellationThe command checks a checkpoint in its loop and stops by itself; without a checkpoint it cannot stop
Late resultA result delivered after a synchronous call timed out, kept in the /late_results mailbox
