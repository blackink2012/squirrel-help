The machine code identifies this computer for licensing. Provide it to the licensor when requesting an offline license.

What it does

The read-only Machine code box in the Current license card of Settings → License activation shows the value, and the Copy button on its right puts the whole string on the clipboard. It shows - when the licensing module is unavailable.

Values and defaults

  • There are no selectable values; the licensing module generates the machine code from the current computer.
  • An empty value or - means the machine code cannot be read, which usually indicates a missing or failed licensing module.

Scope of effect

  • A local license is bound to this computer; moving to another machine requires a new request or activation.
  • The machine code itself is not a license and cannot replace an activation code or license file.
  • The copy button only writes to the clipboard; it changes no configuration.

When to use it

  • Offline activation: send the machine code to the licensor to obtain a license file that matches this machine.
  • Licensing troubleshooting: give the machine code to support so they can check which license belongs here.

Steps

  1. Open Settings → License activation and look at the Current license card.
  2. Click Copy next to the machine code.
  3. Paste it into an email, form or chat message to the licensor.

Verify the result

After clicking Copy, paste into a text editor; the content should match the box.

Tips

The machine code may change after a hardware change or system reinstall. Whether an old machine's license file works on a new machine depends on the license type and the remaining switch count, so confirm the target machine's code before migrating.
