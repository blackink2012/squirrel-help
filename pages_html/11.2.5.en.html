The interface language switches the plug-in's own Chinese / English display and never affects asset names, tags or the Maya interface.

Effect

It chooses the language of plug-in windows, menus and messages.

Values and default

  • Follow system (default), Chinese, English. The field is labelled Language / 语言.

Scope

  • After 「应用」 (Apply) the i18n switches immediately and the category tree rebuilds the display names of built-in categories in the new language.
  • The window shows 「设置已保存。请重启插件以完全生效。」 (settings saved; restart the plug-in for full effect.) Most main-window text unifies after a plug-in restart.
  • It never translates user data such as asset names, Chinese names or tags, and never changes Maya's native interface.
  • The setting is stored under the language key in app_settings.json.

When to change it

  • When a team uses the English interface, or to compare against English documentation.
  • If some windows still show the old language, restart the plug-in and check again.

Tips

Tip: language and appearance theme are independent settings; switching language never changes colors.

Tip: the category tree updates immediately, but open dialogs usually need to be reopened to change language.
