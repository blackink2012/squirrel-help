状态页回答四个问题：库里有什么、有多大、多久没重建、语义检索现在通不通；它还会告诉你哪类查询该信谁。

图只用来指路：状态是让助手执行 maya_docs(action="status") 得到的，菜单里没有单独的「知识库状态」项。

前置条件

能在 AI 助手里调用 maya_docs，或能执行命令面的同名命令。

操作步骤

  1. 让助手执行 maya_docs(action="status")。
  2. 查看条目数与按类型的分布（command / node / api / devguide / doc）、各文件体积、别名数量。
  3. 查看 rebuilt 里的重建时间与各来源，判断知识库是否过期。
  4. 查看 semantic：模型、维度、条数、是否可用及原因；需要端到端验证时加 probe=true，它会真发一次嵌入请求。
  5. 想看本机装了哪些插件，执行 maya_docs(action="plugins")，可按插件名过滤。

结果验证

返回 status=ok 且有 entries、by_type、semantic 与 authority；probe=true 时多出一次真实嵌入的结果。

提示与警告

  • 本地库缺席时会明确显示当前是在线模式，不要误以为本地有数据。
  • authority 写明权威口径：命令参数用实时帮助，节点属性用详情，正文用检索。
  • 知识库过期或内容缺失时，用 tools\rebuild_maya_doc_kb.py 重建；构建期间不要同时跑大量 Maya 操作。
