The main asset library accumulates assets over time, while the project library belongs to the current Maya project; the two are isolated, and favorites are stored separately as well.

Main asset library

  • The library dropdown above the 「分类」 (Categories) tab switches the current asset library; it opens the default library set in settings.
  • The main library holds assets reused across projects (materials, models, textures, lights, scenes, HDR, dynamics, images, audio, animation data, node trees); its path is chosen when the library is added and it is kept long term.
  • Several libraries can be added and switched at any time; see "Library list and switching".

Project library

  • The project library always lives in SquirrelLib under the root of the current Maya project, travels with the project and never pollutes the main library.
  • The 「项目」 (Projects) tab in the left column offers 「创建」 (Create) and 「刷新」 (Refresh): when the project has no SquirrelLib yet the status area says 「项目库未创建」 (project library not created), and clicking Create generates the sub-library directories; after switching projects click Refresh to load it again.
  • The project tree works like the main library category tree, but it is not affected by the "show in the main UI" hiding setting.

Between the two

Assets are not synchronized automatically. To reuse one, select it in the main library, right-click 「复制」 (Copy), switch to the 「项目」 (Projects) tab and 「粘贴」 (Paste); the same works in reverse. Favorites are stored per library, so after switching you see that library's own favorites.
