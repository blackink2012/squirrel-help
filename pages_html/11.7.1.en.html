Which command runs when an asset thumbnail is double-clicked is configured per sub-library, and only one can be chosen.

Effect

The lower half of Settings → 右键菜单 (Context menu) is the double-click command area, sharing the sub-library list on the left. Selecting a sub-library lists its available commands on the right, and one can be chosen.

Values and defaults

Sub-libraryAvailable commandsFactory setting
materialsNone / Import / Assign material to current selectionImport, sub-option zmetal
modelsNone / ImportImport, sub-option ma
nodetreeNone / ImportImport, sub-option ma
lightsNone / Import / Apply light parameters to selected lightImport, sub-option zlight
texturesNone / Import / Import texture / Create material / Assign material to current selection / Assign texture to materialCreate material, sub-option openPBRSurface
scenes / aniNone / ImportImport, sub-option ma
hdrNone / Import / Create environment light / Assign textureCreate environment light, sub-option aiSkyDomeLight.ma
imagesNone / Import (generic fallback)Import: create a file node (the same action as the context menu's import as texture)
audioNone / Import (generic fallback)Import: import to the Maya timeline (current frame = first audio frame)
animationNone / Import (generic fallback)Import: hierarchy mapping plus the channel selection dialog
Custom sub-librariesNone / ImportInherits default: import, format chosen automatically

Images, audio and animation data have no separately registered commands, so they only offer None / Import; what Import really does is decided by the sub-library (see the table above).

Factory values live in the cmd and option fields of Assets/preset/double_click_preset.json.

Scope

  • It only affects double-clicking a thumbnail, never "Import" in the context menu.
  • When the command has a secondary action a 「子选项:」 (Sub-option:) dropdown appears below; without one it is hidden.
  • With 「无操作」 (None) chosen a double-click does nothing at all.

When to change it

When double-clicking a texture should build a material directly, double-clicking an HDR should create a dome light, or double-clicking should never import by accident.

Steps

  1. Open Settings and check 「解锁全部配置」 (Unlock all configuration).
  2. Select a sub-library on the left of the 「右键菜单」 (Context menu) page.
  3. Choose a command in the double-click command area below and pick a sub-option when needed.
  4. Click 「应用」 (Apply) or 「确定」 (OK).

Verify the result

Back in the asset grid, double-click an asset of that type and confirm the new command runs; reopening Settings shows the configuration still there.

Tips

This area is also locked by 「解锁全部配置」 (Unlock all configuration) and is read-only until unlocked.
