Maya's autosave is off by default; you must enable it and write it into the preferences. It only protects scenes that have been saved to disk at least once.

Symptoms

  • After a crash there is no autosave file and the autosave directory is empty.
  • Restarting Maya shows no crash recovery prompt.
  • A crashed new scene cannot be recovered at all.
  • Autosave was enabled, but the setting is off again after a crash.

Steps

  1. Enable autosave in the Maya preferences, set the interval to 10 minutes or less, and save the preferences.
  2. Confirm the setting is written to prefs\userPrefs.mel rather than only the current session; back up the file before editing it.
  3. After creating a new scene, press Ctrl+S once so autosave has a file name to work with.
  4. After a crash, look in Documents\maya\projects\default\autosave for autosave files.
  5. Once found, copy the file to another directory first and open the copy, so recovery does not overwrite the original.
  6. Backups taken before thumbnail rendering live in %TEMP%\squirrel_pre_render\ and keep 3 copies by default; set SQUIRREL_PRE_RENDER_BACKUP=0 to turn them off.

Verify the result

The autosave directory gains a timestamped file whose content matches the pre-crash scene, and the autosave settings are visible in userPrefs.mel.

If it still fails

  • Temporarily set the autosave interval to 1 minute, work normally for a while, then check whether files land in the directory.
  • Confirm the scene really was saved to disk; an untitled new scene never produces an autosave.
  • Autosave files can also be overwritten or rotated out, so save versions manually before important steps.
  • Investigate the crash itself per 6.7.2 "Three steps to recover after a crash" or 6.7.3 "Renderer crash".
