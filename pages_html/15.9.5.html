一句话定位：按子库逐个决定：资产右键菜单里显示哪些项、双击卡片时执行哪条命令。

这一页默认是锁住的，必须先勾「解锁全部配置」并确认警告才能改（见 8.9.1）。

怎么打开

设置窗口 → 勾「解锁全部配置」→ 页签「右键菜单」。

左边先选子库（材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态 / 节点树 / 图片 / 音频 / 动画数据），右边分成上下两块：上面是「右键菜单项」勾选，下面是「双击命令」单选与子选项。

分类专属项为什么会置灰

  • 当前子库不适用的项会置灰不可勾选，并在名字后面补一句「（仅 材质/贴图）」这样的说明；鼠标悬停有提示；
  • 置灰不会清掉原来的勾选值：切回适用分类，你之前配的勾选状态还在；
  • 没在配置里登记过的分类（自定义子库、自建的顶级分类）走「兜底段」default 的配置，不会出现整片空白。

下半部分：双击命令

控件类型作用默认值（材质 / 兜底段）改了会怎样
双击缩略图时要执行的命令单选组（按子库不同）双击资产卡片时执行什么导入 / 导入保存后立即生效；「无操作」= 双击什么都不做
子选项下拉框给选中的命令指定细节zmetal / 自动（资产默认格式）例如「导入」选 zmetal 就只导入材质文件；选「自动」则用资产默认格式

不同子库能选的命令不一样：

子库可选的双击命令
材质无操作 / 导入 / 为当前选择指定材质
模型、节点树、场景、动态无操作 / 导入
灯光无操作 / 导入 / 应用灯光参数到选中灯光
贴图无操作 / 导入 / 导入贴图 / 创建材质 / 为当前选择指定材质 / 指定贴图到材质
HDR无操作 / 导入 / 创建环境光 / 指定贴图

子选项下拉里会出现什么，取决于选了哪条命令：

选中的命令子选项内容
导入自动（资产默认格式）、ma、mb、fbx、obj、usd、abc、ass、vrscene、rs、vrmesh、zmetal、zlight、proxy、vdb
导入贴图导入全部
创建材质自动（跟随渲染器）+ 材质预设列表（带渲染器后缀，如 VRayMtl（VR））
创建环境光HDR_ligt/ 目录里的环境光模板（.ma）
无操作 / 其它不显示子选项

改了之后什么时候生效

  • 保存（应用 / 确定）后，资产右键菜单与双击行为立刻按新配置重建；
  • 只影响菜单长什么样、双击做什么，不会改动已有资产；
  • 关闭「删除」这一项等于把回收站入口从右键菜单里拿掉——之后想删资产得先把这里勾回来。

反悔与风险

情况怎么反悔
还没保存点「取消」
已保存点「恢复默认设置」→ 重新从 context_menu_preset.json / double_click_preset.json 读取（读的是文件里的值，见 8.9.1）
想彻底回出厂用备份的这两个 JSON 覆盖回去（<插件目录>\Assets\preset\）
警告

把「删除」「更新资产」这类关键项关掉后，对应操作在右键菜单里就彻底消失（不是置灰）；不熟悉配置时别一次性关很多项。
