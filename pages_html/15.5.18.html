一句话定位：「版本 / 变体 / LOD」不是独立资产，是主资产内部的条目；右键它们得到的是两张精简菜单，只做「这一份」的事。

怎么走到这一步

  1. 右键主资产卡片 → 展开「导入 ▶」子菜单；
  2. 点其中的 查看版本 / 查看变体 / 查看 LOD 管理；
  3. 资产区切换成内部视图，卡片变成版本 / 变体 / LOD 条目；
  4. 在内部条目卡片上右键。

版本 / 变体条目的右键菜单

段条目说明
①导入 <格式>只把这一份（这个版本 / 变体）导进场景；格式唯一时直接显示格式名
①添加引用把这一份以 Reference 方式引入场景
①查看 LOD 管理该条目下有多条 LOD 时出现，切到它的 LOD 列表
①追加 LOD…给这一份追加一条新 LOD
②添加到收藏夹 ▶收藏的是主资产（内部条目本身不能收藏）
②全选 / 复制 / 打开文件夹复制与打开文件夹都作用于主资产；内部条目不会被复制
③编辑主版本上不可用（置灰，提示「（主版本）」）
③更新缩略图 ▶截取 / 导入；变体还多 Maya拍屏 / 渲染图；添加 / 截取添加。没有「后台渲染」
③更新资产 ▶版本条目给的是：替换资产 / 追加格式 / 追加为 LOD / 创建新版本（子版本上置灰）/ 添加新变体… / 批量添加变体…；变体条目只有一行「更新资产」
③删除主版本不可删（置灰，提示主版本不可删除）
④资产详情打开版本浏览器 / 资产观察窗口

LOD 条目的右键菜单（更精简）

段条目说明
①导入 <格式>只导入这一条 LOD
①打开文件夹打开主资产的文件夹
②设为默认 LOD只在「当前不是默认」时出现；点它把这条设为默认
②重命名 LOD…改名（只改这一条 LOD 的显示名）
③追加 LOD…再给这个版本加一条 LOD
③删除此 LOD资产只剩一条 LOD 时置灰（必须保留至少一条）
④资产详情打开版本浏览器 / 资产观察窗口

为什么这些菜单这么短

内部条目（版本 / 变体 / LOD）不是真实资产，只是主资产里的一个切片。所以：

普通资产能做内部条目为什么不能
移动到 / 复制到分类它没有独立目录，搬不动；要搬就搬主资产
编辑名称 / 分类 / 标签元数据挂在主资产上
删除整个资产只能删「这一份」（LOD 有最小值限制），整包删除要在主资产上做
后台渲染缩略图后台渲染按整个资产包出图，单份条目没有独立包

好处也很实在：在这张菜单里点错，最多改到这一份，不会动到主资产的内容与位置。

注意点

  • 收藏的是主资产：在内部条目上点收藏，收藏夹里出现的是主资产，不是这一个版本。
  • 「设为默认 LOD」会改主资产的行为：默认 LOD 是导入 / 拖入时默认用的那一条，改之前想清楚。
  • 删除变体只删它自己的几何与缩略图：资产共享的贴图 / 材质不受影响（删除时会有确认框写明）。
  • 内部视图里「粘贴」不能用来复制内部条目：复制条目不会进剪贴板。
