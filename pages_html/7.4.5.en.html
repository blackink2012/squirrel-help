The HDR connection is made automatically by creating an environment light; each renderer connects it to the dome light differently, but all of them use the Raw color space.

Prerequisites

  • A dome light already exists, or an HDR asset is about to be used to create one.
  • The HDR file exists and its path is reachable.

Steps

  1. Right-click the HDR asset in the library and choose 「创建环境光」 (Create environment light), or pick an IBL under 「创建灯光」 (Create light) in Create asset.
  2. The tool builds the connection for the current renderer:
    • Arnold: a file node with outColor → dome light color.
    • V-Ray: file + VRayPlaceEnvTex with useDomeTex=1 and the file output → dome light domeTex.
    • Redshift: the HDR path is written directly into the dome light's tex0 string attribute.
  3. To confirm, open the attribute editor and look at the dome light's texture attribute or connection.
  4. Rotate the environment with the dome light or its environment tool's rotation parameter, not by changing the HDR file name.

Verify the result

The dome light's texture attribute has a connection or path; the render background and reflections show the HDR content; the Arnold / V-Ray file node's colorSpace is Raw.

Tips

  • HDR is linear data and must use Raw; setting sRGB darkens the environment and distorts colors.
  • Redshift's tex0 stores only a path and creates no file node, which is expected.
  • Re-importing a .zlight re-resolves the texture paths against the asset's textures/.

Warnings

When the HDR file is missing the tool only logs it: the light is still created but has no environment texture. After moving or deleting an HDR file, reconnect it.
