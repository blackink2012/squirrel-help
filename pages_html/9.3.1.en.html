Batch converts HDR, EXR, PNG, JPEG, TIFF, BMP, WebP and TGA images with OpenCV, supporting resizing and preserving the directory structure.

Purpose

Turn high dynamic range textures into previews, or unify image formats between projects without opening an image editor for every file.

Input and output

  • Input: 「选择文件」 (Choose files) accepts several files; 「选择文件夹」 (Choose folder) scans the images inside recursively.
  • Output: images in the target format keeping the source base name; an empty 「输出位置」 (Output location) means the input file's directory (or the input folder in folder mode).
  • Output structure: 「保持层级结构」 (Keep hierarchy) is on by default and rebuilds the source relative paths under the output directory; when off everything is flattened into the output directory.

Steps

  1. Open 快捷工具 (Quick tools) → 图像格式转换工具 (Image format conversion tool).
  2. Choose the input mode and click 「浏览...」 (Browse...) to pick files or a folder.
  3. To limit the input types fill 「输入格式过滤」 (Input format filter) such as exr or png, jpg (empty converts every supported format).
  4. Set 「输出位置」 (Output location) and 「输出格式」 (Output format).
  5. Fill the output width / height as needed and adjust aspect ratio and format options.
  6. Click 「开始转换」 (Start conversion).

Verify the result

  • The 「转换日志」 (Conversion log) on the left lists each processed path and any renames.
  • The progress bar completes and a summary appears (successes / failures).
  • The output directory contains files in the target format with the source structure preserved (when keeping hierarchy).

Keep hierarchyOnWhen off all files go into one directory
  • Converting HDR/EXR to an 8-bit format applies Reinhard tone mapping and Gamma 2.2 correction, so colors differ from the original float image; it suits previews and thumbnails.
  • File names are cleaned to letters, digits, underscores and dots only, starting with a letter; when a name does not comply the tool renames the source file and logs 源文件已重命名 (source file renamed).
  • EXR reading prefers OpenCV and falls back to imageio; missing dependencies produce an install hint.
  • The output directory is created when it does not exist.
