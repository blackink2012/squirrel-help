右键贴图资产，通过「导入贴图」子菜单把单张贴图或整套贴图变成场景中的 file 节点。

前置条件

  • Maya 场景已打开。
  • 贴图资产的 textures/ 下有可读取的图片文件。

操作步骤

  1. 右键贴图资产，展开「导入贴图」。
  2. 资产有多个精度目录时，先选精度（如 2K、4K）；只有一层时直接列出文件名。
  3. 导入单张：点击文件名，插件创建 file 节点与 place2dTexture，并选中该 file 节点。
  4. 导入整套：点击「导入全部」或「导入全部 (<精度>)」，插件批量创建 file 节点，并让它们共享一个 place2dTexture。

结果验证

  • Hypershade 中出现对应数量的 file 节点。
  • 单张导入后该 file 节点处于选中状态。
  • 批量导入后所有 file 节点的 UV 连接指向同一个 place2dTexture，调整该节点即可统一改 UV。

提示

  • 色彩空间按扩展名给出：png、jpg、jpeg、tga、tif、tiff、bmp、psd 为 sRGB；exr、hdr 为 Raw。
  • 贴图存放位置遵循贴图导入策略；选择「拷贝贴图到项目」时会复制到工程 sourceimages/squirrel_asset/。
  • 要把贴图接到已有材质，请用「指定贴图」；要新建成套材质，请用「创建材质」。
