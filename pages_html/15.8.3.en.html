One-line summary: deleting an asset / category / version first moves it to the recycle bin, from where it can be restored; only delete permanently really removes it from disk.

Remember this difference first

OperationWhere the files areRestorableUses disk space
Move to recycle bin (asset right-click Delete → Move to recycle bin)Still in the library, moved into the recycle bin folderYesYes (the recycle bin is capped at 100 GB, and you must delete old entries when full)
Delete permanently (asset right-click Delete → Delete permanently)Removed from disk directly, never enters the recycle binNoNo
Deleting a category or a versionAlso goes to the recycle bin firstYesYes

Every recycle bin record is labeled as an asset / category / version.

How to open the recycle bin

  1. Look at the category tree in the left navigation: there is a separate Recycle bin entry at the bottom, followed by the entry count;
  2. Click it and the center content area switches to the recycle bin page;
  3. To return to assets, click any category (the recycle bin entry unhighlights).

The category library and the project library each have their own recycle bin entry, and the counts are per library.

The recycle bin page

ElementDescription

Sort / thumbnail sizeThe same three toolbar controls (view / sort / thumbnail slider); the recycle bin has no separate row of buttons
Entry contentThumbnail + name + subtitle (type · size · deletion time); entries whose files are gone say "File lost (record can still be removed)"
Result textThe top shows "N items · used / 100 GB limit" and hints "Right-click an entry: restore / delete permanently"; at 90% it adds "approaching the limit, consider cleaning up", and once full, deleting assets is refused with a prompt to clean up first
Right panelSelecting an entry shows properties and preview read-only (thumbnail and deletion time in the notes) with every thumbnail button disabled

The recycle bin never cleans itself and has no empty-all button: entries can only be deleted one by one with Delete permanently in the context menu.

A typical operation: restore after a mistaken delete

  1. Click the Recycle bin entry in the left navigation to switch to the recycle bin page;
  2. Find the record (sort by type / name; thumbnails make it easy to recognize);
  3. Right-click → Restore;
  4. The list refreshes and the entry disappears; return to its original category and the asset is there.

A typical operation: free space when the recycle bin is full

  1. Confirm nothing in the recycle bin is still needed (permanent deletion cannot be undone);
  2. Right-click the entries to clear → Delete permanently (multi-select works);
  3. In the confirmation dialog click Yes;
  4. The used figure drops and disk space is released.
警告

Delete permanently is irreversible, skips the recycle bin and has no backup (the same for entries whose files were lost). Confirm before acting; when the library holds important assets, take a library backup first (see 4.1.12.4).
