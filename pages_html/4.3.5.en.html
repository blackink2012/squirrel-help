「读取当前分类文件夹」 (Read current category folders) reads the actual folder structure of the library into settings, overwriting the 「默认分类列表」 (Default category list) configuration without touching the disk.

Prerequisites

An asset library is loaded (main or project library).

Steps

  1. Open 「设置」 (Settings) → 「子库与分类」 (Sub-libraries and categories).
  2. Click 「读取当前分类文件夹」 (Read current category folders) above the editor on the right.
  3. Click 「是」 (Yes) in 「同步确认」 (Sync confirmation).
  4. Back in settings, click 「应用」 (Apply) or 「确定」 (OK) to save.

Verify the result

「分类已从当前资产库同步」 (categories synchronized from the current asset library) appears; the sub-library list on the left and the 「默认分类列表」 (Default category list) on the right are replaced by the actual folder structure, and new sub-libraries / categories show up in the list.

Tips

  • This only updates the configuration file; it neither deletes nor modifies any folder on disk.
  • The category tree itself always mirrors the disk and needs no syncing; this button brings the 「默认分类列表」 (Default category list) configuration up to date with the library.
  • It overwrites the existing default category configuration, so confirm beforehand that nothing hand-maintained needs to be kept.
  • It suits the case where category folders were organized on disk first and the default categories in settings should follow; syncing itself does not change how the current category tree displays.
