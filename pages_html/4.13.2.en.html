Export the object selected in the viewport as a new variant of this asset. A new variant writes geometry only; textures and materials keep using the set in the asset root.

Prerequisites

  • Do this in the Maya plug-in edition (variant export needs a local Maya; the standalone edition reports "currently in standalone mode").
  • The object to use as the variant is selected in the viewport; marquee selecting only takes the topmost root object.
  • The asset is a .zasset.

Steps

  1. Right-click the target asset in the grid and expand 「更新资产」 (Update asset).
  2. Click 「添加新变体…」 (Add new variant…).
  3. In the export configuration:
    • Enter the variant name (it also becomes the directory name and may be Chinese);
    • Check at least one geometry format (ma / mb / fbx / obj / usd);
    • The thumbnail source follows the setting in Create asset (screenshot / playblast / render / preview image).
  4. Confirm the export. It then reports 「已添加变体 …（共享资产贴图与材质）」 (variant added… sharing the asset's textures and materials).

How the thumbnail is generated

Thumbnail source in Create assetBehavior when adding a variant
Maya playblast / renderGenerates the variant's thumbnail automatically
ScreenshotOpens the screenshot window for a manual framing confirmation
Preview image / imported imageFollows that setting without taking another image

The variant's thumbnail entries are identical to 「更新缩略图」 (Update thumbnail) (capture, import, Maya playblast, render, add, capture and add), and you can also regenerate later with 「更新资产 → 更新变体 ▶ → that variant」 (Update asset → Update variant ▶ → that variant).

Verify the result

  • The Script Editor shows the variant export log and the asset directory gains variants/<variant name>.<ext> (plus variants/<variant name>.sicon when a thumbnail exists).
  • The new variant can be chosen under 「导入变体 / 版本」 (Import variant / version) in the context menu.
  • The asset grid does not gain a card; the variant hangs off the original asset.
警告

A variant stores geometry only. If only "export materials only" is checked with no geometry format, it reports 「变体只保存几何体」 (variants store geometry only) and stops.
