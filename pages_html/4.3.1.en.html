Categories are folders on disk: a new top-level category creates an independent container in the library root, and a new sub-category creates a folder under the selected category.

Prerequisites

An asset library is loaded; the main library and the project library both work.

Steps

  1. To create a top-level category: right-click empty space in the category tree or 「全部资产」 (All assets) and choose 「添加顶级分类」 (Add top-level category).

To create a sub-category: right-click any category (including a sub-library root node) and choose 「添加子分类」 (Add sub-category).

  1. Fill in 「文件夹名」 (Folder name): required, used as the category's internal ID, for example metal_copper.
  2. Fill in 「易读名」 (Display name): optional; when left empty the folder name is used.
  3. A top-level category also offers 「类型」 (Type), whose dropdown comes from the configured sub-library list; sub-categories inherit the parent type and do not show this field.
  4. Click 「确定」 (OK).

Verify the result

The new category appears in the tree and is selected automatically; a top-level category also gets a 「自定义」 (Custom) sub-category.

Tips and warnings

  • The folder name cannot be empty and cannot match an ancestor category or a built-in sub-library; on a conflict the plug-in refuses to create it and asks for another name.
  • The folder name cannot be changed through the interface after creation, so decide it carefully.
  • Top-level categories cannot hold assets directly; assets imported into a top-level category automatically land in its 「自定义」 (Custom) sub-category.
