选中多个物体一次导出，每个选中根物体生成一个变体。适合「一套贴图、几十种螺丝钉 / 砖块」这类资产。

前置条件

  • Maya 插件版，且已在视口中选中多个物体。
  • 框选时会把同一层级的父子物体收敛到最上层根物体，一个根物体算一个变体。
  • 资产是 .zasset 资产。

操作步骤

  1. 在视口里选中要导出的多个物体。
  2. 右键目标资产 →「更新资产」→「批量添加变体…（每个选中物体一个）」。
  3. 在导出配置里选择几何格式（至少一种）与缩略图来源，确认导出。
  4. 观察进度对话框（可取消）：每条进度显示当前变体名；缩略图来源为拍屏 / 渲染时，进度文案会标出正在出图。

命名规则

  • 变体名取节点的短名（去掉命名空间与层级前缀）。
  • 与已有变体重名时自动追加序号：名字、名字_2、名字_3……

缩略图与选择集

缩略图来源批量时的行为
Maya 拍屏 / 渲染图每个变体导出后自动出图（无需逐个确认）
截图不自动执行（需人工取景），可在事后用「更新变体」逐个补图
  • 批量结束后会恢复你操作前的选择集，不会把手上的选区弄丢。
  • 中途取消时，已完成的变体保留，未处理的跳过。

结果验证

  • 结束提示：「批量添加变体完成：成功 N 个，失败 M 个」。
  • variants/ 下出现 N 个 <变体名>.<ext>，自动出图时同时有对应 .sicon。
  • 右键「导入变体 / 版本」里能看到全部新变体条目。
