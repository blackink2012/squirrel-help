一句话定位：把磁盘上的模型文件夹（ma / mb / fbx / obj / usd…）批量打包成 .zasset 资产，并尽量把贴图、材质和说明一起带走。

它是快捷工具里配置项最多的一个 —— 因为"模型资产"不只是模型文件：贴图要不要带走、哪些子文件夹算依赖、名字和标签从哪个文件读，都得你告诉它。这个窗口把这些规则分成了六个卡片。

从哪打开

入口具体怎么做
顶部工具栏「快捷工具」菜单「快捷工具」→「model to zasset」
命令命令面上叫 model_to_zasset（参数见 5.1.11）
脚本浏览器「脚本浏览器」→ 添加插件目录下的 quicktools 目录 → model_to_zasset.py 双击运行

窗口标题是「模型资产转zasset」。

界面上每个控件做什么

卡片「识别到的模型资产」

控件作用取值建议
按钮「扫描模型」按「模型文件夹」+ 递归设置扫一遍，认出哪些是模型资产先扫描再转换，不扫会提示「没有检测到模型资产，请先扫描」
状态「就绪」/「发现 N 个模型资产」扫描结果数量不对就检查模型文件夹与递归
结果列表逐条列出「模型文件和格式」「大小」，子文件夹会折叠成「子文件夹内容 (N 个文件)」用它核对要入库的到底是哪些
列表标题行「.zasset 结构预览」右侧/下方的结构预览，让你先看会打包成什么样一眼确认贴图有没有带进来

卡片「AI 目录解析」（可跳过）

控件作用取值建议
「解析路径:」输入框 + 「浏览...」让 AI 先看一眼某个目录的文件结构目录命名混乱时有用
按钮「AI 解析资产结构」分析该目录，自动生成文件路由与元数据源配置（追加到下面两张卡里，不会覆盖你已有的行）第一次接一个陌生素材包时点它
「AI 服务:」下拉用哪家模型做解析：Ollama（本地）/ DeepSeek / 通义千问 / 智谱 / OpenAI / 自定义本地有 Ollama 就先用它
「AI 模型:」下拉具体模型（实时拉取，可输入）—
「API Key:」输入框云端密钥；本地服务留空（占位写「本地服务无需填写」）—

AI 解析只是帮你填配置，不解析也能手工填下面两张卡。

卡片「模型文件夹」

控件作用取值建议
路径输入框（占位「选择包含模型文件的文件夹...」）要入库的模型在哪选"每个子文件夹是一套资产"的父目录
「浏览...」选目录—

卡片「输出位置」

控件作用取值建议
路径输入框（占位「选择资产输出文件夹...」）.zasset 生成到哪先输出到空目录（库外）核对，再拷进库
「浏览...」选目录—

卡片「转换选项」

控件作用取值建议
「目标格式 (逗号分隔，留空则打包全部):」输入框（占位「例如: ma,usd,abc」）只打包指定格式的模型文件留空 = 全部打包，最保险
勾选「包含子文件夹」+ 「子文件夹:」输入框（默认 ass, textures, sourceimages）这些名字的子文件夹会被一起打包素材包用了别的名字（如 tex）时补上
勾选「递归搜索子文件夹（扫描深层目录中的模型文件）」深层目录里的模型也算资产结构很深时勾
勾选「包含依赖文件（贴图、材质等）」把贴图 / 材质等依赖一起带走建议勾，否则资产会缺贴图
勾选「使用现有元数据和缩略图」目录里已经有说明 / 缩略图就直接用，不重新生成素材包自带 zooInfo / thumbnail 时勾
勾选「转换后导入当前分类」转完把 .zasset 文件夹拷到主界面当前分类目录输出就在库内分类时可勾

卡片「文件路由配置」

决定"哪些扩展名归到 .zasset 里的哪个子文件夹"。

控件作用取值建议
「+ 添加路由」加一行只有特殊目录结构才需要加
「保存路由」把当前路由存下来，下次打开还在改完就点
每行「文件夹:」输入框资产包内部的相对目录名（root 表示根）与源目录对应
每行「扩展名:」输入框归到该目录的扩展名列表默认已有：模型 / 贴图 / ass
每行「×」删掉这一行删错再「+ 添加路由」补回

卡片「元数据源配置」

决定"资产的名字 / 标签 / 作者 / 版本这些信息从哪读"。

控件作用取值建议
「缩略图搜索路径:」列表 + 「+ 添加路径」按模板去找缩略图，例如 {assetName}_fileDependencies/thumbnail.jpg素材包自带缩略图时保留默认几条即可
「元数据源:」每组「源 N」+「删除」一个来源 = 一个说明文件（如 .zooInfo、.json）没说明文件时这条可以全删
「文件路径模板:」输入框说明文件相对路径模板，支持 {assetName} / {folderName}与素材包实际文件名对齐
「文件格式:」下拉（json / txt）说明文件是 JSON 还是纯文本—
「字段映射:」每行 源字段 → 目标字段 + 处理方式下拉把说明里的字段映射到资产字段（如 tags → tags、creators → author）—
处理方式：none / split_comma / first_linenone 原样用；split_comma 按逗号拆成列表（标签常用）；first_line 只取第一行标签用 split_comma，多行简介用 first_line
「+ 添加字段映射」/「+ 添加源」加一行 / 加一组来源—
「保存配置」把元数据源配置存下来改完就点

底部按钮

按钮作用
图标按钮「使用帮助」打开本工具详细帮助
「取消」关窗不转换
「转换」开始批量转换，弹进度；可中止

一次完整的操作流程

  1. 快捷工具 →「model to zasset」；
  2. 「模型文件夹」选到素材包父目录；「输出位置」选一个空目录；
  3. 需要时勾「递归搜索子文件夹」；
  4. 点「扫描模型」，确认「发现 N 个模型资产」与预期一致；
  5. 勾「包含依赖文件（贴图、材质等）」；子文件夹名单按素材包实际目录名补全；
  6. 「目标格式」留空（打包全部）；
  7. 素材包命名很乱时：AI 目录解析 → 选服务商/模型 → 「AI 解析资产结构」，再检查它追加的路由 / 元数据源，点「保存路由」「保存配置」持久化；
  8. 点「转换」，等「转换完成！成功 X, 失败 Y」；
  9. 去输出目录看每个资产一个 .zasset 文件夹，重点抽查：贴图在不在、meta.json 里名称/标签对不对；
  10. 确认后拷进资产库分类，回主界面刷新。

输出结果在哪

  • 每个模型资产生成一个 .zasset 文件夹，位于「输出位置」下；
  • 文件夹里按路由分好子目录（模型、textures/、ass/ 等）+ 缩略图 + meta.json；
  • 勾了「转换后导入当前分类」时会再拷一份到当前分类，完成提示里写「已导入 N 个到当前分类」；回主界面刷新才看得到。

风险与反悔

  • 同名 .zasset 会被整个替换（先删旧的再建新的）。批量转换前请把输出放在空目录，核对后再入库。
  • 路由 / 子文件夹配错 = 资产缺文件：最常见的坏结果是"模型进来了、贴图没进来"。抓重点抽查 1–2 个资产，而不是只看"成功 X 个"。
  • 字段映射配错 = 标签写错字段：转换前建议先用 2–3 个资产试跑，确认 meta.json 里的内容对了再放量。
  • AI 解析只是追加配置，不会删你已有的行；但它可能加重复行，点「保存」前先扫一眼。
  • 反悔：删输出目录里新生成的 .zasset；已经拷进库的用主界面删到回收站（8.5.16）。
