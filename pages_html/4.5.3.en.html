With 「AI 搜索」 (AI search) checked, describe the asset you want in one sentence and press Enter; the plug-in searches by meaning instead of literal matches.

Prerequisites

  • An asset library is open; otherwise the status bar says 「请先打开一个资产库再使用 AI 搜索」 (open an asset library before using AI search).
  • 「AI 搜索」 (AI search) is checked on the right of the search box. The switch is on by default and remembers your last choice.

Steps

  1. Check 「AI 搜索」 (AI search) on the right of the search box; the placeholder becomes "describe the asset you are looking for in one sentence, press Enter for AI search".
  2. Type a natural-language description, for example "old metal with some grime" or "coarse cloth that would work as a carpet".
  3. Press Enter. A spinner appears in the middle of the grid and the status bar shows 「AI 正在分析意图…」 (AI is analyzing the intent…).
  4. Wait for the results to replace the grid. To cancel, clear the search box or click the built-in ✕.

How it works

  1. Local semantic retrieval comes first: local embedding vectors and lexical results are ranked together, and no large model is called at query time.
  2. When local semantics are unavailable or return nothing, a large model extracts keywords and those are searched against names, tags and notes.
  3. If the keywords still return nothing, the original text is tokenized and searched once more, so "using AI" never makes results worse.

Verify the result

  • With local semantic hits the status bar reads 「语义检索 N 条 · 本地嵌入 模型名 · 毫秒数」 (semantic: N results · local embedding <model> · <ms>).
  • When a large model extracted keywords it reads 「AI 搜索「关键词」：找到 N 个资产」 (AI search "<keywords>": N assets found).
  • The grid keeps only the results, and the properties panel on the right clears because the selection was cleared.

Scope

  • The search scope matches the selected sub-library or category; with a specific category selected it searches only that category and its sub-categories.
  • Typing does not filter live — you must press Enter; clearing the input restores the current category list immediately.
提示

Index status, switches and model configuration are described in "Index status and search settings". When the index is unavailable, search degrades automatically and keeps working.
