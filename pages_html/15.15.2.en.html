One-line summary: the plug-in's License manager window — see the current license status, copy the machine code, enter an activation code or activate the trial directly, expand "Offline license activation" to import a manually issued offline license (file or clipboard), and deactivate or restore this machine.

It governs whether "this computer may use the plug-in". A license is bound to the current computer (through the machine code); after expiry you can still browse the library, but import / export / conversion need a valid license.

A complete activation flow

Case A: you received an activation code

  1. Open the license window;
  2. Enter SQAM-… under Activation code;
  3. Click Activate;
  4. Read the bottom message line: "Activated successfully." and the badge and status text update immediately;
  5. Close the window and continue working.

Case B: you received a license file

  1. Open the license window;
  2. Expand Offline license activation, click Import license file… and choose the file (or drag the file into the window);
  3. The message line reports success and the status refreshes.

Case C: you only received license text

  1. Copy the full license text first;
  2. Expand Offline license activation and click Import from clipboard;
  3. The message line reports success and the status refreshes (the license content is never shown).

Case D: no activation code — start the trial or let the server decide

  1. Leave Activation code empty and click the green Activate (same on Settings → License activation, with no sign-in window);
  2. The server decides from the product state: when trials are available it issues a trial license that includes all features; commercial sales answer "the server requires an activation code", so ask sales for one.

Versions and upgrades

Licenses fall into two version-scope rules (the Version scope line states yours):

LicenseVersion scopeDescription
AnnualUnlimitedThe latest version is always usable while valid
Perpetual (one-time purchase)The major version at first activation plus 3 years of free upgradesThe baseline is the current major version the server publishes at first activation (such as 1.x); releases within the following 3 years are free and the scope expands automatically on the online heartbeat; older major versions keep working. Vendor offline-issued perpetual licenses use the major version at issue time and count 3 years from the issue date
TrialUnlimitedThe latest version is usable during the trial
  • The perpetual 3 years start from the first activation date, shown as "free upgrades until <date>"; the baseline version is the current major version the server published at first activation, not whichever version is installed locally.
  • Offline-issued (imported .lic) perpetual licenses have no "first activation" step: the version scope and the 3-year deadline are written by the vendor at issue time and also show as Version scope / free upgrades until in the window; after an online registration the vendor still expands the scope under online-license rules during the upgrade window.
  • To use a newer major version after the 3 years you must purchase again; the version you already bought keeps working and is never disabled.
  • If a newer plug-in reports "the current version exceeds this license's scope", that version is outside your scope — keep using the older version or buy a new license.

What you see afterwards

  • The status badge and text immediately reflect the new state (such as "Licensed: name (perpetual)");
  • The badge and status line on Settings → License activation refresh too;
  • Restricted features (import / export / conversion) become available again.

Risks and how to undo

  • A license is bound to the current computer: changing machines requires activating again; the license file is tied to the machine code, so use the "deactivate this machine → activate on the new one" flow.
  • Deactivate this machine only hits the daily release cap: online deactivation releases the seat after server confirmation, max 3 times per 24 hours. Offline-issued licenses do not support unbinding, and their button is gray.
  • Offline deactivation: when the server cannot be reached it asks once more "delete only the local license?" (the seat stays occupied and no switch is consumed; contact support to unbind later).
  • Undo: after deactivating you must activate again to use restricted features; the same license file exported before unbinding stops working here and cannot be re-imported; when the Restore this machine's license button is enabled, clicking it is faster (online licenses only).
  • The machine code is read-only and determined by this machine, so editing it is pointless; never paste someone else's license text / activation code onto a machine it does not belong to, because activation will fail.
