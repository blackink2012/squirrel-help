A single click selects, a double-click runs the sub-library preset, and a right-click opens the full asset menu.

Single-click

  • Clicking a card selects only that card, and the properties and preview on the right update.
  • Clicking empty space clears the selection and the right panels return to the unselected state.
  • Clicking a row in list view selects that row's asset.

Double-click

A double-click runs the current sub-library's 「双击命令」 (Double-click command) preset. The factory defaults are:

Sub-libraryDouble-click action
MaterialsImport .zmetal and rebuild the shading network
Models / Scenes / Dynamics / Node treesImport ma (node trees select the newly created nodes after import)
LightsImport .zlight
TexturesCreate a PBR material (openPBRSurface)
HDRCreate a dome light (template picked by the current renderer)
ImagesCreate a file node (wire the image into a texture node)
AudioImport to the Maya timeline (current frame = first frame of the audio)
Animation dataRun hierarchy mapping and channel selection to write keyframes onto the scene hierarchy
Unregistered categoriesImport the first available format

The double-click behavior can be changed per sub-library in Settings → 右键菜单 (Context menu) → 双击命令 (Double-click command).

Right-click

  1. Right-click a card; if the card is already part of a multi-selection the whole selection is kept, otherwise it is selected first.
  2. The top of the menu holds items specific to that sub-library, which differ between sub-libraries:
    • Materials / models / lights / textures / scenes / HDR / dynamics: import (executed directly for a single format, a submenu for several), add reference, import geometry and so on, each with its own items such as apply material, assign texture, apply light or create dome light;
    • Images: import as a file node, create an imagePlane, assign to a selected material slot, open the image;
    • Audio: import to the timeline, import to the Time Editor, import to the Trax Editor, import to the camera sequencer;
    • Animation data: import animation, import animation (hierarchy mapping)…, import to selected attributes;
    • Node trees: import ma, add reference, preview nodes.
  3. The lower part holds common items: favorites, select all, copy, open folder, move / copy to, edit, update thumbnail (capture / import / Maya playblast / render / add / capture and add, and for some sub-libraries 「后台渲染」 (Background render)), update asset, delete, preview nodes, analyze thumbnail with AI, asset details and so on.
  4. Right-clicking empty space in the grid gives a menu that also changes with the category: create asset, paste, import from files and more; under 「全部资产」 (All assets) the 「从外部导入」 (Import from Files) submenu shows a grey line: 「当前分类不支持从外部导入」 (this category does not support importing from files).

Verify the result

  • Double-clicking a model asset adds a new object to the Maya viewport and Outliner; double-clicking an image asset adds a file node in the Hypershade; double-clicking an audio asset shows the waveform on the timeline.
  • Right-clicking a material asset shows 「导入」 (Import) and 「应用材质」 (Apply material); right-clicking an HDR shows 「创建穹顶灯」 (Create dome light); right-clicking animation data shows 「导入动画」 (Import animation).

Tips

  • The complete context menu differs per sub-library and can be toggled in Settings → 右键菜单 (Context menu), see 4.1.4.6.
  • If a double-click does nothing, first confirm that sub-library's double-click command is not set to 「无」 (None).
