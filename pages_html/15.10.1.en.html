One-line summary: this window decides what from the Maya scene goes into a library asset, in which formats, under which name.

What this window is for

  • It is called Create asset on the interface and in its title, and it is the window with the most controls in the whole plug-in and the easiest to be intimidated by.
  • It creates no geometry: it exports the current Maya selection (objects, material nodes) into a .zasset asset, packing thumbnails, textures and material presets into the current category.
  • The window is non-modal: you can keep changing the selection and the viewport in Maya while it is open, then click Create asset on the left.
  • One click does not necessarily produce one asset — it depends on the export mode (see 8.10.2).

Exporting your first asset from scratch (step by step)

  1. Pick a category: click a specific category in the left tree (for example Materials → Custom).
  2. Select objects: back in Maya select the objects to export; to export a material, select the material node.
  3. Open the window: click Create asset on the toolbar. Read the info line first — "Target category: … Asset type: …" — and go back and reselect if either is wrong.
  4. Pick a mode: with a single object keep the default Single asset (merge into one asset, capture manually).
  5. Name it: put an English name in Name (English, used by Maya nodes) (it becomes the .zasset folder name, so avoid Chinese and spaces); Readable name may stay empty, in which case the English name is shown.
  6. Choose a thumbnail source: keep Screenshot tool for now (fastest, you frame the image).
  7. Tick formats: for a material asset tick Material preset .zmetal; for a model asset tick Maya ASCII .ma; to carry textures along, confirm Textures textures/ is ticked (it is by default). Leave the other formats for later.
  8. Click the button: click Create asset at the top of the left column.
  9. Capture: the capture overlay appears; drag a rectangle in the viewport over the area you want as the thumbnail (hold Ctrl to lock a square), and release to capture; press Esc or right-click to cancel.
  10. Check the result: a new card appears in the grid and is selected, the preview on the right shows the exported asset, and right-click Asset details verifies formats and paths.

Rules of this window

  • You can click repeatedly without closing it: change the name or formats and click again creates another asset, not an overwrite. To overwrite an existing asset you must use right-click Update asset.
  • The category decides which formats can be ticked: formats that do not apply to the current category are gray with the tooltip "not applicable to this category, locked (adjust in Settings → Export defaults)".
  • "Ready / not loaded / unavailable" after a format is plug-in status, not the format name; see 8.10.3.
  • Same names ask first: when the target category already holds an asset with that name, the "asset name conflict" window appears first, see 8.12.5.
