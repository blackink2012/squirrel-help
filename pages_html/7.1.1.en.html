zmetal is the node network data of a material asset, stored inside the .zasset; import rebuilds the whole shading network from it.

Prerequisites

  • A material asset (a .zasset folder) exists.
  • The asset directory can be opened in a file manager.

Steps

  1. Right-click the material asset in the library and choose 「打开文件夹」 (Open folder).
  2. Open meta.json and check name, name_cn, node_type, renderer, color_space and formats.
  3. Find node.zmetal. It is JSON, not a Maya scene file; some external assets name the .zmetal after the asset, and import looks for node.zmetal first and only then takes any .zmetal.
  4. Open node.zmetal and confirm it has root_materials and nodes at the top level; material and texture nodes all live in nodes.
  5. When the asset carries textures, look at textures/; fileTextureName inside node.zmetal has been rewritten to a relative textures/... path.

Verify the result

Open the same .zmetal with the context menu's 「预览节点」 (Preview nodes) and the canvas shows the material nodes matching root_materials plus their upstream connections; importing it into the scene creates the same-named material in the Hypershade.

Tips

  • .zmetal records only material nodes and connections; it contains no geometry, cameras or lights.
  • node.mcm records the topological correspondence between materials and objects, which is separate data from zmetal.
  • Prefer .zmetal when importing materials, because it stores node attributes and connections; only when it is missing does import fall back to the material network in .ma/.mb.
  • The file exists only if the zmetal format was enabled at export time.
