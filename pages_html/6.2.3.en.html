The thumbnail source decides how the image is produced and how fast; the capture delay only affects automatic captures of later assets in full-auto mode.

Prerequisites

  • The objects to capture or playblast are visible in the viewport; single-asset mode does not isolate automatically, so isolate manually when needed.
  • With Render the scene needs a renderable camera and the current renderer installed.
  • The thumbnail edge length comes from Settings → 常规 → 缩略图大小 (General → Thumbnail size), 512 pixels by default.

Steps

  1. Choose one under 「缩略图来源」 (Thumbnail source) in the left column:
    • 截屏工具 (Screenshot tool): after export a screen overlay appears; drag a rectangle and release to capture (hold Ctrl to lock a square, Esc or right-click to cancel), capturing the viewport image. Fastest, but produces a still only.
    • Maya 拍屏 (Maya playblast): playblasts the viewport. With animation frame mode set to current frame it produces a still; with timeline or keyframes it produces thumb.mp4 (the first frame is also saved as a still).
    • 渲染图 (Render): renders with the current renderer. Highest quality and slowest; timeline or keyframes also compile thumb.mp4.
  2. Only full-auto mode shows the 「截图延迟」 (Capture delay) box. It sets how many seconds to wait after each asset export before capturing: 0–60, 2 by default, 0 meaning no wait.
  3. Assets without geometry of their own, such as materials, textures and lights, can first get a carrier object placed in the scene via the 创建模型 (Create model) or 创建灯光 (Create light) dropdown, and then be captured.
  4. Finish the remaining format settings and click 「创建资产」 (Create asset).

Verify the result

  • The grid card shows the new thumbnail; a still is thumb.sicon, an animation or video is thumb.mp4.
  • In a batch export, playblast and render thumbnails are generated after all assets are exported, so cards switch to the final image only when the progress finishes.

Tips and warnings

Tip: the first capture in full-auto mode fixes the framing and capture region for every later asset; afterwards only the target is moved to the center of the image, with no auto-framing or distance changes.

Tip: the capture delay only applies to automatic captures with the screenshot tool; semi-auto and single asset are confirmed by you every time, so no delay is needed.

Warning: timeline plus render renders frame by frame and Maya becomes unresponsive for a while; with many assets this takes noticeably longer, so confirm the framing with a playblast first.

Tip: to change the thumbnail of an existing asset use the context menu's 「更新缩略图」 (Update thumbnail); 「后台渲染」 (Background render) is headless offscreen rendering (a separate mayapy / renderer process that does not occupy the current viewport) and is a different entry from the export thumbnail here.
