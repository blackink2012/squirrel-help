A custom quick tool is simply a .py file placed in quicktools/, and the menu lists it automatically by file name.

Directory conventions

LocationWhat goes there
<plug-in root>/quicktools/Quick tool scripts; the menu scans only .py files at this level and never recurses into sub-directories
<plug-in root>/Assets/help/<tool name>/help.htmlThe tool's own help page; for an English page also place a same-named _en.html next to help.html
<plug-in root>/Assets/preset/Tool configuration such as model_mapping.json, pbr_mapping.json, *_expression.json
<plug-in root>/Assets/material_mapper_presets/Material mapping .mmap and .mlist presets

Naming conventions

  • The file must end in .py and its name must be unique in that directory.
  • The menu entry name is the file name without .py with underscores replaced by spaces; a Chinese file name is shown as is.
  • The menu sorts by file name and applies no hidden filter, so do not keep temporary or backup scripts in quicktools/ or they appear in the menu too.
  • Tools called from the script browser or the command channel should keep a stable file name, since frequent renames break favorites and mappings.

Code conventions

  • Use main() or run() as the entry, or keep an if __name__ == "__main__": block for a plain script (see 9.7.2).
  • Match the rest of the plug-in: prefer package-absolute imports and fall back to top-level ui.* / utils.*, so the script runs both inside the plug-in and in the Script Editor.
  • Do not put a tool's own configuration and presets in the root of quicktools/; place them in the matching directory under Assets/ so they are not scanned as scripts.

Verify the result

  • The 「快捷工具」 (Quick tools) menu shows the new file name (with underscores displayed as spaces).
  • Clicking it starts the window or script normally and the Script Editor shows no ImportError.
  • The help button opens Assets/help/<tool name>/help.html.

Notes

  • New files need no menu code or registry change; the menu rescans the directory every time it opens.
  • The standalone edition dispatches quick tools to Maya by default; whether a pure file tool runs locally depends on the host allowlist (see 9.7.3).
