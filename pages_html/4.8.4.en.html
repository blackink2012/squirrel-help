The batch operation bar offers batch entries for tags, names and categories; fields such as notes, renderer and color space have no shared batch form yet.

Fields that can be batch edited

FieldEntryNotes
TagsBatch operation bar → batch tagsAdd tags or remove tags
Display name, file nameBatch operation bar → batch renamePrefix, suffix or find and replace
CategoryBatch operation bar → batch moveChange category within the same sub-library
Name, tags, notes, categoryApplying AI batch analysis resultsWritten in bulk from AI suggestions, see the AI tools chapter

Batch adding or removing tags

  1. Multi-select assets and click 「批量标签」 (Batch tags) in the batch operation bar.
  2. Choose 「添加标签」 (Add tags): type tags (comma separated) or click common tags, then click 「应用」 (Apply).
  3. Choose 「删除标签」 (Remove tags): click existing tags so they turn red, then click 「应用」 (Apply).
  4. Check 「操作预览」 (Operation preview) for the asset and tag counts before running.

Batch changing names and categories

  1. Rename: use 「批量重命名」 (Batch rename), choose display name or file name, then prefix, suffix or find and replace.
  2. Change category: use 「批量移动」 (Batch move) and pick the target category from the current sub-library's list.
  3. Both operations reload the grid when they finish.

Verify the result

  • The properties panel shows the updated tags, name and category.
  • Searching by the new tag or name finds these assets.
  • The asset count of the target category grows in the category tree.
注意

Notes, material type, software, renderer and color space have no batch edit dialog; change them per asset in the properties panel, or write them one by one through the edit command.

警告

Batch writes overwrite the matching fields on the selected assets directly. Confirm the selection and check the operation preview first.
