对话面里的助手不仅能聊天，还能调用插件注册的工具去查资产、读场景、跑脚本；这些工具通过本地底座路由到当前 Maya。

助手能用什么

  • 命令面工具：squirrel_list_instances、squirrel_list_commands、squirrel_execute_command、squirrel_execute_batch。
  • 长任务：squirrel_execute_async 返回作业号，用 squirrel_jobs 查询或取消；超时未回的结果用 squirrel_late_results 取回。
  • 兜底通道：squirrel_maya_bridge，底座或实例不可用时直接走 Maya 的 commandPort。
  • 文档与依赖：maya_docs 查命令、节点与 API；squirrel_ai_deps 体检或安装 AI 依赖。
  • 知识：随包技能束提供操作纪律与场景配方，落在 <dshHome>/skills。

实例绑定

默认绑定本对话所属的那个 Maya 实例，命令可省略实例 id。多开 Maya 时若确实要操作另一台，需显式允许跨实例，否则助手不会替你换人。

模型与凭据

对话用哪个模型由 dsh 自己管理，首次对话时按它的提示登录或填写 API Key；插件不接管这部分凭据。

边界

  • 工具调用受命令风险级别约束；高危命令应先预览再执行。
  • 面板里看不到 squirrel_* 工具时，先确认技能已落位、底座在跑、当前 Maya 已注册；dsh_status 能一次列出这些状态。
