一句话定位：「创建资产」= 把 Maya 里当前选中的东西导出成资产库里的一个新资产，所以它必须先有一个具体分类、并且 Maya 里有东西可导。

怎么用

  1. 左侧分类树里选中一个具体分类（材质 / 模型 / 灯光 / 贴图 / 场景 / 动态 / 节点树等）；
  2. 在 Maya 视口里选中要导出的物体（不选也能打开对话框，但导出时取不到内容）；
  3. 点资产区工具条上的「创建资产」按钮；
  4. 在打开的「创建资产」对话框里确认配置，再执行导出。

这个按钮做什么

项说明
作用打开「创建资产 / 导出」对话框，从当前 Maya 场景导出成资产，写入当前分类
取值来源当前 Maya 场景里选中的物体（独立版取「Maya 目标」那台 Maya 的选中）
前提① 选中了具体分类（不是「全部资产」、不是收藏夹、不在回收站）；② 分类不是「图片」「音乐」；③ Maya 已连接（Maya 内版天然满足；独立版要先选 Maya 目标）；④ 场景里有可导出的数据
点了之后弹出非模态的创建对话框（可以边看场景边填），确认后开始导出并在网格里新增卡片
注意会写资产库（新文件夹 + 元数据 + 缩略图）；同名时按「同名冲突处理」设置决定提示 / 自动改名 / 手动覆盖，见 8.12.5

在不同分类下的变化

当前分类按钮表现
材质 / 模型 / 灯光 / 贴图 / 场景 / 动态 / 节点树正常显示「创建资产」
动画数据文字变成「导出动画」，把当前选中层级逐帧导出成动画资产（.zasset），提示也一起换掉
图片 / 音乐按钮隐藏（这类资产是文件本身，没有「从场景创建」的概念）
全部资产按钮灰掉（没有目标分类，不知道存到哪）
回收站按钮灰掉

子菜单

本按钮没有下拉子菜单（不带 ▾），点一下就是打开对话框。对话框里各页签 / 字段的详解见 8.10.1 ~ 8.10.8。

风险与反悔

  • 新建 vs 覆盖：默认是「新建一个资产」；在对话框里若选了「更新 / 替换」那类模式，才会覆盖已有资产 —— 覆盖前看清确认框。
  • 导出中断可能留下半成品资产（空壳 / 缺贴图）：先在库里确认卡片有缩略图、能正常导入，不合格就删掉重导，见 4.3.5.1。
  • 反悔方式：新资产用右键「移到回收站」删除（可还原）；覆盖类操作按对话框提供的备份 / 版本机制处理，见 8.5.16。

小白易错点

  • 按钮点不动：先看是不是停在「全部资产」或回收站；再看是不是「图片 / 音乐」分类（那里按钮直接隐藏）。
  • 导出后资产是空的：导出前没在 Maya 里选中物体，或选中的东西没有可导出的数据（例如空组）。先在视口里选好再点。
  • 独立版点了报连不上 Maya：先在「Maya 目标」里选中一台在线 Maya，见 8.2.4。
  • 导出没反应 / 一直转圈：大资产或需要渲染缩略图时会慢；看对话框与状态栏提示，别重复点（会重复导出）。
