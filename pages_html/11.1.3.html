插件的设置分散在个人目录和插件包的 preset 目录里，改配置前先分清这两处。

文件一览

文件位置主要内容
app_settings.json~/.squirrel_asset_manager/app_settings.json字号、缩放、主题、语言、视图、库列表与默认库、AI 服务商与 Key、桥接开关、对话面位置、外部工具选择
settings_preset.json~/.squirrel_asset_manager/settings_preset.json「常规 → 设置预设」保存的整套界面偏好快照；可用于导入 / 导出 / 还原（不存在 = 还没保存过预设）
config.json<插件包>/Assets/preset/config.json子库与默认分类、支持格式、贴图后缀、同名冲突策略、贴图 / 依赖导入策略、材质预设
export_preset.json<插件包>/Assets/preset/export_preset.json各资产类型的默认导出格式、关联文件与仅导出材质
context_menu_preset.json同目录各子库的右键菜单项开关
double_click_preset.json同目录各子库的双击命令与导入子选项
pbr_mapping.json同目录PBR 贴图类型别名
library.json每个资产库根目录库版本、名称与子库列表
FolderMetadata.fdata各子库目录子库或分类的 id、名称与类型

<插件包> 指 squirrel_asset_manager 目录；~ 指当前 Windows 用户目录。

怎么定位

  1. 先看设置项属于哪一类：界面偏好与库列表在 app_settings.json，其余在 Assets/preset/。
  2. 在资源管理器地址栏输入 %USERPROFILE%\.squirrel_asset_manager，可直接打开个人配置目录。
  3. 预设文件随插件包走；确认当前实际加载的是哪一份插件包后再改。

修改与备份

  • 优先用设置窗口修改，避免手写 JSON 出错。
  • 手工编辑前先复制一份同名 .bak；修改后重启插件再验证。
  • app_settings.json 加载失败或 JSON 损坏时，会回退默认值，并把原文件备份为 .bak 或 .corrupt_<时间戳>。
  • 同目录还会出现 bridge_port.log 与 bridge_recover.log，用于排查桥接端口与断连自愈。
  • settings_preset.json 是「设置预设」的本机副本：想备份整套界面偏好，直接用设置窗里的「导出预设」生成一份 JSON 更稳妥。

结果验证

  • 修改任意一项设置并点「应用」后，对应文件的修改时间更新。
  • 重启插件后设置仍然保留。

提示

警告：config.json 与各预设文件在插件包内，重装或覆盖插件前先备份。

提示：app_settings.json 中的 API Key 以明文 JSON 保存，不要把该文件发给他人。
