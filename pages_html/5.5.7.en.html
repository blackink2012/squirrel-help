「应用灯光参数到选中灯光」 (Apply light parameters to the selected light) writes a light asset's parameters into the light already selected in the scene; it never creates a light.

Prerequisites

  • One or more light nodes (transform or shape) are selected in Maya.
  • The light asset contains .zlight; otherwise it falls back to the light network in .ma/.mb.

Steps

  1. Select the target light in the viewport or the Outliner.
  2. Right-click the light asset and choose 「应用灯光参数到选中灯光」 (Apply light parameters to the selected light).
  3. The plug-in builds a temporary light from the .zlight under the source renderer to serve as the parameter source.
  4. Parameters are written item by item: same type writes directly, cross type maps through the .mmap files in Assets/light_mapper_presets/.
  5. Afterwards the temporary source light is deleted and the modified light is selected.

Verify the result

  • Color, intensity, exposure, color temperature and texture attributes of the selected light match the asset.
  • The Script Editor reports 「已应用 N 处灯光参数」 (applied N light parameter groups).
  • No temporary light is left in the scene.

Tips

  • With no light selected it reports 「未选中任何灯光节点」 (no light node selected).
  • With nothing applicable it reports 「没有可应用的灯光参数」 (no light parameters to apply).
  • When .zlight is missing and the .ma/.mb fallback also fails it reports 「.zasset 不含 .zlight 文件，且 .ma/.mb 回退失败」 (the .zasset contains no .zlight file and the .ma/.mb fallback failed).
  • This only changes parameters and never changes the light's type in the scene.
