节点编辑器可以打开 .ma 或 .zmetal，把 createNode / connectAttr 或 JSON 里的节点网络画成可读的节点图。

前置条件

  • 已有 Maya ASCII .ma 或资产里的 .zmetal 文件。
  • 文件不是二进制 .mb。

操作步骤

  1. 在资产库右键资产，指向「预览节点」，选择 .zmetal 或非 node.ma 的 .ma。
  2. 也可以直接在编辑器点「打开文件」，或把 .ma / .zmetal 拖进窗口。
  3. 用鼠标中键或 Ctrl+左键拖拽平移，滚轮缩放；「层级布局」按从左到右重排。
  4. 连线时点击节点右侧橙色输出端口，再点目标节点左侧灰色输入端口；方向不能反。
  5. 选中节点或连线后按 Delete 删除；Ctrl+Z / Ctrl+Y 撤销与重做。
  6. 点「保存文件」覆盖原文件；「另存为...」可选择保存为 .ma 或 .zmetal。

结果验证

画布上的节点数与文件中的节点数一致，连接关系与 connectAttr（或 source_node/source_attr）一致；保存后重新打开，改动仍在。

提示

  • .ma 保存以原文件为基底，只删除你移除的节点，几何体、相机等其它数据保留；.zmetal 保存以原 JSON 为基底，只更新变动的节点和连接。
  • 当前版本不支持手动添加新节点；要新增节点请先在 Maya 中创建，保存为 .ma 后再编辑。

警告

保存会直接覆盖原文件。编辑资产内的 .zmetal 前先备份整个 .zasset。
