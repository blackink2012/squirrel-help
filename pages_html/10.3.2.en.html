Assigning textures connects a texture or HDR asset to an existing node: a texture to a material, or an HDR to the selected dome light.

Prerequisites

  • The target material node or dome light exists in the scene and is selected in Maya.
  • The asset type matches the action: a texture asset uses 「指定贴图到材质」 (Assign texture to material), an HDR asset uses 「指定贴图」 (Assign texture).

Steps

  1. Select the target material or light node.
  2. Right-click the texture asset in the library and choose 「指定贴图到材质」 (Assign texture to material); for an HDR asset choose 「指定贴图」 (Assign texture).
  3. You can also call assign_texture: kind=auto decides from the asset's meta.asset_type, texture forces a material connection and hdr forces a dome-light connection.
  4. To import the asset's textures into the scene first, call import_texture; without a texture name it imports every image texture and shares one place2dTexture.

Verify the result

It returns status=ok with an assigned list; a texture asset reports kind as texture and an HDR asset as hdr. For textures a newly connected file node appears in the Hypershade, while the HDR branch updates the dome light's texture path.

Tips and warnings

  • The HDR branch needs an existing selected dome light; without a target it returns an error instead of creating one. Use "create a dome light" for that.
  • auto relies on asset metadata, so pass kind explicitly when type detection is unreliable.
  • A failed assignment returns reason; confirm the target node type matches the current renderer and retry.
