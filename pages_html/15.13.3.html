一句话定位：让 AI 看一眼资产缩略图，然后给出命名、分类、标签、注释的建议，你逐个勾选后写进资产元数据。

它是"看图说话"：输入是缩略图，输出是四条元数据建议。所以没有缩略图的资产不能被分析（会被跳过并打印提示）。AI 只提建议，最后一律由你勾选后点「应用到元数据」才真正写库 —— 这中间那一步审查就是给你改错的机会。

怎么打开

有两种入口，区别在于分析几个资产、要不要先过配置窗：

入口位置行为
单个资产（直接出结果）资产网格里右键一个资产 → AI 分析缩略图用当前「设置 → AI 设置」里的分析配置直接分析，分析完弹出本页的结果窗口
一个或多个资产（先配置）顶部工具栏「AI 工具」→ 菜单第一项「AI 分析缩略图 (N 个选中资产)」先弹「AI 分析配置」窗口让你确认服务商 / 模型 / 语言等，点「开始分析」后跑进度条；勾了「分析完成后弹出窗口供我审查和编辑」时，结束后按数量弹结果窗口
  • 只选 1 个：结束后弹本页的「AI 分析结果」窗口。
  • 选了多个：结束后弹批量结果窗口，见 8.13.4。

第一步要先过「AI 分析配置」窗口（多选入口才有）

控件作用取值建议
标题「请选择 AI 分析参数」说明这一步是选参数，不是直接开跑—
AI 服务商决定用哪家的模型做图像分析本地有 Ollama 就先用它；要用云端再填 Key
API Key云端密钥，密码态；选本地服务时置灰只填自己服务商的 Key（工具会按服务商分别记住，不会串用）
API 地址接口地址；切服务商时若还是默认值会自动换成该家的默认地址一般不改
AI 模型实时拉取的下拉列表，可手工输入模型名必须选支持图片（视觉）的模型，纯文本模型分析不了缩略图
输出语言中文 / English，决定 AI 写出来的命名、标签、注释用哪种语言按团队习惯
提示行（黄色）不同服务商的「哪些模型不支持图片」提醒，会随服务商变化看到它就把模型换掉
勾选「分析完成后弹出窗口供我审查和编辑」勾 = 分析完先给窗口审查（推荐）；不勾 = 直接按结果写库第一次用请保持勾选
勾选「翻译原有 tag 到目标语言」勾 = 资产原有的标签先翻译成目标语言再合并库里混着中英标签时有用
按钮「取消」关掉，不分析—
按钮「开始分析」开始逐资产分析，显示进度条（可取消，已分析完的会保留）—

第二步：AI 分析结果窗口

资产信息（只读）

控件作用
原始名称资产现在的名字，用来和下面的"建议命名"对照
顶级分类资产属于哪个子库（如 materials）

AI 分析结果（逐字段勾选）

控件作用取值建议
「命名」勾选框 + 输入框AI 建议的易读名称只勾你认可的；不勾 = 保留原名
「分类」勾选框 + 输入框AI 建议的子分类只勾你认可的；不勾 = 分类不变
「标签」勾选框 + 输入框（占位「用逗号分隔的标签」）AI 建议的标签，逗号分隔可以手动补删再应用
「注释」勾选框 + 多行输入框AI 生成的一段描述适合做搜索用的说明文字
底部勾选「移动到分析出的分类」勾 = 应用时把资产文件挪到 AI 给出的分类目录；不勾 = 只改元数据里的分类字段第一次建议不勾，确认分类可靠后再考虑

底部按钮

按钮作用
「取消」什么都不写，关掉（分析结果丢弃）
「应用到元数据」把勾选了的字段写进资产元数据；没勾的字段一个都不动

一次完整的操作流程

  1. 在资产网格里选中 1 个或多个资产（多选走「AI 工具」菜单）；
  2. （多选）在「AI 分析配置」里选服务商 / 模型 / 输出语言，保持「分析完成后弹出窗口供我审查和编辑」勾上，点「开始分析」；
  3. 等进度条跑完（1 个资产会直接弹结果窗口）；
  4. 在结果窗口里逐条看建议：名字不对就不勾命名；分类不对就不勾分类；标签可以改完再勾；
  5. 需要让资产真的换分类时再决定要不要勾「移动到分析出的分类」；
  6. 点「应用到元数据」；
  7. 回资产网格确认名称 / 标签 / 注释已更新（分类若移动过，资产会出现在新分类下）。

做完能看见什么

  • 资产的名称、分类、标签、注释按你勾选的字段更新。
  • 勾了「移动到分析出的分类」的资产会搬到对应分类目录下，刷新后在新分类里能看到。
  • 多选时是逐个资产应用；批量那条路的界面见 8.13.4。

风险与反悔

  • 应用是"覆盖式"的：勾了哪个字段，就用 AI 的建议整个覆盖掉那个字段的原值，合并逻辑不在这一步。改错了没有一键撤销 —— 要把字段重新改回去（多选时建议先只试一个资产）。
  • 「移动到分析出的分类」会移动资产文件，这是本页唯一会改磁盘位置的操作。移错了可以右键该资产 →「移动到」再搬回来（见 8.5.15）。
  • 想完全不冒险：把「分析完成后弹出窗口供我审查和编辑」留着，先只应用"标签 + 注释"这两个低风险字段。

常见问题

现象原因处理
弹窗提示 AI 不可用 / 分析失败服务不可达，或当前模型不支持图片换成本地 Ollama 或换成视觉模型
某些资产被跳过它们没有缩略图先右键「更新缩略图」补一张再分析
分析很慢云端模型逐张图调用，或本地模型在冷启动少选几个、或先让本地模型热起来
