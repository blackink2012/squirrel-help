One-line summary: batch-pack the model folders on disk (ma / mb / fbx / obj / usd…) into .zasset assets, bringing textures, materials and descriptions along where possible.

This is the most configurable tool under Quick tools — because a "model asset" is more than a model file: whether textures come along, which subfolders count as dependencies, and where names and tags are read from all have to be told. The window splits those rules into six cards.

A complete flow

  1. Quick tools → model to zasset;
  2. Point Model folder at the asset pack's parent directory and Output location at an empty directory;
  3. Tick Recursively search subfolders if needed;
  4. Click Scan models and confirm "Found N model assets" matches expectations;
  5. Tick Include dependency files (textures, materials and so on) and complete the subfolder list with the pack's real directory names;
  6. Leave Target formats empty (pack everything);
  7. When the pack is messily named: AI directory parsing → choose service / model → AI parse asset structure, review the appended routing / metadata rows, then click Save routes and Save configuration;
  8. Click Convert and wait for "Conversion finished! X succeeded, Y failed";
  9. In the output directory check that each asset is a .zasset folder, and spot-check that textures are present and meta.json has the right name / tags;
  10. Once confirmed, copy into the library category and refresh the main window.

Where the output lands

  • Each model asset produces a .zasset folder under the output location;
  • Inside, the routing splits files into subdirectories (models, textures/, ass/ and so on) plus a thumbnail and meta.json;
  • With Import into the current category after conversion ticked another copy goes into the current category and the completion message says "imported N into the current category"; refresh the main window to see them.

Risks and how to undo

  • A same-named .zasset is replaced entirely (delete the old one, then build the new one). Before a batch conversion, output into an empty directory and import only after verification.
  • Wrong routing / subfolders = missing files: the most common bad outcome is "the model came in, the textures did not". Spot-check 1–2 assets instead of trusting "X succeeded".
  • Wrong field mapping = tags written to wrong fields: test with 2–3 assets and confirm meta.json before scaling up.
  • AI parsing only appends configuration and never deletes your existing rows, but it may add duplicates, so scan the rows before clicking Save.
  • To undo, delete the newly generated .zasset folders; ones already copied into the library go to the recycle bin from the main window (8.5.16).
