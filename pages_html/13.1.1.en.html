If the plug-in is not loaded, usually the install directory is not on Maya's import path, the userSetup.py startup block is missing, or a stale copy is imported first.

Symptoms

  • After Maya starts there is no Squirrel Asset Manager entry in the status line (the shelf button is only created during installation and is not recreated at startup).
  • Running import squirrel_asset_manager in the Script Editor raises No module named 'squirrel_asset_manager'.
  • The package imports, but opening the window reports a missing submodule, for example No module named 'squirrel_asset_manager.core'.
  • Different Maya versions on the same machine behave differently, or an update still loads the old interface.

Possible causes

CauseHow to tellAction
Incomplete install directoryNo __init__.py or ui\main_window.py under %LOCALAPPDATA%\SquirrelAM\squirrel_asset_manager\ (or the directory you chose during install)Rerun the installer with Maya integration ticked
Missing userSetup.py startup blockThe current version's Documents\maya\<version>[\<language>]\scripts\userSetup.py has no "Squirrel Asset Manager - import path" markerRerun the installer and tick Maya integration for that version so the startup block is written
Shelf button deletedThe Custom shelf has no Squirrel Asset Manager button, but the status line icon worksRerun the installer (the button is only created at install time and is not recreated at startup)
Package directory cached as an empty namespace packageOnly Assets\ remains, there is no __init__.py, yet sys.modules already contains squirrel_asset_managerFix the directory and restart Maya; the startup block clears that cache
A stale copy loads first<app>\scripts\squirrel_asset_manager or <version>\scripts\squirrel_asset_manager still existsAfter confirming it is an old copy of this plug-in, delete it and restart Maya
Core module ABI mismatchImport reports an extension module or DLL errorSee 6.1.2 "Version and ABI mismatch"
Install directory is not readableDirectory attributes or antivirus blockingRestore read access, or reinstall into a user-readable directory

Steps

  1. Confirm the install directory exists and contains __init__.py and ui\main_window.py.
  2. Open userSetup.py for the current Maya version and check for both marker lines, "Squirrel Asset Manager - import path" and "Squirrel Asset Manager END".
  3. If the markers are missing, rerun the installer with Maya integration ticked, then fully quit and restart Maya.
  4. Check for stale copy directories. Delete only copies you are certain belong to this plug-in; never delete the whole scripts directory.
  5. In the Script Editor run import squirrel_asset_manager as sq; print(sq.__file__) and confirm the loaded path points at the install directory.
  6. Open the plug-in again from the menu, the shelf or the status line.

Verify the result

sq.__file__ points at %LOCALAPPDATA%\SquirrelAM\squirrel_asset_manager\__init__.py (or the directory you chose during install), and the plug-in window opens with a working category tree.

If it still fails

  • Copy the full traceback from the Script Editor, keeping the first error line and the last few stack frames.
  • Check whether the current Maya's Python version matches the installer's ABI, see 6.1.2 "Version and ABI mismatch".
  • If only AI, bridging or licensing features are unavailable, follow 6.1.3 "Startup errors" to check the matching logs instead of reinstalling repeatedly.
  • When reporting, include the sq.__file__ result, the install directory tree and the relevant part of userSetup.py.
