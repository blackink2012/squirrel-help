Turn an existing image into an asset thumbnail: 「导入」 (Import) replaces the main image, 「添加」 (Add) puts the image into a new extra slot.

Two ways to import

ModeWhereResult
Import (replace)Context menu → update thumbnail → import; or 「导入」 (Import) in the preview panelOverwrites the main thumbnail
Add (new slot)Context menu → update thumbnail → add; or 「添加」 (Add) in the preview panelEvery file becomes a new extra slot

Steps (replace the main image)

  1. Select the asset and choose 「更新缩略图 → 导入」 (Update thumbnail → Import) from the context menu, or click 「导入」 (Import) in the preview panel.
  2. Pick an image file. Supported extensions include .sicon, .jpg, .jpeg, .aicon, .bmp.
  3. After confirming, the plug-in writes the image into the main thumbnail location.
  4. Grid cards and the preview panel refresh automatically.

Steps (add a new slot)

  1. Choose 「更新缩略图 → 添加」 (Update thumbnail → Add) from the context menu, or click 「添加」 (Add) in the preview panel.
  2. Several files can be chosen at once. In addition to the extensions above, .png is supported.
  3. After confirming, every file becomes a new slot and the preview panel jumps to the last one.
  4. Switch between them with the arrows, the mouse wheel or the counter at the bottom.

Verify the result

  • The preview panel shows the newly imported image.
  • After replacing the main image the card cover changes too.
  • After adding several images the counter changes from 1/1 to n/n and the delete button becomes available.
注意

Importing only copies the image content into the asset directory; it never moves or modifies the original file you picked.

警告

「导入」 (Import) overwrites the existing main thumbnail and does not keep the old image. Use 「添加」 (Add) when several images must be kept.
