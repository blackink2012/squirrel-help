对多个 .ma / .mb 依次打开并执行同一段 MEL 或 Python 脚本，可选执行后保存。

用途

适合批量改命名、清理节点、统一渲染设置等重复操作，不必手动逐个打开场景。

输入与输出

  • 输入：一个文件列表（.ma / .mb），以及一段 MEL 或 Python 脚本。
  • 输出：被修改并保存的 .ma / .mb（勾选「执行后保存文件」时）；执行过程写入窗口下方的「执行日志」。

操作步骤

  1. 打开「快捷工具 → 批量处理maya文件」。
  2. 在「文件选择」中点击「添加文件」加入 .ma / .mb，可多选；不需要的条目可「移除选中」或「清空列表」。
  3. 在「脚本输入」选择 MEL 或 Python，粘贴脚本；也可用「MEL示例」「Python示例」快速试用。
  4. 先用「测试执行（当前场景）」验证脚本效果。
  5. 确认「执行选项」后点击「批量执行」。
  6. 查看日志末尾的成功 / 失败统计。

结果验证

  • 日志中出现「批量处理完成！」，并给出成功与失败文件数。
  • 勾选保存时，目标文件在磁盘上的修改时间已更新。
  • 处理结束后，工具会尝试重新打开执行前已保存的场景。

参数与注意事项

选项默认说明
执行后保存文件开每个文件执行成功后以 force 保存
显示详细信息开日志中逐个显示正在处理的文件与保存结果
高级选项关展开「执行前备份文件」「强制保存」「忽略错误继续执行」三项
  • 源码核对：当前批处理逻辑只读取「执行后保存文件」与「显示详细信息」；「高级选项」里的三项尚未被执行逻辑使用，勾选不会改变行为（待确认是否为预留功能）。
  • 单个文件执行出错会记录失败并继续处理下一个，不会中断整批。
  • 批量执行会逐个打开文件，当前未保存的场景可能被替换；执行前请先保存当前场景。只有执行前场景已有文件路径时，结束后才会自动重新打开。
  • 日志支持「清空日志」「保存日志」（.txt）与「复制日志」。
