Click a tag chip in the properties panel, or check tags in the 「编辑标签」 (Edit tags) window, and the grid keeps only assets that carry all of those tags.

Prerequisites

  • An asset with tags is selected, so the properties panel on the right shows tag chips.
  • Tags combine as "all must match" in a real asset library, not "any of them".

Steps

  1. Select an asset in the grid; the properties panel lists its tags.
  2. Click a tag chip to filter by that tag only; click the same tag again to remove it.
  3. Hold Ctrl and click several tags to apply them all at once.
  4. You can also click 「编辑标签」 (Edit tags) in the toolbar to open the tag window, click chips to toggle them and click 「清除筛选」 (Clear filters) to remove them all.
  5. Clicking the ✕ in the search box, or deleting the keyword in it, also clears the tag filter.

Verify the result

  • The grid shows only assets carrying all selected tags.
  • The 「编辑标签」 (Edit tags) toolbar button stays highlighted while a tag filter is active.
  • The selected tag text is written into the search box and a clickable ✕ appears.
注意

In the current version the 「用标签筛选」 (Filter by tags) dropdown inside the search bar is temporarily hidden; filter tags through 「编辑标签」 (Edit tags) in the toolbar or the tag chips in the properties panel.

提示

Tag matching is case-insensitive; filtering only affects what is displayed and never changes the asset's tags.
