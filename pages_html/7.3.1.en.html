Two-column attribute mapping is the row-by-row correspondence of "source material attribute → target material attribute"; conversion copies or converts values according to these rows.

Prerequisites

  • The source and target material nodes can be selected in the Maya scene.
  • 「材质节点属性映射工具」 (Material node attribute mapping tool) is open.

Steps

  1. Select the source material node in Maya and click 「加载源材质」 (Load source material) in the tool.
  2. Select the target material node and click 「加载目标材质」 (Load target material).
  3. Click 「添加行」 (Add row), pick the source attribute in the left column and the target attribute in the right column.
  4. When a conversion is needed, pick a function in the 「转换函数」 (Transform function) column (such as glossiness to roughness or transparency to transmission (weight)); functions with arguments take JSON in the 「参数(JSON)」 (Parameters (JSON)) column, for example {"scalar": 2.0}.
  5. Fill 「默认值」 (Default value) for a fallback; you can also select a target material first and click 「载入默认值」 (Load defaults) to batch-fill the column with its current values.
  6. When an attribute is unclear, click 「属性浏览器」 (Attribute browser) and pick from the selected node's readable, writable and visible attributes.

Verify the result

The row count matches the intended mapping and both columns show attribute names; the status bar shows the row count; after converting to a new material the target values match the source values or the selected function's conversion result.

Tips

  • Do not map color sub-channels (such as diffuseColorR) individually; a color is written through its parent attribute, and writing sub-channels separately often yields wrong results.
  • When the same source attribute appears again, the later row is cleared and a duplicate is reported.
  • The search box filters rows live by keyword, which helps in large tables.
