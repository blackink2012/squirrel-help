资产卡片的右键菜单按「子库 + 设置里的右键菜单预设」生成。每个子库的菜单都不一样：最上面那几行是子库专属的，往下才是所有子库共用的公共段。本页给一张能一眼对照的总表；每一项「点了之后到底发生什么」的细则见「菜单详解」8.5.2～8.5.12。

四、导入变体 / 版本的标题与条目

主资产带版本、变体或多条 LOD 时，「导入」子菜单里会多出这一段：

资产内容菜单标题
有变体，且另有版本导入变体 / 版本
只有变体（没有内嵌版本）导入变体
没有变体，但有多版本或多 LOD导入版本 / LOD
  • 主版本固定排在最上面，其后是各内嵌版本与各变体条目。
  • 每个版本 / 变体条目左侧带小缩略图；鼠标悬停时在菜单旁弹出该条目的预览大图。
  • 变体带 LOD 时再展开一层：本体几何体 + LOD1、LOD2…；同一档位有多个格式时再展开格式子菜单。
  • 这一段的末尾还有「查看版本 / 查看变体 / 查看 LOD 管理」，点它会把资产区切换成内部视图（不是导入）。

五、更新缩略图子菜单

子项作用

Maya 拍屏 / 渲染图先选帧模式（当前帧 / 时间轴范围），再拍屏或渲染出图，替换主缩略图

提示

  • 菜单项受设置中各子库的右键菜单预设控制，未启用的项不会出现；开关在「设置 → 右键菜单」。
  • 在已多选的卡片上右键会保留多选；在未选中的卡片上右键会先单选它。导入、引用、删除、格式转换、后台渲染等对全部选中生效。
  • 图标视图中按空格可在鼠标处弹出十字标记菜单：上=导入、左=引用、右=应用、下=转换。
  • 每一项的「作用 / 前提 / 点了之后 / 注意」逐条说明见「菜单详解」8.5.2～8.5.12，公共条目见 8.5.13～8.5.17，内部条目的右键见 8.5.18。
