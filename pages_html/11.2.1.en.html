Font size is the base size of the plug-in interface, and all text and icons scale from it.

Effect

It adjusts the text size in plug-in windows and acts as the base for the 「有效字号」 (effective font size) calculation.

Values and default

  • The slider ranges from 10 to 24, with 13 as the default.
  • To the right of the slider the current base value and the effective font size are shown: effective = base × interface scaling.
  • For example a base of 13 with 150% interface scaling gives an effective size of about 20 px.

Scope

  • Text in the main window, the Settings window and all dialogs; icons scale proportionally from the 13 px base.
  • After a change the main window resets its style and recomputes its minimum size, and the Settings window re-fits the screen.
  • Only the plug-in's own interface is affected, never Maya's native menus and toolbars.
  • It applies after 「应用」 (Apply) or 「确定」 (OK); no plug-in restart is needed.

When to change it

  • On a small or high-resolution screen where the default text is hard to read, raise the base font size first.
  • To enlarge the whole interface including spacing and icons, prefer 「界面缩放」 (Interface scaling); the two can combine.
  • A base of 24 plus high scaling makes windows very large; content scrolls, but adjusting the scaling step is usually better.

Tips

Tip: if some text still looks small after the change, first check whether 「界面缩放」 (Interface scaling) is set to 「自动」 (Automatic).

Tip: font size and appearance theme are independent and can be set separately.
