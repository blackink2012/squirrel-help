One-line summary: the first page of the settings window holds everyday preferences about what the interface looks like rather than what it costs, plus management of the asset library itself.

This page is not affected by the global lock and can be edited immediately.

How to open it

The Settings button in the top toolbar (8.2.4) → the settings window opens on the General page.

Settings preset (save / import / export / clear / revert)

The Settings preset group at the very bottom manages the whole set of interface settings as one file: handy when changing computers, reinstalling the plug-in, or reverting a trial configuration.

ButtonEffectNotes
Save presetStores the currently applied settings as a local preset (%USERPROFILE%\.squirrel_asset_manager\settings_preset.json)Changes not yet applied with Apply / OK are not included; to include them, click Apply first
Import presetChoose a JSON preset file → overwrite the current settings and apply immediatelyAfter importing the settings window closes automatically (see below); library paths in a preset exported elsewhere may not exist on this machine
Export presetSaves the local preset as a JSON file at a path you chooseWhen no preset has been saved yet, it asks you to Save preset first
Clear presetDeletes the local preset file (with confirmation)It only deletes the preset file and does not affect current settings; an exported JSON backup can still be imported later
Revert presetRestores the whole settings set to defaults (a factory reset, with confirmation)Written to disk and applied immediately, and the settings window closes; API keys and the asset library list are kept; the local preset file is not deleted

The status line states whether a preset exists and when it was last saved.

Why the window closes after import / revert

Import and revert both write straight to disk, while the controls in the settings window still show the old values. If the window stayed open, your next OK would overwrite the freshly imported / reverted settings with those old values. Both buttons therefore close the window on purpose — reopen settings to see the new values.

提示

A preset contains UI preferences only (app_settings.json) and not the config files under Assets\preset\*.json such as export defaults / context menu / texture suffixes / sub-libraries and categories. To move those between machines, copy the matching JSON separately (see "Where the configuration lives" in 8.9.1).
