Geometry formats preset which geometry file formats are checked by default when exporting each asset type.

Effect

When a new export dialog or asset creation starts, geometry formats such as Maya, FBX, OBJ and USD are pre-checked for the current asset type.

Values and defaults

  • Choose the asset type in the list on the left, shown as a sub-library ID.
  • The five options and their default asset types:
OptionAsset types where it is checked by default
Maya ASCII (.ma)materials, models, lights, scenes, ani
Maya Binary (.mb)None
FBX (.fbx)None
OBJ (.obj)None
USD (.usd)None

Scope

  • It only decides the initial state of checkboxes in the export interface; a single export can still change them.
  • It never changes existing assets, the context menu or quick tools.
  • It is stored under the matching asset type key in Assets/preset/export_preset.json.

When to change it

  • Models must be delivered to an engine or another DCC: check .fbx or .usd for models.
  • Only Maya itself uses them: keep .ma, or switch to .mb for smaller files.
  • Material or light assets should not carry geometry by default: uncheck .ma for those types.

Tips

Tip: .ma excludes the default initial SE nodes so the default shader never enters the asset.

Tip: the list on the left holds asset types, not categories; all categories under one type share the same defaults.
