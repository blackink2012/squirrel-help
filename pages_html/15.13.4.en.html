One-line summary: after analyzing many assets at once, this window lines the results up so you can review and tick them one by one, then write them into the library in one go.

It uses the same fields as the single-asset results window (8.13.3) with two differences: several cards on one screen, and an extra "apply selected assets (N)" button at the bottom (N shows how many are ticked).

How to make it appear

  1. Select several assets in the grid (Ctrl / Shift multi-select, or select all in the batch bar, see 8.5.21);
  2. Top toolbar AI tools → "AI thumbnail analysis (N selected assets)";
  3. In the AI analysis configuration window keep "show a window for review and editing when done" ticked and click Start analysis;
  4. When the progress bar finishes this window opens automatically.

Without that review option there is no window — results are written straight into the library. On the first batch use, always keep the review option.

A complete flow

  1. Multi-select assets → AI tools menu → analyze → this window appears;
  2. Click Clear all first (unless you fully trust this batch);
  3. Go through the cards top to bottom: name, category, tags, notes;
  4. Tick the fields you accept; edit anything you want changed inside the input before ticking;
  5. Use each card's summary to see "what the AI understood"; skip the whole card when it is clearly off;
  6. If the files should not move around, leave "move into the analyzed category" unticked at the bottom;
  7. Click Apply selected assets (N);
  8. Refresh the grid and verify the names / tags / notes changed as expected.

What you see afterwards

  • The ticked fields are written into the matching assets' metadata; assets with no ticked field are completely untouched.
  • If "move into the analyzed category" was ticked, those assets move from their original category into the new one (visible after the tree refreshes).
  • A large batch is processed asset by asset, and the main interface returns when it finishes.

Risks and how to undo (the most important part of this page)

  • Changing many assets at once has no one-click undo. Split it into two rounds: apply tags only first, and handle names and notes once that looks right.
  • Ticking "move into the analyzed category" moves files on disk. AI category judgments can be wrong, and after a bad batch move you must move them back one by one (right-click → Move to, see 8.5.15). Leave it unticked on the first batch run.
  • Only ticked fields are overwritten: once an original name is replaced you can only change it back by hand, and the plug-in keeps no "previous field" copy.
  • To be safer, try 3–5 assets first, confirm the AI judges this kind of asset the way you want, then scale up.
