Restore defaults sets every item in the settings window back to its factory value; nothing is written to disk until you confirm and then click Apply or OK.

Prerequisites

The settings window is open. The reset button sits at the bottom left and is not restricted by Unlock all settings.

Steps

  1. Click Restore defaults.
  2. In the confirmation dialog "Restore all settings to their default values? (config.json will be reset)", choose Yes.
  3. Review the reverted values page by page.
  4. Click Apply or OK to save; click Cancel to abandon this reset.

What gets reset

  • General: font size back to 13, UI scale back to automatic, default view back to icons, name conflicts back to Auto rename (the same value as the factory preset's name_conflict_policy.mode).
  • Export defaults: export_preset.json is re-read.
  • Texture suffixes: pbr_mapping.json is re-read.
  • Other configuration: geometry extensions, image extensions and material node types return to the built-in default lists.
  • Context menu: context_menu_preset.json is re-read.

Scope of effect

  • It does not delete asset library files, does not reset licensing, and does not delete preset JSON files.
  • For preset files, restoring defaults means re-reading the disk content, not reverting the file to factory values; if the file was edited earlier, you still read the edited values.
  • Before you click Apply or OK, the reset only affects the current dialog.

Verify the result

After applying, reopen settings: each page should show default values.

Tips

Before resetting, copy config.json and the preset files as described in Backup and migration, so manual tweaks are not lost.
