一句话定位：在资产网格里右键一张动态资产卡片时，弹出的就是这个菜单。 动态资产是「带动态内容」（动画 / 缓存 / 变形）的资产，所以导入和引用都多了一个 abc 选项。

怎么打开

  1. 左侧「分类」页签 → 点「动态」或它下面的任一分类；
  2. 中间资产网格里右键任意动态卡片。

菜单从上到下的顺序

段条目
① 子库专属导入 ▶（ma / abc）、添加引用 ▶（ma / abc）
② 收藏与选择添加到收藏夹 ▶、全选、复制、打开文件夹
③ 整理移动到 ▶、复制到 ▶
④ 维护编辑、更新缩略图 ▶、更新资产 ▶、删除 ▶、格式转换
⑤ 查看与 AI预览节点 ▶、AI 分析缩略图
⑥ 最后一条资产详情

动态是唯一「导入」和「添加引用」都带子菜单（两种格式）的子库。

菜单逐项详解

菜单项作用前提点了之后注意
导入 ▶把动态内容导入当前 Maya 场景Maya 已连接子菜单选格式（见下节）后导入选 ma 与选 abc 导进来的东西不一样，下面有对照
添加引用 ▶以 Reference 方式引入资产里含 .ma / .abc 等可引用格式子菜单选格式后，场景里多一个引用节点abc 引用后缓存文件仍留在资产包里
添加到收藏夹 ▶把资产加入收藏夹资产库已加载子菜单列「默认收藏夹」+ 你自建的收藏夹；点一下加入、再点一下移出多选时对全部选中的资产生效
全选选中网格里当前可见的全部卡片有卡片全部高亮只选当前筛选 / 搜索结果
复制把资产放进剪贴板无内部剪贴板记录资产，同时把资产文件夹写进系统剪贴板真正复制一份要再到目标分类空白处「粘贴」
打开文件夹打开资产在磁盘上的位置资产是 .zasset 目录文件管理器定位到资产文件夹只打开，不改内容
移动到 ▶把资产移到别的分类资产库已加载级联选目标分类，资产从当前分类消失见 8.5.15
复制到 ▶把资产复制一份到别的分类资产库已加载目标分类多出同一资产占双份磁盘空间
编辑改中文名、分类、标签、注释无弹「编辑资产」对话框见 8.5.16
更新缩略图 ▶换掉或新增缩略图「后台渲染」需本机有 mayapy子菜单 7 项：截取 / 导入 / Maya拍屏 / 渲染图 / 添加 / 截取添加 / 后台渲染拍屏 / 渲染图会先问帧模式
更新资产 ▶把资产内容换成 / 扩成新的「替换资产」等需要场景里有选中物体替换资产 / 追加格式 / 追加为 LOD / 创建新版本 / 添加新变体… / 批量添加变体… / 变体管理…都会写磁盘，先看清目标资产
删除 ▶删掉这个资产无子菜单：移到回收站 / 彻底删除「彻底删除」不可还原
格式转换把资产里的几何体转成其它格式并追加进资产包本机有 mayapy弹「格式转换」对话框，勾选目标格式后开始原有格式保留；缓存类内容不在转换范围内
预览节点 ▶看资产内部的节点连接资产里有 .zmetal 或具名 .ma子菜单列出节点文件（样本资产：pSphere2.ma），点一项打开节点编辑器预览只读预览，不导入场景

子菜单：导入 / 添加引用（ma / abc）

子项导进来的是什么适合什么时候用
maMaya 场景文件里的完整内容：物体 + 可能带的动画曲线 / 设置想在场景里继续改、动画也要一起进来
abcAlembic 缓存：主要是烘焙好的几何 / 点缓存只要形态变化、不需要原动画曲线；文件小、播放稳定

引用同理：选 ma 是引用一个 Maya 场景文件，选 abc 是引用一个缓存文件。

这个子库特有的注意点

  • 它是唯一带两种导入 / 引用格式的子库：所以「导入」和「添加引用」都是子菜单，不像模型 / 场景是一行。
  • abc 不是动画曲线：Alembic 存的是烘焙后的结果，导入后时间轴上没有可编辑的关键帧——想要曲线用 ma 或动画数据子库。
  • 格式转换只转几何体：缓存与动画数据不参与转换。
