Configuration pages such as 「右键菜单」 (Context menu) are read-only by default; check 「解锁全部配置」 (Unlock all configuration) before changing them.

Effect

The lock prevents accidental changes. While locked, checkboxes, inputs and buttons are not editable, though current values stay visible.

Values and defaults

  • The 「解锁全部配置」 (Unlock all configuration) checkbox at the bottom of the Settings window is unchecked by default, meaning locked.
  • Checking it opens a 「配置修改警告」 (Configuration change warning); confirming unlocks it, and choosing 「否」 (No) unchecks it automatically.
  • Unlocking affects the export defaults, context menu, supported formats, texture suffixes, sub-libraries and categories and other configuration pages; General, AI settings and About (which holds the license) are never locked, and 「显示在主 UI」 (Show in the main UI) under sub-libraries and categories is directly editable.

Steps

  1. Open Settings → 右键菜单 (Context menu), check 「解锁全部配置」 (Unlock all configuration) at the bottom and choose 「是」 (Yes) in the warning.
  2. Change the menu item checks.
  3. Click 「应用」 (Apply) or 「确定」 (OK). While unlocked, applying opens one more 「配置变更确认」 (Configuration change confirmation) before writing.

Restoring

  • Click 「恢复默认设置」 (Restore default settings) at the bottom left; after confirming, values in the dialog return to factory state and only 「应用」 (Apply) writes them.
  • For the context menu this step rereads Assets/preset/context_menu_preset.json and does not rewrite that file to factory content; if the file was edited before, the edited values are read again.
  • To really restore the factory menu, overwrite that JSON with a backup or change each item back to its default.

Verify the result

Being able to change checkboxes proves it is unlocked; closing and reopening Settings still shows the bottom box unchecked (locked), matching the unlocked state having lapsed.

Tips

Do not unlock when a setting's meaning is unclear; a wrong configuration can leave the context menu missing items or make library features misbehave.
