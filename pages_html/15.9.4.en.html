One-line summary: predefine for each asset type (materials / models / lights…) which formats are ticked on export by default, and which formats are locked out entirely.

This page is locked by default: tick Unlock all settings at the bottom of the window and accept the warning first (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Export defaults tab.

Page structure

The left side is the asset type list (materials / models / lights / textures / scenes / HDR / animation / node tree / images / audio / animation data) and the right side holds that type's formats and options. Click a type on the left first; switching automatically saves the state you set for the previous type.

When these settings take effect

  • After saving, the next time the Create asset / export dialog opens, that type is pre-ticked from these defaults (see 8.10.1);
  • Locking only affects "whether a format can be chosen" and never deletes formats already present in existing assets;
  • An export dialog that is already open does not change live (close and reopen it).

Undo and risks

SituationHow to undo
Not saved yetClick Cancel to discard this session's changes
Already savedClick Restore defaults → it re-reads export_preset.json (note: it reads the file's values, not the built-in factory values; see 8.9.1)
Want a true factory stateOverwrite with a backed-up export_preset.json (the file lives in <plugin dir>\Assets\preset\)
警告

Unlocking a format the type should not have lets users tick unsupported formats when creating assets, which produces empty results or outright failures; locking a needed format makes the whole type export nothing. Think about what the type really supports before changing locks.
