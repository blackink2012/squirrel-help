Naming rules in batch modes

In full-auto and semi-auto the name box placeholder reads "name the first asset manually → later assets use their node names", and the display name hint reads "leave later assets empty". When the name is left empty each asset uses its own object or material node name, and only the display name typed for the first asset takes effect.

Append-format mode

Entering from Update asset → Append format adds a yellow hint at the very top of the right column: no format is checked by default, formats the asset already has are marked (已存在) (already present), checking one replaces that format's original file with this export, and unchecked formats stay as they are.

Notes on the current version

Older help put "export mode, thumbnail source and capture delay" on the left and "asset name, Chinese name and tags" on the right; the current version has "create asset + export mode + naming information + thumbnail source + tags" on the left and "collect linked files + export options + per-format sections" on the right. The current interface wording is authoritative.
