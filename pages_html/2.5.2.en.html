Activation happens on Settings → License activation; renew with a new license by activating again, and release the license on the old machine before moving to a new one. Online deactivation is limited only by the server's daily cap (max 3 per 24 hours); offline-issued licenses cannot be unbound for a machine move.

Activation steps

  1. Open Settings → License activation; if the product is not activated at first launch, the license window opens directly.
  2. Online activation: enter the key in 「激活码」 (Activation key) under the machine code and click 「激活」 (Activate).
  3. To try first: leave the key empty and click the green Activate button; the server issues a per-machine trial license (no sign-in window) that includes all features.
  4. Offline activation: expand the collapsed 「离线许可证激活」 (Offline license activation) section, then click 「导入许可证文件…」 (Import license file…) and pick a .lic / .dat / .json file, or copy the full license text and click Import from clipboard. Offline import only accepts offline license files issued manually by support; files issued by online activation cannot be used for offline activation.
  5. You can also drag the license file directly into the license window (no need to expand the section first).
  6. On success the state becomes 「已授权」 (Licensed) or 「试用中（剩余 N 天）」 (Trial, N days left), and both the window and the settings page refresh.

Renewal

  • A subscription license has a 7-day grace period after expiry during which features keep working; after the grace period it becomes read-only.
  • To renew, run activation again with the newly issued or renewed license; no uninstall is needed.

Moving to a new machine

  1. On the old machine click 「解除本机授权」 (Release this machine) in the license window; the confirmation shows that this consumes 1 switch and how many remain.
  2. Once the server confirms, the seat is released and the remaining switch count drops by 1 immediately (not only when the new machine activates).
  3. Install on the new machine, open the license window, and either activate online with the same activation code or import an offline license matching the new machine code.
  4. When the switch count is used up (5 for perpetual / 3 for subscription), the unbind button is unavailable and you must contact the licensor to extend it or arrange the move.
  5. Offline-issued licenses cannot be unbound: the button is disabled; contact the licensor to reissue for the new machine code.
  6. If the old machine can no longer be used, contact the licensor with the old and new machine codes to request a seat release or transfer.
  7. After unbinding, the previously exported copy of the same license file no longer works on this machine and cannot be re-imported; do not keep using that license on the unbound device.

In trial or unlicensed states the 「解除本机授权」 (Release this machine) button is unavailable, as it is for offline-issued licenses.

Verify the result

  • The state shows 「已授权：<customer name>」 (Licensed: <customer name>) or 「已授权」 (Licensed).
  • Import, export and conversion entry points are available.
  • On the new machine the machine code matches the license and E_LIC_MACHINE no longer appears.

Common failures

  • E_ACT_NET: cannot reach the activation server; use an offline license instead.
  • E_ACT_KEY: the activation code is wrong or no longer valid; check it and retry.
  • E_ACT_SEATS: no seats left; release an old device first or contact the licensor.
  • E_ACT_SWITCH_LIMIT: the machine-switch count is used up (5 for perpetual / 3 for subscription); contact the licensor to arrange the move.
  • E_ACT_OFFLINE_LICENSE: offline-issued licenses cannot be unbound for a machine move; contact the licensor to reissue.
  • E_LIC_REVOKED_FILE: this license file was already unbound and voided on this machine; activate again with the activation code.
  • E_LIC_MACHINE: the license is bound to another computer; request a machine move or use a license that matches this machine.
  • E_LIC_INTEGRITY: program files were modified; reinstall and then activate.
