「导入命名空间」控制直接导入资产时，新节点落在哪个命名空间里。它是防止与场景已有节点重名的那层隔离。

在哪、默认怎么设

  • 位置：设置 → 常规 → 导入命名空间（复选框「直接导入时自动创建命名空间（按资产名，避免与场景节点同名）」）；
  • 默认：勾选（config.json 的 import_namespace 为 true；该键缺失时同样按开启处理）。

开着的时候（默认）

  • 命名空间名取资产名：非字母 / 数字 / 汉字 / 下划线的字符替换成 _，首尾的下划线去掉；
  • 名字以数字开头时自动加 ns_ 前缀（Maya 不允许命名空间以数字开头）；
  • 场景里已有同名命名空间时追加 _1、_2…；
  • 效果：整个资产作为一组节点，可以按命名空间整体选中、隐藏或删除，也不会和场景里同名物体打架。

关掉的时候

  • 新节点直接进根命名空间 :；
  • 与场景已有节点同名时，由 Maya 自动改名（pCube1、pCube2…），节点就分不出「哪几个是这次导入的」。

影响范围

  • 只影响之后的导入：改完保存，下一次导入就按新规则；已经导进来的节点不会被移进 / 移出命名空间；
  • 对「导入几何体 / 场景 / 动画 / 缓存代理」这类直接导入生效；右键「添加引用」有自己的命名空间规则（按资产名 + _1 / _2），不受这个开关影响；
  • 只改节点落点，不改资产包内容，也不改贴图 / 依赖路径；
  • 保存在 config.json 的 import_namespace。

提示

提示：不想要那层前缀，取消勾选并点「应用 / 确定」即可，不需要重启插件。

警告：关掉后同名节点会被 Maya 静默改名，之后要按名字找回「这次导入的东西」会比较麻烦；批量导入同一批资产时建议保留开启。
