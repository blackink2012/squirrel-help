One-line summary: everything adjustable in the plug-in lives here across ten tabs, and most tabs are "locked" by default — tick Unlock all settings first.

Nine out of ten first-time users get stuck on the same thing: options are visible but cannot be clicked and text cannot be typed. That is not a bug; it is the global lock (see "The most common blocker: the global lock" below).

How to open it

  1. In the top toolbar of the main window click the Settings button (the gear, see 8.2.4);
  2. The Settings window opens on the General page;
  3. Switch pages with the tabs stacked vertically on the left (long English labels fit there), then save with the buttons at the bottom.

The most common blocker: the global lock

Default state

There is a checkbox at the bottom of the window, Unlock all settings, unticked by default. While it is unticked, every checkbox, input and button on the other six tabs is gray, except on General, AI settings, License activation and About:

TabWhile locked
Export defaultsCheckboxes gray, lock switches gray
Context menuMenu item switches gray, double-click command radios gray
Supported formatsText box read-only
Texture suffixesAlias text box read-only (the page's Restore defaults button is gray too)
Sub-libraries and categoriesSub-library list, ID / display name and category list all gray (the Show in main UI checkbox still works)
Other configurationText boxes read-only

How to unlock

  1. Tick Unlock all settings;
  2. A configuration change warning appears, listing which tabs will be unlocked and warning that a wrong configuration can break library features;
  3. Click Yes → all six tabs become editable; click No → the checkbox untickes itself and nothing happens;
  4. Remember to save; unticking Unlock all settings locks them again (and does not auto-save).
警告

The lock is not a security boundary, only misclick protection. Once unlocked you change the library's underlying behavior (export formats, context menu, file recognition, texture channel recognition), and a wrong value can break import and export.

The second confirmation while unlocked

Clicking Apply or OK while unlocked shows one more "configuration change confirmation" ("currently unlocked, non-general configuration may have been modified… apply the current settings anyway?"). Answering No means this save does not happen.

What restore defaults really restores

After clicking Restore defaults and confirming, the following immediately return to their default values in the UI (and still need Apply / OK to be written to disk):

Restored itemRestored to
Font size / UI scale / scale anchor13 / automatic / follow system scaling
Default view / name conflictsIcon grid / auto rename
Export defaultsRe-read from export_preset.json (discarding unsaved changes)
Texture suffixesRe-read from pbr_mapping.json (discarding unsaved changes)
Context menuRe-read from context_menu_preset.json (discarding unsaved changes)
Other configurationBack to the built-in factory lists (geometry / image extensions, material node types)

Items that are not restored (an easy misunderstanding):

  • The extension list on Supported formats (change it back by hand or restore from backup);
  • Sub-library IDs / display names / default category lists on Sub-libraries and categories;
  • The asset library list, texture / dependency import strategy, import namespace, language, colors and thumbnail size on General;
  • Everything on AI settings (dependencies, global model, external connections).

So restore defaults is not a factory reset: it re-reads the preset files on disk, and whatever those files hold is what you get back.

提示

For a true factory reset use Settings preset → Revert preset at the bottom of the General page: it writes every UI preference in app_settings.json back to defaults and takes effect immediately (API keys and the asset library list are kept). Scope and flow are in the "Settings preset" section of 8.9.2.

Where the configuration lives

Settings are spread across these files (<plugin dir> is the squirrel_asset_manager folder in the plug-in install directory):

FileWhat it stores
<plugin dir>\Assets\preset\config.jsonAsset library list and default library, name conflict policy, texture / dependency import strategy, supported formats, sub-libraries and categories, other configuration, common tags
<plugin dir>\Assets\preset\export_preset.jsonThe Export defaults page (stored per asset type)
<plugin dir>\Assets\preset\context_menu_preset.jsonThe Context menu page switches (stored per sub-library)
<plugin dir>\Assets\preset\double_click_preset.jsonDouble-click commands on the Context menu page (stored per sub-library)
<plugin dir>\Assets\preset\pbr_mapping.jsonChannel aliases on the Texture suffixes page
%USERPROFILE%\.squirrel_asset_manager\app_settings.jsonUI preferences: font size, UI scale, theme, language, default view, thumbnail output size, bridge port switch, global model, hidden top-level categories
%USERPROFILE%\.squirrel_asset_manager\settings_preset.jsonThe full UI preference snapshot saved by General → Settings preset (move or restore it with import / export preset; absent means no preset has been saved)
提示

Back up these JSON files before editing by hand, and preferably close the plug-in window first. When JSON is broken the plug-in falls back to defaults where it can, but Restore defaults only re-reads files and never repairs them.
