运行安装器、按需勾选 Maya 集成与离线 dsh，即可得到可双击启动的独立版。

前置条件

  • Windows 64 位；按当前用户安装，不需要管理员权限。
  • 安装包已通过 SHA256 校验。
  • 如需 Maya 集成，先确认 Maya 已安装；没有 Maya 时安装器会自动取消该组件。

操作步骤

  1. 双击 SquirrelAssetManager-Setup-1.0.0.exe（测试版为 ...-test.exe）。
  2. 选择安装界面语言：默认跟随系统语言（中文系统默认中文，其他系统默认英文），也可以在这里改成另一门；之后整个向导都用这门语言。
  3. 欢迎页点「下一步」。
  4. 在许可页阅读 EULA 摘要，把「我已阅读上述摘要」和「我已阅读并同意《最终用户许可协议》」两个勾选都打上，「下一步」才可用。
  5. 在组件页按需勾选（可用组件见下方表格）。
  6. 选择安装目录，默认 %LOCALAPPDATA%\SquirrelAM。
  7. 完成后勾选「启动 Squirrel Asset Manager」，或从开始菜单 / 桌面快捷方式打开。

组件说明

组件说明
核心程序（必需）主程序、内置 Python、PySide6、许可与第三方声明
Maya 集成（可选）写入各版本 userSetup.py 的导入路径、状态行按钮与桥接端口，并创建工具架按钮（只在安装时创建一次）
AI 助手 dsh（离线）解压内置 dsh 与便携 Node
桌面快捷方式（可选）在桌面创建启动快捷方式

静默安装

.\SquirrelAssetManager-Setup-1.0.0.exe /S /COMPONENTS=core,maya,aidsh

/COMPONENTS 中未列出的可选组件会被取消；核心组件始终安装。

静默安装不弹语言框：默认同样跟随系统语言，需要指定时加 /LANG=（2052 简体中文 / 1033 English）：

.\SquirrelAssetManager-Setup-1.0.0.exe /S /LANG=1033 /COMPONENTS=core,maya,aidsh

安装器把选定的语言写进 HKCU\Software\SquirrelAssetManager\Language，卸载时自动沿用同一门语言，不会二次询问。

结果验证

  • 勾选 Maya 集成时，Maya 工具架与状态行出现入口；重启 Maya 后生效。工具架按钮只在安装时创建一次，手动删除后不会自动恢复。
  • 双击主程序能打开资产界面。

常见失败

  • SmartScreen 提示未知发布者：当前版本未签名，确认来源可信后选择「更多信息 → 仍要运行」。
  • 没有 Maya 却勾了 Maya 集成：安装后不会出现入口；重新运行安装器并取消该组件。
  • 启动提示找不到内置 Python：安装不完整，重新安装并检查杀毒软件是否拦截。
  • 独立版连不上 Maya：确认 Maya 已启动且桥接端口已开启，见「多版本 Maya 共存」。
  • 安装语言选错了：安装器只在安装时询问一次；装完想换界面语言去「设置 → 通用 → 界面语言」改（卸载器仍沿用安装时选的语言）。

从源码运行独立版

源码包内可双击 启动独立预览.bat，或执行 python squirrel_asset_manager\standalone_preview.py，前提是系统 Python 已装 PySide6。
