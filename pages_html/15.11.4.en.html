One-line summary: two windows appear in sequence when you add another detail level or another version to an existing asset: pick the update mode first, then bind the LOD slot.

This page covers two windows:

  1. The Update asset chooser, which opens from right-click → Update asset and asks how you want to update.
  2. The Append LOD slot window, which opens when you choose Append as LOD in the first window and binds the current Maya selection to a LOD slot.

Window one: update asset (choose the update mode)

The text reads "Asset "<name>" already exists. Choose an update mode:", with a row of buttons:

ButtonEffectResult
Append as LODExports the current Maya selection as another LOD of the same assetThen opens the append LOD slot window
Append formatMerges this export into the existing asset, adding or replacing formatsOpens the pre-filled create asset window in append-format mode (see 8.10.1)
Create new versionClones the current content into a new sub-versionOpens the pre-filled create asset window; when the export finishes it reports "Created new version <tag>"
Add as new variantExports the current selection as one variant (geometry only)First asks for a variant name (also the directory name, Chinese allowed), then opens the export configuration
Batch add variantsOne variant per selected objectExports object by object and generates thumbnails
Replace assetOverwrites the original asset content with this importOpens the export configuration window and overwrites the original asset
CancelDoes nothingCloses the window

Additional rules:

  • The default main button is Replace asset; if the asset has older version records the default becomes Append as LOD.
  • When the current entry is inside a sub-version / variant / LOD, Create new version is not shown (versions cannot nest versions).
  • Create new version does not ask for a version name: for geometry / material assets the plug-in generates the version tag (V1, V2). Only Add as new variant and "append LOD for a variant" open a small input.

The title is Append LOD with the subtitle "Target: <current asset / version name>", and a line below shows "Current selection: <model name>" live.

State badges on the slot cards:

  • Empty: no LOD exists at that slot yet;
  • Exists · N faces: a LOD already exists there (N is the triangle count), and binding again overwrites it;
  • Not bound / → object name: whether and to what this session has bound it.

A complete example (adding LOD1 and LOD2 to a model)

  1. In Maya select the model intended as LOD1 first.
  2. Right-click the asset → Update asset → Append as LOD.
  3. When the Append LOD window opens, click the LOD1 card; it turns ☑ and shows "→ model name".
  4. Back in Maya select the model intended as LOD2, then click the LOD2 card.
  5. Read the warning lines at the bottom of the window:
    • "'LOD1' already exists: its geometry will be overwritten and other LODs are unaffected." → confirm that overwriting is acceptable;
    • "LOD0 is the version's default geometry; after overwriting, double-clicking the card imports the new model." → take special note;
    • "N LODs will be written at once." → confirm the count.
  6. Click Export and append (N slots) and wait; it reports "Appended N LOD(s)".
  7. Verify: double-click the preview to open the version browser; the new slots appear in the LOD management card on the right, where you can also set one as the default LOD.

This window is also reachable from the version browser: LOD management card → Append LOD…. Appending a LOD to a variant uses a different small input ("Append LOD level to variant "X" (1-9)"), not this slot window.

Risks and how to undo

OperationRiskUndo
Overwriting an existing slotThat slot's geometry is replaced by the new export; other LODs and versions are unaffectedBind the correct model again and append once more
Overwriting LOD0LOD0 is the version's default geometry, so double-clicking the asset card imports the new modelBind the original model back to LOD0 and append again
Writing several slots at onceOnly the current bindings are written; extra slots create useless LODsDelete the surplus slots in the version browser's LOD management card (keeping at least one)
Create new versionIt adds a complete extra copy and takes spaceDelete that version in the version browser (irreversible)
