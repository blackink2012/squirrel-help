One-line summary: the AI assistant area holds a single toggle button: click once to start the dsh chat panel, click again to close it completely.

It is not a chat window itself — what actually talks to you is the dsh web chat panel, and this area is responsible for starting that panel, showing it and closing it.

What the area contains

PartDescription
The AI assistant label in the area headerThe area name; the area can be dragged / split / torn off (see 3.2.1)
Area function button (tooltip "AI assistant")The shared area menu: dock / split / tear off / maximize / merge into / close
Toggle buttonThe entire feature of this area: turn the dsh chat panel on / off

The three button states

Button textColorMeaning
AI assistantNeutral secondarydsh is not running (off)
Starting AI assistant…Neutral secondaryThe dsh process is starting (usually a few seconds)
Close AI assistantBlue accentdsh is running and the chat panel is open

What a click does

Current stateResult
OffStarts the dsh web end: depending on settings it docks the chat panel inside Maya (default) or opens it in the system browser; when done the button becomes "Close AI assistant"
StartingWait for it; do not click repeatedly (extra clicks do not start another process)
Already onCloses the panel and ends the dsh process (a real close, not a minimize); clicking again starts it fresh
警告

"Close AI assistant" really kills the dsh process; it does not just hide the panel. Opening it again is a fresh start, and the conversation context depends on the sessions dsh saved itself.

Embedded panel or system browser

This is decided by Settings → AI → AI chat panel → Embed the AI chat panel in Maya (ticked by default), see 8.9.3:

OptionBehavior
Ticked (default)The chat panel docks inside Maya and is available whenever it is open; its title automatically carries the current scene name so it is distinguishable from your other dsh windows
UntickedThe same dsh chat panel opens in the system browser; sessions and tools are identical, only the window lives outside

After changing this option, the next click on AI assistant uses the new mode; Maya does not need a restart.

The panel is gone / the browser tab was closed

This is the most common way to get stuck: dsh is still running but the chat panel is not visible.

  • Open the top AI tools menu → Recall AI panel: it only brings the already running chat panel back, without restarting or killing the process;
  • In browser mode, closing the tab manually is invisible to the plug-in (tabs belong to the browser), so AI assistant then reads "close"; use Recall AI panel to get it back;
  • The floating bubble inside the window does the same: while AI is running it breathes slowly, and clicking it recalls the panel.

When dsh is not installed

The first click on AI assistant opens the install guide (see 8.13.6) with four actions: copy the install command / one-click install the dsh runtime / open the install help / open the website or repository. Click again once it is installed.

Common questions

SymptomCause / what to do
The button stays on "Starting"The first start has to launch the process and the web service, usually a few seconds; if nothing changes after a minute or two, check the Maya Script Editor output
The button is gray and unclickableRare; usually an abnormal window / panel state. Reopen the panel or restart the plug-in
The chat panel opened in the browser and cannot be foundClick AI tools → Recall AI panel
The previous conversation is gone after closing and reopeningWhether dsh keeps a session is up to dsh itself; the plug-in only toggles the process and the panel
