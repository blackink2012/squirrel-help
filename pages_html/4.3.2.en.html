A category's display name can be changed at any time, while the folder name (its internal ID) is read-only in the edit dialog.

Steps

  1. Right-click the category and choose 「编辑」 (Edit).
  2. 「文件夹名」 (Folder name) is read-only and cannot be changed.
  3. Change 「易读名」 (Display name); saving an empty value has no effect.
  4. Change the 「类型」 (Type) dropdown if needed (it affects which context commands are available for assets in that category).
  5. Click 「确定」 (OK).

Verify the result

The category name in the tree changes to the new display name immediately while the folder name on disk stays the same; neither asset locations nor existing assets are affected.

Tips

  • The display name is only for reading; search and locate still match by category ID and path.
  • The plug-in offers no way to change a folder name. Do not rename category folders in Explorer, or the index will drift from disk and assets may disappear from the tree.
  • The type field decides which sub-library a top-level category is handled as; a wrong value makes the context menu offer mismatched import / apply items, so confirm it before changing.
  • Changes are written back to FolderMetadata.fdata in the category folder; no plug-in restart is needed.
  • When you only want to change the category hierarchy, use 「移动到...」 (Move to...); do not try to rename the folder.
