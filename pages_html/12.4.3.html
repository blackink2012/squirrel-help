pbr_mapping.json 负责“贴图文件名 → PBR 通道”，material_mapper_presets/*.mmap 负责“源材质属性 → 目标材质属性”；两者都在插件包内，改完下一次打开工具时生效。

PBR 映射

文件位于 Assets/preset/pbr_mapping.json，结构版本 "1.0"，默认材质类型为 openPBRSurface。

字段说明
resolution_subdirs / resolution_patterns识别 2k、4k、8k 等分辨率目录与文件名后缀
texture_type_rules当前 16 类贴图规则：baseColor、normal、roughness、metallic、ao、arm、orm、emissive、height、opacity、clearcoat、clearcoatRoughness、specular、subsurface、anisotropy、ior
material_property_mappings9 种材质的属性连接表，含 node_attribute、connection_type、requires_conversion、conversion_node

每条 texture_type_rules 可含：aliases（文件名关键词）、priority（识别优先级）、color_space（sRGB / Raw）、is_color、invert_if（如粗糙度遇到 glossiness 时反转）、is_combo 与 channels（如 arm/orm 的 R/G/B 分别指向 ao/roughness/metallic）、is_numeric。

材质映射 .mmap

Assets/material_mapper_presets/ 下当前有 58 个 .mmap，命名为 {源类型}_{目标类型}.mmap，内容是 JSON，核心字段：

字段含义
version / name / software文件版本、显示名、目标软件
source_type / target_type源材质与目标材质节点类型
mappings逐条属性映射
source_attribute源属性；空串表示“无源”，用于把目标属性重置为默认值
target_attribute目标属性；空串表示该条跳过
transform转换函数标识，不需要时为空串
default_value源属性缺失时的兜底值
parameters转换函数参数，如 clamp 的 min_val / max_val

执行时按顺序逐条处理：目标属性不存在就记失败并跳过；颜色子通道（如 diffuseColorR）无条件跳过，颜色必须写父属性；源属性有贴图连接时复制连接；源值缺失时使用 default_value，它也为空则把目标属性重置为当前默认值。

常用转换函数包括 roughness_to_shininess、shininess_to_roughness、specular_to_specular_weight、transparency_to_transmission、translucence_to_subsurface、emission_to_emission_luminance 与 clamp。正反向转换共用同一个 .mmap，反向时自动套用反向函数。

提示：更多规则与已验证的属性对照见 Assets/material_mapper_presets/材质映射指南.md。
