右栏决定「这次打包什么」：关联文件、材质/灯光节点、几何体、动画、缓存和代理，都按分区勾选。

分区控件说明
收集关联文件收集场景中已挂载的缓存/代理/引用文件勾选后把磁盘上已有的缓存、代理、引用等复制到 deps/；不勾选只扫描并记录清单
收集关联文件贴图 textures/默认勾选，把材质和灯光关联的贴图复制到 textures/
导出选项仅导出材质（跳过几何体/代理）只打包材质节点与贴图；材质子库默认勾选，详见「仅导出材质」
材质格式 / 灯光格式 / 节点格式材质预设 .zmetal / 灯光预设 .zlight / 节点预设 .zmetal分区标题随当前子库变化：材质与其它子库是 .zmetal，灯光子库是 .zlight
同上全部材质写入一个 .zmetal勾选后合并为一个文件；不勾选且选中的是材质节点时按材质分别写文件；灯光资产不显示此项
同上材质映射 .mcm (检测到 N 个材质)记录材质对应的模型和面级指派；灯光资产不显示此项
几何体格式（通过 Maya 原生导出）Maya ASCII .ma / Maya Binary .mb / FBX .fbx / OBJ .obj / USD .usd可多选；通过 Maya 原生导出，.ma/.mb 保持引用关系不烘焙
动画导出当前帧 / 时间轴 / 关键帧决定 abc/usd/ass/rs/vrmesh 的帧范围；当前帧 为静帧
缓存格式Alembic .abc导出 Alembic 缓存，帧范围由「动画导出」决定
代理格式Arnold .ass / Redshift .rs / V-Ray .vrscene / V-Ray .vrmesh渲染器代理；需要对应插件已加载

插件状态

几何体、缓存和代理格式的复选框右侧会显示插件状态：已就绪、未加载、不可用。显示不可用时该复选框被置灰，本次不能选；显示未加载时可先到 Maya 插件管理器加载插件，再关闭并重新打开导出对话框。

被锁定的格式

不适用于当前分类的格式会变灰且勾不进导出配置，鼠标悬停提示「该格式不适用于当前分类，已锁定（可在 设置 → 导出默认值 中调整）」。默认锁定规则：材质、灯光锁掉几何与全部代理格式（这类资产没有几何）；贴图、HDR、图片、音乐、动画数据几乎锁掉所有节点与几何格式。要解锁：设置 →「导出默认值」页把对应格式的锁定关掉（见 4.3.4.1）。

追加格式模式的提示

从「更新资产 → 追加格式」进入时，右栏最上方会多一条黄色提示：默认一个格式都不勾；资产已有的格式后面标注「（已存在）」，勾上=用本次导出结果替换该格式原文件，不勾=保持原样。正常的「创建资产」则按导出默认值预先勾选，两者不同。

勾选组合的结果

  • 只勾 .zmetal + 贴图 textures/：得到材质资产，导入后重建材质网络。
  • 勾几何体格式：得到模型资产；需要材质随模型走时同时勾 .zmetal 或 .mcm。
  • 勾缓存或代理：得到动画/渲染器专用文件，是否能导入取决于目标 Maya 是否装了对应插件。
