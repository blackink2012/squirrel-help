The Current license card on Settings → License activation shows the license state and tells you whether import, export and conversion are available.

What it does

The status text is read live by the licensing module and is read-only here. It answers two questions: is the license valid, and which licensing stage are you in.

Values and meanings

TextMeaning
Licensed / Licensed: customer nameA valid license; all features are available
Trial (N days left)A server-issued trial license is valid
Subscription expired (in grace period)The subscription expired but you are still in the grace period
License expired (read-only)The license expired; browsing only
Not activated (read-only)No valid license; browsing only

License management opens the license window. Offline import and deactivate / restore also live in License details & advanced on this page — both paths use the same capabilities.

Scope of effect

  • The license is stored locally and bound to this computer.
  • While expired or not activated you can still browse the library; import, export and conversion require a valid license.
  • The License activation tab is not covered by Unlock all settings; the activation entry is always available.

When to check it

  • When import, export or conversion shows a licensing prompt.
  • After changing computers, reinstalling the system, or renewing the license.
  • The status does not refresh continuously; it is re-read when you reopen settings or complete an activation.

Verify the result

After activating, return to this page: the status should become Licensed or Trial.

Tips

The read-only wording only limits write operations; browsing and searching assets still work.
