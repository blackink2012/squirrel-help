One-line summary: right-clicking a specific category (the level under a sub-library and deeper custom categories) opens the "add sub-category / open folder / move / rename / delete" set.

How to open it

  1. Left navigation → Category tab;
  2. Expand a sub-library (such as Materials) and find a category or sub-category under it;
  3. Right-click that category node.

The number of items is not fixed; it depends on the kind of category and whether it has sub-categories — measurements show 4 / 5 / 6 / 7 items:

Submenus

This menu has no second level (nothing with ▶). It does have a multi-step flow though — the two confirmations for deleting a category, covered below.

Delete category: two confirmations and how to undo

Clicking Delete category runs two confirmations; answering No at either step aborts:

StepContentDescription
① First confirmation"Delete category "X"?" plus the number of sub-categories if any, plus "assets under this category will be moved to the recycle bin"A normal confirmation dialog
② Second confirmationA strong warning that the category and its contents go to the recycle bin (restorable from the recycle bin in the left column); the asset count is stated explicitly when there are assetsFocus defaults to No to prevent slips; a confirm button
ExecutionThe whole category folder moves to the recycle bin and its parent category is selectedIt disappears from the tree immediately

How to undo: open Recycle bin in the left column → find that category record → right-click Restore, see 8.8.3. Note that restoration brings back the whole category, not asset by asset.

Beginner pitfalls

  • "Delete category" is unclickable / not there at all: you right-clicked a built-in default sub-library (such as Materials itself) or an auto-created Custom category — neither can be deleted. See 8.3.4.2.
  • Realizing only after deleting that a sub-category held assets: the confirmation states the asset count, so read it first; if you deleted by mistake, restore from the recycle bin immediately and never "delete permanently" that entry.
  • The folder name is gray under Edit: the folder name is the category id and cannot change; only the readable name and type can.
  • Thinking "Move to..." does anything besides re-parenting: it only moves the category level and touches no asset file content.
