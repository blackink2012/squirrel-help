A .zlight is a renderer-independent light preset: it records the light's physical parameters and its complete upstream node network, and import builds the light for the target renderer.

Prerequisites

  • A light asset (a .zasset folder) exists.
  • The asset directory can be opened in a file manager.

Steps

  1. Right-click the light asset in the library and choose 「打开文件夹」 (Open folder).
  2. Find the .zlight file (normally node.zlight; the import side also recognizes other .zlight file names).
  3. Open it and confirm the structure: the new format is nodes + root_lights, the old format is a lights list.
  4. Check the common fields per light: light_type, source_node_type, color, intensity, exposure, temperature, normalize, visible, transform, plus hdr_path and ies_file.
  5. When a light carries textures or IES, look at connected_files, connections and node_network; the matching files live in the asset's textures/ and their paths have been rewritten as relative paths.

Verify the result

After importing the asset the light node appears in the Outliner with a type matching the current renderer; a dome light's HDR, an IES light's profile and upstream texture nodes all connect back to the light.

Tips

  • light_type supports area, point, spot, directional, dome, disk, cylinder and ies.
  • The new format records source_node_type per light so import can reconstruct it for the source renderer first and then decide whether to convert.
  • The old format has only a lights list without per-light source node types; when "build first, then ask" is needed it infers from meta.node_type.
  • The file exists only if the zlight format was enabled at export; a light asset with only .ma goes through the ordinary scene import.
