右键菜单里的每一项都可以按子库单独开关，勾选后才会出现在资产卡片的右键菜单中。

作用

「设置 → 右键菜单」页右侧是一组复选框，每个复选框对应一个菜单项。勾选表示显示，取消表示隐藏。左侧子库列表决定当前正在编辑哪一份配置。

可选值与默认值

  • 可选值：勾选 / 取消勾选，最终写成 true / false。
  • 默认值来自 Assets/preset/context_menu_preset.json：每个子库只默认勾选自己实际拥有的项，不相关项为 false。
  • 未登记的子库或自定义分类读取同一文件的 default 段。

按作用范围，菜单项分两类（下表按设置页里的实际复选框整理，共 27 项）：

类型菜单项
全分类通用导入、导入几何体、添加引用、收藏夹、全选、复制、打开文件夹、移动到、复制到、编辑、创建资产、更新缩略图、更新资产、删除、预览节点、AI 分析缩略图、资产详情
分类专属后台渲染（模型/场景/动态/材质/贴图/灯光/节点树）、格式转换（仅 模型/节点树/场景/动态/音频）、为当前选择指定材质（材质/贴图）、应用材质参数（材质）、创建材质（仅 贴图）、转换导入（材质/灯光）、导入贴图（仅 贴图）、指定贴图到材质（仅 贴图/HDR）、应用灯光参数到选中灯光（仅 灯光）、创建环境光（仅 HDR）

几点说明：

  • 「贴图」子库的通用「导入」会置灰，界面提示改用「导入贴图」。
  • 「后台渲染」就是无头离屏生成缩略图（旧文档里的「生成缩略图」），它在「更新缩略图」子菜单的最下方，出厂只在模型/场景/动态/材质/贴图/灯光/节点树这 7 类下开启。
  • 图片 / 音频 / 动画数据这三个子库的首组导入项是固定生成的，不在本页复选框控制范围内：图片有「导入为 file 节点 / 创建 imagePlane / 指定到选中材质槽」，音频有「导入到时间轴 / 时间编辑器 / Trax 编辑器 / 摄像机序列器」，动画数据有「自动映射导入 / 导入动画 / 导入到选择属性」。本页对它们能开关的是上面的通用项（收藏夹、全选、复制、打开文件夹、移动到/复制到、编辑、删除、AI 分析、资产详情等）。
  • 出厂预设里，图片 / 音频 / 动画数据把通用「导入」设为关闭（它们用各自的专属导入项代替），节点树则与模型同一套。

影响范围

  • 只影响资产卡片的右键菜单，不改变双击行为（双击见「按子库选择命令」）。
  • 修改需要先解锁，再点「应用」或「确定」写回 JSON；下次弹出右键菜单时按新配置构建。

何时修改

菜单项太多、经常误点危险项（删除、格式转换），或某个子库根本用不到某项功能时。
