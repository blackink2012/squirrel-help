Every help page ends with 「此页是否有帮助」 (Was this page helpful?), which records the quality of that page; to report a plug-in issue to the author, use Settings → 关于 → 反馈与建议 → 发送反馈 (About → Feedback and suggestions → Send feedback) in the main window.

In-page feedback

  1. Open any help page and scroll to the bottom.
  2. Click 「有帮助」 (Yes) or 「没帮助」 (No).
  3. 「已记录，谢谢反馈。」 (Recorded. Thanks for the feedback.) appears next to the buttons; the next time you open that page it shows your previous choice.

Feedback is stored in the local storage of the current browser (key squirrel.help.feedback); it is not uploaded to a server and does not create a ticket automatically.

When something goes wrong

  1. First search this help for the symptom, for example "import failed", "empty asset" or "crash".
  2. Work through the Troubleshooting chapter following "symptom → cause → fix"; log locations are described in 6.8.1.
  3. To report to the author, open Settings → 关于 (About) in the main window, click 「发送反馈」 (Send feedback) in the 「反馈与建议」 (Feedback and suggestions) group and fill in the form (screenshots and logs can be attached).
  4. Having the following ready makes diagnosis much faster:
    • Maya version and plug-in version;
    • steps to reproduce, expected result and actual result;
    • relevant screenshots or screen recordings;
    • Script Editor output and log files.

Verify the result

  • After clicking the in-page feedback, 「已记录，谢谢反馈。」 (Recorded. Thanks for the feedback.) appears.
  • After refreshing the browser and reopening the page, your previous feedback state is shown.

Tips

  • In-page feedback only says whether the page is good; it cannot replace a defect report. Report defects through Settings → 关于 → 发送反馈 (About → Send feedback).
  • When reporting a defect, do not just write "it does not work"; include reproducible steps and logs so it can be located much faster.
