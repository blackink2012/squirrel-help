Run the dependency check to see what is missing, then fill the gaps with the one-click install; that is the shortest path to working AI search and analysis.

Prerequisites

  • The plug-in main window is usable; the install needs a network.
  • Installing Ollama is allowed on this machine; the one-click install uses the system package manager.

Steps

  1. Open Settings → AI 设置 (AI settings) and find 「AI 功能与依赖」 (AI features and dependencies) at the top.
  2. Click 「AI 依赖检查」 (AI dependency check). After a few seconds a text report is generated and opened in Notepad, and the status line shows how many items are missing.
  3. Click 「一键安装 AI 功能与依赖」 (One-click install of AI features and dependencies). The confirmation lists the steps and expected downloads; keep 「同时安装图像检索」 (Also install image retrieval) when image search is wanted and fill in the vision chat model name.
  4. Check 「强制重装（覆盖已装部分）」 (Force reinstall, overwriting installed parts) to overwrite existing parts; otherwise finished steps are skipped automatically.
  5. Watch the live log in the progress window; closing the window cancels, and parts already installed are kept. After a failure, clicking again fills only the failed or missing steps.
  6. When it finishes, run 「AI 依赖检查」 (AI dependency check) once more to confirm.

Verify the result

  • A second check shows fewer missing items or everything ready, and the status line no longer reports missing dependencies.
  • Natural-language search, search by image and AI analysis work.

Tips

Tip: the report is %TEMP%\squirrel_asset_manager\AI依赖检查报告.txt and the install log is ai_install.log in the same directory.

Tip: the Ollama service must stay running for installation and use; stopping it makes AI features unavailable.

Tip: an interrupted install does not break finished parts; click one-click install again to continue.
