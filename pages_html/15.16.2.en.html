One-line summary: the "dictionary index" of this chapter — you remember the wording or the button name but not where it lives: flip to the pinyin initial, then look up where it is and which page to read.

How to use this page

  1. Read the exact text on the menu item / button (if you cannot recall it, guess the initial from the pinyin of its first character);
  2. Find that row in the grouped tables below;
  3. The three columns are menu item (the text printed on the interface), location (the shortest path to it) and page id (click through for the item-by-item details).

Conventions:

  • Location stops at "the level where you can click it" — for example "Asset context menu" does not say which asset type; see the page for the specific sub-library;
  • When several locations reach the same item (for example Import exists in both the materials and lights menus), the table lists the most common one and the page states the other;
  • A page id can be turned straight into a help center deep link: http://127.0.0.1:<port>/#/<page id>, see 8.15.1.
