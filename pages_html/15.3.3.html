一句话定位：分类树就是资产库的「文件管理器」—— 树上的节点按类型分几种，点它只是筛选中间的资产，不改资产本身。

怎么打开

左侧导航 →「分类」页签 → 主体那块树。它固定显示，不需要打开；资产库下拉换了库，树会跟着换成新库的分类。

节点类型一览

节点外观代表什么单击后网格显示
全部资产最上面一行，名字后面有总数跨所有子库的全部资产（不受子库分类限制）当前库的所有资产
子库根第二层，带彩色图标（材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态 / 图片 / 音乐 / 动画数据 / 节点树）一个资产大类该子库全部资产（含下面所有分类）
分类子库根下面一层，文件夹样你自己建的文件夹该分类及其所有子分类里的资产
子分类更深的层级，可多层嵌套更细的文件夹同上，以其为根
「自定义」分类某些子库里插件自动建的那个给「不属于任何具体分类」的资产兜底同普通分类；不可删除
脚本树的最后一行，代码图标不是磁盘分类，是脚本浏览器的入口主区切到脚本浏览器（不是资产网格）
回收站树左下角的独立按钮（不在树里）已删除的资产 / 分类主区切到回收站视图

节点名后面的 (N) 是这个节点包含的资产数量；没有数字表示 0 个。图标颜色按子库区分，方便一眼认出材质（粉色）、模型（蓝色）等。

单击、双击、点箭头分别做什么

操作效果
单击节点名字选中并筛选：网格只显示该节点及其所有子分类里的资产
单击节点前面的箭头只展开 / 折叠这一层，不改变当前筛选
双击节点名字（有子节点时）展开 / 折叠这一层（「全部资产」是特例：整体展开或收起所有子库）
Ctrl + 单击加选 / 减选分类，网格显示多个分类的合集
Shift + 单击选中一段连续的分类
双击「全部资产」所有子库一起展开 / 一起收起；同时也会切到「全部资产」视图

几个要注意的规则

  • 点分类不改资产：分类只是一个筛选视图，资产归属由它所在的文件夹决定。想把资产换分类要用「移动到」，见 8.5.15。
  • 多选后网格是合集：选了「材质」+「模型」两个分类，网格会同时显示两边的内容；想回到单分类，普通单击一个节点即可。
  • 脚本节点不能和资产分类一起多选：它是整块视图的入口（会切走主区），Ctrl 点它时只会保留它自己。
  • 看不到某些子库：可能是设置里把顶级分类隐藏了，见 4.1.2.4。

小白易错点

  • 点了分类，资产数没变：可能这个分类下没有自己的资产，显示的是子分类里的；换一个节点试试。
  • 双击没展开，反而筛选变了：双击的判定窗口较宽（约 800ms），两下点得太慢就会被当成两次单击；点前面的箭头最稳。
  • 分类树空白 / 只有「全部资产」：资产库还在加载或路径失效，先看资产库下拉是否选了有效库，见 8.3.2。
