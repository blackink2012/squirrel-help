The 「收藏」 (Favorites) tab organizes assets by collection; a star only means "belongs to the currently selected collection".

What the panel contains

  • The + to the right of the 「收藏夹」 (Favorites) title creates a new collection.
  • The number after each list item is the asset count in that collection; 「默认收藏夹」 (default collection) is built in.
  • Small text at the top of the panel names the current library (main asset library or project library), because favorites are stored per library.

Actions

  • Clicking a collection shows only its assets in the grid.
  • Dragging an asset card onto a collection: a plain drop moves it into that collection (removing it from others); holding Ctrl while dropping adds it and keeps its previous membership.
  • Clicking the star on an asset card adds or removes it from the active collection, with the same effect as dragging.
  • Right-clicking a collection offers new and empty; custom collections can also be renamed and deleted (the default collection cannot be renamed or deleted).

Verify the result

After dropping or clicking a star the count next to the collection name changes immediately and the grid refreshes within the 「收藏」 (Favorites) tab. The data is stored in favorites.json in the current library root and survives a restart.

Tips

  • 「清空收藏夹」 (Empty collection) only removes members from that collection; it never deletes the assets, which stay in their original categories.
