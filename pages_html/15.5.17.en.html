What "Preview node" actually shows

It reads the node files in the asset and draws nodes and connections in the node editor, answering "how is the network inside this material / scene wired".

Files that get listedFiles that do not
.zmetal (material networks)The generic node.ma (the default node file produced on export)
Named .ma files (such as aiStandardSurface1.ma, place2dTexture1.ma)Textures, caches and thumbnails, which are not node files
.zmetal and named .ma inside variant / LOD directories (shown as variants/<version>/<file>)Cases where the asset holds no node file at all (the row does not appear)

So "my menu has no preview node" usually means this asset has no named node file — the menu is not broken. Compare with the "Conditional" row in 8.5.1.

Further reading: material node preview 4.4.1.4, previewing .ma node connections 4.4.3.4.

What "AI thumbnail analysis" does and writes back

  1. It opens the AI analysis window and hands your thumbnail to the vision model;
  2. It suggests category, tags, Chinese name (readable name) and notes;
  3. After you confirm or adjust each item and apply, the result is written into the asset metadata (the card's name, tags and category follow).

Prerequisites and limits:

  • AI dependencies must be complete (Ollama + embedding model and so on). When missing, the plug-in offers the one-click install in Settings → AI.
  • It analyses the thumbnail, not scene data; better thumbnails give better suggestions.
  • It changes no geometry and no textures, only proposes metadata. To undo a write-back, change it back in the edit dialog.

Which window "Asset details" opens

Asset situationWhat opens
Has versions (V1/V2…) or variantsThe version browser: lists all versions / variants / LODs, can import and manage
An ordinary single-version assetThe asset inspection window: large preview plus detail information

Two notes:

  • This item is always at the very bottom of the menu, after a separator, and closes the menu.
  • Right-clicking inside the asset inspection window reuses this menu but no longer shows Asset details (otherwise it would only open an identical window).

Notes

  • Preview node is read-only: it reads files and draws connections and builds nothing in your scene; go back to Import to import.
  • AI suggestions are not always right: the model only sees the thumbnail, so check category and tag suggestions against your conventions before applying.
  • Asset details equals double-clicking the preview image: two entries, one result — use whichever is convenient.
