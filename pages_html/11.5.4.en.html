Collecting linked files presets, per asset type, whether caches, proxies, references and textures are packaged by default on export.

Effect

When a new export dialog or asset creation starts, collect caches / proxies / references attached in the scene and textures are pre-checked.

Values and defaults

  • Two checkboxes:
    • 「收集场景中已挂载的缓存/代理/引用文件」 (collect caches / proxies / references attached in the scene), mapped to collect_associated.
    • 「贴图 textures/」 (textures), mapped to textures.
  • Defaults per asset type:
Asset typeCollect linked filesTextures
materialsCheckedChecked
modelsCheckedChecked
lightsUncheckedChecked
texturesUncheckedChecked
scenesCheckedChecked
hdrUncheckedChecked
aniCheckedChecked

Scope

  • It only decides the initial state of checkboxes in the export interface; a single export can still change them.
  • Linked files are copied into the asset's deps/ only when 「收集关联文件」 (Collect linked files) is checked; when unchecked the scan still runs and records missing dependencies, it just does not copy.
  • 「贴图 textures/」 (textures) controls whether textures enter the asset's textures/.
  • It is stored under the matching asset type key in Assets/preset/export_preset.json.

When to change it

  • The asset must be delivered to another machine: turn collection on for that type so textures and caches are not missing.
  • The library is local only and smaller assets are wanted: turn collection off and check it per export when needed.
  • Only materials matter and scene references do not: keep texture collection for materials and turn linked files off.

Tips

Tip: even without collection, missing dependencies appear in the export log and meta.json, so you can diagnose before deciding to package.

Tip: files already placed in textures/ as textures are never stored a second time under deps/.
