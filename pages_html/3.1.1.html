主窗口是停靠式三栏结构：顶部工具栏、左侧导航、中间资产区、右侧属性与预览，底部是状态栏。

区域与职责

位置区域负责什么
顶部顶部工具栏搜索、刷新、AI 工具、快捷工具、面板与布局、设置、帮助
左侧导航「分类 / 项目 / 收藏」三个页签与分类树
中间资产视控行 + 资产卡片网格或列表
右侧上属性当前资产的名称、分类、标签、注释等元数据
右侧中预览缩略图查看、切换与缩略图操作
右侧下AI 助手打开 / 关闭 dsh 对话面
底部状态栏资产数量、当前选中、搜索与后台任务进度

默认布局下左侧两栏只占较窄的一列、宽度优先留给中间的资产区；右侧竖向依次为属性、预览、AI 助手。

怎么认这些区域

  1. 每个区域顶部都有一条头部，左侧是面板名，右侧是功能按钮（下拉菜单）。
  2. 中间资产区的头部还并排放着「从外部导入 / 创建资产 / 面包屑 / 编辑标签 / 视图 / 排序 / 缩略图大小」这一行。
  3. 拖动区域之间的缝隙可以改宽高；拖动区域头部可以停靠或浮动。

结果验证

  • 选中一张资产卡片后，右侧「属性」和「预览」同时更新。
  • 点工具栏左侧的折叠按钮，左栏收成窄图标条；再点一次展开。

提示

  • 区域可以拆分、关闭、撕下；拖乱后用工具栏「面板与布局 → 重置布局」恢复。
  • 布局和窗口尺寸会自动保存，下次打开保持上次的样子（见 3.2.5）。
