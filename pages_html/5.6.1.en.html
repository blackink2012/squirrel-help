Drag an asset card out of the plug-in window and release over the Maya viewport; the plug-in completes the import automatically according to the asset type.

Prerequisites

  • A Maya scene is open.
  • The cursor drags from an asset card out of the plug-in window and lands inside the Maya viewport.

Steps

  1. Hold an asset card and start dragging.
  2. Drag out of the plug-in window and move to the position you want in the viewport.
  3. Release.
  4. Wait for the plug-in to finish importing.

Behavior by asset type

Asset typeBehavior after dropping
Models, dynamics, scenesImports with the default format; with snapping on it lands on the surface under the cursor
LightsImports with the default format; with snapping on it lights along the hit surface normal
Materials, texturesAssigns to the selected object if there is one; otherwise creates and selects the new material
HDRPicks a template from the current renderer or the double-click preset and creates a dome light directly
Node treesImports ma; the newly created nodes are selected afterwards (no visible geometry is normal)
Animation dataAsks for 「动画起始位置」 (animation start position) and then imports keyframes by hierarchy mapping; the hierarchy must exist in the scene
Images, audioDropping into the viewport does not import them: they are loose files and not part of the geometry drag pipeline. For images use the context menu's 「导入为 file 节点 / 创建 imagePlane」 (Import as file node / create imagePlane); for audio use 「导入到时间轴 / 时间编辑器 / Trax 编辑器 / 摄像机序列器」 (Import to timeline / Time Editor / Trax Editor / camera sequencer)

Verify the result

  • The asset appears in the scene, or the material is assigned to the selected object (images and audio do not take this path, see the table).
  • The Script Editor shows a [DragDrop] log.
  • When a multi-selection of snappable assets is dropped, they line up near the drop point.

Tips

  • Dragging never opens a format dialog; the format follows the same rule as double-click import.
  • Dropping images or audio into the viewport does not import them (they have no geometry or audio import target), so this is not a "lost drag" — use the context menu. Node trees and animation data can be dropped, but what they import is not visible in the viewport (node network / keyframes).
  • A mixed selection with different placement rules (such as models plus lights) skips snapping and imports item by item.
  • The dragged thumbnail follows the cursor, and snappable assets also show a drop-point preview.
