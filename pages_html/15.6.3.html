一句话定位：属性区域顶部只有一行 —— 左边写着「属性」，右边是一排小图标按钮，最右是区域功能按钮。

这一行同时是所在区域的「抓手」（按住空白处可以拖动这个区域），所以按钮都做得很小。

按钮一览

按钮图标什么时候出现点了做什么
收藏空心灰星 / 实心金星选中了资产、且不是回收站只读条目立刻切换收藏状态（不用保存）：空心 = 未收藏，实心金星 = 已收藏；卡片与收藏夹同步刷新
编辑铅笔一直显示（没选中资产时也在，但点了没反应）进入属性编辑态；等价于右键字段 →「编辑」
保存对勾（绿色）只在编辑态出现把编辑态的改动写回资产元数据，然后退回显示态
取消×（叉）只在编辑态出现丢弃本次未保存的改动，退回显示态（完全还原）
区域功能按钮主图标 + 紧贴的小下箭头，悬停提示「属性」一直显示弹出区域菜单：停靠回主窗口 / 各种拆分 / 撕下 / 撕下副本 / 最大化 / 还原 / 并入 / 关闭本区域

四颗小按钮的显示状态是互斥切换的：

状态收藏编辑保存取消
没选中资产隐藏显示隐藏隐藏
选中资产（显示态）显示显示隐藏隐藏
选中资产（编辑态）隐藏隐藏显示显示
回收站只读条目隐藏隐藏隐藏隐藏

区域功能按钮菜单

这颗按钮不属于属性面板本身，是所有区域共用的入口，只是悬停提示写着当前区域名（这里是「属性」）。菜单项包括：

菜单项作用详见
停靠回主窗口撕下来的浮动窗回到主窗3.2.1
向右 / 向下 / 向左 / 向上拆分把本区域切开，多出一个空区域3.2.2
撕下 / 撕下副本把属性区变成独立浮动窗口（副本是再开一份）3.2.1
最大化 / 还原本区域临时占满窗口 / 还原3.2.3
并入…把本区域合并到相邻区域3.2.2
关闭本区域关掉这个属性区域见下文

把属性面板关掉了怎么找回来

  • 顶部「面板」菜单里重新打开「属性」区域（见 8.2.5）；
  • 或者用「重置布局」把所有区域恢复默认（见 3.2.5）。

常见疑问

现象原因怎么办
看不到星星按钮没选中资产，或选中的是回收站条目回到资产网格选中一个正常资产
看不到保存 / 取消当前不在编辑态先点铅笔（或右键字段 →「编辑」）
点了铅笔没反应没选中资产 / 回收站只读条目 / 刚点了取消后的半秒内（防误触）选中资产、稍等一下再点
编辑时星星不见了编辑态下收藏按钮隐藏，属于正常切换保存或取消后它就回来
