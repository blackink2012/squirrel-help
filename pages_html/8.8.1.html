MCP 是外部 AI 工具调用插件能力的标准通道；只装技能不够，技能正文里写的工具必须真的存在。

两条服务器

名称作用是否依赖 Maya
squirrel-assets查资产、驱动 Maya / Blender 的场景与导入导出依赖在线实例
maya-kb查 Maya 离线知识库不依赖，Maya 没开也能用

两条都通过 stdio 启动：源码形态是 python mcp\squirrel_mcp_server.py，打包形态由主程序带哨兵参数拉起。squirrel-assets 还会写入 --broker-url 与 --instance-id，默认底座是 http://127.0.0.1:39002。

暴露哪些工具

不是全部命令都暴露，而是一份高频白名单，覆盖场景、资产、渲染与执行四组；命令清单始终从底座的 /commands 现取，不写死。高风险命令（如执行 Python）也在白名单里，调用方应先预览再执行。

怎么挂

在「设置 → AI 设置 →『外部 AI 工具』组 →『外部 AI 工具…』」里对目标工具勾选 MCP，插件会把条目写进对方的配置文件；没有可安全写入的配置时，只能复制片段手工粘贴。

边界

MCP 入口不直连 Maya，也不 import maya；它只与本地底座说话。写入别人的配置前会备份，解析失败宁可不写，且只增删我们自己的条目。
