Right-click a texture asset and use the 「导入贴图」 (Import texture) submenu to turn a single texture or a whole set into file nodes in the scene.

Prerequisites

  • A Maya scene is open.
  • The texture asset has readable image files under textures/.

Steps

  1. Right-click the texture asset and expand 「导入贴图」 (Import texture).
  2. When the asset has several resolution directories, choose one first (such as 2K or 4K); with a single level the file names are listed directly.
  3. Import one file: click the file name and the plug-in creates a file node and a place2dTexture, then selects that file node.
  4. Import the whole set: click 「导入全部」 (Import all) or 「导入全部 (<resolution>)」 (Import all (<resolution>)) and the plug-in creates the file nodes in bulk and makes them share one place2dTexture.

Verify the result

  • The matching number of file nodes appears in the Hypershade.
  • After a single import that file node is selected.
  • After a batch import every file node's UV connection points at the same place2dTexture, so adjusting that node changes all UVs together.

Tips

  • Color space follows the extension: png, jpg, jpeg, tga, tif, tiff, bmp and psd are sRGB; exr and hdr are Raw.
  • Where textures are stored follows the texture import policy; 「拷贝贴图到项目」 (Copy textures into the project) copies them to sourceimages/squirrel_asset/ in the project.
  • To connect a texture to an existing material use 「指定贴图」 (Assign texture); to build a new material set use 「创建材质」 (Create material).
