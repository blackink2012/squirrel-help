A .mmap is the attribute correspondence table for "source material type → target material type"; conversion writes each source attribute onto its target attribute row by row.

Prerequisites

  • The plug-in is installed and Assets/material_mapper_presets is reachable in the plug-in directory (Assets/light_mapper_presets for lights); the tool shows the 「预设路径」 (preset path) in use at the bottom, which is authoritative.
  • The node type names of the source and target materials or lights are known (case-sensitive).

Steps

  1. Open the mapping directory and find a file shaped like lambert_aiStandardSurface.mmap; the file name is source type_target type.
  2. Open the file and check the top-level source_type, target_type and mappings; every row in mappings has source_attribute, target_attribute, transform and default_value, plus parameters when arguments are needed.
  3. Load the whole mapping folder into the material conversion tool: click 「加载预设」 (Load presets) (or 「打开文件夹」 (Open folder) first to confirm the directory) and the tool scans every .mmap inside.
  4. Check the row count and mapping contents in the table (material attribute / target attribute / transform function / parameters / default value).

Verify the result

The conversion tool's status bar shows how many mapping files were loaded; the preview table lists source attributes, target attributes, transform functions and defaults; during conversion the Script Editor no longer reports missing mappings.

Tips

  • Lookup order: A_B.mmap in the root → the B/ sub-directory → any first-level sub-directory; light mappings and material mappings are physically isolated and must not be mixed.
  • An empty source_attribute means only default_value is written; a missing source attribute also falls back to the default.
  • transform holds the conversion function name (such as transparency_to_transmission), with JSON arguments passed through parameters when needed.
  • .mmap only describes attribute rules and is not the same as the type mapping configuration preset .mlist, which only records which types convert into which.
