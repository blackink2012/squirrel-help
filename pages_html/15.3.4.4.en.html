One-line summary: the "Scripts" row at the end of the category tree is not a disk category but the entry to the script browser; the recycle bin at the bottom left is not a tree node either but a separate button. Both menus are short.

How to open them

  • Scripts node: left navigation → Category tab → the last row Scripts in the tree → right-click it.
  • Recycle bin: left navigation → Category tab → the Recycle bin N button at the bottom left of the tree → left-click to enter the recycle bin view.
  • Blank tree space: right-click an area of the tree with no node.

Beginner pitfalls

  • Right-clicking Scripts to create a sub-category: not possible; it is not a disk category, and scripts themselves are managed in settings / the script browser.
  • Right-clicking the recycle bin does nothing and seems broken: by design, there is no menu there. Enter it and right-click an entry to get actions.
  • Deleted items from the main library are missing from the recycle bin: check whether the current tab is Category or Project — the two libraries have separate recycle bins.
  • Expecting a one-click empty recycle bin: there is no such button. Entries can only be deleted one by one via Delete permanently, which is irreversible, so read the confirmation text before acting.
