一句话定位：这两条是「资产换分类」的唯一入口，结构完全一样，区别只有一句：移动到 = 搬走，复制到 = 多一份。

长什么样

点开后是一个级联子菜单，第一层是 11 个顶级分类（材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 动态 / 图片 / 音频 / 动画数据 / 节点树），往下每一层展开该分类的子分类。

移动到 ▶
├─ 材质 ▶
│   ├─ 材质        ← 带返回箭头：选这个顶级分类本身
│   ├─ ─────
│   ├─ 自定义
│   ├─ 布料
│   ├─ 金属
│   └─ …
├─ 模型 ▶
│   ├─ 模型
│   ├─ ─────
│   ├─ 建筑
│   └─ …
└─ …

两个读法：

  • 带返回箭头的那一项（图标是一个向左的箭头）= 选中「这个分类本身」，不需要再往里点；
  • 「全部资产」节点不出现在级联里——它不是一个真的存放位置。

逐项详解

菜单项作用前提点了之后注意
移动到 ▶把资产搬到目标分类资产库已加载资产从当前分类消失，出现在目标分类；分类树自动刷新并跳到目标分类移动不经过回收站，但可以再移回来
复制到 ▶把资产复制一份到目标分类资产库已加载目标分类里多出同一资产，原分类仍然保留复制的是完整资产包，占双份磁盘空间

移动 vs 复制

场景用哪个
这个资产就该属于别的分类移动到
同一个资产要在两个分类都能找到复制到
想保留原件、试一套改过的新版本复制到（然后改副本）
想省磁盘空间移动到

多选时

多选后右键「移动到 / 复制到」，对全部选中资产生效——一次把一批资产搬过去。搬完分类树会刷新并停在目标分类上，方便你接着整理。

这个条目特有的注意点

  • 跨子库也能搬：材质移到模型分类、贴图移到 HDR 分类，菜单不拦。但类型不符的资产放到别的子库，之后在那边打开 / 预览可能不符合预期，慎用。
  • 移动前想清楚目标分类：选错了再移一次就能回来，不用重新导入。
  • 复制多的副本要自己删：复制没有「撤销多一份」的按钮，不要了用「删除 → 移到回收站」。
  • 分类树下标可能滞后：移动 / 复制后如果数量没变，点一下工具栏刷新，或切一下别的分类再回来。
