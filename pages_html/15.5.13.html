「导入」在菜单上的三种形态

形态什么时候出现例子
单行「导入 <格式>」资产里只有一种可用格式模型：导入 ma；HDR：导入 hdr
「导入 ▶」子菜单资产里有多种可用格式材质：zmetal / ma；灯光：zlight / ma；动态：ma / abc
子库专用入口该子库的导入方式不止「导文件」贴图 导入贴图 ▶、图片 导入为 file 节点、音频 导入到时间轴…、动画数据 导入动画 ▶

子菜单里的每一项都是「格式名」（只有一种格式时也会显示成「导入 ma」这种带格式的写法），选哪个就直接按哪个格式导。

「导入 ▶」里还可能多出「导入版本 / LOD」

当资产是带版本、带变体或多条 LOD 的主资产时，「导入 ▶」子菜单里会再出现一段内部条目（标题随内容变化）：

条目说明
导入变体 / 版本 ▶（或「导入变体 ▶」「导入版本 / LOD ▶」）展开资产内部的各版本 / 变体 / LOD，可以只导其中一份
版本节点（如 V1、V2）版本自身；点进去再选该版本里的 LOD 或几何格式
变体变体条目，标签后面会带面数（如「— 12,345面」）
主版本资产的主版本内容
查看版本 / 查看变体 / 查看 LOD 管理不是导入，而是把资产区切换成「内部视图」，像文件夹一样浏览内部条目

内部条目本身的右键菜单（精简版）见 8.5.18。

「添加引用」的两种形态

形态什么时候出现
单行「添加引用」资产里只有一种可引用格式
「添加引用 ▶」子菜单资产里有多种可引用格式（典型：动态的 ma / abc）

可被引用的格式是固定的这一组：.ma / .mb / .fbx / .abc / .usd / .obj。资产里一个都没有时，这一行不会出现。

导入和引用该选哪个

你想要的选原因
在场景里改几何体、改材质导入进来的是真正可编辑的节点
只是摆放 / 跟着资产更新添加引用场景只存路径，资产更新后重载即生效
需要节省场景文件体积添加引用内容留在资产包里，不写进当前场景

引用的代价：资产包被移动、改名或删除，引用会断（场景里显示成找不到文件）。导入没有这个问题，但内容进了场景，改资产不会自动跟着变。

点了之后会看到什么

  • 导入：直接在当前场景里生成内容；材质、灯光、节点树类会自动选中新建的节点，方便你接着操作。当前渲染器与资产不同源时，会再弹一次「是否转换」的询问。
  • 添加引用：场景里出现一个引用节点（Outliner 里带引用标记），文件本身不动。
  • 多选后点导入 / 引用：对所有选中资产各执行一次（同一格式），不是只处理你右键的那一个。

注意点

  • 导入不复制资产文件：素材还是从资产包里读的；把资产包挪走，场景里贴图会丢。
  • 同名冲突会先问你：场景里已有同名节点时按设置走（询问 / 自动改名 / 覆盖），见 4.3.6.1。
  • 文档里说「导入」的地方，界面上可能显示成「导入 ma」：这是同一条命令的不同长相，别以为是两个功能。
