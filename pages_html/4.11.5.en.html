Removing a library only unregisters the entry from the library list; no library directory or asset on disk is deleted.

Steps

  1. Open the Settings window and go to the 「资产库管理」 (Asset library management) group on the 「常规」 (General) tab.
  2. Select the library to remove in the list.
  3. Click 「删除选中」 (Delete selected).
  4. Click 「确定」 (OK) to save the settings.
  5. If the current library was removed, go back to the 「分类」 (Categories) page and switch to another library in the dropdown.

Verify the result

  • The settings list loses an item and the main window's library dropdown no longer lists that library.
  • The library directory, its assets and favorites.json on disk stay untouched.
  • 「添加资产库」 (Add asset library) can register it again later.

Tips

警告

At least one asset library must remain; clicking delete when only one is left reports 「至少保留一个资产库」 (keep at least one asset library).

  • Removing the default library does not rewrite default_library; set another library as default before removing it.
  • After removing the current library you must switch manually; library_manage op=remove returns was_current / was_default so you can confirm.
  • To really delete library files, remove the directory outside the plug-in; the plug-in offers no disk-delete operation.
