Adding an existing library registers a ready-made library directory on disk in the library list; it never copies, moves or modifies any file inside the library.

Steps

  1. Open the Settings window, go to the 「常规」 (General) tab and find the 「资产库管理」 (Asset library management) group.
  2. Click 「添加资产库」 (Add asset library).
  3. Pick the library root directory in the file dialog.
  4. Type a display name; the directory name is used by default.
  5. Click 「确定」 (OK) in the Settings window to save.
  6. Go back to the 「分类」 (Categories) page in the main window and choose that library in the dropdown to start using it.

Verify the result

  • The library appears in the settings list as "name — path".
  • The same library appears in the main window's library dropdown.
  • After switching, the library's assets load and nothing in the library root was changed.

Tips

  • Adding the same path twice reports 「该资产库已在列表中」 (this asset library is already in the list); path comparison normalizes slashes and case.
  • It only registers the directory and does not validate the standard structure; a library root usually contains library.json and sub-library directories such as materials and models.
  • Adding does not switch to it automatically; pick it in the library dropdown.
  • On the command side library_manage op=add is equivalent and only accepts an existing directory; an unregistered path is first added to library_paths.
