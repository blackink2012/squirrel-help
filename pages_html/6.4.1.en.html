Settings → 导出默认值 (Export defaults) stores the formats and options checked by default when creating a new asset, per sub-library, in Assets/preset/export_preset.json in the plug-in directory.

Prerequisites

  • The plug-in Settings window can be opened.
  • It is clear which sub-library's defaults should change. The list on the left comes from sub_libraries in Assets/preset/config.json: 11 built-in sub-libraries — materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees — plus any custom sub-libraries.

Steps

  1. Open 「设置」 (Settings) and switch to the 「导出默认值」 (Export defaults) tab.
  2. Choose a sub-library in the list on the left, for example materials.
  3. Check the defaults on the right:
    • Material formats: 材质节点 (.zmetal), 合并材质 (.zmetal_merge), 材质→模型映射 (.mcm).
    • Geometry formats: ma, mb, fbx, obj, usd.
    • Caches and proxies: abc, arnold, vray, redshift, vrmesh.
    • Collect linked files: whether caches / proxies / references and textures are collected by default.
    • Export options: whether "export materials only" is the default.
  4. Switch to another sub-library and continue; the current sub-library's checks are held in memory first.
  5. Click 「应用」 (Apply) or 「确定」 (OK) to write export_preset.json.

Verify the result

  • After closing and reopening Settings the 「导出默认值」 (Export defaults) tab still shows the checks you made.
  • Clicking 「创建资产」 (Create asset) in that sub-library opens a dialog whose format checks match the defaults.
  • The booleans for that sub-library in Assets/preset/export_preset.json are updated.

Tips and warnings

Tip: the defaults only affect Create asset; Update asset restores checks from the asset's existing formats, and choosing Append format starts with everything unchecked.

Tip: checks changed temporarily in the export dialog apply to that one export only and are not written back to the defaults.

Tip: when a sub-library has no entry in the preset file, _default is read; when _default is missing too it falls back to the materials section.

Current version: the buttons on this tab are 「应用」 (Apply) and 「确定」 (OK); there is no separate 「保存」 (Save) button.
