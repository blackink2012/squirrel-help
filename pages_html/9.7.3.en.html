Quick tools have no registry: dropping a .py into quicktools/ completes the UI registration; only the command channel or a special run location needs an extra edit.

The fastest path

  1. Create a .py file in <plug-in root>/quicktools/.
  2. Provide a main(), run() or if __name__ == "__main__": entry.
  3. Open the 「快捷工具」 (Quick tools) menu, confirm the file name appears and click to run it.

The menu rescans the directory every time it opens, so no Maya restart is needed. Calling quicktool_run without name also lists the new file and its entry.

When extra registration is needed

NeedWhat to change
Have the command channel suggest "prefer this first-class command"The _QUICKTOOL_COVERAGE map in squirrel_asset_manager/ai/runtime_commands.py
Have a dedicated command (parameter schema, dry_run, structured result)squirrel_asset_manager/ai/quicktools_commands.py, registering a CommandDescriptor like the existing three commands
A pure file tool that should run locally in the standalone edition instead of being dispatched to MayaThe local_only set in _run_quick_tool in squirrel_asset_manager/ui/main_window.py
A dedicated help page inside the toolPlace help.html in Assets/help/<tool name>/

After registering a command, call refresh_commands if the plug-in is running to rebuild the executor and reconnect; commands in flight at that moment fail, so never call it during a long job.

Verify the result

  1. The menu shows the new entry instead of 「暂无快捷工具」 (no quick tools yet).
  2. Clicking it opens the window or runs the script without ImportError / SyntaxError in the Script Editor.
  3. Calling the command channel without name lists the file and its entry; passing name returns status: ok.
  4. For a pure file tool that should run locally, confirm in the standalone edition that it is not dispatched to Maya.

Notes

  • If it does not appear, first confirm the file is in the root of quicktools/, ends in .py and is not in a sub-directory.
  • Clicking with no effect usually means no recognizable entry; the menu prints 「没有可执行的入口」 (no executable entry).
  • After adding a command or changing a parameter schema, refresh the command list so external AI tools do not keep seeing the old schema.
  • Registration changes are plug-in source changes; verify them in a test environment before distributing.
