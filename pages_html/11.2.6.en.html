The appearance theme switches the plug-in interface between dark and light colors and only affects plug-in windows.

Effect

It chooses the color scheme used by the plug-in main window and dialogs.

Values and default

  • Dark (default), Light.

Scope

  • After 「应用」 (Apply) the main window immediately rebinds color tokens, rebuilds the style sheet and re-renders icons.
  • Backgrounds, text, borders, buttons and status colors all switch together; colored icons in toolbars and menus are re-tinted for the new background.
  • Dialogs opened afterwards use the new colors.
  • It never affects Maya's native interface, the viewport background or render results, and never changes icon shapes or layout.
  • It is stored under the theme key in app_settings.json.

When to change it

  • Light reads better in a bright office; keep dark for dim rooms or night work.
  • Switch when colors should match screenshots or a presentation.
  • Sticking with one theme is fine; frequent switching never affects asset data.

Verify the result

  • The main window's background and text colors change immediately, and newly opened dialogs match the main window.
  • Closing and reopening Settings still shows the chosen value in the theme dropdown.

Tips

Tip: if a window that is already open still shows the old colors, reopen it.

Tip: switching the theme never changes font size or interface scaling.
