One-line summary: the dropdown at the very top of the Category tab switches between main asset libraries — switching libraries means switching the whole category tree and asset set.

How to open it

  1. Left navigation → click the Category tab;
  2. Click the dropdown at the top of the tab (it shows "library name — library path");
  3. Click another library in the expanded list.

Item-by-item details

The number of items equals how many asset libraries you configured in settings (2 in the example environment). Every row is formatted as "library name — full library path".

Submenus

This dropdown has no second level: every row is one library, clicking switches immediately with no further expansion.

Adding and removing libraries is not here

This dropdown only switches; it offers no add / create / remove / set default. Those live in the settings window → General page → Asset library management:

What you wantWhere to go
Add an existing librarySettings → General → Asset library management → Add asset library, see 8.9.2
Create an empty librarySettings → General → Asset library management → Create asset library
Remove a library from the listSettings → General → Asset library management → Delete selected
Make it the startup defaultSettings → General → Asset library management → Set as default

Beginner pitfalls

  • After switching libraries all assets and categories changed: normal. Each library has its own category tree and assets; this is "switching libraries", not "switching categories". Switch back in the dropdown to return.
  • The library I want is not in the dropdown: it has not been registered in settings yet; go to Settings → General → Add asset library.
  • Clicking another library does nothing but shows a warning: that library's path no longer exists (drive letter changed, folder moved or renamed). Restore the folder, or remove the invalid entry in settings.
  • Thinking switching deletes something: switching only changes which library is displayed; it moves and deletes no assets.
