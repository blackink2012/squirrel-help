One-line summary: batch-pack the .hdr / .exr environment maps on disk into .zasset packages the library understands, optionally generating thumbnails along the way.

This is the first tool under Quick tools, and it moves "files outside the library" into "assets inside the library". It never touches your scene; it only reads source files and writes to the output directory.

A complete flow

  1. Quick tools → hdr to zasset;
  2. Choose input mode Choose folder and browse to the HDR / EXR directory;
  3. Choose an empty directory (outside the library) as the output location;
  4. Tick Recursively scan subfolders if needed, and Keep hierarchy as required (leave it off for batch import);
  5. Tick Generate thumbnail preview; add Prefer existing thumbnails when same-named PNG/JPG files sit beside the sources;
  6. Click Scan HDR files and confirm "Found N HDR files" matches expectations;
  7. Click Convert and wait ("Conversion finished: X succeeded, Y failed"; failures list error details);
  8. In the output directory confirm each HDR produced a same-named .zasset folder containing textures/, thumb.sicon and meta.json;
  9. Once it looks right, copy the .zasset folders into the matching library category and click refresh in the main window (the toolbar refresh button) to see them.

Where the output lands

  • .zasset packages are generated under the output location, one per source file, named after the HDR file;
  • A .zasset is a folder (not a single file) holding the packed textures, thumbnail and meta.json;
  • With Import into the current category after conversion ticked it also copies another set into the current category directory and the completion message says "imported N into the current category"; refresh the main window to see them.

Risks and how to undo

  • A same-named asset is replaced entirely: when the output directory already holds <name>.zasset, generation deletes the old one first and then writes the new one. So never point the output at a category directory that already contains same-named assets — output to an empty directory, verify, then copy.
  • Conversion only reads the source HDR / EXR files and never changes them; failing files are listed in the error details and the originals are unaffected.
  • When thumbnail generation fails it asks "continue converting (skip thumbnail generation)?" and you may continue.
  • To undo, delete the newly generated .zasset folders in the output directory; if they were already copied into the library and refreshed, delete them to the recycle bin in the main window (see 8.5.16).
