Ollama is the local model service, the embedding model turns text and images into vectors, and the vision chat model looks at images and gives suggestions; the three serve different purposes and cannot replace each other.

How the model is chosen

AI analysis does not hard-code a model name: it uses your choice first, then picks a model from the provider's live list that can chat and see images, and only then reports an error. When the configured model is not installed or is text-only, the plug-in substitutes an available model and records why.

Switching models

Changing the embedding model changes the vector space, so the old indexes must be rebuilt:

  • Asset text index: python tools\asset_index.py --rebuild --model <model name>
  • Maya documentation index: python tools\build_semantic_index.py --model <model name>
  • Image index: python tools\asset_vision_encode.py sync --library "<library root>" --rebuild --model gemma2

Each index records the model it used, and a mismatch marks it unavailable with the rebuild command.

Verify the result

ollama list shows the model; running 「AI 依赖检查」 (AI dependency check) again shows both the embedding and vision model items as available.
