Batch thumbnail rendering generates thumbnails for assets inside mayapy: the interface shows options first, then a separate process renders without occupying the current viewport.

Options

  • Renderer: Arnold, Maya Software, Maya Hardware 2.0, V-Ray, Redshift. Unavailable renderers are greyed out with a reason.
  • Preset model: material, texture and light assets have no geometry of their own, so pick a preset model from Assets/Meshes to carry them.
  • Environment light (HDRI): check 「使用 HDRI 环境光」 (Use HDRI environment light) and pick a preset; light assets do not show this block because a light is its own source.
  • Size: 256, 384, 512, 768 or 1024, defaulting to the configured thumbnail size.
  • Quality: Fast / Standard / High, mapped to the current renderer's own sampling settings.

Tool requirements

  • Arnold needs kick and oiiotool, which ship with Arnold.
  • Maya Hardware 2.0, V-Ray and Redshift need Maya's Render.exe in a batch session.
  • V-Ray and Redshift also need their plug-ins installed locally; Redshift additionally needs a usable GPU.

Steps

  1. Select one or more assets, right-click → 「更新缩略图」 (Update thumbnail) → 「后台渲染」 (Background render).
  2. In the dialog (also titled "background render") choose the renderer, model (when needed), environment light, size and quality.
  3. Click 「开始生成」 (Start) and wait for the progress window to finish.

Verify the result

Successful thumbnails are written back to the assets and refresh on the cards; failures and skipped items report reasons one by one (missing geometry, missing preset model, missing render tools and so on). Images are validated before writing, so flat or empty images never overwrite existing thumbnails.

Tips and warnings

  • An unavailable renderer is an environment problem; switch to an available one to get images first.
  • Higher quality is slower; Arnold uses the standard level by default.
  • The environment light only provides lighting and never enters the background, so thumbnails have a transparent background.
