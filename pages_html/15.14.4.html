一句话定位：把一批图片从一种格式换成另一种格式（png / jpg / exr / hdr / tga / tif / bmp / webp），可以顺带改分辨率。

它只做"格式与尺寸"的转换，不入库、不碰 Maya 场景。跟资产库里的「图像格式转换」（8.12.4）不是同一个东西：那个是针对库内资产的，这个是针对磁盘目录的。

从哪打开

入口具体怎么做
顶部工具栏「快捷工具」菜单「快捷工具」→「图像格式转换工具」
脚本浏览器「脚本浏览器」→ 添加插件目录下的 quicktools 目录 → 图像格式转换工具.py 双击运行

窗口标题是「图像格式批量转换」。三种快捷工具入口是同一套窗口。

界面上每个控件做什么

卡片「输入模式」

控件作用取值建议
单选「选择文件」手工挑若干个图片只转几个时用
单选「选择文件夹」整个目录转批量用这个

卡片「输入」

控件作用取值建议
路径输入框（占位「选择要转换的图像文件...」/「选择要转换的文件夹...」）源文件或源目录—
「浏览...」选文件 / 选目录—

卡片「输入格式过滤」

控件作用取值建议
输入框（占位「例如: png, jpg, exr」）只转这些扩展名；留空 = 转换所有支持格式目录里混着别的文件时填上
「支持格式: .bmp, .exr, .hdr, .jpeg, .jpg, .png, .tga, .tif, .tiff, .webp」能被读进来的格式清单不在清单里的会读不出来

卡片「输出位置」

控件作用取值建议
路径输入框（占位「选择输出文件夹...」）转换结果放哪务必指向一个空目录或专门的输出目录，见"风险"
「浏览...」选目录—

卡片「输出格式」

控件作用取值建议
「目标格式:」下拉.exr (OpenEXR) / .hdr (Radiance HDR) / .png (PNG) / .jpg (JPEG) / .jpeg (JPEG) / .tif (TIFF) / .tiff (TIFF) / .bmp (BMP) / .webp (WebP) / .tga (TGA)要带透明通道别选 jpg；要 HDR 数据选 exr / hdr

卡片「输出分辨率（留空保持原尺寸）」

控件作用取值建议
「宽:」输入框（占位「不限」）目标宽度（像素）留空 = 保持原宽
「高:」输入框（占位「不限」）目标高度（像素）留空 = 保持原高
勾选「保持宽高比」勾 = 缩放时不变形；不勾 = 拉伸到指定宽高一般都要勾

卡片「输出结构」

控件作用取值建议
勾选「保持层级结构」勾 = 输出保留源目录层级；不勾 = 全部平铺到输出目录源目录分层时建议勾

日志区与底部

控件作用
「转换日志」区实时打印：输出到哪个目录、要转几个文件、每个文件的处理、「源文件已重命名」、每个失败原因
状态文字「就绪」/「正在处理 (i/n): 文件名」当前进度
「已选择 N 个文件」当前输入里有多少个待转文件
图标按钮「使用帮助」打开详细帮助
「取消」关窗口
「开始转换」开跑；跑起来后它会变成「中止」，点一下在下一个文件前停下

一次完整的操作流程

  1. 快捷工具 →「图像格式转换工具」；
  2. 输入模式选「选择文件夹」，浏览选源目录；
  3. 「输入格式过滤」填上要转的格式（例如 exr），不填则转所有支持的；
  4. 「输出位置」选一个空目录；
  5. 「目标格式」选要的输出格式；
  6. 需要改尺寸时填宽 / 高，并勾「保持宽高比」；不需要就都留空；
  7. 源目录分层且想保留结构 → 勾「保持层级结构」；
  8. 点「开始转换」，盯一眼日志：确认"转换 N 个文件 -> .xxx"的数字和「输出到」路径都对；
  9. 转完弹「转换完成！成功 X, 失败 Y」，失败原因在日志里，一条一行；
  10. 去输出目录确认文件（同名文件在对应子目录里）。

输出结果在哪

  • 输出文件在「输出位置」下，文件名 = 源文件名（扩展名换成目标格式）；
  • 勾了「保持层级结构」时，子目录结构和源目录一致；
  • 转换完不会自动打开文件夹，需要自己去输出目录看；日志里每一行都写了处理路径。

风险与反悔（两个真会咬人的点）

  • 同名输出会被直接覆盖，没有任何提示。 输出目录里已经有同名文件（比如上次转过的结果），这次会静默盖掉。想保住旧结果：换一个空输出目录，或先把旧结果改名/移走。
  • 源文件名含 Windows 非法字符时，工具会把源文件改名。 日志里会出现「源文件已重命名: 旧名 -> 新名」。这是它对源目录的唯一写操作，而且不可逆（改名后原文件路径就没了）。不想让它动源文件：先把源目录复制一份再转。
  • 中止是安全的：点「中止」会在当前文件处理完后停下，已转好的文件保留，日志会写「用户中止转换」。
  • 反悔：删掉输出目录里转出来的文件即可；源文件除了上面那种改名之外不会被改动或删除。
