The standalone edition is the same asset interface started outside Maya; the EXE installer sets it up together with a bundled Python runtime and an optional Maya integration.

Standalone edition

  • The entry point is squirrel_asset_manager/standalone_preview.py; in the source package you can also double-click 启动独立预览.bat (Start standalone preview).
  • It runs on system Python with PySide6, or on the mayapy that ships with Maya (without starting the Maya UI).
  • It drives the running Maya through the local commandPort, sending import, export, thumbnail and asset-update jobs to Maya; it has been verified on Maya 2025.
  • When Maya is offline you can only browse, search and run file-level operations; scene import and export are unavailable.

EXE installer version

  • Installs to %LOCALAPPDATA%\SquirrelAM (changeable during installation), per user, with no administrator rights required.
  • Bundles Python 3.11.9, PySide6 6.9.2, Pillow, requests and pypinyin; on startup SquirrelAssetManager.exe sets up the environment and launches standalone_preview.py.
  • The installer offers an optional 「Maya 集成」 (Maya integration): it writes the import path, status-line button and bridge port into each version's userSetup.py, and creates the shelf button once during installation (it is not rebuilt later); when no Maya is found the option is unchecked by default.
  • An optional 「AI 助手 dsh（离线）」 (offline AI assistant dsh) unpacks a bundled dsh and portable Node; skipping it does not affect asset browsing and management.

Who it is for

  • People who want to organize, search and preview assets without opening Maya.
  • Artists who send asset operations to an already open Maya, or who want an external AI or command line to drive Maya.
  • Users who are not comfortable with Python environments and prefer a double-click install: choose the EXE.

Known limits

  • Batch export in the standalone edition is dispatched job by job, without the progress overlay and cancel button of the in-Maya version.
  • Without Maya, scene-dependent features are unavailable; the port only listens on 127.0.0.1.
