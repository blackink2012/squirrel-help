One-line summary: this window's confirm button is not at the bottom — it sits at the top of the left column. Clicking it is the actual export: same-name check first, then packing, then the capture.

Where the buttons are

ButtonPositionEffect
Create asset (blue main button)Top of the left column (not the bottom of the window)Confirms and starts the export using the Maya selection and category at that moment
Orange help iconRight of Create assetOpens the legacy export help page in a browser
Close (window ×)Top right of the windowCloses the dialog without exporting; changed parameters are not saved

Older versions and older help called the confirm button a "bottom button", which is why this page title keeps the wording; in the current version it really is at the top of the left column. When you cannot find the button, look in the upper left of the window.

What happens after clicking Create asset

  1. Validation: whether a category is selected and whether objects are selected in Maya. Either failing shows a prompt and aborts without closing the window.
  2. Live state: it re-reads the current Maya selection (not the one from when the window opened).
  3. Name conflict check: when the target category already holds an asset (or folder) with the same name, the "asset name conflict" window appears first, see 8.12.5. Cancelling it means no export.
  4. Pack and export: writes meta, collects textures, writes material / geometry / cache / proxy files and generates the thumbnail.
  5. Thumbnail: with Screenshot tool a capture overlay asks you to frame; playblast / render image produce it automatically.
  6. Finish: the grid refreshes, the new asset card appears and is selected automatically, and the preview and properties panel switch to it.

The progress window during batch export

A batch (fully automatic / semi-automatic with more than one object) opens a batch export progress window showing which item of how many is running, with Cancel batch export. Cancellation is cooperative: the current asset finishes first and already exported assets stay in the library. In semi-automatic mode each asset also asks for its own framing.

How to undo

  • Abandon this export: just close the window (×) before exporting and nothing is written.
  • Exported with the wrong name / formats: you cannot change it back in this window. The asset is already on disk, so delete and re-export (deleting moves it to the recycle bin and is restorable), or use right-click Update asset to overwrite with the new result.
  • Deleted an asset by mistake: deleted assets go to the recycle bin and can be restored; delete permanently skips the recycle bin and cannot be restored. See 4.1.8.2.
  • Overwrote a same-name asset: the pre-overwrite content is not kept and the plug-in saves no backup. Copy important assets before overwriting.
