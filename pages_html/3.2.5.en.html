The layout needs no manual save: changes are written to the configuration file automatically and restored on the next start; use 「重置布局」 (Reset layout) to return to the default.

Automatic saving

The following state is written to ~/.squirrel_asset_manager/app_settings.json as you work:

  • Window size and position, the area layout tree and the maximized area.
  • Visibility and width of the left and right columns.
  • The current category, expanded category nodes and the active left-column tab.
  • Icon / list view, sorting, thumbnail size, the AI search switch and the layout lock state.

Restoring

Reopening the plug-in window restores the saved values. If an area was closed or the layout is damaged, the plug-in restores a missing preview area or falls back to the default layout as far as possible.

Resetting the layout

  1. Click 「面板与布局」 (Panels and layout) in the toolbar.
  2. Choose 「重置布局」 (Reset layout).
  3. Areas return to the default structure: navigation, assets, properties, preview, AI assistant; both side columns are expanded.
  4. Data state such as the current category and selection is kept where possible, and assets are never cleared.

Verify the result

  • After splitting or closing an area, closing and reopening the window keeps the adjusted layout.
  • After resetting, the area structure is back to default while thumbnails and assets are still there.
  • The maximized state survives a restart (if the window was maximized before closing).

Tips

  • Do not edit app_settings.json by hand while the plug-in is running; a bad edit can make the layout unreadable.
  • To back up the layout, close the plug-in first and then copy that JSON file.
  • Persistence of floating areas is to be confirmed; a docked layout is saved reliably.
