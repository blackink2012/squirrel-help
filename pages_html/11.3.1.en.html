Library list management is where asset libraries are added, created and removed, and where the default library loaded at startup is chosen.

Prerequisites

  • The 「资产库管理」 (Asset library management) group on Settings → 常规 (General) is open.
  • The directory to add is accessible on this machine, and the parent directory is writable when creating a library.

Steps

  1. Add an existing library: click 「添加资产库」 (Add asset library), choose the library directory on disk and type a display name (empty uses the folder name).
  2. Create a new library: click 「创建资产库」 (Create asset library), pick a parent directory and type a name (default SquirrelLib). The plug-in creates the library directory, library.json and the six sub-library directories materials, models, lights, textures, scenes and HDR; the remaining built-in sub-libraries are completed automatically the next time the library loads.
  3. Set as default: select an entry and click 「设为默认」 (Set as default); a [默认] ([default]) marker appears and the library loads automatically at startup.
  4. Delete: select and click 「删除选中」 (Delete selected). This only removes it from the list, never deletes files on disk, and at least one library must remain.
  5. Click 「应用」 (Apply) or 「确定」 (OK) to save.

Verify the result

  • The list shows name — path [default].
  • The main window's library dropdown shows the new library immediately, and it switches automatically when the default changes.
  • Reopening Settings still shows the list and the default marker.

Tips

Tip: the same path (different slashes or letter case) counts as a duplicate, and adding it reports 「该资产库已在列表中」 (this asset library is already in the list).

Tip: when an empty folder is switched to for the first time, all built-in sub-library directories are completed from the configuration (11 in total: materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees).

Warning: deleting a library only changes the list; to really clean the disk, do it yourself in Explorer.
