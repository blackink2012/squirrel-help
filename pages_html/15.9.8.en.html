One-line summary: this page controls which sub-libraries exist in the left column, what they are called, and which categories each one carries by default.

This page is locked by default: tick Unlock all settings and accept the warning first; only Show in main UI in the top right is exempt and can be clicked at any time (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Sub-libraries and categories tab.

Common operations

Hide a sub-library from the left column

  1. Select that sub-library on the left;
  2. Clear Show in main UI;
  3. Click Apply / OK → the left column no longer shows it (its assets still appear under All assets).

To restore it, tick it again. The node tree is hidden by default; tick it when you need it.

Sync categories from the library's real folders

  1. Select and load the asset library in the main window first;
  2. Return to settings → this page → click Read current category folders;
  3. Confirm the prompt (it overwrites the default category list in settings and touches nothing on disk);
  4. The left list and each sub-library's category list refresh from the real structure in the library.

Add a custom sub-library

  1. Right-click the left list → Add sub-library;
  2. An entry such as custom_1 appears; change the display name and fill in default categories as needed;
  3. After saving, the sub-library appears in the left column (provided Show in main UI is ticked).

To delete a custom sub-library: right-click it → Delete sub-library → confirm. The 11 built-in defaults (materials / models / lights / textures / scenes / HDR / animation / images / audio / animation data / node tree) cannot be deleted; hide them by clearing Show in main UI.

Common pitfalls

SymptomExplanation
The left column did not change right after renamingThe column rebuilds after saving; switch a category once or reopen the plug-in
Some category configuration no longer matches after changing a sub-library IDChanging the ID swaps the configuration key, which is an advanced operation; back up config.json and try on a copy library first
Half the categories disappeared after Read current category foldersIt follows the real disk folders; empty directories or categories with no folder will not appear
Show in main UI cannot be clickedThis checkbox is not locked; if even it is gray, the window state is abnormal — reopen the settings window
The project library's categories changed tooThis page edits the default category list in settings and never changes any library directly; existing library folders are unaffected

警告

On this page both Read current category folders and changing a sub-library ID rewrite configuration. The first only affects configuration; the second can make existing configuration stop matching. When unsure, back up <plugin dir>\Assets\preset\config.json first.
