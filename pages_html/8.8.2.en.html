A skill bundle is a manual written for the AI: one directory and one SKILL.md per skill, stating when to use it, how to do the work and which pitfalls exist.

Source and destination

The source directory is <plug-in directory>\dsh_plugins\skills, currently 13 bundled skills covering the asset library, asset conversion, Maya help, headless modeling, Bifrost, plug-in internals, script assets and more.

  • Bundled dsh: before launching the web client each time, the plug-in idempotently lands the skills in <dshHome>\skills and writes user-level rules to <dshHome>\AGENTS.md; the user does nothing.
  • External tools: the same source lands in the other tool's skill root; outside dsh both the directory name and the frontmatter name carry a squirrel- prefix so they cannot clash with the user's existing skills.

Why standing rules are also needed

Skills load on demand and a model may act without reading them; the managed section of AGENTS.md is injected every session and enforces baselines such as "consult the help first, change the scene afterwards". Landing only touches its own section and keeps whatever the user wrote.

Self-checks while landing

Hosts usually ignore problems in skill files silently, so landing fixes fence lines, checks that name matches the directory name, verifies there is no UTF-8 BOM and that another tool's same-named directory is not overwritten.

Updating and uninstalling

Reinstalling first confirms the overwrite list; uninstalling uses the ledger to delete only our skills and leaves other skills in the same directory alone.
