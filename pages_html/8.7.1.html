Maya 文档知识库没有独立窗口，入口在 AI 助手的 maya_docs 工具或命令面的 maya_doc_search：先用一句话找到名字，再按名字看详情。

图只用来指路：文档知识库没有独立窗口，菜单里也没有「文档」入口 —— 先点「AI 助手」，再在对话里让它查命令 / 节点 / API。检索结果是在对话里返回的，不在这个菜单里。

前置条件

本机有自建知识库，或在线兜底可用；语义检索还需要 Ollama 与文档索引，但词法检索不需要。

操作步骤

  1. 在 AI 助手里直接问，例如「polyReduce 怎么用」「怎么让物体沿曲线排列」。
  2. 助手会调用 maya_docs(action="search", query="...", mode="auto")。可限定 type 为 command、node、api、devguide 或 doc，limit 最多 20。
  3. 看结果里的名称、类型、插件、说明与 match 字段，挑出精确名字。
  4. 拿名字再查详情：命令看 maya_docs(action="help") 取本机实时参数，节点与 API 看 maya_docs(action="show")。

结果验证

返回 status=ok 且有 count 与结果列表；match 标明来自词法、语义还是两者。若结果 source 以 online: 开头，说明走的是在线兜底。

提示与警告

  • 命令参数以本机实时帮助为准，知识库只是快照。
  • mode="keyword" 最快且完全离线；口语化问题用默认 auto。
  • 已装插件的命令基本不在离线库里，先查插件清单再用实时帮助。
