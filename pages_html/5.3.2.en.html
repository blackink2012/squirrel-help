Assets with variants, versions or LODs use the 「导入变体 / 版本」 (Import variant / version) submenu to import only the chosen piece of geometry.

Prerequisites

  • The asset has variants (the variants section of variants.json is not empty), embedded versions (such as V1, V2) or several LODs on its main version.
  • The asset has been right-clicked in the grid.

Menu titles

Asset contentsMenu title
Variants plus separate versions「导入变体 / 版本」 (Import variant / version)
Variants only「导入变体」 (Import variant)
Only versions / LODs「导入版本 / LOD」 (Import version / LOD)

The main version is always first, followed by the versions and variants; each entry has a small thumbnail on the left, and hovering shows a large preview beside the menu.

Steps

  1. Right-click the asset and expand the matching 「导入…」 (Import…) submenu.
  2. Choose the target: the main version, an embedded version or a variant entry.
  3. Choose the LOD: 「本体几何体」 (own geometry) is that variant's / version's LOD0, and further levels are listed as LOD1, LOD2…; with no LODs the root geometry files are listed directly.
  4. When one level has several formats, expand the format submenu; entries are the format name or "format · file name".
  5. If that entry also carries .zmetal or .mcm, they are listed alongside the geometry formats and choosing them runs a material import instead.

Verify the result

  • Only the geometry of the chosen variant / version / LOD is added to the scene.
  • The Script Editor shows [VariantImport] 导入变体几何体: <file> (<format>) and the import success log.
  • Texture and material for a variant come from the asset root and need no extra selection.

Tips

  • Variant geometry is stored flat under variants/ (<id>.<ext>, <id>_lodN.<ext>), and the older sub-directory layout variants/<id>/ is still read for compatibility.
  • The default LOD is set by default_lod in lods.json; LOD0 always points at the geometry in the root and is not placed in a lod0/ sub-directory.
  • To use a version's own materials as well, see "Per-version materials"; variants never carry their own materials.
