「转换导入」 (Convert import) imports a material asset and immediately converts it to a chosen material type, so one asset fits different renderers.

Prerequisites

  • The material asset is a .zasset with an importable material format (zmetal preferred).
  • The target material type has a usable conversion path in the mapping table.

Steps

  1. Right-click the material asset and expand 「转换导入」 (Convert import).
  2. The submenu lists only target types that have a conversion path and labels the renderer (for example VRayMtl（VR）).
  3. Click the target type; the plug-in imports the material network first, then converts each material and replaces the source ones in place.
  4. When it finishes the converted material is selected.

Verify the result

  • The material node type in the Hypershade equals the chosen target type.
  • The original texture connections have migrated to the new material and the viewport look is broadly preserved.
  • The Script Editor reports the number converted and the target type.

Tips

  • Automatic conversion only recognizes Arnold, V-Ray and Redshift; native Maya materials are not converted.
  • Right-clicking 「导入」 (Import) also triggers conversion: zmetal without a confirmation, and other formats ask once per batch whether to convert to the current renderer's default material.
  • Default materials per renderer: Arnold → aiStandardSurface, Redshift → RedshiftStandardMaterial, V-Ray → VRayMtl.
  • With no mapping path the original material is kept and the log says 「无 … 映射路径」 (no mapping path for …); that is not a failure.
