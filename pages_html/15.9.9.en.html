One-line summary: three lists: which extensions count as geometry, which as images, and which nodes count as material nodes.

This page is locked by default: tick Unlock all settings and accept the warning first (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Other configuration tab → select the list to edit on the left.

What the three lists are

1. Geometry extensions

  • Effect: extensions recognized as geometry files on import (such as .ma, .fbx, .obj).
  • Default: .ma .mb .fbx .obj .abc .usd .usda .usdc .glb .gltf .dae .ass .proxy .vrmesh .vdb
  • What changing it does: it only applies to the collect a whole folder into the library path — root-level files are split into node.{ext} (geometry) by this list; collecting a single file infers the sub-library from the built-in table and is unaffected.
  • Trap: without .fbx, FBX files are not recognized as geometry when collecting a whole folder.

2. Image / texture extensions

  • Effect: extensions recognized as image / texture files on import (such as .png, .exr, .hdr).
  • Default: .png .jpg .jpeg .exr .hdr .tga .tiff .tif .bmp .psd
  • What changing it does: again it only applies to collecting a whole folder (matching files go into textures/); texture scanning and single-file collection use the built-in table and are unaffected.
  • Trap: without .exr, EXR textures in a PBR set do not come in with the rest.

3. Material node types

  • Effect: used on export / update asset to decide which scene nodes count as material nodes.
  • Default: aiStandardSurface, standardSurface, lambert, blinn, phong, openPBRSurface, pxrSurface, aiHair, aiSkin, aiVolume, VRayMtl, RedshiftMaterial
  • What changing it does: asset export, right-click Update asset and batch export all read this list; it is their only source.
  • Trap: missing your renderer's material (for example only Redshift installed but RedshiftStandardMaterial not listed) makes export report no material node, producing an empty asset or a "material only" error (see 4.3.5.1); adding too much (such as transform) makes non-material nodes count as materials.

General editing rules

  • One value per line; extensions need the dot, and Maya node names keep their original case;
  • Empty lines are ignored;
  • You must click Apply or OK to write config.json;
  • The three lists are independent, and switching items on the left automatically saves the previous item's edits.

警告

Material node types directly affect whether export can detect materials. Before changing them, test an export on a small library and only use it on the real library once it works.
