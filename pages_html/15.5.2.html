一句话定位：在资产网格里右键一张材质资产卡片时，弹出的就是这个菜单。 材质是唯一同时有「赋给物体」「写参数」「跨渲染器转换」三个入口的子库。

怎么打开

  1. 左侧「分类」页签 → 点「材质」或它下面的任一分类（金属 / 石材 / 皮肤…）；
  2. 中间资产网格里右键任意材质卡片（也可以先单击选中再右键）。

在「全部资产」「项目」「收藏」页签里右键材质卡片，弹出的是同一张菜单。

菜单从上到下的顺序

段条目
① 子库专属导入 ▶（zmetal / ma）、添加引用、为当前选择指定材质、应用材质参数、转换导入 ▶
② 收藏与选择添加到收藏夹 ▶、全选、复制、打开文件夹
③ 整理移动到 ▶、复制到 ▶
④ 维护编辑、更新缩略图 ▶、更新资产 ▶、删除 ▶
⑤ 查看与 AI预览节点 ▶、AI 分析缩略图
⑥ 最后一条资产详情

菜单逐项详解

菜单项作用前提点了之后注意
导入 ▶把材质导入当前 Maya 场景Maya 已连接；资产里有 zmetal / ma子菜单列可用格式，点一种直接导入；导入后场景里选中新建的材质节点当前渲染器与材质不同源时，会再弹窗问要不要转成当前渲染器
添加引用以 Maya Reference 方式引入材质所在文件资产里含 .ma / .mb 等可引用格式（材质的 ma 满足）场景里多一个引用节点，材质以引用形式存在引用的是资产包里的文件；资产包被移动或删除后引用会断
为当前选择指定材质把该材质赋给场景里选中的物体场景里已经选中物体（网格 / 组）选中物体整体换上该材质，原来的材质被顶掉会覆盖物体原有材质；不满意按一次 Ctrl+Z 撤销
应用材质参数把资产里的参数值写到场景中已有的材质节点上（不是赋材质）场景里选中了材质节点同类型直接写值、不同类型按映射表转换后写；写完自动选中被改的材质跨类型映射可能丢参数，见 4.2.5.4
转换导入 ▶导入的同时把材质转成指定材质类型资产是 .zasset（否则弹警告）；映射表里有到目标类型的路径先导入，再按目标类型转换；完成后选中转换后的材质只改场景里的材质，不会改资产本身
添加到收藏夹 ▶把资产加入某个收藏夹资产库已加载子菜单列「默认收藏夹」+ 你自建的收藏夹；点一下加入，再点一下移出已收藏的夹是实心金星
全选选中网格里当前可见的全部卡片资产区里有卡片全部卡片高亮只选筛选/搜索结果里的，不是整库
复制把资产放进剪贴板无内部剪贴板记录该资产；同时把资产文件夹写进系统剪贴板想真正复制一份，要在目标分类空白处右键「粘贴」
打开文件夹打开资产在磁盘上的位置资产是 .zasset 目录系统文件管理器定位到该资产文件夹只打开文件夹，不动内容
移动到 ▶把资产移到别的分类资产库已加载级联到目标分类后，资产从当前分类消失、出现在目标分类跨子库也可移动，见 8.5.15
复制到 ▶把资产复制一份到别的分类资产库已加载目标分类里多出同一资产（原分类保留）复制的是资产包副本，占双份磁盘空间
编辑改资产的中文名、分类、标签、注释无弹「编辑资产」对话框，保存后卡片与属性面板同步更新见 8.5.16
更新缩略图 ▶换掉或新增缩略图无（「后台渲染」需本机有 mayapy）子菜单 7 项：截取 / 导入 / Maya拍屏 / 渲染图 / 添加 / 截取添加 / 后台渲染截取类会先弹截图覆盖层；拍屏与渲染图会先问帧模式
更新资产 ▶把资产内容换成 / 扩成新的「替换资产」等需要场景里有选中物体子菜单：替换资产 / 追加格式 / 追加为 LOD / 创建新版本 / 添加新变体… / 批量添加变体… / 变体管理…每一项都会写磁盘，做前先看清目标资产
删除 ▶删掉这个资产无子菜单两项：移到回收站 / 彻底删除「彻底删除」不可还原，见 8.5.16
预览节点 ▶看材质内部的节点连接资产里有 .zmetal 或具名 .ma 节点文件子菜单列出节点文件（样本资产：aiStandardSurface1.ma、aiStandardSurface1.zmetal），点一项开节点编辑器预览窗口只读预览，不会把节点导入场景
AI 分析缩略图让 AI 读缩略图给建议AI 依赖已装好（本机 Ollama + 模型）打开 AI 分析窗口，给出建议分类 / 标签 / 中文名 / 注释，确认后写回资产见 8.5.17
资产详情单独看这个资产的详情无有版本或变体的资产打开版本浏览器，其余打开资产观察窗口与双击右侧预览图是同一条链路

子菜单：导入 ▶（zmetal / ma）

材质资产通常同时带两份内容，所以「导入」是一个子菜单而不是单条：

子项说明
zmetal用资产自带的材质网络文件重建节点网络（材质资产的首选）
ma用 Maya ASCII 场景文件导入（常用于需要保留完整节点 / 层级的情况）

只有一种可用格式时，菜单里就直接显示成一行「导入 ma」或「导入 zmetal」，没有子菜单。

子菜单：转换导入 ▶（18 种目标类型）

这一行是材质独有的：导入后立刻把材质转成另一种类型，省掉「先导入再开转换工具」两步。子菜单由映射表动态生成，样本资产上出现的是这 18 种：

读法：括号里的 AI / RS / VR 是渲染器族标注，Maya 原生材质不标注。列表长短取决于「源材质类型 → 目标类型」在映射表里有没有路（可直连，也可经一次中转），所以换一个源材质，这 18 条会变短或变长。

这个子库特有的注意点

  • 「赋材质」和「写参数」是两件事：「为当前选择指定材质」动的是物体上的材质槽（换材质）；「应用材质参数」动的是场景里已存在的材质节点（换数值）。前者用于铺材质，后者用于把一个库里的材质调好参数后刷到场景里已有的材质上。
  • 转换导入只影响场景：它不会回写资产库。要让库里也多出一种格式，用「更新资产 → 追加格式」。
  • 转换导入要求资产是 .zasset：散文件资产点它会弹警告，这是设计如此，不是坏了。
