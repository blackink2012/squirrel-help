一句话定位：后面每一页都会用到这几个符号与状态，先在这里一次认全，翻其它页时就不用再解释。

灰色的项 = 现在不能用

菜单项、按钮变灰（点不动）不是坏了，而是当前状态不满足它的前提。常见原因：

现象原因怎么办
「创建资产」「从外部导入」灰掉当前停在「全部资产」或回收站页，没有明确的落点分类先在左侧分类树里选一个具体分类；退出回收站
「创建资产」直接不见了当前在「图片」或「音乐」分类 —— 这类资产是文件本身，没有「从场景创建」这一说换到材质 / 模型 / 灯光等分类
右键菜单里少了几项当前资产的子库不支持，或设置里把该项隐藏了换对应子库的页面查；右键菜单可在 8.9.5 里增删
整块菜单只有一条灰字功能还没就绪（例如 AI 工具菜单的「初始化中...」）等界面加载完再点

一个通用判据：灰掉的项鼠标悬停通常能看到它要什么前提；点了没反应，先怀疑前提不满足，而不是插件坏了。

勾选（✓）= 当前正在生效

  • 视图菜单里「图标 / 列表」只能选一个；菜单项本身不标勾，当前视图看工具条按钮上的文字。
  • 排序菜单里「名称 / 类型 / 分类 / 时间」是当前排序依据（看工具条按钮文字）；方向看按钮上的蓝色箭头，菜单里的「升序 / 降序」不带勾。
  • 「面板与布局」菜单里的锁定项：打勾 = 布局已锁定，此时菜单项文字会变成「解锁布局」。
  • Maya 目标菜单里勾落在当前选中的那台 Maya 实例行上；默认「自动选择（优先最新版本）」时，插件自动挑中的实例会带勾。

▶ = 还有下一级

带 ▶ 的项不是立刻执行，而是再弹出一层子菜单。本词典里这类项都会在页面中单独开一节，把下一级的每一项也列成表格。例如「面板与布局 → 新建面板 ▶」。

名字后面带「…」= 点了会弹窗

点了会弹出对话框或窗口，需要你再填内容、选路径、点确定。不带「…」的通常是立即生效（例如切视图、切排序）。

分隔线 = 按动作类型分组

同一个菜单里用横线隔开，通常的分组逻辑是：常用动作 → 危险动作 → 视图 / 布局设置。分隔线本身不能点，只是提示「上下不是一类东西」。

顶部带虚线的菜单可以「撕下来」

「AI 工具」「快捷工具」「面板与布局」这几个下拉菜单顶部有一条虚线：按住虚线往下拖，菜单会变成独立浮窗，可以一直摆在屏幕上反复点。关掉浮窗不影响主窗口，菜单内容与下拉时完全一样。

键盘与鼠标的固定用法

操作效果
单击选中对象 / 选中分类（资产卡片点一下是选中，点两下才执行默认动作）
双击资产卡片执行「双击命令」（默认行为可在设置 → 右键菜单里改，见 8.9.5）
右键弹出这个对象的菜单（资产卡片、分类节点、空白处各不相同）
Ctrl / Shift + 单击多选（分类可多选后一起筛选；资产可多选后批量操作）
Ctrl + 滚轮在图标视图里缩放资产卡片（与工具条的缩略图滑块是一回事）
回车在搜索框里执行搜索
点输入框右侧 ✕取消当前搜索 / 清除筛选，恢复当前分类的全部资产

哪些操作能反悔（重要）

操作能不能反悔怎么做
删除资产（「移到回收站」）能左栏「回收站」→ 右键条目「还原」，见 8.8.3
「彻底删除」不能直接删文件，不会进回收站
删除分类能（有限）分类及其下资产一并进回收站，可从回收站还原，见 8.3.4.3
「移动到」/「复制到」能，但要手动移回「移动」只是换分类；移错了再移动回原分类即可，没有自动撤销
「更新资产」「覆盖变体」部分能旧版本 / 旧格式是否保留取决于你在对话框里的选择；选「替换」就是真覆盖
「重置布局」不能自动撤会销毁并重建界面区域，需要重新拖一次布局，见 8.2.5
关闭插件窗口随时能再开Maya 内只关插件窗口，Maya 与场景不受影响
「停止 AI 底座服务」能下次用 AI 功能会自动再拉起，正在进行的 AI 任务会中断

几个名词先对齐

名词在本章里的意思
子库左侧树里的材质 / 模型 / 灯光 / 贴图等大类，决定了资产怎么用
分类 / 子分类子库下面你自己建的文件夹层级，点它只做筛选，不改变资产本身
易读名分类 / 资产显示给人看的中文名（可以留空，留空就显示文件夹名）
LOD同一个资产的不同精度版本（远看用低模、近看用高模）
资产库 / 项目库主资产库是全局复用的库；项目库跟着当前 Maya 工程走，见 4.1.1.3
Maya 目标插件要驱动哪一台 Maya（多开时靠它认人），见 8.2.4
