HDR 连接由创建环境光自动完成，不同渲染器接到穹顶灯的方式不同，但都使用 Raw 色彩空间。

前置条件

  • 已有一盏穹顶灯，或准备用 HDR 资产创建穹顶灯。
  • HDR 文件存在且路径可访问。

操作步骤

  1. 在资产库中右键 HDR 资产，选择「创建环境光」；或在「创建资产」里用「创建灯光」选一张 IBL。
  2. 工具按当前渲染器建立连接：
    • Arnold：file 节点，outColor → 穹顶灯 color。
    • V-Ray：file + VRayPlaceEnvTex，useDomeTex=1，file 输出 → 穹顶灯 domeTex。
    • Redshift：直接把 HDR 路径写进穹顶灯 tex0 字符串属性。
  3. 需要确认时打开属性编辑器，查看穹顶灯的贴图属性或连接。
  4. 旋转环境时用穹顶灯或其环境工具的旋转参数，不要改 HDR 文件名。

结果验证

穹顶灯的贴图属性有连接或路径；渲染时背景和反射出现 HDR 内容；Arnold/V-Ray 的 file 节点 colorSpace 为 Raw。

提示

  • HDR 是线性数据，必须用 Raw；设成 sRGB 会让环境变暗、颜色失真。
  • Redshift 的 tex0 只存路径，不会生成 file 节点，这是正常现象。
  • 重新导入 .zlight 时，贴图路径会按资产内 textures/ 重新解析。

警告

HDR 文件不存在时工具只打印日志，灯仍会创建但没有环境贴图；移动或删除了 HDR 文件后需要重新连接。
