Key points:

  • The difference between Capture / Add and Capture and add is overwrite versus append: items with "add" go into a new slot and keep the previous main thumbnail.
  • Background render is the only one independent of the current viewport: it renders in another process, so you can keep working in Maya; with a multi-selection it processes all selected assets.
  • Playblast and render ask the frame mode first: animation assets should use "timeline range", stills "current frame".

The format conversion dialog

Clicking Format conversion opens a small window:

Area / controlDescription
Top textShows "will run on N assets" plus the asset names
CheckboxesMaya ASCII .ma / Maya Binary .mb / FBX .fbx / Wavefront OBJ .obj / USD .usd / Alembic .abc
Bottom textConversion happens entirely in a temporary directory outside the library and is verified before being written into the package; existing formats are not deleted
ButtonsCancel / Start conversion
  • It can only append formats; "convert and delete the original" is not possible;
  • Conversion is headless, so do not close Maya (plug-in edition) or quit the program (standalone edition) during it;
  • With several assets selected it converts in one batch and writes back into each package.

Risk warnings for this part of the menu

  • "Delete permanently" under Delete ▶ is the only irreversible operation in the whole menu, with no recycle bin safety net.
  • Updating an asset overwrites content: replace asset means "overwrite the old content with the current scene", and the old content is recoverable only if it exists in some version.
  • Format conversion only adds: assets grow, never shrink.
