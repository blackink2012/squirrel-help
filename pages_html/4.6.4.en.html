The category decides where an asset sits in the left category tree; the sub-library (asset type) decides whether it belongs to materials, models, textures or another container.

Changing the category

  1. Select the asset in the grid and choose 「编辑」 (Edit) from the context menu.
  2. Choose the target category in the 「分类」 (Category) dropdown of the edit dialog. The dropdown covers the whole category tree, so pick a category in the same sub-library; moving across sub-libraries is described below.
  3. Click 「保存」 (Save). The plug-in moves the asset's .zasset directory and writes the metadata back.
  4. The category tree and grid refresh and the asset appears in its new category.

Batch changing the category

  1. Multi-select assets within the same sub-library.
  2. Click 「批量移动」 (Batch move) in the batch operation bar.
  3. Choose the target category in the list and confirm.
  4. When it finishes the grid reloads and the counts of the old and new categories change together.

About sub-libraries

  • 「资产类型」 (Asset type) in the properties panel is a read-only display showing which sub-library the asset belongs to.
  • The current interface offers no direct way to switch sub-libraries; moving across sub-libraries can be done with the sub_library parameter of the edit command (that entry is not exposed in the UI; whether it will be added is to be confirmed).
  • A cross-sub-library move really moves the .zasset files and can be combined with a target category.

Verify the result

  • The target category's asset count grows and the original one shrinks.
  • The asset no longer appears in the original category.
  • The 「分类」 (Category) field shows the new display name; after a cross-sub-library move 「资产类型」 (Asset type) shows the new sub-library.
警告

Do not move, copy or rename .zasset folders in Explorer, or the plug-in index will lose track of the assets.

提示

To view assets differently for a moment you do not need to move categories; use search or tag filtering instead.
