Conversion first looks for a direct .mmap from the source type to the target type; without one it converts in two steps through an intermediate type such as openPBRSurface.

Prerequisites

  • The scene already contains materials to convert, or objects using them are selected.
  • The mapping directory has at least one direct or intermediate .mmap.

Steps

  1. Open 「材质转换工具」 (Material conversion tool).
  2. Fill in the source and target material types under 「材质类型映射配置」 (Material type mapping configuration); 「加载源」 (Load source) and 「加载目标」 (Load target) read the types from the current selection.
  3. Click 「浏览...」 (Browse...) and pick the mapping folder (the plug-in's built-in material mapping directory by default).
  4. Select the materials or objects in Maya and click 「转换选择」 (Convert selection); use 「转换全部」 (Convert all) for the whole scene.
  5. Without a direct mapping the tool goes A → openPBRSurface → B automatically and deletes the intermediate materials when it finishes.

Verify the result

The target type's new material appears in the Hypershade; a dialog shows the number of converted materials, succeeded / failed attributes and a failure list. Use 「在Maya中选中失败材质」 (Select failed materials in Maya) to locate failures.

Tips

  • Try 「转换选择」 (Convert selection) on one or two materials before running 「转换全部」 (Convert all).
  • Intermediate materials from multi-hop conversions are cleaned up automatically, leaving only the target type.
  • To cover several source types at once, add several rows to the configuration table, one source / target pair per row.

Warnings

Conversion creates new materials and replaces the source ones according to the options, so save the scene first; when there is neither a direct mapping nor a usable intermediate, that material counts as a failure.
