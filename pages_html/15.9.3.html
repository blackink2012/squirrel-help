一句话定位：跟 AI 有关的开关都在这页：装依赖、更新 / 重建索引、配大模型、逐家同意云端服务、决定对话面开在哪（含 dsh 版本轨）、以及允不允许外部工具连本机 Maya。

这一页不受全局锁定影响，打开就能改。

怎么打开

设置窗口 → 点左侧导航的「AI 设置」（见 8.9.1）。

2. 向量索引维护

控件类型作用默认值改了会怎样需要先解锁
更新向量按钮增量同步当前资产库的向量索引：只重新嵌入新增 / 变更的资产，图像 / 媒体索引只刷新已存在的—（动作按钮）不删任何文件、不需要二次确认；与后台自动更新走同一条命令。打开进度框可看实时日志，可取消（已嵌好的行保留，下次继续）；完成后状态行显示结果否
重建全部向量索引按钮把当前后端的帮助、文档、当前资产库（文本 / 图像 / 音频 / 视频）向量索引全部删掉重新嵌入—（动作按钮）先二次确认；这是全量重建，不是增量同步，耗时随库大小增长；重建期间 AI 检索会暂时退回词法（关键词）检索否
索引状态只读文字显示「正在更新… / 正在重建…」与最后的结果（成功，或失败项数）空更新与重建共用这一行状态否
提示

日常入库后想让新资产马上能搜到，点「更新向量」即可；只有换嵌入模型 / 换后端、或怀疑索引损坏时才需要「重建全部向量索引」。

警告

重建索引期间 AI 语义搜索会暂时失效（退回关键词），资产多时可能要等较久。不要边重建边做大批量入库，否则刚建的索引又落后了。

3. 全局大模型（默认）

这里的配置是全局默认：AI 缩略图分析等需要大模型的功能默认用它；AI 搜索里勾「使用全局大模型」时也用它。

控件类型作用默认值改了会怎样需要先解锁
AI 服务商下拉选模型服务商Ollama（本地）切换服务商会联动 API Key、API 地址与模型列表；Key 按服务商分别保存，不会串用否
API Key密码输入框云端服务商的密钥空（本地服务无需填写，框会置灰）只有云端服务商需要；各服务商的 Key 分开存否
API 地址输入框接口地址，可填自建 / 中转代理http://localhost:11434/v1（Ollama 默认；留空时用服务商默认地址）换成自定义地址后，模型列表会按新地址重新拉取否
AI 模型可输入的下拉框选模型，或直接打字输入模型名已保存的模型名；没有时显示「正在获取模型列表…」打开时会后台实时拉取该服务商的模型列表；拉不到可以手动输入；名字不属于当前服务商时下方会给提示否
开启思考模式复选框控制模型是否先输出推理过程再回答不勾选（关闭）开启后复杂推理更准，但打标签 / 分类 / 一句话描述会更慢，max_tokens 不够时正文还会为空；部分服务商无法真正关闭（见 4.8.4.2）否

4. 云端服务同意（单独同意 · 可撤回）

控件类型作用默认值改了会怎样需要先解锁
服务商行（DeepSeek / 通义千问 / 智谱 / Kimi / OpenAI / Anthropic Claude / 自定义）只读状态文字每个云端服务商占一行，显示「未同意（不会发送数据）」，同意后变为已同意全部未同意—否
查看并同意按钮逐项单独同意某一家云端服务商—弹窗列明接收方、数据类别、传输目的、保存期限与出境风险；同意记录存本机，可随时撤回，撤回后立刻停止向该服务商发送数据否

本地服务（Ollama / LM Studio）不出本机，不需要同意。完整说明见 4.8.4.7。

5. AI 对话面

控件类型作用默认值改了会怎样需要先解锁
在 Maya 内嵌 AI 对话面（取消则用系统浏览器打开）复选框决定点「AI 助手」时对话面开在哪勾选（内嵌停靠在 Maya 里）取消勾选 → 改用系统浏览器；两种方式起的是同一个 dsh，会话与工具一致。下一次点「AI 助手」生效，不用重启否
版本轨下拉：稳定轨（验证过的版本）/ 尝鲜轨（npm 最新版）决定下一次「一键安装」装哪一版 dsh稳定轨尝鲜轨在安装时查询 npm 上的最新版、装下来并钉住（未经验证）；切轨不会自动升级已装的运行时，要重装才生效否
版本下拉：验证过的几个版本（默认项带「（推荐）」后缀）稳定轨下具体装哪一版当前推荐版（如 0.2.2-rc.3）只在稳定轨可选；切到尝鲜轨这一项会自动置灰。同样只影响下一次一键安装否

对话面的开关与召回见 8.8.2；版本轨与版本切换的完整说明见 4.8.4.3。

6. 外部连接

控件类型作用默认值改了会怎样需要先解锁
允许外部工具连接 Maya（独立版 / 命令行）复选框Maya 启动时监听本机回环端口，供独立版 / 命令行获取场景信息、导入导出资产不勾选（默认关闭）端口按版本分配（2026→7001、2025→7002…），同版本多开时后启动的自动退到备用段 7110~7129。保存后立即尝试生效，失败会提示「设置已保存，下次启动 Maya 时会按配置重试」否
警告

这个端口只监听本机回环地址，但等价于任意代码执行入口（能连上就能让 Maya 执行代码）。不需要外部工具驱动时，取消勾选更稳妥。

7. AI / MCP 通道（默认关闭）

这一组是权限开关：决定外部进程能不能驱动本软件，默认全关。逐项说明见 4.8.4.6。

控件类型作用默认值需要先解锁
打开资产管理器时自动连接 AI 底座复选框开窗时自动起 broker 并注册本机，外部 AI 才能驱动不勾选否
Maya 启动时就把本机注册到 AI 底座复选框不开窗口也注册，外部 AI 随时可驱动不勾选否
本地文档没有时，在线查询 Maya 官方帮助复选框允许 AI 在本地知识库没命中时联网查 Autodesk 官方帮助不勾选否
允许 AI 在 Maya 中执行任意 Python / MEL（高危）复选框maya_run_python / maya_run_mel 可用：即调用即执行、无审批不勾选否；首次开启要过风险确认弹窗
允许 AI 删除 / 覆盖替换资产（破坏性操作）复选框AI 才能经资产接口删除（软删进回收站）或覆盖导出（旧版进历史）不勾选否
警告

万能执行通道的权限等于当前系统用户，且可绕过软删与库路径约束。只在受信任环境临时开启，用完关回去。

8. 外部 AI 工具

控件类型作用默认值改了会怎样需要先解锁
外部 AI 工具…按钮打开面板，把本插件的技能与 MCP 通道接给 Claude Code / Codex / Gemini CLI 等—（动作按钮）面板里的操作直接写入对方目录 / 配置，与本次设置的「确定 / 取消」无关（点取消不会回滚）；详见 8.13.5否

常见疑问

现象怎么办
AI 搜索没反应 / 提示语义未生效先点「AI 依赖检查」看缺什么，再点「一键安装 AI 功能与依赖」（见 4.8.4.1）
换了服务商后模型列表为空检查 API Key 与地址；有些服务商需要填 Key 才能列模型；也可以直接在「AI 模型」里手输模型名
装完 AI 依赖仍搜不准需要重建向量索引；索引不会自动追平大批量入库
刚入库的资产搜不到 / 索引落后点「更新向量」做增量同步（见 4.5.6.4）；只有换嵌入模型 / 换后端或索引损坏才需要重建
切了版本轨 / 版本，AI 助手没变正常：这两项只影响下一次「一键安装」，不会自动升级已装运行时；真要换版本，改完再点一次「一键安装 AI 功能与依赖」（见 4.8.4.3）
独立版连不上 Maya检查「允许外部工具连接 Maya」是否勾选，端口是否被占用（见 4.8.4.4）
