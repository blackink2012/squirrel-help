「导入HDR」 (Import HDR) packages .hdr and .exr files into separate HDR assets inside the current category; it never creates a dome light automatically.

Prerequisites

  • The left column is switched to the HDR sub-library and a target category is selected. 「导入HDR」 (Import HDR) only appears in 「从外部导入」 (Import from Files) of the HDR sub-library, where the menu has just 「导入 .zasset 资产」 (Import a .zasset asset) and 「导入HDR」 (Import HDR).
  • On 「全部资产」 (All assets) the whole 「从外部导入」 (Import from Files) menu is disabled and only the grey line 「当前分类不支持从外部导入」 (this category does not support importing from files) is shown.
  • The HDR files are readable on disk.

Steps

  1. Switch the category tree on the left to the HDR sub-library and select the target category.
  2. Click 「从外部导入」 (Import from Files) in the toolbar above the asset area.
  3. Choose 「导入HDR」 (Import HDR).
  4. Select one or more .hdr and .exr files in the file dialog.
  5. On confirm each file becomes its own .zasset with the HDR stored in its textures/.
  6. The plug-in generates a thumbnail from the HDR content.

Verify the result

  • The matching number of HDR assets appears in the grid with visible thumbnails; when thumbnail generation fails the asset is still added.
  • textures/ in the asset directory contains the original HDR file.
  • It reports 「成功导入 N 个HDR资产」 (imported N HDR assets), matching the number of files chosen.

Tips

  • This only adds to the library. To build an environment light in the scene, right-click the HDR asset and choose 「创建环境光」 (Create environment light), or drag the HDR straight into the viewport.
  • To change the texture of an existing dome light, select the dome light and then right-click the HDR asset and choose 「指定贴图」 (Assign texture).
  • Not finding 「导入HDR」 (Import HDR) in other sub-libraries is normal: the entry belongs only to the HDR sub-library, which keeps environment images from being filed into material or model categories by mistake.
