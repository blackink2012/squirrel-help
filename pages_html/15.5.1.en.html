One-line summary: right-clicking an asset card in the asset area opens this menu; it is the main entry to plug-in features, and every sub-library's menu differs. This page first gives a "who has what" table, then links to per-item details per sub-library.

How to open it

  1. On the left Category tab (or the Project / Favorites tab), click into any category;
  2. In the center asset area, right-click any asset card.

Icon view and list view share the same menu: right-clicking a row in list view opens exactly the same contents.

The image shows the materials menu. Other sub-libraries add or remove items on it — the top segment (import / reference / apply / convert) differs per sub-library, while the common segments below are broadly the same.

The menu has 6 segments

What "Conditional" means: Preview node ▶ appears only when the asset package holds a .zmetal or a named .ma node file. The generic node.ma produced by model / scene export does not count — which is why the sample model and scene menus may not show it. That is not a broken feature.

What "—" means:

  • Images and audio have no update thumbnail / update asset — their thumbnails and content are updated through import items;
  • Textures, HDR and images do not use a generic "Import" row but their own specific entries (import textures / import hdr / import as file node);
  • In textures and HDR the item after import is "open image", not "preview node";
  • Animation data's Update asset is a reduced version: only replace asset, create new version, add new variant…, variant management… — no append format / append as LOD / batch add variants.

When items are hidden by settings

Every item in the context menu can be toggled per sub-library in Settings → Context menu (see 8.9.5). If someone else's screenshot has an item you do not see, check that page first.

The menu gets shorter when several assets are selected

Right-clicking after a multi-selection keeps only batch-capable items (import, favorite, move, delete and so on), applied to all selected assets at once. The batch entries are in 8.5.21.
