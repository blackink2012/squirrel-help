Categories decide where a script sits in the left column, while favorites and recently run are two cross-category shortcuts.

Purpose

Once scripts multiply, use categories to organize them, favorites to pin the ones used often and recently run to return to what you just used.

The three entries

EntryContentsSource
CategoriesThe script asset category directories; first-level sub-directories of extra script roots also count as categoriesThe category table in script_assets/scripts.json plus disk directories
★ FavoritesScripts favorited by hand, with the count in parenthesesThe favorites path list in plug-in settings
🕘 Recently runScripts run recently, newest first, at most 15Recorded automatically after each run
UnregisteredScripts whose file exists but whose metadata is missing from the registryScan results

Steps

  1. Right-click a script in the right column and choose 「★ 收藏」 (Favorite) or 「取消收藏」 (Remove favorite).
  2. Click 「★ 收藏」 (Favorites) or 「🕘 最近运行」 (Recently run) in the left column to see those lists.
  3. Right-click a category node on the left for 「新建分类…」 (New category…), 「新建脚本…」 (New script…), 「重命名分类…」 (Rename category…), 「删除分类（含内容）…」 (Delete category with contents…) and 「打开该分类文件夹」 (Open that category folder).
  4. Drag a script from the right column onto a category on the left to move it and update its category.

Verify the result

  • The counts in parentheses for favorites and recently run change with your actions.
  • After a move, the paths in favorites and recently run update instead of disappearing.
  • After a drag the script appears in the target category and no longer in the original one.

Notes

  • Dropping onto the virtual nodes 「全部」 (All), 「★ 收藏」 (Favorites), 「🕘 最近运行」 (Recently run) and 「未登记」 (Unregistered) is refused and the status bar explains why.
  • Dragging across script roots, or onto a category that already has a same-named script, does not move anything.
  • 「删除分类（含内容）…」 (Delete category with contents…) permanently deletes the scripts inside the directory, and the confirmation defaults to 「否」 (No).
  • Recently run keeps at most 15 entries; older ones drop out.
