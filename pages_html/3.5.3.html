每个帮助页底部都有「此页是否有帮助」，用于记录本页质量；要向作者反馈插件问题，走主窗口的「设置 → 关于 → 反馈与建议 → 发送反馈」。

页内反馈

  1. 打开任意帮助页，滚到底部。
  2. 点「有帮助」或「没帮助」。
  3. 按钮旁会显示「已记录，谢谢反馈。」；再次进入该页会显示你上次的选择。

反馈结果保存在当前浏览器的本地存储中（键名 squirrel.help.feedback），不会上传到服务器，也不会自动创建工单。

遇到问题时

  1. 先在本帮助顶部搜索症状，例如「导入失败」「空壳」「崩溃」。
  2. 到「疑难解答」章节按「症状 → 原因 → 解决步骤」排查；日志位置见 6.8.1。
  3. 需要向作者反馈时，打开主窗口「设置 → 关于」页，在「反馈与建议」组里点「发送反馈」，在反馈窗口里填写信息（也可附上截图与日志）。
  4. 准备以下信息会更方便定位：
    • Maya 版本与插件版本；
    • 复现步骤、预期结果与实际结果；
    • 相关截图或录屏；
    • 脚本编辑器输出与日志文件。

结果验证

  • 点页内反馈后出现「已记录，谢谢反馈。」。
  • 刷新页面后再次打开该页，能看到上次的反馈状态。

提示

  • 页内反馈只代表「这页写得好不好」，不能替代缺陷报告；缺陷走「设置 → 关于 → 发送反馈」。
  • 反馈缺陷时不要只写「不能用」，附上可复现步骤与日志，定位会快很多。
