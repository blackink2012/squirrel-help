导入时先按扩展名判定导入器，再由对应导入器把文件变成 Maya 场景里的节点。

类别扩展名导入行为
几何体ma、mb、fbx、obj、usd、usda、usdc、abc、glb、gltf、dae交给 Maya 的 file 导入；abc、usd 先复制到工程缓存再导入；ma/mb 额外重写贴图路径、重定向关联依赖
渲染代理ass、rs、vrmesh、vrscene、proxyass 创建 Arnold StandIn；rs 创建 RedshiftProxyMesh；vrmesh 创建 V-Ray 代理；vrscene 创建 VRayScene；proxy 按普通文件导入
体积vdb按普通文件导入，实际显示取决于已安装的渲染器插件
贴图png、jpg、jpeg、tga、tiff、tif、bmp、psd新建 file 节点并连接 place2dTexture，按扩展名给 sRGB
HDRhdr、exr新建 file 节点并设为 Raw；从库里导入 HDR 还可走「创建环境光」
材质zmetal按节点网络重建着色网络，贴图按导入策略落盘
灯光zlight按当前渲染器创建灯光，HDR、IES、贴图等依赖按导入策略落盘
图片（散文件）png、jpg、jpeg、tga、tif、bmp、exr 等不走几何导入器：右键图片资产 →「导入为 file 节点」建 file + place2dTexture；「创建 imagePlane」做视图参考图；「指定到选中材质槽」接到选中材质的颜色槽
音频（散文件）wav、aiff（mp3 / flac / m4a / ogg / aac 会先转出 WAV 副本）右键音频资产 → 导入到时间轴 / 导入到时间编辑器 / 导入到 Trax 编辑器 / 导入摄像机序列器；Maya 只认 wav、aiff
动画数据.atom（打包在 .zasset 里）右键 →「导入动画」（自动映射）或「导入动画（层级映射）…」或「导入到选择属性」；只写关键帧，场景里要先有目标层级
节点树.zasset 内的 .ma 节点网络右键 →「导入 ma」；导入后按前后节点差集选中新建节点（场景里可能看不到几何，去 Hypershade / 节点编辑器看）
材质映射mcm先导入材质，再按顶点、面、边拓扑匹配赋给选中物体

上表前几类（几何 / 材质 / 灯光 / 贴图 / HDR）走「资产右键菜单 → 导入」里的格式列表；最后四类（图片 / 音频 / 动画数据 / 节点树）是散文件或特殊内容，入口是各子库的专属菜单项，不在格式列表里，详见 4.2.1.2 与「菜单详解」8.5.9 ~ 8.5.12。

hdr 与 exr 在统一导入入口中优先按 HDR 处理，不当作普通贴图；需要普通贴图行为时，请走贴图资产的「导入贴图」子菜单。

贴图格式不会出现在右键「导入」的格式列表里，由「导入贴图」子菜单单独处理；sicon、aicon 也不可导入。

可用格式优先读取 meta.json 的 formats 或 exported_formats；字段缺失时扫描 .zasset 内文件推断。推断时会跳过 textures/ 下的普通贴图，只保留 HDR。
