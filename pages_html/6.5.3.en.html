An interrupted export falls into two kinds: a long job that makes Maya temporarily unresponsive, and a real failure or a manual cancel; the handling differs.

Symptoms

  • The batch progress stops at one asset and the Maya interface does not respond.
  • You clicked 「取消批量导出」 (Cancel batch export) or 「跳过当前」 (Skip current).
  • A failure list appears at the end and some assets were not created.
  • With timeline plus render the wait is long and looks like a hang.

Common causes

CauseHow to tellFix
Rendering or playblasting right nowThe progress window is still there and Maya is merely unresponsiveWait for it to finish; do not click repeatedly
Timeline plus renderMany frames, slow renderUse a playblast to confirm framing first, or shorten the playback range
The user cancelledThe progress window says 「正在取消」 (cancelling)Finished assets are kept and later ones are not exported
One asset failedThe failure list names the asset and the errorFix the cause and click 「重试」 (Retry) to rerun only the failures
Not enough disk space or permissionsThe log reports write failures or access deniedFree space or switch to a writable category directory
A format plug-in became unavailable during the exportThe asset lacks that format's fileLoad the plug-in and export that asset again

Steps

  1. First check whether Maya is only rendering: if the progress window is alive and CPU/GPU are busy, keep waiting.
  2. When you really want to stop, use 「跳过当前」 (Skip current) or 「取消批量导出」 (Cancel batch export) in the progress window; cancelling stops later assets from exporting.
  3. After the batch ends read the result dialog: note the success count plus the failed asset names and reasons.
  4. Fix the failure cause (plug-in, selection, permissions, disk) and click 「重试」 (Retry) to rerun only the failures.
  5. Finished assets are never rolled back by a cancel; asset updates go through a temporary directory, so a failure never overwrites the original asset.

If it still fails

  • Open the Script Editor and search for [AssetExport], [Export] and [Perf] to see which stage it stopped at.
  • Check that the category directory is writable and the disk has space; a disconnected network drive also shows up as a write failure.
  • Select the failed asset alone and re-export with only one format checked to narrow the problem down.
  • If Maya is completely unresponsive for a long time, follow the crash recovery workflow; already exported assets are unaffected.
