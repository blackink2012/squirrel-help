One-line summary: the top of the properties area is a single row — "Properties" on the left, a row of small icon buttons on the right, and the area function button at the far right.

This row doubles as the area's grip (dragging blank space moves the area), which is why the buttons are so small.

Button overview

ButtonIconWhen it appearsWhat it does
FavoriteHollow gray star / filled gold starAn asset is selected and it is not a read-only recycle bin entryToggles the favorite state immediately (no save needed): hollow = not favorited, filled gold = favorited; the card and favorite sets refresh
EditPencilAlways shown (also with no asset selected, where clicking does nothing)Enters property edit mode; equivalent to right-clicking a field → Edit
SaveCheck mark (green)Only in edit modeWrites edit-mode changes back to asset metadata and returns to display mode
Cancel×Only in edit modeDiscards unsaved changes and returns to display mode (fully restored)
Area function buttonMain icon plus a small attached down arrow, tooltip "Properties"Always shownOpens the area menu: dock back to main window / various splits / tear off / tear off a copy / maximize / restore / merge into / close this area

Area function button menu

This button does not belong to the properties panel itself; it is the entry shared by every area, and only the tooltip shows the current area name ("Properties" here). Its items include:

Menu itemEffectDetails
Dock back to main windowReturns a torn-off floating window to the main window3.2.1
Split right / down / left / upSplits this area to create an extra empty area3.2.2
Tear off / tear off a copyTurns the properties area into an independent floating window (a copy opens another one)3.2.1
Maximize / restoreTemporarily fills the window with this area / restores it3.2.3
Merge into…Merges this area into an adjacent one3.2.2
Close this areaCloses this properties areaSee below

How to get the properties panel back after closing it

  • Reopen the Properties area from the Panels menu at the top (see 8.2.5);
  • Or use Reset layout to restore every area to default (see 3.2.5).
