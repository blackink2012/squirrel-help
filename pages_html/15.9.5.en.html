One-line summary: decide per sub-library which items the asset context menu shows and which command runs when a card is double-clicked.

This page is locked by default: tick Unlock all settings and accept the warning first (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Context menu tab.

Pick a sub-library on the left (materials / models / lights / textures / scenes / HDR / animation / node tree / images / audio / animation data); the right side splits into two blocks: context menu items checkboxes on top and double-click command radios with a sub-option below.

Why category-specific items gray out

  • Items that do not apply to the current sub-library are gray and cannot be ticked, with a note such as "(materials/textures only)" after the name and a tooltip on hover;
  • Graying does not clear the previous value: switch back to an applicable category and your configuration is still there;
  • Categories not registered in the configuration (custom sub-libraries, self-created top-level categories) use the fallback section default, so the page is never blank.

When changes take effect

  • After saving (Apply / OK) the asset context menu and double-click behavior are rebuilt from the new configuration immediately;
  • Only what the menu looks like and what double-click does change; existing assets are untouched;
  • Turning off Delete removes the recycle bin entry from the context menu — to delete assets again you must tick it back.

Undo and risks

SituationHow to undo
Not saved yetClick Cancel
Already savedClick Restore defaults → it re-reads context_menu_preset.json / double_click_preset.json (the values in the files; see 8.9.1)
Want a true factory stateOverwrite with backups of those two JSON files (<plugin dir>\Assets\preset\)
警告

Turning off key items such as Delete and Update asset makes those operations vanish from the context menu entirely (not grayed); while you are unfamiliar with the configuration, do not switch off many items at once.
