Every context menu item can be switched per sub-library; it only appears in the asset card's context menu when checked.

Effect

The right side of Settings → 右键菜单 (Context menu) is a set of checkboxes, each mapping to one menu item. Checked means shown, unchecked means hidden. The sub-library list on the left decides which configuration is being edited.

Values and defaults

  • Values: checked / unchecked, written as true / false.
  • Defaults come from Assets/preset/context_menu_preset.json: each sub-library checks only the items it actually has, while unrelated items are false.
  • Unregistered sub-libraries or custom categories read the default section of the same file.

By scope the items fall into two kinds (the table follows the actual checkboxes on the settings page, 27 in total):

KindMenu items
Shared by all categoriesImport, import geometry, add reference, favorites, select all, copy, open folder, move to, copy to, edit, create asset, update thumbnail, update asset, delete, preview nodes, AI thumbnail analysis, asset details
Category specificBackground render (models / scenes / dynamics / materials / textures / lights / node trees), format conversion (models / node trees / scenes / dynamics / audio only), assign material to the current selection (materials / textures), apply material parameters (materials), create material (textures only), convert import (materials / lights), import texture (textures only), assign texture to material (textures / HDR only), apply light parameters to the selected light (lights only), create environment light (HDR only)

Notes:

  • The generic 「导入」 (Import) of the 「贴图」 (Textures) sub-library is greyed out with a hint to use 「导入贴图」 (Import texture) instead.
  • 「后台渲染」 (Background render) is the headless offscreen thumbnail generation (the old "generate thumbnail"); it sits at the bottom of the 「更新缩略图」 (Update thumbnail) submenu and is on by default only for models / scenes / dynamics / materials / textures / lights / node trees.
  • The first group of import items for images, audio and animation data is generated statically and is not controlled by this page: images have import as file node / create imagePlane / assign to selected material slot, audio has import to timeline / Time Editor / Trax Editor / camera sequencer, and animation data has automatic mapping import / import animation / import to selected attributes. What this page can switch for them are the generic items above (favorites, select all, copy, open folder, move / copy to, edit, delete, AI analysis, asset details and so on).
  • In the factory preset images, audio and animation data have the generic 「导入」 (Import) turned off (their dedicated imports replace it), while node trees use the same set as models.

Scope

  • It only affects the asset card's context menu and never double-click behavior (see "Choosing a command per sub-library").
  • Changes require unlocking first and then 「应用」 (Apply) or 「确定」 (OK) to write the JSON; the next context menu is built with the new configuration.

When to change it

When the menu is too long, dangerous items are often clicked by mistake (delete, format conversion), or a sub-library never uses a feature.

Related settings

The lower half of the same tab holds double-click commands, and both share the sub-library list on the left.
