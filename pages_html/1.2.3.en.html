How to choose

  • Work only inside Maya: check 「Maya 集成」 (Maya integration) when installing the EXE and skip the extra process and port.
  • Often organize assets without opening Maya: install the EXE and start the main program directly; browsing and search are always available.
  • Both: one installation is enough. With 「Maya 集成」 (Maya integration) checked you get both the in-Maya entry point and the standalone program; they share the same asset library, settings and license.
  • Team sharing: put the library on a shared drive; keep the semantic index in a local directory per person so several writers do not overwrite each other.
