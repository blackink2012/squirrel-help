变体是同一资产下共用一套贴图与材质的多个几何形态：贴图和材质只存一份放在资产根，变体目录里只有几何体。它解决的是「一套依赖、多种造型」的体积重复问题。

与版本、LOD 的区别

维度存什么材质与贴图典型用途
版本（V1/、V2/）完整自包含的一份资产每份独立，可各不相同改破损、改 UV、改造型的可回溯迭代
LOD（lod1/、lod2/）同一形态的不同精度跟随所属版本高模展示、低模摆放
变体（variants/）只有几何体统一继承资产根，所有变体共享同一套材质的砖头 / 螺丝钉 / 瓦片等多种款式

三者可以同时存在，互不影响。

存储结构

Brick.zasset/
├── meta.json
├── variants.json          # variants 段登记每个变体的 id / label / 几何 / LOD / 缩略图
├── node.ma                # 主版本几何体
├── textures/              # 全部变体共享的贴图
├── materials/             # 全部变体共享的材质
└── variants/              # 平铺，不再分二级目录
    ├── 标准砖.ma
    ├── 标准砖.sicon       # 该变体的缩略图
    ├── 破损砖.ma
    ├── 破损砖.sicon
    └── 破损砖_lod1.ma     # 变体的 LOD 档位：<id>_lodN.<ext>
  • 变体几何体按 <id>.<ext> 平铺在 variants/ 下，不再为每个变体建子目录。
  • 变体不出现在资产网格里，只挂在所属资产下，通过右键菜单、变体管理窗口或版本浏览器查看；含变体的资产卡片左上角会有 V 角标。
  • 变体缩略图独立保存（variants/<id>.sicon 等），不覆盖资产主缩略图。

什么时候用变体

需求用哪个维度
同样的材质，模型造型换一换（砖头缺角、螺丝钉头型）变体
模型整体改版，需要保留旧结果版本
同一模型要高低模LOD
同一模型不同版本各用各的贴图版本（含独立材质）
注意

变体按「共享贴图」设计：变体只保存几何体，不携带自己的贴图或材质。确实需要独立材质时，请改用版本。
