Type a name, tag or ID fragment into the top search box and the grid filters matching assets within the current category immediately.

Prerequisites

  • An asset library is open and a sub-library or category is selected in the left tree; the search only covers that scope.
  • 「AI 搜索」 (AI search) is unchecked. When it is checked, typing does not filter live and you must press Enter to run a semantic search.

Steps

  1. Select the sub-library or category to search in the left tree.
  2. Type a keyword in the top search box. About 150 ms after you stop typing the grid refreshes, no Enter needed.
  3. Separate several keywords with spaces, for example metal arnold; any matching fragment counts.
  4. Click the ✕ on the right of the search box to clear the keyword and restore every asset of the current category.

What is matched

Matched againstNotes
Asset IDFull ID or a prefix; no arbitrary substring matching
Display name and nameCase-insensitive
TagsA hit when any tag contains the keyword
Material type, asset type, sub-libraryIncludes sub-library display names (such as 「材质」 (Materials))
CategoryIncludes category display names
Export format, software, renderer, color spaceA hit when the field value contains the keyword

Verify the result

  • The status bar shows the visible count and the total.
  • The grid keeps only matching assets and is empty when nothing matches.
  • Clicking ✕ returns to the complete list of the current category.
提示

Keyword search combines with tag filtering: when both are active an asset must satisfy both.

警告

With 「AI 搜索」 (AI search) checked, typing a non-empty keyword does not trigger the ordinary filter; press Enter or uncheck it first.
