One-line summary: right-clicking an animation data card in the asset grid opens this menu. Animation data stores ATOM keyframes, and every import item answers the same question: which nodes / attributes in the scene should receive these keyframes.

How to open it

  1. Left Category tab → click Animation data or any category under it;
  2. In the center asset grid, right-click any animation data card.

The animation data menu has no import geometry, format conversion or preview node — the asset holds only .atom keyframes, with neither geometry nor a node network.

Submenu: what the four paste modes mean

Import animation ▶ and Import to selected attributes ▶ each have 4 sub-items using Maya ATOM's native paste semantics:

Sub-itemEffect
ReplaceOverwrites only existing curves on attributes with the same name on the target and leaves others alone
Replace allClears existing animation on the target nodes first, then imports the whole segment (cleanest, and easiest to lose things with)
InsertInserts at the insertion point and shifts later keyframes back
MergeMerges with existing curves on the target by time (on shared frames the imported value wins)

When unsure, use Replace: it only touches attributes it can match, so the impact is smallest.

Start position: asked every time

Except for Import animation (hierarchy mapping)…, the other three entries first ask for an "animation start position":

OptionMeaning
Timeline current frame (default)Aligns the animation's first frame to the current timeline frame
Original animation start frameUses the originally recorded first frame and does not shift it to the current frame

A wrong choice does not require starting over: undo with Ctrl+Z after importing and import again.

Notes specific to this sub-library

  • Automatic does not mean universal: automatic mapping matches by node name / hierarchy; when nodes do not match, use Import animation (hierarchy mapping)… and assign manually.
  • Animation data is not an object in the scene: it only writes keyframes and creates neither skeletons nor objects. Have the target hierarchy first, then import.
  • Update asset is the reduced version: no append format / append as LOD / batch add variants, because ATOM has only one kind of content.
