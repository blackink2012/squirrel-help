The status bar at the bottom of the window shows counts and the current action; when minimized, the window collapses into a floating bubble on the desktop, and a single click opens the asset library again (the pure standalone edition keeps its taskbar button).

Status bar

The status bar is pinned to the bottom of the window; the asset count (材料: 可见数/总数, materials: visible / total) is on the left and the information area on the right changes with what you do, for example:

  • When an asset is selected it shows the asset name.
  • During AI search it shows 「正在思考」 (Thinking) or a description of the results.
  • During image / audio-video search it shows the matching result, for example 「图片搜索：按关键词「…」找到 N 个资产」 (Image search: N assets found for the keyword "..."), 「音视频搜索：命中 N 个资产」 (Audio-video search: N assets matched) or 「文字搜音乐：命中 N 个音频」 (Text search for music: N audio files matched); cancelling shows 「已取消以图搜图 / 音视频搜索，恢复当前分类的全部资产」 (Image / audio-video search cancelled; restoring all assets of the current category).
  • While recording audio or the screen it shows the recording duration and the limit; when finished the recording becomes a search.
  • During 「后台渲染」 (Background render), the headless thumbnail render, it shows render progress.
  • Messages such as repairing UUIDs or an image search with no results also appear here.

Floating bubble

With the floating bubble enabled, minimizing the main window collapses it into a draggable squirrel icon:

  1. A single click restores the main window, which is the "quick open" of the asset library.
  2. Hold and drag the bubble anywhere on screen; its position is remembered.
  3. While the AI assistant is running the bubble shows the running state (a glow).
  4. Right-clicking the bubble opens a menu that differs by form: both include 「打开资产库」 (Open asset library) and 「打开AI助手」 (Open AI assistant); the in-Maya version adds 「关闭窗口」 (Close window), which closes only the plug-in window, and the standalone edition adds 「退出」 (Exit), which ends the whole process. In the standalone edition, choosing Exit while the AI assistant is running asks for confirmation first.

Verify the result

  • Minimizing the window shows the squirrel bubble; clicking it restores the main window with the layout it had before minimizing.
  • After selecting an asset the status bar shows that asset's name.

Tips

  • The in-Maya version and an attached standalone edition have no taskbar button, so restore the window by clicking the floating bubble; the pure standalone edition can still be restored from the system taskbar.
  • A restored window brings back the previous layout, side-column widths and maximized state from the last save (see 3.2.5).
