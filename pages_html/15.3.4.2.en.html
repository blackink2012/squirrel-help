One-line summary: right-clicking a sub-library root such as Materials, Models or Lights opens a category management menu — add a sub-category, open the folder on disk, move it, change its display name, expand or collapse.

How to open it

  1. Left navigation → Category tab;
  2. Find the sub-library root in the tree (second level, with a colored icon, such as Materials, Models, Lights);
  3. Right-click that node.

Submenus

This menu has no second level (all 6 items run directly or open a dialog; nothing has ▶).

Why there is no "Delete category"

The 11 sub-libraries Materials / Models / Lights / Textures / Scenes / HDR / Animation / Images / Audio / Animation data / Node tree are built-in defaults that the plug-in relies on to decide how assets are used, so deletion is not offered. What you will see:

  • Right-clicking one of these 11 built-in roots → the menu has only the 6 items above, no Delete category.
  • Right-clicking a top-level category you created at the library root → Delete category appears (see 8.3.4.3).
  • Even if you reach the deletion logic another way, built-in sub-libraries are refused with "built-in default sub-libraries cannot be deleted; hide them with Show in main UI".
  • To keep one out of the left column: Settings → Sub-libraries and categories → clear Show in main UI (assets and disk folders remain).

Beginner pitfalls

  • Wanting to add categories such as "metal" or "wood" but right-clicking All assets: that creates a top-level category. To add under materials, right-click Materials → Add sub-category.
  • The target you want is missing from "Move to...": the dropdown only lists top-level categories and root; moving directly under a deep sub-category is not supported.
  • The folder name cannot be edited under Edit: by design — the folder name is the category id and changing it would break the index; only the readable name and type can change.
  • Assets placed by hand via "Open folder" do not appear: refresh only re-reads registered assets; use import or category sync, see 4.1.3.5.
