Scripts can be run directly, run with parameters, imported as a module, or loaded into the Maya Script Editor.

Purpose

Use the same script for different purposes: run it directly to see the effect, run it with parameters to pass values, or load it into the editor for further editing.

Running

  1. Select the script and double-click, press Enter or click 「▶ 运行」 (Run).
  2. Scripts registered as high risk ask for confirmation first, with 「否」 (No) as the default; you can suppress the prompt for this session.
  3. Python scripts are syntax-compiled first, so syntax errors are never executed; MEL runs through mel.eval.
  4. For parameters, right-click and choose 「带参数运行…」 (Run with parameters…) and fill a JSON object that is preset as PARAMS for the script (Python only).
  5. A script may put its result into RESULT, whose summary the window prints in the Script Editor.

Importing and loading

  • 「导入（加载为模块）」 (Import, load as a module) only supports Python: it adds the script's directory to sys.path, registers the module under the file's base name in sys.modules and lists the available names. MEL is not a module and is refused.
  • 「加载到脚本编辑器」 (Load into the Script Editor) writes into the Python or MEL tab by extension; when the target tab already has content it asks before overwriting.
  • 「生成执行命令（放工具架）…」 (Generate an execution command for the shelf…) generates a Python / MEL shelf button command.

Verify the result

  • The status bar shows 「已运行 <name>（用时 x.xxs）」 (ran <name>, x.xx s); failures open a copyable error dialog.
  • The script's print output and traceback appear in the Maya Script Editor history.
  • After importing you can use import <module name> in the Script Editor; after loading, the editor tab shows the script source.

Notes

  • Running with parameters does not apply to MEL; MEL has no PARAMS / RESULT convention, so print the important results.
  • The standalone edition dispatches the script to an online Maya; when Maya is offline it reports 「投送 Maya 失败」 (dispatch to Maya failed).
  • Suppressing the prompt for high-risk scripts only lasts for the current session.
