快捷工具没有登记表：把 .py 放进 quicktools/ 即完成界面注册；只有需要命令通道或特殊运行位置时才要额外改一处。

最快路径

  1. 在 <插件根>/quicktools/ 新建 .py 文件。
  2. 提供 main()、run() 或 if __name__ == "__main__": 入口。
  3. 打开「快捷工具」菜单，确认文件名出现并点击运行。

菜单每次展开都会重扫目录，不需要重启 Maya。命令通道不传 name 调 quicktool_run 时，也能在返回清单里看到新文件及其 entry。

需要额外注册的情况

需求要改哪里
希望命令通道提示「优先用某条一等公民命令」squirrel_asset_manager/ai/runtime_commands.py 的 _QUICKTOOL_COVERAGE 映射
希望有专门命令（带参数 schema、dry_run、结构化结果）squirrel_asset_manager/ai/quicktools_commands.py，按现有三条命令的写法注册 CommandDescriptor
纯文件工具，希望独立运行版在本地执行而不是投送 Mayasquirrel_asset_manager/ui/main_window.py 中 _run_quick_tool 的 local_only 集合
希望工具内部有独立帮助页在 Assets/help/<工具名>/ 放 help.html

命令注册后，如果插件已在运行，可调用 refresh_commands 重建执行器并重连；重连瞬间在飞的命令会失败，长任务执行中不要调用。

结果验证

  1. 菜单中出现新条目，且不是「暂无快捷工具」。
  2. 点击后窗口打开或脚本执行，脚本编辑器无 ImportError / SyntaxError。
  3. 命令通道不传 name 时，清单里能看到该文件与 entry；传 name 后返回 status: ok。
  4. 需要本地执行的纯文件工具，在独立运行版中确认没有走 Maya 投送。

注意事项

  • 如果菜单里没有出现，先确认文件在 quicktools/ 根目录、后缀是 .py，且没有放进子目录。
  • 点击后无反应，多为没有可识别入口；菜单会打印「没有可执行的入口」。
  • 新增命令或修改参数 schema 后，记得刷新命令清单，避免外部 AI 仍看到旧 schema。
  • 注册改动属于插件源码修改，建议在测试环境验证后再分发。
