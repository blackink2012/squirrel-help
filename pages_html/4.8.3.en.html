Batch rename uses a prefix, a suffix or find-and-replace to change the display names or file names of several assets at once.

Prerequisites

  • At least two assets are selected and the batch operation bar is visible.
  • The rename target and rule are decided; the operation writes straight into the asset metadata.

Steps

  1. Multi-select assets and click 「批量重命名」 (Batch rename) in the batch operation bar.
  2. Choose the target in the 「重命名」 (Rename) dropdown:
    • Display name (name_cn): changes only the name shown in the interface.
    • File name (name): also renames the .zasset asset directory.
  3. Choose the mode:
    • Add prefix: puts the typed text in front of the old name.
    • Add suffix: puts the typed text after the old name.
    • Find and replace: fill in the search text and the replacement text.
  4. Check every "old name → new name" row in the preview list; unchanged rows are marked 「不变」 (unchanged).
  5. The main button shows the changeable count and the total, for example 「执行重命名 (8/10)」 (Run rename (8/10)); it is disabled when the changeable count is 0.
  6. Click 「执行重命名」 (Run rename); the number of successes is reported and failures are appended to the same message.

Verify the result

  • Grid card names update immediately.
  • The status message reports the number of successes and failures.
  • With 「文件名」 (File name) chosen the asset directory names change too, and the renamed assets are still visible after reopening the library.
注意

Find and replace is a literal, case-sensitive replacement; prefixes and suffixes do not add separators automatically, so type a space or underscore yourself when needed.

警告

Never rename .zasset directories outside the plug-in. Always use this dialog for file-name mode.
