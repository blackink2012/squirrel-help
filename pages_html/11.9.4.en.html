Read current category folders uses the real folder structure of the asset library to overwrite the sub-library and default category lists in settings.

Prerequisites

  • An asset library is loaded. Otherwise the UI reports "Please load an asset library first"; when the asset manager is unavailable it reports "Cannot get the asset manager".

Steps

  1. Open Settings → Sub-libraries and categories.
  2. Click Read current category folders.
  3. Confirm in Sync confirmation. The prompt explains that the default category list will be overwritten, but no folder on disk is deleted or modified; only the configuration is updated.
  4. When syncing finishes, the UI reports "Categories synced from the current asset library".
  5. Click Apply or OK to write the result back to config.json.

Result

  • The left sub-library list is rebuilt from the top-level categories of the current library, including custom top-level categories.
  • All sub-categories under each top-level category (recursively) are collected into that sub-library's default category list, using the readable category name as the display name.
  • Syncing only changes settings data; it does not touch disk folders.

Verify the result

The left list shows the top-level categories of the current library, and the default category list on the right matches the disk structure.

Tips

  • Syncing rebuilds the whole list, so custom sub-library entries that do not exist in the current library disappear from the list and from the configuration after applying.
  • If you cancel before clicking Apply, no change is saved.
  • This action is also subject to Unlock all settings.
