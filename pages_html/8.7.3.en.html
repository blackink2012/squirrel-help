Prerequisites

The exact name has been found by search; note that Maya commands are case-sensitive.

Steps

  1. In the AI assistant say "show me the details of polyReduce", or call maya_docs(action="show", name="polyReduce") directly.
  2. It returns a compact summary by default: the synopsis, long and short flag names with types and related notes. When a long list exceeds the limit it names the remaining items.
  3. To focus on one parameter add flag="percentage" to get that flag's full description.
  4. For the complete body add full=true; guide bodies can run to tens of thousands of characters, so use it sparingly.
  5. For a command's live parameters use maya_docs(action="help", name="polyReduce"), which goes through Maya's cmds.help.

Verify the result

It returns status=ok with the name, type and detail fields; a flag query returns only the target parameter's full description. An unknown name returns nearby candidates to retry with.

Tips and warnings

  • Node types cannot be looked up with cmds.help; use show, because help only knows commands.
  • The online fallback only has page bodies and no flag tables; parameter help requires a local Maya or the local knowledge base.
  • Commands from installed plug-ins follow the live help, and the offline library may not include them.
