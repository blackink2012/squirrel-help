导入完成后，用选中集、Outliner、Hypershade 与脚本编辑器日志四处对照，就能确认资产是否真的进入场景。

前置条件

  • 已完成一次库内资产导入，并知道本次使用的格式。
  • Maya 的 Script Editor 可用（用于查看插件日志）。

操作步骤

  1. 查看当前选择：导入材质格式后会选中新建材质；导入 zlight 后会选中新建灯光；部分几何导入会选中新根节点。
  2. 打开 Outliner，确认出现新的 transform 或 shape。导入统一进根命名空间 :，同名节点由 Maya 自动改名。
  3. 打开 Hypershade（Window > Rendering Editors > Hypershade），确认材质网络与 file 节点存在。
  4. 选中 file 节点，在属性面板查看 fileTextureName，确认贴图指向 sourceimages/、工程缓存或 .zasset/textures/。
  5. 打开 Script Editor，检查 [ImportExecutor]、[FileImporter]、[Import] 开头的日志。

结果验证

  • 日志出现「导入成功」或「已创建 N 个节点」，且没有「导入失败」「未知格式」。
  • 场景中出现预期数量的新节点，材质或灯光能在 Hypershade、Outliner 中找到。
  • 视口中模型、贴图或灯光表现正常；贴图不黑、不丢。

四类资产的验证点

图片、音频、动画数据、节点树 不产生几何体，验证方式与上面的 Outliner / Hypershade 不同：

子库导入后到哪看
图片Hypershade 里出现 file 节点（带 place2dTexture），看 fileTextureName 是否指向库内文件；imagePlane 则在 Outliner 里按 imagePlane 找
音频时间轴出现声音波形（sound 节点）；时间编辑器里多一个 audio clip；Trax 里多一条声音轨；摄像机序列器的 shot 上挂声音
动画数据目标节点的属性被写入关键帧：在 Graph Editor / 时间轴看曲线；导入前场景里要先有对应层级
节点树视图里可能看不到新东西——它不是几何；看 Hypershade / 节点编辑器，或直接看当前选择（导入后会自动选中新建节点）

这四类资产导入后如果「什么都没看到」，先按下表确认是不是正常现象，再按 4.2.7.1 排查。

提示

  • 日志里的「无 … 映射路径，保留原材质/原灯光」不是失败，表示该条目没有跨渲染器转换路径，资产按原类型保留。
  • 只看到「材质已创建（无选中物体，未赋予）」说明材质建出来了，但导入前没有选中物体可赋值。
