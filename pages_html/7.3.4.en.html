The node editor can open a .ma or .zmetal and draw the createNode / connectAttr data or the JSON node network as a readable node graph.

Prerequisites

  • A Maya ASCII .ma or a .zmetal from an asset is available.
  • The file is not a binary .mb.

Steps

  1. In the library right-click the asset, point at 「预览节点」 (Preview nodes) and choose the .zmetal or a .ma other than node.ma.
  2. You can also click 「打开文件」 (Open file) in the editor, or drop a .ma / .zmetal into the window.
  3. Pan with the middle mouse button or Ctrl+left drag, zoom with the wheel; 「层级布局」 (Hierarchical layout) rearranges left to right.
  4. To connect, click the orange output port on the right of a node and then the grey input port on the left of the target node; the direction cannot be reversed.
  5. Select a node or link and press Delete to remove it; Ctrl+Z / Ctrl+Y undo and redo.
  6. Click 「保存文件」 (Save file) to overwrite the original; 「另存为...」 (Save as...) lets you save as .ma or .zmetal.

Verify the result

The node count on the canvas matches the file, and the connections match connectAttr (or source_node / source_attr); after saving and reopening, the changes are still there.

Tips

  • Saving a .ma keeps the original file as the base and only removes the nodes you deleted, preserving geometry, cameras and other data; saving a .zmetal keeps the original JSON as the base and only updates changed nodes and connections.
  • The current version does not support adding new nodes by hand; to add nodes, create them in Maya first, save as .ma and then edit.

Warnings

Saving overwrites the original file. Back up the whole .zasset before editing a .zmetal inside an asset.
