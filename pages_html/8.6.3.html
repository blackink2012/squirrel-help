索引状态可以在不联网的情况下查清：是否可用、用的哪个模型、有多少条、放在哪、是否落后于资产库。

前置条件

已打开资产库；要查文档索引，本机需有知识库或开启在线兜底。

操作步骤

  1. 在 AI 助手里要求查询索引状态，或调用只读命令 asset_semantic_status。
  2. 重点看四组字段：available 与 reason（能不能用、为什么）、model / dim / count（模型与规模）、index_dir / library_id（索引位置与所属库）、index_lag（是否落后）。
  3. 需要更细的环境诊断时，运行 python tools\asset_index.py --status 或 --doctor；图像索引可用 python tools\asset_vision_encode.py status --library "<库根>"。
  4. 文档索引改用 maya_docs(action="status")，其中 semantic.diagnose 会列出缺哪一环与对应命令。

结果验证

available=true 且 index_lag.stale=false 表示索引可用且跟得上库；reason 为空或只说明可选功能未装。

提示与警告

  • 状态查询只读本地文件，不会联网；--doctor 才会探测 Ollama 与模型。
  • index_lag.stale=true 不致命，下一次检索会增量同步；多人共用库时常见。
  • 索引目录里那份索引若属于另一个库，会明确报错，不要手工拷贝索引目录来「修」。
