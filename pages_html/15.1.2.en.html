One-line summary: every page that follows uses these symbols and states, so learn them once here and no other page has to explain them again.

Grayed-out item = not available now

A grayed-out (unclickable) menu item or button is not broken; it means the current state does not meet its prerequisite. Common causes:

SymptomCauseWhat to do
"Create asset" and "Import from outside" are grayYou are on the All assets page or in the recycle bin, so there is no definite target categorySelect a specific category in the left tree first; leave the recycle bin
"Create asset" is missing entirelyYou are in the Images or Audio category — those assets are files themselves, so "create from scene" does not applySwitch to materials / models / lights and similar categories
A few items are missing from the context menuThe current asset's sub-library does not support them, or they are hidden in settingsCheck the page for that sub-library; add or remove items in 8.9.5
The whole menu is one gray lineThe feature is not ready yet (for example "Initializing..." in the AI tools menu)Wait for the interface to finish loading

A general rule: hovering over a grayed item usually shows what it needs; if clicking does nothing, suspect an unmet prerequisite before blaming the plug-in.

Checked (✓) = currently in effect

  • In the view menu, only one of "Icons / List" can apply; the menu does not show a check, so read the toolbar button text for the current view.
  • In the sort menu, "Name / Type / Category / Time" is the current sort key (see the toolbar button text); the direction comes from the blue arrow on the button, and "Ascending / Descending" in the menu carry no check mark.
  • Lock items in the Panels and layout menu: checked = the layout is locked, and the item then reads "Unlock layout".
  • In the Maya target menu the check sits on the currently selected Maya instance row; with the default "Auto select (prefer newest)" the instance the plug-in picked carries the check.

▶ = there is another level

An item with ▶ does not run immediately but opens another submenu. In this dictionary such items get their own section on the page, listing every item of the next level in a table. For example "Panels and layout → New panel ▶".

An ellipsis after the name = clicking opens a dialog

Clicking opens a dialog or window where you fill in content, choose a path and confirm. Items without an ellipsis usually take effect immediately (for example switching the view or the sort).

Separators = groups by type of action

Horizontal lines inside one menu usually group like this: common actions → dangerous actions → view / layout settings. A separator cannot be clicked; it only says "the things above and below are not the same kind".

Menus with a dashed line at the top can be "torn off"

The AI tools, Quick tools and Panels and layout dropdowns have a dashed line at the top: drag down from the dashed line and the menu becomes a floating window you can keep on screen and click repeatedly. Closing the floating window does not affect the main window, and its contents are exactly the same as the dropdown.
