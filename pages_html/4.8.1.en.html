After multi-selecting assets you can move them all into another category within the same sub-library, or copy them into another category.

Prerequisites

  • At least two assets are selected; the batch operation bar appears with a multi-selection.
  • The target category must already exist in the current sub-library. The target list is based on the sub-library of the first selected asset.
  • Batch move and copy do not work across sub-libraries.

Batch move

  1. Multi-select assets in the grid.
  2. Click 「批量移动」 (Batch move) in the batch operation bar.
  3. Choose a category in the 「选择目标分类」 (Choose target category) list and confirm.
  4. The plug-in moves the assets one by one, then rescans and refreshes the grid.

Batch copy

  1. Multi-select assets and click 「批量复制」 (Batch copy) in the batch operation bar.
  2. Choose the target category and confirm.
  3. A copy of each asset is created in the target category; copies are renamed automatically and get new asset IDs.
  4. The originals stay in their original category.

Verify the result

  • The asset count of the target category grows.
  • After a batch move the assets no longer appear in the original category; after a batch copy both categories hold one.
  • The category tree and grid refresh automatically afterwards.
警告

Batch move and copy really move or copy .zasset directories. Confirm the target category before running, and never move them with Explorer.

提示

An empty target list means the current sub-library has no categories yet; create one in the category tree first.
