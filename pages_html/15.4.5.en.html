One-line summary: click Edit tags to open the tag editor and click tags to filter the list down to assets carrying them; it only changes the filter and never touches assets.

How to open it

  1. On the right of the asset area toolbar, find the Edit tags button (left of View and Sort);
  2. Click it → a non-modal "Edit tags" window opens (only one at a time; clicking again brings it forward);
  3. Click tag chips in the window to filter; the filter stays active after you close the window.

Filtering rules

RuleDescription
One tag selectedShows only assets carrying that tag
Several tags selectedUnion: assets carrying any one of them are shown
Combined with keyword searchKeywords and tag filters apply together (intersection)
Combined with a categoryThe scope is first limited to the current category (and sub-categories), then filtered by tag inside it
Visibility of the filterSelected tags are written into the search box as text, so you can see at a glance what is filtering; the ✕ at the right of the search box appears as well
ClearingClick Clear filter, or the ✕ at the right of the search box (both remove keywords and tags together)

Submenus

The Edit tags button itself has no dropdown; clicking opens the window directly. The only context item in the window is Delete (for one tag), which is not a menu level either.

Risks and how to undo

  • Tag filtering is fully reversible: Clear filter or ✕ restores everything and changes no asset.
  • Right-click Delete on a common tag only removes that tag name from the common tag list (written to configuration); it never batch-deletes tags already applied to assets. To undo, add it back manually.
  • Adding a tag likewise only extends the common list; deleting a common tag does not change tags shown on existing assets.

Beginner pitfalls

  • The word I want is not in the tag list: common tags are stored per category type (materials / models…), so confirm the current category; if it is missing, add it manually.
  • Clicking a tag changes nothing: the current category may simply have no assets with that tag; try another category or clear the keyword search first.
  • Assuming multi-selected tags mean "all of them": it is a union (any match), not an intersection.
  • Assuming deleting a common tag removed it from assets: it did not. The assets keep their own tags; this filtering entry just no longer lists it.
  • Trying to filter tags in the recycle bin: Edit tags is gray (disabled) there; tag filtering only works on the asset page.
