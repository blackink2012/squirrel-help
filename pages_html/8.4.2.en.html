AI analysis produces four results: a display name, a suggested sub-category, tags and notes. All of them are suggestions that can be edited or unchecked before applying.

What the four results mean

FieldWhere it is writtenEffect
Display nameThe asset's name_cnShows a friendlier Chinese name in the interface
Suggested sub-categoryThe asset's categoryPicked from the existing sub-categories under that top-level category in the current library
TagsThe asset's tagsKeywords such as material, color and purpose, used by search
NotesThe asset's notesA short description that is also included in keyword search

Tags merge with the asset's existing tags rather than replacing them; category candidates come from the real sub-categories of the current library, not a list the model invented.

Why human confirmation matters

The model only sees the thumbnail and cannot know the asset's real use, scale or project conventions, so treating suggestions as final easily files assets under the wrong category. With 「移动到分析出的分类」 (move to the suggested category) checked by default, applying actually moves the asset to that category directory, which matters more than changing tags.

Scope of application

  • Single asset: check fields one by one in the result window and confirm to write them immediately.
  • Batch: select all or check items one by one in the batch result window and click 「应用选中的资产」 (Apply selected assets).

Recommendation

When the category is uncertain, first uncheck 「移动到分析出的分类」 (move to the suggested category) and apply only the name and tags; move the asset once the category is confirmed.
