When on, Maya listens on a local loopback port at startup so the standalone edition, a command line or the AI backend can connect to the current Maya.

Effect

It gives external tools a channel to read scene information and import or export assets, and is also the fallback connection when the backend is unavailable.

Values and default

  • The checkbox 「允许外部工具连接 Maya（独立版 / 命令行）」 (allow external tools to connect to Maya, standalone / command line) is off by default, so it must be checked for Maya to listen at startup.

Scope

  • When on, Maya listens on a loopback port at startup, assigned by version: 2026 → 7001, 2025 → 7002 and so on.
  • A second instance of the same version uses the backup range 7110–7129.
  • The port only binds 127.0.0.1 and is never opened to the LAN.
  • Clicking 「应用」 (Apply) tries to open or close it immediately without restarting Maya; on failure it reports that the port could not listen, still saves the setting and retries at the next start.

When to change it

  • Turn it off when security requirements are high and no external tool needs to connect.
  • When a firewall or security software blocks the port, confirm an exception first, or disable this item temporarily to isolate the cause.

Verify the result

  • External tools connect to the current Maya and the connection page shows the matching version and port.
  • After disabling and restarting Maya, external tools can no longer connect.

Tips

Warning: this channel is equivalent to an arbitrary-code-execution entry; even though it binds loopback only, do not leave it on long term in untrusted environments.

Tip: with several sessions of the same version the port steps aside automatically; no manual port changes are needed.

Tip: the port-to-instance mapping is described in "Connection method and ports".
