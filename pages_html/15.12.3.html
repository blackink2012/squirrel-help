一句话定位：把场景里的材质导出成「预设文件」的配置窗（窗口标题「导出材质为预设」），供以后导入复用。

当前版本入口说明：这个窗口的界面与逻辑都还在（点击「开始导出」会真的执行导出），但资产右键菜单里没有登记这一项，正常操作路径下点不到它。所以本页按源码写清窗口里有什么、每个控件管什么；现在要把预设存成文件，请走下面的「现在该走哪条路」。

现在该走哪条路

你想做的事当前版本的做法
让「创建资产」默认勾好某些格式改导出默认值：设置 →「导出默认值」页（8.9.4），对应文件 export_preset.json（4.3.4.2）
把场景里的材质导出成可在别处复用的文件用快捷工具「材质导入导出工具」（8.14.7），可导出 JSON / .ma / .zmetal
导出成 zasset 资产里的 .zmetal用「创建资产」并勾「材质预设 .zmetal」（8.10.6）

窗口结构（按源码）

分区一：导出格式与路径

控件类型作用建议取值填错会怎样
导出目录单行输入 +「浏览」按钮预设文件写到哪选一个专门目录，别写进资产库目录不存在会尝试新建；建不了会弹「无法创建目录」
文件名单行输入自定义文件名留空 = 用当前时间命名和已有文件同名会被覆盖（插件不另确认）
导出为 JSON 格式 (默认)复选框导出为 JSON 材质描述一般保持勾选不勾且不勾 .ma → 可能没有可导出产物
同时导出 .ma 格式 (可选)复选框额外导出一份 Maya .ma（材质节点网络）需要在 Maya 里直接引用时勾大材质网络导 .ma 会慢、文件偏大
每个材质导出为独立文件复选框勾选=每个材质一个文件；不勾=合并成一个材质多且要分别挑时勾不勾会全部写在一个文件里
导出材质对应模型数据 (.mcm)复选框附带「材质→模型」映射材质原本挂在模型上、要还原贴回关系时勾不勾只保材质

分区二：元数据设置

控件类型作用建议取值填错会怎样
色彩空间下拉（ACEScg / sRGB / Rec709 / linear）记录预设的色彩空间与项目一致（一般 ACEScg）记录错会导致以后导入时色彩解释错
材质分类下拉（不指定 / 金属 / 铬 / 钢 / …… / 自定义）给预设归类，便于以后筛选按材质实际类型选选错只会影响分类检索，不影响导出本身
中文名单行输入预设的显示名留空 = 用英文原名只影响显示
标签标签芯片区 +「编辑标签」给预设打标签；「编辑标签」可增删常用标签用常用标签标签只在预设元数据里，不会自动进资产库
自定义标签输入 +「添加标签」单行输入 + 按钮手动补标签（逗号分隔）短词同上

分区三：截图预览

控件类型作用建议取值填错会怎样
截图预览画布图片区显示当前截到的预览图；空着时提示「点击截图获取预览图」——
256×256 / 512×512 / 自定义单选 + 两个宽高输入截图分辨率512×512 足够自定义填 0 或非数字可能截出空图
截取当前视图主按钮（导出色）截当前 Maya 视口作为预览先在视口摆好物体与角度没物体/视口为空会提示「请先在视图中选择物体或调整视角」
从文件导入缩略图次按钮用磁盘图片当预览（png/jpg/bmp/tga/tiff）已有渲染图时用选到非图片/损坏文件会失败

分区四：批量导出选项

控件类型作用建议取值填错会怎样
导出选择 / 导出全部单选只导当前选择 / 导场景里全部材质先在视口里选好再用「导出选择」选「导出全部」会连场景里临时材质一起导
批量导出时自动截图复选框（默认勾）批量时为每个材质自动取预览图批量时勾按源码实现，批量截图方式尚未完全落地——勾了也可能只有第一张预览图

底部

按钮作用
取消关窗，不导出
开始导出校验目录 → 执行导出 → 关窗；状态显示在底部左侧一行小字

风险与反悔

操作风险反悔
开始导出目标目录里同名文件会被覆盖导出前先确认目录；重要文件先备份
导出全部场景里临时材质也会进预设只选需要的材质用「导出选择」
截图只是取一张图，不写场景无需反悔

出问题怎么办

现象原因处理
点「开始导出」提示「请选择导出目录」目录输入框空着先点「浏览」选目录
导出后目录里没文件目标环境不是 Maya（独立版/无 maya.cmds），或渲染导出模块加载失败看脚本编辑器 [ExportPreset] 日志
截图失败视口里没有可截内容在视口里选中物体、调好视角再点「截取当前视图」
找不到这个窗口的入口当前版本右键菜单没登记它（见页首说明）走「现在该走哪条路」里的替代入口
