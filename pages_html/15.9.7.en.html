One-line summary: tell the plug-in "when these words appear in a file name, treat it as this PBR channel" — pick a channel on the left and write aliases line by line on the right.

This page is locked by default: tick Unlock all settings and accept the warning first (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Texture suffixes tab.

When these aliases apply

  • When importing a whole PBR texture set (a texture folder, or the quick tool PBR textures to asset), the plug-in decides which file is color, which is normal and so on — from these aliases;
  • Aliases match by file-name keyword (both wood_basecolor.png and wood_diff_4k.jpg are recognized as baseColor);
  • After saving, the next import / texture scan uses the new aliases; assets already in the library are unaffected.

Common questions

SymptomCause / what to do
A texture lands in "unknown channel"The word in the file name is not in any alias; add that word to the matching channel's alias list
A normal map is treated as a height mapBoth images may match a word such as bump; delete the unwanted alias from that channel
I changed aliases but nothing happenedYou did not click Apply / OK, or you edited a different channel (it was not selected on the left)
I want the factory aliases backThe page's Restore defaults only re-reads the file; change them back from the table above by hand, or overwrite with a backed-up pbr_mapping.json (<plugin dir>\Assets\preset\)

警告

Besides aliases, pbr_mapping.json also stores channel mappings, so when editing it in a text editor keep the JSON structure intact and back it up first.
