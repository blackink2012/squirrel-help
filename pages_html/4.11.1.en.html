The dropdown at the top of the main window's 「分类」 (Categories) tab lists every registered asset library; switching reloads that library and refreshes the category tree and asset grid.

Prerequisites

  • At least one asset library is registered (usually true when the plug-in opens by default).
  • The library directory to switch to actually exists on disk.

Steps

  1. Open the 「分类」 (Categories) tab on the left.
  2. Click the asset library dropdown above the category tree; entries read "name — path".
  3. Choose the target library.
  4. Wait for it to load. Loading happens on a background thread, so the window does not freeze.

Verify the result

  • The dropdown and the status bar show the new library, and the category tree and asset grid switch to its contents.
  • The Script Editor prints 「已切换资产库: 路径」 (switched asset library: <path>).
  • On the 「收藏」 (Favorites) tab the collections follow the current library.

Tips

警告

When the library directory is missing the plug-in reports 「资产库路径不存在」 (the asset library path does not exist) and stays on the previous library. Fix or remove that entry in settings first.

  • The load priority when the window opens is: explicitly given path → default library → last used library → order in the library list.
  • "Library" here means the main asset library; 「项目」 (Projects) is a separate tab and the project library is not in this dropdown.
  • Collections and favorites.json are stored per library, so switching never mixes data.
  • On the command side use library_manage op=switch; the switch writes last_library_path, and an open window refreshes its interface as well.
