After an import, check the selection, the Outliner, the Hypershade and the Script Editor log to confirm the asset really entered the scene.

Prerequisites

  • One library import has just finished and the format used is known.
  • Maya's Script Editor is available (to read plug-in logs).

Steps

  1. Check the current selection: after a material import the new material is selected; after a zlight import the new light is selected; some geometry imports select the new root nodes.
  2. Open the Outliner and confirm a new transform or shape exists. Imports go into the root namespace :, and Maya renames same-named nodes automatically.
  3. Open the Hypershade (Window > Rendering Editors > Hypershade) and confirm the material network and file node exist.
  4. Select the file node and check fileTextureName in the properties panel to confirm the texture points at sourceimages/, the project cache or .zasset/textures/.
  5. Open the Script Editor and read the logs starting with [ImportExecutor], [FileImporter] or [Import].

Verify the result

  • The log says 「导入成功」 (import succeeded) or 「已创建 N 个节点」 (created N nodes) and contains no "import failed" or "unknown format".
  • The expected number of new nodes appears in the scene, and materials or lights can be found in the Hypershade and Outliner.
  • Models, textures and lights look right in the viewport; textures are neither black nor missing.

Where to verify the four special asset types

Images, audio, animation data and node trees produce no geometry, so verification differs from the Outliner / Hypershade steps above:

Sub-libraryWhere to look afterwards
ImagesA file node (with place2dTexture) appears in the Hypershade; check that fileTextureName points at a library file. An imagePlane is found in the Outliner by imagePlane
AudioA sound waveform appears on the timeline (sound node); the Time Editor gains an audio clip; Trax gains a sound track; the camera sequencer shot carries the sound
Animation dataThe target node's attributes receive keyframes: look at the curves in the Graph Editor / timeline; the matching hierarchy must exist beforehand
Node treesYou may see nothing new in the viewport — it is not geometry; look in the Hypershade / Node Editor, or simply at the current selection (new nodes are selected after import)

If "nothing appears" for one of these four, first confirm with the table above that this is expected, then troubleshoot as described in 5.7.1.

Tips

  • A log line such as 「无 … 映射路径，保留原材质/原灯光」 (no mapping path for …, keeping the original material / light) is not a failure: it means that item has no cross-renderer conversion path and the asset keeps its original type.
  • Seeing only 「材质已创建（无选中物体，未赋予）」 (material created; no object selected, not assigned) means the material was built but nothing was selected to assign it to.
