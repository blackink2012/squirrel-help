The context menu of an asset card is generated from the sub-library plus the context menu presets in settings. Every sub-library has a different menu: the first few rows are specific to the sub-library, and below them come the shared items. This page gives one table for comparison; what each item actually does is described in the "Menu reference" pages 15.5.2 to 15.5.12.

Two points to keep in mind while reading the table:

  • Textures, images, audio and animation data have no generic "import" / "add reference": their imports are the specific entries of their own kind (import texture / import as file node / import to timeline / import animation), so the menu is not broken.
  • Submenu contents follow the asset's contents: when only one format exists the entry is a single line such as 「导入 ma」 (Import ma); with several formats (for example zmetal + ma for materials, or ma + abc for dynamics) it becomes an 「导入 ▶」 (Import ▶) submenu.

4. Import variant / version titles and items

When the main asset has versions, variants or several LODs, an extra section appears in the 「导入」 (Import) submenu:

Asset contentsMenu title
Variants plus separate versions「导入变体 / 版本」 (Import variant / version)
Variants only (no embedded versions)「导入变体」 (Import variant)
No variants, but several versions or LODs「导入版本 / LOD」 (Import version / LOD)
  • The main version is always listed first, followed by the embedded versions and the variant entries.
  • Each version / variant entry carries a small thumbnail on the left, and hovering shows a large preview next to the menu.
  • A variant with LODs expands one more level: its own geometry plus LOD1, LOD2…; when one level has several formats, a format submenu opens as well.
  • The end of this section offers 「查看版本 / 查看变体 / 查看 LOD 管理」 (View versions / View variants / View LOD management), which switches the asset area to an internal view rather than importing.

5. Update thumbnail submenu

ItemEffect
「截取 / 导入」 (Capture / Import)Take a screenshot or pick a local image and replace the main thumbnail
「Maya 拍屏 / 渲染图」 (Maya playblast / Render)First choose the frame mode (current frame / timeline range), then playblast or render an image that replaces the main thumbnail

「后台渲染」 (Background render) appears only in the 7 sub-libraries materials, models, lights, textures, scenes, dynamics and node trees; HDR and animation data do not have it, and images and audio lack the whole update-thumbnail row. See 4.7.1.

Tips

  • Menu items are controlled by the context menu presets per sub-library in settings; disabled items do not appear. The switches are in Settings → 右键菜单 (Context menu).
  • Right-clicking a card that is already part of a multi-selection keeps the whole selection; right-clicking an unselected card selects only it first. Import, reference, delete, format conversion and background render apply to the whole selection.
  • In icon view, pressing Space opens a cross menu at the mouse: up = import, left = reference, right = apply, down = convert.
  • What each item does, requires and warns about is described in the "Menu reference" pages 15.5.2 to 15.5.12; shared items in 15.5.13 to 15.5.17; internal item context menus in 15.5.18.
