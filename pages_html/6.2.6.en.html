「动画导出」 (Animation export) decides the frame range for every animation format; caches and proxies are two different products and can both be checked.

Frame range

OptionBehaviorBest for
当前帧 (Current frame)Exports only the current frame as a stillStatic assets, single-frame proxies
时间轴 (Timeline)Exports over the Maya playback rangeFull animation
关键帧 (Keyframes)Takes the minimum to maximum keyframe over the selected objects' animation curves; falls back to the current frame when there are no keysExporting only the animated interval

The interface labels the animation section with (abc/usd/ass/rs/vrmesh). Playblast thumbnails capture only the first 240 frames when the range exceeds that; render thumbnails have no such cutoff.

Cache formats

FormatProductNotes
Alembic .abc<name>.abcVertex animation cache written with -uvWrite -writeVisibility and the ogawa data format; the frame range follows the option above

Proxy formats

FormatExtensionRequired plug-inProduct with timeline / keyframes
Arnold.assmtoaOne file per frame in a sequence such as ass/<name>_0001.ass
Redshift.rsredshift4mayaOne file per frame in a sequence such as rs/<name>_0001.rs
V-Ray Scene.vrscenevrayformayaA single file with the frame range passed at export
V-Ray Mesh.vrmeshvrayformayaA single file whose animation is written in one pass through animOn

In still mode each of the four proxies produces one same-named file (<name>.ass, <name>.rs, <name>.vrscene, <name>.vrmesh).

Tips and warnings

Tip: caches and proxies are "re-baked" products and are not the same as "collect linked files", which copies files already on disk; one asset can check both.

Tip: proxy formats only export when the matching plug-in is loaded. The checkbox is greyed out when the plug-in is unavailable; if the plug-in state is not "loaded" at export time the format is skipped silently, so afterwards check that proxy files really appeared inside the .zasset.

Warning: timeline plus render renders frame by frame and Maya becomes unresponsive for a while; proxy sequences create many files, so check free disk space before exporting.
