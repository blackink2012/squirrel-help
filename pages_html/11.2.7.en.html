The thumbnail output size is the default edge length shared by generated and captured thumbnails; it decides sharpness as well as render time and file size.

Effect

It unifies the square edge length used by default for headless renders, AI thumbnail shots, export screenshots and the screenshot tool.

Values and default

  • 256 × 256, 384 × 384, 512 × 512 (default), 768 × 768, 1024 × 1024.
  • When the settings file holds a value off the list, the dropdown shows an extra 「自定义」 (Custom) entry keeping that value.
  • It is clamped to 64–4096 pixels when read.

Scope

  • Generation side: headless offscreen rendering, AI thumbnail shots, playblast and render thumbnails on export, and the thumbnail cap for ingesting external files and PBR imports.
  • Capture side: the initial width × height of the screenshot tool and the long edge of preview-panel quick captures.
  • Quick tools (HDR / model / PBR to .zasset) also follow it.
  • It never decides how large thumbnails appear in the main grid; the toolbar slider does that.
  • It applies from the next generation or capture after 「应用」 (Apply); no restart is needed.

When to change it

  • Raise it for sharper asset covers, at the cost of headless render time and file size.
  • Lower it when batch output needs speed or disk space is tight.
  • 512 balances sharpness and cost, so the default suits most cases.

Tips

Tip: raising it never redoes existing thumbnails; regenerate or recapture them.

Tip: headless rendering and the screenshot tool share this one value, so do not change it in only one dialog.
