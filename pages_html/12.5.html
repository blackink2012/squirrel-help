插件包自包含：把 squirrel_asset_manager/ 一个目录放好即可运行；资产库、用户设置、缓存与日志分别落在包外。

插件包

目录内容
core/数据层：管理器、.zasset 读写、导出编排、材质与分类
ui/主窗口、缩略图网格、预览、设置与各类对话框
integration/Maya 导入/导出执行器、格式路由、贴图与依赖处理
utils/设置、JSON、截图、桥接与异常处理
quicktools/PBR/模型/HDR 转资产、图像格式转换、批量处理等独立工具
ai/Maya 侧命令实现（query / generate / convert / organize / scene 等）
ai_base/宿主无关底座：命令注册表、broker、作业、进度、取消、索引
embedded/独立版挂载与常驻预热
mcp/MCP server 入口
dsh_plugins/技能束 skills/ 与 dsh 侧工具 patch
dsh_home/运行期 dsh 目录：会话、技能、审计与作业记录
knowledge/Maya 文档知识库与发布件
Assets/preset/ 预设、prompt/ 提示词、help/v2/ 帮助、图标、材质映射、IBL 与示例网格
bin/随包的 ffmpeg.exe / ffprobe.exe（动图与序列编码）
tools/索引、帮助构建、许可证与自检脚本

安装后位于 Documents/maya/squirrel_asset_manager/；README 建议装在版本无关的 maya\ 下，一份供所有 Maya 版本使用。

资产库

资产库根/
├── materials/  models/  lights/  textures/  scenes/  hdr/  ani/
├── .squirrel_index_cache.json
└── .squirrel_ai_index/        # 语义检索索引（按后端分家：official/ ollama/；可改到本地其他根）

每个 .zasset 是文件夹资产包，常见内容为 meta.json、node.zmetal、thumb.sicon、thumb.aicon、thumb.mp4、node.mcm、几何/代理文件与 textures/。

包外位置

路径内容
~/.squirrel_asset_manager/app_settings.json、桥接端口/自愈日志、broker 开机日志、Maya 帮助缓存
<包>/dsh_home/dsh 运行期目录；可用 SQUIRREL_DSH_HOME 或 DSH_HOME 改到别处
%TEMP%\squirrel_asset_manager\AI 依赖检查报告与安装日志
{工程}/cache/alembic/squirrel_asset/导入 abc 缓存
{工程}/cache/squirrel_asset/导入代理缓存

帮助源文件在 Assets/help/v2/pages/，toc.json、pages_html/、search/ 与 generated/ 是构建产物，不要手改。
