One-line summary: right-clicking the preview image opens this thumbnail menu — the same implementation as Update thumbnail ▶ in the asset card context menu.

How to open it

  1. Select an asset in the asset grid (the preview shows an image);
  2. Hover the preview image and right-click (it opens on press, no need to wait for release).

Recycle bin entries and virtual entries such as versions / variants do not have this menu.

Item-by-item details

The menu has four groups separated by horizontal lines:

When the whole menu is missing

Whether this menu appears is controlled by the per-sub-library switch in Settings → Context menu (see 8.9.5):

SwitchBehavior when off
Update thumbnailRight-clicking the preview opens nothing, and the submenu is gone from the asset card menu too
Background renderThe menu remains but the last item, background render, is not shown
Sub-library scopeWhen a sub-library does not allow headless rendering, background render is not shown in the first place

Risks and how to undo

  • Capture / import / Maya playblast / render image / background render all overwrite the main image: the old cover is gone with no undo.
  • To undo, do it again (background render or another capture is safest); if you really have no good image, you may recover a backup of the old one from the asset directory.
  • Add / Capture and add create a new slot and leave the main image alone; if you do not want it, switch to that image in the preview and click Delete (deletion is irreversible and again has no confirmation).
提示

Just want a new cover without capturing anything? Import an existing image — it is the fastest. For many assets at once, right-click Background render queues them up (see 4.1.7.1).
