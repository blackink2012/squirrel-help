Drag a region of the screen with the mouse to use as the asset thumbnail; handy for quickly recording a viewport look or an existing reference image.

Two capture entry points

EntryCharacteristics
「截取」 (Capture) button in the preview panelFull-screen marquee and immediate capture, with no toolbar and no recording; the result is saved at the default thumbnail size
Context menu → update thumbnail → captureThe full screenshot tool with toolbar options such as width and height, forced resolution and screen recording

Steps (quick capture from the preview panel)

  1. Select the asset and click 「截取」 (Capture) at the bottom of the right-hand preview panel.
  2. The screen dims; drag a region and release to capture; hold Ctrl while dragging to lock a square.
  3. Press Esc or right-click to cancel.
  4. The screenshot is scaled proportionally by its long edge to the 「默认缩略图大小」 (Default thumbnail size) and written as the asset's main thumbnail.

Steps (full screenshot tool)

  1. Right-click the asset and choose 「更新缩略图 → 截取」 (Update thumbnail → Capture).
  2. Marquee a region on the screenshot overlay; the toolbar lets you adjust width and height and check forced resolution.
  3. Click the capture button to confirm; the result becomes the main thumbnail and is copied to the system clipboard.
  4. For processing several assets in a row the tool stays open; 「截取添加」 (Capture and add) writes into a new extra slot.

Verify the result

  • The grid card and the right-hand preview show the new image immediately.
  • After capturing with the full screenshot tool the same image is on the system clipboard.
  • With 「截取添加」 (Capture and add) the thumbnail counter in the preview panel increases.
注意

The full screenshot tool also offers a screen-recording button; the recording becomes an animated .aicon thumbnail and depends on the bundled ffmpeg.

警告

「截取」 (Capture) replaces the main thumbnail. To keep the old main image, use 「截取添加」 (Capture and add) to write a new slot instead.
