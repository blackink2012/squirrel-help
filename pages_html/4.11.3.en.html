Creating an asset library makes a standard library directory (library.json plus six sub-libraries) and adds it to the library list.

Steps

  1. Open the Settings window and go to the 「资产库管理」 (Asset library management) group on the 「常规」 (General) tab.
  2. Click 「创建资产库」 (Create asset library).
  3. Choose the parent directory for the library.
  4. Type the asset library name; the default is SquirrelLib.
  5. Confirm and wait for the 「创建成功」 (created successfully) message.
  6. Click 「确定」 (OK) in the Settings window to save the list.

Verify the result

  • A folder named after the library appears under the parent directory.
  • It contains library.json plus the six sub-library directories materials, models, lights, textures, scenes and hdr.
  • Each sub-library directory contains a FolderMetadata.fdata.
  • The new library shows up both in the settings list and in the main window's library dropdown.

Tips

警告

Creating is refused when the target directory already exists; choose another name or clean up the same-named directory first.

  • The first time the new library loads it completes the standard structure such as the 「自定义」 (Custom) sub-category and merges in the remaining built-in sub-libraries from the configuration (images, audio, animation data, node trees and so on) — that is why creating a library writes only six base directories, and loading / switching to it completes all 11 built-in sub-libraries.
  • On the command side library_manage op=create accepts path or parent_dir + name; on failure it rolls back the half-built directory and never leaves an empty library behind.
  • It does not switch to the new library automatically; select it in the library dropdown.
