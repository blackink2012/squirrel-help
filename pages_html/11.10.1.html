「设置 → 授权激活」页的「当前授权」卡显示授权状态，用来判断导入、导出、转换是否可用。

作用

状态文字由授权模块实时读取，只读展示，不能在这里修改。它回答两个问题：许可证是否有效、当前处于哪种授权阶段。

可选值与含义

显示文案含义
已授权 / 已授权：客户名有效许可证，功能可用
试用中（剩余 N 天）服务器签发的试用授权有效
订阅已到期（宽限期内）订阅到期但仍在宽限期
授权已到期（只读）许可证过期，只能浏览
未激活（只读）没有有效许可证，只能浏览

状态徽标与入口

控件 / 按钮作用什么时候出现
状态徽标显示「已授权 / 试用中 / 宽限期 / 已到期 / 未激活」始终
同步授权立即向服务器同步一次授权（续费 / 换机后不必等次日心跳）有授权记录时显示；离线授权也可以点（只做只读登记与心跳，不会吊销 / 降级本机授权）
激活码输入框 + 激活常驻机器码下方，填入激活码后点「激活」始终
主按钮随状态变化：未激活「授权管理」、试用中「购买授权」、已授权「授权管理」、已到期「续费授权」始终，同一状态只有一个主按钮
次按钮购买授权 / 授权管理（始终显示，不适用时置灰并提示原因）随状态
账号与我的授权登录 / 注册、设备管理、退出登录账号功能开启时
授权详情与高级操作离线许可证导入（文件 / 剪贴板）、解除本机授权、恢复本机授权始终，默认折叠

「授权管理」打开的是授权窗口，离线导入、解除 / 恢复本机授权与页内「授权详情与高级操作」是同一套能力，两处都可以用。

影响范围

  • 授权保存于本机并绑定当前电脑。
  • 到期或未激活时仍可浏览资产库；导入、导出、转换需要有效授权。
  • 「授权激活」页不参与「解锁全部配置」锁定，激活入口始终可用。

何时查看

  • 导入、导出或转换弹出授权提示时。
  • 更换电脑、重装系统或许可证续期后。
  • 状态不会持续自动刷新；重新打开设置，或完成一次激活后，会重新读取。

结果验证

完成激活后返回本页，状态应变为「已授权」或「试用中」。

提示

状态文案中的「只读」只限制写操作，不影响查看资产与搜索。
