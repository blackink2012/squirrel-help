Batch mapping means configuring several "source → target" rows in one type mapping table so one conversion covers several source materials.

Prerequisites

  • Every "source type → target type" pair has a matching .mmap, or can route through openPBRSurface.
  • The scene is saved.

Steps

  1. Add several rows to the 「材质类型映射配置」 (Material type mapping configuration) table in 「材质转换工具」 (Material conversion tool).
  2. Use the dropdowns on each row to pick the source and target material types; you can also select materials in Maya and click 「加载源」 (Load source) / 「加载目标」 (Load target) to read their types.
  3. With only one row and 「源」 (Source) left empty, every material is converted to that target type.
  4. Click 「浏览...」 (Browse...) and choose the folder containing every needed .mmap.
  5. Select the scope and click 「转换选择」 (Convert selection), or click 「转换全部」 (Convert all) to process the whole scene.
  6. To infer attribute rows automatically, configure an AI service in the mapping tool and click 「一键映射」 (One-click mapping), then fine-tune by hand and save as .mmap.

Verify the result

The converted material count and applied object count in the dialog match the scene, and the failure list is empty or can be located item by item with 「在Maya中选中失败材质」 (Select failed materials in Maya).

Tips

  • 「一键映射」 (One-click mapping) only fills attribute rows; the type mapping table still has to be configured in the conversion tool.
  • A multi-row configuration can be saved as an .mlist preset and restored later with 「加载预设」 (Load preset).
  • Materials of the same type are skipped and never converted twice.

Warnings

Batch conversion creates and replaces many materials in a row, so always save the scene first; when one pair lacks a mapping those materials count as failures while the rest keep converting.
