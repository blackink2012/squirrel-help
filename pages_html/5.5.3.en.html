Right-click a material or texture asset and choose 「为当前选择指定材质」 (Assign material to the current selection); the plug-in builds the material network and assigns it to the selected objects.

Prerequisites

  • One or more objects are selected in Maya.
  • The material asset contains .zmetal, or a .ma/.mb with a material network; a texture asset needs a properties record.

Steps

  1. Select the target objects in the scene.
  2. Right-click the material or texture asset and choose 「为当前选择指定材质」 (Assign material to the current selection).
  3. The plug-in picks a path from the asset's contents:
    • With .zmetal: rebuild the node network and assign the root material to the selection.
    • Without .zmetal but with .ma/.mb: import the material network and assign it to the selection.
    • Texture only: create an openPBRSurface, connect the texture and assign it.
  4. Wait for the assignment to finish.

Verify the result

  • The selected object's shadingGroup points at the new material.
  • The matching material node appears in the Hypershade.
  • The Script Editor reports 「赋予材质 … → N 个物体」 (assigned material … to N objects).

Tips

  • With nothing selected the material is only created, not assigned, and the log says 「材质已创建（无选中物体，未赋予）」 (material created; no object selected, not assigned).
  • When an asset has several root materials only the first usable one is assigned to the whole selection; for per-face assignment use MCM.
  • A texture asset without properties cannot map channels, so the assignment stops.
