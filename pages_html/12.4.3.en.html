pbr_mapping.json handles "texture file name → PBR channel", while material_mapper_presets/*.mmap handles "source material attribute → target material attribute". Both live inside the plug-in package and take effect the next time the tool is opened.

PBR mapping

The file is at Assets/preset/pbr_mapping.json, schema version "1.0", and the default material type is openPBRSurface.

FieldDescription
resolution_subdirs / resolution_patternsRecognize resolution folders and file name suffixes such as 2k, 4k, 8k
texture_type_rulesThe current 16 texture type rules: baseColor, normal, roughness, metallic, ao, arm, orm, emissive, height, opacity, clearcoat, clearcoatRoughness, specular, subsurface, anisotropy, ior
material_property_mappingsAttribute connection tables for 9 materials, including node_attribute, connection_type, requires_conversion, conversion_node

Each texture_type_rules entry can contain: aliases (file name keywords), priority (detection priority), color_space (sRGB / Raw), is_color, invert_if (for example inverting roughness when glossiness is found), is_combo with channels (for example arm/orm mapping R/G/B to ao/roughness/metallic), and is_numeric.

Material mapping .mmap

Assets/material_mapper_presets/ currently holds 58 .mmap files named {source type}_{target type}.mmap. The content is JSON, with these core fields:

FieldMeaning
version / name / softwareFile version, display name, target software
source_type / target_typeSource material and target material node type
mappingsAttribute mappings, one per entry
source_attributeSource attribute; an empty string means "no source", used to reset the target attribute to its default
target_attributeTarget attribute; an empty string skips that entry
transformConversion function id, empty when not needed
default_valueFallback value when the source attribute is missing
parametersConversion function parameters, such as min_val / max_val for clamp

Execution processes entries in order: if the target attribute does not exist, it is recorded as a failure and skipped; color sub-channels (such as diffuseColorR) are skipped unconditionally because colors must be written to the parent attribute; when the source attribute has a texture connection, the connection is copied; when the source value is missing, default_value is used, and if that is also empty the target attribute is reset to its current default.

Common conversion functions include roughness_to_shininess, shininess_to_roughness, specular_to_specular_weight, transparency_to_transmission, translucence_to_subsurface, emission_to_emission_luminance and clamp. Forward and reverse conversion share the same .mmap; the reverse function is applied automatically when converting backwards.

Tip: For more rules and verified attribute pairings, see Assets/material_mapper_presets/材质映射指南.md.
