In-place replacement puts the converted material in place of the source one: the source material is deleted, the new material is renamed back to the source name, and the shading engines are reconnected, so the material name and assignment on objects stay unchanged.

Prerequisites

  • One material conversion has completed and the mapping path is usable.
  • The scene is saved, or you accept losing the current material changes.

Steps

  1. In 「转换选项」 (Conversion options) of the material conversion tool confirm that 「保留原始材质」 (Keep original material) is unchecked (unchecked by default).
  2. Keep 「复制纹理连接」 (Copy texture connections) and 「自动应用到选择对象」 (Apply to selected objects automatically) checked.
  3. Select the materials or objects and click 「转换选择」 (Convert selection).
  4. The tool records the source material's connections to each shadingEngine, deletes the source material, renames the new material to the source name, and reconnects the new material's outColor to the original shading engine input.

Verify the result

Only one material remains in the Hypershade, with the same name and the target type; the original objects still use that material name and nothing is lost in the viewport; the Script Editor reports success.

Tips

  • To keep the old material for rollback, check 「保留原始材质」 (Keep original material). The new material then keeps a suffixed name (_ai, _vr, _rs, _opb or _cvt) and is assigned to the original objects automatically.
  • Intermediate materials from multi-hop conversions are deleted automatically and never left in the Hypershade.

Warnings

Replacement deletes the source material node; save the scene before converting, or validate the mapping on a test material first.
