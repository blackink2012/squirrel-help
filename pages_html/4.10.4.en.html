In 「导入版本 / LOD」 (Import version / LOD) in the asset context menu, choose version, LOD and format step by step to pick what to import into the scene.

Prerequisites

  • The asset has several versions, or the main version itself has several LODs; otherwise the submenu is not shown.
  • A Maya scene is open and the asset library is loaded.

Steps

  1. Right-click the asset thumbnail and choose 「导入版本 / LOD」 (Import version / LOD).
  2. Choose the version: 「主版本」 (Main version), V1, V2 and so on.
  3. Choose the LOD. Entries show the display name, the LOD ID and the face count.
  4. When one LOD has several geometry formats, choose the format.
  5. Click to import through the normal import pipeline.
  6. You can also double-click the preview on the right to open the version browser, select a version and click 「导入此版本」 (Import this version) to import it using one of its available formats.

Verify the result

  • The imported geometry appears in the Outliner.
  • When the version directory contains .zmetal or .mcm the version submenu additionally lists a material entry; choosing it runs a material import.
  • The import log shows the version directory and format.

Tips

  • With only one version there is nothing to switch, and the menu still lists "main version → LOD"; with only one LOD it lists geometry formats directly.
  • Importing does not replace existing models in the scene; delete the old model by hand when a replacement is needed.
  • Material files inside a version directory belong to that version; versions without their own materials use the main version's materials.
  • Version information can be reviewed together in the version browser, see 4.10.7.
