One-line summary: add tags to several assets at once, or strip one tag from a whole batch.

How to open it

  1. Multi-select assets in the grid (2 or more).
  2. Below the grid, in the batch bar, click Batch tags.
  3. The window opens titled "Batch tag management (N assets)".

Tagging a single asset is done in the properties panel and does not need this window.

A complete example

Adding tags to a batch

  1. Multi-select assets → batch bar → Batch tags.
  2. Keep Add tags.
  3. Click the common tags to add (they highlight), or type industrial,metal (English comma).
  4. Read the preview: "will affect N assets: add X tags".
  5. Click Apply; when done it reports "Batch tag operation finished: N succeeded".

Removing a tag from a batch

  1. Multi-select assets → Batch tags → switch to Remove tags.
  2. In the existing tag chips click the one to remove (it turns red = pending removal).
  3. The preview should read "will affect N assets: remove X tags (red marked)".
  4. Click Apply.

Risks and how to undo

OperationRiskUndo
Batch adding tagsA wrong tag pollutes search / filtering (tags take part in retrieval)Select the same assets and strip it with Remove tags
Batch removing tagsOne pass removes from a whole batch and there is no undoYou must add them back from memory or common tags; check the preview count before running
Chinese comma separationIt becomes part of one long tag nameWatch for English commas when re-adding

Tags affect search and filter results (see 4.1.5.2), so try a small batch first.
