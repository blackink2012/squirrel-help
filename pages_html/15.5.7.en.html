One-line summary: right-clicking an HDR asset card in the asset grid opens this menu. HDR images are environment (IBL) textures, so there is no "import geometry" — only import HDR, create dome light and assign to a light.

How to open it

  1. Left Category tab → click HDR or any category under it;
  2. In the center asset grid, right-click any HDR card.

The HDR menu has no background render (update thumbnail has only 6 items), no format conversion and no preview node — HDR assets hold neither geometry nor node files.

Submenu: Create dome light ▶

The sample asset shows 3 templates, one dome light per renderer:

Sub-itemDescription
VRayLightDomeThe V-Ray dome light
aiSkyDomeLightThe Arnold sky dome light
rsDomeLightThe Redshift dome light

These templates come from the plug-in's bundled dome light preset directory; whichever .ma templates that directory holds is what the submenu shows. Pick the entry for the renderer you want to light with.

Notes specific to this sub-library

  • "Create dome light" and "Assign texture" are a pair: the first builds a light and wires the image; the second only wires the image onto a light you already have. If a dome light exists and you just want a new environment, use Assign texture.
  • The renderer of the chosen light must be installed: whether a template can be built depends on that renderer's plug-in being loaded.
  • HDR has no import geometry / format conversion / preview node: nothing is missing; HDR assets simply contain none of those.
