一个 .zasset 是一个文件夹，元数据、几何体、材质、贴图、缩略图和依赖文件都放在里面，文件夹本身就是完整资产。

目录结构

MyAsset.zasset/
├── meta.json                 # 元数据
├── node.ma / node.mb / node.fbx / node.obj / node.usd
├── node.zmetal               # 材质节点网络（材质/模型资产）
├── node.zlight               # 灯光预设（灯光资产）
├── node.mcm                  # 材质 → 模型映射
├── textures/                 # 材质与灯光贴图
├── deps/                     # 收集到的关联文件（可选；旧版为 associated/）
│   ├── textures/  caches/  proxies/  volumes/
│   ├── references/  audio/  movies/  imageplanes/  others/
├── thumb.sicon               # 静态缩略图
├── thumb.aicon / thumb.mp4   # 动图或视频缩略图
├── lods.json                 # 当前 LOD 索引（lod0 = 根目录几何体）
├── lod1/                     # LOD1 及以后的几何体
├── variants.json             # 变体登记表（变体几何/缩略图、旧版版本与版本材质）
├── variants/                 # 变体几何（<id>.ma 平铺；旧版结构为 <version>/lod*/）
└── V1/ V2/ …                 # 新版本：每个都是自包含的版本资产（登记在 meta.json）

关键文件

文件作用
meta.json资产身份与索引：id、name、name_cn、tags、category、asset_type、formats、ani 等
node.<ext>根目录几何体，等同于 lod0；多种格式可同时存在
node.zmetal / node.zlight材质或灯光的节点网络，导入时重建
node.mcm顶点/面/边数和面级材质指派，用于导入匹配模型
textures/贴图统一平铺存放；同名同内容只留一份，同名不同内容追加序号
deps/勾选「收集关联文件」时才复制；子目录按文件类型分类（旧版目录名为 associated/，仍可读取）
lods.json当前 LOD 索引：default_lod 和 lods 列表；lod0 指向根几何体
variants.json变体与旧版版本的登记表：variants[]（每个变体的几何/缩略图入口）与 versions[]（旧版版本的标签、LOD 列表、版本独立材质路径）
variants/变体几何体：新结构平铺为 variants/<变体id>.ma（多 LOD 为 variants/<id>_lod1.ma）；旧版结构为 variants/<version>/lod*/；变体缩略图也在该目录
V1/、V2/由「更新资产 → 创建新版本」生成的内嵌自包含版本，各自带 meta.json；主资产 meta.json 的 version_assets 登记这些子版本

元数据里的依赖账

导出时无论是否勾选收集，都会扫描依赖并把结果写进 meta.json：dependencies_missing 记录找不到的文件，dependencies_out_of_scope 记录本次不打包的依赖，dependencies_unresolved_tokens 记录路径里无法解析的记号。texture_map 记录贴图原始路径到包内路径的映射，导入时据此重映射。

两套索引：lods.json 与 variants.json 并存

lods.json 与 variants.json 是两套并用、各管一段的索引，不是「新结构取代旧结构」：

  • lods.json 管当前 LOD：default_lod + lods 列表，lod0 指向根目录几何，之后按 lod1/… 存放精度递减的几何。
  • variants.json 管变体与旧版版本：
    • 变体：variants[] 里一条一个变体，几何平铺在 variants/<id>.ma（旧结构在 variants/<id>/lod*/），缩略图也在 variants/ 下；
    • 旧版版本：versions[] 记录版本 id / 标签 / LOD 列表，几何在 variants/<version>/lod*/；这类版本的独立材质导出到 variants/<version>/node.zmetal，并写进该版本的 material 字段。
  • 这些现在仍在写：变体的增删（core/zasset_builder.py 的 add_variant / add_variant_lod / remove_variant）、版本独立材质（core/export_orchestrator.py 的 _export_variant_material）都会更新 variants.json。所以看到资产里有 variants.json 不是「历史遗留」，是它在用变体/旧版版本能力。
  • 「更新资产 → 创建新版本」另走一条：在主资产里建内嵌自包含的 V{n}/，登记在主资产 meta.json 的 version_assets，这条不写 variants.json。
  • meta.json 的 variant_types 记录该资产含 variant / lod 哪几类内部结构；读取侧由 core/asset_scope.py 把内嵌 V{n}/、旧版 variants/<version>/、平级子 .zasset 三种形态统一合并，老资产不需要手工迁移。
