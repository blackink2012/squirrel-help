When no library is configured, the plug-in creates SquirrelLib automatically; you can also add an existing directory or create a new empty library.

Automatic initialization

The first time the main window opens without a configured library, SquirrelLib is created in the user directory. Loading that library completes the directories for all 11 built-in sub-libraries and creates the default sub-categories plus a 「自定义」 (Custom) category. library.json and favorites.json are written to the library root.

Adding or creating a library

  1. Open Settings → General.
  2. In the 「资产库管理」 (Asset library management) group, click 「添加资产库」 (Add asset library) and pick an existing directory.
  3. Or click 「创建资产库」 (Create asset library) and choose a new directory.
  4. With a library selected you can click 「设为默认」 (Set as default) so it loads first next time.
  5. Click 「确定」 (OK) to save; the category tree in the main window refreshes.

What the directories look like after completion

  • The 「创建资产库」 (Create asset library) button creates only 6 base directories: materials, models, lights, textures, scenes, hdr.
  • Loading or switching to that library completes all 11 built-in sub-libraries: materials, models, lights, textures, scenes, hdr, ani, images, audio, animation, nodetree — in other words, the remaining five (dynamics, images, audio, animation data, node trees) appear the first time the library is loaded.
  • On first run (when the library root has no library.json), or when a sub-library has no sub-categories, sub-category folders are created from the default configuration.
  • Every sub-library root also gets an AAAcustom (custom) sub-category so assets always have a place to go.
  • Top-level categories cannot hold assets directly; assets belong in their sub-categories.

Verify the result

  • The category tree on the left shows 11 built-in sub-libraries, and expanding them reveals the default categories and 「自定义」 (Custom).
  • library.json, favorites.json and the sub-library directories appear in the library root.
  • The library is listed in library_paths in ~/.squirrel_asset_manager/app_settings.json.

Common failures

  • Invalid path / no permission: switch to a local directory you can write to, or ask an administrator to grant write access on the share.
  • The library loads empty: the directory has no .zasset packages, or the category levels differ from what you expect; check the sub-library and category directories.
  • The library disappears after the settings file is corrupted: the settings file is backed up as .bak, and library_paths can be restored from it.
  • Several people renaming in a shared library at the same time: the library has no cross-machine file lock, so avoid moving the same asset concurrently (the exact lock strategy is to be confirmed).
