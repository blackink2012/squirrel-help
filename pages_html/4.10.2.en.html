Appending a LOD exports the currently selected low-poly geometry as a new detail level of an existing asset, written into lod{n}/ and registered in lods.json.

Prerequisites

  • The geometry to use as the new LOD is selected in the Maya viewport.
  • The target asset can be located in the library (right-click its thumbnail).
  • At least one geometry format is checked in the export configuration: ma, mb, fbx, obj or usd.

Steps

  1. Select the decimated or simplified geometry in Maya.
  2. Right-click the asset, expand 「更新资产」 (Update asset) and choose 「追加为 LOD」 (Append as LOD).
  3. In the export dialog that follows, check a geometry format and confirm that the asset name, category and so on stay unchanged.
  4. Click export.
  5. The system takes the highest existing non-lod0 level plus one, writes lod{n}/ and updates lods.json.

Verify the result

  • An L badge appears at the top left of the asset card (when several LODs exist).
  • Entering the asset through 「导入变体 / 版本」 (Import variant / version) (or 「导入版本 / LOD」 (Import version / LOD) when there are no variants) shows the new LOD and its face count.
  • The lods array in lods.json in the asset root gains an entry.

Tips

警告

With no geometry format checked it reports 「追加 LOD 需要导出几何体」 (appending a LOD requires exporting geometry); the flow aborts when the export result contains no geometry file.

  • The target of an appended LOD follows the current entry: operate on the main asset in the grid, or select a version / LOD in the asset versions window first and then append.
  • lod0 is the root geometry, and new levels start at lod1 and increase.
  • After appending, a thumbnail is captured again to show the new LOD.
  • A LOD can target a specific V{n}: select that version in the asset versions window and click 「追加 LOD」 (Append LOD) so the LOD is written into that version (selecting the main version adds it to the main asset).
