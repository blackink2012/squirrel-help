1. The feedback window

How to open it

Settings → About page → Feedback group → Send feedback.

What every control does

ControlEffectHow to fill it

Bottom message lineThree outcomes: submitted, id: xxx / currently offline, saved locally and will retry when online / submission failed: reasonNote the id for later communication

A complete feedback flow

  1. Reproduce the problem and note the steps and symptoms (screenshots / logs help);
  2. Settings → About page → Send feedback;
  3. Choose a type → write the title → write the details;
  4. Add contact details if you want a follow-up;
  5. Click Submit feedback;
  6. Read the message line:
    • submitted → note the id;
    • offline → the content is stored locally and retried automatically once online (you need not keep the window open);
    • failed → handle the stated reason (an unreachable service address, for example).

How to write a useful report

  • Must include: what you did, what you saw, what you expected;
  • Attach when possible: log locations are in 6.8.1 and the report template in 6.8.3;
  • No sensitive data: never paste keys / license codes into the description, and the contact field is optional.

Risks and how to undo

  • Feedback is sent to the server, and there is no "withdraw" once it succeeds — check the content (especially contact details) before submitting.
  • Queued offline content is stored locally and retried when online; if you do not want it sent, do not submit before the network comes back.
