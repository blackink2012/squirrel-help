一句话定位：在资产网格里右键一张场景资产卡片时，弹出的就是这个菜单。 场景资产的「导入」会把一整段布置（多个物体、灯、相机）带进当前场景，菜单结构基本和模型一样。

怎么打开

  1. 左侧「分类」页签 → 点「场景」或它下面的任一分类；
  2. 中间资产网格里右键任意场景卡片。

菜单从上到下的顺序

段条目
① 子库专属导入 ma、添加引用
② 收藏与选择添加到收藏夹 ▶、全选、复制、打开文件夹
③ 整理移动到 ▶、复制到 ▶
④ 维护编辑、更新缩略图 ▶、更新资产 ▶、删除 ▶、格式转换
⑤ 查看与 AI预览节点 ▶、AI 分析缩略图
⑥ 最后一条资产详情

菜单逐项详解

菜单项作用前提点了之后注意
导入 ma把整个场景内容导入当前 Maya 场景Maya 已连接；资产里有 .ma直接导入；场景里多出该资产包含的物体 / 灯 / 相机和你当前场景并存，不会替换当前场景；导入后可撤销
添加引用以 Maya Reference 方式引入场景文件资产里含 .ma / .mb 等可引用格式场景里多一个引用节点，内容以引用形式存在引用路径指向资产包，移动资产包会断
添加到收藏夹 ▶把资产加入收藏夹资产库已加载子菜单列「默认收藏夹」+ 你自建的收藏夹；点一下加入、再点一下移出多选时对全部选中的资产生效
全选选中网格里当前可见的全部卡片有卡片全部高亮只选当前筛选 / 搜索结果
复制把资产放进剪贴板无内部剪贴板记录资产，同时把资产文件夹写进系统剪贴板真正复制一份要再到目标分类空白处「粘贴」
打开文件夹打开资产在磁盘上的位置资产是 .zasset 目录文件管理器定位到资产文件夹只打开，不改内容
移动到 ▶把资产移到别的分类资产库已加载级联选目标分类，资产从当前分类消失见 8.5.15
复制到 ▶把资产复制一份到别的分类资产库已加载目标分类多出同一资产占双份磁盘空间
编辑改中文名、分类、标签、注释无弹「编辑资产」对话框见 8.5.16
更新缩略图 ▶换掉或新增缩略图「后台渲染」需本机有 mayapy子菜单 7 项：截取 / 导入 / Maya拍屏 / 渲染图 / 添加 / 截取添加 / 后台渲染拍屏 / 渲染图会先问帧模式
更新资产 ▶把资产内容换成 / 扩成新的「替换资产」等需要场景里有选中物体替换资产 / 追加格式 / 追加为 LOD / 创建新版本 / 添加新变体… / 批量添加变体… / 变体管理…都会写磁盘，先看清目标资产
删除 ▶删掉这个资产无子菜单：移到回收站 / 彻底删除「彻底删除」不可还原
格式转换把资产里的几何体转成其它格式并追加进资产包本机有 mayapy弹「格式转换」对话框：勾选 .ma / .mb / .fbx / .obj / .usd / .abc 后开始库外临时目录转换 + 验证后才写回；原有格式保留
预览节点 ▶看场景文件内部的节点连接资产里有 .zmetal 或具名 .ma子菜单列出节点文件（样本资产：deepseek_low_Street.ma），点一项打开节点编辑器预览只读预览，不导入场景
AI 分析缩略图让 AI 读缩略图给建议AI 依赖已装好打开 AI 分析窗口，确认后写回资产见 8.5.17
资产详情单独看这个资产的详情无有版本 / 变体打开版本浏览器，否则打开资产观察窗口与双击右侧预览图同一条链路

和模型资产菜单的差别

条目场景模型
导入 / 添加引用✓（导入 ma）✓（导入 ma）
格式转换✓✓
预览节点✓（样本里有具名 .ma）样本里没有（节点文件是通用 node.ma）
其余公共条目相同相同

也就是说：场景和模型的菜单在结构上是一样的，差异只来自资产包里到底有哪些文件。

这个子库特有的注意点

  • 「导入」不会清空你现在的场景：它是把内容合并进来。想只要场景资产的内容，先自己新建一个空场景。
  • 场景资产往往比较大：导入后如果发现多了相机 / 渲染设置，先在 Outliner 里确认哪些是该资产带来的。
  • 格式转换不处理贴图与相机：它只转几何体（通过 Maya 原生导出），所以别指望转完 .fbx 里什么都有。
