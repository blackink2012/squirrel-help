A version can be deleted in the version browser; deleting removes the whole content of that version and cannot be undone.

Deleting a version

  1. Double-click the asset preview on the right to open the version browser.
  2. Select the version to delete in the 「版本」 (Versions) list on the left.
  3. Click 「删除此版本」 (Delete this version) at the bottom.
  4. Choose yes in the 「确定要删除版本…」 (Delete version…?) confirmation.
  5. The list and the library refresh immediately.

The main version entry has no delete action (the button is disabled).

Verify the result

  • The version browser's left column loses an item and version_assets in the main asset's meta.json drops the matching folder.
  • The V{n}/ directory inside the main asset disappears from disk.
  • After deleting the last version, has_versions and version_assets on the main asset are cleared.

Tips

警告

Deleting a version removes its geometry, materials, textures and thumbnail together, and cannot be undone; back up the whole .zasset first for important versions.

  • Deleting a single LOD: select the LOD entry in the asset versions window and click 「删除此 LOD」 (Delete this LOD); the button is disabled when only one LOD is left (at least one must remain), and the main version itself cannot be deleted.
  • Variants are a separate model; their delete entries are 「更新资产 → 更新变体 → 删除变体」 (Update asset → Update variant → Delete variant) or 「变体管理…」 (Variant management…), see "Variant management and deletion".
  • On the command side, version_manage op=remove_version backs up the whole version directory to squirrel_ai_undo under the system temp directory before deleting and returns the backup path; copy that directory back into the main asset root to restore it.
  • Versions deleted through the command can also be rolled back with undo_last.
