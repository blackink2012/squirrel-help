The default library decides which library loads first the next time the asset library window opens; it is not the same as the "current library".

Steps

  1. Open the Settings window and go to the 「资产库管理」 (Asset library management) group on the 「常规」 (General) tab.
  2. Select the target library in the list.
  3. Click 「设为默认」 (Set as default).
  4. A [默认] ([default]) marker appears after the list item.
  5. Click 「确定」 (OK) to save.

Verify the result

  • Reopening the Settings window the library still carries the [默认] ([default]) marker.
  • When the asset library window reopens, the default library ranks high among load candidates (after an explicit path, before the last used library).
  • The default field returned by library_manage op=list is that library's path.

Tips

  • Setting the default does not switch the current library immediately; use the library dropdown at the top of the 「分类」 (Categories) page to switch.
  • With no default set, the Settings window shows the first list item as the default, while startup actually prefers the last used library.
  • On the command side library_manage op=set_default requires the library to be registered in library_paths already.
  • The default library setting is stored in user settings and not written into the library directory.
