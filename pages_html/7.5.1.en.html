The image format conversion tool reads and writes through OpenCV, converting between floating-point HDR/EXR and the common 8-bit formats; converting float to 8-bit applies tone mapping automatically.

Supported formats

FormatExtensionData modeNotes
Radiance HDR.hdrFloatHigh dynamic range environment image
OpenEXR.exrFloatProduction-grade high dynamic range image
PNG.png8-bitLossless, supports an alpha channel
JPEG.jpg, .jpeg8-bitLossy compression, small files
TIFF.tif, .tiffFloat or 8-bitSupports several compressions
BMP.bmp8-bitUncompressed bitmap
WebP.webp8-bitHigh compression ratio
TGA.tga8-bitCommon in games

Output options

Output formatAvailable options
JPEGQuality 1–100, 95 by default
PNGCompression level 0–9, 5 by default
TIFFCompression NONE / LZW / DEFLATE, LZW by default
EXRCompression mode, ZIP by default
HDR / othersNo extra options

Use and verify

  1. Choose files or a folder in the tool and set the output format and options.
  2. Click 「开始转换」 (Start conversion); the log shows each file's result.
  3. When it finishes, confirm in the output directory that the files exist, have the right extension and can be read by a Maya file node.

Tips

  • Requires opencv-python and numpy; imageio is not required but improves EXR compatibility.
  • TIFF can keep float data or output 8-bit; once TIFF is chosen, decide the compression by purpose.
  • Converting HDR/EXR to PNG/JPEG applies Reinhard compression and 2.2 gamma, so it is only suitable for previews or thumbnails.
  • When the full dynamic range must be kept, output .exr or .hdr again.
