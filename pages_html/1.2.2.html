独立版是在 Maya 之外启动的同一套资产界面；EXE 安装包把它、内置 Python 运行时和可选的 Maya 集成一起装好。

独立版

  • 入口是 squirrel_asset_manager/standalone_preview.py，源码包内可双击 启动独立预览.bat。
  • 运行环境为系统 Python + PySide6，或使用 Maya 自带的 mayapy（不启动 Maya 界面）。
  • 它通过本机 commandPort 驱动正在运行的 Maya，把导入、导出、缩略图、更新资产等操作投给 Maya 执行；真机验收过 Maya 2025。
  • Maya 不在线时，只能浏览、搜索和执行文件层操作，不能做场景导入导出。

EXE 安装版

  • 安装到 %LOCALAPPDATA%\SquirrelAM（安装时可改），按当前用户安装，不需要管理员权限。
  • 内置 Python 3.11.9、PySide6 6.9.2、Pillow、requests、pypinyin，启动时由 SquirrelAssetManager.exe 设置环境并拉起 standalone_preview.py。
  • 安装器可选「Maya 集成」：写入各版本 userSetup.py 的导入路径、状态行按钮与桥接端口，并在安装时创建一次工具架按钮（之后不再自动重建）；没有 Maya 时默认不勾选。
  • 可选「AI 助手 dsh（离线）」：解压内置 dsh 与便携 Node；不装也不影响资产浏览与管理。

适合谁

  • 想在不开 Maya 时整理、搜索、预览资产的人。
  • 需要把资产操作投给已打开 Maya 的美术，或想让外部 AI / 命令行驱动 Maya 的人。
  • 不熟悉 Python 环境、希望双击即用的人优先选 EXE。

已知边界

  • 独立版批量导出目前是逐单顺序投递，没有 Maya 内版的进度覆盖层与取消按钮。
  • 不启动 Maya 时，依赖场景的功能不可用；端口仅监听 127.0.0.1。
