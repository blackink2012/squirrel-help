一句话定位：插件的「授权管理」窗口 —— 看当前授权状态、复制机器码、填激活码激活 / 直接激活试用、展开「离线许可证激活」导入手动签发的离线许可证（文件或剪贴板）、解除或恢复本机授权。

它管的是"这台电脑能不能用"这件事。授权绑定当前电脑（靠机器码），到期后仍可浏览资产库，但导入 / 导出 / 转换这些操作需要有效授权。

怎么打开

入口具体怎么做
设置窗口设置 → 左侧导航「授权激活」页 → 「授权管理」按钮
首次启动第一次打开插件（或授权已到期）时先自动弹出这个窗口；取消后仍可只读浏览
功能受限时自动弹授权过期 / 未激活时去用导入、导出、转换等受限功能，会提示并直接打开这个窗口

窗口标题是「授权管理 - <产品名>」。

界面上每个控件做什么

卡片「当前状态」

控件内容怎么读
状态徽章授权版本：试用 / 买断 / 订阅 / 浮动 / 未授权一眼看是哪种授权
状态文字「试用中，剩余 N 天」/「已授权：某某（永久）」/「已授权：某某（至 日期）」/「订阅已到期（宽限期内，剩余 N 天）」/「授权已到期，当前仅可浏览」/「离线校验已过期，请联网启动一次（当前只读）」/「未激活（只读）」决定你现在能做什么；「离线校验已过期」表示断网太久，联网启动一次即可续租
版本范围「版本范围：1.x · 免费升级至 2029-11-15」/「版本范围：不限」告诉你能用哪个大版本、新版本免费到什么时候（年费与试用显示「不限」）

信息卡（机器码 / 激活码）

控件作用取值建议
「机器码」只读输入框本机的机器码（形如 E41D-6406-80F7-52A9），买授权 / 找客服时要用不要手改
「复制」按钮复制机器码到剪贴板（按钮文字会短暂变成「已复制」）发给销售 / 客服时用
「激活码」输入框（占位 SQAM-XXXX-XXXX-XXXX-XXXX）收到的激活码填这里有激活码就填；没有就留空
「激活」按钮连服务器激活：填了激活码就按激活码激活；没填就交给服务器按产品状态下发（试用由服务器决定；正式售卖会要求激活码）一般点这个就够了

激活码下方有一行说明：「直接点击「激活」即可激活试用，试用包含完整功能。」 —— 没买也能先试用，确认好用再购买。设置 →「授权激活」页同样是绿色的「激活」按钮，空码点击即开始试用（不弹登录窗）。

折叠卡片「离线许可证激活」

默认收起，离线导入收在里面；点标题展开（箭头 ▸ 变 ▾），再点收起。日常在线激活不需要打开它。

控件作用取值建议
「导入许可证文件…」选本地的 .lic / .dat / .json 许可证文件导入激活拿到的是客服手动签发的离线授权文件（不是激活码）时用；在线激活的授权文件不能离线导入
「从剪贴板导入」读取剪贴板里的许可证全文并直接激活客服只发了一段文本时用；不会把许可证内容显示在界面上，只回结果

也可以直接把 .lic / .dat / .json 文件拖进这个窗口，它会按"导入许可证文件"处理（不需要先展开折叠区）。

底部

控件作用注意
「解除本机授权」解绑这台电脑服务器确认后释放席位，只受每日解绑上限（每 24 小时最多 3 次）约束；离线签发授权时按钮是灰的
「恢复本机授权」把之前解绑的本机副本恢复回来（会向服务器确认）始终显示；本机无解绑副本时置灰并悬停提示
「关闭」关窗（已做的激活 / 解除都已生效）—
底部消息行显示激活成功 / 失败原因 / 「[错误码] 说明」等出问题先看这行

购买授权与「我的授权」已移到「设置 → 授权激活」页；同步授权也在该页「当前授权」卡右上角。授权窗口只负责激活码、离线导入、解除 / 恢复。

一次完整的激活流程

情况 A：拿到的是激活码

  1. 打开授权窗口；
  2. 「激活码」里填入 SQAM-…；
  3. 点「激活」；
  4. 看底部消息行：「激活成功。」则状态徽章与状态文字会立刻更新；
  5. 关窗，回去继续用。

情况 B：拿到的是许可证文件

  1. 打开授权窗口；
  2. 展开「离线许可证激活」区块，点「导入许可证文件…」选文件（或直接把文件拖进窗口）；
  3. 看消息行提示成功，状态刷新。

情况 C：只拿到一段许可证文本

  1. 先复制许可证全文；
  2. 展开「离线许可证激活」区块，点「从剪贴板导入」；
  3. 看消息行提示成功，状态刷新（许可证内容不会显示在界面上）。

情况 D：没有激活码，想先试用 / 靠服务器下发

  1. 「激活码」留空，直接点绿色的「激活」（设置 →「授权激活」页同样操作，不弹登录窗）；
  2. 服务器按产品状态决定发什么：可试用时自动发试用证，试用包含完整功能；正式售卖会回「服务器要求激活码」，这时就得找销售要码。

版本与升级

授权按版本分两种口径（窗口的「版本范围」一行会写清楚你现在属于哪种）：

授权版本范围说明
年费授权不限有效期内始终可以使用最新版本
永久授权（买断）首次激活时的大版本 + 3 年免费升级首次激活时以服务器发布的当前大版本为基准（如 1.x）；之后 3 年内发布的新版本免费获得，联网心跳时自动扩大范围；更早的大版本照常可用。厂商离线签发的买断证以签发时的大版本为基准、从签发日起算 3 年
试用不限试用期内可用最新版本
  • 永久授权的 3 年从首次激活日起算，窗口里显示为「免费升级至 日期」；基准版本取首次激活时服务器发布的当前大版本，不看你本机装的是哪个版本。
  • 离线签发（导入 .lic 文件）的买断证没有「首次激活」这一步：版本范围与 3 年截止由厂商在签发时写入，窗口里同样显示「版本范围 / 免费升级至」；联网登记后，服务商在升级期内仍会按在线证规则自动扩大范围。
  • 3 年后如需使用更新的大版本，需要重新购买；你手里已买到的版本可以一直使用，不会被停用。
  • 如果打开新版插件时提示「当前版本超出该授权范围」，说明该版本超出了你的版本范围——继续用旧版本，或购买新授权。

做完能看见什么

  • 状态徽章和状态文字立刻变成对应的授权状态（如「已授权：某某（永久）」）；
  • 设置 →「授权激活」页的状态徽标与状态行会跟着刷新；
  • 受限功能（导入 / 导出 / 转换）恢复可用。

风险与反悔

  • 授权绑定当前电脑：换电脑要重新激活；许可证文件与机器码绑定，换机请走「解除本机授权 → 新机激活」流程。
  • 「解除本机授权」只受服务器每日解绑上限约束：在线解除 = 服务器确认后释放席位，每 24 小时最多 3 次；离线签发授权不支持解绑换机，按钮不可用。
  • 离线解除：连不上服务器时会再问你一次"是否仅删除本机授权"（席位仍占用、不消耗切换次数，之后可联系客服解绑）。
  • 反悔：解除后需要重新激活才能用受限功能；解绑前导出的同一份许可证文件会在本机失效，不能重新导入；有「恢复本机授权」按钮且可用时点它更快（仅限在线授权）。
  • 机器码是只读的、由本机决定，改它没有意义；别把别人的许可证文本 / 激活码贴到不属于它的机器上，会激活失败。
