If dsh is not installed when 「AI 助手」 (AI assistant) is clicked, the plug-in shows an actionable install guide; installing once that way needs no Maya restart.

Prerequisites

Network access. dsh requires Node.js ^22.19 || >=24; 22.18 and below as well as 23 do not work.

Steps

  1. In Maya click AI 工具 (AI tools) → AI 助手 (AI assistant).
  2. In the prompt choose 「一键安装（推荐）」 (One-click install, recommended). The plug-in checks Node first, downloads portable Node into <plug-in directory>\node when needed, uses it to install dsh into <plug-in directory>\dsh and opens the assistant when it finishes.
  3. On a restricted network, or to control the version yourself, choose 「复制安装命令」 (Copy the install command) and run the npm command with full paths in a terminal; install into the plug-in's dsh sub-directory so the system-wide install is not overwritten.
  4. After a manual install, return to Maya, reopen the asset window and click 「AI 助手」 (AI assistant); no Maya restart is needed.

Verify the result

Run python squirrel_asset_manager/install_ai_dsh.py --list: the dsh runtime line should show 0.2.2-rc.3 with an in-package path, and the node line should show a qualifying interpreter.

Tips and warnings

  • The one-click install downloads about 38 MB of Node and 60–80 MB of dsh dependencies, preferring a domestic mirror first.
  • Close any open AI panel before a manual install, or files are locked and it reports EBUSY.
  • pip install deepseek-harness-sdk installs the single-file SDK runtime without the web profile, so it cannot serve as the chat surface.
  • When dsh lives elsewhere, point at it with SQUIRREL_DSH_BIN or SQUIRREL_DSH_ROOT.
