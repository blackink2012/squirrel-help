One-line summary: the row above the center asset grid is the "asset area toolbar" — import and create on the left, where you are in the middle, and filtering, view, sort and thumbnail size on the right.

Where it is

Below the title strip of the center block (the asset grid) there is a horizontal row of buttons, and it needs no "opening". It follows the current area: if you split the layout and opened several asset panels, each asset panel has its own. The recycle bin view reuses the same row (import / create / tags are temporarily disabled).

Beginner pitfalls

  • Cannot find the import button: it is above the asset grid at the far left, labeled Import from outside with a dropdown arrow — not in the top-right corner.
  • Imported but nothing appeared: first confirm a specific category is selected (not All assets), then that the file format is supported by that category, see 8.4.2.
  • Changing view or sort also changes the recycle bin: intentional; the recycle bin shares view, sort and thumbnail with the asset page.
  • Assuming the thumbnail slider works in list view too: list rows have a fixed height, so the slider mainly affects icon view (it applies when you switch back).
