The sub-library ID is the unique identifier; the display name only affects text in the UI. Both are edited on the right side of the Sub-libraries and categories page.

What it does

The left list shows Display name (ID). The ID also maps to the sub-library folder name inside the asset library, and is referenced by per-sub-library configuration sections such as the right-click menu, double-click presets and export presets. The display name is only for presentation.

Values and defaults

  • There are 11 built-in sub-libraries, with IDs and display names: materials Materials, models Models, lights Lights, textures Textures, scenes Scenes, hdr HDR, ani Animation, images Images, audio Audio, animation Animation data, nodetree Node tree.
  • materials, models, lights, textures, scenes, hdr and ani are protected from deletion. images, audio, animation and nodetree are built-in IDs but can currently be deleted (see Add and delete sub-libraries for the risks).
  • Custom sub-library IDs look like custom_1, custom_2, with display names like Custom1.
  • An ID must not duplicate an existing sub-library; otherwise the UI reports "Sub-library ID 'xxx' already exists".

Steps

  1. Open Settings → Sub-libraries and categories and select a sub-library on the left.
  2. Edit Sub-library ID: or Display name:.
  3. Click Apply or OK.

Scope of effect

  • Changing the display name is safe; it only changes UI text.
  • Changing the ID only changes the key in the configuration file. It does not rename the sub-library folder on disk, so existing assets may no longer find their sub-library.
  • IDs of core sub-libraries are referenced by sections in other presets; after a change those old sections may stop applying.

Verify the result

After applying, the left list should show the new Display name (ID) and keep it after reopening settings.

When to change it

Normally only change the display name. If you really must change an ID, back up the asset library and config.json first, then check the sections with the same name in the right-click menu and double-click presets.
