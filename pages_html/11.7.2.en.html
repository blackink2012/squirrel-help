When the chosen double-click command has a secondary action, the 「子选项」 (Sub-option) dropdown decides which format or type is used.

Effect

The dropdown appears only when the command has optional sub-items, labelled 「子选项:」 (Sub-option:). It refines the command: for example Import needs to know which format and Create material which material node type.

Values and defaults

CommandSub-optionsNotes
ImportAutomatic (the asset's default format), ma, mb, fbx, obj, usd, abc, ass, vrscene, rs, vrmesh, zmetal, zlight, proxy, vdbAutomatic or empty prefers the preset format and otherwise takes the asset's first available format
Import textureAllFixed: imports every texture inside the asset, with no other option
Create materialAutomatic (follow the renderer) plus the node types in material_presets from config.jsonThird-party renderer materials carry a short suffix such as aiStandardSurface（AI） or VRayMtl（VR）
Create environment lightScans Assets/HDR_ligt/*.ma dynamicallyThe list follows the files in that directory

Create material and create environment light are not hard-coded: the former reads material_presets from config.json and the latter scans the plug-in's built-in HDR light directory.

Scope

  • Sub-options only affect double-clicking; Import in the context menu still follows each command's own format selection.
  • Choosing 「自动」 (Automatic) is equivalent to leaving option empty: the format actually in the asset decides, and the first available is used when nothing matches.

When to change it

When the asset package holds several formats and a fixed one should always be used on double-click, for example always fbx for models.

Verify the result

After applying, double-click an asset of that type and the format actually imported should match the dropdown.

Tips

Older data may store only the command string without a sub-option; the interface then offers the current command's default items again.
