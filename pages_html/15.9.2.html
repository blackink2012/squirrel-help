一句话定位：设置窗口的第一页，放的都是「界面长什么样、钱怎么花」之外的日常偏好，以及资产库本身的管理。

这一页不受全局锁定影响，打开就能改。

怎么打开

顶部工具栏「设置」按钮（8.2.4）→ 设置窗口默认就在「常规」页。

设置预设（保存 / 导入 / 导出 / 清除 / 还原）

页面最底部的「设置预设」分组用来把整套界面设置当一份文件管理：换电脑、重装插件、或者试完一套改法想退回去时用。

按钮作用注意
保存预设把当前已应用的整套设置存成本机预设（%USERPROFILE%\.squirrel_asset_manager\settings_preset.json）窗口里还没点「应用 / 确定」的改动不会进预设；要连刚改的一起存，先点「应用」再点它
导入预设选一个 JSON 预设文件 → 覆盖当前设置并立即生效导入后设置窗口会自动关闭（见下面的「为什么导入 / 还原后窗口会关」）；别的机器导出的预设里资产库路径可能在本机不存在
导出预设把本机预设另存为自选路径的 JSON 文件还没保存过预设时会提示先点「保存预设」
清除预设删除本机预设文件（二次确认）只删预设文件，不影响当前设置；之后仍可导入备份的 JSON
还原预设把整套设置恢复为默认值（相当于恢复出厂，二次确认）写盘后立即生效，并关闭设置窗口；API Key 与资产库列表会保留；本机预设文件不会删

状态行会提示当前有没有预设、最后一次保存的时间。

和底部「恢复默认设置」的区别

底部「恢复默认设置」常规 → 设置预设 → 还原预设
范围只把本窗口的一部分控件改回默认（字号、缩放、视图、同名冲突等）app_settings.json 里的全部界面偏好（语言、配色、AI 模型、各类开关…）
何时落盘还要再点「应用 / 确定」确认后立即写盘并生效
API Key / 资产库列表不动保留（不会被清掉）
配置文件重新读取 export_preset.json / pbr_mapping.json 等不重置这些配置文件（要重置某一项请到对应页签操作）

为什么导入 / 还原后窗口会关

导入和还原都是"直接改磁盘"的操作，而设置窗口里各个控件还显示着旧值。如果窗口继续开着，你再点「确定」，就会用这些旧值把刚导入 / 还原的设置整片盖回去。所以这两个按钮执行完会主动关窗——重新打开设置就能看到新值。

提示

预设只包含界面偏好（app_settings.json），不含「导出默认值 / 右键菜单 / 贴图后缀 / 子库与分类」这些存在 Assets\preset\*.json 里的配置文件。换机器时想连这些一起搬，需要另外拷贝对应 JSON（见 8.9.1 的「配置文件在哪」）。

几个容易踩的点

现象说明
改完字号，重启后又是原来的要确认点的是「应用」或「确定」；只点「取消」不会保存
换了语言只变了一半语言改动要重启插件才完全生效；当前窗口里部分文案可能还是旧的
缩略图大小改了，老资产没变这个设置只影响之后生成 / 截取的缩略图；要给老资产重新出图，用右键「更新缩略图」（见 8.7.2）
缩略图大小下拉里出现一个不在梯子里的值说明设置文件里被手改成了非标准值；插件会原样显示成「自定义」项，不会吞掉你的值
删除资产库后它又回来了删的可能不是列表项而是别的东西；请在列表里选中该库点「删除选中」，并确认默认库不是它
只有一个库时「删除选中」不生效至少保留一个资产库，这是硬限制
导入进来的节点名前面多了一串 资产名:正常：「直接导入时自动创建命名空间」默认勾选。不想要就取消勾选并保存，下次导入的新节点会并进根命名空间
点了「导入预设 / 还原预设」后设置窗口自己关了正常设计：两个按钮都直接改磁盘，关窗是为了防止窗口里的旧控件值把结果盖回去；重新打开即可
保存预设里没有我刚改的东西「保存预设」存的是已应用的设置，先在窗口里点「应用」再保存
还原预设后 AI Key / 资产库还在故意的：凭据与资产库列表不属于界面偏好，不会被还原清掉
