「添加引用」 (Add reference) uses a Maya Reference to bring the asset's geometry file into the scene; the scene keeps only the reference relationship and never copies the model data.

Prerequisites

  • The asset contains one of ma, mb, fbx, abc, usd or obj.
  • The Maya scene is saved.

Steps

  1. Right-click the asset and choose 「添加引用」 (Add reference).
  2. With one referenceable format it runs directly; with several, choose the format in the submenu.
  3. The plug-in creates a namespace named after the asset; duplicates get _1, _2 appended.
  4. For ma/mb the default LOD's geometry is preferred, and the dependency import policy decides where the referenced file lives.
  5. After the reference is created, confirm the entry in the Reference Editor.

Verify the result

  • A namespaced reference node appears in the Outliner.
  • The Reference Editor lists the referenced file and its namespace.
  • For ma/mb the texture paths were rewritten per the texture policy and the referenced objects display correctly.

Tips

  • When the dependency policy is 「当前资产目录」 (current asset directory) or 「源文件目录」 (source file directory) the reference points directly at files inside the .zasset; with 「拷贝到项目」 (copy into the project) they are copied to references/squirrel_asset/ in the project.
  • Referenced objects cannot be vertex- or edge-edited in the current scene; to edit them open the referenced source file or remove the reference in the Reference Editor.
  • Replacing the asset later does not refresh existing references automatically; reload them in the Reference Editor.
