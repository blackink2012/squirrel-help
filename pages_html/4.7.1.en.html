注意

This item is called 「后台渲染」 (Background render) in both the menu and the dialog title (older versions called it 「生成缩略图」 (Generate thumbnail)). It renders offscreen in a separate mayapy process, without occupying the current viewport or modifying the current scene, so you can keep working in Maya.

Which sub-libraries have it

Sub-libraryBackground render inside the context menu's update thumbnail ▶
Materials, models, lights, textures, scenes, dynamics, node treesYes
HDR, animation dataNo (update thumbnail has only 6 items)
Images, audioNot even the whole update thumbnail row

If you cannot find the item, check two things: whether the current sub-library is in the "Yes" row above, and whether background render for that sub-library is switched off in Settings → 右键菜单 (Context menu).

Two ways to run it

ModeWhereNotes
Background (headless)Context menu → update thumbnail → background renderStarts a separate mayapy process to render; good for filling in many thumbnails without interrupting your work
LocalCapture, Maya playblast, render, render on exportRuns inside the Maya process and occupies the current viewport; see the following pages

Prerequisites

  • An asset is selected in the grid; a multi-selection processes every selected item (a single selection processes the one you right-clicked).
  • mayapy must be findable on the machine; otherwise the plug-in says so and stops.
  • Material, texture and light assets have no geometry of their own, so a preset model must be chosen in the dialog as the subject to shoot.

Steps

  1. Right-click an asset card (or select several first and then right-click) and open 「更新缩略图 → 后台渲染」 (Update thumbnail → Background render).
  2. Choose the options in the background render dialog in order (each is described in the table below).
  3. Click 「开始生成」 (Start).
  4. While rendering, watch the headless job progress window (see below): it shows which asset is being processed, the percentage and the image that was just produced.
  5. When everything finishes a report appears: successes / failures, failure reasons, and which renderer, environment light and quality this batch used — for materials / textures / lights it also names the preset model.
  6. Successful items are written back as thumbnails, and grid cards and the right-hand preview refresh immediately.

During rendering: the headless job progress window

Clicking 「开始生成」 (Start) opens a non-modal progress window (it does not block your work) with three things:

  • A status line (preparing / which asset is rendering / current stage);
  • A progress bar (advancing by the number of assets in the batch);
  • A preview of the most recent image (showing "(no image yet)" before the first one);
  • 「取消」 (Cancel) and 「关闭」 (Close): Cancel really stops this batch (images already produced are kept).

Verify the result

  • The card and the right-hand preview show the new thumbnail.
  • The report lists successes and failures, with reasons for failures.
  • For material, texture and light assets the report names the preset model, renderer, environment light and quality used.

Notes

  • The original main thumbnail is overwritten: to keep the old main image, do not use background render; use 「更新缩略图 → 添加 / 截取添加」 (Update thumbnail → Add / Capture and add) to write the new image into an extra slot.
  • How to undo a bad result: capture or import another image over it. Background render only produces thumbnails and never touches the asset's geometry, materials or textures, so it cannot break the asset.
  • The size only affects future renders: old thumbnails are not redone automatically; only a new render uses the new size (see 4.7.6).
  • Options are remembered: the dialog preselects the last renderer, model, environment light, size and quality, so next time you can just click Start.
提示

「恢复默认」 (Restore defaults) only changes the options in this dialog; the values are written back to settings after clicking Start, so the new defaults appear next time.
