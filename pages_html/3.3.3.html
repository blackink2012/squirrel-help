同一批资产有两种看法：图标视图看缩略图，列表视图看名称、类型、分类与标签等字段。

切换

  1. 点视控行的「视图」按钮。
  2. 菜单里选「图标」或「列表」；菜单项本身不标勾，当前模式看按钮上的文字。
  3. 按钮上的图标与文字随当前模式变化。

图标视图

  • 卡片显示缩略图、易读名与收藏星标。
  • 拖动「缩略图」滑块调整卡片大小；Ctrl + 滚轮 也可缩放。
  • 支持框选、多选、拖动到视口或分类树。
  • 卡片按当前宽度自动排成多列，窗口变宽会加列。

列表视图

  • 列为：收藏星标、名称、资产类型、分类、标签。
  • 点星标列可直接收藏 / 取消收藏，不改变行选中。
  • 点表头按该列排序；同一列连续点击切换升 / 降序。
  • 双击行执行与图标卡片相同的双击预设，右键菜单也一致。

结果验证

  • 切换视图后，当前分类与选中状态保持不变。
  • 列表视图点「名称」表头，资产按名称排序；再点一次反向。
  • 图标视图拖滑块，卡片变大或变小，列数随之变化。

提示

  • 默认打开哪种视图在设置 →「常规 → 默认视图」里选。
  • 视图模式、排序方式与缩略图大小都会保存，下次打开保持。
