All quick tools live behind the 「快捷工具」 (Quick tools) button in the main window toolbar, and the menu lists the scripts in the plug-in's quicktools/ directory.

Purpose

The menu gathers HDR, model and PBR texture to asset conversion plus image conversion, batch processing, material tools and the script browser in one place, so you do not have to remember each script path.

Steps

  1. Click 「快捷工具」 (Quick tools) in the main window toolbar (tooltip 「快捷工具：运行 quicktools 目录里的脚本」 (quick tools: run scripts in the quicktools directory)).
  2. The menu rescans quicktools/ every time it opens and lists the .py files inside.
  3. Click an entry to open the tool window, then choose inputs, set parameters and run it there.
  4. For conversion tools, check the configured output directory afterwards for the .zasset or converted files.

Verify the result

  • The menu lists tool entries instead of 「暂无快捷工具」 (no quick tools yet).
  • Clicking an entry opens its window normally.
  • Conversion tools report success / failure counts in the status bar or a dialog, and the output directory contains the products.

Notes

  • The menu loads only .py files in the root of quicktools/ and never scans sub-directories; an entry name is the file name without .py and with underscores turned into spaces.
  • New scripts need no registration and appear the next time the menu opens (see 9.7.1).
  • A tool needs a main(), run() or if __name__ == "__main__" entry, otherwise clicking it does nothing (see 9.7.2).
  • In the standalone edition, tools that need Maya are dispatched to an online Maya; 图像格式转换工具.py and 批量镜像复制.py are pure file tools that run locally.
