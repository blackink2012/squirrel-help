One-line summary: when an asset carries several versions, LODs or variants, double-clicking the preview opens this three-column window.

Version vs LOD vs variant: what really differs

ItemVersionLOD (same asset, different detail)Variant
In one sentenceA different iteration of the same assetA different level of detail of the same assetA different form / dressing of the same asset
Typical case"Chair v1 shape → v2 restyle""LOD2 low-poly far away, LOD0 high-poly up close""The same chair: red fabric / leather / damaged"
What is storedA complete, independent set of content (geometry / materials / textures / thumbnail)Only the geometry at different detail; the rest is shared from the parent versionOnly geometry; textures and materials are shared from the asset root
How it appears in the libraryEach is an independent asset entryRows under the version or main assetA row under the asset
What you pick on importThe version you wantThe detail level you needThe form
Quantity relationshipsCan stack: a version can also hold LODsSeveral under one ownerCan coexist with versions

One-line conclusion: a version swaps the iteration, an LOD swaps the detail, and a variant swaps the form (geometry only, with shared textures and materials).

Common operations

Inspect a version's content

  1. Open the version browser.
  2. Click an entry on the left; the details card and included formats on the right follow.
  3. Use the wheel in the middle column to browse that entry's thumbnails.

Import a version / LOD / variant

  1. Select the target entry on the left (select a LOD row for a specific detail level).
  2. Click Import this version / Import this LOD / Import this variant on the right.
  3. The content is imported into the current Maya scene. You can also drag the middle preview into the viewport.

Set the default LOD

  1. Select an entry with several LODs on the left so the LOD management card appears.
  2. Click Set as default LOD after a non-default row.
  3. A "default" mark appears after that row, and later imports at default detail use it.

Append a LOD

  1. Click Append LOD… in the LOD management card on the right.
  2. Go through the append LOD detail window, see 8.11.4.

Delete

  • Deleting a version deletes all of that version's content (geometry / materials / textures / thumbnail) and cannot be undone.
  • Deleting a LOD removes only that detail level and leaves the other LODs and the version alone; every version must keep at least one LOD, so the last one cannot be deleted.
  • Deleting a variant removes only that variant's geometry and thumbnail; shared textures / materials are unaffected.

Risks and how to undo

OperationRiskUndo
Delete this versionAll content of that version is deleted and cannot be undoneThere is no undo; before deleting, use Import this version to confirm it is not the only copy, or back up the whole library
Delete this LODThat detail level is lostExport / append that LOD again
Delete this variantThat variant's geometry is lostAdd the variant again
Main versionThe main version is the asset itself and cannot be deleted hereTo delete it, delete the whole asset (through the recycle bin, restorable)

Troubleshooting

SymptomCauseWhat to do

"Import this version" does nothingThat version has no importable format, or the standalone mode is not connected to MayaCheck the Script Editor; confirm Maya is online
The append LOD button is unavailableThe current entry is not an owner that can hold LODs, or it has no LOD listTry selecting the main version / version row; for variants use the variant's own append LOD entry
The delete button is grayOnly one LOD remains, or the current entry is the main versionAdd a new LOD first, or delete the whole asset
