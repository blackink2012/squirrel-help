Deleting a version happens in the asset versions window; the entry for deleting a single LOD cannot be found in the current interface, and the context-menu delete described in older help no longer exists.

Deleting a version

Prerequisites

  • The main asset has sub-versions (V1/, V2/…).
  • Confirm the version is no longer needed; deletion cannot be undone.

Steps

  1. Select the main asset in the grid and double-click the preview on the right to open the asset versions window.
  2. Select the sub-version to delete (such as V1) in the 「版本」 (Versions) list on the left, not 「主版本」 (main version).
  3. Click 「删除此版本」 (Delete this version).
  4. Click 「是」 (Yes) in the confirmation dialog.

Verify the result

  • The version disappears from the list and its V{n}/ directory is removed entirely.
  • The main asset's meta.json drops the matching version_assets entry; with no versions left, has_versions and version_assets are cleared together.
  • The main version cannot be deleted: with 「主版本」 (main version) selected the delete button is greyed out.

Warning: the confirmation states explicitly that all content of that version (geometry, materials, textures, thumbnail) is deleted and cannot be undone. Back up the .zasset first.

Deleting a LOD

A single LOD can be deleted in the asset versions window: select the LOD entry → 「删除此 LOD」 (Delete this LOD); the button is greyed out when only one LOD is left (at least one must remain) and the main version cannot be deleted. The asset context-menu delete described in older help no longer applies.

Only when the interface cannot delete it (for example the file is locked by another program) is manual handling needed:

  1. Back up the whole .zasset first.
  2. Delete the matching lodN/ directory (N ≥ 1).
  3. Remove the entry with id lodN from the lods list in lods.json.

Warning: never delete the root node.* geometry — it is lod0; the default detail level breaks without it.

Tips

Tip: the append LOD window lets you pick a level that is already taken; confirming warns that its geometry will be overwritten, which replaces that same LOD level. To add a level, pick an empty one.
