One-line summary: build a table of "which source material attribute → which target material attribute", optionally adding a conversion function per row; saved as a preset, that table is then executed in bulk by the material conversion tool.

It never changes the scene or a material: it only reads the selected material node types and their attribute names and produces a mapping table (and a .mmap preset file). The tool that really applies the table is 8.14.9.

A complete flow

  1. Select the source material node in Maya (a VRayMtl, for example);
  2. Quick tools → Material node attribute mapping tool → click Load source material and confirm Source node type looks right;
  3. Select the target material node in Maya (an aiStandardSurface, for example) → click Load target material;
  4. Click Load defaults to fill the default value column with current target values (optional but recommended);
  5. Configure the mappings:
    • manually: click Add row, pick a source attribute and a target attribute, and choose a conversion function if one is needed;
    • or click One-click mapping in the AI area, then check each row;
  6. Use Browse attributes for attribute names you cannot type;
  7. Click Save preset and give it a name;
  8. Open the material conversion tool (8.14.9) → Load preset with that .mmap → run the batch conversion.

Where the output lands

  • The mapping table lives in the window (not on disk);
  • Save preset writes a .mmap file whose path is shown in "Preset path: …" at the bottom;
  • The table is later loaded by the material conversion tool (8.14.9);
  • This tool never changes any material in the scene.

Risks and how to undo

  • It is read-only toward the scene: it creates nothing, changes no material and touches no assignments. A wrong table causes no immediate damage — damage happens when you use it for a bulk conversion.
  • Clear table, Reverse mapping and One-click mapping all rewrite the current table with no undo key. Save preset first; if you click wrongly, Load preset reads the previous file back.
  • Save preset overwrites a same-named .mmap file, so save important tables under different names.
  • The undo path is clean: reload the old preset, or close and reopen the window (unsaved table edits are lost).
