一句话定位：把场景里一批同类型材质（如 VRayMtl）按一张映射配置转成另一种类型（如 aiStandardSurface），能自动建新材质、拷纹理、并按需替换场景里的指定。

它比「材质导入导出」更"重"：导入导出是整包搬，这个是按规则重建。所以它有两个前置文件概念：

  • 材质类型映射：哪类材质 → 哪类材质（可以在窗口里手配，也可以存成预设）；
  • 属性映射文件（.mmap）：源材质的哪个属性 → 目标材质的哪个属性，带转换函数。这个文件由 8.14.8 产出。

关于本页截图：这个工具目前没有专用截图（自动截图没有采集到它的窗口）。下面这张图是同一套 Kit 窗口的样式参照（图像格式转换工具），不是材质转换工具的界面 —— 它的真实界面以本节控件表为准。

界面上每个控件做什么

卡片「材质类型映射配置」

控件作用取值建议
映射表格每行一条：源材质类型 → 目标材质类型（双击单元格可编辑；源类型留空表示"所有材质都转成这个目标类型"）先用「加载源 / 加载目标」把两端带进来，再确认行数
「加载源」把 Maya 里当前选中的材质节点，按它的类型加进"源材质类型"列场景里选中一个源材质再点
「加载目标」把当前选中的材质节点类型设为"目标材质类型"选中一个目标材质再点
「+ 添加行」手工加一行映射（可以配多行做批量）多种源类型一起转时用
「删除选中」删掉选中的行—
「清空全部」清空整张映射表换一套转换前点；清空前先「保存预设」
「保存预设」把这张映射表存成 .mlist 预设配好就存
「加载预设」读回之前存的 .mlist—

卡片「材质信息」

控件作用
「源材质:」（未选择 / 名称）+ 类型显示当前加载到的源材质，以及有没有选中
「目标材质:」（未选择 / 名称）+ 类型显示当前加载到的目标材质

控件作用取值建议

「浏览...」选目录，工具会自动加载目录里所有 .mmap—
「打开文件夹」在资源管理器里打开该目录找文件 / 加新映射
映射状态标签「映射关系: 未加载」/「已加载 N 条映射」点转换前先看它

卡片「属性映射预览」

控件作用
页签区每个加载到的 .mmap 一个页签，切换可看该映射文件里的属性对照表和转换函数
「属性映射预览」标题让你在转换之前核对"哪个属性会写到哪个属性"

卡片「转换选项」

控件作用取值建议
勾选「复制纹理连接」转换时保留源材质的纹理贴图连接（贴图节点接过来）建议勾，否则新材质是纯色
勾选「保留原始材质」转换后不删除原材质节点，只新建目标材质第一次用建议勾，留退路；确认没问题再取消
勾选「自动应用到选择对象」转换后把新材质赋给原来用旧材质的对象想把场景整体换掉时勾
勾选「无映射→默认材质」没有对应映射文件时，创建一个基础目标材质替换源材质兜底用；不想出现"莫名的默认材质"就别勾

一次完整的转换流程

  1. 先准备映射文件：用 8.14.8 配好源/目标属性映射并「保存预设」得到 .mmap；
  2. 在 Maya 里选中一个源材质 → 快捷工具 →「材质转换工具」→ 点「加载源」；
  3. 选中一个目标材质（或直接选目标类型）→ 点「加载目标」；
  4. 确认「材质类型映射配置」表格里有一行 源类型 → 目标类型；多种源类型就再加行；
  5. 「映射文件」里「浏览...」选到 .mmap 所在文件夹，确认状态变成「已加载 N 条映射」；
  6. 在「属性映射预览」里扫一眼属性对照，确认粗糙度 / 金属度 / 法线这些关键项都映射上了；
  7. 「转换选项」：勾「复制纹理连接」；第一次先勾「保留原始材质」，先不勾「自动应用到选择对象」；
  8. 点「转换选择」小范围试：看新材质长什么样、贴图接上没有；
  9. 满意后回到场景整体：决定是否勾「自动应用到选择对象」，点「转换全部」并在确认弹窗里确认；
  10. 看批量结果弹窗里的统计（转换材质数 / 成功复制属性 / 使用默认值 / 复制纹理 / 失败属性）。

输出结果在哪

  • 新材质节点生成在当前 Maya 场景里（目标类型，如 aiStandardSurface）；
  • 勾了「自动应用到选择对象」时，原来用旧材质的对象会换成新材质；
  • 勾了「保留原始材质」时旧材质还在（方便对比 / 回退）；
  • 有转换失败的材质时，会弹出「转换失败材质列表」，里面有「在Maya中选中失败材质」按钮，可以直接定位到它们；
  • 批量结束弹出统计：转换材质数、成功复制属性数、使用默认值属性数、复制纹理数、失败属性数。

风险与反悔（转换是改场景的操作）

  • 它会在场景里新建材质、并可能改掉指定关系。做之前先 Ctrl+S 保存场景 —— 这是最可靠的反悔方式（不保存 / 重开即可回到转换前）。
  • 第一次一定先勾「保留原始材质」+ 只用「转换选择」试一个材质：属性映射配错时，新材质可能一片漆黑或全是默认值，先看结果再批量。
  • 「转换全部」会遍历场景里所有符合配置的材质，不只是你选中的那几个 —— 确认弹窗里的数字要看清。
  • 勾了「无映射→默认材质」时，没配映射的材质会被换成基础默认材质 —— 不想出现这种结果就别勾。
  • 反悔：
    • 场景没保存 → 直接不保存重开；
    • 已经保存了 → 靠「保留原始材质」找回旧材质，重新指定（或用 Maya 的撤销，见 8.1.2 里的撤销约定）；
    • 映射配错 → 回 8.14.8 改预设，重新加载再转。
