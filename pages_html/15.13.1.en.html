One-line summary: describe what you want in one sentence (or just send a reference image) and it finds the closest assets in the current library.

This is not ordinary file-name search. It first turns your sentence into intent keywords and then runs a vector search in the library with them; with use global model ticked, the understanding step is handed to the large model. That is why it can find words that are not in any name (for example "gray frosted sphere" still hits).

How to open it

Two routes open the same interface:

  1. Standalone window: top toolbar AI tools → click AI search preview assets in the menu.
  2. As a panel inside the main interface: top toolbar Panels and layout → New panel → AI search preview assets; you can also switch an existing area's header dropdown to this panel type.

Also note the AI search checkbox to the right of the main window's search box is not this window — that one searches the asset grid semantically, see 8.2.3.

Three prerequisites

  • Open an asset library first. With no library nothing typed into this window works; it reports "open an asset library before using AI search".
  • To use the large model for intent analysis: configure the global model in Settings → AI settings first, then tick use global model back in this window. Unticked also works, using only local vector retrieval (no model calls, no cost, no network).
  • To make search-by-image work: the local AI dependencies (embedding model) must be installed. On the first search the status bar shows "loading embedding model… (about 10–20 seconds the first time, seconds afterwards)", which is normal.

A complete usage flow

  1. Confirm an asset library is open on the left (the right one).
  2. Open the AI search window and type a plain sentence, for example "rusted metal sheet, large and old".
  3. If needed, click the image button to send a reference image, or the screenshot button to frame part of the screen.
  4. Press Enter (or click Send).
  5. Read the results:
    • remove clearly off-target keywords with × and it searches again automatically;
    • click Expand all ↓ when there are many results; loosen the description when there are few.
  6. Right-click the assets you like: click Import into Maya for the ones to use now, and Add to wishlist for later.
  7. Before wrapping up, use the wishlist to gather everything this project needs at once.

What you see afterwards

  • Result cards appear in the conversation area sorted by relevance, each a real asset in the library.
  • Imported assets appear in the current Maya scene (equivalent to one asset import).
  • Wishlist entries survive closing the window.
