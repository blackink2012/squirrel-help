「导入 .zasset 资产」 (Import a .zasset asset) copies .zasset assets from an external folder into the current category in bulk and gives them new asset IDs.

Prerequisites

  • A specific category is selected on the left. On 「全部资产」 (All assets) the whole 「从外部导入」 (Import from Files) menu is disabled and only the grey line 「当前分类不支持从外部导入」 (this category does not support importing from files) is shown.
  • The current sub-library is not images or audio: those two only have loose-file entries and no 「导入 .zasset 资产」 (Import a .zasset asset).
  • The external folder directly contains one or more .zasset sub-folders.

Steps

  1. Click 「从外部导入」 (Import from Files) in the toolbar above the asset area.
  2. Choose 「导入 .zasset 资产」 (Import a .zasset asset).
  3. Select the folder containing the .zasset folders in the directory dialog.
  4. The plug-in scans only the .zasset sub-directories one level down in that folder and copies them one by one into the current category.
  5. After copying it rewrites the asset IDs and redirects paths in meta.json that pointed at the source directory to the new directory.
  6. When the target category already has a same-named asset, the new name gets _001, _002 suffixes.

Verify the result

  • 「导入完成」 (import finished) appears with 「成功导入 N 个 .zasset 资产」 (imported N .zasset assets).
  • When some copies fail the same message appends 「跳过 N 个（复制失败）」 (skipped N, copy failed).
  • New assets appear in the grid and the category tree locates the import target category automatically.

Tips

  • When no .zasset is found it reports 「在选定文件夹中未找到 .zasset 资产」 (no .zasset asset found in the selected folder); check which directory level you picked.
  • Prefer this entry for migrating assets instead of copying .zasset folders by hand, which leaves assets outside the library index.
  • Metadata such as texture_map and formats in the source asset is preserved; only identity and ownership fields are replaced.
