同名冲突分两层：入库时资产重名会自动加序号，进场景时节点重名由 Maya 自动改名。

症状

  • 导入资产后，网格里出现 名字_001。
  • 场景中导入的节点名带数字后缀，与资产原名不同。
  • MCM 匹配或材质赋值时按名字找不到目标。

原因与规则

场景规则
从文件、贴图、HDR、.zasset 入库目标分类已有同名资产时，新资产名加 _001、_002
场景内导入默认放进以资产名命名的独立命名空间（重名时 _1/_2）；可在 设置 → 常规 → 导入命名空间 关闭，关闭后统一进根命名空间 :，重名节点由 Maya 自动改名
添加引用命名空间取资产名，已存在时追加 _1、_2
MCM 名称映射场景材质被 Maya 加数字后缀时，按去掉尾部数字的名字回退匹配
音频导入到时间轴同名的 sound 节点会被顶掉，插件会先给新声音取唯一名再用
图片导入同一张图多次导入会生成多个 file 节点，节点名由 Maya 自动加序号
动画数据导入按节点名 / 层级映射写入；名字对不上时不会写入（见 4.2.7.1）

处理步骤

  1. 在资产网格中确认最终资产名，需要时在右侧属性面板改名。
  2. 场景内需要固定名字时，先用 Reference 建立独立命名空间，再在命名空间内操作。
  3. 发现名字被自动加后缀时，检查是否已有同名节点或同名材质未清理。
  4. MCM 匹配失败时，先确认选中物体的拓扑，不要依赖名字匹配。

结果验证

  • 新资产名与预期一致，网格中不出现覆盖或丢失。
  • Outliner 中节点名带预期命名空间或序号。
  • 材质赋值结果与选中物体对应。

提示

  • 插件不会覆盖已有资产，也不会覆盖场景中已有节点。
  • 需要唯一名字时，先在 Maya 中清理同名节点，或改用 Reference 隔离。
