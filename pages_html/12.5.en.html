The plug-in package is self-contained: placing the single squirrel_asset_manager/ directory is enough to run it. The asset library, user settings, caches and logs live outside the package.

Plug-in package

DirectoryContent
core/Data layer: manager, .zasset read/write, export orchestration, materials and categories
ui/Main window, thumbnail grid, preview, settings and the various dialogs
integration/Maya import/export executors, format routing, texture and dependency handling
utils/Settings, JSON, screenshots, bridging and exception handling
quicktools/Standalone tools: PBR/model/HDR to asset, image format conversion, batch processing and more
ai/Maya-side command implementations (query / generate / convert / organize / scene and so on)
ai_base/Host-independent base: command registry, broker, jobs, progress, cancellation, indexing
embedded/Standalone mounting and resident warm-up
mcp/MCP server entry
dsh_plugins/Skill bundles under skills/ and dsh-side tool patches
dsh_home/Runtime dsh directory: sessions, skills, audit and job records
knowledge/Maya documentation knowledge base and releases
Assets/preset/ presets, prompt/ prompts, help/v2/ help, icons, material mappings, IBL and sample meshes
bin/Bundled ffmpeg.exe / ffprobe.exe (animated images and sequence encoding)
tools/Index, help build, license and self-check scripts

After installation it lives in Documents/maya/squirrel_asset_manager/; the README recommends the version-independent maya\ folder so one copy serves all Maya versions.

Asset library

<library root>/
├── materials/  models/  lights/  textures/  scenes/  hdr/  ani/
├── .squirrel_index_cache.json
└── .squirrel_ai_index/        # semantic search index (split per backend: official/ ollama/; can be moved to another local root)

Each .zasset is a folder asset package, typically containing meta.json, node.zmetal, thumb.sicon, thumb.aicon, thumb.mp4, node.mcm, geometry/proxy files and textures/.

Locations outside the package

PathContent
~/.squirrel_asset_manager/app_settings.json, bridge port/self-heal logs, broker boot log, Maya help cache
<package>/dsh_home/dsh runtime directory; can be moved with SQUIRREL_DSH_HOME or DSH_HOME
%TEMP%\squirrel_asset_manager\AI dependency check reports and install logs
{project}/cache/alembic/squirrel_asset/Imported abc cache
{project}/cache/squirrel_asset/Imported proxy cache

Help sources live in Assets/help/v2/pages/; toc.json, pages_html/, search/ and generated/ are build outputs and should not be edited by hand.
