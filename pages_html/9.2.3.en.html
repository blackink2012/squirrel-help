Group a set of channel-named PBR textures by material, package each material into a .zasset and detect channel types and resolutions automatically.

Purpose

Skip the manual sorting of BaseColor, Normal, Roughness and other textures, and turn Megascans, Zoo Tools or your own texture folders straight into assets.

The menu shows the script name: the quick tools menu scans the scripts in quicktools/ directly, and an entry name is the file name without .py with underscores replaced by spaces, so the menu shows pbr to zasset rather than a Chinese title. The three conversion tools map as follows: hdr to zasset = HDR to asset, model to zasset = model to asset, pbr to zasset = PBR texture to asset.

Input and output

  • Input: a folder containing PBR textures; with 「批量模式」 (Batch mode) checked pick a parent folder so each sub-folder becomes a separate asset.
  • Output: one <material name>.zasset per material, written to the input folder by default (or a separate 「输出位置」 (Output location)).
  • Inside the asset: textures stored by channel under textures/, and for several resolutions in tiers such as textures/2k/ and textures/4k/. meta.json records the properties channel mapping plus optional resolutions and default_resolution, and thumb.sicon when a thumbnail exists.

Texture naming rules

The tool recognizes textures by "underscore + channel alias", case-insensitively:

ChannelAccepted aliases
baseColorbasecolor, base_color, albedo, diffuse, col, color, base, diff
normalnormal, norm, nor, nrm, n, normalmap, nor_dx, nor_gl
roughnessroughness, rough, rgh, roughnessmap, rough_map
metallicmetal, mtl, metalness, metal_map, metallic_map
aoao, ambient, occlusion, ambient_occlusion, ao_map, occ
emissiveemissive, emit, emission, illumination, emissive_map, glow
heightheight, heightmap, height_map, bump, bump_map, disp, displacement, disp_map
  • An alias must be separated from the preceding name by _, for example wood_albedo.png; woodcolor.png is not recognized.
  • The packed maps arm / orm are treated as R=AO, G=Roughness, B=Metallic.
  • Resolution markers (_2K_, _4K_, _8K_ and so on) are stripped from the file name, and can also be expressed with sub-directories such as 2k/ or 4k/.
  • The material name is the text before the channel alias, for example brick_2K_Albedo → brick.

Steps

  1. Open 快捷工具 (Quick tools) → pbr to zasset.
  2. Click 「浏览」 (Browse) and choose the texture folder, or the parent folder in batch mode.
  3. Click 「扫描贴图」 (Scan textures) and check the material count, channels and resolutions on the right.
  4. Set the output location and adjust options as needed.
  5. Click 「转换」 (Convert).

Verify the result

  • After scanning the status bar shows the number of materials and textures found.
  • Conversion shows a summary and each material's .zasset appears in the output directory.
  • Opening an asset shows the channel paths in meta.json and the contents of textures/; the library can display the thumbnail.

Options and notes

OptionDefaultNotes
Export .zasset asset filesOnWhen off only scanning / preview happens
Batch mode (sub-folders as separate assets)OffSuits a parent directory holding several asset folders
Import into the current category after conversionOffCopies the .zasset into the current library category afterwards
Package all resolutionsOnWhen on each resolution goes into textures/<resolution>/; when off only the default resolution is packaged
Scan sub-folders recursivelyOffTurn on when textures live in sub-directories such as tex/; choose automatic recursion or specify folder names manually
ExcludeEmptyFolder names skipped during recursion, comma separated, for example Thumbs, previews
  • When no valid textures are found the status bar reports no PBR textures and suggests checking the underscores and aliases in the names.
  • Thumbnail and metadata sources are configured in Assets/preset/pbr_mapping.json, which supports {materialName} / {folderName} placeholders and JSON/TXT metadata sources.
  • Conversion needs a valid convert license.
