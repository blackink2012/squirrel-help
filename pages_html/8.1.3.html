默认情况下资产与缩略图不出本机；只有启用云端大模型、使用 Maya 在线帮助兜底，或让 dsh 连接云端模型时，相关请求才会离开这台机器。

留在本机的数据

  • 索引：文本语义索引默认在 <资产库>\.squirrel_ai_index\<official|ollama>\（按后端分家），图像索引在同目录 img\、媒体索引在 media\；设置了 ai_asset_index_dir 时，则落在该根目录下按「库 + 后端」分开的子目录。
  • 图像 sidecar：<插件目录>\.venvs\asset-vision 及其缓存。
  • 运行记录：<插件目录>\dsh_home\（dsh 会话、安装日志、复用记录）；AI 依赖报告与安装日志在 %TEMP%\squirrel_asset_manager\。
  • 在线帮助缓存：~\.squirrel_asset_manager\help_cache（目录树 7 天、页面 30 天）。

会离开本机的数据

  • 选择云端大模型时，提示词与做分析时的缩略图会发往对应服务商。
  • 本地知识库缺席或本地未命中时，「在线兜底」把查询发给 help.autodesk.com，只取公开帮助页。
  • dsh 使用哪个模型由 dsh 自己的设置决定，它可能连接云端。

凭据

API Key 保存在插件设置文件 ~\.squirrel_asset_manager\app_settings.json，不是加密保险箱，请按普通配置文件保护。AI 搜索的 Key 与全局大模型的 Key 分开存放。

建议

涉密项目里关闭云端模型，只保留本地 Ollama；需要断网时可在启动前设 MAYA_KB_ONLINE=0 关闭在线帮助兜底。
