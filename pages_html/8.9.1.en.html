First work out which layer is broken: semantic search, visual analysis and the AI assistant are three independent paths, so one being unavailable does not mean the other two are broken.

Symptoms and causes

SymptomCommon cause
「AI 服务不可用，已用关键词直接搜索」 (AI service unavailable; searched by keyword instead)Ollama is not running, the embedding model is not pulled, or the index is unavailable
AI analysis says the model does not support images, or fails outrightThe current model is text-only, or no vision model exists
The AI assistant will not open or prompts to installdsh is missing locally, or the Node version does not qualify
Cloud model errorsMissing API key, wrong endpoint or a network problem

Steps

  1. First run Settings → AI 设置 (AI settings) → AI 功能与依赖 (AI features and dependencies) → AI 依赖检查 (AI dependency check) and use the report to locate the exact layer.
  2. Ollama: confirm ollama list works and run ollama serve when needed.
  3. Missing model: use 「一键安装」 (One-click install) to add the embedding or vision model.
  4. Index problems: follow the rebuild command in the report, or see the "Missing model or index" page.
  5. dsh problems: reinstall as described in "Install guide when dsh is missing".
  6. Cloud problems: check the provider, API key, API endpoint and model name.

What still works after a fallback

  • Search falls back to keywords and tags, and asset browsing, import and export are unaffected.
  • Without AI analysis you can fill in the name, category and tags by hand.
  • Without the AI assistant you can still use the main interface's AI search and the documentation command surface.

If it still fails

Report the dependency report, the end of the relevant logs and reproduction steps together; do not reinstall the whole dependency set repeatedly.
