In the standalone edition the Maya target button in the toolbar specifies which Maya to drive when several are open, preventing automatic selection from importing assets into the wrong scene. In the current implementation the button is created only in the standalone edition while it is not attached by Maya:

FormHas the Maya target buttonWhy
Standalone edition / EXE (started on its own, not attached)YesYou need to choose which online Maya to drive
In-Maya version (the plug-in runs inside Maya)NoIt is already inside Maya, so the target is itself
Standalone attached by Maya (opened embedded from a Maya menu)NoThe target is locked to the host; offering a switch would mislead and could import into another scene

Prerequisites

  • You are using the standalone edition (not inside Maya) and it is not attached by Maya; the in-Maya and attached forms do not have this button.
  • The target Maya is running; if its bridge port is closed it is still listed but cannot be connected directly.

Steps

  1. Click the Maya target button in the standalone top toolbar; the tooltip reads "choose the Maya to drive (for several sessions; each has a window thumbnail in the menu)". (The in-Maya version has no such button.)
  2. The first menu item is 「自动选择（优先最新版本）」 (Automatic, preferring the newest version), which returns to picking a Maya by port.
  3. Every other row is one Maya: the title shows the version, the subtitle the scene name, PID and port, and a window thumbnail sits on the left.
  4. Clicking a row applies immediately, restores that Maya and brings it to the front; the choice is also written into settings (maya_target) and restored the next time the standalone edition starts.
  5. When a row reads 「Maya（未开桥接端口）」 (Maya, bridge port closed), clicking it copies the repair command to the clipboard and brings that Maya forward; paste it into its Script Editor and press Enter to open the port.

Verify the result

The currently selected instance row carries a check mark, the button tooltip appends the chosen target's version, scene, PID and port, and a read-only operation (such as the scene overview) returns the expected scene.

Tips and warnings

  • Automatic selection picks in port order, and with several sessions of the same version the first one holds the default port, so specify manually when working with several.
  • If the button is missing from the toolbar, first check which form you are in: the in-Maya version and the attached standalone edition never show it (see the table above); this is not a missing feature.
  • A minimized Maya yields no window thumbnail and the menu says why; Windows does not render minimized windows.
  • Restoring the last choice at startup does not bring Maya to the front; when that instance is offline it falls back to automatic selection and logs an explanation.
