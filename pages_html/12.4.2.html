三个预设文件分别控制右键菜单、双击缩略图和创建资产的默认导出格式，都由设置窗口写入，并按子库（asset_type）分节。

文件作用设置入口
Assets/preset/context_menu_preset.json每个子库显示哪些右键菜单项设置 → 右键菜单
Assets/preset/double_click_preset.json双击缩略图执行哪条命令设置 → 右键菜单（该页下半部分的「双击命令」分组）
Assets/preset/export_preset.json创建资产时的默认导出选项设置 → 导出默认值

设置里没有独立的「双击命令」页签；双击命令在「右键菜单」页的下半部分。

右键菜单预设

default 段是兜底，未登记的自定义子库或分类按它显示；11 个内置子库各有自己的段。每个键为布尔值，缺省即 false。

  • 通用项默认开启：import（导入）、import_geometry（导入几何体）、add_reference、favorites、select_all、duplicate、open_folder、move_to、copy_to、edit、create_asset、update_thumbnail、update_asset、delete、preview_node、ai_analysis、generate_thumbnail（后台渲染）、asset_details。
  • 专用项默认关闭，按子库打开：材质打开 apply_material、apply_material_params、convert_import；贴图打开 apply_material、create_material、import_texture、assign_texture；灯光打开 apply_light、convert_import；HDR 打开 create_dome_light、assign_texture；模型 / 场景 / 动态 / 节点树打开 convert_format。
  • 图片 / 音频 / 动画数据这三类只有通用项（收藏、复制、打开文件夹、移动到、编辑、删除、AI 分析、资产详情等）；音频额外开 convert_format（转 WAV 副本），动画数据额外开 update_thumbnail。它们各自的专属导入项不在这个预设表里，由界面按子库直接提供。
  • 文件里只列出该子库实际拥有的项，不存在的项不会显示。

导出预设

_default 提供兜底，其余键按 asset_type 覆盖。字段分四组：

  • 格式开关：zmetal、zmetal_merge、mcm、mcm_min_count、ma、mb、fbx、obj、usd、abc、arnold、vray、redshift、vrmesh。
  • 内容开关：material_only、collect_associated、textures。
  • 动画取帧：ani_frame_mode 取 current / timeline / keyframe。
  • 缩略图：delay_ms（默认 2000）与 thumb_source（screenshot / playblast / render）。

当前默认：收集关联文件与贴图均为开，缩略图来源为 screenshot；材质子库 material_only=true；动态子库 ani_frame_mode=timeline。

11 个内置子库都有段落，其中新增的几段差别比较明显：

子库段与 _default 的差别
images关闭全部几何格式（ma 也是 false）、material_only=true、collect_associated=false、只留图片相关的纹理打包
audio / animation关闭全部几何格式，material_only / collect_associated / textures 均为 false（这两类没有可导出的几何或贴图）
nodetree与 _default 基本一致（ma 开）
aniabc=true、ani_frame_mode=timeline

提示：手工改完需重新打开主窗口或重载插件；设置窗口里的改动会立即写回这些文件。
