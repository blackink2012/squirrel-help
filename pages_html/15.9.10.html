一句话定位：设置窗口左侧导航最后两个页签。「授权激活」管这台电脑能不能用；「关于」只放软件信息、反馈与合规信息。

这两页都不参与全局锁定：不用勾「解锁全部配置」也能点（激活入口必须始终可用）。

怎么打开

设置窗口 → 点左侧导航的「授权激活」或「关于」（页签竖排在窗口左边）。

1. 授权激活

当前授权

控件类型作用说明
状态徽标只读显示「已授权 / 试用中 / 宽限期 / 已到期 / 未激活」颜色随状态变化
当前状态只读文字一句话说明授权对象、剩余天数或到期状态随本机授权情况刷新
机器码只读输入框本机唯一标识，找客服或买授权时要用不可编辑
复制（机器码旁）按钮把机器码放进剪贴板—
同步授权按钮立即向服务器同步一次授权（续费 / 换机后不必等次日心跳）在线 / 离线授权都可用；离线授权只做只读登记与心跳，不会吊销或降级本机授权

激活码与状态入口

控件类型作用说明
激活码输入框输入框常驻在机器码下方有激活码时直接填这里
激活绿色按钮用输入框里的激活码联网激活；还没试用过时不填激活码，点它即开始免费试用已有授权记录 / 试用过时，输入为空会提示「请先输入激活码」
主按钮按钮随状态变化：未激活「授权管理」、试用中「购买授权」、已授权「授权管理」、已到期「续费授权」同一状态只保留一个主操作
次按钮按钮随状态变化：购买授权 / 授权管理（始终显示，不适用时置灰并在悬停提示原因）—

授权到期后的行为：浏览资产库不受影响，导入 / 导出 / 转换需要有效授权。激活与续期步骤见 2.5.2。

未授权 / 授权已到期时，启动插件仍会自动弹出「授权管理」窗口，保留一次激活机会。离线导入、解绑 / 恢复本机授权在本页「授权详情与高级操作」里也能完成（见 8.15.2）。

账号与我的授权

控件类型作用说明
未登录 / 已登录只读徽标显示当前账号状态—
登录 / 注册按钮打开账号窗口，用邮箱验证码登录仅未登录时显示
设备管理按钮打开账号窗口，查看设备、换机、领取试用仅已登录时显示（原「我的授权」入口并入这里）
退出登录按钮清除本机会话仅已登录时显示

登录是可选的：用激活码激活、或空码点「激活」领取试用都不需要登录。需要跨设备管理、换机解绑时才登录。

授权详情与高级操作

默认折叠，点标题展开；低频与危险操作都收在这里。

控件作用说明
导入离线许可证…选择 .lic / .dat / .json 离线授权文件仅支持客服手动签发的离线授权；在线激活的文件不能离线导入

控件类型作用默认 / 当前值改了会怎样

更新日志按钮拉取并显示历史版本更新说明（后台「版本管理」维护）—弹窗展示版本号 / 日期 / 说明；没有日志时提示「暂无更新日志」

常见疑问

现象说明
找不到「授权」页签原来的「授权/关于」已拆成「授权激活」和「关于」两个页签，都在左侧导航最后
机器码是灰的正常，机器码只读，用旁边的「复制」
激活码输入框一直显示正常，它常驻在机器码下方，有码直接填、点「激活」
找不到「我的授权」已并入「授权激活 → 账号与我的授权」；登录后点「设备管理」
找不到「同步授权」在「授权激活 → 当前授权」右上角；有授权记录时显示，离线授权也能点（只读登记，不会吊销 / 降级）
检查更新失败需要联网；失败提示里会写原因，也可以直接访问官网看最新版
授权到期后还能打开库吗能浏览；导入 / 导出 / 转换会被拦，需要先激活 / 续期
