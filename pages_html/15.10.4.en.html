One-line summary: the third block of the left column decides where the asset card image comes from — your own rectangle capture, a Maya playblast, or a render.

Create model and Create light are import / build-light actions: they write nothing into the asset and do not capture for you — they only give material / texture assets something visible to shoot.

Screenshot delay

It only appears in fully automatic mode, ranges from 0 to 60 seconds and defaults to 2 seconds (the factory value comes from the export preset's delay_ms). It waits before the automatic capture so the viewport can refresh and the render can settle. Heavy scenes are safer at 3–5 seconds; 0 tends to capture an unfinished frame.

Gestures when capturing with the screenshot tool

  1. After clicking Create asset a capture overlay appears.
  2. Drag a rectangle over the area you want as the thumbnail.
  3. Hold Ctrl to lock a square selection (thumbnails should be square, so holding it is recommended).
  4. Release to capture.
  5. To cancel: press Esc or right-click.

This uses the same screenshot tool as Update thumbnail → Capture, see 4.1.7.2.

A complete example (a material asset needing a demo render)

  1. The scene is empty or holds only a material sphere: confirm the current renderer (Arnold / Redshift / V-Ray) first, otherwise Create light cannot build.
  2. In the left column of the export dialog click Create model, pick a sphere or box and place it.
  3. Click Create light and choose an HDRI to build a dome light (or use existing lights).
  4. Keep the thumbnail source on Screenshot tool and frame a good angle in the viewport.
  5. Click Create asset → drag a rectangle (hold Ctrl) → release.
  6. Check the new card's image; if you dislike it, right-click the card → Update thumbnail → Capture and frame again.

Troubleshooting

SymptomPossible causeWhat to do
The thumbnail is a gray placeholderNo real image was produced this time (render / playblast failed, or the capture was skipped)Right-click → Update thumbnail → Background render (headless, see 8.12.6) or Capture again
The capture shows another object / a messy viewportThe frame was misplaced, or fully automatic mode reused the previous asset's frameRe-export with semi-automatic / single asset, or use Update thumbnail → Capture afterwards
Everything comes out blackThe scene has no lights, or the renderer is not readyUse Create light to build a dome light; for render images first confirm the renderer works
The thumbnail is tiny / blurrySettings → General → Thumbnail size is too smallIncrease it and regenerate (see 4.1.7.6)
