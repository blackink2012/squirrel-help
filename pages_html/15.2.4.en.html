One-line summary: four buttons at the right of the toolbar: refresh re-reads the asset library, Maya target decides which Maya the plug-in drives, settings opens the settings window, and help opens the help center.

How to open them

They sit on the right of the toolbar, in this order: refresh → AI tools → quick tools → panels and layout → maintenance → Maya target → settings → help (this page covers only refresh, Maya target, settings and help; the menus in between are in 8.2.5 ~ 8.2.8).

Hovering an icon shows its name, for example "Refresh material library", "Choose the Maya to drive (used when several are open; each Maya gets a window thumbnail in the menu)", "Settings (AI / font size / language / asset library…)", "Help".

Submenu: Maya target ▾

The menu rescans online Maya instances every time it opens, so a Maya that just started appears and one that just closed disappears.

Menu item / rowDescription
Auto select (prefer newest)The default. Without naming one, the plug-in picks an online Maya from the bridge ports; the check lands on the instance it selected (Maya 2025 in the example)
One row per MayaEach row shows "Maya version + scene name (an unsaved scene reads 'Unsaved scene') + PID + port", with that Maya's window thumbnail at the start; clicking the row switches the target, and the current one ends with a ✓
(No online Maya found — start Maya first, or make sure its bridge port is open)A gray hint meaning nothing was detected
Maya (bridge port not open)The process was detected but its bridge port is closed, so the plug-in cannot connect. Clicking this row does not switch the target; it copies a repair command to the clipboard and brings that Maya forward — paste and press Enter in its Script Editor to open the port

Beginner pitfalls

  • Changes did not appear after refresh: refresh rescans .zasset packages on disk and rebuilds categories, so a complete asset package you copied in by hand does show up; but loose files (unpacked images / models / textures) do not become assets this way and need the import flow, see 4.1.3.5.
  • Cannot find "Maya target": you are in the Maya-embedded edition or a host-mounted standalone edition, so the target is fixed and cannot be switched here.
  • Switched Maya but assets still import into the other one: check which row carries the ✓; the plug-in only uses that row's port. After switching, look at the status bar or export a test asset to confirm.
  • Clicking Settings does nothing: it may already be open elsewhere (non-modal singleton); clicking again brings it forward instead of opening a second one.
