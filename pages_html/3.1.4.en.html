The asset area in the middle is where you work day to day: a view-control row on top and the assets of the current category below, as icon cards or as a list.

The view-control row

From left to right:

  • The 「从外部导入」 (Import from Files) dropdown: its contents change with the current category (see the table below); on 「全部资产」 (All assets), favorites or the recycle bin the whole button is disabled.
  • 「创建资产」 (Create asset): export the object selected in Maya as an asset.
  • The 「音乐播放」 (Music playback) dropdown (only when the 「音乐」 (Music) category has audio): play / pause, previous / next and playback mode.
  • Breadcrumb: shows the current location (All assets › sub-library › category …); click an earlier segment to jump back.
  • 「编辑标签」 (Edit tags): opens the tag editor to filter by tag.
  • The 「视图」 (View) button: its label shows the current mode (「图标」 (Icons) or 「列表」 (List)); click to switch.
  • The 「名称」 (Name) button (sorting): its label is the current sort key; click to choose the sort field and ascending / descending.
  • The 「缩略图:」 (Thumbnail:) slider: adjusts card size; in icon view you can also zoom with Ctrl + wheel.

The asset count is not on this row; it is in the status bar at the bottom (材料: 可见数/总数, materials: visible / total).

All assets / Favorites / Recycle binButton disabled; the 「从外部导入」 (Import from Files) submenu of the empty-area context menu shows a grey line: 「当前分类不支持从外部导入」 (this category does not support importing from files)

The menu is trimmed by top-level sub-library: to import something, first select the specific sub-library or category in the left column so the plug-in knows where the asset should land.

Cards and list

  • Icon view: each card shows the thumbnail, the display name and a favorite star; selected cards are highlighted and hovered cards get an outline.
  • List view: columns are the favorite star, name, asset type, category and tags, which makes metadata easy to check.
  • Single-click selects, double-click runs the current sub-library's double-click preset, and the context menu opens the asset menu; drag a card into the Maya viewport or onto the category tree.
  • Right-click empty space to create an asset, paste or import; drag on empty space to marquee-select.

Verify the result

  • After switching category the grid shows only that category's assets and the count in the status bar changes accordingly.
  • Switching 「视图」 (View) toggles the same assets between cards and a table, keeping the selection.

Tips

  • Double-click behavior differs by sub-library: models / scenes / dynamics / node trees import ma, materials import zmetal, textures create a PBR material, HDR creates a dome light; images create a file node, audio imports to the timeline, and animation data goes through hierarchy mapping. You can change it per sub-library in Settings → 右键菜单 (Context menu) → 双击命令 (Double-click command).
  • A card with no thumbnail shows a placeholder; capture one in the preview panel, or use 「更新缩略图 → 后台渲染」 (Update thumbnail → Background render).
