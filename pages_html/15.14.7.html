一句话定位：把一个场景里调好的材质网络导成文件（.zmetal 或 MA+JSON），再在另一个场景里导回来并自动指定给对应模型。

它解决的是"材质要跨场景 / 跨机器搬"这件事。两个页签是两种产物格式，能力一样、格式不同：

页签产物适合什么情况
全频雷达版完整材质网络 → .zmetal（可选带 .ameta 元数据、.mcm 物体映射、贴图文件夹）只想搬材质，用插件自己的格式
MA+JSON 版材质网络 → Maya .ma 脚本 + .json 数据对方不装插件 / 想用原生 MA 还原

从哪打开

入口具体怎么做
顶部工具栏「快捷工具」菜单「快捷工具」→「材质导入导出工具(材质管理)」
脚本浏览器「脚本浏览器」→ 添加插件目录下的 quicktools 目录 → 材质导入导出工具(材质管理).py 双击运行

窗口标题是「材质导入导出工具」，两个页签在窗口顶部。

通用前提

  • 导出前先在场景里选好要导的东西（模型或材质都可以，看下面选项）；
  • 导出的文件会写到「工作目录」，所以先定工作目录；
  • 导入前先把场景准备好（MA+JSON 版窗口顶部那行红字就写着：「>> [重要] 请确保当前场景里已经有需要被赋值的模型！」）。

页签一：全频雷达版（.zmetal）

卡片「导出 - 基础设置」

控件作用取值建议
「工作目录:」+ 「浏览」导出文件存哪一个专用目录，别跟工程文件混放
「文件名:」输入框（占位「留空使用默认命名」）导出的文件名（不含扩展名）留空 = 按当前时间命名，不容易撞名

卡片「导出 - 选项」

控件作用取值建议
「导出模式:」单选「导出所选」/「导出所有」只导当前选择的，还是导场景里全部材质默认「导出所选」；导全场景时确认场景干净
勾选「选择的是材质」当前选中的是材质节点而不是模型时勾上选材质时必须勾，否则会提示"所选对象没有关联的材质"
勾选「材质单独文件」每个材质生成一个独立文件，而不是打包成一个想之后单独挑某个材质导入时勾
勾选「导出物体映射」（默认勾）额外生成 .mcm，记录材质与模型的对应关系建议保持勾，导入时才能自动指定回模型
勾选「导出元数据」（默认勾）额外生成 .ameta，记录版本 / 渲染器 / 色彩空间 / 分类 / 标签等建议保持勾
勾选「创建文件夹」每个材质建独立文件夹（内含材质文件 + 元数据 + textures/）材质多、贴图多时推荐
勾选「打包纹理」把材质连接的贴图拷进 textures/ 并把路径改成相对路径换机器必勾，否则对方缺贴图
「执行导出」开始导出—

可折叠「导出 - 元数据设置 ►」（点了才展开）

控件作用取值建议
色彩空间写进元数据的色彩空间（默认自动检测，如 ACEScg）自动检测对就别改
分类材质的分类信息（如 金属/布料/皮肤）给材质库管理用，可留空
标签逗号分隔的标签同上
中文名材质的中文名称，留空用英文原名团队有中文命名规范时填
命名空间引用模型时自带的前缀（如 ns1）有引用命名空间时填
原模型前缀 / 后缀导出时模型路径的前缀 / 后缀导入时要做路径替换才需要填
新模型前缀 / 后缀导入时要替换成的路径前缀 / 后缀同上

可折叠「导入 - 基础设置 ►」

控件作用取值建议
命名空间给导入的材质加命名空间，避免重名场景里已有同名材质时填一个
材质前缀 / 后缀给导入的材质名加前后缀，避免冲突反复导入时有用
原模型前缀 / 后缀导出时的模型路径前后缀与导出侧对应
新模型前缀 / 后缀导入后要替换成的模型路径前后缀与导出侧对应
「执行导入」选文件并导入—
「从文件夹导入...」递归导入文件夹里所有材质文件批量还原时用

卡片「导入 - 选项」

控件作用取值建议
「导入模式:」单选「导入所选」/「导入所有」只导入文件里选中的材质 / 全部导入默认「导入所有」
勾选「自动指定物体」（默认勾）按 .mcm 映射把材质指定给对应模型建议勾，否则只有材质没有指派
勾选「模糊匹配」精确匹配失败时，按名称子串包含关系匹配模型名在导出/导入后变了（如多出 _temp）时勾
勾选「拷贝纹理」（默认勾）把贴图拷到当前工程的 sourceimages换成"用相对路径"时取消勾选
「执行导入」选文件导入—
「从文件夹导入...」选文件夹递归导入批量时用

页签二：MA+JSON 版

结构基本一致，差别是产物与部分选项：

区域控件说明
顶部红字提示「>> [重要] 请确保当前场景里已经有需要被赋值的模型！」导入前必须有可被赋值的模型
导出 - 基础设置工作目录 / 文件名文件名留空按时间命名

底部按钮（两个页签都有）

按钮作用
「ℹ 使用帮助」打开当前页签对应的详细帮助窗（全频雷达版 / MA+JSON 版各一份说明）
「关闭」关窗（已导出的文件不受影响）

一次完整的导出 → 导入流程

  1. 快捷工具 →「材质导入导出工具」；
  2. 选「全频雷达版」页签（或 MA+JSON 版，按对方需不需要装插件决定）；
  3. 「工作目录」选一个空目录；
  4. 回到 Maya 选中要导的模型（或材质，并在「导出 - 选项」里勾「选择的是材质」）；
  5. 决定导出模式（默认「导出所选」），把「导出物体映射」「导出元数据」保持勾上；要换机器就勾「打包纹理」；
  6. 点「执行导出」，等提示；
  7. 去工作目录确认产物：.zmetal（+ .ameta / .mcm / textures/），或 .ma + .json；
  8. 换到目标场景：先把要赋材质的模型准备好；
  9. 展开「导入 - 基础设置 ►」，必要时填命名空间 / 前后缀；「导入 - 选项」里保持「自动指定物体」勾上；
  10. 点「执行导入」（或「从文件夹导入...」批量），确认材质出现在场景里且已指定给模型。

输出结果在哪

  • 导出：文件写进「工作目录」，文件名来自「文件名」输入框或默认时间戳；
  • 导入：材质节点出现在当前 Maya 场景的材质编辑器里，并在勾了「自动指定物体」时赋给对应模型；
  • 勾了「打包纹理」时贴图在材质的 textures/（或导入时拷到工程 sourceimages/）。

风险与反悔

  • 导出会直接覆盖同名文件：工作目录里已有同名 .zmetal / .ma / .json 时会被写掉，没有任何提示。留空文件名（按时间戳命名）能避免大多数撞名；或每次导出换一个工作目录。
  • 导入会往场景里加材质节点并改指定关系：做之前先把场景存一下（Ctrl+S），改坏了直接不保存 / 重开。
  • 导入时的「自动指定物体」依赖 .mcm 映射；模型名变了就勾「模糊匹配」，但模糊匹配可能配错人 —— 大批量导入前先拿一两个试。
  • 反悔：导出错了 → 覆盖的工作目录文件拿不回来（下次把导出目录单独分开）；导入错了 → 不保存场景重开。
