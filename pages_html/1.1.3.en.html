Squirrel Asset Manager covers storing, finding, viewing, editing, importing and exporting Maya assets; it is not a modeling, rendering or cloud collaboration platform.

What it can do

CapabilityWhat it covers
Asset management11 sub-libraries: materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees; categories, tags, favorites, project libraries
ImportImport geometry, materials, textures, HDRs, lights, scenes and animation from external files, folders or the library; images can become a file node, an imagePlane or a texture slot assignment, audio can go to the timeline, the Time Editor, Trax or the camera sequencer, and animation data can be imported with hierarchy mapping
ExportSingle asset, batch full-auto, batch semi-auto; supports .ma, .mb, .fbx, .obj, .abc, .usd, .glb, .ass, .vrmesh, .rs, .zmetal, .mcm and more
ThumbnailsCapture, Maya playblast, render, import an image; headless batch rendering in the background; multiple thumbnail slots and output sizes
Media searchUpload an image, video or audio file to find visually or acoustically similar assets; screen-capture and screen-recording search; under audio you can record the sound the system is playing (not the microphone)
Audio and animation dataAudio cards can be auditioned and imported to the timeline; animation data can be imported and exported with hierarchy-to-attribute mapping
Batch operationsMove, copy, delete, rename, and edit tags and fields in batches
Versions and LODsCreate a new version, append a LOD, switch version or LOD, per-version materials
Materials and lightsCross-renderer material conversion, attribute mapping, material matching, applying material and light parameters, creating a dome light
AIThumbnail analysis, category/tag/Chinese-name suggestions, natural-language search, search by image, semantic index
Maya integrationScene read/write, screenshots and renders, native tools, headless batch processing, MCP / external AI access
Quick toolsPBR, model and HDR to asset conversion, image format conversion, batch mirror copy, material conversion and more

What it cannot do

  • No modeling, sculpting, rendering or animation: those stay with Maya and its plug-ins.
  • Not a cloud asset marketplace: there is no online hosting, account system, comment backend or asset trading.
  • The standalone edition cannot edit the scene without Maya: when Maya is offline you can only browse, search and run file-level operations.
  • AI is optional: it needs a local Ollama or a cloud model you configure; without it those features are unavailable, while core browsing and management keep working.
