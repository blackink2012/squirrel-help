Node formats store the connection network of materials or lights, while geometry formats store model files that can be imported again; both can be checked together and neither replaces the other.

Node formats

FormatContentsNotes
材质预设 .zmetal (material preset)Maya material node network (JSON)Material assets normally check this; with "write all materials into one .zmetal" checked they merge into one file, and unchecked with material nodes selected it writes one file per material
灯光预设 .zlight (light preset)Renderer-independent light parameters plus upstream texture, IES and HDR nodesShown in the lights sub-library; the merge sub-option is not shown
材质映射 .mcm (material mapping)Material → model mapping: vertex / face / edge counts, object list, per-face material assignmentsAn independent option that does not depend on .zmetal; on import models are matched by topological signature and receive the material

.mcm matching requires the target model's vertex, face and edge counts to be exactly those at export; triangulation, point merging or topologies changes make matching fail.

Native Maya export

Geometry files are always named node.<extension> and placed in the .zasset root; several formats can coexist. For .ma / .mb export the shadingEngine associated with the materials is included in the selection set, so networks such as displacement are not lost.

Why some formats are greyed out

Geometry and proxy formats are locked by current category: formats that do not apply to the category are greyed out and cannot be checked, with the tooltip 「该格式不适用于当前分类，已锁定（可在 设置 → 导出默认值 中调整）」 (this format does not apply to the current category and is locked; adjust it in Settings → Export defaults). Default rules:

CategoryFormats locked by default
Materials / lightsFBX, OBJ, USD, Alembic and all proxy formats (such assets have no geometry)
Textures / HDR / images / music / animation dataAlmost every node and geometry format (they are files or pure transform data)

To change the locks, go to Settings → 导出默认值 (Export defaults) and turn off that format's lock (see 6.4.1).

Relationship with "export materials only"

With 「仅导出材质（跳过几何体/代理）」 (export materials only, skipping geometry / proxies) checked, fbx, obj, usd, abc and every proxy format are skipped; ma / mb can still be exported, but they contain only material nodes and no model meshes.

Tips

Tip: when only materials are needed prefer .zmetal + 贴图 textures/ (textures); add geometry formats only when the model should travel with them.

Tip: proxy formats (.ass / .rs / .vrscene / .vrmesh) are renderer products and not among the geometry formats on this page; see "Animation, caches and proxies".
