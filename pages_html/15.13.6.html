一句话定位：点「AI 助手」时，如果本机没有检测到可用的 dsh 运行时，就会弹这个窗口告诉你缺什么、怎么装。

dsh（DeepSeek Harness）是插件内置 AI 对话面所依赖的运行时，它不是一个 Python 包，而是一个 Node 程序。所以"装 AI 助手"这件事本质上是装 Node + 装 dsh，这个窗口就是这两步的引导页。

什么时候会弹

  • 顶部工具栏「AI 工具」→「AI 助手」；
  • 本机找不到可用的 dsh 运行时 → 自动弹出本窗口，AI 助手起不来。

窗口上有什么

区域 / 控件内容或作用怎么用
警告图标 + 摘要「本机没有检测到可用的 dsh 运行时，AI 助手无法启动。」说明问题，不是错误弹窗
「安装（需要 Node ^22.19 或 >=24（推荐 24 LTS））：」依赖的 Node 版本要求（界面写作 `^22.19>=24`）自己装的话按这个版本装
安装命令（一块可选中复制的只读文本）一条 npm i -g --prefix ... 命令，路径指向本插件的运行时目录点下面的「复制安装命令」拷走，粘到终端里跑
「装完后回到 Maya，再点一次 AI 助手即可。」手动安装后的收尾动作装完回来重点一次 AI 助手
「想看详细步骤…点下面的「打开安装帮助」」引导到完整文档命令跑不通时看它
按钮「复制安装命令」把上面那条命令复制到剪贴板（会弹 Maya 内提示「安装命令已复制到剪贴板」）手动安装路线第一步
按钮「打开安装帮助」打开本机随包的安装帮助页（分平台命令、验证方法、常见问题、官方链接）排错首选
按钮「打开官网」浏览器打开 dsh 官网—
按钮「打开 GitHub」浏览器打开 dsh 仓库想看源码 / 版本说明时
按钮「关闭」什么都不做直接关掉窗口现在不想装
按钮「一键安装（推荐）」由插件自动装：准备便携 Node + npm 拉 dsh 依赖大多数人的正确选择

一次完整的安装流程（推荐路线：一键安装）

  1. AI 工具 →「AI 助手」，弹出本窗口；
  2. 点「一键安装（推荐）」；
  3. 会出现一个进度窗口（不挡 Maya，安装期间可以继续干活）：
    • 标题「正在安装 dsh 运行时」；
    • 说明文字里有完整日志的路径（<dsh_home>/dsh_install.log）；
    • 有实时滚动的日志区，卡在哪一步能看见；
    • 有「取消」按钮；
  4. 等它跑完（要联网，通常 1–5 分钟，网络慢会更久）；
  5. 成功：进度窗口显示「dsh 运行时已就绪，正在打开 AI 助手…」，AI 助手面板自动打开；
  6. 失败：窗口会显示失败原因，并提示"可改用「复制安装命令」手动装，或点「打开安装帮助」看分步说明"。

手动安装路线

适合以下情况：一键安装失败、公司网络限制 npm、想自己管 Node 版本。

  1. 在本窗口点「复制安装命令」；
  2. 打开终端（cmd / PowerShell 都行），粘贴并执行；
  3. 命令里的 --prefix 已经指向本插件期望的运行时目录，不要自己改路径，否则插件还是找不到；
  4. 装完回 Maya，再点一次「AI 助手」；
  5. 还不行就点「打开安装帮助」，对照分平台步骤和验证方法排查。

做完能看见什么

  • AI 助手面板能正常打开（面板本身见 8.8.2）；
  • 再点「AI 工具」菜单时，「AI 助手」那一项的文字会随状态变化（开启 / 关闭 / 启动中）；
  • 安装日志落在 <dsh_home>/dsh_install.log，出问题拿它去反馈。

风险与反悔

  • 一键安装会联网下载（便携 Node + 依赖包，几百 MB 量级），流量/时长请自己评估。
  • 安装期间可以取消：取消只停止后续步骤，已经装好的部分会保留；下次再点「一键安装」会从缺的地方继续补。
  • 安装不碰你的资产库、不碰 Maya 场景，也不会改插件设置；反悔的话把 <dsh_home> 目录删掉即可回到"没装"的状态（AI 助手会重新提示安装）。
  • 别在安装进行中重复点「一键安装」—— 会提示「已有一个安装在进行中，请等它结束或取消」。
