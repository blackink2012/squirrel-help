一句话定位：一个资产下面如果挂了多个版本、多条 LOD 或多个变体，双击预览图打开的就是这个三栏窗口。

怎么打开

入口操作前提
双击右侧预览图双击右侧「预览」面板里的图片该资产有版本或变体
资产右键菜单右键资产 →「资产详情」同上（有版本/变体时走这个窗口）

只是想「进入版本/变体文件夹」在网格里翻：用右键 →「查看版本 / 查看变体 / 查看 LOD 管理」，那是在网格里展开，不会打开本窗口。

三栏结构

栏内容怎么用
左栏 · 列表主版本、各版本、各变体，以及它们各自的 LOD 行单击切换；带 LOD 的条目会展开成多行
中栏 · 预览大预览图 + 下方多缩略图条滚轮换图、点缩略图切换；图可直接拖出窗口导入 Maya
右栏 · 信息标题卡（名称/面包屑/角标）、详情卡、LOD 管理卡、包含格式卡、标签卡、注释卡、路径卡只读；LOD 管理卡里有「设为默认 LOD」「删除此 LOD」「追加 LOD…」
右栏 · 按钮导入此版本 / 删除此版本 / 关闭（选中 LOD 或变体时按钮文字会变）见下

按钮文字会随当前条目变：

当前选中的是按钮文字
主版本 / 普通版本导入此版本、删除此版本
LOD 行导入此 LOD、删除此 LOD
变体行导入此变体、删除此变体

版本 vs LOD vs 变体：到底差在哪

项目版本（Version）LOD（同资产不同精度）变体（Variant）
一句话同一个资产的不同迭代同一个资产的不同精细度同一个资产的不同形态/换装
典型场景「椅子 v1 造型 → v2 改款」「远景用 LOD2 低模、近景用 LOD0 高模」「同一把椅子：红色布面 / 皮面 / 破损版」
存什么独立完整的一套内容（几何/材质/贴图/缩略图）只存不同精度的几何；父版本其余内容共用只存几何体，贴图与材质共享资产根目录的
在库里怎么显示各自是独立资产条目挂在版本或主资产下面的行挂在资产下面的一行
导入时选哪个选你要的那一版按需要选精度选形态
数量关系可以叠加：一个版本下也能有 LOD一个 owner 下多条与版本可并存

一句话结论：版本 = 换一版；LOD = 换精度；变体 = 换形态（只换几何，贴图材质共用）。

常用操作

看某个版本的内容

  1. 打开版本浏览器。
  2. 左栏点条目；右栏详情卡与「包含格式」随之切换。
  3. 中栏滚轮可看该条目的多张缩略图。

导入某个版本 / LOD / 变体

  1. 左栏选中目标条目（要特定精度就选到 LOD 行）。
  2. 点右栏「导入此版本 / 导入此 LOD / 导入此变体」。
  3. 内容导入当前 Maya 场景。也可以直接把中栏预览图拖进视口。

设为默认 LOD

  1. 左栏选中带多条 LOD 的条目，让右栏出现「LOD 管理」卡。
  2. 在非默认的那条后面点「设为默认 LOD」。
  3. 该行文字后出现「默认」标记；下次按默认精度导入时就用它。

追加 LOD

  1. 右栏 LOD 管理卡点「追加 LOD…」。
  2. 走「追加 LOD」档位窗，见 8.11.4。

删除

  • 删除版本：连同该版本全部内容（几何/材质/贴图/缩略图）一起删，不可撤销。
  • 删除 LOD：只删这一档精度，其它 LOD 与版本不受影响；每个版本至少要留一条 LOD，最后一条删不掉。
  • 删除变体：只删该变体的几何与缩略图，共享的贴图/材质不受影响。

风险与反悔

操作风险反悔
删除此版本该版本内容全部删除，不可撤销没有撤销；删前先「导入此版本」确认不是唯一一份，或整库备份
删除此 LOD该精度丢失重新导出/追加该档 LOD
删除此变体该形态几何丢失重新添加变体
主版本主版本就是资产本身，不能在这里删要删请删整个资产（走回收站，可还原）

出问题怎么办

现象原因处理
双击预览图只打开资产详情该资产确实没有版本/变体用右键「更新资产 → 创建新版本 / 添加为新变体」先建一个
「导入此版本」没反应该版本无可导入格式，或独立运行模式未连 Maya看脚本编辑器；确认 Maya 在线
追加 LOD 按钮不可用当前条目不属于可写 LOD 的 owner，或条目没有 LOD 列表选主版本/版本行再试；变体请用变体自己的「追加 LOD」入口
删除按钮灰着只剩一条 LOD，或当前是主版本先加一条新 LOD，或删整个资产
