For a failed import, read the Script Editor log first, then check item by item whether the format exists, the license is valid and the file is readable.

Symptoms

  • Right-clicking 「导入」 (Import) adds nothing to the scene.
  • The log says "import failed", "unknown format", "extraction failed" or "no .zmetal / .zlight / .mcm".
  • A license prompt appears during the import.
  • The 「从外部导入」 (Import from Files) button is greyed out (you are on 「全部资产」 (All assets), favorites or the recycle bin with no target category).
  • Dropping images or audio into the viewport does nothing; importing a node tree shows nothing in the scene; importing animation data leaves the model unmoved.

Common causes and fixes

Log or symptomCauseFix
[ImportExecutor] 未知格式 (unknown format)No file of that format inside the asset, or the format name is not in the routing tableChoose another format in the context menu; confirm a file with that extension really exists in the .zasset
[FileImporter] 提取失败 (extraction failed)Files inside the package are missing or cannot be extractedRe-export from the source files, or re-import the asset from a backup
[ImportExecutor] .zasset 不含 .zmetal 文件 (the .zasset contains no .zmetal file)The asset was exported by a quick tool and has no node networkUse 「应用材质到选中」 (Apply material to selection) or the ma/mb materials inside the asset
[Licensing] 功能 'import' 被拒绝 (feature 'import' denied)The license expired or is invalid, so import is gatedActivate or renew, then retry
fbx does nothingThe fbxmaya plug-in is not loadedLoad it in Maya's plug-in manager and retry
Proxy or volume formats do not displayThe matching renderer plug-in is not installedInstall Arnold, V-Ray or Redshift and retry
The import-from-files button is greyed out / the menu only says "this category does not support importing from files"You are on All assets, favorites or the recycle bin with no concrete target categorySelect a specific sub-library and category in the left column first
Dropping images or audio into the viewport does nothingThese are loose files and not part of the geometry drag pipelineUse the context menu: images → import as file node / create imagePlane; audio → import to timeline and so on (see 15.5.9, 15.5.10)
Animation data imports but the animation does not changeThe scene has no hierarchy matching the asset, so automatic mapping failsUse 「导入动画（层级映射）…」 (Import animation (hierarchy mapping)…) to point at the nodes, or select the target hierarchy and use 「导入到选择属性」 (Import to selected attributes)

Verify the result

  • After changing the format the log says 「导入成功」 (import succeeded) and the Outliner shows new nodes.
  • Once the license is restored the same action no longer reports a denial.

If it still fails

  1. Confirm the .zasset directory really contains a file of that format and that its size is not 0.
  2. For images and audio, first confirm the asset file exists (loose files sit in the category directory), then check that you used the matching import entry.
  3. Import using another format to tell whether the problem is one file or the whole import path.
  4. Report the full log together with the asset name; the traceback in the log points at the specific importer.
