The 「项目」 (Projects) tab manages the asset library dedicated to the current Maya project, always at SquirrelLib under the project root.

What the panel contains

  • 「创建」 (Create) in the toolbar: creates SquirrelLib, its sub-library folders and metadata in the project root; only needed when the project library does not exist.
  • 「刷新」 (Refresh) in the toolbar: rescans the project library. After switching Maya projects the new path is not discovered automatically, so refresh manually.
  • Status area: shows the full project library path, or 「项目库未创建」 (project library not created).

Using it

  1. Switch to the 「项目」 (Projects) tab and the plug-in tries to load SquirrelLib; if it is missing the grid is emptied with a hint.
  2. Click 「创建」 (Create) to generate the project library, then create categories and import assets exactly as in the main library.
  3. Click 「刷新」 (Refresh) to reload the current project's library and restore the previously selected category.

Relationship with the main library

The two libraries are fully isolated: categories, assets and favorites are stored separately. To reuse an asset across libraries, 「复制」 (Copy) in the main library, switch to the 「项目」 (Projects) tab and 「粘贴」 (Paste); assets in the project library never appear under 「全部资产」 (All assets) of the main library.

The project tree also supports creating, editing, moving and deleting categories and dragging assets, exactly like the main library.

Tips

  • When the project library does not exist, do not create an empty directory by hand; 「创建」 (Create) writes library.json and the sub-library metadata as well, so the category tree can recognize the types correctly.
