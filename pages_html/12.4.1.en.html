Assets/preset/config.json is the plug-in's shared structural configuration. It decides sub-libraries, default categories, format detection, tags and colors, and a change affects every machine using this plug-in directory.

Location and writes

The file is at <plugin package>/Assets/preset/config.json and the current schema version is "1.0". The General (asset library management group), Supported formats, Texture suffixes and Sub-libraries and categories pages of the settings window write their results back here. Personal preferences (font size, theme, library paths, AI keys) are not here but in ~/.squirrel_asset_manager/app_settings.json.

Editing notes

  • Manual edits must stay valid JSON; back up first, then reopen the main window or reload the plug-in afterwards.
  • Adding a sub-library is not just one line: you also need the matching asset folders and a category sync in the settings window.
  • Unknown keys are ignored without an error; a misspelled key silently does nothing.

Warning: This is shared configuration, not personal settings. When several machines share one plug-in directory, a change affects every other user too.
