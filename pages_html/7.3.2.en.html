An attribute mapping can be saved as an .mmap preset, loaded again next time and reused by the material conversion tool.

Prerequisites

  • The source / target node types are loaded in the mapping tool and the mapping rows are filled in.
  • Write access to the plug-in directory Assets/material_mapper_presets.

Steps

  1. Click 「保存预设」 (Save preset); the tool names the file source node type_target node type by default and saves it to Assets/material_mapper_presets.
  2. When the file name does not end in .mmap the tool appends it; the saved content includes source_type, target_type, created_date and the complete mappings.
  3. Next time click 「加载预设」 (Load preset), choose the .mmap, and the tool restores the source / target types and all mapping rows.
  4. For a reverse mapping click 「反向映射」 (Reverse mapping); the tool swaps the source / target node types and attributes and tries to replace transform functions with their reverse counterparts.

Verify the result

After reloading, the source / target node types and the row count match what was saved; after placing that .mmap in the material mapping directory, 「浏览...」 (Browse...) in the material conversion tool finds and loads it.

Tips

  • Closing the window saves the current configuration to _last_preset.mmap automatically and restores it next time.
  • For the conversion tool to find a mapping automatically by "source → target", the file must be named source type_target type.mmap and live in Assets/material_mapper_presets.
  • What is saved is an attribute rule, not a material instance; changes to a preset only take effect after converting again.
