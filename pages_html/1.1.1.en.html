Squirrel Asset Manager is a local asset management tool that runs inside Maya. It keeps materials, models, lights, textures, scenes, HDRs, dynamics, images, audio, animation data and node trees in one library you can search and import into the scene.

Positioning

  • Built for Maya workflows: it is not a modeling or rendering application; it gathers the assets scattered across hard drives, project folders and many Maya files into one reusable library.
  • Local first: assets live as ordinary folders and .zasset packages under the library path you choose, with no cloud dependency by default; the library can sit on this machine, a LAN share or a project drive.
  • A folder is an asset: every .zasset is a folder containing meta.json, the material or geometry files, thumbnails, textures/ and other dependencies, so it can be copied, zipped and backed up directly.
  • Two run modes: the Maya plug-in edition runs inside the Maya process; the standalone edition / EXE starts on its own and drives a running Maya through the local commandPort.

Which problems it solves

It solves the problem of assets accumulated while working in Maya being hard to manage, and of reusing assets while a project is running. It brings "find assets, view thumbnails, organize categories and tags, batch add to library, export assets, cross-renderer conversion, version and LOD management" into one window, so you no longer switch back and forth between the file browser and Maya.

Main capabilities

Eleven built-in sub-libraries: materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data and node trees. Around them it offers categories and tags, thumbnails (including headless background rendering), batch operations, versions and LODs, material conversion, AI analysis and semantic search, search by image / video and by sound, quick tools, and Maya scene read/write.

Fit and boundaries

It suits individuals and teams that accumulate and reuse Maya assets over time. It is not a cloud asset marketplace: there are no accounts, comments or online hosting; AI features need a local Ollama or a cloud model you configure; after the license expires you can still browse, while import, export and conversion are restricted.
