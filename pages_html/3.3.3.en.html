The same assets can be viewed two ways: icon view shows thumbnails, list view shows fields such as name, type, category and tags.

Switching

  1. Click the 「视图」 (View) button in the view-control row.
  2. Choose 「图标」 (Icons) or 「列表」 (List); the menu items are not check-marked, and the current mode is shown by the button label.
  3. The icon and label on the button follow the current mode.

Icon view

  • Cards show the thumbnail, the display name and a favorite star.
  • Drag the 「缩略图」 (Thumbnail) slider to change the card size; Ctrl + wheel also zooms.
  • Supports marquee selection, multi-selection, and dragging to the viewport or the category tree.
  • Cards wrap into as many columns as the width allows, and widening the window adds columns.

List view

  • The columns are: favorite star, name, asset type, category, tags.
  • Clicking the star column adds or removes a favorite without changing the selected row.
  • Clicking a header sorts by that column; clicking the same column again toggles ascending / descending.
  • Double-clicking a row runs the same preset as the icon card, and the context menu is the same.

Verify the result

  • Switching views keeps the current category and selection.
  • Clicking the 「名称」 (Name) header in list view sorts assets by name; clicking again reverses it.
  • Dragging the slider in icon view makes cards larger or smaller and changes the column count.

Tips

  • Choose the default view in Settings → 常规 → 默认视图 (General → Default view).
  • The view mode, sorting and thumbnail size are all saved and restored on the next start.
