多选遵循 Windows 资源管理器习惯：Ctrl 点选切换单项，Shift 点选连续范围，空白拖动框选。

鼠标多选

操作结果
Ctrl + 单击切换这一张的选中状态，其余选中保留
Shift + 单击从锚点到这一张的范围加入选中，锚点不动
Ctrl + Shift + 单击同上，范围加入已有选中
空白处拖动框选；无修饰键 = 替换选中，Ctrl / Shift = 加选
空白处单击无修饰键 = 清空；Ctrl / Shift = 保留已有选中

锚点是上一次普通点击或 Ctrl 点击落在的卡片；连续 Shift 点击会在同一段上伸缩，不会从头重新量。

键盘多选

  1. 点进资产网格，把键盘焦点交给网格。
  2. 方向键移动焦点并选中；Shift + 方向键 扩展范围；Ctrl + 方向键 只移动焦点、不改选中。
  3. Ctrl + A 全选；Ctrl + F 把当前选中滚到视口中央。

结果验证

  • 多选后工具栏出现批量操作栏，状态栏显示已选数量。
  • 在空白处拖动出现框选矩形，框到的卡片实时高亮。
  • Ctrl 点击已选卡片可以取消它，其余选中不会被清掉。

提示

  • 列表视图同样支持 ExtendedSelection，Ctrl / Shift 语义与图标视图一致。
  • 多选后拖动其中任意一张，会整批拖入 Maya（见 3.3.5）。
