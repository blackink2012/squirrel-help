插件通过 Maya 原生的 commandPort 驱动一个正在运行的 Maya，连接只走本机回环地址 127.0.0.1，不会把 Maya 暴露到局域网。

前置条件

  • Maya 已启动，且目标版本与插件匹配。
  • 设置中已勾选「允许外部工具连接 Maya（独立版 / 命令行）」。对应配置项为 bridge_auto_port，默认开启，安装时写入各版本 userSetup.py 的启动块。

端口规则

默认端口按年份倒排：端口 = 7001 + (2026 - 版本年份)。

Maya20262025202420232022
端口70017002700370047005

同一版本开第二个实例时，默认端口会被先启动的那台占用，后启动者改用备用段 7110~7129，详见「备用端口与自动发现」。

操作步骤

  1. 启动目标 Maya，确认设置里的上述勾选项处于开启状态。
  2. 在项目根执行 python maya_bridge.py --ping，确认能收到回包。
  3. 需要知道哪几个版本在线时执行 python maya_bridge.py --scan。
  4. 需要临时手动开端口时，在 Maya 的 Script Editor（Python 标签页）执行：
import maya.cmds as cmds
cmds.commandPort(name="127.0.0.1:7001", sourceType="python")

结果验证

--ping 返回形如 2026 | <untitled> 的字符串，前半是 Maya 版本，后半是当前场景；--scan 会逐端口列出在线状态。

提示与警告

  • 通道是 eval 模式：只求值单行表达式，结果经返回值回传；print 的输出只进 Maya Script Editor，不会回到调用方。
  • 在 Maya 进程内不要调用桥接客户端，那会连接自己并阻塞主线程，代码里有明确的防死锁拦截。
  • 需要固定目标时可设环境变量 SQUIRREL_MAYA_PORT，或使用 --maya 2025 / --port 7002。
