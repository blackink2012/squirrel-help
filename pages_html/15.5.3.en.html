One-line summary: right-clicking a models asset card in the asset grid opens this menu. There is no "apply" item here — models only bring geometry into the scene, and materials come along with the asset.

How to open it

  1. Left Category tab → click Models or any category under it (architecture / characters / props…);
  2. In the center asset grid, right-click any model card.

Why there is no "Preview node"

The models menu shows no Preview node item on the sample asset. The feature is not missing: that row appears only when the package holds a .zmetal or named .ma node file, and these assets are exported with the generic node.ma, which is not listed. Materials, lights, scenes, animation and node tree samples use named node files, so they show it.

Notes specific to this sub-library

  • Choose between "Import ma" and "Add reference": to edit the model, import it into the scene (you get editable geometry); to just place it and follow asset updates, use a reference (the file stays in the package and the scene stores a path).
  • "Format conversion" adds formats to the package, it does not swap them: afterwards the asset holds both .ma and .fbx and the original is kept. Slimming down must be handled separately; this step cannot do it.
  • Prepare content in the scene before updating the asset: replace asset, append as LOD, create new version and add variant all export the current scene selection into the asset.
