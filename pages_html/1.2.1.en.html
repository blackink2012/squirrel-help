The Maya plug-in edition installs the whole interface and feature set inside the Maya process and reads and writes the current scene directly. It is the most complete and the smoothest form to work with.

How it runs

  • The plug-in code lives in the squirrel_asset_manager folder of the local EXE install directory (default %LOCALAPPDATA%\SquirrelAM, changeable during installation), and one installation serves every installed Maya version.
  • Core modules ship as several .pyd builds, one per Python ABI; Maya loads the matching build at startup.
  • When 「Maya 集成」 (Maya integration) is checked in the installer, it writes a marked startup block into the userSetup.py of every Maya version detected locally (or checked in the wizard): import path, MCP startup registration, status-line button and bridge port. The shelf button is created only once, at install time.

Where to open it

  • The 「松鼠资产管家」 (Squirrel Asset Manager) button in the Custom category of the Maya shelf.
  • The squirrel icon on the right side of the Maya status line.
  • MaterialLibraryWindow.show_window() in the Script Editor (no separate Maya menu item is registered).

Advantages

  • Uses the current scene and viewport directly: drag and drop, snapping, thumbnail capture and material assignment all happen in the same process.
  • No separate Python or PySide6 install; it uses the Qt bindings that ship with Maya.
  • Shares the same commands and data as the AI backend, MCP and headless batch processing.

Requirements and limits

  • Requires one of Maya 2022–2027; earlier versions (2021 and before) have no matching .pyd and cannot run it.
  • Close all Maya instances before installing or overwriting .pyd files so the files are not locked.
  • The plug-in edition cannot run on its own when Maya is not running; use the standalone edition / EXE to browse assets instead.
