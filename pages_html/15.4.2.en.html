One-line summary: this button turns files and folders on disk into assets in the library — it is a dropdown, and which items it contains depends on the category you selected.

How to open it

  1. In the left category tree, select a specific category (not All assets, and not inside the recycle bin);
  2. Click the dropdown arrow next to Import from outside at the far left of the asset area toolbar;
  3. Choose an import mode from the menu.

In the Materials category the menu has 3 items (separators not counted), exactly the three in the screenshot:

Submenus

This menu has no second level (nothing with ▶) — the layer opened by Import from outside ▾ is the final menu, and every item opens a file / directory chooser directly.

The same button shows different items per category (the plug-in lists only the import modes that category really supports), which explains "someone else's menu has more items than mine":

Not in the mood for menus? Drop files in

Dropping files or folders from Explorer straight onto the asset grid is equivalent: the plug-in first checks whether the category accepts them and which import mode applies, then runs the same flow. Rejected files are explained in the log and in the dialog.

Risks and how to undo

  • Importing adds to the library and never deletes or overwrites existing assets (same-name conflicts follow your settings and may ask you to rename or overwrite).
  • Importing writes to disk (copying / packing files, generating thumbnails), so large files or batches take time.
  • Imported by mistake: delete the new asset with right-click Move to recycle bin (restorable), see 8.5.16.
  • The dependency collection policy (textures / caches) decides whether an asset is self-contained, see 4.3.6.5.

Beginner pitfalls

  • The menu will not open / the button is gray: no specific category is selected, or you are in the recycle bin. Select a category first.
  • The new card is a hollow shell / has no thumbnail: usually Maya is not connected or dependencies were not fully collected; see the prerequisites in 8.4.3 and the checks in 4.3.6.1.
  • Import textures brought in only one image: texture import follows the "one PBR set" logic and suffixes must line up; to place a single image choose Import images (Images category).
  • Cannot find the new asset among same-name assets: the import may have renamed it per the conflict policy; search its name or sort by newest.
