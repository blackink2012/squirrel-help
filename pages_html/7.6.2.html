导入后材质只剩纯色或变黑，通常是资产里没有贴图、贴图路径仍指向原机器，或 fileTextureName 没有改写成功。

症状

Hypershade 中 file 节点路径显示为黄色/红色或指向不存在的目录；视口材质没有图案；灯光资产的 HDR / IES 也没有连上。

常见原因

  1. 导出时没有勾选贴图，.zasset 里根本没有 textures/。
  2. 导入策略设为「源文件目录」，路径仍是导出机器的绝对路径。
  3. 资产被移动或改名后，meta.texture_map 里的原路径失效。
  4. 灯光贴图/HDR/IES 未被收集，或文件在资产外被删除。
  5. 多精度贴图只导入了当前选中的那一档，其它精度缺失。

解决步骤

  1. 打开 .zasset，确认 textures/ 下确有对应文件。
  2. 在设置中把贴图导入策略改为复制到工程或资产目录，再重新导入。
  3. 回到源场景，重新导出并勾选贴图，避免只导出材质节点。
  4. 查看脚本编辑器中的「贴图路径已解析」「复制依赖失败」等日志，定位是哪个文件。
  5. 少量缺失时，可在属性编辑器中手动把 file.fileTextureName 指回正确文件。

结果验证

file 节点的路径指向现存文件；视口显示贴图；穹顶灯的环境贴图和 IES 灯的光域网恢复正常。

仍不行怎么办

  • 检查 meta.texture_map 是否记录了「原始路径 → textures/...」，没有记录时导入端无法精确匹配。
  • 不要手动改 textures/ 里的文件名，.zmetal / .zlight 内的相对路径会对不上。
  • 资产源文件已丢失时，只能从原始工程重新导出。
