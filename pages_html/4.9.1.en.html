Favoriting puts frequently used assets into a collection; the star on a card shows whether the asset belongs to the active collection, and the data is stored per library in favorites.json.

Prerequisites

  • The asset library is loaded and the 「收藏」 (Favorites) tab is available on the left.
  • The target collection exists. A missing collection is not created automatically, and the write is ignored.

Steps

  1. Open the 「收藏」 (Favorites) tab on the left and select a collection in the list (the default is 「默认收藏夹」 (default collection)).
  2. In the asset grid or list view click the star icon on a card; its tooltip reads "click to add / remove favorite".
  3. Clicking the same star again removes the favorite.
  4. You can also right-click an asset and choose 「添加到收藏夹」 (Add to favorites), then pick a collection in the submenu: a filled gold star means it is in that collection, an outlined grey star means it is not.

Verify the result

  • The star toggles between filled and outlined and the count next to the collection changes.
  • With that collection selected on the 「收藏」 (Favorites) tab the grid lists only its assets.
  • In favorites.json in the library root the asset ID appears under the collection's materials entry.

Tips

注意

The star writes into the active collection. Select the collection first and then click the star so assets are not filed into the wrong one.

  • Favorites are stored per library: the main asset library and the project library each have their own, and the top of the panel shows the current library (main asset library / project library).
  • A plain drag moves an asset into the target collection (removing it from others); holding Ctrl while dragging adds it and keeps the previous membership.
  • The default collection cannot be deleted; on the command side use favorite (op=list/add/remove/toggle), which returns COLLECTION_NOT_FOUND when the collection does not exist.
