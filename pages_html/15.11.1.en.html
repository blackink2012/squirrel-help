One-line summary: a window that lays one asset out for inspection — large image on the left, every piece of information on the right.

The window title is not always "Asset details": it shows the asset's display name (or the English name when there is none), and the asset name appears in the upper left inside the window.

How to open it

EntryActionResult
Asset context menuRight-click an asset card → Asset detailsAssets without versions / variants → this window; assets with them → the version browser (8.11.2)
Double-click the right previewDouble-click the image in the Preview panel on the rightSame as above (the same path)

Note: if the asset has versions or variants, this entry opens the version browser instead of this window.

A complete example (dragging the preview into the current scene)

  1. Right-click the asset → Asset details.
  2. Press the left mouse button on the large image and drag it out of the window onto the Maya viewport, then release.
  3. The plug-in imports it in the asset's default format (the same logic as dragging an asset card into the viewport).
  4. To look at another thumbnail: use the wheel or click the strip below.
  5. To do something else with this asset: right-click inside the window for the same context menu as the asset card.

The window hints "drag the image out of the window → import into Maya", which is the drag-import entry.

Common questions

QuestionExplanation
Why does double-clicking the preview open the version browser?The asset has versions or variants. To inspect a single asset, import its main version from the version browser, or remove the versions / variants first
Why is there no ma under included formats?Geometry formats were not ticked on export, or this is a material-only asset (material categories lock geometry formats)
Why is the image a gray placeholder?That export produced no real image. Right-click → Update thumbnail → Background render (see 8.12.6) or Capture
Why is the size much larger than expected?Textures and associated files were collected into the package, see 8.10.5
