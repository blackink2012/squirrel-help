Run the installer, check the Maya integration and the offline dsh as needed, and you get a standalone edition you can start with a double-click.

Prerequisites

  • 64-bit Windows; installs per user, so no administrator rights are needed.
  • The installer has passed SHA256 verification.
  • For the Maya integration, confirm Maya is installed first; without Maya the installer unchecks that component.

Steps

  1. Double-click SquirrelAssetManager-Setup-1.0.0.exe (the test build is ...-test.exe).
  2. Choose the installer language: it follows the system language by default (English on an English system, as shown) and can be changed here; the whole wizard then uses that language.
  3. On the welcome page click Next.
  4. Read the EULA summary on the license page and tick both confirmations ("I have read the summary above" and "I have read and agree to the End User License Agreement"); Next becomes available only then.
  5. On the components page tick what you need (see the table below).
  6. Choose the install directory, %LOCALAPPDATA%\SquirrelAM by default.
  7. When it finishes, keep 「启动 Squirrel Asset Manager」 (Launch Squirrel Asset Manager) checked, or open it later from the Start menu or the desktop shortcut.

Components

ComponentDescription
Core program (required)Main program, bundled Python, PySide6, licence and third-party notices
Maya integration (optional)Writes the import path, status-line button and bridge port into each version's userSetup.py and creates the shelf button (created only once, during installation)
AI assistant dsh (offline)Unpacks the bundled dsh and portable Node
Desktop shortcut (optional)Creates a launch shortcut on the desktop

Silent installation

.\SquirrelAssetManager-Setup-1.0.0.exe /S /COMPONENTS=core,maya,aidsh

Optional components not listed in /COMPONENTS are unchecked; the core component is always installed.

A silent install shows no language dialog; it also follows the system language. Add /LANG= to override (2052 Simplified Chinese / 1033 English):

.\SquirrelAssetManager-Setup-1.0.0.exe /S /LANG=1033 /COMPONENTS=core,maya,aidsh

The chosen language is stored in HKCU\Software\SquirrelAssetManager\Language, and the uninstaller reuses it instead of asking again.

Verify the result

  • With the Maya integration checked, entry points appear in the Maya shelf and status line after restarting Maya. The shelf button is created only at install time and is not restored automatically after manual deletion.
  • Double-clicking the main program opens the asset interface.

Common failures

  • SmartScreen warns about an unknown publisher: the current version is unsigned; once you trust the source, choose "More info → Run anyway".
  • Maya integration checked without Maya: no entry point appears after installation; run the installer again and uncheck that component.
  • Startup says the bundled Python is missing: the installation is incomplete; reinstall and check whether antivirus software blocked it.
  • The standalone edition cannot reach Maya: confirm Maya is running and the bridge port is open, see "Multiple Maya versions".
  • Wrong installer language: the installer asks only once; after installation change the UI language in Settings → General → UI language (the uninstaller keeps the language chosen at install time).

Run the standalone edition from source

In the source package you can double-click 启动独立预览.bat (Start standalone preview), or run python squirrel_asset_manager\standalone_preview.py, provided the system Python has PySide6 installed.
