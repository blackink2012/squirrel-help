Assets/preset/external_agents.json is the ledger of which external tools have had skills landed into them; the actual skill sources live in dsh_plugins/skills/, currently 13 skill bundles.

Landing ledger

The ledger schema version is 1, with one key per tool:

FieldMeaning
rootThe skill root directory of that tool (absolute path after expanding the local user directory)
landedNames of skills already landed
problemsIssues found while landing (missing name:, directory name mismatch, and so on)

The tools currently recorded are codex, custom, workbuddy, doubao, qoderworkcn, trae-cn, agents-shared, dsh-desktop, qoderwork and claude-code. The paths are local values; they are re-detected on another machine, so do not copy them around as generic configuration.

Skills are only manuals: they tell an external model which commands and disciplines exist. The actual executable channel is the MCP entry (mcp/squirrel_mcp_server.py), and both are needed.

Install and update

In Settings → AI settings → External AI tools, tick per tool to install, update or remove. Landing is a plain copy and writes SQUIRREL_PROVENANCE.txt into the target directory to record the source; the ledger is maintained by the plug-in. MCP configuration comes in three kinds: writable directly (writer), requiring the user to paste manually (manual-needed), and no MCP support for that tool (not-supported).

Warning: Do not hand-edit the ledger and do not edit the landed skill copies directly — the next update overwrites them wholesale. To change content, edit the sources under dsh_plugins/skills/ and land them again.
