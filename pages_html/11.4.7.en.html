In one line: with a cloud provider selected, data may only be sent after you consent separately once — the record is stored locally, can be withdrawn at any time, and withdrawal stops sending immediately.

Why it is needed

Local services (Ollama / LM Studio) never send data off the machine, so they need no consent; a cloud service sends asset thumbnails, prompts or query text, and metadata such as asset names and categories to the provider, which is why this uses "separate consent plus withdrawal" instead of hiding inside a master switch.

Interface

Settings window → AI settings page → the 「云端服务同意（单独同意 · 可撤回）」 (Cloud service consent: separate, withdrawable) group:

ElementNotes
Status text「未同意（不会发送数据）」 (not consented, no data is sent) or 「已同意（时间）」 (consented at …)
Review and agreeOpens the consent dialog; without consent, cloud calls are blocked with a prompt to consent first
WithdrawShown only when consented; withdrawing returns the state to not consented and immediately stops sending data to that provider

Consent is recorded per provider: consenting for provider A does not mean B is consented.

What the consent dialog lists

It states every fact and requires checking the box at the bottom before 「同意并启用」 (Agree and enable) becomes available:

  • Recipient: the provider name and API endpoint;
  • Data categories: thumbnails, prompts or query text, and metadata such as asset names and categories;
  • Purpose: generating thumbnail descriptions and tags, and intent analysis for semantic retrieval;
  • Retention: decided by that provider's privacy policy; this software stores none of this data locally;
  • Cross-border risk: the server may be abroad and subject to local law; cloud services are not recommended for sensitive assets;
  • Privacy policy: available on the provider's website (this software does not reproduce it).

After withdrawing

  • The state returns to 「未同意（不会发送数据）」 (not consented, no data is sent) and the next cloud call is blocked again;
  • Data already sent cannot be recalled (that is governed by the provider's privacy policy);
  • To use it again, simply go through consent once more.

Recommendations

  • Prefer local services (Ollama / LM Studio) for sensitive or managed assets;
  • Consent only when you clearly understand that data leaves the machine and accept that risk;
  • After a project ends or when moving machines, remember to withdraw or confirm the state.
