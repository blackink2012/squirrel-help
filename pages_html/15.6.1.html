一句话定位：在资产网格里选中一个资产，右侧「属性」区域就会列出它的全部信息字段。

属性面板只负责「看」；要改，用右键菜单（见 8.6.2）或标题栏的编辑按钮（见 8.6.3）。

怎么打开

  1. 左侧导航里点任意分类，进入资产网格；
  2. 单击任意一张资产卡片（不用双击）；
  3. 右侧「属性」区域立刻显示这个资产的字段。

面板被关掉了也不怕：顶部「面板」菜单里能把「属性」区域重新打开（见 8.2.5）；这个区域本身还能拖动、拆分、撕下来（见 3.2.1）。

字段总表

下表按面板从上到下的顺序排列。「能不能改」里的「可改」指进入编辑态后能改，不是直接点一下就能改。

字段显示内容能不能改怎么改注意
名称易读名（中文名，meta 里的 name_cn）可改右键该行 →「编辑」，或标题栏铅笔按钮卡片上和状态栏显示的就是它；留空后卡片只剩「资产名」
资产名资产真实名（英文名，meta 里的 name），文件与节点用这个名字不可改—没有值时整行隐藏；要改名请用右键「编辑」改「名称」，不要改磁盘文件名
节点类型Maya 里的节点类型，如 aiStandardSurface、VRayMtl可改右键该行 →「编辑」（编辑态里这行叫「材质类型」）只是可读文本，填错不会改场景里的真实节点；导入时按真实节点类型判断
资产类型它属于哪个子库（材质 / 模型 / 灯光 / 贴图…）不可改编辑态里该下拉框是灰的想换子库请把资产移动到另一个子库的分类（见 4.1.6.4）
分类资产所在的分类易读名不可改编辑态里该下拉框是灰的换分类用右键「移动到 / 复制到」（见 8.5.15）
格式资产包里实际包含的格式，如 zmetal、ma、fbx；可能有多个小徽标不可改—散文件资产取源文件扩展名；要加格式用右键「更新资产 → 追加格式」（见 8.5.16）
动画格式动画数据资产包含的动画格式列表不可改—只有动画类资产才有内容，其它资产整行隐藏
大小资产文件的磁盘占用（.zasset 是包内所有文件合计）不可改—是磁盘体积，不是显存 / 内存占用
分辨率贴图的像素尺寸，如 2048 × 2048不可改—只对能读到图片尺寸的贴图类资产显示，其它资产整行隐藏
音频时长 · 采样率 · 声道，如 3.2 s · 44.1 kHz · 立体声不可改—只在音乐 / 音频资产上显示
软件产出该资产的软件（如 Maya、Substance）可改右键该行 →「编辑」只是记录信息，不影响导入行为；没记录时显示「-」
渲染器材质 / 灯光所属渲染器（arnold / redshift / vray）可改右键该行 →「编辑」同上，是记录信息；导入时看的是真实材质类型
色彩空间该资产约定的色彩空间，如 sRGB、Raw、ACEScg可改右键该行 →「编辑」，可从预设里选，也可直接输入改这里不会改 Maya 里已导入贴图的色彩空间设置
创建时间资产创建 / 导出的时间，如 2026-11-03 10:24不可改—没有记录时整行隐藏
标签这个资产挂的全部标签胶囊可改双击某个标签胶囊，或右键标签行 →「编辑」单击标签 = 按这个标签筛选；Ctrl + 单击 = 多标签筛选（见 4.1.6.1）
注释资产备注文字，可多行可改右键该行 →「编辑」没有注释时显示灰字「右键可编辑」；回收站条目会把删除时间写在这里

哪些行会「时隐时现」

面板不是每次都把 16 行全画出来，下面这些行按资产情况显隐（看不到不代表坏了）：

行出现条件
资产名meta 里有 name 才显示
动画格式该资产带有动画格式列表
分辨率能读到贴图尺寸（贴图类资产）
音频资产类型是音频 / 音乐
创建时间有 create_date 或 export_date
软件 / 渲染器 / 色彩空间选中资产后一直显示，没记录值时是「-」

没选中资产时

  • 属性列表整体收起，标题行还在，铅笔按钮也还在；
  • 这时右键 / 点铅笔都不会进入编辑（没有对象可改）。

只读状态（回收站条目）

在回收站里选中一条记录时，右侧属性与预览都是只读的：

  • 星星（收藏）和铅笔（编辑）按钮隐藏；
  • 右键菜单里的「编辑」置灰，只剩「复制 / 复制 ID」；
  • 注释里会多出「已移入回收站 · 删除时间」。
  • 回收站的用法见 8.8.3。
