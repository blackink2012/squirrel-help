An asset is the smallest unit the plug-in manages: one .zasset folder is one asset. The sub-library decides which kind of asset it is, the category is the folder hierarchy inside the library, and tags are cross-category search terms.

Key nouns

NounMeaningWhere it appears in the interface
AssetA .zasset folder containing metadata, thumbnails, materials / geometry / textures and other filesEvery card in the asset grid
Sub-libraryA top-level container under the library root that decides the asset typeTop-level nodes of the Categories tree in the left column: materials, models, lights, textures, scenes, HDR, dynamics, images, audio, animation data, node trees (11 built-in sub-libraries)
CategoryA multi-level folder inside a sub-library (or under a custom top-level category in the library root)Nodes at every level of the tree
TagA free-form word in the asset metadata, used for filtering「标签」 (Tags) in the properties panel, 「编辑标签」 (Edit tags) in the toolbar

Why it is split this way

  • The sub-library decides how an asset is imported and which commands its context menu shows.
  • A category is a pure folder structure; moving a category moves the folder, and sub-categories travel with their assets.
  • Tags do not consume folder levels: one asset can carry several tags, which makes cross-category lookup possible.

Notes

  • Do not copy, move or rename .zasset folders by hand, and do not delete category folders inside the library directly. The plug-in indexes assets by metadata and folder structure, so manual changes make assets invisible; do moves, renames and deletions inside the plug-in.
  • A category's folder name is its internal ID and cannot be changed through the interface after creation.
