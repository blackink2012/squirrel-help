Right-click a model asset in the grid and choose a geometry format under 「导入」 (Import) to bring the model into the current Maya scene.

Prerequisites

  • A Maya scene is open and anything that must be kept has been saved.
  • The model asset contains a geometry file such as ma, mb, fbx, obj, usd, abc, glb, gltf or dae.

Steps

  1. Right-click the target model asset in the asset grid.
  2. With only one available format the menu shows 「导入 <format>」 (Import <format>) directly; with several formats expand the 「导入」 (Import) submenu.
  3. Choose the geometry format to use.
  4. Wait for the import log in the Script Editor.

Verify the result

  • A new transform appears in the Outliner; for some formats the plug-in selects the new root nodes.
  • The Script Editor shows 「导入成功」 (import succeeded) or the import log of that format.
  • For ma/mb the texture paths were rewritten and materials look right in the viewport; abc and usd were copied into the project cache.

Tips

  • Imports go into the root namespace :; Maya renames automatically when a same-named node already exists.
  • ma/mb rewrite texture paths per the dependency import policy and redirect linked files under deps/.
  • Formats that need persistent paths, such as abc and usd, are first copied into the project cache and then imported.
  • If an fbx import does nothing, first check in Maya's plug-in manager that fbxmaya is loaded.
