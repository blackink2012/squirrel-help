The material network structure is zmetal's complete description of a Maya shading network: which nodes exist, each attribute's value, and who connects to whom.

The top level has two parts

{
  "root_materials": ["Gold_ai"],
  "nodes": {
    "Gold_ai": {
      "node_type": "aiStandardSurface",
      "attrs": {
        "base": {"type": "value", "value": 1.0},
        "baseColor": {
          "type": "connection",
          "source_node": "file1",
          "source_attr": "outColor"
        }
      },
      "displacement_node": "displacementShader1"
    }
  }
}

root_materials are the material node names to build on import; nodes is the node table keyed by node name.

What a single node contains

  • node_type: the Maya node type, such as aiStandardSurface, file or place2dTexture.
  • attrs: the attribute table. Plain values are written as {"type": "value", "value": ...}; connections are written as {"type": "connection", "source_node": ..., "source_attr": ...}, and upstream nodes are written recursively into nodes.
  • displacement_node: the displacement node associated with the material; on import the plug-in creates the shading engine and links it instead of serializing the SE directly.

Why it is designed this way

  • Import does not depend on the original .ma: as long as the node types exist in the current Maya, the network can be rebuilt from attribute values.
  • Textures are not embedded; they are collected into textures/ and fileTextureName is rewritten to a relative path, so the asset can be moved as a whole.
  • Array element attributes (such as a ramp's colorEntryList[i].color) are collected separately to avoid falling back to defaults after import.
  • Scene global nodes (time1, defaultColorMgtGlobals and similar) are not written, avoiding duplicate globals at import time.

Notes

A connection attribute's static value is only a reference; import honors the connection. Same-named attributes do not imply the same semantics, and cross-renderer work still needs a .mmap to define the mapping explicitly.

On import every node is rebuilt under the key names in nodes, and root_materials then decides which materials to assign to objects. When names clash Maya adds numbers automatically, and the plug-in keeps reconnecting through an old-name to new-name map, so the original node names in the asset need not match the scene exactly.
