An upgrade replaces only the program files; the asset library, settings and sign-in state live outside the program directory and are normally left untouched.

Upgrading the standalone edition / EXE

  1. Close the running SquirrelAssetManager.exe and the related dsh front-end processes.
  2. Run the new installer; it reads the install directory from the registry and overwrites the original location by default.
  3. Re-check the Maya integration and the offline dsh as needed.
  4. Restart Maya (if the Maya integration is installed), then start the standalone edition and confirm the version number.

Before upgrading

  • Note the old version number and keep the old installer so you can roll back.
  • Confirm the asset library and settings have backups.
  • If the current version is using the AI assistant dsh, close the web front end first so the files are not locked.

Verify the result

  • The version number in the main window title is the new one.
  • The existing library, favorites, tags and settings are still there.
  • The Maya shelf / status-line entry points work and the dsh and Node directories have not been deleted.

Common failures

  • Access denied: not all Maya instances are closed; close them and reinstall.
  • The entry point disappears after upgrading: restart Maya; if needed, run the installer again with 「Maya 集成」 (Maya integration) checked to rewrite the startup block.
  • Old files left behind: an EXE overwrite install does not remove files deleted in the new version; uninstall first and then install.
  • Settings or library layout incompatible: back up before a major-version upgrade and roll back if needed (the exact compatibility range is to be confirmed).
