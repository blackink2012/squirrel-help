::: note 名字说明搜索框左侧的入口现在覆盖图片、视频、音频三类媒体，「以图搜图」是沿用下来的叫法。本节标题保留旧名，正文按界面上的实际按钮讲。无论是传图、截屏、录一段屏，还是录一段系统声音，插件都会按画面或声音的相似度在当前分类里找资产。 :::

前置条件

  • 已打开资产库，并勾选搜索框右侧的「AI 搜索」。未勾选时，搜索框左侧的上传 / 采集按钮会隐藏。
  • 检索范围跟随当前选中的子库或分类；当前分类不覆盖这类媒体时，会退回到全库范围去找。
  • 首次使用视频 / 音频检索会先加载嵌入模型（约 10–20 秒，之后是秒级）。

搜索框左侧的按钮随分类变化

当前分类输入框里的按钮
材质 / 模型 / 灯光 / 贴图 / 场景 / HDR / 节点树 / 图片上传、截屏、录屏
动态 / 动画数据上传、截屏、录屏（按画面找相似动画）
音频（音乐）上传、截屏、录音（录当前电脑正在播放的声音，不是麦克风）

「上传」不是一个按钮直达，点开是一个小菜单：上传图片搜索 / 上传视频搜索 / 上传音频搜索，选哪个就走对应的检索路线。

操作步骤

  1. 上传文件：点输入框左侧的上传图标 → 在菜单里选「上传图片搜索 / 上传视频搜索 / 上传音频搜索」→ 选文件。
    • 图片：png、jpg、jpeg、webp、bmp、tif、tiff
    • 视频：mp4、mov、mkv、webm、gif
    • 音频：wav、mp3、aiff、aif、flac、ogg、m4a、aac
  2. 截屏搜索：点「截屏搜索」图标，在屏幕上拖出选区，松手即开始搜索；拖拽时按住 Ctrl 锁定正方形；Esc 或右键取消。
  3. 录屏搜索（动态 / 动画数据分类）：拖出选区后，选区右下角出现录制按钮——点一下开始录、再点一下停止，随后自动搜索。录屏上限约 10 秒、最长边 960、15fps；Esc / 右键取消。
  4. 录音搜索（音频分类）：点「录制系统声音搜索」，开始录当前电脑正在播放的声音，界面显示「录音中 N 秒 / 上限 N 秒」，点「停止并搜索」开始检索。录音太短（不足 0.5 秒）会提示重录。
  5. 拖入：把本地图片 / 视频 / 音频文件、网页媒体或库里的资产卡片直接拖到搜索框，按实际格式选择对应检索（拖资产卡片时用它的缩略图；该资产没有缩略图会提示）。
  6. 文字搜媒体：在音频分类里直接输入「找一段下雨的环境声」这类描述回车，会走「文字搜音乐」；在动态 / 动画数据分类里输入画面描述回车，会走「文字搜视频」。输入框的占位文案会跟着分类变。

检索路线

查询类型路线
图片① 图像向量检索（像素级相似度，首选）→ ② 视觉模型把图转成一句中文再走文本语义 → ③ 视觉模型提关键词后走词法
视频按画面特征做媒体向量检索（抽帧 / 指纹），命中带缩略视频的动画 / 动态资产
音频按声音特征做媒体向量检索，命中音频资产

状态与结果

搜索期间状态栏会显示「AI 正在分析意图…」或在加载嵌入模型；完成后按实际路线给出结果，例如：

  • 图片搜索：图片搜索：图像向量检索命中 N 个资产（xxx ms） / 按关键词「…」找到 N 个资产 / 按「…」识别后找到 N 个资产；
  • 视频 / 音频：视频搜索：命中 N 个资产（xxx ms） / 音频搜索：命中 N 个资产（xxx ms）；
  • 文字搜媒体：文字搜音乐：命中 N 个音频（xxx ms） / 文字搜视频：命中 N 个动画（xxx ms）；
  • 没结果：媒体搜索：未找到匹配资产（或「文字搜视频：没有找到匹配的动画」）；
  • 环境不就绪：媒体搜索暂不可用：原因。

结果出来后网格只显示命中项，搜索框内出现当前查询的缩略图 / 媒体标记。

取消

  • 点输入框里的查询缩略图 / ✕，或按搜索框最前方的退格（只移除查询、保留已输入文字）；
  • 状态栏会提示「已取消音视频搜索（或以图搜图），恢复当前分类的全部资产」。
提示

录屏与录音都依赖随包的 ffmpeg 合成查询文件；找不到 ffmpeg 时会明确提示，而不是静默失败。
