插件未加载，通常是安装目录不在 Maya 的导入路径、userSetup.py 启动段缺失，或旧副本抢先被导入。

症状

  • Maya 启动后状态行没有松鼠资产管家入口（工具架按钮只在安装时创建一次，缺失不会在启动时自动补建）。
  • 在脚本编辑器执行 import squirrel_asset_manager 报 No module named 'squirrel_asset_manager'。
  • 能导入包，但打开窗口时报子模块缺失，例如 No module named 'squirrel_asset_manager.core'。
  • 同一台机器上不同 Maya 版本表现不一致，或更新后仍加载旧界面。

可能原因

原因判断方法处理
安装目录不完整%LOCALAPPDATA%\SquirrelAM\squirrel_asset_manager\（或你安装时选的目录）下没有 __init__.py 或 ui\main_window.py重新运行安装器（勾选「Maya 集成」）
userSetup.py 启动段缺失当前版本的 Documents\maya\<版本>[\<语言>]\scripts\userSetup.py 里没有「松鼠资产管家 - 导入路径」标记重新运行安装器并勾选该版本的「Maya 集成」，让安装器写入启动段
工具架按钮被删除「自定义」分类里没有「松鼠资产管家」按钮，但状态行图标正常重新运行安装器（按钮只在安装时创建一次，启动不会补建）
包目录被缓存成空命名空间包目录里只剩 Assets\，没有 __init__.py，但 sys.modules 里已有 squirrel_asset_manager修好目录后重启 Maya；启动段会清掉这份缓存
旧副本抢先加载<app>\scripts\squirrel_asset_manager 或 <版本>\scripts\squirrel_asset_manager 仍存在确认是本插件旧副本后删除，再重启 Maya
核心模块 ABI 不匹配导入时报扩展模块或 DLL 错误见 6.1.2「版本与 ABI 不匹配」
安装目录没有读取权限目录属性或杀毒软件拦截恢复读取权限，或换到用户可读目录后重新安装

解决步骤

  1. 确认安装目录存在，且包含 __init__.py 与 ui\main_window.py。
  2. 打开当前 Maya 版本的 userSetup.py，检查是否有「松鼠资产管家 - 导入路径」与「松鼠资产管家 END」两行标记。
  3. 标记缺失时，重新运行安装器并勾选「Maya 集成」，然后完全退出并重启 Maya。
  4. 检查旧副本目录。只删除确认属于本插件的副本，不要删除整个 scripts 目录。
  5. 在脚本编辑器执行 import squirrel_asset_manager as sq; print(sq.__file__)，确认加载路径指向安装目录。
  6. 再次从菜单、工具架或状态行打开插件。

结果验证

sq.__file__ 指向 %LOCALAPPDATA%\SquirrelAM\squirrel_asset_manager\__init__.py（或你安装时选的目录），并且插件窗口能正常打开、分类树能加载。

仍不行怎么办

  • 把脚本编辑器里的完整 traceback 复制出来，尤其保留第一行错误和最后几行调用栈。
  • 确认当前 Maya 的 Python 版本与安装包 ABI 是否匹配，见 6.1.2「版本与 ABI 不匹配」。
  • 如果只有 AI、桥接或授权功能不可用，按 6.1.3「启动报错」检查对应日志，而不是反复重装。
  • 反馈时附上 sq.__file__ 的结果、安装目录树和 userSetup.py 中相关片段。
