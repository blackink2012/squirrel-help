One-line summary: for an asset with versions / variants / LODs, importing is not "import the asset" but "pick one first and import it" — this page covers where that choice happens and how.

Two entries, remember the conclusion first

ScenarioWhich entry to use
Just drop a variant / version / LOD into the scene quicklyRight-click the asset → the Import variant / version submenu and click that row (fastest)
Look at the images and information before importingDouble-click the preview to open the version browser, select the entry on the left and click Import this version / Import this LOD / Import this variant on the right

Entry one: the right-click submenu

Right-click an asset with versions / variants → the Import… submenu, whose title follows the asset content:

Submenu titleWhen it appears
Import variantThe asset has only variants (no multiple versions)
Import version / LODThe asset has only versions / LODs (no variants)
Import variant / versionBoth variants and versions exist (or older version records exist)

The submenu lists variants / versions one by one:

  • A variant with several LODs → another submenu level (LOD detail);
  • A variant with several geometry formats → another format submenu (ma, fbx…, distinguished by file name when several files share an extension);
  • Hovering an entry pops up that entry's large thumbnail.

Clicking the last level imports directly.

Entry two: the version browser

In the version browser (8.11.2): select an entry on the left and use the button on the right. The button text becomes Import this version / Import this LOD / Import this variant to match the selection.

The source also holds a standalone selection dialog

The plug-in source retains a standalone "Import variant geometry" dialog (the older selection method): it lists the asset's versions as radios plus the matching LOD detail radios and imports on OK. The current version does not attach it to any menu, so it cannot be reached through normal operation — use the two entries above. Its structure is described here so old documents and screenshots are recognizable:

ControlContent
TitleImport variant geometry
TopThe asset name to import
VersionA radio list, each row tag - display name (creation date), with notes on their own line when present
LOD detailA radio list, each row display name (LODx) plus triangle / vertex counts and available formats; a version without LODs shows "this version has no available LOD"
With no variantsShows only "this asset contains no variant data" and Cancel
ButtonsCancel / OK

In short: seeing this window means you are using the old entry; with the current version use right-click Import variant / version or the version browser.

A complete example (importing a variant's LOD1 in ma format)

  1. Find the asset with a variant badge in the grid.
  2. Right-click → expand the Import variant / version submenu.
  3. Find the target variant row and hover to check the popup thumbnail so you click the right one.
  4. If there is a LOD level, expand it and choose LOD1.
  5. If there is a format level, choose ma.
  6. Releasing imports the geometry into the current Maya scene.
  7. To verify which version came in, read the [VariantImport] log in the Script Editor, which states version/lod/geom.

Troubleshooting

SymptomCauseWhat to do
No import variant / version submenu in the context menuThe asset has no variants / multiple versions, or only one usable format so no submenu appearsUse plain Import, or create variants / versions first
Nothing happens after choosingThat entry's geometry file is missing, or the standalone mode is not connected to MayaCheck the [VariantImport] log; confirm Maya is online
The imported model is wrongThe wrong LOD or format was chosenImport the right entry again and undo the previous one with Ctrl+Z
Importing an animation asset errors outAnimation versions use ATOM mapping import rather than geometry importUse the asset's animation import path, or the matching import button in the version browser
