One-line summary: this vertical strip on the left is the master switch for "which library, which type, which folder you browse" — three tabs give three entry sets, with the category tree and the recycle bin below.

How to open it

It is always on the left of the window and needs no "opening". If the whole column is gone, first check whether it was collapsed into a narrow icon strip (the fold button at the far left of the toolbar, see 8.2.2).

Right of the tab row is the collapse / expand entry for the whole column (at the far left of the toolbar, see 8.2.2); collapsed it shows a single column of icons (the three tabs plus top-level category icons) with the same features.

Which page covers clicks and right-clicks

  • Clicking any tab / node → the center grid follows; behavior rules in 8.3.3.
  • Right-clicking a category tree node → different nodes show different menus, see 8.3.4.1 ~ 8.3.4.4.
  • Right-clicking a favorites set → adding, editing and deleting favorites, see 8.3.6.

Beginner pitfalls

  • The whole left column vanished: 99% of the time it was collapsed. Click the fold button at the far left of the toolbar; if that fails use Panels and layout → Reset layout (8.2.5).
  • Assets seem fewer after switching tabs: each tab maps to a different library / favorites set, so the contents differ by design; assets are not lost.
  • Changed a category on the Favorites tab and found no change back on the Category tab: the two tabs operate on different libraries; check which tab you are on.
  • The recycle bin is not in the tree: it is a separate entry button at the bottom left of the category tree, not a category node.
