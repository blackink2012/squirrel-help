Check the Windows architecture, Maya version and permissions before installing; this avoids most "failed halfway" installations.

Minimum requirements

ItemRequirement
Operating system64-bit Windows; the installer is a Windows desktop program (minimum Windows version to be confirmed)
Maya (plug-in edition)Maya 2022–2027
Standalone edition / EXEBundled Python 3.11.9 (amd64) and PySide6 6.9.2; no separate Python install
UI languageThe installer and uninstaller support Simplified Chinese / English; the language follows the system by default and can be changed during installation
PermissionsInstalls per user; administrator rights are not required
DiskThe installer and runtime take a few hundred MB; the optional dsh / Node takes about another 300 MB (see the actual package)
NetworkCore features work offline; online activation, dsh download and cloud AI need a network

Steps

  1. Double-click the exe to install. If Windows shows a warning, click “More info” and then “Run anyway”.
  2. Confirm Windows is 64-bit; 32-bit systems are not supported.
  3. Confirm free disk space for the installer, the runtime and the asset library.
  4. Close all running Maya instances before installing the plug-in edition.
  5. If you only use the standalone edition you do not need Maya; the installer unchecks 「Maya 集成」 (Maya integration) automatically.

Verify the result

  • The Maya version can be read and falls within 2022–2027.
  • The target disk is writable and the current user can write to the install directory.
  • No running Maya instance is locking the plug-in directory.

Common failures

  • Maya too old: there is no .pyd for that ABI, so the plug-in cannot load.
  • 32-bit system: the bundled Python and Qt are both 64-bit and cannot run.
  • Company policy: antivirus software or an application allowlist may block the installer; request an exception first.
  • macOS / Linux: only a Windows installer (Setup.exe) is provided; macOS and Linux have no package and are not supported.
