A variant is one of several geometry forms that share a single set of textures and materials under the same asset: textures and materials are stored once in the asset root and the variant directory holds only geometry. It solves the storage duplication of "one set of dependencies, many shapes".

How it differs from versions and LODs

DimensionWhat is storedMaterials and texturesTypical use
Version (V1/, V2/)A complete self-contained assetIndependent per version, may all differRevisitable iterations of damage, UVs or shape
LOD (lod1/, lod2/)Different detail levels of one shapeInherited from the owning versionHigh-poly display, low-poly placement
Variant (variants/)Geometry onlyInherited from the asset root, shared by all variantsMany styles of bricks, screws or tiles under one material set

All three can coexist without affecting each other.

Storage layout

Brick.zasset/
├── meta.json
├── variants.json          # the variants section registers id / label / geometry / LOD / thumbnail per variant
├── node.ma                # main version geometry
├── textures/              # textures shared by every variant
├── materials/             # materials shared by every variant
└── variants/              # flat, no second-level directories
    ├── standard_brick.ma
    ├── standard_brick.sicon   # thumbnail of this variant
    ├── broken_brick.ma
    ├── broken_brick.sicon
    └── broken_brick_lod1.ma   # a variant's LOD level: <id>_lodN.<ext>
  • Variant geometry is stored flat as <id>.<ext> under variants/, with no per-variant sub-directory.
  • Variants do not appear in the asset grid: they hang off their asset and are viewed through the context menu, the variant management window or the version browser; an asset with variants shows a V badge at the top left of its card.
  • Variant thumbnails are stored separately (variants/<id>.sicon and so on) and never overwrite the asset's main thumbnail.

When to use variants

NeedDimension to use
Same material, slightly different shapes (a chipped brick, a screw head type)Variant
Overall model revision that must keep earlier resultsVersion
High and low poly of the same modelLOD
Different textures per version of the same modelVersion (with its own materials)
注意

Variants are designed around shared textures: a variant stores geometry only and carries no textures or materials of its own. When independent materials are really needed, use a version instead.
