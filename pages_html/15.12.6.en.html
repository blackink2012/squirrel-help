One-line summary: the settings window that opens first when you right-click Background render. It decides which renderer, which model, which light, what size and what quality, and renders the thumbnail in a separate mayapy process.

The window is titled Background render and its first line reads: "Headless rendering: starts a separate mayapy process, which does not occupy the current viewport and does not change the current scene."

How to open it

  1. Select the assets needing thumbnails (several are fine).
  2. Right-click → Update thumbnail ▶ → Background render.
    • Do not pick Capture (a screen rectangle) or Import (an image from disk) by mistake.
  3. The Background render options window opens.

With a multi-selection: a single selection processes only the right-clicked asset, while a multi-selection processes all selected assets.

Block one: renderer

Common reasons an entry is unavailable: Arnold needs kick.exe / oiiotool.exe (installed with Arnold), while Maya software / Hardware 2.0 need a mayapy.exe of the same version as the current Maya. When none is available, Start generating reports "this machine has no usable headless renderer…".

Block two: preset model (only shown when needed)

Materials, textures and lights have no mesh of their own, so a demo model must be built and the material applied before rendering.

ControlTypeEffectSuggested valueWhat filling it in wrongly does

  • Model and scene assets come with geometry, so this block is not shown at all.
  • Light assets do show this block: the model is what gets lit.

A complete example

  1. Select one asset or a batch → right-click → Update thumbnail ▶ → Background render.
  2. Under renderer choose an available one (unavailable entries state the reason on the right).
  3. For material / texture / light assets: pick a model under preset model (hover for a large preview).
  4. Environment light: decide whether to use HDRI, and pick one if so.
  5. Size 512×512, quality standard.
  6. Click Start generating; the progress window appears showing progress and finished images (see 8.12.7).
  7. When finished the window closes and the grid refreshes with the newly rendered images.

Risks and how to undo

OperationRiskUndo
Start generatingIt overwrites those assets' existing thumbnailsRender again (the old image has no backup); save important images first with Update thumbnail → Import
Cancel the jobCooperative cancellation: it stops after the current asset finishesFinished images are kept, so you can fill in the rest next time

Troubleshooting

SymptomCauseWhat to do
"No usable headless renderer"kick / oiiotool is missing, or no mayapy of the same versionInstall Arnold, or confirm a same-version mayapy exists
It reports the preset model is missingThere are no model files in Assets/MeshesAdd .fbx/.obj/.ma model files and retry
Images come out transparent / blackHDRI is unticked, or renderer sampling is too lowTick HDRI and raise quality to standard
The job hangsThe mayapy process is stuck on a stepClick Cancel in the progress window and retry
The Background render item is missingUpdate thumbnail or Background render is switched off in the context menuEnable it on the Settings → Context menu page
