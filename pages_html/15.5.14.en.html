Two details:

  • State is visible: a set already containing the asset shows a filled gold star and others show an outlined gray star — no need to open it to check.
  • Multi-selection applies to all selected assets: after multi-selecting, clicking a set adds or removes all of them together.

What "Select all" really selects

  • It selects the cards visible in the current view: after filtering tags, searching keywords or filtering by category, Select all only covers the result set.
  • On the All assets tab, select all means every visible asset of the whole library (potentially a large number, so be careful with subsequent batch operations).
  • After selecting all you can right-click for batch operations, see 8.5.21.

What "Duplicate" actually copies

LayerContent
Plug-in internal clipboardThe asset id and the asset package path
System clipboardThe path of the asset folder (the .zasset directory)

Therefore:

  • Right-click blank space → Paste in the asset area copies the clipboard asset as a duplicate into the current category (see 8.5.19);
  • Pasting in Windows Explorer copies the whole asset folder out (useful for backups or sending to a colleague).

Internal virtual entries such as versions / variants are not duplicated — they are not independent assets.

Which folder "Open folder" opens

  • A .zasset asset: the asset package directory itself (holding meta, geometry, textures, thumbnails).
  • A loose-file asset (images / audio): the folder containing the file.

Once inside, do not casually rename or delete files: the library index points at these paths, and deleting them corrupts the asset. To free space, use Delete → Move to recycle bin.

Notes

  • Favoriting is not copying: favoriting only adds a reference in a favorite set and the asset stays in its category.
  • A mistake after select all is a batch mistake: before batch deleting or moving, check that the status bar's "N assets selected" is right.
  • Duplicating does not rename: pasting into the same category goes through the name conflict handling (ask / auto rename), see 8.12.5.
