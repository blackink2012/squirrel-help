Open several .ma / .mb files in turn and run the same MEL or Python script on each, optionally saving afterwards.

Purpose

Suits repetitive work such as batch renaming, node cleanup or unifying render settings, without opening each scene by hand.

Input and output

  • Input: a file list (.ma / .mb) plus a MEL or Python script.
  • Output: the modified and saved .ma / .mb files (when 「执行后保存文件」 (Save files after running) is checked); progress is written into the 「执行日志」 (Execution log) at the bottom of the window.

Steps

  1. Open 快捷工具 (Quick tools) → 批量处理maya文件 (Batch process Maya files).
  2. Under 「文件选择」 (File selection) click 「添加文件」 (Add files) to add .ma / .mb files, several at a time; remove unwanted entries with 「移除选中」 (Remove selected) or 「清空列表」 (Clear list).
  3. Under 「脚本输入」 (Script input) choose MEL or Python and paste the script; 「MEL示例」 (MEL sample) and 「Python示例」 (Python sample) are quick starting points.
  4. Validate the script with 「测试执行（当前场景）」 (Test run on the current scene) first.
  5. Confirm 「执行选项」 (Execution options) and click 「批量执行」 (Run batch).
  6. Read the success / failure summary at the end of the log.

Verify the result

  • The log shows 「批量处理完成！」 (batch processing finished!) with the number of succeeded and failed files.
  • With saving checked, the target files' modification times on disk are updated.
  • Afterwards the tool tries to reopen the scene that was saved before running.

Options and notes

OptionDefaultNotes
Save files after runningOnEach file is saved with force after a successful run
Show detailed informationOnThe log lists each file being processed and its save result
Advanced optionsOffExpands backup before running, force save and ignore errors and continue
  • Source check: the current batch logic only reads "save files after running" and "show detailed information"; the three advanced options are not used by the execution logic yet, so checking them changes nothing (whether they are reserved for later is to be confirmed).
  • A failing file is recorded as a failure and processing continues with the next one; the batch is never aborted.
  • Batch runs open files one by one, so an unsaved current scene may be replaced; save the current scene before running. It is only reopened afterwards when it already had a file path.
  • The log supports 「清空日志」 (Clear log), 「保存日志」 (Save log) as .txt and 「复制日志」 (Copy log).
