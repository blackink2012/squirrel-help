One-line summary: right-clicking an animation asset card in the asset grid opens this menu. Animation assets carry dynamic content (animation / cache / deformation), so both import and add reference gain an abc option.

How to open it

  1. Left Category tab → click Animation or any category under it;
  2. In the center asset grid, right-click any animation card.

Submenu: Import / Add reference (ma / abc)

Sub-itemWhat comes inWhen to use it
maThe full content of a Maya scene file: objects plus any animation curves / settingsYou want to keep editing in the scene and keep the animation with it
abcAn Alembic cache: mostly baked geometry / point cacheYou only need the shape change without the original curves; smaller files and steadier playback

References behave the same way: choosing ma references a Maya scene file, choosing abc references a cache file.

Notes specific to this sub-library

  • It is the only sub-library with two import / reference formats: that is why Import and Add reference are submenus instead of single rows as with models and scenes.
  • abc is not an animation curve: Alembic stores baked results, so after import the timeline holds no editable keyframes — use ma or the animation data sub-library when you need curves.
  • Format conversion only converts geometry: caches and animation data do not take part.
