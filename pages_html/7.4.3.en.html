Apply the parameters from a light asset onto lights already in the scene, without creating a new light or moving the existing ones.

Prerequisites

  • The target lights exist in the scene (transform or shape both work).
  • The light asset contains .zlight, or at least a .ma/.mb light network to fall back on.

Steps

  1. Select one or more lights in Maya that should receive the parameters.
  2. Right-click the light asset in the library and choose 「应用灯光参数到选中灯光」 (Apply light parameters to the selected light).
  3. Same-type lights: the tool writes back the serialized source attributes exactly.
  4. Cross-type lights: it maps source attributes to target attributes through .mmap and migrates texture and IES connections as well.
  5. When the asset has no .zlight, the tool imports its .ma/.mb, uses the lights inside as the parameter source, and cleans up the temporary imported nodes afterwards.

Verify the result

The Script Editor reports 「已应用 N 处灯光参数」 (applied N light parameter groups) and the modified lights stay selected at the end. The target lights' color, intensity, exposure, HDR / IES and so on match the asset.

Tips

  • When the source light has no texture slot, leftover texture connections on the target are disconnected so old textures do not occupy the attribute and block the color value.
  • Some plug-in attributes are read-only; an ineffective write prints 「属性写入未生效（可能只读）」 (attribute write had no effect; it may be read-only).
  • Texture nodes are kept and the temporary source light is deleted.

Warnings

With no light selected the tool reports an error straight away; cross-type application needs the matching light .mmap, otherwise nothing is written.
