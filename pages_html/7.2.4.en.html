Convert import merges "import the asset" and "convert to the target type" into one step: import first, then convert the newly created materials or lights to the chosen type.

Prerequisites

  • The target is a .zasset with an importable format (zmetal preferred for materials).
  • A matching .mmap mapping exists, or a usable intermediate path does.

Steps

  1. Right-click the material or light asset in the library and point at 「转换导入」 (Convert import).
  2. Choose the target type in the submenu: for materials the reachable material types, for lights the target light node types.
  3. The tool imports the asset (zmetal first for materials) and finds the materials or lights created this time.
  4. Materials are converted through the mapping and replace the source in place; lights are rebuilt as the target light type.

Verify the result

The target type material appears in the Hypershade and the original objects keep their material assignment; a light asset produces a light of the target type in the Outliner and it is selected. The Script Editor reports the number of nodes imported and converted.

Tips

  • Convert import only supports .zasset; import an ordinary .ma into the library first and then convert.
  • When the asset has no importable format or no new material is created after import, it reports an error with the reason.
  • A light asset without .zlight cannot be rebuilt from generic parameters and takes the ordinary .ma/.mb import path.

Warnings

When conversion fails, read the Maya Script Editor log; a missing mapping is the most common cause, so verify the mapping file first as described in 7.2.1.
