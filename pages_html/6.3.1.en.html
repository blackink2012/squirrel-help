「追加为 LOD」 (Append as LOD) writes the model currently selected in Maya as one detail level (LOD0–LOD4) of an existing asset without touching the other levels or the materials.

Prerequisites

  • The target .zasset already exists and its card is visible in the grid.
  • The asset already has a geometry format that can be reused (ma/mb/fbx/obj/usd/abc); appending a LOD reuses the asset's existing format, so no format needs choosing.
  • The model to use for that level can be selected in Maya. You do not need to select everything before opening the window — the level window is non-modal, so you can select as you bind.

Steps

  1. Select the model to use for a LOD level in the Maya viewport.
  2. Right-click the asset card → 「更新资产 ▶」 (Update asset ▶) → 「追加为 LOD」 (Append as LOD).
  3. The append LOD level window opens; its subtitle names the target asset / version and a line below shows 「当前选择：<model name>」 (current selection: <model name>) live.
  4. Click the matching level card (LOD0–LOD4) to bind it: the card becomes ☑ and shows → <model name>.
  5. In Maya select another model → click another level card to bind several levels at once; clicking a bound card unbinds it, and 「清空绑定」 (Clear bindings) starts over.
  6. Read the warning lines at the bottom of the window and confirm:
    • 「「LODn」已存在：将覆盖它的几何体，其它 LOD 不受影响。」 (LODn already exists: its geometry will be overwritten, other LODs are unaffected.)
    • 「LOD0 是版本默认几何体，覆盖后双击卡片导入的就是新模型。」 (LOD0 is the version's default geometry; after overwriting, double-clicking the card imports the new model.)
    • 「将一次写入 N 条 LOD。」 (N LODs will be written in one go.)
  7. Click 「导出并追加（N 档）」 (Export and append, N levels) to export and write each level. It then reports 「已追加 N 档 LOD。」 (appended N LOD levels.); failed levels are noted in parentheses after the message.

The current version no longer opens the create-asset export configuration window: appending a LOD reuses the target asset's existing format, exporting to a temporary directory outside the library → verifying → writing the LOD (lods.json or the older variants.json). When the asset has no reusable geometry format it reports 「该资产没有可沿用的几何体格式（ma/mb/fbx/obj/usd/abc），无法追加 LOD。」 (this asset has no reusable geometry format (ma/mb/fbx/obj/usd/abc), so a LOD cannot be appended.)

Verify the result

  • The message 「已追加 N 档 LOD。」 (appended N LOD levels.) appears.
  • Right-click the asset → 「资产详情」 (Asset details) (the version browser when versions or variants exist) → the new LOD row can be selected on the left and the 「LOD 管理」 (LOD management) card on the right lists that level.
  • lod{n}/node.<ext> is added inside the .zasset and the lods list in lods.json gains the entry (lod0 is always the root geometry).

Tips and warnings

Tip: the level is chosen by you on the level cards (LOD0–LOD4), not computed as the current maximum plus one; several levels can be written at once.

Tip: appending a LOD writes geometry only and never replaces materials or textures; for new materials use Create new version.

Tip: while the level window is open you can switch back to Maya and change the selection, and the window follows with 「当前选择」 (current selection); with several objects selected it binds the last one (the active object).

Warning: writing into an existing level overwrites that level's geometry (other LODs and versions are unaffected); overwriting LOD0 changes "the model that a double-click imports by default".

Current version: appending a LOD acts directly on the main asset you right-clicked; the "choose target version" dialog no longer appears, and sub-versions are independent V{n} assets. Appending a LOD for a variant uses a separate small input box (「为变体「X」追加 LOD 级别（1-9）」 (append a LOD level to variant "X", 1-9)), not this level window.
