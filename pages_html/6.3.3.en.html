Every version is a self-contained version asset; checking .zmetal when creating a new version gives it its own materials and textures instead of sharing the main version's.

Prerequisites

  • The main asset exists and already has one or more V{n} sub-versions, or a new version is about to be created.
  • Materials and textures for the new version are set up in Maya.
  • Be ready to check 材质预设 .zmetal (material preset) in the export dialog; keep 贴图 textures/ (textures) when textures are needed.

Steps

  1. Assign materials and textures to the new version's model in Maya.
  2. Select that model.
  3. Right-click the main asset card → 「更新资产」 (Update asset) → 「创建新版本」 (Create new version).
  4. In the export dialog check 材质预设 .zmetal and the needed geometry formats; keep 贴图 textures/ when textures are needed.
  5. Click 「创建资产」 (Create asset).

Verify the result

  • node.zmetal and textures/ appear inside V1/.
  • Right-click the asset → 「导入版本 / LOD」 (Import version / LOD) → V1 and the menu lists that version's zmetal (or mcm) entry; choosing it runs a material import.
  • The main version root's node.zmetal and textures/ stay unchanged.

Tips and warnings

Tip: a version's "independence" comes from the complete V{n} directory rather than a shared variants/ material directory; each version can have its own materials and textures.

Tip: with only geometry formats checked and .zmetal unchecked, the new version gets no material file of its own; whatever materials the imported ma/mb carries is then authoritative. Check .zmetal explicitly when stable reuse matters.

Warning: checking .zmetal writes the current scene's material network into the new version; changing the main version's materials afterwards does not propagate to the sub-version, and vice versa.

Current version: the variants/v2/node.zmetal described in older help is a historical structure; the current version uses V1/node.zmetal.
