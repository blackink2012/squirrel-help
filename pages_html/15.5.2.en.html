One-line summary: right-clicking a materials asset card in the asset grid opens this menu. Materials is the only sub-library with all three entries — assign to objects, write parameters, and cross-renderer conversion.

How to open it

  1. Left Category tab → click Materials or any category under it (metal / stone / skin…);
  2. In the center asset grid, right-click any materials card (you may also single-click to select first).

Right-clicking a materials card on the All assets, Project or Favorites tab opens the same menu.

Submenu: Import ▶ (zmetal / ma)

Materials assets usually carry two formats, so Import is a submenu rather than one row:

Sub-itemDescription
zmetalRebuilds the node network from the asset's own material network file (the preferred choice for materials)
maImports through a Maya ASCII scene file (often used when the full node graph / hierarchy must be preserved)

When only one format is available the menu shows a single row, "Import ma" or "Import zmetal", with no submenu.

The list length depends on whether the mapping table has a path from the source material type to the target type (direct or through one hop), so a different source material makes these 18 shorter or longer.

Notes specific to this sub-library

  • Assigning a material and writing parameters are two different things: Assign material to selection touches material slots on objects (swaps materials), while Apply material parameters touches material nodes already in the scene (swaps values). The first is for laying materials down; the second is for tuning a library material and pushing it onto existing scene materials.
  • Convert import only affects the scene: it never writes back to the library. To add a format to the library, use Update asset → Append format.
  • Convert import requires a .zasset asset: clicking it on a loose-file asset shows a warning — by design, not a bug.
