Creating a new version builds a complete self-contained V{n} directory inside the main asset and fills it with this export.

Prerequisites

  • The modified model or material is ready in Maya.
  • The objects to export are selected. A new version does not require geometry; exporting only materials or textures also works.

Steps

  1. Select the modified model in the Maya viewport.
  2. Right-click the asset, expand 「更新资产」 (Update asset) and choose 「创建新版本」 (Create new version).
  3. In the export dialog that follows, check the content you need (geometry formats, .zmetal and so on).
  4. Click export.
  5. The system takes the highest existing V{n} number plus one, first clones the main asset into a complete self-contained version, then replaces it entirely with this export.
  6. When it finishes the interface reports the version label (for example V2) and captures a separate thumbnail for that version.

Verify the result

  • A multi-version badge appears on the asset card.
  • Double-clicking the preview on the right opens the version browser and the new V{n} appears in the 「版本」 (Versions) list on the left.
  • version_assets in the main asset's meta.json gains a {id, folder, label, tag} entry.

Tips

  • Version directory names are always V{n}, the label defaults to the same text, and the semantic version defaults to {n}.0.
  • A new version contains exactly this export: unchecked content does not appear in that version's directory.
  • 「追加 LOD」 (Append LOD) follows the currently selected entry: with a V{n} selected the LOD goes into that version, with the main version (the asset itself) selected it goes into the main asset.
  • When versions need different materials, check .zmetal to give the version its own materials; see 4.10.5.
