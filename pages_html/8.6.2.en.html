The documentation index is a vector copy of Maya commands, nodes, APIs and guides, stored under the knowledge base's kb/semantic; it only serves Maya documentation search and is unrelated to the asset library.

What it contains

The local knowledge base holds about 17,000 entries typed as command, node, api, devguide or doc. The index only generates vectors for their names and descriptions; the body text is still read from the local knowledge base by source.

The vector directory contains meta.json (build record), names.txt (entry names in row order), vectors.i8 (int8 quantized vectors) and scales.f32 (dequantization factors); it is 768-dimensional under the current default embedding model.

When it is used

Documentation search defaults to auto: lexical first, then semantic results are fused with lexical ones when available. When the semantic index is missing, Ollama is not running or the model is not pulled, it uses lexical only without reporting an error.

Rebuilding

After changing the embedding model, when dimensions do not match or entries were rebuilt on a large scale, run:

python tools\build_semantic_index.py --model embeddinggemma-2:740m

The "documentation vector index" step of the one-click install does the same thing and only rebuilds when the model changes.

Notes

The documentation index and the asset index record their models separately and never replace each other; rebuilding one does not speed up the other.
