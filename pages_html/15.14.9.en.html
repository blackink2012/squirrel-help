One-line summary: convert a batch of same-type materials in the scene (such as VRayMtl) into another type (such as aiStandardSurface) using a mapping configuration, creating new materials, copying textures and reassigning as needed.

It is "heavier" than material import/export: importing/exposing moves whole packages, while this one rebuilds by rules. That is why it involves two prerequisite files:

  • Material type mapping: which material type → which material type (configure it in the window or save it as a preset);
  • Attribute mapping file (.mmap): which source attribute → which target attribute, with conversion functions. That file is produced by 8.14.8.

A complete conversion flow

  1. Prepare the mapping file first: configure source/target attribute mappings in 8.14.8 and Save preset to get a .mmap;
  2. Select a source material in Maya → Quick tools → Material conversion tool → click Load source;
  3. Select a target material (or just pick the target type) → click Load target;
  4. Confirm the mapping table holds one row "source type → target type"; add rows for more source types;
  5. Under Mapping file click Browse... to the .mmap folder and confirm the status becomes "N mappings loaded";
  6. Scan the attribute mapping preview to confirm roughness / metalness / normal and other key attributes are mapped;
  7. Under conversion options, tick Copy texture connections; on the first run also tick Keep the original material and leave Auto-apply to selected objects off;
  8. Click Convert selection for a small trial: check what the new material looks like and whether textures are connected;
  9. Once satisfied, decide whether to tick Auto-apply to selected objects, click Convert all and confirm in the dialog;
  10. Read the statistics dialog (materials converted / attributes copied / defaults used / textures copied / failed attributes).

Where the output lands

  • New material nodes are created in the current Maya scene (the target type, such as aiStandardSurface);
  • With Auto-apply to selected objects ticked, objects that used the old material switch to the new one;
  • With Keep the original material ticked the old material remains (handy for comparison / rollback);
  • When some materials fail, a "materials that failed to convert" dialog appears with a select failed materials in Maya button that locates them;
  • When the batch ends, statistics appear: materials converted, attributes copied, attributes using defaults, textures copied, failed attributes.

Risks and how to undo (conversion changes the scene)

  • It creates materials in the scene and may change assignments. Press Ctrl+S before starting — that is the most reliable undo (do not save / reopen to return to the pre-conversion state).
  • Always tick Keep the original material and try one material with Convert selection first: with a bad attribute mapping the new material can come out black or full of defaults, so inspect the result before batching.
  • Convert all walks every material in the scene that matches the configuration, not only the selected ones — read the number in the confirmation dialog.
  • With No mapping → default material ticked, materials without a mapping are replaced by a basic default material — leave it off if you do not want that.
  • To undo:
    • the scene was not saved → simply do not save and reopen;
    • it was already saved → recover the old material via Keep the original material and reassign (or use Maya's undo, see the undo conventions in 8.1.2);
    • the mapping was wrong → go back to 8.14.8, fix the preset, reload and convert again.
