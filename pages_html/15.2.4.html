一句话定位：工具栏右段这四颗：刷新重读资产库、Maya 目标决定插件驱动哪台 Maya、设置打开设置窗口、帮助打开帮助中心。

怎么打开

它们都在工具栏右侧，从左到右依次是：刷新 → AI 工具 → 快捷工具 → 面板与布局 → 维护 → Maya 目标 → 设置 → 帮助（本页只讲刷新、Maya 目标、设置、帮助这四颗；中间的菜单另见 8.2.5 ~ 8.2.8）。

鼠标停在图标上会显示名称，例如「刷新材质库」「选择要驱动的 Maya（多开时用；菜单里每台一张窗口缩略图）」「设置（AI / 字号 / 语言 / 资产库…）」「使用帮助」。

逐项详解

按钮作用前提点了之后注意
刷新重新读取当前资产库（分类树与资产卡片），并丢掉缩略图像素缓存重新加载资产库已加载网格与分类树按磁盘上的最新内容重画；状态栏数字更新在「收藏」页签里刷新的是当前收藏夹，不会把你踢回分类页；它会重新扫到磁盘上的 .zasset 资产包，但散文件不会因此变成资产
Maya 目标 ▾选择插件要驱动哪一台 Maya（多开时认人用）独立版且没有被 Maya 挂载弹出 Maya 清单菜单（见下节）Maya 内版 / 被宿主挂载时不显示这颗按钮，属于正常
设置打开设置窗口无弹出非模态的设置窗口（同一时间只有一个，再点会前置已开的那个）改完要按设置窗口自己的「确定 / 应用」才落盘，见 8.9.1
使用帮助打开帮助中心无用浏览器打开帮助中心页面帮助中心打不开时会自动回退到旧帮助页；两者都失败时只在脚本编辑器打印日志，界面没有弹窗

子菜单：Maya 目标 ▾

这个菜单每次弹出都会重新扫描在线 Maya，所以刚启动的 Maya 会出现、刚关掉的会消失。

菜单项 / 行说明
自动选择（优先最新版本）默认项。不用你指定，插件按桥接端口自动挑一台在线的 Maya；勾会落在被自动选中的那台实例行上（示例里是 Maya 2025）
一台 Maya 一行每行显示「Maya 版本 + 场景名（未保存场景会写「未保存场景」）+ PID + 端口」，行首是这台 Maya 的窗口缩略图；点这一行即切换目标，当前那台行尾有 ✓
（没发现在线的 Maya —— 先启动 Maya，或确认它的桥接端口开着）灰字提示，表示一台都没探测到
Maya（未开桥接端口）探测到了进程、但它的桥接端口没开，插件连不上。点这一行不会切换目标，而是把「修复命令」复制到剪贴板并把那台 Maya 提到前台 —— 到它的 Script Editor 粘贴回车即可打开端口
没抓到画面 / Maya 已最小化缩略图位置的提示。最小化的窗口 Windows 不渲染画面，所以抓不到缩略图；点这一行会复原并提到前台

小白易错点

  • 刷新后改动没出现：刷新会重新扫描磁盘上的 .zasset 资产包并重建分类，所以手工拷进来的完整资产包刷新后是能看到的；但散文件（没打包的图片 / 模型 / 贴图）不会因此变成资产，要走导入流程，见 4.1.3.5。
  • 找不到「Maya 目标」：你用的是 Maya 内版或宿主挂载的独立版，目标已经定死了，不需要也不允许在这里切。
  • 切了 Maya，资产却导进了另一台：检查菜单里当前带 ✓ 的那一行；插件只认这一行对应的端口。切完建议先看状态栏 / 导出一个测试资产确认。
  • 设置窗口点了没反应：它可能已经在别处打开着（非模态单例），再点一次会把它提到前台，而不是开第二个。
