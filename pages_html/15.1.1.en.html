Two ways to look things up

  1. By position (recommended): find the area on the window first (top / left / center / right), go to the matching page from the table above, then find the row in that page's menu table.
  2. By wording: search in plain language in the help center search box (for example "import model", "button is gray", "what is in the right-click menu"). Each page's keywords / synonyms are written the way people speak, so you never need to memorize the official UI names.
  3. By task: when you only know what you want to do, use the "I want to…" list in 8.16.1 to work back to the menu location.

Read the four table columns like this:

  • Effect: what the item actually does, in one sentence.
  • Prerequisite: the state it needs to be meaningful (for example a category is selected, Maya is online, objects are selected).
  • What happens on click: what you see change immediately in the UI (dialog / progress / new node / new card).
  • Notes: whether it overwrites, whether it can be undone, and which settings it interacts with.

How to read numbered screenshots

  • Numbers on the image run left to right, top to bottom; the numbers below the image or in the table correspond one to one.
  • Screenshots without numbers are photos of the whole menu; table rows follow the menu from top to bottom, so match them in order.
  • Names in this dictionary always use the official UI text (for example "Import from outside", "Panels and layout") rather than invented labels.
