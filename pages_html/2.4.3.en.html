Uninstalling removes the program and the Maya startup block, but the asset library, user settings and license are yours to keep or delete.

Uninstall

  1. Run the uninstaller from Windows Settings → Apps or from 「卸载 Squirrel Asset Manager」 (Uninstall Squirrel Asset Manager) in the Start menu.
  2. The uninstaller first removes the startup block from each version's userSetup.py, then deletes the install directory, shortcuts and registry entries.
  3. It does not delete the asset library, ~/.squirrel_asset_manager or Ollama models.
  4. Restart Maya; if the 「松鼠资产管家」 (Squirrel Asset Manager) button is still in the Custom shelf category, delete it from the context menu (the plug-in creates the button only at install time and does not rebuild it at startup).

Verify the result

  • After Maya starts there is no squirrel entry point and the Script Editor shows no plug-in import errors.
  • The install directory is gone and the disk space is released.
  • The asset library is still there and opens normally.

Common failures

  • Maya reports import errors after uninstalling: a startup block is still in userSetup.py; delete the four sentinel blocks by hand (「导入路径」 import path, 「状态行按钮」 status-line button, 「MCP 启动注册」 MCP startup registration, 「桥接端口」 bridge port), each of which appears as a pair.
  • The license is lost: the EXE's local license may sit inside the install directory; back up license.dat before uninstalling, and reactivate if needed.
  • The asset library is deleted by mistake: uninstalling never deletes it, but do not treat it as an install leftover during manual cleanup.
  • The shelf button remains: the button is defined in Maya preferences and the uninstaller does not clean it up; delete it manually.
