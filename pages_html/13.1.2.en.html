Core modules are compiled per Python ABI into several coexisting .pyd files; when Maya's Python version does not match the .pyd cp tag, the import fails.

Symptoms

  • Opening the plug-in or importing a core module raises an extension module error such as ImportError or DLL load failed while importing ....
  • The same installation works in some Maya versions but not in another.
  • After an update only some features fail: the UI opens, but import, export or material operations fail.
  • When both .py and .pyd exist in the source tree, this machine loads .py first, so the problem may only appear in the release build.

Possible causes

CauseHow to tellAction
The ABI build for this Maya is missingThe core directory has no .pyd with the matching cp tagUse an installer that contains that ABI, or run from source

Steps

  1. In the Maya Script Editor run import maya.cmds as cmds; print(cmds.about(version=True)) and confirm the Maya year.
  2. Run import sys; print(sys.version_info) and confirm the Python major/minor version.
  3. Look in the core module directory and confirm a .pyd matching the Python version exists (for example Maya 2026 needs cp311).
  4. If the tag does not match, switch to a matching installer; never rename a .pyd across versions.
  5. For local debugging you may keep the .py sources, since the package entry loads .py first; a .pyd-only release must match the ABI.
  6. After replacing files, fully quit and restart Maya.

Verify the result

The plug-in opens, and importing core modules such as import squirrel_asset_manager.core.manager no longer raises extension module errors.

If it still fails

  • Record cmds.about(version=True), sys.version_info and the failing module name together.
  • Confirm no .pyd left over from an older version is overwriting the current one.
  • If only one core module fails, check whether that module is missing from the installer instead of continuing to change the environment.
  • If you still cannot tell, follow 6.1.3 "Startup errors" to capture the full traceback and report it.
