松鼠资产管家覆盖 Maya 资产的「存、找、看、改、导入导出」；它不是建模、渲染或云端协作平台。

能做什么

能力说明
资产管理11 个子库：材质、模型、灯光、贴图、场景、HDR、动态、图片、音频、动画数据、节点树；分类、标签、收藏夹、项目库
导入从外部文件、文件夹或库内导入几何、材质、贴图、HDR、灯光、场景与动画；图片可导入为 file 节点 / imagePlane / 指定到材质槽，音频可导入到时间轴 / 时间编辑器 / Trax / 摄像机序列器，动画数据可导入动画并按层级映射
导出单资产、批量全自动、批量半自动；支持 .ma、.mb、.fbx、.obj、.abc、.usd、.glb、.ass、.vrmesh、.rs、.zmetal、.mcm 等格式
缩略图截取、Maya 拍屏、渲染图、导入图片；后台渲染可无头批量出图；支持多缩略图槽与输出尺寸
媒体检索上传图片 / 视频 / 音频按内容找相似资产；截屏搜索、录屏搜索；音频分类下可录制系统正在播放的声音检索（录的不是麦克风）
音频与动画数据音频卡片可试听，可导入到时间轴；动画数据可导入 / 导出，支持层级映射到选择属性
批量操作批量移动、复制、删除、重命名、改标签与字段
版本与 LOD创建新版本、追加 LOD、切换版本/LOD、版本独立材质
材质与灯光跨渲染器材质转换、属性映射、材质匹配、应用材质与灯光参数、创建穹顶灯
AI缩略图分析、分类/标签/中文名建议、自然语言搜索、以图搜图、语义索引
Maya 集成场景读写、截图出图、原生工具、无头批处理、MCP/外部 AI 接入
快捷工具PBR/模型/HDR 转资产、图像格式转换、批量镜像复制、材质转换等

不能做什么

  • 不做建模、雕刻、渲染或动画：这些仍由 Maya 及其插件完成。
  • 不是云资产市场：不提供在线托管、账号体系、评论后台或资产交易。
  • 独立版不能脱离 Maya 做场景操作：Maya 不在线时只能浏览、搜索和执行文件层操作。
  • AI 不是必装项：需要本机 Ollama 或你配置的云端模型；缺失时相关功能不可用，核心浏览与管理不受影响。
