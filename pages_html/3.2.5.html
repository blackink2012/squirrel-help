布局不需要手动保存：调整后自动写入配置文件，下次打开自动恢复；需要回到默认时用「重置布局」。

自动保存

以下状态会随操作写入 ~/.squirrel_asset_manager/app_settings.json：

  • 窗口尺寸与位置、区域语义布局树、最大化区域。
  • 左右栏显示 / 收起状态与宽度。
  • 当前分类、展开的分类节点、当前左栏页签。
  • 图标 / 列表视图、排序方式、缩略图大小、AI 搜索开关、布局锁定状态。

恢复

重新打开插件窗口时会按保存值恢复。若某个区域已被关闭或布局损坏，插件会尽量补回缺失的预览区或退回默认布局。

重置布局

  1. 点工具栏「面板与布局」。
  2. 选「重置布局」。
  3. 区域回到默认结构：导航、资产、属性、预览、AI 助手；左右栏展开。
  4. 当前分类、选中资产等数据状态会尽量保留，不会把资产清空。

结果验证

  • 拆分或关闭一个区域后关窗重开，布局保持调整后的样子。
  • 重置后区域结构回到默认，缩略图与资产内容仍在。
  • 最大化状态在重开后仍保持（若关闭前处于最大化）。

提示

  • 不要在插件运行时手工改 app_settings.json；改坏了可能导致布局读不出。
  • 需要备份布局时，先关闭插件，复制该 JSON 文件即可。
  • 悬浮区域的持久化行为待确认；停靠布局会稳定保存。
