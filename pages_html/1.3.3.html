资产库就是普通文件夹：资产以 .zasset 文件夹存放，元数据是 JSON，复制库目录即可完成备份。

库根目录

库根下有 11 个内置子库目录，缺哪个就在加载时补哪个：

你的资产库/
├── library.json            # 库元数据
├── favorites.json          # 收藏夹
├── materials/              # 材质
├── models/                 # 模型
├── lights/                 # 灯光
├── textures/               # 贴图
├── scenes/                 # 场景
├── hdr/                    # HDR
├── ani/                    # 动态
├── images/                 # 图片
├── audio/                  # 音频
├── animation/              # 动画数据
├── nodetree/               # 节点树
└── .squirrel_ai_index/     # 语义索引（派生数据，可重建；按后端分 official/ ollama/）

两条容易混淆的规则，分开记：

  • 设置里的「创建资产库」按钮只建 6 个基础目录：materials、models、lights、textures、scenes、hdr；
  • 每次加载 / 切换到某个库时，插件按内置 11 个子库补齐目录（缺哪个建哪个，并补 FolderMetadata.fdata）；如果这个库根还没有 library.json（首次运行），或某个子库下没有任何子分类，还会按默认配置创建子分类。

每个子库与分类目录下还有 FolderMetadata.fdata，记录易读名与类型；顶级分类不能直接存放资产，资产要放在其子分类中。

单个资产

MyAsset.zasset/
├── meta.json               # 名称、分类、标签、格式等
├── node.zmetal             # 材质节点（可选）
├── node.ma / .fbx / ...    # 几何体（可选）
├── thumb.sicon             # 静态缩略图（可选）
├── thumb.aicon / .mp4      # 动态缩略图（可选）
├── textures/               # 贴图（可选）
└── deps/                  # 收集的缓存、代理、引用（可选；旧版为 associated/）

配置与日志

  • 应用设置：~/.squirrel_asset_manager/app_settings.json。
  • 桥接与恢复日志：同目录下的 bridge_port.log、bridge_recover.log、broker_boot.log 等。
  • 语义索引：默认在库根 .squirrel_ai_index/<official|ollama>/（按后端分家），也可在设置中指定本地索引根。

数据安全

  • 备份：关闭 Maya 后复制整个库目录与 app_settings.json 即可；资产不是数据库，单个 .zasset 也能单独拷走。
  • 设置写入：采用临时文件替换的原子写入；设置文件损坏时会先备份为 .bak，再回退默认值。
  • 索引：属于派生数据，可重建；不建议放在共享盘或同步盘，多写入方没有跨机协调，容易互相覆盖。
  • 并发：库本身没有跨机文件锁，多人共享时避免同时重命名或移动同一资产（待确认具体锁策略）。
