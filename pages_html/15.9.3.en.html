One-line summary: every AI-related switch lives here: install dependencies, update / rebuild the index, configure the model, consent to each cloud provider, decide where the chat panel opens (including the dsh release track), and allow or forbid external tools reaching this Maya.

This page is not affected by the global lock and can be edited immediately.

How to open it

Settings window → click AI settings in the left-hand navigation (see 8.9.1).

提示

To make newly added assets searchable right away, click Update vectors; only switch embedding models / backends or suspect index corruption before using Rebuild all vector indexes.

警告

Semantic AI search is unavailable during a rebuild (falling back to keywords), which can take a while with large libraries. Do not run a large import while rebuilding, or the fresh index lags again immediately.

6. External connections

ControlTypeEffectDefaultWhat changing it doesNeeds unlock
Allow external tools to connect to Maya (standalone / command line)CheckboxMakes Maya listen on a local loopback port at startup so the standalone edition / command line can read scene info and import or export assetsUnticked (off by default)Ports are assigned per version (2026→7001, 2025→7002…), and when several instances of one version run, later ones fall back to 7110–7129. Saving tries to apply immediately; on failure it reports "settings saved, Maya will retry at next startup"No
警告

This port only listens on the loopback address, but it is equivalent to an arbitrary code execution entry (anyone who connects can make Maya run code). When you do not need external tools to drive Maya, leaving it unticked is safer.

Common questions

SymptomWhat to do
AI search does nothing / a notice says semantics are inactiveClick AI dependency check to see what is missing, then One-click install AI features and dependencies (see 4.8.4.1)
The model list is empty after switching providersCheck the API key and address; some providers need a key before listing models; you can also type the model name under AI model
AI results are still inaccurate after installing dependenciesThe vector index needs rebuilding; it does not catch up with large imports by itself
Assets just imported cannot be found / the index lagsClick Update vectors for an incremental sync (see 4.5.6.4); rebuild only when switching embedding models / backends or when the index is corrupt
I switched the release track / version but the AI assistant did not changeNormal: both only affect the next one-click install and never upgrade the installed runtime by themselves; to switch versions, change them and then run One-click install AI features and dependencies again (see 4.8.4.3)
The standalone edition cannot reach MayaCheck whether Allow external tools to connect to Maya is ticked and whether the port is taken (see 4.8.4.4)
