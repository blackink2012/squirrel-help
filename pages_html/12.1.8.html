maya_plugins
列出已装插件及其能力		列出本机已装插件（cmds.pluginInfo）：版本、提供的命令与节点类型数量。传 plugin="MASH" 看该插件的全部命令 / 节点名。用途：具名命令清单只覆盖插件自己注册的几十条，操作 Arnold / Redshift / MASH / Bifrost / USD 等已装插件前，先用它确认有哪些命令与节点；拿到节点名用 maya_doc_show 查属性，拿到命令名用 maya_live_help 查参数。plugin / loaded_only只读同步
maya_live_help
实时命令帮助（本机）		在活着的 Maya 里取一条命令的帮助：版本精确（不受知识库版本限制）、覆盖已装插件（Arnold / Bifrost / Redshift / MASH / USD / FBX…）、flag 长短名与类型与本机完全一致、随 Maya UI 语言本地化。写 maya_run_python / maya_run_mel 代码前优先用它核对命令名与参数名；flags_only=true 只回参数行（省 token）。边界：cmds.help 不认识节点类型 —— 节点属性 / API / 开发指南请用 maya_doc_show（知识库）。name / flags_only只读同步
maya_doc_search
查 Maya 文档（搜索）		在包内知识库做检索：词法 + 语义混合。中文 / 口语直接问（减面 / 骨骼 / 循环边 / 怎么让物体沿曲线排列 / 渲染太吵了怎么去噪）——词法接不住的说法由语义一路兜底（本机 Ollama 嵌入模型，向量索引在 kb/semantic/，Ollama 不在或没建索引时自动退回纯词法，不报错）。词法侧：名称命中优先、多词按 AND、同义词表 711 键；排序 = 原生命令 / 节点 / API → Run Time Command（DeleteHistory / InsertEdgeLoopTool 这类 MEL 命令）→ 中文说明页。每条结果带 match 字段（keyword / semantic / both）说明来自哪一路；返回体里的 semantic 字段给出语义是否可用、用的哪个模型。注意：语义不可用时是静默降级（只剩词法，查询照常有结果），所以返回体会多一个 advisory 与 semantic.hint 说明原因与安装步骤 —— 照实转述给用户，别把降级读成"这插件没有语义检索"。mode=keyword 强制纯词法（最快、完全离线）；mode=semantic 只看语义（排查用）。拿到名字后用 maya_doc_show 看细节；命令的 flag 细节优先用 maya_live_help。query / lang / mode / limit只读同步
maya_doc_show
