One-line summary: the sort button on the asset area toolbar: its text is the current sort key and its arrow is the direction; click it to change the sort.

How to open it

  1. Find the sort button on the right of the asset area toolbar (its text is the current key, such as "Name");
  2. Click it to open the sort menu;
  3. Click a sort key, or click Ascending / Descending to change direction.

Item-by-item details

The menu has 6 items in two parts (above the separator you choose the key, below it the direction).

Menu itemEffectPrerequisiteWhat happens on clickNotes
NameSorts by the asset display nameNoneThe list re-sorts and the toolbar button reads "Name"The item carries no check mark; it sorts by the readable / display name, not the disk folder name
TypeSorts by the asset's sub-library (materials / models / textures…)NoneAssets of the same sub-library group togetherInside a type, assets keep a stable name order
CategorySorts by the display name of the asset's categoryNoneAssets of the same category group togetherIt uses the category display name (Chinese / readable name), not the category id
TimeSorts by the asset files' modification timeNoneReorders chronologicallyIt is file modification time, not "import time"; to find the newest import, sort by time descending
AscendingSmall to large / earliest to latestNoneDirection becomes ascending and the button arrow points upDirection items carry no check and no arrow icon: read the toolbar button arrow for the current direction
DescendingLarge to small / latest to earliestNoneDirection becomes descending and the button arrow points downAs above; clicking the same item twice does not toggle, so click the other item

Submenus

This menu has no second level (all 6 items apply immediately, nothing with ▶).

In list view you can also click column headers

After switching to list view, clicking the Name / Type / Category column headers also sorts (the time column is not in the header and needs this menu). Both routes give the same result, and the button text and check stay in sync.

The recycle bin behaves the same

The recycle bin page reuses the same sort button: sorting there only affects the recycle bin list, and returning to the asset page keeps the asset page's own sorting.

Beginner pitfalls

  • Cannot tell whether it is ascending or descending: read the arrow direction on the toolbar sort button; the Ascending / Descending items carry no check and no arrow, so do not look for one there.
  • Sorted by time but the newest is not first: the direction is ascending (old to new). Click Descending.
  • Name sorting does not match alphabetical order: names sort by display name (possibly a Chinese readable name), and Chinese order is not identical to English letter order.
  • Selected assets disappeared after changing the sort: sorting only reorders the display and never changes the selection; if it really is empty, you probably clicked blank space earlier and cleared it.
