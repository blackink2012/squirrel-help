One-line summary: when you click AI assistant and no usable dsh runtime is detected on the machine, this window opens to say what is missing and how to install it.

dsh (DeepSeek Harness) is the runtime behind the plug-in's built-in AI chat panel; it is not a Python package but a Node program. So "installing the AI assistant" really means installing Node plus dsh, and this window guides both steps.

When it appears

  • Top toolbar AI tools → AI assistant;
  • No usable dsh runtime is found → this window opens automatically and the AI assistant cannot start.

A complete install flow (recommended: one-click install)

  1. AI tools → AI assistant and this window appears;
  2. Click One-click install (recommended);
  3. A progress window appears (it does not block Maya, so you can keep working):
    • titled "Installing the dsh runtime";
    • the description holds the full log path (<dsh_home>/dsh_install.log);
    • a live scrolling log shows where it is stuck;
    • a Cancel button;
  4. Wait for it to finish (network required, usually 1–5 minutes, longer on slow networks);
  5. Success: the progress window reads "dsh runtime ready, opening the AI assistant…" and the panel opens;
  6. Failure: the window shows the reason and suggests Copy install command for a manual install or Open install help for step-by-step instructions.

The manual install route

Use it when one-click install fails, when a corporate network blocks npm, or when you want to manage the Node version yourself.

  1. Click Copy install command in this window;
  2. Open a terminal (cmd or PowerShell) and paste and run it;
  3. The command's --prefix already points at the runtime directory the plug-in expects, so do not change the path, otherwise the plug-in still cannot find it;
  4. Return to Maya and click AI assistant again;
  5. If it still fails, click Open install help and follow the per-platform steps and verification.

What you see afterwards

  • The AI assistant panel opens normally (the panel itself is in 8.8.2);
  • The AI tools menu's AI assistant item text follows the state (open / close / starting);
  • The install log lands in <dsh_home>/dsh_install.log; include it when reporting a problem.

Risks and how to undo

  • One-click install downloads from the network (portable Node plus dependency packages, hundreds of MB), so judge the traffic and time yourself.
  • You can cancel during installation: cancelling only stops later steps and keeps what already installed; the next one-click install continues from what is missing.
  • Installation never touches your asset library or the Maya scene and changes no plug-in settings; to undo, delete the <dsh_home> directory to return to the "not installed" state (the AI assistant then asks to install again).
  • Do not click One-click install repeatedly while it is running — it reports "an installation is already in progress, wait for it to finish or cancel it".
