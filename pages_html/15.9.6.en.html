One-line summary: this page is one large text box with one file extension per line — they are the whitelist the library treats as "asset files".

This page is locked by default: tick Unlock all settings and accept the warning first (see 8.9.1).

How to open it

Settings window → tick Unlock all settings → the Supported formats tab.

Controls and defaults

ControlTypeEffectDefaultWhat changing it doesNeeds unlock
Extension listMulti-line monospaced text box (one extension per line)The whitelist of extensions the library treats as asset filesSee the factory list below (40 entries including .zasset, .ma, .png, .wav and so on)Remove one → those files are ignored when collecting a whole folder and rejected on drop; add an unrelated one → unrelated files get collected as asset filesYes

What this list actually governs

ScenarioDescription
Collecting a whole folder into the libraryUses this whitelist to decide which root-level files count as asset files (geometry / textures / audio…); unknown ones are skipped
The Import from outside file chooserThe file filter is built from this list (see 8.4.2)
Drop acceptanceWhen dropping files into the asset area, this list plus the current category's supported import modes decide whether they are accepted

Note that it does not decide whether Maya can import a format (that is Maya's / the renderer's business), and it does not replace the geometry / image extensions on the Other configuration page (those only sort files when collecting a whole folder, see 8.9.9).

Things to watch when editing

  • One per line, with the dot (.fbx, not fbx); empty lines are ignored;
  • You must click Apply or OK to write the configuration; Cancel saves nothing;
  • Removing a common suffix shows up as "the files are there but never collected / drops are refused", the most common trap;
  • Adding unrelated suffixes (such as .txt) makes readme files get collected as assets.

警告

This is the library's recognition whitelist, and a mistake directly affects folder collection and drop import. Copy config.json somewhere safe before editing.
