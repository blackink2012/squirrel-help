一句话定位：修显示、补缺件、出证据、回滚四种"维护性动作"都收在这一颗按钮里 —— 它不动素材内容本身，只动清单、缩略图、无效条目、日志与覆盖历史。

怎么打开

在顶部工具栏，「面板与布局」右边、Maya 目标左边，那颗扳手/维护图标（提示「维护：重建索引 / 导出诊断日志」）。单击弹出菜单，不用先选任何东西。

菜单逐项详解

菜单项作用前提点了之后注意
重建资产索引删掉磁盘上的清单缓存，全量重扫当前库并刷新界面已打开一个资产库重建完成后弹窗给出「N 个资产 / M 个分类 / 耗时 X 秒」；有加载失败的资产会追加提示不动任何 .zasset、不删资产；资产很多时要等一会儿
补缺失缩略图…扫描整库，列出缺缩略图或只有占位图的资产，选中后无头补图已打开一个资产库弹「补缺失缩略图」窗口（默认全选），点「开始生成」后进「后台渲染」选项窗，再由独立 mayapy 进程出图只读扫描、不动场景；出图会覆盖这些资产的现有缩略图，详见 8.12.8
清理无效资产扫描缺 meta.json / 只有空目录的无效资产，确认后修复或移入回收站已打开一个资产库弹「清理无效资产」窗口：可打开路径人工核对、补回 meta.json、修复全部、清理全部（移入回收站，可还原）不会自动删目录；只有你点「清理全部」才移入回收站，详见 8.12.9
导出诊断日志…把日志、脱敏配置快照与资产清单打成一个 zip无（建议先重现问题）弹保存框（默认文件名 SquirrelAssetManager-logs-<时间戳>.zip），保存后提示路径不含任何资产文件内容；配置快照已脱敏
恢复历史版本…把当前选中资产「覆盖导出」前留的旧版还原回原位先在资产网格里选中一个资产弹「恢复历史版本」窗口，列出历史时间点；选中一个点「还原选中版本」历史来自覆盖导出；还原本身也会留一份历史，所以还原错了还能再退回去

重建资产索引：什么时候用

  • 资产明明在磁盘上，列表里却看不到 / 数量对不上；
  • 手动整理过库目录（不推荐）、或怀疑清单缓存损坏；
  • 换机器、拷贝过整个库之后第一次打开。

它做的是"重新读一遍磁盘"，不是"重算缩略图"、也不改资产的任何元数据。

补缺失缩略图：整库出图

不用逐个右键「后台渲染」，这一项直接扫全库：

  • 候选 = 缺 thumb.sicon 或只有占位图的资产；两类会在列表里分别标「缺缩略图」「只有占位图」；
  • 列表默认全选，可以 Ctrl / Shift 调整；右键可「定位到资产 / 打开资产路径 / 从列表移除」（移除只影响本次列表，重新扫描会回来）；
  • 点「开始生成」后先选渲染器 / 预设模型 / 环境光 / 尺寸与质量（8.12.6），再由独立 mayapy 进程批量出图（观察窗见 8.12.7）；
  • 出图会覆盖这些资产现有缩略图；作业在后台跑，不占用当前 Maya 视口。

旧版的「补几何格式」入口已移除：有几何体才有格式转换的来源，零几何无从补。单个资产的格式转换仍在右键「格式转换」里（8.5.16）。

清理无效资产：先看清，再决定

扫描的是「缺少 meta.json」与「空壳（无 meta、无有效文件）」两类：

  • 右键可「打开资产路径」人工核对、「从列表移除」（只移出列表，不动磁盘）、「修复：补回 meta.json」；
  • 底部「修复全部」只处理有有效格式文件的条目，空壳会被跳过并计数；
  • 底部「清理全部（移入回收站）」是唯一会动磁盘的动作，确认后进回收站，可在左栏还原（8.8.3）；
  • 修完 / 清完主窗口会自动重扫并刷新。

导出诊断日志：包里有什么

内容说明
日志插件运行日志（报错栈、命令耗时等）
脱敏配置快照app_settings.json 等配置的结构与取值，敏感字段已脱敏
资产清单当前库的资产 / 分类索引，用来复现"哪条记录不对"

不包含：缩略图、模型、贴图等资产文件内容。可以放心发给支持方排查。

恢复历史版本

历史来自覆盖导出：每次覆盖同一个资产前，旧版会留一份快照（默认保留最近 5 版或 30 天内）。窗口里选中一个时间点，点「还原选中版本」，文件回到原位；还原动作本身也生成一条新历史。

  • 资产从没被覆盖导出过 → 窗口提示「这个资产还没有覆盖历史」；
  • 没选资产就点菜单 → 提示先在网格里选中一个资产；
  • 多个文件分多次覆盖时，还原会逐文件处理，部分失败会单独提示成功 / 失败数。

常见疑问

现象怎么办
新建 / 移动资产后列表没跟上先点「重建资产索引」；仍不对再查 6.5.1
重建完资产数变少有资产加载失败（弹窗会写条数）；清单缓存本身没问题，去看失败原因
卡片图一直是灰的 / 占位图「补缺失缩略图…」整库补一次，或对单个资产右键「后台渲染」
列表里混进空缺目录「清理无效资产」先扫描，核对路径后再修复或清理
想找回被覆盖前的模型「恢复历史版本…」，前提是该资产当初是覆盖导出的
汇报问题时该给什么「导出诊断日志…」的 zip + 出问题的资产名 + 复现步骤
