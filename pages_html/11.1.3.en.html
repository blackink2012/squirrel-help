The plug-in's settings are split between the user directory and the preset directory of the plug-in package; know which is which before editing.

File overview

FileLocationMain contents
app_settings.json~/.squirrel_asset_manager/app_settings.jsonFont size, scaling, theme, language, view, library list and default library, AI provider and keys, bridge toggle, chat surface location, external tool choice
settings_preset.json~/.squirrel_asset_manager/settings_preset.jsonA snapshot of all interface preferences saved by General → Settings preset; used for import / export / restore (absent means no preset has been saved)
config.json<plug-in package>/Assets/preset/config.jsonSub-libraries and default categories, supported formats, texture suffixes, duplicate name policy, texture / dependency import policies, material presets
export_preset.json<plug-in package>/Assets/preset/export_preset.jsonDefault export formats per asset type, linked files and materials-only
context_menu_preset.jsonSame directoryContext menu item toggles per sub-library
double_click_preset.jsonSame directoryDouble-click commands and import sub-options per sub-library
pbr_mapping.jsonSame directoryPBR texture type aliases
library.jsonEach asset library rootLibrary version, name and sub-library list
FolderMetadata.fdataEach sub-library directorySub-library or category id, name and type

<plug-in package> means the squirrel_asset_manager directory and ~ the current Windows user directory.

How to find them

  1. Decide which kind of setting it is: interface preferences and the library list live in app_settings.json, everything else in Assets/preset/.
  2. Type %USERPROFILE%\.squirrel_asset_manager in the Explorer address bar to open the personal configuration directory directly.
  3. Preset files travel with the plug-in package; confirm which package is actually loaded before editing.

Editing and backing up

  • Prefer the Settings window over hand-editing JSON.
  • Copy to a same-named .bak before manual edits; restart the plug-in afterwards to verify.
  • When app_settings.json fails to load or its JSON is corrupt, defaults are used and the original is backed up as .bak or .corrupt_<timestamp>.
  • bridge_port.log and bridge_recover.log also appear in the same directory, for diagnosing bridge ports and disconnect recovery.
  • settings_preset.json is the local copy of "settings preset": to back up all interface preferences, generating a JSON with 「导出预设」 (Export preset) in the Settings window is safer.

Verify the result

  • After changing any setting and clicking Apply the matching file's modification time updates.
  • Settings survive a plug-in restart.

Tips

Warning: config.json and the preset files live inside the plug-in package, so back them up before reinstalling or overwriting the plug-in.

Tip: API keys in app_settings.json are stored as plain JSON, so never send that file to anyone.
