「资产详情」 (Asset details) opens a separate 「资产观察」 (Asset inspector) window that gathers the large image, several thumbnails and the complete metadata.

How to open it

  • Right-click an asset card and choose 「资产详情」 (Asset details) at the very bottom of the menu.
  • Double-click the preview image in the preview panel.
  • For assets with several versions the 「版本浏览器」 (Version browser) opens instead.

Window contents

Two columns with a draggable divider in between:

Left column (preview)

  • A square preview area on top: the current thumbnail at full size, the wheel switches when there are several, and GIF / MP4 animate.
  • A thumbnail strip below, shown only when there are several thumbnails; clicking switches the main image and the current one is highlighted.
  • The preview can be dragged straight into the Maya viewport to import, using the same path as dragging an asset card.

Right column (scrollable information cards)

CardContents
Title cardAsset name (large heading) plus the category breadcrumb
Details cardTwo columns of label / value: node type, asset type, size, resolution, software, renderer, color space, animation format, creation time (whichever exist)
Formats cardFormat chips of the importable files inside the asset (such as zmetal, ma)
Tags cardAll tags of the asset as chips; the whole card hides when there are none
Notes cardThe note text, selectable and copyable; the whole card hides when empty
Path cardFull path of the asset on disk, selectable and copyable; the whole card hides when unavailable

Right-clicking the preview inside this window opens exactly the same asset context menu as the grid, except that 「资产详情」 (Asset details) is no longer there, to avoid opening an identical window again.

Verify the result

The window title shows the asset name and the divider can be dragged to resize the columns. Switching thumbnails only changes the preview on the left; the information on the right still describes the current asset.

Tips

  • The default window size is computed from the screen and the interface scale; dragging the divider adjusts the column ratio, with the left column absorbing width changes while the right column keeps a fixed width.
  • Asset details are read-only; change the name, tags and notes back in the properties panel.
