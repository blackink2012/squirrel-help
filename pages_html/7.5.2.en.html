Batch conversion can process every image in a folder recursively, convert them all to the target format, and resize or preserve the directory hierarchy as needed.

Prerequisites

  • opencv-python and numpy are installed.
  • The input directory is readable and the output directory is writable.

Steps

  1. Open 「图像格式转换工具」 (Image format conversion tool).
  2. Set the input mode to 「选择文件夹」 (Choose folder) and click 「浏览...」 (Browse...) to pick the directory; the tool collects the images inside recursively.
  3. To limit the source formats, fill 「输入格式过滤」 (Input format filter) such as exr or png, jpg; empty means every supported format.
  4. Choose 「输出格式」 (Output format) and set JPEG quality, PNG compression level or TIFF compression as needed.
  5. Set 「输出位置」 (Output location); empty means the input directory.
  6. To resize, fill the width / height under 「输出分辨率」 (Output resolution); empty keeps the original size. Check 「保持宽高比」 (Keep aspect ratio) to avoid stretching.
  7. Choose 「保持层级结构」 (Keep hierarchy) or uncheck it so every file lands in one directory.
  8. Click 「开始转换」 (Start conversion) and watch the log and progress.

Verify the result

The log shows "processing" and the output path for each file, and the converted count at the end; the number of files in the output directory matches the filtered input count and their extensions match the target format.

Tips

  • Setting only the width or only the height computes the other side proportionally; setting both with keep-aspect-ratio scales by the smaller ratio.
  • The tool creates the output folder when it does not exist.
  • Large-resolution EXR decodes slowly; converting in batches reduces memory pressure.

Warnings

When a source file name does not follow Maya's rules (letters, digits, underscore and dot only, starting with a letter), the interface batch conversion renames the source file and the log says 「源文件已重命名」 (source file renamed). The command channel convert_image_format explicitly does not rename; if the source must stay untouched, copy it first and then convert.
