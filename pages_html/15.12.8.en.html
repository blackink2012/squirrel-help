One-line summary: the whole-library scan window opened from Maintenance → Fill missing thumbnails…: it first lists assets missing a thumbnail or holding only a placeholder, lets you choose, then hands the selection to headless batch rendering.

How to open it

  1. Top toolbar → Maintenance ▾ → Fill missing thumbnails…;
  2. It scans the current library immediately on opening (reading every meta in the library, so large libraries take a moment and the cursor becomes a wait cursor).

Prerequisite: an asset library is loaded; when none is loaded it asks you to open one first.

What the window contains

AreaContent
Summary line"Scanned N assets that need images (missing thumbnail or placeholder only)"; with none it reads "No assets need images: the whole library has thumbnails."
Hint lineExplains multi-select, the context menu and what Start generating will do
Asset listEach row shows "name / asset path · status", with only two statuses: missing thumbnail and placeholder only; selected entirely by default
Bottom buttonsFrom the left: Rescan, Start generating (N), Cancel

How to choose

  • Everything is selected by default, which suits routine maintenance;
  • To fill only some: Ctrl+click / Shift+click to deselect the rest;
  • Right-clicking a row (it opens on press) offers three items:
ItemEffectDescription
Locate assetSwitches the main window to the asset's sub-library / category, selects it and brings it forwardFalls back to selecting by path when the record cannot be found; this window changes no library state
Open asset pathOpens the asset's disk directory in ExplorerFor checking the asset content by hand
Remove from listTakes the row out of this list onlyUI only, nothing on disk; Rescan brings it back

After clicking Start generating

  1. The Background render options window appears first: renderer, preset model, environment light, size and quality (8.12.6);
  2. After confirming, a separate mayapy process renders the selected assets one by one; the progress window is in 8.12.7;
  3. The job runs in the background and does not occupy the current viewport or change the scene, so you can keep working in Maya;
  4. When it finishes the main window refreshes and the card images update.

Risks and how to undo

OperationRiskUndo
Start generatingIt overwrites those assets' existing thumbnails (placeholders are replaced too)Render again; the old image has no backup, so first save important images with Update thumbnail → Import
Remove from listOnly skipped this timeRescan restores it
Cancel midwayCooperative cancellation: it stops after the current asset finishesFinished images are kept, so fill in the rest next time

Troubleshooting

SymptomCauseWhat to do
The scan result is emptyThe whole library really does have thumbnailsUse Update thumbnail → Background render on individual assets
It reports no usable headless rendererkick / oiiotool is missing, or no same-version mayapySee "Troubleshooting" in 8.12.6
The image is still gray afterwardsThe asset lacks geometry, or rendering failedRead the progress window log, or capture / import an image manually
